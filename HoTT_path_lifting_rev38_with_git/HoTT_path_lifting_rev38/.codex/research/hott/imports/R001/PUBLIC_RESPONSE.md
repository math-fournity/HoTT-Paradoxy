## 一、本轮实际推进了什么

### 1. 把“阶段压平”推进为一个有明确前提的翻译障碍

我核对了 guarded lambda-calculus（gλ）中的固定点构造。它接受的不是任意普通函数，而是一个带延迟输入的函数：

\[
\mathrm{gfix}_A:(\triangleright A\to A)\to A,
\]

并满足：

\[
\mathrm{gfix}_A(f)
=
f\bigl(\mathrm{next}(\mathrm{gfix}_A(f))\bigr).
\]

这里的类型与固定点方程分别来自论文的 Example 1.9(3) 和 Lemma 3.9。([arxiv.org](https://arxiv.org/pdf/1606.09455))

接下来，我检验这样一组**翻译要求**：把 `▷A` 译成普通 `A`，把 `next` 译成恒等，同时保留完整的普通函数类型、应用、开放方程和目标中的替换。

对于布尔类型 \(B=\{0,1\}\)，这些要求会产生：

\[
G:(B\to B)\to B,
\qquad
\forall f:B\to B,\quad G(f)=f(G(f)).
\]

现在代入布尔否定 `not`：

\[
G(\mathrm{not})=\mathrm{not}(G(\mathrm{not})).
\]

无论左边是 \(0\) 还是 \(1\)，都与右边相反。因此，**这组翻译要求不能同时满足。**

准确的结果不是“HoTT 已经产生内部矛盾”，而是：

> **若保留真正的布尔区分，就不能同时完全擦除延迟、放开全部普通函数，并原样保留这项固定点能力及其方程。**

这比“时间消失了，所以可能有悖论”更具体：现在已经有了实际的源构造、明确的联合要求和可以逐步检查的不相容证明。

### 2. 找到了真实的忘却操作，说明不能把上述结果夸大

随后我反向检验：**有没有一种真正消去延迟的操作，却不会产生矛盾？**

有。在树拓扑斯的分阶段模型中，可以用“全局截面”取得相干的完整值。该模型的对象、阶段限制、`later` 和固定点结构都有明确的一手定义。([arxiv.org](https://arxiv.org/pdf/1208.3596))

根据这些定义，我展开了一个具体布尔实例：

| 比较对象 | 实际结果 |
|---|---|
| “当前布尔值”的完整取值 | \(0\) 或 \(1\) |
| “稍后布尔值”的完整取值 | 同样对应 \(0\) 或 \(1\) |
| 源模型中，从“稍后布尔值”到“当前布尔值”的合法态射 | **只有常0、常1两个** |
| 两个普通布尔集合之间的函数 | **常0、恒等、否定、常1四个** |

两个合法源态射为什么都只能是常值？因为最初阶段尚无输入值，输出已经必须确定；阶段之间的一致性又要求后续函数与这个初始决定相容。这个要求直接排除了“现在读取稍后输入”的恒等和否定操作。

所以，这个真实忘却确实消去了完整取值中的延迟区别，**却没有保留完整函数空间**。

这正好解释了为什么它不产生前面的矛盾：源固定点器仍只接受受限制的函数，不能突然把目标中多出来的 `not` 塞进去。

**这轮真正定位到的接口，是“对象取值相同”被提升成“全部操作也相同”的那一步。**这是一项明确的翻译合同障碍，不是“任何时间遗忘都会产生矛盾”。

### 3. 用交替流排除了一个容易复活的错误

我还构造了合法的交替流：

\[
0,1,0,1,\ldots
\]

以及相应的流函数：

\[
H(s)=0::\operatorname{map}(\mathrm{not},s).
\]

这条完整序列满足 \(a=H(a)\)。它是**流的固定点**，不是要求某个布尔值满足 \(b=\neg b\)。

因此：

> **把整个过程表示成一个对象，不等于把所有阶段的值压成同一个值。**

这项反向构造非常重要。项目现有 `guard-erasure-implies-fixed-point` 引理，已经明确以“所有阶段等于同一个值”为前提；不能把“整体可定义”直接当成这个前提已经得到证明。[已有源码](sandbox:/mnt/data/ALL-Markdown-snapshot/HoTT/formal/self-contained/ZCore.agda)

### 4. 进一步区分了两种不能混称的“时间问题”

本轮还写出了一个流模型中的对应证明：**满足固定前缀因果性的完整流函数，与该分阶段流模型中的自然态射相对应。**

这里的前缀因果性是：

\[
\text{输入在时刻 }n\text{ 前相同}
\;\Longrightarrow\;
\text{输出在时刻 }n\text{ 前相同}.
\]

这种性质可以由输入输出函数本身决定；函数相等时，该性质也随之保留。它与某个具体程序实现运行了多少步，不是同一类观察量。完整对应构造已写入[本轮证明 §6](sandbox:/mnt/data/HoTT_R001_skill_execution/.codex/research/hott/rounds/R001-20260909-guard-erasure/research-note.md)。

因此，未来不能因为两个问题都包含“时间”，就都套用“函数外延性必然抹去它”的论证。

这不是用“HoTT 能表示时间”关闭研究，而是把问题进一步分清：**哪些时间要求依赖外延行为，哪些依赖实现、历史或更强的可用性条件。**
