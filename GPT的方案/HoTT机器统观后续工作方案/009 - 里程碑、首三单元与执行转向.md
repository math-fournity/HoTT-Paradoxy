# 里程碑、首三单元与执行转向

## 1. 里程碑

| 里程碑 | 工作 | 可验结果 | 返回／转向 |
|---|---|---|---|
| `M0` | 读取完整方案；FR-001；获准时 VC-001 | active source identity 与可恢复证据闭合 | 高价值批次可恢复后停止整理 |
| `M1-A` | PSJ-001A C-71–C-76 | 一个形式判词＋一个提升判词 | 不等所有候选，转 TGSQ |
| `M1-B` | TGSQ-001A | 双分支八项分母＋holdout＋首轮 source verdict | 回 PSJ 第二候选 |
| `M1-C` | PSJ-001B C-96–C-99 | P0/P1＋PromotionSource＋essentiality | 决定直达 A1 或转 M2 |
| `M2-A` | ATD 最多两个任务族 | source-grounded consumer 或具名无命中 | 只对命中任务建 OTM |
| `M2-B` | R4X formal target＋arithmetic-only | generic 或 HoTT-essential 终局 | generic 停止同型深化 |
| `M3-A` | CAN 五对照 | canonicity 精确分类 | 有 source consumer 才入 A1 |
| `M3-B` | TGF/OTM/HoTT bridge | same-task correspondence | 无来源不造现实 witness |
| `M4` | proof、ablation、countermodel、positive control | candidate evidence package | 走 P0/P1/A1 阶梯 |
| `M5` | 六生成器、coverage、independent holdout | 声明范围 coverage/fairness | unexpected result 修 taxonomy |
| `M6` | 中间／最终报告 | material claims 可重建 | 根 Goal 只按最终门完成 |

不以固定周数改变数学判词。每个里程碑按证据完成或停止。

## 2. 第一单元：PSJ-001A / DELAY-RACE-DEADLINE

### 输入

- C-71–C-76 source/proof/run/index；
- Delay/result equivalence/set quotient；
- `bind`、race、deadline observation；
- 相关论文、库 API 和 source consumer；
- current target、comparison calculus、refined representation。

### 动作

1. 冻结九字段；
2. 冻结 comparison pool 与 translation obligations；
3. 搜先在 PromotionSource；
4. 核 same task；
5. 做 P0/P1 ablation 与独立 HoTTEssentiality；
6. 运行正控制；
7. 给形式层与提升层判词。

### 交付

```text
PSJ TaskSpec
source denominator/receipt
comparison/preservation record
candidate judgment report
no new proof unless exact new theorem appears
```

## 3. 第二单元：TGSQ-001A / DENOMINATOR-FREEZE

### 输入

用户时间/时序核心原文、已有 Theory Schema、HoTT/几何/物理数学/应用来源候选。

### 动作

1. 分开 TIME-STRUCTURE 与 TEMPORAL-ORDER；
2. 各冻结八项 source denominator；
3. 冻结六维 holdout；
4. 选择首批来源；
5. 提取 Path/interval/HIT/transport 被赋予的实际解释；
6. 给三终局。

### 交付

不开始圆环形式化；先交 denominator、source manifest、资格判词、remainder 和 TGF 是否有资格。

## 4. 第三单元：PSJ-001B / SAME-FUNCTION-DIFFERENT-TIME

### 输入

C-96–C-99、funext 规则、程序／函数表示、来源化资源任务、cost/trace 观察和细化正控制。

### 动作

1. 判断 funext 是否是现象必要条件；
2. 比较具名非 HoTT calculus/model；
3. 查谁实施“函数相等＝过程完整身份”；
4. 核任务来源与 same task；
5. 给 P0/P1、PromotionSource、HoTTEssentiality 与 A1 判词。

## 5. 三单元后的证据复盘

| 结果 | 转向 |
|---|---|
| 任一候选 `REALITY_RELATIVE_CANDIDATE_READY_FOR_PROOF` | 暂停宽搜，直达 OTM/bridge/proof/holdout |
| 两候选均 general/boundary | 启动 ATD＋R4X，不在同族换故事 |
| TGSQ `INTERPRETATION_SOURCE_FOUND` | 启动 TGF |
| TGSQ no-use within denominator | 关闭本 pass，不把 Path 强行物理化 |
| TGSQ 多解释冲突 | 先查已有 ruling；无法消解才请用户选择 |
| comparison preservation 未闭合 | 保持 INCONCLUSIVE，不作 P0/P1 |

## 6. 每个 bounded unit 的十项

1. 本轮减少哪个关键 unknown；
2. exact input/calculus/source/task/version；
3. 八轴 cell；
4. generator/reducer/consumer/observation/completion；
5. proof/model/runtime/source/correspondence oracle；
6. positive/negative/ablation/strongest counter-explanation；
7. finite remainder 或 infinite fairness；
8. result status 与禁止外推；
9. holdout/out-of-envelope；
10. successor/stop/reopen。

来源资格化、反模型或错误定位可以成为完整单元；不强迫每轮产出新构造，但必须减少会改变选择的 unknown 或留下失败证据。

## 7. 反停滞

连续两个单元只有 re-pin/格式/索引变化，且没有必要的正确性原因时，触发父目标复盘。相同失败重复时换 generator、consumer、comparison 或子问题，不改名维持活跃。

当一条真实候选出现，广度工作让位于贯通候选；当候选被同任务正控制排除，立即回覆盖图选不同机制。

## 8. R4 的位置

R4 只后移 FR＋两个短判决单元，不废弃。其 TaskSpec 尚未实现，先修提升／来源未知可以避免在第三套编码或不保真受限方言上深化后返工。
