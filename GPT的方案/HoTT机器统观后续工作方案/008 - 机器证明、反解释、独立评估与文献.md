# 机器证明、反解释、独立评估与文献

## 1. 候选进入 proof 的条件

只有出现尚未由现有 C-claim 覆盖的精确数学命题，才新增 proof package。先固定：

- claim/proof ID；
- 命题全文、量词、假设、universe、calculus；
- 自然语言与形式命题的逐项对应；
- source-grounded task 与 consumer；
- positive/negative/ablation controls；
- source manifest、依赖、禁止外推。

探索猜想不强迫形式化；但未过门禁不能作为已成立数学结论交付。

## 2. F-011 证据链

```text
HoTT/formal/<topic-or-claim-id>/
  proof source + project/toolchain identity

HoTT/verification/runs/<run-id>/
  RUN.json

  stderr.txt
  environment.txt

  index-row-manifest.json when required
```

HoTT/univalence/cubical/HIT/Path 命题使用原生系统或已有机器证明的保真翻译。普通 Python 枚举、Lean `Eq`、文件存在或 compile success 不替代 exact HoTT 证明。

## 4. 最强反解释

每个候选主动尝试：

- 保留 label/modulus/representative/trace；
- 显式 clock/stage/temporal order；
- crisp/global/modal/context restriction；
- transport/coherence evidence；
- pointwise-fibrant input；
- comparison calculus；
- task 的强弱版本是否被混淆；
- source consumer 是否已经声明限制。

若反解释在不改变 input/observation/completion 时完成，候选降为 boundary/defense。若只有换任务才能恢复，现实相对不相容继续。

## 5. 中性义务分类

```text
DATA_RETENTION
ASSUMPTION_STRENGTHENING
MODAL_OR_CONTEXT_RESTRICTION
THEORY_EXTENSION
IMPLEMENTATION_LIMITATION
POSITIVE_CONTROL
```

只有同时满足以下五项，才标 `ABSTRACTION_DEBT_CANDIDATE`：

1. 附加项是抽象前同任务已有前提／区分；
2. 抽象确实删除或使其不可恢复；
3. source consumer 本质依赖；
4. 恢复不改 task/input/observation/completion；
5. 不是原任务未要求的统一化义务。

`DEFENSE_WORKS_WITH_EXPLICIT_PAYMENT` 不自动等于债务；它可能是诚实适用域。

## 6. 六类 holdout

1. source holdout；
2. 不同作者／项目任务；
3. natural consumer holdout；
4. 第二 kernel/framework transfer；
5. temporal historical prediction；
6. defense 应成功的 negative holdout。

每项声明：selection、author/project、temporal、framework、consumer、visibility 六维独立性。不满足的维度必须披露。

## 7. 评价指标

不按文件数、候选数或行数评分。评价：

```text
unique valid candidate count
invalid or ill-typed rate
source-grounded rate
PromotionSource hits
same-task preservation
HoTTEssentiality
positive-control survival
out-of-envelope remainder
human and compute cost per adjudicated candidate
```

AI-guided、规则驱动和随机／枚举 generator 在同 denominator、预算、oracle 下比较；AI proposer 不读 holdout golden。

## 10. 文献覆盖验收

只有具名渠道／场馆／查询、全文读取、前提抽取、实验映射、backward/forward citation 和 holdout 闭合，才称“截至某日、声明范围内覆盖”。搜索结果数或 41 个标题不能承担全面覆盖。

新来源经 unknown ingress 进入新 revision；不偷偷顺延旧分母。
