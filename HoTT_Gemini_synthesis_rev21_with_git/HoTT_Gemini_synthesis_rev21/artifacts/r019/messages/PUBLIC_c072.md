*   **现实对照组（遵循时序）：** 程序 `reality_not(True)` 瞬间停机，给出结果 `False`。
*   **HoTT 理论组：** 使用单价公理 `ua(not)` 将取反动作空间化为路径，执行 `transport(ua(not), true)`。
*   **致命揭露：** HoTT 的静态类型检查器傲慢地宣称“这是一个合法的 `Bool`”，绕过了对计算路径的 `ASK`。但底层时序求值器当场罢工，机器死死卡在 `transport(ua(not), true)`。
*   **证明结论：** 理论用静态拓扑掩盖时序，导致本应瞬间完成的计算被**异化为永远无法走通的空间黑洞**。

### 机器证明二：现实无法完成，理论假装已完成（非法过程的静态化）
*   **现实对照组（遵循时序与ASK）：** 我们在 Python 中写了一个 `while` 循环去寻找不可停机程序的步数（模拟罗素悖论构造）。程序诚实地陷入死循环，打出 `TIMEOUT_ERROR_NON_TERMINATING`。这在计算理论中是完全坦然的——非法提问，拒绝停机。
*   **HoTT 理论组：** 理论利用命题截断和唯一选择原则，直接从一个非构造性的纯逻辑证明 `||halting_step||` 中提取出了步数 $n$：`extract_value(...)`。
*   **致命揭露：** HoTT 的静态类型检查器再次傲慢地宣称“我已经提取出了步数，它是一个合法的自然数 `Nat`！”。但当底层机器试图把这个数打印出来时，发现这只不过是一张皮：`extract_value(...)`。里面**没有任何从 0 推进到 n 的计算构造**！
