# 测量口径与方法

## 一、三类成本的定义（本报告严格区分）

| 类别 | 定义 | 例 |
|---|---|---|
| **上下文成本** | 按治理合同必须**全文经过模型会话**的文本（读义务） | always_full_boot、always_full_documents、research_full |
| **写作成本** | 每工作单元必须**新产生**的文本（写义务） | SESSION.md、CORE_COGNITION_AUDIT、RUNS.json |
| **磁盘成本** | 只占存储、不进上下文的累积 | checkpoints before/after、sessions 档案、~/.codex/sessions |

判断"是否上下文成本"的权威依据链：根/`.codex` AGENTS → `LOAD_SET.json`（层归属）→
`cognition_runtime.py` graph()（实际组装规则）→ `read_chunk`/`check_coverage`
（`FULL_EMITTED_BYTES_MATCH` 要求 plan 内每个文档的每个字节都被发射过）。
runtime 自己声明 `model_context: NOT_CERTIFIED_BY_TOOL`——即合同要求的是**发射义务**，
本报告测的是**发射义务的量**，不是模型内部实际保留量（后者见 011 未验证项）。

## 二、est tokens 公式

```
est_tokens = CJK 字符数 × 1.0 + 非 CJK 字符数 ÷ 3.8
```

- 依据：主流 tokenizer（cl100k/o200k 系）对中文≈1 token/字、对 ASCII/markdown≈3.5–4 字符/token
  的经验行为。CJK 判定含 CJK 统一表意、扩展 A/B、兼容、CJK 标点与全角区段。
- **误差带 ±20%**。所有表格同时给出 bytes/lines/cjk，任何读者可用自己的 tokenizer 重算绝对值；
  排名与占比结论对 tokenization 选择不敏感（量级差都是 3–200 倍级）。

## 三、配套脚本（本目录 `measure_context.py`，可直接复算）

```python
#!/usr/bin/env python3
"""口径：est_tokens = CJK×1.0 + 非CJK÷3.8；只统计解码后文本字符。"""
import argparse, os, sys

def is_cjk(ch):
    cp = ord(ch)
    return (0x4E00 <= cp <= 0x9FFF or 0x3400 <= cp <= 0x4DBF
        or 0x20000 <= cp <= 0x2A6DF or 0xF900 <= cp <= 0xFAFF
        or 0x3000 <= cp <= 0x303F or 0xFF00 <= cp <= 0xFFEF)

def measure_file(path):
    raw = open(path, "rb").read()
    text = raw.decode("utf-8", "replace")
    cjk = sum(1 for c in text if is_cjk(c))
    return {"bytes": len(raw), "lines": text.count("\n"), "cjk": cjk,
            "other": len(text) - cjk, "tokens": cjk + (len(text) - cjk) / 3.8,
            "path": path}
# walk() 递归目录、跳过 .git/__pycache__/node_modules/.pytest_cache，
# 按 --ext（默认 .md,.json）过滤，按 est tokens 降序输出；--sum-only 只出总计。
```

（完整可运行版本以目录内文件为准；此处为口径摘录。）

## 四、加载链重建方法（profile 总额怎么来的）

1. `cognition_runtime.py plan` 是权威出口，但**当前被 `UNCOMMITTED_STATE` fail-closed 拦截**
   （`.codex/research/hott/RESUME.md` 与 `HEAD.json.tracked` 哈希不一致，见 008）。
   测量未修改任何状态去绕过它。
2. 因此按 graph() 源码规则手工重建（规则逐一读自 `.codex/tools/cognition_runtime.py:242-340`）：
   - governance = always_full_documents（四件套，分片展开为索引+全部分片）

       R4-HOTT-NAT-EFFECTIVITY-001.md、Atria的方案/修订片/008）；
   - research = governance + research_full 5 项；
   - 系统化研究 = research + HOTT-PARADOX-PROGRAMMATIC-EXPLORATION-COMPLETENESS（索引+分片）。
3. 去重规则与 graph() 一致（同 path 只计一次）；`核心认知.manifest.json` 属 query_first
   层，未计入全额加载（仅在被动提升时进入）。

## 六、口径限制（诚实边界）

1. est tokens 非 tokenizer 精确值（±20%）；不影响任何量级结论。
2. 未回放真实会话 trajectory（模型实际注入/保留量），只测**合同义务量**；
   复核入口见 011。
3. RTK hook 会压缩 Bash 工具回显，但 `measure_context.py` 的输出经 python 子进程打印，
   数字取自脚本 stdout 原文；关键数字已用独立命令（wc -c、jq 式 python 解析）交叉。
4. `~/.codex` 全局侧为 2026-09-18 晚实况快照，其 AGENTS.md/skills 后续变化不在本报告内。
5. 磁盘数字（du）含文件系统块开销，与 bytes 合计略有出入，只用于量级。
