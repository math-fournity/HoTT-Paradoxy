## 十一、G2 映射控制增量（2026-10-04）

**新增的可恢复事实：** Foundation 中的 ZFC `SetTheory` interface 和 generic `ArithmeticTheory` Gödel interface 是两个不同的类型入口。该 source tree 内没有自动的直接实例化；Lean 的预期拒绝已由 `20261004-SOURCE-REPLAY-FOUNDATION-ZFC-GODEL-GAP-001` 保存。

同一 receipt 的 source scan 还保留一个必要的反向控制：Foundation 的 SetTheory 模型层确实有 `ω`、natural-number recursion、`CSeq`／`result` 与 definability；因此本卡不是“集合论无法表示时间或递归”。它只是说明 fixed source tree 没有把这些模型资产实现为 `ZFC ⊲ ArithmeticTheory` 的 concrete `DirectInterpretation` instance。

**它改变的决策：** 不改变 G0 的三类来源分母和 parent-process underdetermination；它只把 G2 的最小前置条件具体化为“提供并验证实际 interpretation／arithmetization”，并禁止借同源共存跳过这一项。

**仍开放的关键项：** 同一 source 的 `OriginDone`、`ρ`、bridge；actual acceptance 的 T 内 code/check/representability；任何 target-specific diagonal 或 reflection theorem。

**G2 的新增不可跳过条件：** 任何未来 target mapping 除 `Code/Check/Diag` 外，还须交付 code 到 T 内 numeral/term 的 correspondence，以及外部 proof relation 到 T 内 `Prov_T` formula 的 adequacy。缺任一项时，结果只能保持在 M 层或 source inspection。

**下一动作与失效条件：** 下一自然工作单元仍以一个统一 source interface 为门。若出现真实映射 source 或 user 重新固定 target theory/过程合同，则重新读取本 closure、对应 run receipt 和 GodelizationCard；不能用这次 direct type mismatch 推出数学上的不存在。
