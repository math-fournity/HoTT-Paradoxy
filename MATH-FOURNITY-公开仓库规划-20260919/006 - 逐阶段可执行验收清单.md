# 逐阶段可执行验收清单

## 0. 使用合同

本清单是未来构建公开结果包的**执行合同**，不是 P1–P4 已完成的声明。每个 check 都在同一条证据链中记录：输入快照、实际命令或人工动作、PASS/FAIL oracle、产物 locator、执行环境、时间和责任边界。

状态只可取：`NOT_STARTED`、`PASS`、`FAIL`、`BLOCKED_ON_USER`、`NOT_APPLICABLE_WITH_REASON`。没有对应 evidence locator 的“完成”一律无效。任一 `FAIL` 或 `BLOCKED_ON_USER` 停在所属阶段；不得跳到后续阶段、CI badge、公开 README 宣称、commit、push 或发布。

所有未来 check 的默认恢复规则：保留 source receipt、staging、失败日志和当前 manifest；不删除历史 run、不重写旧 receipt、不用手工编辑 hash 制造 PASS。修复后创建新的 receipt，并明确它验证的是新 snapshot。
