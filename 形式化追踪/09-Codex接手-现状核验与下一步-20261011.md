## 2. 唯一剩余缺口：Z0 完整形式的 D3（= `ShCraigElim`）

精确阻塞引理（带 `sorry`，不进收据源）：

```lean
-- HoTT/formal/claude-cg001/godel-q-zfc-z0-full/GodelQ/ZFC/Z0Blocked.lean:29
theorem zfcTr_D3_internalize {V : Type*} [ORingStructure V] [V↓[ℒₒᵣ] ⊧* 𝗜𝚺₁]
    (τ : ArithmeticSentence)
    (h : Provable 𝗭𝗙𝗖 (⌜arithTrln.translate τ⌝ : V)) :
    Provable 𝗭𝗙𝗖 (⌜arithTrln.translate (zfcTr τ)⌝ : V) := by sorry
```

**归约链（已证部分可收据，只剩最右一格）**：

```
ShCraigElim            ← 真正的数学内容，要证的是它
   （Z0UniBridge.ShCraigElim: ∀ σ, Provable Sh.craig ⌜σ⌝ (V) → Provable 𝗭𝗙𝗖 ⌜translate σ⌝ (V)）
  ⇒ bwd_of_shcraig_elim   (C-390，已收据)
  ⇒ bwd ⇒ keyE
  ⇒ zfcTr_D3_internalize  (Z0Blocked.lean:29，带 sorry)
  ⇒ Z0Full.zfc_z0_full_of_D3_internalize
  ⇒ 𝗭𝗙𝗖 ⊬ (𝗭𝗙𝗖.consistent)ᵗ   ← Z0 完整形式，主线即完成
```

`ShCraigElim` 的数学含义：把 V 中一条 `Sh.craig` 推导的**编码**翻译成一条 `𝗭𝗙𝗖` 推导的**编码**。
这不是语义完备性（`Foundation.of_provability` 是语义的，搬不进非标准 V），而是**语法的推导翻译**，
这正是第三份 AI 反馈里“真实缺口 = `Provable Sh.craig → Provable 𝗭𝗙𝗖` 的语法翻译”与仓库归约链一致的地方。

> **2026-10-11 三次更正（实测复核，本机 Lean 4.34.0）**：本节原文写的「99 行」「8/9 支已编译通过」

> **动手前按本条的实测数字，不要按下面的「99 行/8-9 支」描述。** 下面的根因分析与对照
> （`SeqTranslateFormula.lean:344` 的 `isSemiformula_iT`）方向仍然可用。

- **8/9 支已编译通过**：`rel`/`nrel`/`verum`/`falsum`/`and`/`or` 以及归纳框架本身都过。
- **仅剩 2 个 quantifier 支失败**：`all`（第 93 行）与 `exs`（第 99 行）。
- 报错核心：`rewrite failed: Did not find an occurrence of
  neg ℒₛₑₜ (result ℒₒᵣ iT.construction (iT.construction.allChanges param 0) p) in the target ...`，
  目标里是 `iT (iT.construction.exsChanges param 0) (neg ℒₒᵣ p)`。
- **根因（已定位，是机械错误，不是死路）**：在 `all` 支里用了 `iT_all`/`iT_exs`，
  它把 LHS 写成 `iT (exsChanges param 0) (neg p)`；而归纳假设 `ih 0` 的键是
  `allChanges param 0`（两者 definitionally 都等于 `param+1`，但 `rw` 不会自动把 `exsChanges` 展开成 `allChanges`）。
  对照 `SeqTranslateFormula.lean:344-355` 的 `isSemiformula_iT` 同形 `all`/`exs` 支，
  它直接用 `iT.construction.result_all`/`result_exs` 而不用 `iT_all`/`iT_exs`，LHS 自然就是
  `result (allChanges param 0) p`，与 `ih 0` 对得上。
- **修法（未应用、未实测，但方向确定）**：把 `all`/`exs` 支里那句方向写反、且把 `exsChanges` 当目标的
  `show` 改写为先把目标 LHS 的 `iT (exsChanges param 0) (neg p)` 改写成 `iT (allChanges param 0) (neg p)`
  （`by simp [iT.construction]`），再 `rw [← ih 0 (by simp [iT.construction]) (by simp [iT.construction, h])]`，
  最后 `simpa [iT.construction, neg, imp, domZero]`。这与 `isSemiformula_iT` 的收尾完全一致。
