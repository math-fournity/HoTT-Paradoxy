| 运算 | 对 `^#z`（bvar） | 对 `^&x`（fvar） |

## A2. 三个关键的技术发现

### (a) `Semiformula.quote_shift` 的层级错配可以绕过

`Semiformula.quote_shift` 要 `Semiproposition`（`ξ = ℕ`），
而 `cFuncN` 的码在 `Semisentence`（`ξ = Empty`）层。
**两者在 `V` 层的码由 `rfl` 相同**，故 `show` 改型即可用：

```lean
lemma shift_quote_sentence {n : ℕ} (σ : Semisentence ℒₛₑₜ n) :
    shift ℒₛₑₜ (⌜σ⌝ : V) = ⌜σ⌝ := by
  have h : Rewriting.shift (σ : Semiproposition ℒₛₑₜ n) = (σ : Semiproposition ℒₛₑₜ n) :=
    rew_shift_eq_self _ (not_fvar_emb σ)
  rw [show (⌜σ⌝ : V) = ⌜(σ : Semiproposition ℒₛₑₜ n)⌝ from rfl,
      ← Semiformula.quote_shift (V := V) (σ : Semiproposition ℒₛₑₜ n), h]
```

这是 §2 里记为「卡点」的那一步的解法。

### (b) `induction_setup` 的 `P` 谓词有语义问题，必须换成 `Q`

`Provable T φ` 内部是 `∃ d, Proof d φ`，而 `Proof d φ := DerivationOf T d {φ}`——
**要求结论 sequent 恰好是单元素集**。`translateSeq s` 一般不是单元素集，
故 `P d := Provable 𝗭𝗙𝗖 (translateSeq (fstIdx d))` 在 `s ≠ {φ}` 时几乎必然为假。

**正确的不变量是 `Q d := Derivable 𝗭𝗙𝗖 (translateSeq (fstIdx d))`**（sequent 层）。
`ShCraigElimSetupQ.induction_setup_Q` 是本轮新增的 `Q` 版，7 支已接入。

### (c) `hAll`/`hExs`/`hRoot` 的障碍已**精确刻画**（三轮反例）

三条剩余支都是**跨语言翻译**的实质困难，不是技术细节：

| 支 | 障碍 | 三轮反例 |
|---|---|---|
| `hAll` | `iVE` 的 `eqAtom` **自带绑定变量 `#0`**，外层 `subst` 必然穿透改它；而 `iT` 在绑定层下用 `substs_all` 的**保护**语义（`qVec` 首分量换成 `^#0`）。两种语义不可调和 | 第十二轮：`termSubst ?[^&0] ^#0 = ^&0` vs `termSubst (^#0 ∷ ^&0 ∷ 0) ^#0 = ^#0`；第十五轮：`p` 含 `all` 时两边 `imp domZero` 层数 1 vs 2；第十八轮：`iVE 1 ^#0` 经 `subst` 得 `^&0 ∷ 0 ∷ 0` vs `^#0 ∷ ^&0 ∷ 0` |
| `hExs` | 同 `hAll`（`substs1` 版） | 同上 |
| `hRoot` | **就是 D3 本身**：`p ∈ Sh.craig.Δ₁Class → Provable 𝗭𝗙𝗖 (iT 0 p)` | 无（这是定义层的事实） |

**已排除的路线**（不要重复尝试）：
* 「`iT` 与 `free`/`subst` 逐层交换」——三轮反例覆盖朴素/层数对齐/`qVec` 对齐三种形状；
* 「`iT 0 (free ℒₒᵣ p) = free ℒₛₑₜ (imp domZero (iT 1 p))`」——已证伪。

**一条已探过但未完成的路线**：`hAll` 不需要**等式**，只需要**可导性传递**。

第二十轮实测了这条路的**正确形状**（`probes/` 里的 ProbeBB 一轮）：

```
replace_of_imp : Derivable (insert (imp A B) ∅) → Derivable (insert A S) → Derivable (insert B S)
```

`cut A` 的第一条分支（`insert A (insert B S)` ← `wk`）**已经打通**，
第二条（`insert (neg A) (insert B S)`）需要把 `imp A B = neg A ⋎ B`
与 sequent 里已有的 `¬A`、`B` 组合——**这一步的 sequent 演算设计尚未完成**。

**关键判据**：若 `replace_of_imp` 能证成，则 `hAll` 只需再证一条
**算术蕴含式** `⊢ free ℒₛₑₜ (imp domZero (iT 1 p)) → iT 0 (free ℒₒᵣ p)`
（方向待定），而那是一条 𝗭𝗙𝗖 内部的公式可证性，属于 Σ1 完全性的范围。

**注意**：这条路**不再要求两公式相等**，与已被证伪的三轮反例不冲突。

**第二十一轮：完整证法已写出，只剩两处 Lean 细节**

正确形状需要 **A ↔ B（双向）** 而非单向，完整证法：

```
replace_of_iff : Derivable (insert (imp A B) ∅) → Derivable (insert (imp B A) ∅)
               → Derivable (insert A S) → Derivable (insert B S)
```

证法：
1. `cut A`：
   * (i) `insert A (insert B S)` ← `wk hd` ✅ **已打通**；
   * (ii) `insert (neg A) (insert B S)` ← 用 `hBA`（`¬B ⋎ A`）：
     先 `wk` 把 `¬B ⋎ A` 搬进 sequent，再 `or_m` 于 `(¬B ⋎ A)`，
     得 `insert (neg B) (insert A (insert (neg A) (insert B S)))`，
     该 sequent 含 `A` 与 `¬A`，`Derivable.em` 直接收尾 ✅ **结构已通**。

**剩余的两处 Lean 细节**（探针 `probes/W8-replace_of_iff-attempt-20261011.lean`）：
* `Derivable.wk` 的 `s'`（源）是 `insert (imp B A) ∅`，
  而 `imp B A` 与 `neg B ⋎ A` 是 `rfl` 相等——需要显式 `show` 或 `simp [imp]` 对齐；
* `IsFormulaSet` 对目标 sequent 的逐元素证明（5 个分支）。

**证完后的 `hAll` 收尾**：再证一条 𝗭𝗙𝗖 可证的算术蕴含式
（`A := iT 0 (free ℒₒᵣ p)`、`B := free ℒₛₑₜ (imp domZero (iT 1 p))`，
方向待定），属 Σ1 完全性范围。**这条路前景明朗**。

**第二十四轮更正：`intro_and` 是假命题**

上一轮说「`intro_and` 用 `Derivable.and` + 两次 `wk`」——**错了**。
逐步算清后发现：

```
h : Derivable (insert p (insert q s))
目标 : Derivable (insert (p ⋏ q) s)
```

`wk` 需要 `insert p (insert q s) ⊆ insert p (insert (p⋏q) s)`，
但 `y = q` 在左边而不在右边——**不是包含关系**。

`Derivable.and` 要 `Derivable (insert p s)` 与 `Derivable (insert q s)`，
而 `h` 给的是 `insert p (insert q s)`——**也不是同一个形状**。

**根本原因**：sequent 的语义是「析取」，
`{p, q} ∪ s` 对应 `¬p ∨ ¬q ∨ ⋁¬s`，
而 `{p, p⋏q} ∪ s` 对应 `¬p ∨ ¬(p⋏q) ∨ ⋁¬s = ¬p ∨ ¬p ∨ ¬q ∨ ⋁¬s`。
后者**更强**（多一个 `¬p`），故 `intro_and` 不成立。

**这不影响 `hAll`**：`split_or`（已证，进生产）是对的方向——
它把 `p ⋎ q` 拆成 `p` 与 `q`（析取在**结论**侧是弱的，可拆）。
`intro_and` 那条路本来就是我猜的，现在排除了。

**第二十五轮：`replace_of_imp` 已证并入生产（exit 0）** ⭐

```
replace_of_imp : Derivable (insert (neg A ⋎ B) ∅) → Derivable (insert A S)
               → Derivable (insert B S)
```

证法（**关键**：用 `split_or`）：
```
cut A
  (i)  insert A (insert B S)        ← wk hd                      ✅
  (ii) insert (neg A) (insert B S)  ← split_or (¬A ⋎ B) 得
                                      insert (neg A) (insert B ∅)，再 wk  ✅
```

`split_or` 正好把 `¬A ⋎ B` 拆成 `¬A` 与 `B`——两条引理配合得天衣无缝。

**`hAll` 的收尾现在只差一条算术蕴含式**：

```

```

**注意方向**：用 `replace_of_imp` 时，`A` 是 `hd` 里的公式、`B` 是目标里的。
`hd : Derivable (insert (iT 0 (free p)) S')`、目标 `insert (free (imp domZero (iT 1 p))) S'`。
故 `A := iT 0 (free ℒₒᵣ p)`、`B := free ℒₛₑₜ (imp domZero (iT 1 p))`，
需要证 **`⊢ ¬A ⋎ B`**，即 `⊢ A → B`。

**这是 `hAll` 现在的唯一剩余障碍**，且它是**算术公式的可证性**——
属 Σ1 完全性的范围，不再是结构问题。
