## Z0 是什么

- 【原话】十三条 [1]（KC-000063）：“……我们甚至还可以找到Q0（H0（Z0）），意思就是Q0是ZFC的Q，其实对应了H0在ZFC中的对应物Z0。”
- 【判断】Z0 的候选，是 ZFC 对自身矛盾的逐步搜索（CG-005 设计 §3）。它和 H0 逐字段同形：都是逐步追问，都有局部判定，都是找到就停。差别在于，HoTT 能证明自己宇宙上的追问永不停（C-78），ZFC 却证明不了自己的矛盾搜索永不停（哥德尔第二定理）。
- Z0 的 UR：“检查自己会不会自相矛盾，本来是很简单的事——一直查下去就行——甚至在 ZFC 中都做不到。”

### (c) 的收窄（2026-10-09，CG-007 W8，CG001-C-121、C-122）

原计划的形状是“𝗜𝚺₁ ⊢ Con(𝗭𝗙𝗖) → Con(Sh.craig)”。Foundation 的 `Sh.craig` 一致性句来自 `codeOfREPred`，那是用选择公理挑出的某个 Σ1 公式；它在 ℕ 中正确，在非标准模型里的行为由这次选择决定，因此这条桥在 𝗜𝚺₁ 内部无从推理。改用**显式**谓词 `𝔅Z(x) := Provable 𝗭𝗙𝗸 (iT 0 x)`（没有选择，逐字由 C-119 的内部翻译 `iT` 给出）作为 `Provability 𝗜𝚺₁ Sh`，沿 Foundation 的抽象第二定理 `con_unprovable` 逐条核对它的前提：

| 前提 | 状态 |
|---|---|
| D1 | ✅ 定理（`iT_quote` + `internalize_provability`） |
| D2（HBL2） | ✅ 定理（`modus_ponens_sentence`） |
| 对角化 | ✅ Foundation 对 𝗜𝚺₁ 自带 |
| `𝗜𝚺₁ ⪯ Sh` | ✅ C-110 |
| `Sh` 一致 | ✅ C-103 |
| **D3** | ◐ **唯一阻塞引理** |

D3 被固定成 `godel-q-zfc-z0-full/GodelQ/ZFC/Z0Blocked.lean:zfcTr_D3_internalize`：

```lean
theorem zfcTr_D3_internalize {V : Type*} [ORingStructure V] [V↓[ℒₒᵣ] ⊧* 𝗜𝚺₁]
    (τ : ArithmeticSentence)
    (h : Provable 𝗭𝗙𝗸 (⌜arithTrln.translate τ⌝ : V)) :
    Provable 𝗭𝗙𝗸 (⌜arithTrln.translate (zfcTr τ)⌝ : V)
```

读作：“𝗭𝗙𝗰 证明了 τ 的翻译，那么 𝗭𝗙𝗰 也能证明‘𝗭𝗙𝗰 证明了 τ 的翻译’这句话的翻译。”这就是经翻译的形式化 Σ1 完全性。Foundation 对算术理论的 D3 有完整机器证明（`DerivabilityCondition/D3.lean`，179 行，加 `PeanoMinus`/`EquationalTheory` 共约 1080 行），但它服务的是 `T.standardProvability`（谓词 `Provable T ⌜σ⌝`，T 是算术理论）；本处谓词作用在**翻译后**的公式上，不能直接套用。Foundation 的 `LK/Interpretation.lean:443 of_provability`（`U ⊢ σ → T ⊢ π.translate σ`）用完备性定理**语义地**证明，其中没有可搬进 𝗜𝚺₁ 的语法证明翻译——这是它成为实的缺口的原因。

该引理带未证标记，因此被驱动与双重校验器同时拒收为收据源；`Z0Full.zfc_z0_full_of_D3_internalize` 表明它一旦成立，完整形式 `𝗭𝗙𝗰 ⊬ (𝗭𝗙𝗰.consistent)ᵗ` 立即随之成立（这条条件定理本身无未证标记，已过核）。正对照：D3 在标准模型 ℕ 中成立（同一运行内机器核对）。
