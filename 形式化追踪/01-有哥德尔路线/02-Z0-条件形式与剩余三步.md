> 有哥德尔路线 · 第 2 节。证明包 `HoTT/formal/claude-cg001/godel-q-zfc-z0/`（CG001-C-103，提交 `81547eee`）、`godel-q-zfc-z0-pa/`（CG001-C-109、C-110，CG-007 W3）、`godel-q-zfc-z0-re/`（C-111，W4a）与 `godel-q-zfc-z0-translate/`（C-119、C-120，W4b）；思考笔记 CN-067、CN-072。

## Z0 是什么

- 【原话】十三条 [1]（KC-000063）：“……我们甚至还可以找到Q0（H0（Z0）），意思就是Q0是ZFC的Q，其实对应了H0在ZFC中的对应物Z0。”
- 【判断】Z0 的候选，是 ZFC 对自身矛盾的逐步搜索（CG-005 设计 §3）。它和 H0 逐字段同形：都是逐步追问，都有局部判定，都是找到就停。差别在于，HoTT 能证明自己宇宙上的追问永不停（C-78），ZFC 却证明不了自己的矛盾搜索永不停（哥德尔第二定理）。
- Z0 的 UR：“检查自己会不会自相矛盾，本来是很简单的事——一直查下去就行——甚至在 ZFC 中都做不到。”

## 已证到哪里（C-103）

- **算术影子** Sh = {σ ∣ 𝗭𝗙𝗖 ⊢ σᵗ}，即 𝗭𝗙𝗖 经翻译能证明的算术句子的全体。下面三条无条件成立：
  - `Sh ⊢ σ ↔ 𝗭𝗙𝗖 ⊢ σᵗ`；
  - Sh 一致（经 Foundation 的 `zfc_consistent`，属 Lean 元层）；
  - `𝗥₀ ⪯ Sh`。
- **条件定理**：在 `[Sh.RE] [𝗜𝚺₁ ⪯ Sh]` 两条前提下，`𝗭𝗙𝗖 ⊬ (Sh.craig.consistent)ᵗ`，并且 `Sh ⊬ Sh.craig.consistent`。
  - 走的是 Foundation 的 Craig 版第二定理 `craig_consistent_unprovable_of_RE`。
  - 为什么用 Craig 版：Sh 只可枚举、不可判定。若误用要求 Δ1 的 `consistent_unprovable`，就要前提 `Sh.Δ₁`，而这在数学上不成立。
- **负控制**：只给 `Sh.RE`、不给 `𝗜𝚺₁ ⪯ Sh`，证明在缺实例处被拒；已证的 `𝗥₀ ⪯ Sh` 代替不了它。

### (c) 的收窄（2026-10-09，CG-007 W8，CG001-C-121、C-122）

原计划的形状是“𝗜𝚺₁ ⊢ Con(𝗭𝗙𝗖) → Con(Sh.craig)”。Foundation 的 `Sh.craig` 一致性句来自 `codeOfREPred`，那是用选择公理挑出的某个 Σ1 公式；它在 ℕ 中正确，在非标准模型里的行为由这次选择决定，因此这条桥在 𝗜𝚺₁ 内部无从推理。改用**显式**谓词 `𝔅Z(x) := Provable 𝗭𝗙𝗸 (iT 0 x)`（没有选择，逐字由 C-119 的内部翻译 `iT` 给出）作为 `Provability 𝗜𝚺₁ Sh`，沿 Foundation 的抽象第二定理 `con_unprovable` 逐条核对它的前提：

| 前提 | 状态 |
|---|---|
| D1 | ✅ 定理（`iT_quote` + `internalize_provability`） |
| D2（HBL2） | ✅ 定理（`modus_ponens_sentence`） |
| 对角化 | ✅ Foundation 对 𝗜𝚺₁ 自带 |
| `𝗜𝚺₁ ⪯ Sh` | ✅ C-110 |
| `Sh` 一致 | ✅ C-103 |
| **D3** | ◐ **唯一阻塞引理** |

D3 被固定成 `godel-q-zfc-z0-full/GodelQ/ZFC/Z0Blocked.lean:zfcTr_D3_internalize`：

```lean
theorem zfcTr_D3_internalize {V : Type*} [ORingStructure V] [V↓[ℒₒᵣ] ⊧* 𝗜𝚺₁]
    (τ : ArithmeticSentence)
    (h : Provable 𝗭𝗙𝗸 (⌜arithTrln.translate τ⌝ : V)) :
    Provable 𝗭𝗙𝗸 (⌜arithTrln.translate (zfcTr τ)⌝ : V)
```

读作：“𝗭𝗙𝗰 证明了 τ 的翻译，那么 𝗭𝗙𝗰 也能证明‘𝗭𝗙𝗰 证明了 τ 的翻译’这句话的翻译。”这就是经翻译的形式化 Σ1 完全性。Foundation 对算术理论的 D3 有完整机器证明（`DerivabilityCondition/D3.lean`，179 行，加 `PeanoMinus`/`EquationalTheory` 共约 1080 行），但它服务的是 `T.standardProvability`（谓词 `Provable T ⌜σ⌝`，T 是算术理论）；本处谓词作用在**翻译后**的公式上，不能直接套用。Foundation 的 `LK/Interpretation.lean:443 of_provability`（`U ⊢ σ → T ⊢ π.translate σ`）用完备性定理**语义地**证明，其中没有可搬进 𝗜𝚺₁ 的语法证明翻译——这是它成为实的缺口的原因。

该引理带未证标记，因此被驱动与双重校验器同时拒收为收据源；`Z0Full.zfc_z0_full_of_D3_internalize` 表明它一旦成立，完整形式 `𝗭𝗙𝗰 ⊬ (𝗭𝗙𝗰.consistent)ᵗ` 立即随之成立（这条条件定理本身无未证标记，已过核）。正对照：D3 在标准模型 ℕ 中成立（同一运行内机器核对）。

## 缺口的第二次收窄：`keyE` 的哪一半才是核心（2026-10-10 晚，本机 Lean 4.34.0 实测；**不是新收据**）

> 本节只追加，不改上面任何判定。它记录两件事：`keyE` 的两个方向**不是同等困难**，
> 以及 Foundation 里此前几轮都没用到的三件 **V 内部**（不是元层）工具。**本轮没有证出任何新命题。**

**第一次把缺口写成 `keyE` 时，两个方向被当成同等困难；实测后不是。**

| 方向 | 内容 | 现状 |
|---|---|---|
| → | `zfcTr σ → provabilityPred Sh.craig σ` | **看起来可证**，走 V 内部的 Δ1 类工具（见下） |
| ← | `provabilityPred Sh.craig σ → zfcTr σ` | **核心难点**：需要 V 内部的语法解释定理 |

**三件此前未用到的 V 内部工具**（都在 `Foundation` 里，本机 `#check` 通过）：

1. `Derivation.of_ss` / `Derivable.of_ss`（`Bootstrapping/Syntax/Proof/Basic.lean:756/841`）：
   `T.Δ₁Class (V:=V) ⊆ U.Δ₁Class → Derivable T s → Derivable U s`。这是 **V 内部**的推导弱化；
   元层的 `WeakerThan.pbl` 搬不进非标准 V，这一条可以。
2. `provable_standardProvability_imp_of_Δ₁Class_subset`（`Incompleteness/StandardProvability.lean:121`）：
   `(∀ V p, p ∈ T.Δ₁Class → p ∈ U.Δ₁Class) → 𝗜𝚺₁ ⊢ □_T σ 🡒 □_U σ`。把 Δ1 类的包含**提升成可证蕴含**。
3. `Theory.reWitness_spec` 与 `Theory.mem_craig_codes_iff`（`Syntax/CraigTrick.lean`）：
   `reCh x ↔ ∃w, reWitness(w,x)`（V 内部），而 `reWitness : {Γ := 𝚺, rank := 0}` —— **Σ0**；
   `T.craig` 的码由 `∃ s < n, ∃ m < n, … reWitness(s,m)` 给出，这正是 `craigCh` 为 Δ1 的原因。
   即：**V 能对 `Sh.craig` 的公理做有界搜索**。

**另一个实测事实**：`Sh.RE` 的底层 Σ1 谓词（`GodelQ/ZFC/TranslateRE.lean:43` 的 `translate_provable_re`）
逐字是 `fun b ↦ Provable 𝗭𝗙𝗂 (iT 0 b)` —— 与 `Z0Full.trProv` 的内容相同。所以 `Sh.reCh` 与 `trProv`
在 V 内部很可能是同一个谓词（**待证**：`V ⊧ Sh.reCh ⌜σ⌝ ↔ V ⊧ zfcTr σ`）。

**由此得到的 → 方向路线（尚未执行）**：
`zfcTr σ`（V 内部即 σ ∈ Sh）→ `Sh.reCh ⌜σ⌝`（上一条待证）→ `∃w, reWitness(w,⌜σ⌝)`（`reWitness_spec`）
→ `σ.padding w ∈ Sh.craig`（`mem_craig_codes_iff`，`w` 有界）→ `provabilityPred Sh.craig σ`。

**← 方向为什么仍是核心**：它是 `bridge`（C-128）的另一副面孔。Foundation 的
`DirectInterpretation.of_provability`（`LK/Interpretation.lean:443`）经
`Theory.Proof.complete_on_eq_models`（**完备性定理，语义**）证明，不含可搬进 𝗜𝚺₁ 的语法翻译；
而 `Derivable.of_ss` 只在**同一语言**内弱化，跨语言（ℒₒᵣ → ℒₛₑₜ）仍缺一条 V 内部的语法解释定理。
C-128 的 `bridge` 因此没有被绕开，只是被更精确地定位。

**结论**：D3 仍未证；`keyE` 的 ← 方向 = `bridge` = **V 内部的语法解释定理**，是需要单独立项的形式化工作，
不是"再读一遍源码就能补上的引理"。C-120 的影子形式仍无条件成立，不受影响。
