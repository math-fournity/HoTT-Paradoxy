## 抽象层（CG-005，`HoTT/formal/claude-cg001/godel-q/`，提交 `81d8af75`）

对象：任何满足四条标准元性质的“有效理论”。四条元性质是：永不停句的定理可枚举；真的 Σ1 事实都被证明；有限阶段的“尚未停”都被证明；一致。

| 编号 | 人话 |
|---|---|
| C-84 | 停机就是在某个有限时刻停机；“到第 k 步已停”可以机械判定 |
| C-85 | 对角：任给一个可枚举的接受集，都有过程 d，使“d 停”恰好当且仅当“d 被接受”（Kleene 递归定理） |
| C-86 | 没有完备的“永不完成”观察者；“永不停机”集不可枚举 |
| C-87 | 任何观察者都有严格更大的观察者，而更大的那个仍有漏点 |
| C-88 | 有效理论看得见每一个有限阶段：证明每次真实的停机，也证明“到第 k 步尚未停” |
| C-89 | 存在永不停的 d，理论每一刻都证明它“尚未停”，却证明不了“永不停” |
| C-90 | 魔鬼交易：有效、Σ1/Δ0 完全、一致，再加 ω 完成规则 P，四者不能同时成立 |
| C-91 | 哥德尔–芝诺跑者：跑者到达终点，当且仅当理论不能确认它到达；普通芝诺跑者的到达是确认得了的 |
| C-92 | 可推导条件（HBL）形式：一致的理论证明不了自己的一致性句；ZFC + Con 严格更强 |
| C-93 | 芝诺、H0（参数形式）、Z0、跑者是同一个 ω 追问（见第 04 章） |
| C-94 | 把“极限理论解决芝诺式问题”当作一般方法（A_general），等价于 Q 完备；P 推出 A_general；一致有效的理论没有 A_general |
