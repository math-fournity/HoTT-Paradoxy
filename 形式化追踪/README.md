- 回答“某条线做到哪了、下一步是什么”：

## 怎么维护

1. **什么时候更新**：每个形式化工作单元结束时都要更新，包括新命题过核、新的运行收据、一次失败的尝试、换路线、出现新方向、研究发起人作出裁定。
2. **更新什么**：
   - 该线 README 的状态表与“下一步”；有细节变化时，改对应的节文件；
   - 本 README 总览表中该线那一行；
   - 在 `99-更新日志.md` 追加一行，写日期、线、变化、提交。
3. **怎么写**：
   - 每条状态写明证据身份（机器证明、条件定理、来源层或解释），并附链接；
   - 只说到证据支持的那一层；
   - 不复制证明内容。
4. **出现新线时**：新建 `NN-名称/README.md`，写明目标（用研究发起人原话）、状态表、剩余步骤、可能方向和线头，并在总览表加一行。
5. **何时提交**：形式化改动与本文件夹的更新放在同一次提交，或紧随其后的 records 提交。
