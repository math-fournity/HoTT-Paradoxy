## 怎么读 `HoTT/CLAIM_EVIDENCE_MATRIX.md` 的状态词（2026-10-13 补，防误判）

矩阵里的状态词分两类，**不能混读**：

1. **历史证据状态文本**（`MACHINE_PROVED_LOCAL_UNCOMMITTED` 等，226 处）：
   这是各 run 建立索引时的证据状态，被 `index-row-manifest.json` **固定、不得改写**
   （矩阵 §"Git 版本闭合登记"明说，原位改状态会破坏历史 run 的逐行收据）。
   **它不表示"当前有 226 条未提交"**。
2. **当前可恢复性的权威**：`HoTT/verification/PROOF_VERSION_CLOSURE.json`
   （现解释为 `MACHINE_PROVED_VERSION_CLOSED`，17 个 package）+ git 版本闭合登记一节。

**唯一可靠的"是否已证"判据**（舰队纪律，五例实证后定型）：
**进程 exit code + `#print axioms` 不含 `sorryAx`**。
凡只凭日志文本计数（`grep -c sorry`、`grep -c error`、甚至 `grep -q` 模式）判定的，
都可能因空日志、半截日志、路径前缀不匹配而给出假绿灯或假红灯。
