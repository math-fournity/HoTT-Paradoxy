### 1.1 三个决定性发现（都改变了后续路线）

**(a) `Semiformula.quote_shift` 的层级错配可绕过。**
它要 `Semiproposition`（`ξ = ℕ`），而 `cFuncN` 的码在 `Semisentence`（`ξ = Empty`）层；
**两者在 `V` 层的码由 `rfl` 相同**，`show` 改型即可用。这是 10- 号文档 §2 记为「卡点」那一步的解法。

**(b) `induction_setup` 的 `P` 谓词有语义问题，必须换成 `Q`。**
`Provable T φ` 内部是 `∃ d, Proof d φ`，而 `Proof d φ := DerivationOf T d {φ}`——
**要求结论 sequent 恰好是单元素集**。`translateSeq s` 一般不是，故
`P d := Provable 𝗭𝗙𝗖 (translateSeq (fstIdx d))` 在 `s ≠ {φ}` 时几乎必然为假。
正确的归纳不变量是 `Q d := Derivable 𝗭𝗙𝗖 (translateSeq (fstIdx d))`（sequent 层）。
**`ShCraigElimSetupQ.induction_setup_Q` 是 `Q` 版，7 支已接入。**

**(c) `hAll` 不需要公式等式，只需可导性传递。**
三轮反例证伪了所有「`iT` 与 `free`/`subst` 交换」的朴素形状（见 §3）；

## 2. 当前缺口：一条精确的算术蕴含式

`induction1` 的 10 个支里 **7 支已填**（`hAxL`/`hVerumIntro`/`hAnd`/`hOr`/`hWk`/`hShift`/`hCut`），
剩 **`hAll`/`hExs`/`hRoot`**。三支的障碍已**完全定型**（不是笼统的「还差」）。

### 2.1 `hAll` 的完整归约（已定型，只剩一条蕴含式）

```
hAll 的目标：Derivable (translateSeq s)，其中 ^∀ p ∈ s
  Derivable.all (q := imp ℒₛₑₜ domZero (iT 1 p))       -- ∀ 引入（不是 all_m！）
    ├─ IsSemiformula ℒₛₑₜ 1 q                          ✅ isSemiformula_domZero' + isSemiformula_iT
    └─ Derivable (insert (free ℒₛₑₜ q) (setShift ℒₛₑₜ (translateSeq s')))
         ← 从 ih（Derivable (insert (iT 0 (free ℒₒᵣ p)) (setShift ℒₛₑₜ (translateSeq s')))）
           用 **replace_of_imp**（已证，`ShCraigElimSetupQ.replace_of_imp`）
             ├─ 需要 ⊢ ¬A ⋎ B，即 ⊢ A → B，其中
             │    A := iT 0 (free ℒₒᵣ p)
             │    B := free ℒₛₑₜ (imp ℒₛₑₜ domZero (iT 1 p))
             └─ 其余分支 ✅
```

**所以 `hAll` 的全部剩余 = 一条算术蕴含式 `⊢ A → B`。**

### 2.2 这条蕴含式的性质与三条候选路径

`A` 与 `B` 都是 `ℒₛₑₜ` 的**闭公式**（层数 0），且都是「`p` 的自由化 + 翻译」的编码。
它属 **𝗭𝗙𝗖 内部的公式可证性**。若两式语义等价，由
`Theory.Proof.complete_on_eq_models` 可得；但 `V` 是非标准模型，**不能直接用**。

**候选路径（按可行性）**：

1. **元层引理（最有希望）**：`iT_quote`（已核实存在）给
   `iT n ⌜φ⌝ = ⌜arithTrln.translate φ⌝`；Foundation 的
   `Semiformula.free_quote`（`Formula/Coding.lean:125`）给
   `⌜Rewriting.free φ⌝ = Semiformula.free ⌜φ⌝`。两者合起来把问题化为**元层**的
   `translate (Rewriting.free φ) = Rewriting.free (translate φ)`
   ——一条关于翻译定义的引理，比码层等式容易。
   **局限**：`hAll` 里的 `p` 是 `V` 内任意码，不是 `⌜φ⌝` 形式，需再评估推广。
2. **结构归纳**：对 `p` 用 `semiformula_result_induction` 逐支证 `⊢ A → B`
   （`rel` 支最易）。难点：`free` 不是 `UformulaRec1` 的构造。
3. **换 `iT` 的定义**：让 `all`/`exs` 支用「替换」而非「保护」语义。
   **代价**：`iT` 已被 C-390/C-391 等收据引用，属**接口级改动，须研究发起人裁定**。

### 2.3 `hExs` 与 `hRoot`

* **`hExs` 同形**：用 `Derivable.exs` + `replace_of_imp`，
  剩余是同一类蕴含式（`substs1` 版）。
* **`hRoot` 就是 D3 本身**：走 `Derivable.by_axm` 需要
  `iT 0 p ∈ 𝗭𝗙𝗖.Δ₁Class`（当 `p ∈ Sh.craig.Δ₁Class`）——
  这正是 `Z0UniBridge.ShCraigElim` 的另一面，是**整条消去的实质内容**，
  不是技术细节。**不要把它当成「填一个洞」。**

**2026-10-12 复核（`hRoot` 比上面写的更近）**：

1. **`Sh.craig ⪯ Sh` 自动可得**——`inferInstance` 即可，
   来自 Foundation 的 `Theory.craig ⪯ T` 实例（`CraigTrick.lean:321`）。
   **不需要额外证明。**
2. `Sh_provable_iff : Sh ⊢ σ ↔ 𝗭𝗙𝗖 ⊢ arithTrln.translate σ`（`Z0Shadow.lean:44`）。
3. **`provable_iff_provable : Provable T ⌜φ⌝ ↔ T ⊢ φ`**（Foundation）——
   这是「V 层 `Provable`」与「元层可证」之间的桥，**前几轮没找到**。
4. 新增并已证（进 `ShCraigElimSetupQ.lean`）：

   ```
   provable_into_sequent : IsFormulaSet B → Derivable (A ⫽ ∅) → Derivable (A ⫽ B)
   ```

   即「可证公式可入 sequent」。这是 `hRoot` 收尾的必需件：
   `by_axm` 只接受**公理**，而 `Sh.craig` 的公理经翻译后只是**可证**
   （由 `Sh.craig ⪯ Sh`），所以要先把「可证」搬进目标 sequent。

**`hRoot` 的剩余难点（已精确定位）**：把
`p ∈ Sh.craig.Δ₁Class`（其 `mem_iff` 是 `CraigTrick.lean:311` 的复合式：
`IsCraigAxiom ⌜φ⌝ ↔ ∃ ρ ∈ T.craig, φ = ρ`）化到 `Sh.craig` 成员，
再经 `Sh.craig ⪯ Sh` + `iT_quote` + `provable_into_sequent` 收尾。
**技术障碍**：`Theory.Δ₁.mem_iff` 接受 `Proposition`（元层），
而 `hRoot` 手里是 `V` 元素；需要用 `Δ₁Class.defined` 实例的 `.iff`
（对任意 `V` 元素）而非 `.mem_iff`。**这是下一步的第一个具体动作。**

## 3. 已证伪的路线（不要重复尝试）

三轮反例，全部本机实测：

| 轮次 | 被证伪的命题 | 反例 |
|---|---|---|
| 第十二 | 「`subst ?[^&0]` 与 `subst (qVec ?[^&0])` 可互换」 | `termSubst ?[^&0] ^#0 = ^&0`，但 `termSubst (^#0 ∷ ^&0 ∷ 0) ^#0 = ^#0` |
| 第十五 | 「`iT 0 (free ℒₒᵣ p) = free ℒₛₑₜ (imp domZero (iT 1 p))`」 | `p` 含 `all` 时左边一层 `imp domZero`、右边两层 |
| 第十八 | 「`iVE` 与 `subst` 逐层交换」 | `subst ?[^&0] (iVE 1 ^#0) = ^rel 2 cEqN (?[^&0, 0])`，而 `iVE 0 ^&0 = ^rel 2 cEqN (?[^#0, ^&0])` |
| 第二十四 | 「`insert p (insert q s) ⊢ insert (p⋏q) s`」 | sequent 语义是析取：`{p,q}∪s ↔ ¬p∨¬q∨⋁¬s`，而 `{p,p⋏q}∪s ↔ ¬p∨¬p∨¬q∨⋁¬s`（更强） |

**根因**：`iVE` 的 `eqAtom t = ^rel 2 cEqN ?[^#0, t]` **自带一个绑定变量 `#0`**，
外层 `subst` 必然穿透改它；而 `iT` 在绑定层下用的是 `substs_all` 的**保护**语义
（`qVec` 首分量换成 `^#0`）。**两种语义不可调和。**
