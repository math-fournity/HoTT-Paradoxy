## 2.5 `hAll` 的**精确**剩余（2026-10-12，分析，尚未机器验证）

上一轮把 `hAll` 归到「一条算术蕴含式 `⊢ A → B`」。本轮把它**算开**了：

```
A := iT 0 (free ℒₒᵣ p)                        （层数 0）
B := free ℒₛₑₜ (imp ℒₛₑₜ domZero (iT 1 p))    （层数 0）
```

用已证的 `free_imp_domZero`（`TranslateShiftCompat.lean:792`）：

```
B = imp ℒₛₑₜ (subst ?[^&0] domZero) (free ℒₛₑₜ (iT 1 p))
  =: D 🡒 free (iT 1 p)          （D := domZero[&0]，即「&0 ∈ ω」）
```

**关键观察（新）**：`A → B` **不是**等式问题，而是

```
A → B   ⟺   A → (D → free (iT 1 p))
```

若再有一条 **`iT_free`**：

```
iT_free :  iT 0 (free ℒₒᵣ p)  =  free ℒₛₑₜ (iT 1 p)        (p 层数 1)
```

则 `B = D → A`，于是 `A → B` 就是 **`A → (D → A)`——命题逻辑恒真式**，
`Derivable` 层由 `axL` + `Derivable.or` 直接构造（**不需要任何算术内容**）。

### 为什么 `iT_free` 可信（手算两例）

* **原子**：`p = ^rel 2 eq ?[^#0,^#0]`。
  左边 `iTR 0 2 0 ?[^&0,^&0]`；右边 `subst ?[^&0] (iTR 1 2 0 ?[^#0,^#0])`。
  `iTR` 的 `conjunct` 把「p 的变量」编码成 `#(n+1)`，经 `qqAlls 2` 后正好是自由 `#0`，
  于是右边那次 `subst` 落在同一个位置上。两边逐项对上。
* **全称**：`p = ^∀ p'`。左边 `iT 0 (∀¹ (p'[#1↦&0])) = ∀¹ (domZero → iT 1 (p'[#1↦&0]))`；
  右边 `free (∀¹ (domZero → iT 2 p')) = ∀¹ (domZero → (iT 2 p')[#1↦&0])`。
  两者相等**当且仅当** `iT 1 (p'[#1↦&0]) = (iT 2 p')[#1↦&0]`——
  **同一条律的上一层**。故 `iT_free` 是**自相似**的，可由
  `UformulaRec1.Construction.semiformula_result_induction`（`iT_shift` 用的同一台机器）一次拿下。

### 等价的一般形式

`free L p = substs1 L ^&0 (shift L p)`，配合已证的 `iT_shift`，`iT_free` **等价于**

```
iT_subst_fvar :  iT 0 (subst ℒₒᵣ ?[^&0] σ) = subst ℒₛₑₜ ?[^&0] (iT 1 σ)      (σ 层数 1)
```

即「**把最外层绑定变量换成自由变量**」这一代入与 `iT` 交换。
上一层需要 `?[^#0,^&0]` 版（即 `qVec ?[^&0]`），故实际要证的是
「`w` 为**变量向量**（各分量是 `^#j` 或 `^&j`）时 `iT 0 (subst w p) = subst w (iT n p)`」。

**这与已证伪的「`iVE` 与任意 `subst` 交换」不同**：反例（第十二、十八轮）用的是
**含函数符号的项向量**与**穿透 `iVE` 自带绑定变量 `#0` 的代入**；
而 `?[^&0]`/`?[^#0,^&0]` 是纯变量向量，`iVE` 的 `#0` 由 `qqAlls 2` 绑定，代入不穿透。
**这是本轮最需要机器验证的一条判断。**

```
C    = subst ?[^#0,^#1] (cRel R)
```

**关键**：右边那次 `subst` 在 `qqAlls` **外面**，向量是 `qVec ?[^&0]`（长度 2：
`?[^#0, ^&0]`）。这正是补偿 `conjunct` 把 `#0 ↦ #i` 所需的那一层。

剩余核对（机械）：
1. `subst (qVec ?[^&0])` 经 `substs_neg`/`substs_or` 分配到 `imp` 的两个分量；
2. `subst (qVec ?[^&0]) C = C`（`cRel R` 是闭式，用 `subst_eq_self` 类引理）；
3. `subst (qVec ?[^&0]) (conjunct 2 1 i (iVE 1 ^#0)) = conjunct 2 0 i (iVE 0 ^&0)`
   ——需展开 `conjunct` 的 `#0 ↦ #i` 换名（`iVE 0 ^&0 = ^rel 2 cEqN ?[^#0, ^&0]`，
   `iVE 1 ^#0 = ^rel 2 cEqN ?[^#0, ^#1]`，外层 `subst` 把 `#1 ↦ ^&0`）。

#### 完整算例（`k = 0`，`p = ^rel 2 0 ?[^#0,^#0]`，逐项展开）

这是把猜想从「可信」推到「可核对」的那一步。记 `C := subst ?[^#0,^#1] (cRel 0)`。

**左边** `iT 0 (free p)`：
```
free p = subst ?[^&0] (shift p) = subst ?[^&0] p = ^rel 2 0 ?[^&0, ^&0]   -- shift 不动 bvar
iT 0 上式 = iTR 0 2 0 ?[^&0,^&0] = qqAlls (imp (K0 ⋏ (K1 ⋏ ⊤)) C) 2
  K0 = (subst ?[^#0] cDomN) ⋏ ^rel 2 cEqN ?[^#0, ^&0]
  K1 = (subst ?[^#1] cDomN) ⋏ ^rel 2 cEqN ?[^#1, ^&0]
```

**右边** `free (iT 1 p)`：
```
iT 1 p = iTR 1 2 0 ?[^#0,^#0] = qqAlls (imp (L0 ⋏ (L1 ⋏ ⊤)) C) 2
  L0 = (subst ?[^#0] cDomN) ⋏ ^rel 2 cEqN ?[^#0, ^#2]
  L1 = (subst ?[^#1] cDomN) ⋏ ^rel 2 cEqN ?[^#1, ^#2]
shift (iT 1 p) = iT 1 p        -- iT 1 p 是闭式（无 fvar），shift 只在 fvar 上作用
free (iT 1 p) = subst ?[^&0] (iT 1 p)
              = qqAlls (subst (qVec² ?[^&0]) (imp (L0 ⋏ (L1 ⋏ ⊤)) C)) 2
其中 qVec ?[^&0] = ?[^#0, ^&0]，qVec² ?[^&0] = ?[^#0, ^#1, ^&0]
```

**逐项比较**（`subst ?[^#0,^#1,^&0]` 的作用：`#0 ↦ #0`、`#1 ↦ #1`、`#2 ↦ ^&0`）：
```
subst ?[^#0,^#1,^&0] L0 = (subst ?[^#0] cDomN) ⋏ ^rel 2 cEqN ?[^#0, ^&0] = K0   ✓
subst ?[^#0,^#1,^&0] L1 = (subst ?[^#1] cDomN) ⋏ ^rel 2 cEqN ?[^#1, ^&0] = K1   ✓
subst ?[^#0,^#1,^&0] C  = C                                                       ✓
```

（第一个等号里 `subst ?[^#0] cDomN` 复合两次仍是 `subst ?[^#0] cDomN`，因为 `#0 ↦ ^#0`；
`cRel 0` 是闭式。）

**两边相等。** 机制：`wvec (k+2) j` 恰好把 `#(k+1) ↦ ^&j` 且 `#i ↦ #i`（`i ≤ k`），
正是内层 `conjunct` 右移一层所要求的补偿。

#### 一般情形仍需 V 内部归纳

上面的算例只对**标准**原子成立。`hAll` 里的 `p` 是任意 `V` 元素（`IsSemiformula ℒₒᵣ 1 p`），
在非标准 `V` 中**不能**用 `IsSemiformula.sound`（那个 `{n φ : ℕ}` 限定在标准模型）把它写成 `⌜φ⌝`。
所以一般 `iT_rename` 必须走 `UformulaRec1.Construction.semiformula_result_induction`
（`iT_shift` 用的同一台机器），`rel` 支的补偿正是上面的算例。

#### 2026-10-12 关键更正：`iT_rename` 的形状**必须用 `qVec²`**

**先说清证据层级**：先前那条「项层测试」（`subst ?[^&0] (iVE 1 ^#0) = iVE 0 ^&0`）
**是我把陈述写错了**——它没有把 `iVE` 输出层数 `k+1` 与 `subst` 越界补零算进去。
真正的证据是**公式层探针**（`W8-iT-rename-rel-twolevel`）显示的目标形状，
加上下面的手算。**结论（`qVec²`）由手算验证，不是由那条项层测试得出的。**

机器实测（`probes/W8-iT-rename-termlevel-20261012.lean`）确认：那条项层陈述
**确实不成立**——两侧的向量长度对不上：

```
左：subst ℒₛₑₜ (^&0 ∷ 0)  (^rel 2 cEqN (^#0 ∷ ^#1 ∷ 0))     ← 向量长度 1
右：iVE 0 ^&0 = ^rel 2 cEqN (^#0 ∷ ^&0 ∷ 0)
```

**根因**：`iVE` 的 `eqAtom t = ^rel 2 cEqN ?[^#0, t]` **自带一层绑定变量**，
所以 `iVE k` 的**输入层数 `k`** 与它**输出公式的层数**相差 2。
「用同一个向量做 `subst`」在每一层绑定上都错位——这正是 §3 三轮反例的同一根源。

**更正后的形状**（`qVec² w := qVec (qVec w)`，长度 = `len w + 2`）：

```
iVE_rename :  iVE k (termSubst w t)  =  subst (qVec² w) (iVE (k+2) t)
iT_rename  :  iT  k (subst w p)      =  subst (qVec² w) (iT  (k+2) p)
```

**交叉验证**：`k = 0` 时 `qVec² ?[^&0] = ?[^#0, ^#1, ^&0]`——
与 `probes/W8-iT-rename-rel-twolevel-20261012.lean` 实测到的
右边那次 `subst` 的向量形状**逐字相同**。两条独立探针互相印证。

**手算验证 `qVec²`（`k=0`，逐项）**：

```
左：conjunct 2 0 0 (iVE 0 ^&0)
    = (subst ?[^#0] cDomN) ⋏ subst (^#0 ∷ shiftVec 2 0) (^rel 2 cEqN ?[^#0, ^&0])
    = (subst ?[^#0] cDomN) ⋏ ^rel 2 cEqN ?[^#0, ^&0]        -- ^&0 是 fvar，subst 不动它
右：conjunct 2 1 0 (iVE 1 ^#0) 再经外层 subst (qVec² ?[^&0])
    = (subst ?[^#0] cDomN) ⋏ subst (^#0 ∷ ?[^#2]) (^rel 2 cEqN ?[^#0, ^#1])
      再 subst (qVec² ?[^&0]) = subst ?[^#0, ^#1, ^&0]
    = (subst ?[^#0] cDomN) ⋏ ^rel 2 cEqN ?[^#0, ^&0]        -- #2 ↦ ^&0
```

**两侧相等。** 关键是 `subst` 只动 **bvar**（`^&0` 是 fvar，原样保留），
以及 `qVec² ?[^&0] = ?[^#0, ^#1, ^&0]` 恰好把 `#2 ↦ ^&0`。

**代价**：`iT_rename` 比 `iT_shift` 复杂——不是「同一台机器换向量」，
而要同时处理**层数 `k` 与 `k+2` 的配对**（`iT_shift` 里层数不变）。

| 轮次 | 被证伪的命题 | 反例 |
