# 现代机器化对照与R2-R4前提

## 一、O’Connor 2005：数值编码路线的实际工程量

O’Connor 的 Coq theorem 对任意系统 `T` 要求：`NN ⊆ T`、`T` 能在自身表达其公理、`T` 的 axiom membership 可决定；随后构造一个句子，使 `T` 若证明它或其否定便 inconsistent。对一致 `T` 才推出 independent sentence。

机器工程包括：

- 一阶 syntax、capture-avoiding substitution、proof 与 system proof；
- formula/proof 的自然数 code；
- primitive recursive function 表示性；
- `codeSubFormula` 正确且 primitive recursive；
- `checkPrf` 正确且 primitive recursive；
- fixed-point theorem 与 Rosser sentence。

其中 substitution 的 course-of-values recursion 因重命名产生可能更大的 code 而失败；作者改用有限 computation trace tree，先证明 trace code 的 primitive-recursive bound，再在界内搜索。这一点直接反驳“只要有语法码，对角化就是几行代码”的工程直觉。

论文明确说第二不完备性尚未完成：Coq 外层证明第一不完备性不等于 PA 内层拥有该证明。后续需要 Hilbert–Bernays–Löb 三条件，尤其 `Prov(φ) → Prov(Prov(φ))` 的内部化最困难。这个历史边界与本 repo ERCF-3 的 representability/reflection gate 完全对齐。

## 二、Kirst–Hermes 2021：synthetic reduction 的前提

该路线在 constructive type theory 中把所有可定义函数视为可计算，因此 many-one reduction 只需定义并验证函数，不必再编码成 Turing machine。它机器化 PA/ZF 相关 entailment 的不可判定／不完备性，但具体结果仍依赖：

- 问题和 reduction 的精确定义；
- 标准模型或相应 standardness；
- 对某些 completeness→halting-decider 结论使用 LEM；
- ZF 变体中的额外 collection／transitive-set 假设；
- 上游已机器证明的 H10/PCP/TM reductions。

“元语言可定义，所以 reduction 可计算”是该 constructive foundation 的工作合同，不是任意 HoTT universe 的无条件事实。

## 三、Kirst–Peters 2023：EPF 与 strong separation

论文把 formal system 抽象为句子类型、否定和 provability predicate，并先构造 proof/refutation 的 partial decider。`EPF` 是显式公理：存在 universal partial function `Θ`，每个部分函数都有 code。

关键层级：

1. self-halting `K_Θ(x) := Θ_x(x)↓`；
2. 对任意候选 partial decider，用 EPF 给对角函数取得 code，并构造一个使候选发散的具体 index（Fact 15）；
3. 弱表示 + sound extension 给 weak incompleteness（Theorem 16）；
4. 对输出 `1/0` 的两个 self-halting predicate 做 strong separation；
5. 任意 consistent extension 因 proof/refutation partial decider 在某个显式 index 发散而产生 independent sentence（Theorem 20），并得到 essential undecidability（Theorem 21）。

Robinson `Q` 的实例不是从裸 EPF 自动得到。论文引入 `CT_Q`／`EPF_μ`、Σ₁ representability 和 strong separation，才得到任意一致 `A ⊇ Q` 的 independent sentence。作者 Coq 源现已在 main 以 `MP-COQ-SYNTHETIC-INCOMPLETENESS-R3-001` / C-244–C-249 从 repo-contained exact archive fresh build、资格化并完整重放；这关闭一般 R3 基准，但 `T` 仍是一阶算术理论，尚未迁成 exact HoTT calculus。

用户新取得的 Benjamin Peters 2022 学士论文是这条工作的 48 页长版前身，与既有 18 页 CSL 2023 论文在 PDF 哈希、页数和 MinerU 全文上均不同。它补出了会议论文压缩掉的工程脉络：§5.2 对照 Gödel 与 Rosser 的 proof predicate，§5.3 给 strong separation 构造，§5.4 实例化 essential incompleteness；§7.2 报告抽象部分约 400 行 Coq、只保留最强结果时约 150 行，而一阶逻辑实例另约 2,250 行。这里的行数只是作者对其工程的 source report，当前 repo 没有据此新增机器证明状态。

长版还澄清一个直接影响 R4 的边界：作者依靠 DPRM 机器化取得 Robinson `Q` 中 enumerable predicates 的表示性，再用 Rosser trick 从 weak representability 推到 strong separation。它没有让 syntax/proof/representation 义务消失，而是通过既有库承担它们。对 exact-HoTT 不完备性路线，必须同样登记这些义务究竟由 inner HoTT、outer metatheory 还是导入 reduction 提供。

## 四、2LTT：为什么“HoTT 对自己说话”不能默认成立

2LTT 明分 inner 与 outer：inner 可为含 univalence/HIT 的 HoTT，outer 是带 UIP 的传统类型论，作为 inner 的内部化元理论。论文明确指出，某些“对每个外部固定 n 可构造”的 HoTT 元结果不能在 HoTT 自身表达，却能在 outer 层把 n 作为变量表达。

基础 2LTT 有 conservativity 结果；但加入 outer natural numbers 与 inner natural numbers 的同构、outer cofibrancy/fibrancy、某些 fibrant-limit 或 replacement 强化后，是否仍能回到普通 HoTT 往往未知。故 R4 需要登记：

- syntax/proof code 生活在哪一层；
- conversion/proof checker 由哪一层证明 total；
- univalence/HIT 规则的 code 与 soundness 在哪一层；
- 从 outer theorem 返回 inner HoTT 时使用哪一个 conservativity theorem。

## 五、Swan–Uemura：Church thesis 的 HoTT 适用域不是全局常量

论文采用带 propositional truncation 的 Church thesis：每个 `ℕ→ℕ` 函数仅 mere-exists 一个程序 index 和计算见证。两项主结果形成关键对照：

- Theorem 4.1：在 cubical assemblies 的 univalent type theory 模型中，Church thesis 的否定成立；
- Theorem 6.4：通过 nullification／反射子宇宙，Martin-Löf type theory 加 propositional truncation、univalence、Church thesis 与 Markov principle 保持一致。

因此 `EPF/CT` 与 univalence 并非简单矛盾，但也不是完整 cubical universe 的定理；它可以只在特定 reflective subuniverse 中成立。对本项目，这给出一个真正 HoTT 相关的资格轴：

```text
ambient universe
  ≠ reflective/modal computability universe
```

若一个自然 consumer 在 modality 内得到 `Universal θ`，随后把它当作 ambient universe 的全域 evaluator 使用，就可能形成资格提升候选。当前尚未找到这条真实调用链，故状态只是 `HOTT_SPECIFIC_CANDIDATE_SCHEMA`。
