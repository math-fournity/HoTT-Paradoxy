# 扩展认知逐段落论证之二（shards 004–006）

> 格式：`该段教的工作姿态 | 已走过的路是否在这个姿态上（证据） | 偏航诊断 | 对下一选择的指令`
> 被审计单元 = 区间 I 设计探针。**本单元是扩展认知 005 片姿态的首次执行**（见下）。

## 扩展认知 004 片 · 走进 HoTT 与理论自反

### 段「走进 HoTT，保留问题，也保留理论的真实样子」（KC-000002 / 008 / 009 / 027）

- 姿态：Theory Schema 是定位工具，不是构造名称清单；要由问题走到具体规则，或由规则反问「省下了什么、何时要重新承担」。
- 是否在姿态上：**是，且本单元执行得最纯**。探针由问题（「I 上能写什么」）走到具体规则（I 的消去子与 sort 结构），并带回了两条可引用的诊断名。这是「由问题走到规则」的教科书式实例——**没有枚举任何文法，只走了 Schema 这一步**。
- 偏航诊断：一个次要警示（沿用 168）——Schema 的**完整性**仍未被独立核验。F2 缺口（PAT / LEM / resizing / AC / unique choice / 截断时机判据 / Dedekind-Ω：来源在手、分母零条）是 Schema 不完整的证据。本单元没有核验完整性，只走了已登记的一格。
- 指令：把 F2 缺口层当作 Schema 完整性问题的具体形态；SUPPLY-010 是它的首次系统性执行。

### 段「历史悖论提供可迁移的构造关系」

- 姿态：迁移的是关系（逐项可行→整体完成、关系的逆→操作的逆、未来可得→现在可用、验证者进入被验证域），每次迁移须重新核实规则。
- 是否在姿态上：**部分**。前三条迁移都被落地成族；**第四条（验证者进入被验证域）从未落地**。本单元未涉及任何迁移（表达层探针不是构造关系的迁移）。
- 偏航诊断：第四条正是自反轴（KC-000025/026/028），链路的敏感面矩阵上最大的空洞。
- 指令：见分片 008（B 侧新族为长期节点）。

### 段「HoTT 已对齐程序」（KC-000027）

- 姿态：保留认识的演化——HoTT 不是纯静态系统；向程序靠近不等于研究结束；新追问是程序的有效性、完成条件与自反问题怎样进入理论。
- 是否在姿态上：**是**。CE-MAP/R3/R4 线执行了这个追问；本单元的 `[NotADatatype]` 是程序侧不可判定性在表达层的同类事实。
- 偏航诊断：无（但见 KC-000027 指令——不得让程序域唯一化）。
- 指令：保持程序域与运动/连续域的并列。

### 段「当理论把自己放进问题里」（KC-000025 / 026 / 028 / 036）

- 姿态：验证者进入被验证域后，原来顺畅的推理会怎样；要找到「谁要求了下一份担保、为什么必须由同一过程提供、是否存在合法终止依据」；量词「某种情况下、某些问题上」必须保留；不能把「有回环」直接当成「不能停止」。
- 是否在姿态上：**否（零执行）**。链路的归约链严格 DAG；没有任何单元把验证者放进被验证域。本单元的三个探针是三个独立模块的核检查，同样无回环。
- 偏航诊断：这是**结构性未闭合**，不会因多跑几个 A 侧族或探针而消失。
- 指令：分片 008 把它列为长期序列的必经节点，即使不是下一单元。

## 扩展认知 005 片 · 表达界限、文章作为起点与编写说明

### 段「一个理论可以表达多少，也值得被当作问题」（KC-000031 / 035）

- 姿态：极简理论理应被覆盖却因严格性不能被覆盖；「能把名字放进类型里」不等于表达；要对准明确的保真要求。
- 是否在姿态上：**是（已执行——本单元是本片姿态的首次执行，也是 EXP-001 的收尾）**。168 指出的低成本执行路径被走完了：DM3 作为「最小化理想理论」（极简三元链、已被原生核确认可承载三个结构分离）被拿来测 HoTT 的保真覆盖。结论 = **能覆盖，但形态改变、语义随之改变**：DM3 的 `separates` 语义在 I 上只能以 cofibration 分片形态承载，不能以 Bool 全局观察形态承载（exit 42 × 2）。「能把名字放进类型里」确实不等于表达——`identityOnI` 连类型都成型不了（`[UnequalSorts]`）。
- 偏航诊断：无。这是 168 审计登记的「未执行」在本单元被关闭的第一项。
- 指令：未来任何「HoTT 无法表达 X」的主张必须区分「完全无法表达」与「只能以改变语义的形态表达」；两者证据强度不同。SUPPLY-010 的前提候选须附表达层标注。

### 段「让一篇文章变成思考的起点」

- 姿态：原文不是供奉的引文；真正的启发应当**改变下一项动作**；若读完仍选不出一个明确的可用性任务或一个待比较的表示，那么原文只是被读到了。
- 是否在姿态上：**是（本审计链路本身）**。修订片 020 之后，审计从「被读到」升级为「改变下一项动作」：168 的分片 008 改变了队列（改道至 SUPPLY-010），169 的分片 008 确认并执行该裁决的第 (1) 项。本单元是「文章改变下一动作」的第二次执行——而且它是**可检验的**：STATE 指引的条件分支被实测命中。
- 偏航诊断：无。
- 指令：保持；每份审计的分片 008 必须给出可被后续单元证伪的裁决。

### 段「机器证明不是取消哲学展开的理由」（KC-000021）

- 姿态：机器证明要求与哲学展开相互需要；机器证明的收据不取消对理论姿态的追问。
- 是否在姿态上：**是**。本单元是这条的正面实例：三个核收据（0/42/42）被用来支撑一个**哲学命题**（表达的层与形态是实质的），而不是替代它。收据回答「事实是什么」，哲学展开回答「它意味着什么」——本单元两者都做了。
- 偏航诊断：无。
- 指令：保持；SUPPLY-010 的每个前提候选都应能说清它的哲学展开与它的收据路径。
