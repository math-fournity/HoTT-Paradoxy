# 用户语义、三刀与来源边界

## Source-first 四项对齐

| 项 | 本轮复核 |
|---|---|
| 用户主张 | ZFC／极限／芝诺可被理解为Meta Theory、Sub Theory和过程的关系；若两层遗漏时间／可计算过程维度，便可能看不见子层适用边界；圆环以逼近和复原强迫这一观察。 |
| 不得收窄 | 不得把它降成“ZFC不能表示时间”，也不得反过来以“可表示序列”宣称过程完成已被支付；不得宣称ZFC形式矛盾。 |
| 任务后果 | 冻结`MetaSide → SubTheorySide → BridgeSource → ProcessSide`，并要求LiftClaim、Preservation和Payment。 |
| 开放义务 | 需要实际来源的C/I/O/Done与LiftClaim；需要判断其保持、改写或省略过程Done；需要再做责任归因。 |

## 三刀的本轮分工

| 刀 | 输入 | 判词 | 为什么没有越界 |
|---|---|---|---|
| P1 | ZFC基础框架、子理论结果、未知C | `SOURCE_CONSUMER_GAP` | 不因“基础”自行发明强制审查consumer。 |
| P2 | 三层关系 | `NOT_APPLICABLE` | 没有同一对象的binder/form/bridge/reentry。 |
| P3-C | formality→process的解释 | `P3C_FIELD_REFINEMENT` | `MetaSubProcessBoundaryCard`只列桥字段，不捏造Draft/Admitted/OperatorUse。 |

## H081/H082 的证据边界

H081是采样前输入合同失败；H082是唯一授权字段修复后的source-match。worker不联网、不读项目、零tools／文件／approval；Master以已读来源复核其公开E0–E7。L1完整AGENTS正文和L3独立recall均未认证，因此H082只能支持冻结来源摘要的分类，不支持worker看到全部系统规则、独立原典阅读或Q1成立。
