## 来源、运行与理论层的边界

`Univ.thy`和`Epsilon.thy`给的是 Isabelle/ZF 形式化 proof theory 中的定义、定理和推导。H066 的 App Server terminal 证明一次受控 `gpt-5.6-terra/max` source-match 按冻结输入输出了公开 E0–E7，且无工具／文件修改／审批。Master 的层级解释由原典和同卡控制裁决。它们分别支持：

```text
source equation / rank theorem       = source-reported proof-theory fact
worker MatchTrace                    = bounded behavior evidence
Master PS0–PS6 verdict               = source-local research judgment
ZFC inconsistency / real task / UR   = NOT ESTABLISHED
```

如果下一卡研究“所有层的总宇宙”，它必须先判断这种说法是 object、class、model、metatheoretic shorthand 还是实际consumer；不能用这张 `Vrec` card 补造该层。
