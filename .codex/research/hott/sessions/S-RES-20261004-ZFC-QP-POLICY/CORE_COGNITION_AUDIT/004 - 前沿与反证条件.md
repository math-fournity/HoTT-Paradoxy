# 前沿与反证条件

| 路线 | 当前判词 | 重开／升级条件 |
|---|---|---|
| 条件政策演算 | `KERNEL_ACCEPTED_WITH_SCOPE` | 新规则或真实source映射改变条件时重跑。 |
| 实际 Q 缺失 | `Q_CANDIDATE_ONLY` | 一手ZFC/基础来源定义Q并显示缺失。 |
| 实际 P 采纳 | `ACTUAL_ADOPTION_UNPROVED` | 数学史或基础文献说明共同体以P运作。 |
| A↔P | `A_P_EQUIVALENCE_UNPROVED` | 同一任务的来源规则给出双向路径。 |
| P→B | `P_TO_B_SOURCE_UNPROVED` | 一份来源给出同一P导致B的保真链。 |
| 对象层矛盾 | `NORMATIVE_TENSION_ONLY` | B违反正式真理约束或A/B不相容被机器化。 |

本单元的停止不是“ZFC问题关闭”，而是对当前可用来源的诚实边界：继续重复 Standard Solution 或 QuestioningDelay 材料不会支付同一P、同一任务或P→B。下一步需要一份真正改变这几个字段的来源，或用户对P/B作出更精确的任务裁定。
