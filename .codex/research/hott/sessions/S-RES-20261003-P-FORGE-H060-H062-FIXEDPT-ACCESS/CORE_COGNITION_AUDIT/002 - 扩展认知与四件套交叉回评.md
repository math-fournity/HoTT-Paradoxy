## 四件套与来源层的具体边界

`Fixedpt.thy`是 Isabelle/ZF proof theory 中的固定定义与引理；它给出的 `lfp`／`induct` 成功条件是来源事实。官方 fixedpoint manual 给出的可及性解释是该例的来源事实。H060–H062 的 Terra 输出只能证明：在封存 source card 和 no-tools profile 下，worker 的公开 MatchTrace 如其 receipt 所载。Master 的 PS0–PS6 判词依靠前两类来源及同一 TaskCard 的反控制。

本单元的现实、历史和理论边界保持如下：

```text
Isabelle/ZF proof package  ≠  standard-ZFC full semantics
proof-package acceptance  ≠  Draft/Admitted/OperatorUse lifecycle
private worker elapsed     ≠  theory-internal time
source-card absence        ≠  global nonexistence theorem
candidate guard blocked    ≠  ZFC is safe / Power Set is correct
```

这些分界是本轮结论的约束条件；任何未来 H063 或之后的卡若要改变它们，必须提供版本固定来源、相同 `T/u/F/C/I/O/Done`、正负控制和相称的审计证据。
