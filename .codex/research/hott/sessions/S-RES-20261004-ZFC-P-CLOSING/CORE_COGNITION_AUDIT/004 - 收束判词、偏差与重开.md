# 收束判词、偏差与重开

## 当前可用判词

> 在 ZFC 作为 Standard Solution 实分析的基础语境的实际使用中，来源可在显式改写完成条件后宣布一个命名问题得到解决，而固定来源包没有自动交出“修订完成仍是同一原过程完成”的桥。因此，该使用层需要显式 O3–O5 completion-observation audit。

这是 `COMPLETION_OBSERVATION_AUDIT_REQUIRED`，不是对象语言矛盾或完整的 ZFC 负结论。

候选分支的独立验证把其中的“审计”加固为一个可机器核验的语言边界：若 `originDone` 根本没有进入被使用的
成员 formula language 或 completion bridge，那么该语言／base theory 不会自动选择其真值；若 bridge 被明确支付，
异判被控制排除。它也形式化了：跨 Zeno—HoTT 的强完成政策只有在 source-owned scope 与 B 都另行支付时才会
得到条件性 `False`。因此这个增量是 `Q_NARROW`，不改变 `ZFC_Q_NOT_LOCATED` 的 current boundary。

## 被拒绝的越级

- `ZFC ⊢ False`；
- ZFC完全没有时间观察能力；
- 所有极限／截断必然换题；
- IEP和HoTT已证明采用同一共同体 P；
- `P → B`已经有来源因果链；
- HoTT main 的 UR解释已成为内核定理。

## P/Q 共同涌现判词

P的当前可审形状是 R1 resolution、R2 replacement、R3 same-task bridge。H100/H104使 R1/R2在两个异构现场出现，H103/H105维持R3缺口，H101/H102禁止把bare `QuestioningDelay`伪写成P源。锻刀直接让 ZFC Q 从泛化“缺少时间”收紧为“completion observation audit”。这符合“锻刀与发现Q是一件事”的原初要求；没有提出P4。

`CommunityObservationPolicy` 现补足反证式回溯的精确范围：若 B 没有独立 base origin，固定 policy
calculus 的 B derivation 回溯到 P；若 B 已是 base claim，则不能将 B 归因于 P。它让“回溯找 P”成为
可检验 provenance 规则，而不是从实际 HoTT 现象直接跳到历史／社区因果结论。

`MetaSubtheoryAudit` 进一步将“ZFC 应审查 Sub Theory 边界”写成 completion-audit 条件：meta acceptance
与 origin promotion 之间必须由 bridge 支付，粗 observation collision 则拒绝 audit。正控制表明此要求不是对
所有 meta theory 的预设否定；它仍待实际 ZFC-supported consumer 资格化。

## 偏差审计

| 分类 | 判词 |
|---|---|
| 原初理念 | `ALIGNED`：理论级靶、明显位置、罗素计算张力、main H0均被消费。 |
| 规格 | `IDEA_SPEC_INCOMPLETE` 已修复：旧H099缺IEP明示Done字段，H100–H103将strict P与candidate P分层。 |
| 执行 | `ALIGNED`：每个节点先封存NodeCard/prompt，轨迹在终态后审计。 |
| 新刀 | `OLD_TOOL_FIELD_GAP`：P1/P3-C已经表达本花纹，无P4。 |
| 工具漂移 | 无：每个节点都改变固定P/Q卡或终局措辞；不是单纯运行维护。 |

## 重开条件

1. IEP或同级来源给出R3的同一任务保持桥；
2. 发现共同体实际采用P的来源；
3. 发现由P到main HoTT B的来源／理论推导；
4. 来源表明R1或R2读取错误；
5. 用户修订原过程的Done或最终判词。
6. full ZFC language/schema encoding 或实际来源表明 `originDone` 已被定义并以同一任务 bridge 支付。
