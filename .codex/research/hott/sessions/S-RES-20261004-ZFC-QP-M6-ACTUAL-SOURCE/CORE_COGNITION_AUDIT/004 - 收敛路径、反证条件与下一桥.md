# 收敛路径、反证条件与下一桥

## P/Q 共同收敛状态

```text
wide ZFC suspicion
  → QProfile / Done / bridge controls
  → M1–M5 local frontier (wrong task routes removed)
  → H103 source-completeness repair
  → H104/H105 actual UOU P-card + H106 SEP-controlled Battle
  → H107–H110 witness-field map + two Lean policy/frontier checks
  → finite M7 evidence frontier; reopen only for a missing witness field
```

锻刀没有脱离发现Q：H103的修复提高了“source payment”字段的门槛；H104/H105使P从
抽象 policy symbol获得实际来源卡；两个 Lean controls防止 Done 被词面合并。Q 尚未成为
已定位的ZFC能力缺失，而是被压缩为这个来源提升的具体审查责任。

M7 的新收获是把“锻刀和发现 Q 是同一收敛过程”落实成可检查的反向门：一把刀只要不能
改变 source P、adoption、actual-Q、PBacktrace、A/B incompatibility 或 bridge 其中之一，就不应继续
制造节点。Lean 账本将当前有限来源分母的停点写清，而 `ActualPolicyWitness` 将未来真正会合所需的
全部字段写清；两者共同防止“继续锻打”在没有 Q 进展时取代“发现 Q”。

## 反证条件

| 当前判断 | 可推翻证据 |
|---|---|
| UOU P-card 未付 bridge | UOU同一来源/版本给出F→D task-preserving theorem、明确等价或过程trace。 |
| UOU D不等于用户强Done | 用户明示D取UOU定义，或来源逐字段连到圆环M/反向操作/复原Done。 |
| SEP是付款控制 | 更完整SEP文本否定其Done distinction，或来源证明其区分仍是同一强任务bridge。 |
| Q仍未来源化 | bare ZFC/数学共同体来源明示拒绝或缺少这种F→D资格检查，并把该缺失作为推理许可。 |
| H0仍只是探测器 | 同一来源给出promotion到ordinary HoTT Done并导出特定B的PBacktrace。 |
| 当前分母不能闭合完整归谬 | 新来源填 adoption、actual-Q、PBacktrace、formal A/B incompatibility 字段，或 UOU 同源支付／修订 F→D bridge。 |

## 下一条最小桥

优先读取能够直接填 `ActualPolicyWitness` 某一空字段的来源，或同一UOU来源传统中是否显式连接
“limit-defined sum”与“Achilles catches up”的过程模型；若桥不存在，继续寻找一个**独立版本固定**来源，
而不是重复同一教材的关键词。任何未来卡必须保留 SEP / final-action / every-step / UOU D /
user circle Done 的竞争合同，并先说明它会使Q生成、收紧、桥接、淘汰还是会合。若答不出，停止为`TOOL_ONLY_DRIFT`。
