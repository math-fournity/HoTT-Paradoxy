## A. 类型构造子的规则四元组（formation / introduction / elimination / computation）

### PREMISE-A-01 · Π（依赖函数类型）的规则四元组

- **类别**：A
- **P1 前提陈述**：若 `A : U` 且 `B : A → U`，则 `Π x:A, B(x) : U`（formation）；
  若在 `x : A` 的假设下 `b : B(x)`，则 `λ x. b : Π x:A, B(x)`（introduction）；
  若 `f : Π x:A, B(x)` 且 `a : A`，则 `f(a) : B(a)`（elimination）；
  `(λ x. b)(a) ≡ b[a/x]`（computation，β）。
- **P1 出处**：`HoTT/theory-schema/CORE_RULES.md` C05；HoTT Book §1.4（快照见
  `HoTT/theory-schema/SOURCES_AND_COVERAGE.md`）；cubical 形式见
  `EXTENSIONS_AND_METATHEORY.md` E02/E11。
- **P2–P4**：step-2 起。

### PREMISE-A-02 · Σ（依赖对类型）的规则四元组

- **类别**：A
- **P1 前提陈述**：若 `A : U` 且 `B : A → U`，则 `Σ x:A, B(x) : U`（formation）；
  若 `a : A` 且 `b : B(a)`，则 `(a, b) : Σ x:A, B(x)`（introduction）；
  若 `p : Σ x:A, B(x)`，则 `pr₁ p : A`、`pr₂ p : B(pr₁ p)`（elimination）；
  `pr₁ (a, b) ≡ a`、`pr₂ (a, b) ≡ b`（computation）。
- **P1 出处**：CORE_RULES.md C06；HoTT Book §1.6–1.7。
- **P2–P4**：step-2 起。

### PREMISE-A-03 · 自然数 Nat 的规则四元组

- **类别**：A
- **P1 前提陈述**：`Nat : U`（formation）；`0 : Nat` 且若 `n : Nat` 则 `succ n : Nat`
  （introduction）；给定 `P : Nat → U`、`pz : P(0)`、`ps : Π n, P(n) → P(succ n)`，
  得消除子 `R(pz, ps, n) : P(n)`（elimination）；`R(pz, ps, 0) ≡ pz`、
  `R(pz, ps, succ n) ≡ ps(n, R(pz, ps, n))`（computation）。
- **P1 出处**：CORE_RULES.md C09；HoTT Book §1.9。
- **P2–P4**：step-2 起。

### PREMISE-A-04 · identity / Path 类型的规则四元组

- **类别**：A
- **P1 前提陈述**：若 `A : U` 且 `x, y : A`，则 `Id_A(x, y) : U` / cubical 中
  `Path A x y : U`（formation）；`refl_x : Id_A(x, x)` / cubical 中
  `λ i. x : Path A x x`（introduction）；基于 `C : Π x y:A, Id(x,y) → U`、
  `c : Π x, C(x, x, refl)` 的 J 消除子 / cubical 中对面条件的 transport 与 comp
  （elimination）；J 在 `refl` 上的计算规则 / cubical 中 comp 的计算规则（computation）。
- **P1 出处**：CORE_RULES.md C11；HoTT Book §1.12；cubical 的 Path/comp 见 E02/E11。
- **P2–P4**：step-2 起。

### PREMISE-A-05 · universe U / El 的规则四元组

- **类别**：A
- **P1 前提陈述**：`U : U'`（每个宇宙属于下一宇宙，formation）；
  若 `A : U` 则 `El A` 是一个类型（introduction/decode）；universe 在类型构造子下
  封闭（见 PREMISE-F-01，此处登记其"形成资格"部分）；code/decode 的转换规则
  （computation，`El (Code A) ≡ A` 的变体）。
- **P1 出处**：CORE_RULES.md C04；HoTT Book §1.11、§A.2 的 universe 规则。
- **P2–P4**：step-2 起。

### PREMISE-A-06 · 高阶归纳类型（HIT）的构造子与消除规则

- **类别**：A
- **P1 前提陈述**：HIT 由**点构造子**（生成 0 维元素）与**路径/高阶路径构造子**
  （生成 1 维及更高维元素，如 `loop : base = base`）共同形成；其消除子（recursor /
  induction）必须为**所有**构造子提供处理分支，包括高阶路径构造子；计算规则覆盖点
  构造子（如 `rec(base) = b₀`）与路径构造子（如 `ap rec(loop) = p`）两层。
- **P1 出处**：CORE_RULES.md C16；HoTT Book §1.13、第 6 章；cubical 计算 HIT 见
  `EXTENSIONS_AND_METATHEORY.md` E12。
- **P2–P4**：step-2 起。

### PREMISE-A-07 · 余积 A+B 的规则四元组

- **类别**：A
- **P1 前提陈述**：若 `A, B : U`，则 `A + B : U`（formation）；`inl(a) : A + B`
  与 `inr(b) : A + B`（introduction）；给定 `P : A + B → U`、
  `pl : Π a:A, P(inl a)`、`pr : Π b:B, P(inr b)`，得消除子
  `match(pl, pr, w) : P(w)`（elimination）；`match(pl, pr, inl a) ≡ pl(a)`、
  `match(pl, pr, inr b) ≡ pr(b)`（computation）。
- **P1 出处**：CORE_RULES.md C07；HoTT Book §1.5。
- **P2–P4**：step-2 起。

### PREMISE-A-08 · 空类型 0 的规则四元组

- **类别**：A
- **P1 前提陈述**：`0 : U`（formation）；**没有 introduction 规则**（无构造子）；
  给定任意 `P : 0 → U`，得消除子 `exfalso : Π z:0, P(z)`（elimination，
  从空类型导出任意类型）；无 computation 规则（因无构造子可计算）。
- **P1 出处**：CORE_RULES.md C08；HoTT Book §1.7。
- **P2–P4**：step-2 起。

### PREMISE-A-09 · 单位类型 1 的规则四元组

- **类别**：A
- **P1 前提陈述**：`1 : U`（formation）；`⋆ : 1`（唯一的 introduction）；
  给定 `P : 1 → U` 与 `p⋆ : P(⋆)`，得消除子，其结果对 `⋆` 计算为 `p⋆`
  （elimination + computation）。单位类型的相等是平凡命题。
- **P1 出处**：CORE_RULES.md C08；HoTT Book §1.8。
- **P2–P4**：step-2 起。

### PREMISE-A-10 · 布尔类型 2 的规则四元组

- **类别**：A
- **P1 前提陈述**：`2 : U`（formation）；`0₂, 1₂ : 2`（两个 introduction）；
  给定 `P : 2 → U`、`p₀ : P(0₂)`、`p₁ : P(1₂)`，得消除子（elimination）；
  在 `0₂` 上计算为 `p₀`、在 `1₂` 上计算为 `p₁`（computation）。这是"有限分支
  判定"的最简形态。
- **P1 出处**：CORE_RULES.md C08；HoTT Book §1.8。
- **P2–P4**：step-2 起。

### PREMISE-A-11 · W 类型（一般归纳定义）的规则四元组

- **类别**：A
- **P1 前提陈述**：给定 `A : U` 与 `B : A → U`，形成 `W x:A, B(x) : U`
  （formation）；其 introduction 是 `sup(a, f)`，其中 `a : A` 且
  `f : B(a) → W x:A, B(x)`（树形递归的分支函数）；其消除子是 `W`-recursion/
  induction，对每个 `a : A` 与分支函数 `f` 给出递归结果（elimination）；
  计算规则在 `sup` 上展开（computation）。W 类型是"任意分支树的归纳闭包"，
  是一般良基归纳的语法形态。
- **P1 出处**：CORE_RULES.md C10；HoTT Book §1.10。
- **P2–P4**：step-2 起。

## B. 判定与相等

### PREMISE-B-01 · definitional equality / conversion 是可判定的判断

- **类别**：B
- **P1 前提陈述**：类型论设一个语法层的**定义相等** `a ≡ b : A`（conversion），它由
  固定的规则集（α、β、η 及 δ/ι/ζ 等展开规则）生成，并且**可判定**：任给两个项，
  存在机械过程判定它们是否 convertible。它与命题相等（identity type）分离，
  `a ≡ b : A` 蕴含 `refl : a = b`，反之不成立。
- **P1 出处**：CORE_RULES.md C01、C03、C17；HoTT Book §1.1（判断形状）与附录的
  conversion 规则。
- **P2–P4**：step-2 起。

### PREMISE-B-02 · β-reduction（各构造子的计算规则）

- **类别**：B
- **P1 前提陈述**：每个构造子的消除子作用在 introduction 形式上立即化简：
  `(λ x. b)(a) ≡ b[a/x]`（Π）；`pr₁ (a,b) ≡ a`（Σ）；
  `R(pz,ps,0) ≡ pz`（Nat）；J/refl 的 comp（identity）。这确立"计算"在理论内部
  是一个可逐步执行的化简过程。
- **P1 出处**：CORE_RULES.md C05/C06/C09/C11 的 computation 部分；HoTT Book §1.4/1.6/1.9/1.12。
- **P2–P4**：step-2 起。

### PREMISE-B-03 · η-laws（外延性计算规则）

- **类别**：B
- **P1 前提陈述**：η 规则把"两个 introduction 形式在所有观察下相同"提升为定义相等：
  Π 的 η（`f ≡ λ x. f(x)`：函数由其在所有输入上的取值完全决定）；Σ 的 η
  （`p ≡ (pr₁ p, pr₂ p)`）；Path/identity 的 η 变体。在书式 HoTT 中函数外延性
  是公理（见 PREMISE-C-02），在 cubical 中 η 与 comp 结合使其可计算地成立。
- **P1 出处**：CORE_RULES.md C05、C14；HoTT Book §2.9；cubical 的 Π-η 见 E02/E11。
- **P2–P4**：step-2 起。

### PREMISE-B-04 · J 的计算规则与 transport

- **类别**：B
- **P1 前提陈述**：J 在 `refl` 参数上计算为该分支的值；由 J 导出 `transport`：
  对 `p : x = y` 与 `P : A → U`，得 `transport^P(p) : P(x) → P(y)`，且
  `transport^P(refl) ≡ id`。路径的代数（对称、合成、结合律）由此计算地建立。
- **P1 出处**：CORE_RULES.md C11、C12；HoTT Book §1.12、§2.1–2.2。
- **P2–P4**：step-2 起。

## C. 恒等与等价

### PREMISE-C-01 · identity type 的命题性（isProp）

- **类别**：C
- **P1 前提陈述**：对任意 `x y : A`，identity type `Id_A(x, y)` 是一个命题
  （`isProp(Id_A(x,y))`）：任意两条路径 `p q : x = y` 之间存在更高阶路径
  `p = q`。即相等类型的"证明"在类型层被压平为至多一个元素（局部命题性）。
- **P1 出处**：CORE_RULES.md C11；HoTT Book §3.1（局部命题性）；
  cubical 中由 comp 推出，见 E02。
- **P2–P4**：step-2 起。

### PREMISE-C-02 · 函数外延性（function extensionality）

- **类别**：C
- **P1 前提陈述**：若 `f g : Π x:A, B(x)` 且对**所有** `x : A` 有 `f(x) = g(x)`，
  则 `f = g`。即在 Π 类型上，两个函数相等当且仅当它们逐点相等。
- **P1 出处**：CORE_RULES.md C14；HoTT Book §2.9（由 univalence 推出）；
  cubical 中为定理，见 E02/E11。
- **P2–P4**：step-2 起。

### PREMISE-C-03 · univalence（公理形式）

- **类别**：C
- **P1 前提陈述**：等价蕴含相等：`(A ≃ B) → (A = B)`，与 canonically 相等的逆
  一同给出 `A = B ≃ (A ≃ B)`。作为公理加入书式 HoTT（Axiom 3 / §2.10），
  它断言"等价"与"相等"是同一概念。
- **P1 出处**：CORE_RULES.md C15；HoTT Book §2.10、§A.2（Axiom 3）。
- **P2–P4**：step-2 起。

### PREMISE-C-04 · univalence（cubical 定理形式，与 C-03 分别登记）

- **类别**：C
- **P1 前提陈述**：在 cubical 类型论中 univalence 不是公理而是**可计算地证明的定理**：
  由 `Glue` 类型与 composition/cofibration 机器，对每个等价 `e : A ≃ B` 构造
  路径 `ua(e) : A = B`，并给出 `ua` 与其逆的构造与计算规则（comp 规则）。
  这与 C-03 的公理形式在证明义务与计算内容上不同，故分别登记。
- **P1 出处**：`EXTENSIONS_AND_METATHEORY.md` E02（CCHM）、E11（Cartesian cubical）；
  原始规则见 CCHM 的 Glue/composition 规则。
- **P2–P4**：step-2 起。

## D. cubical 机器

### PREMISE-D-01 · 区间 I 与端点、连接（connections）

- **类别**：D
- **P1 前提陈述**：存在一个区间类型 `I`，带端点 `0, 1 : I`；`I` 上有连接操作
  `∧`、`∨`（De Morgan 代数结构）与最大/最小元；依赖类型的项可在 `I` 上变化
  （`λ i. ...`），使"路径"成为 I 上的函数族。
- **P1 出处**：`EXTENSIONS_AND_METATHEORY.md` E02/E11；CCHM/ABCFHL 的区间规则。
- **P2–P4**：step-2 起。

### PREMISE-D-02 · cofibration / 面条件（face formula）

- **类别**：D
- **P1 前提陈述**：由区间端点与连接构成的**面公式**（cofibration，形如
  `i = 0`、`i = 1`、`φ ∧ ψ` 等）标出"区间的哪些部分被约束"；类型与项可以在
  面条件上被部分指定，形成部分元素（partial element），由 cofibration 语法管理。
- **P1 出处**：`EXTENSIONS_AND_METATHEORY.md` E02；CCHM 的 cofibration 规则。
- **P2–P4**：step-2 起。

### PREMISE-D-03 · composition / coe / transport（区间上的类型转换）

- **类别**：D
- **P1 前提陈述**：给定沿区间变化的类型族与边界上的部分元素，存在
  `composition` 操作把该部分元素"合"成一个完整的面（填充给定边界）；
  `coe`（强制转换/沿路径的类型迁移）与 `transport` 由 composition 导出，
  并给出其计算规则。
- **P1 出处**：`EXTENSIONS_AND_METATHEORY.md` E02/E11；CCHM 的 composition 规则。
- **P2–P4**：step-2 起。

### PREMISE-D-04 · Kan 填充（composition 的填充物存在）

- **类别**：D
- **P1 前提陈述**：cubical 类型论要求每个类型的 composition 操作同时提供
  **填充物**（filler）：一个高维盒子，其边界由被合成的面与"底"构成。
  这即 Kan 条件在 cubical 语法中的内置化。
- **P1 出处**：`EXTENSIONS_AND_METATHEORY.md` E02/E11；CCHM 的 Kan 填充规则。
- **P2–P4**：step-2 起。

### PREMISE-D-05 · cofibration 的紧性 / 在操作下的封闭性

- **类别**：D
- **P1 前提陈述**：cofibration 在 composition 与相关操作下封闭，可被系统
  （uniformly）用于任意类型的构造，而不必为每个类型单独假设可填充性
  （与"每个 cofibration 都可填充"作为设计决策的 G-05 相区分：本条登记的是
  语法层封闭性，G-05 登记的是把它设为构造可用资源的决策）。
- **P1 出处**：`EXTENSIONS_AND_METATHEORY.md` E02/E11；CCHM 的 cofibration 紧性。
- **P2–P4**：step-2 起。

## E. 截断与层级

### PREMISE-E-01 · isProp / isSet 与截断层级的定义

- **类别**：E
- **P1 前提陈述**：`isProp(A) := Π x y:A, x = y`；`isSet(A) := Π x y:A, isProp(x = y)`；
  由此上推 `is-n-type` 的层级塔（n-truncation hierarchy），每一层由"更上一层
  的路径类型是命题"定义。
- **P1 出处**：`HoTT/theory-schema/DERIVED_STRUCTURES.md`；HoTT Book §3.1、§3.3。
- **P2–P4**：step-2 起。

### PREMISE-E-02 · 命题截断（propositional truncation，-1-截断）

- **类别**：E
- **P1 前提陈述**：对任意 `A`，存在命题截断 `||A||`（HIT）：它是一个命题，
  带构造子 `|·| : A → ||A||` 与消除规则"只需在命题目标上使用 `|a|` 的像"；
  它把"存在性"与"具体见证"分离，只保留存在性信息。
- **P1 出处**：HoTT Book §3.6、§6.9；DERIVED_STRUCTURES.md。
- **P2–P4**：step-2 起。

### PREMISE-E-03 · 商 HIT 与高阶截断

- **类别**：E
- **P1 前提陈述**：给定关系 `R : A → A → U`，存在商类型 `A/R`（set-quotient HIT），
  带等价类构造子与 0-截断条件（`isSet(A/R)`）；一般地，对每个 n 存在
  n-截断 HIT `||A||_n`，其构造子含把高阶路径截断到 n 层的条件。
- **P1 出处**：HoTT Book §6.9、§7.3；DERIVED_STRUCTURES.md。
- **P2–P4**：step-2 起。

### PREMISE-E-04 · 层级的稠密性（截断塔可任意延伸）

- **类别**：E
- **P1 前提陈述**：截断层级不预设上限：对每个 n，n-类型与 (n+1)-类型的区分
  与截断操作都可用，截断塔可任意延伸；理论不指定"现实世界落在哪一层"，
  层级选择由具体任务决定而非理论决定。
- **P1 出处**：HoTT Book §7.3（截断层级）；DERIVED_STRUCTURES.md。
- **P2–P4**：step-2 起。

## F. 宇宙与分层

### PREMISE-F-01 · universe U 的封闭性

- **类别**：F
- **P1 前提陈述**：每个宇宙 `U` 在 Π、Σ、Nat、identity、HIT 等类型构造子下
  封闭：若 `A : U` 且 `B : A → U`，则 `Π x:A, B(x) : U`、`Σ x:A, B(x) : U`；
  `Nat : U`；`Id_A(x,y) : U`；HIT 的形成结果在 `U` 中（universe closure rules）。
- **P1 出处**：CORE_RULES.md C04；HoTT Book §1.11、§A.2 的 U 规则。
- **P2–P4**：step-2 起。

### PREMISE-F-02 · Cumulativity / 2LTT 式的内外层分工

- **类别**：F
- **P1 前提陈述**：宇宙层级之间可设**累积**（cumulativity：`U_i : U_{i+1}` 且
  `U_i` 的元素也是 `U_{i+1}` 的元素），或采用两层（2LTT）分工：外层 universe

## G. 设计决策类前提（用户意义上的"抽象"）

### PREMISE-G-01 · 把恒等设为类型族（而非固定命题常量）

- **类别**：G
- **P1 前提陈述**：HoTT 把相等处理为一个**类型族** `Id_A : A → A → U`，
  而不是一个返回固定命题 `Prop` 的二元谓词；`x = y` 的"证明"是某个类型的
  居留者，其居留者可以多于一个，并且这些居留者自身构成更高阶类型。
- **P1 出处**：CORE_RULES.md C11；HoTT Book §1.12（identity type 的形成方式）。
- **P2–P4**：step-2 起。

### PREMISE-G-02 · 把相等设为命题（局部命题性作为设计选择）

- **类别**：G
- **P1 前提陈述**：与 G-01 并存的设计选择是：**相等类型本身是命题**
  （`isProp(x = y)`，PREMISE-C-01 的事实形态）。二者共同确定 HoTT 的"集合式"
  行为：同一对元素之间的路径在类型层"实际上只有一个"，更高阶路径存在但不
  携带新的相等信息（对 isSet 类型而言）。
- **P1 出处**：CORE_RULES.md C11；HoTT Book §3.1（"每个类型的相等类型是命题"
  作为基本事实的陈述方式）。
- **P2–P4**：step-2 起。

### PREMISE-G-03 · 把高阶相等设为可无限迭代

- **类别**：G
- **P1 前提陈述**：对 `p q : x = y`，可形成 `p = q`；对后者的两条元素又可形成
  更高阶的相等，**无上限地迭代**。这使每个类型携带一个 ∞-groupoid 结构
  （无穷高阶路径塔），理论不预设哪一层是"最后一层"。
- **P1 出处**：CORE_RULES.md C11；HoTT Book §2.1（路径类型迭代）、§A.2。
- **P2–P4**：step-2 起。

### PREMISE-G-04 · 把等价提升为同一（univalence 的方向）

- **类别**：G
- **P1 前提陈述**：设计决策的方向是"等价即相等"：不仅相等蕴含等价（平凡），
  而且**等价蕴含相等**。这把"两种结构同构"与"两种结构是同一个东西"在类型层
  同一化，使类型上的陈述对等价保持（structure invariance）。
- **P1 出处**：CORE_RULES.md C15；HoTT Book §2.10（univalence 的陈述动机）。
- **P2–P4**：step-2 起。

### PREMISE-G-05 · 把"所有 cofibration 可填充"设为构造可用

- **类别**：G
- **P1 前提陈述**：cubical 类型论把"所有面条件都有填充物"（Kan 条件）设为
  **构造性可用资源**：不只是存在性断言，而是语法层每个类型都自带 composition
  与 filler 操作，可在任意构造中直接调用。这是"无限/连续可被处理"的工程化
  形态（与 D-03/D-04 的规则登记相区分：D 登记规则内容，本条登记把它设为
  可用资源的决策）。
- **P1 出处**：`EXTENSIONS_AND_METATHEORY.md` E02/E11；CCHM 的 Kan 条件作为
  内置规则。
- **P2–P4**：step-2 起。
