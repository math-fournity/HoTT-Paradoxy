# 范围、渠道与证据语义

## 一、时间与主题范围

本轮以 2026-09-14 为截止日。历史起点包含 Gödel 1931，因为不完备性先于 Turing/Church 1936；用户所说“从图灵开始”按“经典可计算性与不完备性起点”解释，而不删除更早的直接前驱。

必须覆盖七个主题族：

1. `FND`：Gödel、Turing、Church、Rosser、Kleene、Post、Rice/Rice–Shapiro、Tarski、Hilbert–Bernays、Löb、Lawvere、Rogers/Myhill、Chaitin；
2. `MOC`：Turing/Minsky/register/λ/μ-recursion/FRACTRAN/DPRM、universal evaluator、halting 与 many-one/Turing reduction；
3. `TRM`：normalization、canonicity、decidable conversion/type checking、unification/inhabitation/proof search、termination/size-change/sized types；
4. `PAR`：partiality、dominance、general recursion、coinduction、guarded/clocked recursion、productivity、domain theory；
5. `HCT`：HoTT、univalent/cubical type theory、Cubical Agda、computational higher type theory、cofibration logic、modalities 与 higher identity；
6. `MET`：2LTT、internal syntax、QIIT/HIIT、reflection/quotation、MetaRocq、proof checker、inner/outer theory 与 conservativity；
7. `MFM`：Coq/Rocq、Agda、Cubical Agda、Lean、Isabelle 中的机器化 computability、incompleteness、Löb、Tarski、Chaitin 和 formal-system syntax。

每个核心来源至少映射到一个机器问题：R0–R5、TC/OP/CC/OL/CP/OR/FM、或一个反解释/防线。没有机器映射的来源可以保留为历史背景，但不能占用“关键依赖已闭合”的状态。

## 三、纳入与排除

### 纳入

- 给出本项目某项定义、定理前提、反例、模型、算法、复杂度、形式化实现或系统边界；
- 与 HoTT/univalence/cubical/2LTT 的计算、部分性、自指、语法、证明搜索或可判定性直接相关；
- 经典工作即使没有现代关键词，也因谱系位置预注册；
- 最新论文若修改 CompletionProperty、HoTT essentiality、inner/outer 或 consumer taxonomy，优先纳入。

### 排除或背景化

- 只借用 “Gödel/Turing/univalent” 名称、但对象属于医学影像、泛 AI 哲学、调和单叶函数等无关领域；
- 无作者/版本/正文、无法定位一手来源的聚合页面；
- 仅重复教科书叙述且不新增前提、证明路线或形式化；
- 哲学解释可进入背景，不得替代形式 theorem/assumption。

排除必须有理由；title-only triage 不执行最终排除。

## 四、证据状态

`DISCOVERY_UNREVIEWED` → `PRIMARY_ENTRY_CONFIRMED` → `FULL_TEXT_OR_DECLARED_SECTIONS_READ` → `THEOREM_ASSUMPTIONS_EXTRACTED` → `TASKSPEC_MAPPED` → `EXPERIMENT_OR_FORMAL_DEPENDENCY`。

另有 `BACKGROUND_ONLY`、`DUPLICATE_VERSION`、`OUT_OF_SCOPE_WITH_REASON`、`PRIMARY_BODY_UNAVAILABLE` 和 `REVIEW_REQUIRED`。只有最后三层闭合的核心来源，才能支撑方案或数学判断；metadata 命中只能证明“候选被发现”。
