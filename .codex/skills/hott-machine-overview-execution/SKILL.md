# 第三轮机器统观执行工作法

## 目的与前置

让用户的理论经济/普适性元思考实际组织HoTT发现：找出被省去或增加的条件，再设计恰好需要它的过程。先建立repo-cognitive-closure，完整读root AGENTS、共同治理与TASK_ROUTING，按实际任务选择：原A读[Goal6](../../../goal-6.md)及[Goal5](../../../goal-5.md)；续做C完整读[Goal7](../../../goal-7.md)，由它拥有新父范围、SOP/闭包和完成门。旧方法可复用，旧完成口径不授予C完成资格。

确认用户确实要执行第三轮及A或C角色；仅准备方案或审计时不进入执行。不得因触发Skill自动create_goal、另建任务、spawn或推送。开始时核root/Git/dirty/index、并行writer和STATE，保护历史与他人修改。

## Goal7续做分支：先父范围充分性，再研究结案

C先依Goal7§4的Book/附录、全部Schema条目及已命名子分支、配置/关键接口形成父范围，再读旧35单元及四proof包；不要让旧案例定义新范围。每项的实审/精确复用/排除/待审与研究结果分轴，缺来源、未审、未定重要性不能用OPEN结果注销。

R0固定旧final-002并核复用，R1建来源到研究的双向映射，R2从全范围构造嵌套/重叠语义单元与关系，R3补真实敏感过程与相称验证，R4用独立组织重建挑战范围，R5双重结案与新封存。无信号也审结构；联合/顺序/背景/参数族不丢，重要遗漏回前阶段处理，不改成范围外。

C必须在complete前交自己的覆盖充分性论证；全部自选项通过、少数proof或将来D审计均不够。Goal7六门逐项取得证据，无命中不等于不完整，但覆盖欠项必须保持PARENT_SCOPE_INCOMPLETE。C写Session-C及Goal7授权路径，旧A只读；新record关联旧阶段不继承其整体完成。具体工具/权限/恢复/结束以Goal7为准，下方通用发现与核证循环继续适用。

## 输入与强制认知

首次研究按核心→方向→全景→扩展完整读四件套全部逻辑分片，research profile、三问、当前前沿与程序化完备性规划全部分片；源版本、证据等级和当前队列分开。旧研究结果按精确命题/任务/版本裁决复用，不把旧PASS当本轮新覆盖。

每换理论语义单元、主要靶前提，或压缩后恢复分析，重新全文读单体最高指示，并重读KC47/48完整原文；动态以core当前ID核身份，不硬编码KC总数。按最高指示回答14题、三次呈现/迁移与当前尺度/未审邻域/原问余项。只有可见回答和后续具体过程能支持本轮消费，不以hash认证理解。

按最高指示§0B区分全局方法目标、候选自身X_i、实际引用或声称回答的历史X_h。新候选可直接由理论及现实／假想现实活动生成，无须历史祖先。第8题允许没有历史类比，第11题首先核X_i，历史保真仅在实际引用/承接时触发；不要求每次回接圆环，也不禁止圆环或环路题材。

触发后的义务仍有层次：引用核来源与上下文，类比说明所借关系及差异，声称精化/回答原案才承担相应任务范围的桥接。引用或受启发本身不使新候选承担全案翻译。

## 工作循环

1. **定位**：先给八域的来源、独立问题、旧覆盖与缺口首遍；为当前单元写精确演算、尺度、成员/关系、收益和来源。不得从最熟悉后端缩窄全局。
2. **生成**：考察添入理想条件和省去/合并条件两面；用普通话写E、T→T′、P、O/Done的联系。先交出具体过程雏形，再进入核证；不凑同义候选。
3. **跨尺度**：按Goal5§5从来源作用形成可递归、重叠、多父的语义单元，五种方式不固定深度。成员无异常也审机制、组合、共同背景和整体。关系保留联合条件、顺序及配置；由整体向下找规则/消费者，局部结果向上反馈父问题，不只遍历章节或pairwise。
4. **敏感性与查重**：固定X_i/Input/Operation/Observation/Done及未承接部分；仅实际声称承接X_h时追加历史桥。模型不含T或改变T无可定位影响时补桥/换模型，不扩大枚举。核现有proof/source避免重复，查重不要求历史祖先。
5. **实际判别**：选择与该问题相称的程序化/原生/现实方法，正控制与最强反解释保持同任务。假说允许失败；类型拒绝、timeout、实现行为不能越层成为HoTT矛盾。
6. **证据与表达**：强数学结论按F-011保存精确source/kernel/run/index；候选/来源报告保持等级。逐结论建立公开账本，按最高指示24维适用性审计，修正文、摘要及依赖。
7. **反遗漏与反思**：从父目标核价值/新事实/换题/上下横向遗漏；执行同源重新组织、删中层/漏联合/抹顺序等粒度负例及正常控制、异机制留出与偏差回归。至少在真实HoTT主题重组一次；脚本预给案例不认证自主发现。留出按未覆盖机制选择，无固定题材配额。已接受中高层问题逐项有自己的分析/判别和余项，不以一项示例抵全层；连续同机制无新增判别时换支。
8. **写回与继续**：独占研究证据先落盘；状态升级T3后canonical checkpoint，精确本地commit按实际启动授权和search SOP。确认父范围未完项并继续，不在第一支线结束。

## 权限、恢复与失败

A写Session-A，C写Session-C及各自Goal授权的proof/run/必要owner；current state只由当前唯一研究integrator经canonical事务推进。旧sources/run不改；core不因治理讨论手工追加；不得触碰其它研究者/审计者输出或全局config。源/角色/权限漂移先停止受影响动作，继续无冲突工作。

压缩/跨Session先重新读本Skill、所选Goal6或Goal7及最高指示，再恢复父范围、原文、当前状态、证据和下一动作。不能凭阶段名或hash免正文。缺件/截断先补齐；checkpoint stale/锁冲突不绕过；治理兼容缺口如实登记。

最高指示及方法更新会使旧来源pin失效；按所选Goal的恢复节重读、公开复核并由实际研究者更新自身当前记录，保留旧at-run哈希。核候选历史桥、父范围/工作集、多尺度单元与判别，不自动否定/提升旧成果，也不把更新冒充原文损坏或已消费。

## 输出与完成

A按Goal5/6交付，C按Goal7交付；C尤其须有父范围与覆盖、旧成果复用/缺口、覆盖充分性复核及实际过程/结论/执行证据。全部适用完成门取得实物后封存新代次，给对应审计者路径/hash/subject。执行完成、命中、审计完成及通过分别报告；未命中不免覆盖充分性和验证，预算耗尽不算完成。

方法存在/静态验证不认证未来执行。使用本Skill后仍由真实论证、代码/运行与独立审计判断结果；不要求或记录模型隐藏推理。

原A的任务事项以Goal6§0为对照；C必须改用Goal7的父范围与六项完成门。任何角色都不能把方案/脚本已完成算作真实研究已完成；旧A交付已冻结时，当前Skill的增量不追溯改写其输入。
