# 核心认知逐条论证之二（KC-000025–KC-000046）

> 格式：`relation | 该条要求的工作姿态 | 已走过的路实际做了什么 | 论证 | 对下一选择的指令 + 反证条件`

### KC-000025 · 自指型悖论本应好找

- relation: **NOT_TOUCHED**（且这是本链路最薄的敏感面之一；本单元未改变）
- 姿态：找个自指型悖论本不该这么慢；催促的是真正的构造，不是分类。
- 为什么未触及：五个冻结族 + DM3 三轴 + 本单元的三个探针**全部不含自指构造**。R2 自反线（S-143/144）在 CE-MAP 阶段做过半停机/合成对偶核，但未进入 PREMISE-001 的分母。
- 下一单元要做什么才会触及：把「验证者进入被验证域」落成一个可冻结族（例如：一个 HoTT 规则在检查自身实例的可用性时，其 witness 依赖被检查对象本身）。
- 反证：若 DM3 的 `tower` op 实际构成自指，本条改判（目前 `tower_levels=[0,1]` 有界，不构成自指）。

### KC-000026 · HoTT 不能越过对其自身的自指

- relation: **NOT_TOUCHED**

- 为什么未触及：链路没有对 HoTT 的任何自反机制（规范性、univalence 的自我实例化、截断塔的自我应用）做过机械检查。本单元的 `[UnequalSorts]` 是 sort 层的结构事实，不是自反机制。
- 下一单元：同 KC-000025。这是**结构性未闭合**，不会因多做几个枚举族或探针而消失。
- 反证：无。

### KC-000027 · HoTT 对齐程序后继承程序的自反界限

- relation: **ALIGNED**（链路层面，非本单元）
- 姿态：HoTT 是「逻辑+几何+程序」，已对齐程序；程序的问题（无法写出验证所有程序合法性的程序）就成了它的问题。
- 已做：计算合法性主线（CE-MAP v1 478 项坐标化、R3 不完备性重放、R4 obligation matrix）在 2026-09-14/15 执行过；PREMISE-001 的分母把「程序视角」作为 P2 的默认现实域之一。本单元的 `[NotADatatype]` 是这条的**程序侧实例**：一个不能被模式匹配的对象，正是一个不能被「验证所有程序合法性」的机制处理的形态。
- 论证：链路没有丢掉这条。本单元未直接做哥德尔对照，但表达层诊断与程序侧的自反界限是同一类事实（不可判定性/不可消去性）。
- 指令：保持；但不得让 PREMISE-001 的分母把程序域**唯一化**——KC-000044/000046 要求母域（运动、转动、连续）同等出席。
  反证：若 P2 的 `reality_skeleton` 全部退化到计算域，本条降为 TENSION（修订片 007 的 corpus_pressure 条款就是防这个）。

### KC-000029 · 理论经济收益是自馈回环的高风险位置

- relation: **DEEPENED**
- 姿态：理论想用比现实简单的方式刻画现实，拿掉平凡案例里显得多余的因素；风险就藏在这里。
- 已做：两个方向的**双向对象化**——(i) `declared_faces` 真子集（省下的填充义务被转移成默认假设）；(ii) BLI 单元（`x∧¬x=0` 对三个结构分离非必需——理论保留了一个本可丢弃的假设）。本单元补上**第三种记账**：理论为经济性安排的**表达层结构**——I 不提供 eliminator、`I : IUniv` 不进 `Type` 宇宙，这是 cubical 类型论为了 univalence 的计算解释而作出的安排，代价是 Bool 观察器形态不可写。
- 论证：旧审计只把经济性读成「理论拿掉了现实因素」；168 补上「理论保留了非必需的律」；169 补上「理论的形态选择本身有代价」。三个方向都可机械核查、都带 falsifier。
- 指令：未来候选若声称「理论为经济性舍弃了 X」，必须同时检查「理论是否也为经济性保留了 Y」与「理论的形态选择付出了什么表达代价」。
  反证：若 BLI 结论被 `BLIFalsify` 推翻，本条的反方向收窄为 CORRECTED；若某工具链版本允许 I 的 eliminator，本条的形态代价收窄。

### KC-000031 · 最小化理想理论能否被 HoTT 覆盖

- relation: **DEEPENED**（168 为 NOT_TOUCHED；本单元执行了 168 指出的低成本路径并收尾了 EXP-001）
- 姿态：构造一个极简理论，理应被覆盖却因严格性不能被覆盖。
- 已做：DM3 就是一个「最小化理想理论」候选——极简（三元链 `0<a<1`，`~a=a`），且已被原生核确认为可承载三个结构分离（168）。本单元测了它能否被 HoTT **保真表达**：结论 = **保真翻译存在，但承载层改变**——DM3 的 `separates` 语义可翻译进 cofibration 层（`Partial (r ∨ ~ r)` 的端点体制分片是形态证据），但**不能**翻译成 `I → Bool` 的全局可判定观察（两条来路均 exit 42）。
- 论证：KC-000031 的原始措辞「理应被覆盖却因严格性不能被覆盖」获得了第一个**实测形态**：不是「完全不能覆盖」，而是「能覆盖但形态改变、语义随之改变」。`Partial (φ)` 的「约束下分片定义」≠ `Bool` 的「全局可判定观察」。这是一个有界结论（作用域 = Cubical Agda 2.8.0 + cubical v0.9），不是数学定理。
- 指令：未来任何「HoTT 无法表达 X」的主张必须注明：是完全无法表达，还是只能以改变语义的形态表达。这两者的证据强度不同。
  反证：若一个被核 ACCEPT 的非恒常 `I → Bool` 出现，本条降为 CORRECTED（覆盖变成平凡的）；若 cofibration 翻译被证明不保真，本条升级（找到真正的不可覆盖）。

- 指令：SUPPLY-010 必须是对这三条姿态的**首次执行尝试**，且**不得**要求它替代构造与核验（006 片的三点保留：发现路径不是证明路径）。

### KC-000041 / KC-000042 / KC-000043 · 用好 AI 与超越 AI、符号翻转

- relation: **TENSION**
- 姿态：助力与阻力一体两面；在「超越」上，第一件事的流利通道会变成认知惯性与路径依赖；判据是能力被当透镜还是当对象。
- 已做（好的一半）：判断层全部交给不流利的机器（原生核、枚举、负控制）——本单元把最流利的形态（Bool 观察器）当**对象**测了一次，这是 KC-000043 第 2 点要求的执行。
- 未做（张力的一半）：**供给层仍然是流利通道的产物**。五个族是 AI 在元数学议题上最流利的几个方向；本单元的探针形态（Bool 观察器）也是熟悉形态——虽然这次它被当对象而非透镜，但它**仍是流利通道选出的对象**。符号翻转在「选什么当对象」这一层还没发生。
- 论证：符号翻转在本链路**执行了一半**。判断层翻转了（机器判断），对象层部分翻转了（流利形态被测），供给层没有（AI 的熟悉通道继续供给新任务）。
- 指令：SUPPLY-010 必须自带一个自检：它之所以最先被想到，是因为切中了被省略的结构，还是因为这条通道被走过太多次？该自检的答案写进供给登记。
  反证：若 SUPPLY-010 的候选被证明只能由反观得到（而非任何流利通道），本条升为 ALIGNED。

### KC-000044 · 理论是现实的骨架式模仿；非现实性内容恰恰该认真考虑

- relation: **DEEPENED**
- 姿态：理论永远是对现实的比方与骨架提取；假想中的现实也是现实；不存在「无法用现实把握同伦型」这回事。
- 已做：本单元**测量了同一现实骨架在不同表达层之间的不可互换性**——DM3 分离语义（一个真实的非布尔结构）在 I 上只能以 cofibration 分片形态承载，不能以 Bool 全局观察形态承载。168 测的是「两种骨架之间不可嵌入」（4,096 穷举 = 0）；169 测的是「同一种骨架在两种表达层之间不可互换」。
- 论证：「非现实性内容恰恰是该认真考虑的」在本单元获得第三个精确形态：不是「某个前提看起来不自然」，不是「一个结构无法被另一个结构忠实承载」，而是**「一个语义无法被一个形态忠实承载」**——且这个事实由核的 exit 42 + 诊断名直接给出，可复算。
- 指令：未来任何「该前提非现实」的候选都应问：它是坍缩了布尔性、中间面，还是落错了表达层？登记坍缩方向/层错配，而不是登记形容词。
  反证：若某个被核 ACCEPT 的非恒常 `I → Bool` 出现，本条的层错配论证收窄。

### KC-000045 · 数学与 HoTT 必然可映射现实；对齐的断裂处就是候选出发地

- relation: **DEEPENED**（方法层）／**TENSION**（执行层）
- 姿态：必然存在用人话、用现实例子解释同伦型的路；解释不断贴合又断裂的地方，就是理论为经济性舍弃了不该舍弃之物的地方。
- 已做（方法层）：本单元**确实尽力用现实把握了一次**——把 DM3 分离语义拿到真实区间 I 上对齐，并对齐出了结果：Bool 层断裂（exit 42）、cofibration 层可承载但改变定义。断裂被定位、被收据化，而不是被掩盖。判词分级（168）+ 层定位（169）是「对齐」的两级记账。
- 未做（执行层）：**「用现实解释理论、在断裂处停下」这个动作从未被系统执行于前提清单**。它只在机器统观的原始出发点上被执行过一次（「能否用 HoTT 框架代码构造不可停机的程序」是一个现实问题），以及本单元对 DM3 语义的一次对齐。前提清单的 35 行从未被回到母域逐行解释并记录断裂。
- 论证：扩展认知 008 片的最后一句精确指出「计算是对齐结果可被机器核验的那一个域，但不是唯一现实域」。链路把计算域做透了，母域（运动、转动、连续性）仍只出现在 P2 的 `reality_skeleton` 字段里。
- 指令：SUPPLY-010 必须包含一次真正的现实解释动作（对 F2 层至少一条前提，回到 `reality_skeleton` 指定的域解释，记录断裂处），而不是只填字段。
  反证：若某 P2 条目的 `reality_skeleton` 已被回到母域验证过断裂，本条升为 ALIGNED。

### KC-000046 · AI 缺的是用现实理解理论的动作；机器统观的出发点本身是现实问题

- relation: **ALIGNED**
- 姿态：AI 训练数据充满现实性内容；缺的是「试图用现实去理解理论」这个动作。机器统观的出发点（HoTT 框架代码能否构造不可停机程序）本身就是一个现实问题。
- 已做：本单元的问题「I 上到底能写什么形态的分离」是一个**关于可把握性的现实问题**——它问的不是符号，而是「这种结构能不能被写成一种可观察的东西」。三个探针模块的答案（可写/不可写）都是对可把握性的直接回答。
