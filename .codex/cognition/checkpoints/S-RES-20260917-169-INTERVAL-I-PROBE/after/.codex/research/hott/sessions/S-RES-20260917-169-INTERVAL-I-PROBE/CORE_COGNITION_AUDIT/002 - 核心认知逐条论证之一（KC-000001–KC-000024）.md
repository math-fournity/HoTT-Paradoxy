> 格式：`relation | 该条要求的工作姿态 | 已走过的路实际做了什么 | 论证 | 对下一选择的指令 + 反证条件`

### KC-000001 · 三问（找什么/怎么找/凭什么）

- relation: **ALIGNED**
- 姿态：三问必须同时回答，且相互制约——目标不能窄化成边界族，方法不能空成资料路线，依据不能虚成模型自信。
- 已做：链路对三问各有载体——找什么=`PREMISE-001` 分母（35 条前提，A–G）；怎么找=冻结族→枚举→归约→原生核；凭什么=remainder=0 + 核收据 + exit 42 负控制。本单元的「凭什么」= 三个探针 run 的退出码与诊断（0 / 42 / 42），全部可复算。
- 论证：本单元没有把三问中的任何一问替换成更容易的那一问。探针是一个**纯 Schema 问题**（「I 上能写什么」），它的答案由核直接给出，不依赖 AI 的判断。不足（沿用 168 的诊断，本单元未改变）：三问的「找什么」目前答的是「找非现实性候选的**可枚举分母**」，尚未答「找**候选本身**」。
- 指令：下一单元必须保持「凭什么 = 收据」不变；可以改的是「找什么」的候选供给方式（见分片 008）。
  反证：若某单元以「AI 判断它像悖论」作为依据交付，本条降为 DEVIATED。

### KC-000002 · Theory Schema 先行

- relation: **DEEPENED**（168 为 ALIGNED；本单元是该条最纯净的一次执行）
- 姿态：先冻结语义（Schema/文法），再在有界分母上枚举。
- 已做：探针**先冻结了「I 上能写的形态」这一 Schema 问题，并且完全没有枚举**——它问的是 Schema 本身（I 的消去子/宇宙/sort 结构提供了什么）。结论是 Schema 层的：可写 = 类型族+PathP / cofibration；不可写 = Bool 观察器层。
- 论证：这是 Schema 先行的一次**自返执行**：不只是先冻结文法再枚举，而是把「能冻结什么文法」本身当成问题。STATE 指引（revision 168）预言了这个分支（「替代形态改变分离定义」），实测命中。这比 168 的证据更强地说明：分母的形状不是给定的，它由理论的表达层决定。
- 指令：未来任何族在冻结文法前，应先问「这个文法对应的形态在理论里真的可写吗」。SUPPLY-010 的前提候选必须附带它预期落在哪个表达层。
  反证：若某文法在冻结后被发现形态不可写（如本单元的 Bool 观察器），本条不降级——它被这条指令提前拦住了；若 SUPPLY-010 的候选不附带表达层标注，本条降回 TENSION。

### KC-000006 · 时间机制不能收窄为稠密性

- relation: **ALIGNED**

- 论证：判词分级（修订片 019）本身就是这条的执行；本单元的判词名把形态写进判词（`BOOL_OBSERVER_UNWRITABLE` / `FORMS_FAMILY_AND_COFIBRATION`），是同一记账纪律的延续。

### KC-000007 · LLM 内在知识与模式匹配

- relation: **TENSION**（既有张力，本单元未消解）
- 姿态：用户期待 LLM 用模式匹配把悖论「求解出来」；但 KC-000017 同时要求不被训练先验带着走。
- 已做的执行解：模式匹配**只在供给层**使用（AI 冻结任务族与文法、设计探针模块），判断层一律由原生核承担。
- 论证（为什么仍是 TENSION 而非 ALIGNED）：执行解是**分工**，不是**和解**。本单元的三个探针模块由 AI 设计（形态选择本身就是模式匹配的产物——「Bool 观察器」是 DM3/点集 oracle 的熟悉形态），判断由核给出。这是正确的分工，但模式匹配至今没有产出一个分母外的候选。
- 指令：分片 008 裁决的 SUPPLY-010 就是让模式匹配/知识谱反观去**供给新前提**（不是判定），并显式标注是哪条语义重定向在驱动。
  反证：若某单元的模式匹配产出了被原生核接受的分母外候选，本条升为 ALIGNED。

### KC-000008 / KC-000009 · 历史悖论启发与定位 HoTT 的时间维度

- relation: **ALIGNED**
- 姿态：迁移的是**构造关系**（逐项可行→整体完成、关系的逆→操作的逆、未来可得→现在可用、验证者进入被验证域），不是故事；迁移后必须重新核实规则。
- 已做：`supply`/`fill`/`tower`/`between` 这组 op 是「未来可得→现在可用」的可枚举形态；本单元在**规则位置**上落了新脚：I 的消去子结构（`I : IUniv`，非归纳类型，无 eliminator）——这是一个具体的、可指认的规则事实，不是空泛怀疑。
- 论证：链路确实在 HoTT 的规则位置上落了脚。本单元的脚落得尤其具体：`[NotADatatype]` 与 `[UnequalSorts]` 是两条**可引用的诊断名**，任何后续工作都可以指它们说「这里是 I 的规则位置」。
- 指令：下一选择不得以「已经定位」替代「尚未发现」——本单元把定位做得更好了，发现仍未发生。
  反证：若下单元用定位陈述充当发现陈述，本条降为 DEVIATED。

### KC-000010 · 目标是现实相对非现实性而非内部矛盾

- relation: **DEEPENED**
- 姿态：不找内部矛盾，找「Think in HoTT 后推出现实中不存在的困难」，且困难以不可完成/不可停机为特征。
- 已做：本单元的两条拒绝**都不是矛盾**——`I` 上写不出 Bool 观察器，不是「写了会矛盾」，而是「形态不可成型/不可消去」。这是与 168 的 BLI（a∧¬a=a≠0 无矛盾而分离成立）同一方向的第二个证据：理论的表达界限可以**完全不带矛盾地**存在。
- 论证：「非现实性」与「矛盾」在数学上确实可以分开——168 证了「无矛盾而分离成立」，169 证了「无矛盾而形态不可写」。两个证据的作用域都严格限定，都不是结论，但它们共同把「要找的东西的形状」描得更清楚：它更可能是一个**形态/层错配**，而不是一个矛盾。
- 指令：未来任何候选都应先问「它有没有内部矛盾」——若有，它更可能只是类型错误或已知边界（KC-000027 的警告），不是本研究的靶标。
  反证：若某候选的非现实性最终被证明依赖一个隐含矛盾，本条对「形状」的描摹收窄为 CORRECTED。

### KC-000011 · 理论推演排除时序、程序显式时序

- relation: **DEEPENED**
- 姿态：看理论**什么时候不想让时序参与**，而不是看它的对象里有没有时间变量。
- 已做：availability 轴（`supply` op：对象存在 ≠ 此刻可用）把「时序可用性」做成文法坐标；本单元为它补上了一个**表达层前提**：availability 观察若要做成 `I → Bool` 的全局可判定观察，在区间 I 上不可写——它只能做成 `Partial (r ∨ ~ r)` 的端点体制分片。
- 论证：用户区分的两组判据（对象含时间 vs 过程承担时序）在本单元获得第三种落点：「时序可用性」不仅可以用坐标表达，还可以用**约束分片**表达，且后者才是区间 I 上可写的形态。
- 指令：保持；SUPPLY-010 的前提候选若涉及时序，必须注明它落在坐标形态还是分片形态。
  反证：若 availability 被证明可在纯无时序文法内表达，本条降为 CORRECTED。

### KC-000014 / KC-000022 / KC-000024 · 两种方向（A/B）

- relation: **TENSION**（方向不平衡；本单元未改变）
- 姿态：A = 现实能完成、理论里无法完成；B = 现实无法完成、理论却绕过 ASK 假装已完成。二者不可互替。
- 已做：五个冻结族里，completion-process、existence-vs-availability、divisibility 属 A 侧；identity-observation-layer 触及 B 侧。168 的 DM3 分离两侧都不是；本单元的探针是**表达层诊断**，两侧都不是。
- 论证（为何 TENSION）：**B 侧被系统性薄待**。KC-000024 的长段综合把「多数理论从一开始就打算无视时序」指认为悖论的温床——B 侧是「无视」变成「假装已有」的那一侧。罗素、说谎者、Better-Best 都是 B 侧。本单元没有改变族分布。
- 指令：分片 008 必须保留「一个 B 侧新族」为长期序列节点；不得让 A 侧的干净穷举继续冒充「两类都在找」。
  反证：若 identity-observation-layer 族实际已覆盖 B 侧的完整判据，本条改判 ALIGNED（目前只覆盖「观察层身份」，未覆盖「绕过 ASK 假装已完成」）。

### KC-000015 · 抽象即否定现实前提，需定义「否定」

- relation: **DEEPENED**
- 姿态：抽象必然否定某个现实前提；研究要找到「否定」的具体形态，而不是停留在口号。
- 已做：「否定」在本链路被对象化为至少四种可登记形态：`declared_faces` 真子集（可填充性被预设）、`supply` 的延迟（可用性被预设为存在性）、层级塔的截断（高层被当作已取得）、布尔性的强加（168 的 BLI：x∧¬x=0 非必需）。本单元**未新增第五种**——它给出的是这四种形态的**层定位**：每种「否定」必须注明它打算落在 Bool 观察层还是 cofibration 层，因为层的改变会改变否定本身的定义。
- 论证：这不是新形态，但是对已有形态的**加细**。「理论保留了 Y」这句话在 I 上只有两种写法：全局可判定的（不可写）或约束分片的（可写但语义不同）——因此「保留」的内容随层而变。
- 指令：保持登记习惯 + 层标注。反证：若任一形态被证明不可机械核查，本条收窄。

### KC-000023 · 时间时序处理应可直接定位，「不应这么难」
