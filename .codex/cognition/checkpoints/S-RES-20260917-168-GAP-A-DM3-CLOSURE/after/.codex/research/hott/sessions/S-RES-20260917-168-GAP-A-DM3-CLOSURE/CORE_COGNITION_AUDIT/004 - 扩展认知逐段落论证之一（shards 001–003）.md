# 扩展认知逐段落论证之一（shards 001–003）

> 格式：`该段教的工作姿态 | 已走过的路是否在这个姿态上（证据） | 偏航诊断 | 对下一选择的指令`

## 扩展认知 001 片 · 问题意识与理论的简化

### 段「在回答以前，先让问题真正发生」

- 姿态：最难察觉的误解是把新问题装进旧问题的框架；先让问题改变自己的思考，再调用已有知识。
- 是否在姿态上：**部分**。判断层在姿态上（原生核、falsifier、作用域限定，全是「不让旧框架抢先回答」）。供给层**不在**——五个冻结族全部是旧框架（完成性/可用性/同一性/可分性/层级）的延续。
- 偏航诊断：供给层是「旧框架抢先回答」的高风险区，且它是本链路唯一尚未加防的一层。
- 指令：第三路径单元必须显式声明「这个候选为什么不是某个熟悉框架的又一次复用」。

### 段「理论为什么要把世界变得简单」（KC-000015 / 018 / 029 / 030）

- 姿态：抽象的动机是善意（工具性）；问题藏在优点里；要追踪「哪一项前提被拿掉、哪一种区别被合并、哪一个过程被换成完成态」。
- 是否在姿态上：**是**。`declared_faces` 真子集（可填充性被预设）、`supply` 延迟（可用性被预设为存在性）就是「哪一个过程被换成完成态」的直接登记。BLI 补上反向：理论为简洁**保留**了非必需的布尔律。
- 偏航诊断：无。本段是链路执行得最好的姿态之一。
- 指令：保持「双向经济性」记账（舍弃了什么 / 保留了什么）。

### 段「路线图比喻」

- 姿态：评价抽象必须把「为了什么任务而省略」与「后来又要承担什么任务」连在一起。
- 是否在姿态上：**是**。越界检查（392/392 被既有文法全拒）正是「省略在别的任务里会不会重新成为必需」的机械版本。
- 偏航诊断：无。
- 指令：保持越界检查为标准配置。

## 扩展认知 002 片 · 前提改变、结果与时间

### 段「被改变的前提，怎样在结果里重新出现」（KC-000003 / 019 / 032–034）

- 姿态：不要只挑术语解释真值表；要把注意力从结论移回支撑结论的现实条件；观察理论化如何修改了这些条件。
- 是否在姿态上：**部分**。`reality_skeleton` 字段把每条前提放回了它被提取出来的现实域（D-01 转动域、D-04 制造工装域、E-04 量仪精度域、G-03 运动域——全部非空且未默认只填计算域，这是修订片 007 的 corpus_pressure 条款在起作用）。
- 偏航诊断：**字段填了，但没有回到那些域去实际走一遍**。「把注意力移回现实条件」要求的是解释动作，不是登记动作。
- 指令：第三路径单元对至少一条前提执行「回到母域解释 → 记录断裂处」。

### 段「时间与时序：先后关系不能穷尽时间问题」（含 2026-09-13 用户澄清）

- 姿态：时间与时序是两组不能互相吞并的观察方式；时序问先后/依赖/可用，时间问理论把时空与运动设定成什么结构（连续、稠密、可分）。
- 是否在姿态上：**是，且被刻意保护**。五个族里 divisibility（时间结构层）与 existence-vs-availability（时序可用层）分属不同族，没有被合并；判词分级（修订片 019）拒绝把 density 与 availability 合成一个标签。
- 偏航诊断：无。
- 指令：保持两组判据分离；任何把「有 delay/tower op」叙述成「HoTT 处理了时间」的说法必须被拒绝。

### 段「多个敏感面不能互相吞并」（KC-000006）

- 姿态：成本不吞自指；稠密不吞可用；时序不吞时间结构。
- 是否在姿态上：**部分**。五个面里有四个被族覆盖（完成性、可用性、可分性、同一观察）；**自反面与 B 方向面未被族覆盖**。
- 偏航诊断：敏感面清单本身没有维护机制——它随链路增长，但没有人检查「当前最薄的面是哪两个」。
- 指令：分片 008 必须显式列出当前敏感面覆盖矩阵与最薄两轴。

## 扩展认知 003 片 · 芝诺、圆环、ASK 与两种方向

### 段「把静止的图景重新展开：芝诺与圆环」

- 姿态：把理论的时间/时空/运动前提放进一个具体构造，让构造显出后果；不要把结构性问题改名为时序问题。
- 是否在姿态上：**否（本单元）**。DM3 单元的构造在代数层，不在运动/时空层。
- 偏航诊断：这是**链路层的长期缺口**，不是本单元的特殊失误——但 168 个单元下来，没有一个构造落在运动/时空域。
- 指令：候选排序中应出现一个运动/时空域的构造（例如 D-01 转动域或 G-03 运动域的前提被冻结成族）。

### 段「在真与假之前，谁允许我们提出这个问题」（KC-000016 / 012 / 013）

- 姿态：先问对象是否已取得资格；非法的程序不是理论的失败，但理论把未构造对象当成已有就是失败；ASK 不是万能拒绝，也不要求发明无所不知的审批者。
- 是否在姿态上：**是（机制层）**。入口检查 + exit 42 负控制 = 「资格先于真值」的机械版本；且链路没有把 ASK 做成「先回答所有开放问题才允许开始」的门槛（有界 pass 在开放世界仍 active 时可以完成，正是 §5.5 的纪律）。
- 偏航诊断：**发现层未反向使用 ASK**——即主动去问某条 HoTT 规则「你绕过了哪个 ASK」。
- 指令：把「ASK 反向」列为供给动作。

### 段「两种方向：有时困难被制造，有时困难被抹去」（KC-000014 / 022 / 024）

- 姿态：A 与 B 不可互替；A 侧要警惕把简单现实任务偷偷换成强理论任务；B 侧要警惕把合法数学对象直接说成现实能力。
- 是否在姿态上：**不平衡**。A 侧有四个族；B 侧只有一个族触及（identity-observation-layer），且只覆盖「观察层身份」，未覆盖「绕过 ASK 假装已完成」。
- 偏航诊断：这是本审计最重要的偏航发现之一。KC-000024 的长段综合明确把「多数理论从一开始就打算直接无视时序」指认为悖论温床——那是 B 侧。罗素、说谎者、Better-Best 全在 B 侧。链路的族分布与历史悖论的分布**不匹配**。
- 指令：分片 008 必须把「一个 B 侧新族」写进候选前列；同时保留 A 侧的防偷偷换任务纪律（越界检查）。

### 段「完成」的含义必须保有细节

- 姿态：不停持续输出可能正好完成了持续服务的任务；已给出一串输出也可能尚未满足稳定答案的任务；要让读者准确看见哪一种完成被许诺、哪一种出现困难。
- 是否在姿态上：**是**。`separation_kind`（6 种全出现）与三轴分级就是这个要求的记账形式：不同种类的「无法完成」没有被合并。
- 偏航诊断：无。
- 指令：保持。

### 段「精彩」与基本叙事

- 姿态：一个符合精神的候选应能被追随：从不起疑的起点走到意外困难，且回头能看清困难与某个理论选择的联系。
- 是否在姿态上：**否**。链路至今没有任何候选达到「精彩」——全部是分母内的有界负结论。这不是纪律失误，但它是**目标未达**的诚实状态。
- 偏航诊断：无偏航，但这是本审计必须如实记录的：56,160 次检查与 396 个见证，没有一个被外部观察者会觉得「现实里不存在这种困难」。
- 指令：不得把工程完成度叙述为发现进度。
