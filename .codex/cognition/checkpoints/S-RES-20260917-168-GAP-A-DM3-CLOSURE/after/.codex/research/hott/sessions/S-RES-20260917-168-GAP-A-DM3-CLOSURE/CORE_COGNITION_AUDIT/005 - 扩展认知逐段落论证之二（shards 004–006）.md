# 扩展认知逐段落论证之二（shards 004–006）

> 格式：`该段教的工作姿态 | 已走过的路是否在这个姿态上（证据） | 偏航诊断 | 对下一选择的指令`

## 扩展认知 004 片 · 走进 HoTT 与理论自反

### 段「走进 HoTT，保留问题，也保留理论的真实样子」（KC-000002 / 008 / 009 / 027）

- 姿态：Theory Schema 是定位工具，不是构造名称清单；要由问题走到具体规则，或由规则反问「省下了什么、何时要重新承担」。
- 是否在姿态上：**是**。文法冻结（`v2-dm3-a-v1`）就是 Schema 先行；越界检查就是「何时要重新承担被省下的责任」。
- 偏航诊断：一个次要警示——Schema 的**完整性**仍未被独立核验。修订片 016 的 selftest 142/142 与 V2 ground agreement 3,179/3,179 覆盖的是引擎自身的正确性，不是「HoTT 的 Theory Schema 是否完整」。F2 缺口（PAT / LEM / resizing / AC / unique choice / 截断时机判据 / Dedekind-Ω：来源在手、分母零条）就是 Schema 不完整的证据。
- 指令：把 F2 缺口层当作 Schema 完整性问题的具体形态，而不是当作「以后再说」。

### 段「历史悖论提供可迁移的构造关系」

- 姿态：迁移的是关系（逐项可行→整体完成、关系的逆→操作的逆、未来可得→现在可用、验证者进入被验证域），每次迁移须重新核实规则。
- 是否在姿态上：**部分**。前三条迁移都被落地成族（completion-process / identity-observation-layer / existence-vs-availability）。**第四条（验证者进入被验证域）从未落地**。
- 偏航诊断：第四条正是自反轴（KC-000025/026/028），链路的敏感面矩阵上最大的空洞。
- 指令：见分片 008。

### 段「HoTT 已对齐程序」（KC-000027）

- 姿态：保留认识的演化——HoTT 不是纯静态系统；向程序靠近不等于研究结束；新追问是程序的有效性、完成条件与自反问题怎样进入理论。
- 是否在姿态上：**是**。CE-MAP/R3/R4 线执行了这个追问；本单元的 availability 轴是它在文法层的延续。
- 偏航诊断：无（但见 KC-000027 指令——不得让程序域唯一化）。
- 指令：保持程序域与运动/连续域的并列。

### 段「当理论把自己放进问题里」（KC-000025 / 026 / 028 / 036）

- 姿态：验证者进入被验证域后，原来顺畅的推理会怎样；要找到「谁要求了下一份担保、为什么必须由同一过程提供、是否存在合法终止依据」；量词「某种情况下、某些问题上」必须保留；不能把「有回环」直接当成「不能停止」。
- 是否在姿态上：**否（零执行）**。链路的归约链严格 DAG；没有任何单元把验证者放进被验证域。
- 偏航诊断：这是**结构性未闭合**，不会因多跑几个 A 侧族而消失。自反轴的零覆盖与「验证者进入被验证域」的零迁移是同一件事。
- 指令：分片 008 应把它列为长期序列的必经节点，即使不是下一单元。

## 扩展认知 005 片 · 表达界限、文章作为起点与编写说明

### 段「一个理论可以表达多少，也值得被当作问题」（KC-000031 / 035）

- 姿态：极简理论理应被覆盖却因严格性不能被覆盖；「能把名字放进类型里」不等于表达；要对准明确的保真要求。
- 是否在姿态上：**否（未执行）**。EXP-001 登记未执行。但本单元的 DM3 证据**自然指向**一条低成本执行路径：DM3 极简（三元链）、已被原生核确认可承载三个结构分离——问 HoTT 能否保真表达 DM3 上的分离语义，就是一个现成的「最小化理想理论」覆盖测试。
- 偏航诊断：未执行，但路径已由本单元证据指出。这是本审计能给出的最具体的「下一动作」之一。
- 指令：分片 008 将其列为候选；若 HoTT 有平凡表达，登记有界负结论（同样有价值）。

### 段「让一篇文章变成思考的起点」

- 姿态：原文不是供奉的引文；真正的启发应当**改变下一项动作**；若读完仍选不出一个明确的可用性任务或一个待比较的表示，那么原文只是被读到了。
- 是否在姿态上：**这是本审计存在的原因**。旧审计合同（一行 KC 表格）恰恰把原文退化成「被读到」——它无法改变下一项动作，因为它不审计下一项动作。
- 偏航诊断：**旧合同的系统性偏航**。修订片 020 的修正正是针对这一点：审计必须落到「即将作出的选择」。
- 指令：本分片集（004–006）与分片 008 一起构成「文章改变下一动作」的首次执行。

### 段「机器证明不是取消哲学展开的理由」（KC-000021）

- 姿态：叙述应引导到可检查的构造；形式化核对的应正是叙述所声称的命题；把较弱命题证明得漂亮不能替代较强原问题。
- 是否在姿态上：**是，且被刻意保护**。判词 `ENGINEERING_ACCEPTANCE_ONLY / NO_NEW_MATH_CLAIM`、`registers_new_claim:false`、BLI 的作用域限定（=DM3）——全部是「弱命题不冒充强命题」的记账。
- 偏航诊断：无。
- 指令：保持；这是本链路不可让步的底线。

### 编写说明段（essay-role:v1 声明）

- 姿态：扩展认知是 AI 阐释层，不是用户原文权威；它的展开不构成数学结论；原文 generation 变化时应据新原文重检覆盖。
- 是否在姿态上：**是**。本审计对扩展认知的每段论证都以「教的工作姿态」为单位，不把展开文字当成命题；所有强结论都回到 KC 原文锚点。
- 偏航诊断：无。
- 指令：保持。核心认知 generation-7（46 条）是当前原文；本审计按 generation-7 全量执行。

## 扩展认知 006 片 · 第三条发现路径：把知识谱当作被考察对象

### 段「一眼想到不是修辞」（KC-000037）

- 姿态：发现的成本可以极低，只要站在「前提在哪里」而不是「结论是否可推导」；但发现不费力不等于发现无根据——圆环悖论一眼可见，是因为提出者保有对现实过程的直接判断。
- 是否在姿态上：**否（零执行）**。
- 偏航诊断：链路始终站在「结论是否可推导」这一侧（枚举、归约、核验）。用户的姿态从未被测试。
- 指令：这是分片 008 的直接动因。

### 段「阅读作为发现路径」（KC-000038）

- 姿态：关键抉择藏在出发点（等价视为同一、路径视为可替换身份、完成视为给定结构）；「捕捉思路缺陷」不是攻击推演错误，而是追问这些出发点各自把现实的哪部分当作可省略的冗余。
- 是否在姿态上：**否**。链路的每一次供给都是「把已形式化的构造关系写成文法」，没有一次是「阅读出发点、追问可省略性」。
- 偏航诊断：这是**供给层的系统性单一来源**——所有候选都来自构造层，没有一个来自阅读层。
- 指令：第三路径单元的产出形态必须是「前提候选 + 它由哪条出发点驱动」，不是文法。

### 段「必然」的方法论分量（KC-000039）

- 姿态：基础问题在基础之处，而基础必然已在训练数据里——因此「找不到」不能归因于材料不足，只能归因于材料从未被当作被审视的对象。
- 是否在姿态上：**否，且这条对链路的指责最重**。链路的归因是「候选空间需要机器穷举」，而用户的归因是「材料未被审视」。两个归因不矛盾（机器穷舉是验证侧必需的），但链路只执行了一个。
- 偏航诊断：见上。
- 指令：见分片 008。

### 段「路径的枢轴与三点保留」（KC-000040）

- 姿态：把知识谱当作**被考察对象**而非**判断权威**；同时保留三点——(1) 它是发现路径不是证明路径，候选仍须构造与核验；(2)「完整知识谱」是要求不是已兑现事实，反观能见多少取决于实际被唤起的范围；(3)「非现实」的判断最终落在现实对应上，不由「看起来不自然」裁定。
- 是否在姿态上：**本审计必须执行第 (2) 点**——承认链路的反观范围目前极窄（只在 DM3/面格/延迟几个形式化区域内）。
- 偏航诊断：无（本片是姿态本身，链路的偏离在「未执行」而非「执行错」）。
- 指令：第三路径单元必须显式声明它唤起了多大范围的知识谱，并把第 (2) 点的不足写进登记。
