# 核心认知逐条论证之一（KC-000001–KC-000024）

> 格式：`relation | 该条要求的工作姿态 | 已走过的路实际做了什么 | 论证 | 对下一选择的指令 + 反证条件`

### KC-000001 · 三问（找什么/怎么找/凭什么）

- relation: **ALIGNED**
- 姿态：三问必须同时回答，且相互制约——目标不能窄化成边界族，方法不能空成资料路线，依据不能虚成模型自信。
- 已做：链路对三问各有载体——找什么=`PREMISE-001` 分母（35 条前提，A–G）；怎么找=冻结族→枚举→归约→原生核；凭什么=remainder=0 + 四路核收据 + exit 42 负控制。
- 论证：本单元没有把三问中的任何一问替换成更容易的那一问。特别是「凭什么」被收据化而不是被声望化——这是本链路最不可替代的一条。不足：三问的「找什么」目前答的是「找非现实性候选的**可枚举分母**」，尚未答「找**候选本身**」。
- 指令：下一单元必须保持「凭什么 = 收据」不变；可以改的是「找什么」的候选供给方式（见分片 008）。
  反证：若某单元以「AI 判断它像悖论」作为依据交付，本条降为 DEVIATED。

### KC-000002 · Theory Schema 先行

- relation: **ALIGNED**
- 姿态：先冻结语义（Schema/文法），再在有界分母上枚举。
- 已做：`v2-dm3-a-v1` 文法在枚举前冻结；56,160 checks 的分母（40 contexts × 1,404 等价对）在跑之前就是确定的。
- 论证：remainder=0 之所以是证据而非口号，唯一理由是分母在枚举前已被冻结且可复算。若先有结果再圈分母，同一句话会从证据退化成辩解。
- 指令：区间 I 设计探针必须先冻结「I 上能写的形态」这一 Schema 问题，再谈枚举。
  反证：若下单元的分母是事后按结果圈定的，本条降为 DEVIATED。

### KC-000003 / KC-000019 · 合取命题与稠密性

- relation: **NOT_TOUCHED**
- 姿态：现实中一件事成立是许多条件的合取；理论换掉其中一个条件，过程未必还是同一个过程。
- 为什么未触及：DM3 单元的机制是**非布尔性**（a∧¬a=a≠0），不是稠密性；稠密轴在本链路由 `TASK-FAMILY-DIVISIBILITY` 承担，本单元未跑该族。
- 下一单元要做什么才会触及：V2 第二族的 G-a 稠密族（需要先供给序结构），或直接对 `PREMISE` 的稠密性条目做一次现实对齐解读。
- 反证：若 DM3 的 availability/level 分离其实蕴含了稠密性结论，本条改判 DEEPENED（目前未证）。

### KC-000004 / KC-000020 · 悖论作为反证、运动量子化

- relation: **NOT_TOUCHED**
- 姿态：先构造一个真正值得解释的困难，再问它指向哪个前提；最终归因是「下一个故事」。
- 为什么未触及：本单元是工程验收，没有构造任何悖论过程。运动/量子化对照不在 DM3 机制内。
- 下一单元：这条与 KC-000005 是**发现侧的判据**；任何声称「找到悖论」的单元必须回到这条。
- 反证：无（未触及即未触及）。

### KC-000005 · 先找悖论后作最终归因

- relation: **ALIGNED**（本链路执行得最一致的一条）
- 姿态：不要在看到现象之前就规定病因；候选可以先走，归因后走。
- 已做：本单元判词 `DM3_DE_MORGAN_CONFIRMED_NON_BOOLEAN_LIFT` 的**作用域被严格限定**为 DM3，并显式声明区间 I 分支开放、density 部分仍是模型层。这正是「不提前归因」的记账形式。
- 论证：整条链路从未把某个分母内的负结论升级为「HoTT 的某个前提是非现实的」。9 条 P3/P4 判定全部标 `AI_ADJUDICATED_PENDING_EXTERNAL_AUDIT`。
- 指令：保持。反证：若任何收据被叙述成「已证明某前提非现实」，本条降为 DEVIATED。

### KC-000006 · 时间机制不能收窄为稠密性

- relation: **ALIGNED**
- 姿态：保持多个敏感面——可用性、落定、构造过程、层级、稠密性、自指——不让一个吞掉另一个。
- 已做：五个冻结族（completion-process / wellfounded-branching / identity-observation-layer / divisibility / existence-vs-availability）+ DM3 三轴（availability/level/density）正是五个不能互相吞并的敏感面。
- 论证：判词分级（修订片 019）本身就是这条的执行——它拒绝把 availability/level/density 合并成一个族级标签。
- 指令：敏感面清单要随链路显式增长；分片 008 会指出**自指轴**与 **B 方向**是当前最薄的两个面。

### KC-000007 · LLM 内在知识与模式匹配

- relation: **TENSION**（既有张力，本单元未消解）
- 姿态：用户期待 LLM 用模式匹配把悖论「求解出来」；但 KC-000017 同时要求不被训练先验带着走。
- 已做的执行解：模式匹配**只在供给层**使用（AI 冻结任务族与文法），判断层一律由原生核承担。
- 论证（为什么仍是 TENSION 而非 ALIGNED）：执行解是**分工**，不是**和解**。五个冻结族全部落在 AI 熟悉的通道上（完成性、可用性、同一性、可分性、层级）——这正是 KC-000043 所警告的「最顺手的通道最先被想到」。模式匹配至今没有产出一个分母外的候选。
- 指令：分片 008 裁决的第三条路径单元就是为这条准备的——让模式匹配/知识谱反观去**供给新前提**（不是判定），并显式标注是哪条语义重定向在驱动。
  反证：若某单元的模式匹配产出了被原生核接受的分母外候选，本条升为 ALIGNED。

### KC-000008 / KC-000009 · 历史悖论启发与定位 HoTT 的时间维度

- relation: **ALIGNED**
- 姿态：迁移的是**构造关系**（逐项可行→整体完成、关系的逆→操作的逆、未来可得→现在可用、验证者进入被验证域），不是故事；迁移后必须重新核实规则。
- 已做：`supply`/`fill`/`tower`/`between` 这组 op 就是「未来可得→现在可用」的可枚举形态；`declared_faces` 真子集就是「理论预设了可填充性」的可登记形态。
- 论证：链路确实在 HoTT 的**规则位置**上落了脚（不是空泛怀疑），这一点兑现了 KC-000009。但「定位」≠「发现」——脚落下了，过程还没造出来。
- 指令：下一选择不得以「已经定位」替代「尚未发现」。
  反证：若下单元用定位陈述充当发现陈述，本条降为 DEVIATED。

### KC-000010 · 目标是现实相对非现实性而非内部矛盾

- relation: **DEEPENED**（本单元最实质的认知推进）
- 姿态：不找内部矛盾，找「Think in HoTT 后推出现实中不存在的困难」，且困难以不可完成/不可停机为特征。
- 已做：DM3 上 **a ∧ ¬a = a ≠ 0，没有内部矛盾**，而三个结构性分离照样被原生核确认（BLI 单元 KERNEL_BLI_PASS）。
- 论证：这是本条核心认知第一次获得**可核验的构造形态**。它证明「非现实性」与「矛盾」在数学上确实可以分开——不是宣言，是一个带 falsifier 的机械事实。判词名里的 `interval_i_confirmed=false` 同时拒绝把模型层结果冒充现实层结论。
- 指令：未来任何候选都应先问「它有没有内部矛盾」——若有，它更可能只是类型错误或已知边界（KC-000027 的警告），不是本研究的靶标。
  反证：若 DM3 分离被证明其实依赖某个隐含矛盾，本条降为 CORRECTED。

### KC-000011 · 理论推演排除时序、程序显式时序

- relation: **DEEPENED**
- 姿态：看理论**什么时候不想让时序参与**，而不是看它的对象里有没有时间变量。
- 已做：availability 轴（`supply` op：对象存在 ≠ 此刻可用）就是把「时序可用性」做成文法坐标；越界检查要求新族被既有无时序文法拒绝，正是检验「时序被排除后旧文法接不住」。
- 论证：用户区分的两组判据（对象含时间 vs 过程承担时序）在本单元都被落成可枚举量。
- 指令：保持。反证：若 availability 被证明可在纯无时序文法内表达，本条降为 CORRECTED。

### KC-000012 / KC-000013 · ASK 计算合法性预分析

- relation: **ALIGNED**（机制层）／**TENSION**（发现层）
- 姿态：先问 Q 是否合法、可停机；理论为了工具性往往想绕过 ASK。
- 已做（机制层）：ASK 被实现为**入口检查**——越界检查 + 负控制（exit 42：一个把 `refl` 放在 `false ≡ true` 上的错误命题必须被核拒绝）。核不会接受一个未取得资格的命题。
- 未做（发现层）：ASK 作为**启发式**还没有被反过来用——即「主动去问 HoTT 的某条规则：你绕过了什么 ASK」。这正是扩展认知 003 片教的姿态，链路未执行。
- 指令：分片 008 的第三路径单元要把 ASK 反向使用列为供给动作之一。
  反证：若 ASK 反向使用已被某单元执行，本条升为 ALIGNED。

### KC-000014 / KC-000022 / KC-000024 · 两种方向（A/B）

- relation: **TENSION**（方向不平衡）
- 姿态：A = 现实能完成、理论里无法完成；B = 现实无法完成、理论却绕过 ASK 假装已完成。二者不可互替。
- 已做：五个冻结族里，completion-process、existence-vs-availability、divisibility 属 A 侧；identity-observation-layer 触及 B 侧。本单元的 DM3 分离两侧都不是。
- 论证（为何 TENSION）：**B 侧被系统性薄待**。而 KC-000024 的长段综合把「多数理论从一开始就打算无视时序」指认为悖论的温床——B 侧恰恰是「无视」变成「假装已有」的那一侧。罗素、说谎者、Better-Best 都是 B 侧。链路的五个族偏 A 侧，是熟悉通道（KC-000043）的又一次胜出。
- 指令：分片 008 必须把「一个 B 侧新族」写进候选；不得让 A 侧的干净穷举继续冒充「两类都在找」。
  反证：若 identity-observation-layer 族实际已覆盖 B 侧的完整判据，本条改判 ALIGNED（目前只覆盖「观察层身份」，未覆盖「绕过 ASK 假装已完成」）。

### KC-000015 · 抽象即否定现实前提，需定义「否定」

- relation: **DEEPENED**
- 姿态：抽象必然否定某个现实前提；研究要找到「否定」的具体形态，而不是停留在口号。
- 已做：「否定」在本链路被对象化为至少三种可登记形态：`declared_faces` 真子集（可填充性被预设）、`supply` 的延迟（可用性被预设为存在性）、层级塔的截断（高层被当作已取得）。本单元新增第四种：**布尔性的强加**（BLI：x∧¬x=0 这条经典经济性假设对三个结构分离非必需——理论保留了一个本可丢弃的假设）。
- 论证：这四种形态互不相同，且都可机械核查。「否定」在这条链路里不再只是一个词。
- 指令：保持登记习惯。反证：若任一形态被证明不可机械核查，本条收窄。

### KC-000016 · Russell 构造过程与计算合法性

- relation: **NOT_TOUCHED**
- 姿态：「集合 S」是否已取得资格，先于它是否满足性质；非法程序不是理论的失败，但理论把未构造对象当成已有就是失败。
- 为什么未触及：本单元未处理任何自指构造。
- 下一单元要做什么才会触及：R2/自反线（S-143/144）与 KC-000028 的自反真实验证是这条的载体；或分片 008 裁决的 B 侧新族。
- 反证：无。

### KC-000017 · 训练先验批判与 Thinking in my math philosophy

- relation: **ALIGNED**（本单元执行得最强的一条）
- 姿态：不顺着世界上过往的分析判断思考；先理解提出者的悖论观，再观察已有悖论。
- 已做：DM3 的选取本身是**反先验**的——布尔代数是 AI 最熟悉、最流利的结构，而本单元恰恰离开它，去三元链上做确认，并把「布尔律非必需」登记为可被 `BLIFalsify` 推翻的机械事实，而不是 AI 的直觉主张。
- 论证：这条与 KC-000007 构成张力的一对，本单元在**判断层**完全站在 KC-000017 一侧（原生核、falsifier、作用域限定），没有让流利冒充正确。
- 指令：保持。反证：若下单元的判断重新回到「看起来像悖论所以是悖论」，本条降为 DEVIATED。

### KC-000018 · Z 铁律、工具性与认知惯性

- relation: **ALIGNED**
- 姿态：否定是为了工具性（好用）而做的，不是为制造悖论；因此问题藏在理论的优点里。
- 已做：文法设计原则就是「理论为了省事预设了什么」——`declared_faces` 是经济性预设的直接对象化。
- 论证：链路始终在检查「优点里的代价」，没有去寻找粗心错误。
- 指令：保持。反证：无。

### KC-000021 · 机器证明与真实运行要求

- relation: **ALIGNED**
- 姿态：不仅语言公式论述，要有代码实际证明、真在沙盒运行过。
- 已做：56,160 checks 机械可复算；4 见证 × 4 路核（含必须被拒的 exit 42 与精确 replay）；4,096 函数穷举；BLI 单元带显式 falsifier。零纸面断言。
- 论证：本条是本链路的准入门槛，本单元无任何例外。
- 指令：保持；BLI 的 falsifier 机制应作为标准配置保留。
  反证：若任一收据被证明未实际运行，本条降为 DEVIATED（严重）。

### KC-000023 · 时间时序处理应可直接定位，「不应这么难」

- relation: **TENSION**（本审计最尖锐的一条，见分片 008）
- 姿态：既然历史参照能让我们指出理论怎样安排时间，在 HoTT 中也应当能指到具体规则位置；不应该这么难。
- 已做：链路确实指到了规则位置（见 KC-000008/0009），但**代价巨大**——56,160 次检查换来的仍是分母内的负结论，而不是用户预期的那种「一眼可见」。
- 论证（为何 TENSION 而非 ALIGNED）：用户的预期（KC-000037–000040）是「基础问题在基础之处，反观知识谱即可见」。链路的实际路径是机器统观。这两者之间的落差**没有被任何单元处理**。本单元也不能声称处理了它——DM3 闭合是工程层的，不是「一眼可见」的回归。
- 指令：这是分片 008 裁决的直接动因。本条不得被「工程做得很扎实」安抚掉。
  反证：若某单元以低成本反观方式命中了候选，本条升为 ALIGNED；若连续三个单元仍无回归，本条升级为本链路的**结构性张力**登记入 STATE。
