## 模式匹配：两句人话与一张对照表

把两边各压成一句人话：

- **芝诺**：从这里走到那里，本来走过去就到了。数轴理论为了好用，让距离可以无限细分。于是“走到”永远了结不了：先走一半，还剩一半；再走一半，还剩一半。每一步都确定地还没到，这段路永远走不完。
- **HoTT**：两个东西是不是同一个，本来是一句话的事：是就是，不是就不是，没有“以哪种方式是”这一说。HoTT 为了省事，规定同构的就是同一个（单价性）；又为了普适，让任意高维的形状在宇宙里一次齐备（高阶归纳类型）。于是在它的宇宙里，“是同一个”永远了结不了：以哪些方式是？这些方式之间又以哪些方式是同一个？每一层都确定地还有下一层，这个确认永远完成不了。

这里说的“了结不了”，精确含义是：“是同一个”永远落不成一句话的事。HoTT 当然能证明两个东西是同一个（给出一条路径）；做不完的，是确认这份相同到哪一层才算了结。

| | 芝诺 | HoTT 的追问 |
|---|---|---|
| 本来很简单的事 | 从这里走到那里 | 确认两个东西是不是同一个 |
| 理论为了好用改掉的条件 | 位置可以无限细分 | 相同可以无限细分 |
| 专门碰它的过程 | 每次走剩下的一半 | 每次问上一层“以什么方式相同” |
| 每一步看到什么 | 还剩一半，确定地没到 | 这一层还没了结，确定的“否” |
| 结局 | 永远走不完 | 追问程序等于 `never`，对任意判定器都如此 |
| 推理本身 | 没有问题 | 没有问题，而且经过内核检查 |
| 离散或有界的对照 | 量子化的空间，有限步走完 | 相同是事实，第 1 问停；成员高度封顶，在封顶处停 |
| 教科书消解 | 极限：1/2 + 1/4 + … = 1 | 截断：对集合截断发问，第 1 问就停 |
| 消解建在什么上 | 稠密性本身（KC-000003） | 截断本身是高阶归纳类型，用一个构造子把“相同是事实”重新宣布回来 |

HoTT 一栏的机器证据在 Claude 线的目标本地索引（`.claude/goals/CG-001-targeted-overview/证据索引.md` §19–§22）：宇宙与例 8.8.6 的乘积上追问等于 `never`（C-75、C-78、C-81）；相同是事实的世界第 1 问停（C-80，Lean 按同一组方程的转写）；成员高度有界时在界上停（C-79、C-82）；对集合截断发问第 1 问停，而截断把宇宙里 Bool 与自己相同的两种方式合成一种，且解码不回去（C-83）。这些运行只在一个平台上重放，共享的证据矩阵与 STATE 尚未登记。第 010 片说“追问永不停机”没有单独机器化，那是 2026-09-26 写入时的状态；2026-09-30 起它已在上述目标本地索引里写成内部定理，共享 owner 的更新另待授权。

对照表里有三处对位，最能说明这不是牵强附会。

- **“做不完”是同一种。** 第 003 片区分过几种“无法完成”：反复变化、一个指定程序不停止、每个有限阶段都还未精确到达、当前信息不足、缺少统一方法。芝诺属于“每个有限阶段都还未精确到达”，把减半写成程序，就是“一个指定程序不停止”。HoTT 的追问这两样都有：每个有限层都确定未了结，指定的程序不停止。它不是芝诺线（A7）那种“每层做得到、缺统一方法”。
- **两副面孔都在。** 芝诺有过程形式（永远走不完）与结果形式（没有哪一个有限步到达）；这里也有过程形式（程序等于 `never`）与结果形式（没有哪一层了结，问“有没有一层”第 0 步就答“否”）。后者不消解 UR，它是 UR 的定理形式。
- **教科书消解是同一个动作。** 极限用一条定义把“走到了”宣布回来，截断用一个构造子把“相同是事实”宣布回来；两者都不恢复被改掉的现实条件本身（离散的空间、事实式的相同），也都是理论内部的正当构造。按 KC-000014 与 KC-000016 的眼光，“凭定义宣布完成”正是 B 向所在。于是 A、B 两向在这条线上可以分工：书式 HoTT 里的现象是 A 向；修复里的宣布完成是 B 向。这是解释，不是定理。

这张表也回答了最强的反解释，即“换题”：有人会说，在 HoTT 里与事实世界那一问对应的，是对集合截断发问，第 1 问就停，所以 HoTT 并没有做不到那件简单的事，它只是默认问了一个更难的问题。回应是：截断回答的是“有几个分支”，被问的对象已经不是原来那份目录；而且这一步回不去。换题争议本身，也正是 UR 的一部分：简单的问题要先离开理论对“相同”的原生理解，才答得出来。这与当年“另记一本账算不算完成”是同一类问题，由用户裁定。

## 被改掉的条件：相同可以无限细分

芝诺的被告，是“位置可以无限细分”（用户的归因，KC-000003、KC-000004）；这里对位的是“相同可以无限细分”。它由两件事合成：

- 单价性把“是不是同一个”换成“以哪些方式是同一个”，相同从此有了层；收益是经济，同构的东西直接当作相同（KC-000029、KC-000047 所说的经济性）；
- 高阶归纳类型让宇宙里有任意高维的形状，使每一层都不平凡；收益是普适，一切形状一次齐备（KC-000047 所说的为普适而理想化）。

KC-000032 说，理论否定现实因素之后，相当于引入了新的内容，并招来悖论对这种存在性的攻击；这里被引入的新内容，就是无穷多层不平凡的相同。

对照已经把两件事的作用分开：相同是事实，第 1 问就停；保留单价性、给成员高度封顶，就在封顶处停。AI 的判断（条件于用户对任务忠实性的回答）是：首先该审单价性。理由是，同样高维的空间在经典数学里也有（∏ₙ K(ℤ,n+1) 的同伦群在每一维都是 ℤ，这是标准代数拓扑的来源级事实，本仓库未机器证明），变的是“相同”指什么；高阶归纳类型是这批对象上永不停的必要一环，它相对用户的物理现实（有限、离散）算不算非现实，是另一个问题。反证法只否定合取的整体，所以这是排序，不是唯一的被告（KC-000019、KC-000049）。

这个前提的名字只借芝诺的结构（每一步都留下下一步），不把 HoTT 的问题收窄成稠密性（KC-000006）。

## “找到了”说到哪一层

用户问：“我想，我们已经找到了，对吗？”AI 的回答是：对，按 UR 的定义找到了，一个第一类（A 向）的非现实性悖论，形状与芝诺逐行对得上。身份要分开说：

- 推理部分是机器证明，范围见上面的证据索引；
- “不合理”的判定按 UR 的定义属于一眼看过去的人，这里是用户，用户说“我已经闻到了这种`不合理`的味道”；
- 逐行对应与归因排序是 AI 的判断。

它不是 HoTT 的内部矛盾，也不是说 HoTT 的规则在数学上错了。它是 HoTT 为好用改掉的条件，在一件本来简单的事上露了形（KC-000010）。

要让外人也一眼看出来，还差几件写法上的事，不是有没有的问题：

- 芝诺的“简单的事”不用解释；这里要一句铺垫：“是同一个，本来是一句话的事。”
- 芝诺对每一段路都成立；这里是“在某种情况下”：宇宙，以及这类乘积。宇宙不是边缘情形：它是单价性所说的那个对象，也是 HoTT 不能拒绝的论域元素（KC-000050）。
- 宇宙与这类乘积没有有限层，这件数学事实专家早就知道（HoTT Book 例 8.8.6；Kraus–Sattler 2015）。几何级数人人会算；新的是把它读成 UR，并指出它指向哪一个前提。KC-000015 说，要找的正是这种现象在 HoTT 中也存在。这一读法没有做过文献查重。
- 教科书消解（截断）要在正文里先答掉，答法见上一节。
