# 逐项回应GLM与整体论证的缺口

## 1. A01：共同 X、任务对应与 M3 的实际结论

我理解用户的“现实同一性”是：不同理论表述、抽象或判据面对的仍是同一个 X，以及相关的来源和变换过程。X 不限于实验室可测物理对象，也可以是有明确解释的数学现实或假想现实。这个研究起点不需要先取得 HoTT 的批准。

但把共同 X 选为起点，与证明两个特定形式任务恰好对应这个 X 的同一完成要求，是两项工作。仅因 `Spec_A` 和 `Spec_B` 类型不同就宣布整个研究方向失败，是不充分的；仅因它们都谈到 √2 就宣布任务已相同，同样不充分。

当前 M3 的两个实际目标为：

```text
Spec_A：返回一个判定 q² < 2 的布尔函数，附逐点正确性。
Spec_B：返回一个 q : ℚ，附 q² = 2 的证明。
```

M3-UNC 的证明体从 `Spec_A` 的居住性经假定等价得到 `Spec_B`，再调用 M2 的 `spec-B-empty`。**这个精确形式分离的地位保留**；同任务桥不是维持这条局部证明的前提。

整体归因是另一回事。Book 的“实数可用切割表示”没有要求返回有理数精确根，也没有给出上面两个规格的等价。`Spec_A` 的平方谓词还不是 GOLD 的完整下切割谓词：后者包含独立的负数分支。代码命名为“读出/算出”，不能省去输入、输出、观察量和完成条件的比较。

GLM 第 003 片 §3 改答“拒绝的是从 A 居住性到 B 居住性的任何无付费桥”。现有签名确实不支持从 A 交付 B 的所述用途，但**没有一个收费参数，也没有一个已验证的支付后恢复分支**。这不提供“HoTT 免费时失效、支付某原则后恢复同一任务”的费用定理。为什么本来应当存在这座桥，仍需解释与证据。

这里不要求把全部数学实践社会学编码进 Agda：真实文本承诺可由原文证据支持；共同 X 的选择可作为显式解释；形式化后的数学保持关系则需要相称证明。若只提出条件论证，可写“在解释合同 I 下”；若要声称整个 HoTT 被击落，就不能隐藏 I 尚未获得论证或并非其必然承诺。

这些行有些带论证层或 QUESTION 限定，须保留这一正面事实；但“已分层”不等于“层内每个推论已经正确”。正确说法是：**登记中存在精确局部类型和保守标签，也混有待证的解释、错误归因或未支持的元论证。** 因此我不接受 GLM 第 003 片“不得不引用会话而非矩阵”的描述。

用户最初明确要求审计“已经完美闭环、足以引发第四次数学危机”的判断。按这一父目标验收不是擅自提高标准。如果 GLM 当前改成只交付有开放项的研究材料，这是可以采纳的降格，而不是证明原强判断本来已经达标。

第 002 片已给出新定义与重放。A02 从当前代码阻断转为**已修复、有剩余文档同步义务**。GLM 所谓“修一个字符层级的问题不触及证明本体”，可以描述其修改成本和充分性构造可复用；不能据此否认命题截断影响规格含义，也不能用新 run 追认旧 run 忠实于原典。

## 4. A03：必要性开放是双方共识，但仍有两项实质缺口

第一，我认可原 `NecessityLEM` 的精确目标：`LEMProp ℓ → SingleOmega ℓ`，因而可得到条件版 `Necessity`，证明体不使用 `ℝLayerAt`。这项设计不属于隐藏错误；本次新收据已经独立复验。

第二，这不解决 `Necessity ℓ = ℝLayerAt ℓ → SingleOmega ℓ` 的无条件真值。GLM 也承认 CONJECTURE。因此“免费路线已经被机器排除”必须撤回，而非仅为“收费”换一个更宽的名词。

第三，源码与 package 仍混合了三个不同问题：

- `PropResizing` 搬运单个高层命题，而 `SingleOmega` 要求整个 `hProp ℓ` 有指定层的小型表示；源码 L81 写“等价于”，L141 写“不蕴含”，L146 又写“关系未论证”。本轮未补任何相关方向的证明。
- `ℝLayerAt` 要求整个指定实数类型有低层表示，不能直接读成“实数存在”或“这个 √2 已能实际计算”。原典第一条路线就是保留层级追踪。
- package §3 用 σ-frame 路线宣布某个反向蕴含“已被证伪”，§4 又称该路线是不同实数类型。没有精确前件成立、后件失败的模型，就不能将替代路线当作当前形式命题的反例。

这些也是原说明 owner 内的数学解释问题，不是只有会话语气问题。本轮保持相关方向 OPEN，没有另行证明 SingleOmega 与 resizing 的正确关系。
