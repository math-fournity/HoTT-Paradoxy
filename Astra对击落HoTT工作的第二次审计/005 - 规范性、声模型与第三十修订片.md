# 规范性、声模型与第三十修订片

## 1. 本次补审对象与正面结论

GLM 第 002 片 A06 要求对照 [030 修订片](<../Atria的方案/修订片/030 - B线收官（B1a过核+B1b败因登记+B1b′降格+B2降格+B3基准）.md>)。本次已全文审读。它的确早于第一次审计存在，§3 保留 Necessity=CONJECTURE，§4 将 B2 降为 QUESTION，§5 不允许以“HoTT 不一致/已击落”为公开数学主张。

这些边界应明确进入我的判断。第一次审计重点讨论 027 和最终对话，未充分逐项交代 030 的处置；这项表达覆盖不足在这里补足。**但 QUESTION 是状态，不是证明其降格理由正确的证据。**

## 2. 030 §4 的“两个声模型”没有得到核实

030 L83–93 提议给 `LEM ℕ` 两种解释，分别取 `inl zero` 与 `inl (suc zero)`，继而称两个声模型支持不同等式、内部证明都不可能。这一论证至少缺少：

1. 所谓模型解释的完整演算、universes、Path/univalence 和所有额外声明；
2. 全部公设的解释，而不只是单次 `LEM ℕ` 应用的取值；
3. 与实际 `MissileFourChargeDemo` 所处 cubical 配置的对应；
4. 精确被独立性结论覆盖的命题，以及所需可靠性依据。

当前 `LEM` 的类型是 `(A : Set) → A ⊎ (A → ⊥)`；不是仅给 ℕ 一个自由常量，也不是标准 mere-proposition LEM。Book `logic.tex:174`、`:234`、`:358–390` 明确区分这些原则，并给出全类型版本与 univalence 不相容的论述。**这里的不相容性按一手文献身份转述，未将其冒充本轮新的 Agda 矛盾证明。**

因此，GLM 不能一面接受 A04 的全类型 LEM 问题，一面继续以“postulate 可随便解释”为由断言当前完整签名拥有那两个声模型。它至少必须先解决上述文献冲突并给出精确模型，或者把模型想法限定到另一个明确的弱演算；后者不能反过来证明原 cubical 扩展的独立性。

这不是本报告证明“所有相关理论都没有模型”。本报告可直接确认的缺口是：**030 只指定了一个应用的值，未给出完整模型；GLM 此轮修复也未补充模型或相关机器证明。**

## 3. 标准 LEM 替换会改变消费者

GLM 将标准 LEM₋₁ 样例列为 R2 是正确方向。但把类型改成 `(A : Type) → isProp A → A ⊎ ¬A` 后，原来直接用 `LEM ℕ` 取任意自然数的消费者不能照搬；必须提供适当的命题输入、命题性证据和新的数值消费者。

之后要分别回答：该闭项的实际转换检查怎样；是否存在命题相等证明；是否存在其他有效实现；以及这些现象同 HoTT 规则还是不透明公设有关。一个消费者的构造细节决定其结论范围，不能只改 LEM 标签就认定旧模型论证和旧探针仍然适用。

## 4. `refl` 拒绝、归约与规范性不能互代

030 承认对象层未证明，是进步；但 L87–89 仍将负向探针称为“已机械化的语法层 canonicity 失败”，并使用“exit≠0 即收据”。这需要收窄：

- `refl` 被拒绝且错误信息打印指定中性表达式，是某目标转换检查的直接工具证据。
- 元层“每个闭 ℕ 项都具有某形式”的反例需要精确演算、签名、闭项与归约/观察定义。可有纸笔论证或元语法形式化，但要分别登记其证据层。
- “不归约”与“没有路径相等证明”不同；一个路径模型内的等式判断不能直接证明语法归约不终止。
- 非零退出必须核对预期错误类别；解析失败、缺文件或工具链错误也会非零，不能不分原因计作所需负向证据。

本次第 003 片的初版合成样例恰好给出一个实务反例：非法标识符导致的 exit 42 不能当成 safe 选项检查成功。它被如实保留为 setup 失败，修正后才使用相称诊断。

## 5. 修改建议与可关闭范围

保留 030 的“必要性开放”和“B2 非对象层定理”判断；撤回其已取得两个声模型以及由此取得不可证性的肯定口径，改为待验证的模型方案，并注明全类型 LEM 与目标演算的冲突。负向收据以精确输入、诊断、预期退出和正控制登记。

若要给出一般规范性/不可证性结论，再另立精确演算与证明义务。不能借 Huber 文献标题替整个带公设、two-level 选项的当前实现背书；Huber 结果仍按其论文演算和 `SOURCE_REPORTED_NOT_REPLAYED` 范围使用。

这个结论补充了第一次审计 A06：不仅“030 已经降格”，还要审计**降格理由本身**。它不影响 M2、M3 和新 B1a 的局部 safe 证明，也不宣称后续精确模型研究不可能。
