**关于可缩类型。** 在补丁理论的最终设计里，可缩不是个别例子，而是架构：上下文空间可缩（A.5），单点模型的每个纤维可缩（§6.2），于是整体状态空间可缩（C-32）。

**关于操作语义。** 2014 年作者没有；今天的 Cubical Agda 有。C-33 在内核里跑了这几件事：

### 3.4 O-010：C-24 的目标循环

**撤回与修正。** 沿有向旅程 0 → 1 → 2 的读数 a、b、a（a ≠ b），把两支箭头送到读数目标中的 a → b 与 b → a。需要什么取决于目标：

| 读数目标 | 箭头 | 能否先升后降 | 依据 |
|---|---|---|---|
| 离散（箭头都塌缩为相等） | 只有恒等 | 不能 | 【证明】C-34 |
| 反对称（偏序） | 有 a → b 就没有 b → a（a ≠ b 时） | 不能，只能单调 | 【证明】C-34 |
| 互逆对迫使两端相等（Rezk 条件“同构即相等”的推论） | 可以有 a → b、b → a | 能，但回路必须不可逆 | 【证明】C-35；存在性见 C-37（行走的收缩，一个范畴） |
| 互逆对不塌缩（如余离散） | 两个不同对象之间可有互逆对 | 能，可逆回路即可 | 【证明】C-36（你在 003 §5 的指正） |

所以我原来那句话，恰好只在 Rezk 型目标上成立；Rezk 型是 RS17 用来当作 (∞,1)-范畴的那一类，但作为一般说法它是错的。

**核对有向类型论中的实际类型（你要求的来源核对）：**
- 在 GWB 的 triangulated type theory（TT_□）中，**Nat 与 Bool 是离散的**（推论 3.20：它们是 𝕀-零化的，即群胚），依据是公理 6（𝕀 检测离散性）与 `Nat ≃ ⟨♭ | Nat⟩`。【来源】
- 有向区间 𝕀 本身：全局点只有 0、1 且 0 ≠ 1（公理 7）；𝕀 → 𝕀 的映射由端点对 a ≤ b 决定（引理 3.7，Phoa 原理），所以 𝕀 值读数沿箭头只能单调。【来源】
- 离散类型的宇宙 S 满足有向单价（hom_S(A, B) ≃ (A → B)），并满足 Rezk 条件（GWB §6，我只读到摘要与 §2–§3 的陈述，§6 的证明未读）；其中 Bool → Unit → Bool 就是一个不可逆回路。【来源 + 解释】
- GWB 称 Δⁿ 是该系统中第一个显式构造出来的非离散范畴（推论 3.13 之后的说明），摘要说构造了单纯类型论里第一批有非平凡同态的类型。【来源】
- RS17 的 sHoTT 中 Nat 是否可证离散：**未核**。在其预期模型中，离散类型解释为常值单纯空间。
- 整数：GWB 推论 3.20 只提 Nat 与 Bool；ℤ 是否同样离散，**未核**（我预计同理，这是【猜想】）。

**一处反纠正。** 003 §5 说，只有当读数目标“特意选为离散类别或偏序 (ℕ, ≤)”时，才分别得到常值或单调。在 TT_□ 里恰好反过来：普通的 Nat、Bool **本来就是离散的**，不需要特意选；要特意构造的是非离散的读数类型。于是温度计若取普通数值，在有向出路下它沿每支箭头根本不动，不只是不能先升后降（C-38 的抽象冻结 + GWB 推论 3.20）；把 (ℕ, ≤) 当作有向读数类型，需要另建。这把 CN-019 原先的直觉在正确的条件下部分找了回来：有向出路本身不解冻数值读数；解冻要靠让读数类型自己带箭头。
