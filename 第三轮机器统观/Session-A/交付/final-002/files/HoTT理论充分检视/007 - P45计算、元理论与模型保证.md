# P45计算、元理论与模型保证

本wave检视HoTT的计算与语义保证究竟针对什么系统、什么输入和什么结论，尤其检查旧“可判定性／拒签”叙述及模型论证的适用范围。方法是Book A.3/A.4、固定版本元理论论文及既有证明索引对照。所有外部数学定理均按 `SOURCE_REPORTED_NOT_REPLAYED`；本波未重建模型、未重跑kernel、未证明全HoTT一致或不一致。

## 1. 本波合同

新分母是规则→操作语义／模型→元理论结论。P40–P44已核的对象与推导接口不能自动决定正规化、有效检查或模型兼容性。goal-3与KC47/48在本波开始整段重读；经济性问题落实到两种明确选择：把判断相等作为形式推导接口，以及用模型／相干性方法抽象掉反复的替换记账。

判词改变条件：若某论文只证明特定构造子／上下文，收窄继承范围；若旧开放问题已有后续结果，不能将旧状态当今天的全局否定；若模型／计算定理不含指定现实观察，就不据它排除现实相对挑战。正控制是精确系统标签与相应定理；最强反解释是“不同问题由不同判据负责，不等于没有表达对象”。

## 2. 不能合并的计算与逻辑任务

| 问题 | 输入与要回答的内容 | 本波证据边界 |
|---|---|---|
| 判断相等／conversion | 指定上下文中、指定演算的类型和项是否按其判断相等规则一致 | 需该演算的相等算法或元定理；不是所有现实属性相同 |
| 给定证明检查 | 一个已给证明项／推导是否满足精确命题 | 与自动发现该项不同；parser/elaborator、核与库公理仍要分开 |
| 正规化 | 良型项／类型与normal form的关系；强正规化还量化归约路径 | 不自动给实际时间上界；不同文献的归约式与reduction-free结果不能混称 |
| Canonicity | 特定基类型的闭项，或指定name context中的项，是否对应canonical constructor | 比一般开放项正规化窄；也不是任意公理扩展的保证 |

| 一致性／soundness | 对象演算与元理论中模型／解释的关系 | 必须带假设和演算范围，不是理论内部对自身无条件全真值认证 |
| 现实有效交付 | 固定Input/Operation/Observation/Done及资源、可用性 | 以上各项没有自动提供该桥；也不能仅因没有资源字段就指控瞬时物理能力 |

Book `formal.tex:968–1115`区分elaboration、公理常量和判断计算；`:1115–1195`的基础元理论明确针对先前MLTT呈现，随后另谈HoTT扩展。公理常量阻滞通常的constructor计算说明需要重新审查canonicity；它本身不证明任意项会无限归约，也不证明类型检查全失去可判定性。

## 3. Cubical计算结果：两份主要论文的精确范围

[Huber 2017 v2](https://arxiv.org/pdf/1607.04156v2) 的Corollary4.21针对仅含维度name变量的上下文，给Nat项的数码对应；§5讨论circle与propositional truncation扩展。其typed weak-head操作语义与替换相容性是论证内容，不能由结论标题替代。该文当时把更广正规化／检查可判定性列作后继，不表示后来没有进展。

[Sterling–Angiuli 2021 v2](https://arxiv.org/pdf/2101.11479v2) §I.D、Theorem42及Corollary46–47针对其cartesian系统的Π/Σ/path/glue/circle，建立reduction-free正规化及atomic context中的判断相等可判定性。§I.D明确没有在正文展开universes和De Morgan修改；不得把作者关于可推广性的说明直接充当所有Agda配置的完整证明。

这两项足以纠正“公理化Book计算疑问=所有Cubical无计算解释”的读法，但不是本项目独立重放、全部HIT/HIIT认证或实现正确性证明。2026《Normal forms in cubical type theory》本波只核标题／摘要，它自述是既有normal form规格的显式整理；没有把它当作新的更强正规化定理。

## 4. 模型、相干性与宇宙：保证的实际输入

本节各行均为来源报告；只核列出的定义／主定理与范围，不声称全文重证。对同一论文的摘要与正文属于同一来源，不能算两份独立证明。

| 来源 | 已核定理／构造及必要限定 | 对全局研究的影响 |
|---|---|---|
| [Kapulkin–Lumsdaine v5](https://arxiv.org/pdf/1211.2851v5) | §1.1/Definition1.2.10限定Π/Σ/Id/W/0/1/+与一个Tarski单价宇宙；3.4.2–3.4.3带两个不可达基数；1.2.9将语法initiality单列为该文的conjecture，主结果用contextual-category呈现 | 模型不是任意HIT/任意库的总认证；该版本的语法解释资格不能被省略，也不能据旧conjecture宣布今天无人解决 |
| [Lumsdaine–Warren v2](https://arxiv.org/pdf/1411.1736v2) | 主定理要求full comprehension category、finite products、特定display-map exponentials及weakly stable构造；local-universe类型带(VA,EA,Γ→VA)，以预合成处理替换 | 严格化有实际数据与前提；不是无条件把所有弱相干等式当判断相等，也不是删除物理时间的同义词 |
| [Lumsdaine–Shulman](https://arxiv.org/pdf/1705.07088) | Definition2.1的good/excellent条件含simplicial局部笛卡尔闭、right proper及相关生成性；12.13–12.15对cell monad with parameters，参数须随重索引相容；对应具体HIT仍需翻译 | 其方法未覆盖任意HIIT或构造子内fibrant操作，也不自动给参数化HIT的宇宙闭包；这限制该论文适用域，不等于相关对象矛盾 |
| [Shulman 2019 v2](https://arxiv.org/pdf/1904.07004v2) | 11.1–11.3给Grothendieck (∞,1)-topos的适当Quillen呈现，宇宙数依不可达基数；区分所列构造的存在与宇宙对参数HIT闭包，Appendix A采用non-cumulative Tarski处理 | 不是所有elementary高阶topos或所有扩展的同一证明；resizing原则的模型结果与语法resize规则不可混同 |

这些限制的作用是准确核对保证，不能把“一个充分构造用了大基数”升级为“任何HoTT模型必须用这些大基数”，也不能把某项语义缺口当作已经找到反模型。模型中的同伦等价、严格替换稳定、源内identity与实现conversion属于不同关系。

### 4.1 Initiality的后续校准

[de Boer 2020论文](https://su.diva-portal.org/smash/get/diva2:1431287/FULLTEXT01.pdf)给出指定MLTT语法的initiality证明与Agda形式化报告，列出0/1/N/+、Π/Σ/Id及可数Tarski宇宙，§4.3从总解释与唯一性建立结论；因此不能从2018论文的conjecture推出今日所有语法—模型连接仍未证明。本波没有运行该形式化，也没有证明其列表与上述含W/UA/HIT目标的完整保真扩展，范围差异继续明示。

后续反射／内部模型研究也不能仅以“已经能表示自己的语法”宣称全域自验证。既有C244–249是带显式参数的一般R3重放，矩阵保持 `HOTT_R4_OPEN`；本波不再证明同义Gödel/no-go，也不把它当指定HoTT演算的内部不一致证据。

## 5. 旧B-01/B-02的来源资格

旧PREMISE-001第002片B-01将判断相等可判定解释为“不含观察／用途的现实同一机械判据”，第005片又从命题同一的判定问题推出“整个系统没有对象承载观察条件”。这一推断没有得到所引规则支持：**一个判定任务没有通用算法，与一个性质／结构能否被表达，是不同问题**。P41/P44已经定位结构、谓词、目标类别与相关观察条件的源内载体；不能把它们从分母中删掉，再宣布不存在。

本波撤回B-01作为“可判定性本身造成全系统表达缺失”的来源归因，保留具体语法判据与实际语义合同错配的候选资格。若要重开，须给确切演算、任务以及推导怎样把conversion用于强观察，而不是再跑更大的Delay observer表。

旧B-02既在P2写β“瞬时”，又在P3P4以“符号替换确实瞬时”为理由判现实。两边都把没有运行成本的形式规则与实际执行时间混在一起。源文提供替换／计算等式，不提供物理零时间保证；不因这个纠正判β错误，也不改旧run的数值结果。B03/B04的呈现／相等层纠正继续沿P41。

对旧四弹“Agda拒签”的解释也因此更准确：一次拒绝可能是请求并非所选类型的项、缺少证明、规则不同或实现配置；它不自动等于Agda不忠于HoTT。只有固定规则与实际核行为冲突才触发P4。这是证据分类，不是本波已审所有失败日志。

## 6. 经济性、可疑任务与尚未闭合的义务

本波确实定位到有来源的理论经济：严格语法接口让已给证明可机械检查；局部宇宙和synthetic方法减少替换／相干性记账；normal form为判断相等提供精确比较。它们选择性地保留某些观察，没有自动承诺运行成本、物理阶段或所有语义真值。

值得进一步排序的任务包括：一个实际接口是否把某演算的检查成功当作另一个演算的有效证书；是否把有条件canonicity用于额外公理后的执行承诺；是否把元层模型存在用于对象层全域自验证。尚无新同任务见证；既有R1–R4／2LTT和实现审计必须先查重。当前不为这些问题建立新运行平台。

本波未做所有元理论证明的逐行形式化、未审全部编译器源码、未穷尽最新模型。明确不覆盖的系统不能被称作已认证；但这些开放边界不会阻止完成本轮按声明来源的性质区分。下一P46补具体Cubical规则与相关扩展的侧条件、兼容范围，再作整体排序；首轮总目标仍未完成。
