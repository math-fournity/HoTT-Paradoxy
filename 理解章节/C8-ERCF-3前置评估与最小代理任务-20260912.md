## 0. 摘要

1. ERCF-3 原文（C4 §12.1）：让任务族 `𝒥` 能编码并观察认证器 `Cert` 的行为，要求 `Cert` 总停机、健全、完备并**在内部证明这些性质**；预期对角构造迫使 `TOTALITY / SOUNDNESS / COMPLETENESS / INTERNAL_CERTIFIABILITY` 至少一项失败。
2. 本轮把该要求分解为 8 个前置条件（P1–P8）与 5 个最小代理任务（T1–T5），并执行 T1：在固定工具链（Agda 2.8.0-3d04bac + Cubical v0.9，`--safe --cubical --guardedness`，`--ignore-interfaces`）中机器核查抽象对角核——Lawvere 不动点、`Bool` 的固定点自由自映射、**不存在带 section 的精确自编码** `A → (A → Bool)`、以及正控制（常值谓词片段可精确表示）。
3. 关键评估发现：**若 ERCF-3 的"编码并观察自身"读作带 section 的精确编码，则该前提本身已被对角核反驳**——失败发生在 ENCODING_EXACTNESS 层，先于 Cert 的性质层，且该论证不使用 univalence、cubical Path、HIT 或 truncation，因此是通用边界而非 HoTT 特有悖论。
4. 因此 ERCF-3 的可满足读法必须显式弱化编码要求（有限片段 / 无 section / 分层元理论），而每一种弱化都会改变需要证明的命题；在没有 P8（真实 natural consumer）之前，继续投入 ERCF-3 本体的期望收益低于把同一证据纪律用于用户主方向的其它可判别动作。
5. 判定：`GATED`；T1 完成；下一工作包 = T2 编码路线实验（有界、仅可行性），备选 = A11.1 W51×RP-B01 命题化。
6. **S054 更新（T2 完成）**：路线 (a)（普通归纳编码）在**同一层、无 cubical 特征、无库导入**下给出了最小对象语法 + 无捕获替换 + 证明谓词接口（`ObjectSyntax.agda`；`--safe` 与 `--safe --without-K` 两种检查均 `EXIT=0`、零 warning）。因此 P2/P3 的**语法层**不需要新增层级；QIIT/2LTT 的压力属于 P6（同层内部化类型论自身），不在本层。下一工作包 = A11.1 W51×RP-B01 命题化；T3/T4 与 ERCF-3 本体保持 gated。

## 1. 评估对象：ERCF-3 的原文与词表

C4 §12.1 原文（摘要）：

```text
α : R → A                    -- 遗忘/同一化
𝒥 : Type                     -- 允许任务族
Eval : 𝒥 → R → Outcome
Cert : Code(𝒥) → Decision    -- 充分性/合法性认证器

ERCF-3：让 𝒥 能编码并观察 Cert 的行为，要求 Cert 总停机、健全、完备，
并内部证明这些性质；预期对角构造迫使 TOTALITY / SOUNDNESS /
COMPLETENESS / INTERNAL_CERTIFIABILITY 至少一项失败。
```

词表（本评估固定用法）：

| 记号 | 本文含义 |
|---|---|
| `Code` | 对象层"任务/公式/谓词"的编码类型 |
| `⟦_⟧` 或 `e` | 解码：把代码映回它表示的谓词/任务（`Code → (Code → Bool)` 是二值判定读法） |
| section | 解码的精确性：每个谓词 `f` 都有代码 `a` 使 `e a ≡ f`（满射的显式见证） |
| `Cert` | 全判定器：`Code → Decision`（本项目关注二值或含 UNKNOWN 的决策） |
| 内部可证 | 在目标理论 `T` 自身的证明谓词内证明（而非在更强元理论中证明） |

## 6. 关键分析：ERCF-3 的三种读法

### 6.1 读法 A（强）：`𝒥` 精确编码全部相关谓词并观察 `Cert`

义务：给出带 section 的编码 `e : Code → (Code → Decision)`。
T1c 表明：当 `Decision` 含固定点自由自映射（如 `Bool` 的 `not`）时，这样的编码**不存在**。因此读法 A 的"至少一项失败"在编码层就被触发（`ENCODING_EXACTNESS`），先于 `TOTALITY/SOUNDNESS/COMPLETENESS/INTERNAL_CERTIFIABILITY`。这是通用对角化，不是 HoTT 特有。

### 6.2 读法 B（弱）：编码只覆盖有限片段或不带 section

义务：证明该片段（i）包含对角函数/自指代码，或（ii）对代码封闭。若片段过小，对角论证不再适用，`Cert` 的 total/sound/complete 在该片段上可能成立；ERCF-3 的"必然失败"需要额外假设（这正是 P2/P3 的具体工作）。

### 6.3 读法 C（分层）：在更强元层研究 `T` 的内部认证要求

义务：选定 `L1` 路线（QIIT/2LTT/算术化）并承担内部化代价。结论形式通常是经典 Gödel–Tarski 边界 + "同层内部化需要表示变化"。C4 §13 已把"足够强 HoTT 拥有内部健全完备总真理判定器"判为 `NO_GO_UNDER_STANDARD_CONDITIONS`——本评估确认该判定是通用边界；HoTT 特有的部分只在"内部化的表示代价"（P6）。

### 6.4 三种读法的共同结论

没有任何一种读法会在当前证据下产生 `NATURAL_USAGE_MISMATCH` 或 `INTERNAL_INCONSISTENCY`：强读法在前提层被通用对角核反驳，弱读法不自动触发，分层读法是通用边界 + 表示代价。要升级为项目悖论候选，缺的正是 `P8`（一个真实系统宣称并要求这套包）。
