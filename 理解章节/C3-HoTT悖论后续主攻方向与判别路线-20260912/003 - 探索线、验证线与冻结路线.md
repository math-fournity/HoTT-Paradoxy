# 探索线、验证线与冻结路线

## 7. 探索线：在线因果与 guard 擦除

这两条线保留，但不与主线并行铺开。

### 7.1 完整流函数与在线策略

最小自然问题可以写成：

> 数学上给出 `F : Stream(A) → Stream(B)`，是否足以在输入逐步到达的现实中在线产生输出？

在线资格应由 prefix causality 明确表达，例如输出前 `n` 步只依赖输入有限前缀，而不是只凭函数类型。一个需要“明天输入”才能决定“今天输出”的完整流函数，可能是合法数学函数，却不是当前观察协议下的在线策略。

这条线的价值是把用户的时间怀疑从“运行多久”推进到“信息何时可用”。但必须先选真实 guarded/clocked/coinductive 接口；若该理论本来就通过 `later`、clock 或 causal morphism 强制因果性，结论应是防御成立。

### 7.2 guard 擦除

只有在固定以下四项后才重开：

1. source calculus 的 guard/clock 规则；
2. target HoTT 片段；
3. 明确的 forgetful translation；
4. 应被保持却被擦除的 observable。

研究问题不是“删掉时间会不会出错”这一口号，而是：翻译能否同时保持值、固定点方程和在线／完成性质。若不能，哪一项是不可兼得的？

### 7.3 同函数异时

“两个实现外延上算同一个函数但成本不同”本身并不构成悖论；函数外延性从未承诺复杂度相同。它应被并入 race/timeout/contextual-equivalence 研究：只有当一个实际 consumer 需要 deadline、竞争、取消或资源观察，却仍把函数 path 当作完整替换依据时，才有新的资格断层。

## 8. 独立验证线：R034 Cubical Agda

R034 的原生 Cubical Agda 核查值得做，但它是**验证线，不是发现主线**。

它能回答：

- path-indexed certificate 的具体陈述是否在真实 Cubical Path/Univalence/Truncation 下成立；
- 固定 Bool 对、实际 transport 和 `¬MereMove` 边界是否被纸笔说明准确表达；
- 普通 Lean `Eq` 对照与真正 univalent transport 的差异在哪里。

它不能单独回答：

- A/B 哪条现实相对悖论已经成立；
- 数学 R041 的 race 是否在某个 partiality QIIT 上下降；
- RP-B01 的自然交付接口是否存在。

因此，环境可得时做原生验证；环境不可得时保持 `NOT_RUN`，不让安装或工具链问题长期占据数学主线。

## 9. 明确冻结或禁止作为主攻的路线

### 9.1 冻结重复性有限样本

- 不再增加 `later^n(now a)` 的同类枚举；
- 不再用 timeout 耗尽推断真实发散；
- 不再用更多自环图冒充一般余归纳定理；
- 只有引入新操作、新等价或新真实接口时才重开。

### 9.2 永久撤销错误自指公式

- `Map(1,G) ≃ G` 不是 loop space，也不提供 Gödel 编码；
- “元证明属于被证明对象的点”没有一般依据；
- “相邻宇宙角色相似所以等价”不能触发 univalence；
- 没有 syntax、substitution、evaluation、provability 和对角闭合就不能声称 HoTT 自指悖论。

### 9.3 不把一般定理换标题

- 一般停机不可判定不自动成为 HoTT 独有悖论；
- 一般 quotient 不支持非同余操作不自动成为 HoTT 核心错误；
- 函数等价不保存复杂度是一般事实；
- 只有 HoTT 的具体规则、构造或自然解释进入关键桥梁，才称 HoTT 实例；只有确有新机制，才讨论原创性。

### 9.4 不从物理隐喻直接得数学结论

Planck 尺度、宇宙离散、旋转、圆环和 Matrix 直觉可以提供候选形状，但必须给出真实物理 observable、数学模型和桥梁。没有桥梁时不得把物理叙述当作 HoTT 反例。

### 9.5 不让治理替代构造

来源审计、逐 claim 裁决和 R041 执行谱系补齐很重要，但它们不是新的悖论。每个数学研究单元必须交付至少一种实质增量：

- 一个新合法构造；
- 一个新正例／反例；
- 一个真实接口的保持或不保持定理；
- 一个被直接证据关闭的关键未知。
