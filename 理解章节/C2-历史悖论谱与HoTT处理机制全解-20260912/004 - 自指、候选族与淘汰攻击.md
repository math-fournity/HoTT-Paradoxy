# 自指、候选族与淘汰攻击

## 5. 自指、Gödel 与“无限之镜”

这条线不是六律之一，却是用户对 HoTT 的原始押注。

用户追问 HoTT 能否把自己整个宇宙当对象、能否在同一层证明自己的完备可靠和一致，以及“最终观察者”是否总在体系外。历史 AI 曾把 `Map(1,G)` 错当 loop space，又从宇宙角色相似直接推出宇宙等价；这些公式已经被撤销。

HoTT 的真实处理是：

1. universe hierarchy 防止无条件同层自包含；
2. 对象理论可以编码自身的某些片段，但 raw syntax、substitution、judgmental equality、semantics 和 soundness 需要精确构造；
3. two-level type theory 用 strict outer layer 内部化 inner HoTT 的部分元理论；
4. 对足够强、有效且一致的固定系统，Gödel/Tarski/Lawvere 型限制继续约束全局 truth、consistency 和 reflection。

裁决：`INHERITED_LIMIT / REAL_SELF_METATHEORY_GAP`。

HoTT 没有“解决”自指到可以完全自证。它做的是分层、限定接口、把所需元理论放到更高层或更强系统。用户的直觉——理论不能无代价同时做对象、观察者和最终担保者——有真实技术对应；但“HoTT 完全不能谈自己”仍然过强。

## 6. 项目 HoTT 候选族：HoTT 分别怎样回应

### 6.1 同函数异时

两个程序 `fast`、`slow` 对每个输入返回同一值；函数外延性可给出函数 identity，但固定求值语义下成本不同。

HoTT 的回应是：函数 identity 只拥有输入—输出行为，不拥有代码、轨迹、墙钟和能耗。若要这些观察量，应使用 `Program`、`Sem`、`Cost/Trace` 或 cost-aware/quantitative/effectful type theory。

裁决：`REPRESENTATION_LIMIT / OPEN_REALITY_PROMOTION`。错误只发生在把裸函数 equality 提升为完整执行过程 identity 时；项目尚未给出自然应用中这项提升的最终实例。

### 6.2 Guard-Erasure

阶段过程 `x_(n+1)=F(x_n)` 若忘掉所有阶段，又要求单值 `x` 继续满足更新律，就得到 `x=F(x)`；对 Bool 取反没有固定点。

bare HoTT 可以把整个序列作为对象，并不强迫压成单值。Guarded/clocked theory 用 `later` 与 clock 保留“稍后可用”。只有一个真实 forgetful translation 同时擦掉 stage、又要求更新律下降时，才出现条件障碍。

裁决：`GENERAL_LEMMA_VERIFIED / HOTT_TRANSLATION_OPEN`。

### 6.3 原作—复制品与 provenance

当前快照相同，原作身份不同。单价性只识别声明在结构里的内容。若 `IsOriginal` 依赖历史，就把 provenance 放进 Σ-结构或记录类型。忘掉它以后不能从裸快照恢复。

裁决：`VERIFIED_INFORMATION_LOSS / NOT_HOTT_FAILURE`。

### 6.4 identity path 可逆与现实不可逆

每个 `p:x=y` 有逆 `p^-1:y=x`；现实中的破碎、死亡、资源消费不可逆。HoTT 的回应是：identity path 表达同一性，不是一般状态转移。现实过程应使用普通函数、`Step x y` 关系、范畴态射、directed type theory 或带资源/效应结构。

裁决：`INTERPRETATION_CONFLICT_IF_IDENTITY_AS_PROCESS`。

### 6.5 无规范“较早事件”

一个完全无标签的二元素类型有两个对称点，不能自然选出“较早的一个”；自同构会交换两点。加入顺序、标签或选定点后可以选择。

裁决：`CORRECT_REFUSAL / NO_CANONICAL_POINT`。这是 HoTT 防止凭空生成时间方向的正面结果。

### 6.6 截断存在、见证与交付

从“存在某个值”不能一般地直接取出该值并运行。命题截断限制消去；但可以得到命题目标，或在唯一性/额外选择原则下取得更多。

裁决：`QUALIFICATION_PRESERVED_BY_ELIMINATION_RULE`。历史“截断凭空造见证”的 AI 攻击是错的。

### 6.7 RP-B01：数学分类与有效实现

借助排中律可以在数学上定义停止分类 `χ(p,x):Bool`；这不自动给出可以执行的全域停止算法。

必须分三层：

1. 对固定实例，有有限证书时可以运行；
2. 在加入经典公理的数学理论里，可以证明一个总分类函数存在；
3. 不存在无神谕的统一有效算法实现一般停机分类。

公理常量有类型，不等于有计算规则。一个 proof assistant 接受定义，也不等于 `#eval` 能给所有输入结果。

裁决：`PAPER_AND_FINITE_MODEL_BOUNDARY / NATURAL_HOTT_USE_BRIDGE_OPEN`。这正是用户 B 方向与 W51“逻辑+几何+程序”认知的主交点。

### 6.8 R034：路径证书与 `MereMove`

问题是：已知 `||X=Y||` 且有 `x:X`，能否对所有 `X,Y` 自然地产出 `Y` 元素：

~~~
Π(X,Y:U). ||X=Y|| → X → Y
~~~

R034 纸笔论证用 Bool 取反自同构、Σ 回路与依赖自然性证明这个统一接口不可居留。固定 `Bool/Bool` 对上的恒等函数仍可构造；给实际路径时 transport 也可构造。

裁决：`PAPER_PROVED_WITH_FINITE_CONTROLS / NATIVE_NOT_RUN`。这不是 HoTT 失败，而是 HoTT 的相干性阻止“只知道有路径”被提升为任意统一搬运器。用户提供的 Web 展示文件与 workspace R034 正文 SHA 完全一致；原生 Cubical Agda 仍未运行。

### 6.9 R036/R038：抽象路径与当前态提升

逐边存在具体代表，不等于当前选定代表能沿整个无限路径相容地前进。有限终止链的状态商可能出现抽象无限路径。

HoTT 要求当前态 lift、ranking/Acc 或相容代表。命题截断可向命题性的 Acc 消去，说明截断并非一律毁掉终止证据；无限多个有限前缀又不自动拼成单一无限执行。

裁决：`FINITE_CHECKED_CONDITIONAL_BOUNDARY`。

### 6.10 R039/R041：silent steps、`bind` 与 `race`

R039 证明：发散不敏感弱互模拟可以保 may、不保 must；错误的无限单边余归纳关系甚至不传递；正确结果等价保留是否返回和返回值。

用户新提供的数学 R041 在结果等价 `≈` 下进一步给出：

- 实际 continuation 的顺序 `bind` 尊重 `≈`；
- `race` 不尊重 `≈`；
- `p0≈p2`，但 `C(p0)` 返回 7，`C(p2)` 进入 `ω`；
- 黑箱选择器不能同时满足值可靠、响应性和结果外延性；
- 支持 race 的相容关系必须保留更多完成时刻信息。

集合商的递归原则只允许尊重关系的函数下降。因此 `bind` 可在已证相容范围内下降；`race` 依赖被商掉的完成先后，不能自动下降。拒绝 `race` 是理论准确报告“你的抽象不够支持这个操作”。

裁决：`R041_PAPER_SOURCE_ACQUIRED / CODE_RUN_GIT_LINEAGE_OPEN`。文件名为 R401，但正文记录号是 R041。当前只有 150 行证明笔记；其声称的 25 测试、源码、`cf58f27` 和增量容器未在当前 repo 取得。

### 6.11 自指/反射/Löb 族

历史 R029–R032 得到的正确边界是：

- 固定有限片段、受限反射、proof-producing reflection 可以工作；
- 全域同域解释、无条件 `Prov(A)→A`、完整自身 soundness 会触发对角/Löb/Gödel 条件；
- 必须固定语法、编码、替换、评价和总性；
- 更高 universe 或 two-level outer theory 是显式富化。

裁决：`REAL_GENERAL_LIMIT / HOTT_SPECIFIC_CONSTRUCTION_OPEN`。用户押注有方向价值，但历史工作尚未给出新的 HoTT 特定构造定理。

## 7. 被淘汰攻击：HoTT 为什么没有被它们击中

| 旧攻击 | 为什么失败 | HoTT 的真实规则 |
|---|---|---|
| `Map(1,G)` 是 loop space | `Map(1,G)≈G`；loop space 是 `g=_G g` | 类型必须先正确 |
| 相邻 universe 角色相似故等价 | 角色相似不是 equivalence 数据 | 单价性只把真实等价变成路径 |
| `Id_A(a,b)` 可跨 `a:A,b:B` | 端点必须在同一类型，或先 transport | identity formation 有明确侧条件 |
| 所有 transport 只能发生一次 | 误读线性资源；不同资源可各用一次 | bare HoTT 还是 Cartesian，可复制变量 |
| type checking 慢/搜索难说明本体失败 | 检查给定项与无界搜索不是同一任务 | checking、search、execution 分层 |
| 未定义 `Translate` 可直接接停机归约 | 输入语言、正确性和编码都没给 | 归约必须有完整函数与保持证明 |
| axiomatic `transport(ua(e),x)` 不归约就是永远卡死 | 书式呈现缺计算规则不等于所有 cubical 呈现都不计算 | Cubical TT 给 univalence 计算解释 |
| `||A||` 可提取任意 `A` | 违反截断消去限制 | 目标为命题或有额外条件时才可消去 |
| 有限 fuel 用尽证明程序发散 | 预算耗尽只证明这次未完成 | 发散需循环证书、归纳反证或一般定理 |
| 文件/测试很多证明 HoTT 被推翻 | 工程存在与数学结论不同 | 主张、形式证明、运行、现实桥梁分层 |

这些负结果告诉我们 HoTT 已有的防线在哪里，也防止未来 AI 为迎合目标复活已知错误。
