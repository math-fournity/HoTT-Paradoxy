# 六个参照悖论

## 4. 六个用户参照悖论：逐一讲清

## 4.1 芝诺悖论

### 悖论内容

每次走剩余路程的一半：

~~~
x_n = 1 - 2^(-n)
~~~

每个有限 `n` 都有 `x_n<1`，却有极限 `lim x_n=1`。

### 用户的本质判断

用户认为，理论把实际运动的逐步完成换成一个已经给定的无限序列整体，再用极限的静态性质说“到达 1”。这可能隐藏必须按次序完成每一步、无限可分/稠密空间的前提，以及现实运动可能离散或量子化。

所以在用户视角下，芝诺属于 A 类：现实运动能完成，稠密理论过程却制造“永远还有一半”的无法完成。

### HoTT/标准数学怎样处理

HoTT 可以构造实数、Cauchy/Dedekind 完备性、序列和极限。它会严格区分：

~~~
lim x_n = 1
与
∃n, x_n = 1
~~~

前者不推出后者。数学极限也不是“执行了最后一次无限步骤”的程序记录。

### 到底解决了什么

- `DISSOLVED_BY_DISTINCTION`：极限对象与有限索引命中被区分；
- `MODELED_WITH_EXPLICIT_STRUCTURE`：若任务是实际逐步执行，必须另给时间/过程语义；
- `INTERPRETATION_OPEN`：HoTT 不证明物理时空连续或离散，也不证明普朗克尺度是最小像素。

人话结论：

> HoTT 能让“极限等于 1”和“某一步已经走到 1”不再混淆；它不能只靠这一区分替物理世界回答运动究竟连续还是离散。

## 4.2 罗素悖论

### 悖论内容

令 `S` 为所有“不包含自身的集合”的集合。问 `S∈S`：若包含，按定义不该包含；若不包含，按定义又该包含。

### 用户的本质判断

用户提出“假集合”：描述一个集合的样子，不等于它能被构造。又把构造写成阶段：

~~~
r_(n+1) = not r_n
~~~

即不断把 `S` 拿入/拿出，永不落定。用户认为朴素集合论的问题是把尚未形成的 specification 先提升成已经存在的集合，绕过 ASK。

### HoTT 怎样处理

HoTT 没有无限制 comprehension，也没有同层“所有类型的类型”。要写对象，必须通过类型形成规则；宇宙分层为 `Ui:U(i+1)`，不允许 `U:U`。

此外，HoTT 区分一个类型合法形成与该类型是否有元素。一个自相冲突的性质可以对应空类型；理论不因空类型存在就矛盾，只有从空类型造出闭项才出问题。

### 到底解决了什么

- `BLOCKED_AT_FORMATION`：朴素的全域自成员构造没有对应的合法同层形成规则；
- `DISSOLVED_BY_DISTINCTION`：描述/形成/有元素被拆开；
- 用户的“formation gate”直觉与 HoTT 很接近；
- 但用户的 `r_(n+1)=not r_n` 是一种动态解释，不是 HoTT 处理 Russell 的唯一标准证明。

人话结论：

> HoTT 不先把那个危险的 S 当作现成对象再问它属于不属于自己。它先问：你凭哪条规则造出了 S？造不出来，就到此为止；造出一个空类型，也不等于造出了其中的东西。

## 4.3 说谎者悖论

### 悖论内容与用户判断

“这句话是假的。”用户把稳定真值计算写成 `p=not p`；若按时间修订，则成为：

~~~
p_(t+1) = not p_t
~~~

后者可以一直交替，但没有稳定完成值。问题在于句子要求在自己的真值落定前读取该真值。

### HoTT 怎样处理

HoTT 没有一个自动适用于所有内部句子的全域真理谓词，也没有无条件同层 quote/eval。普通递归与归纳构造受类型、宇宙和严格正性约束。

如果要表示交替流，可以显式定义状态序列，或在 guarded/clocked theory 中用 `later` 表示下一阶段；这时得到的是合法动态对象，不是稳定 Bool。

### 到底解决了什么

- `BLOCKED_AT_FORMATION`：没有合法全域自真理接口时，经典自指句不能直接进入；
- `MODELED_WITH_EXPLICIT_STRUCTURE`：修订序列可以表示，但任务从“稳定真值”变成“持续过程”；
- `INHERITED_LIMIT`：Tarski/Gödel 型全域 truth/reflection 界限没有消失。

人话结论：

> HoTT 不必强迫这句话在 true/false 里选一个。它可以拒绝那个自读取真值的接口，也可以把“不断反转”当成一个过程；但过程存在不等于稳定答案存在。

## 4.4 Better Best 悖论

### 悖论内容与用户判断

甲选择“成为最好的”，乙选择“成为比甲更好的”。用户强调先接受甲的选择，使甲的“最好”成为已提交不变量，再审查乙的新要求是否合法。乙的要求与现有承诺冲突，应有限拒绝。

这不是一定要无限循环的程序；错误在于把不相容的后续请求也准入。

### HoTT 怎样处理

可以把状态和不变量编码在依赖类型中：

~~~
State
ValidRequest : State → Request → Type
apply : (s:State) → (r:Request) → ValidRequest s r → State
~~~

没有 `ValidRequest` 的证明，就不能调用 `apply`。也可以把“甲最好且乙比甲更好”表达成空类型/不可满足结构。

### 到底解决了什么

- `DISSOLVED_BY_DISTINCTION`：承诺状态、候选请求和合法更新分开；
- `BLOCKED_AT_FORMATION`：没有合法性见证就不能应用更新；
- bare HoTT 不会自动知道现实中的先后；状态和协议必须建模。

人话结论：

> HoTT 可以让“你已经答应了什么”进入下一步函数的输入类型。乙没有通行证，程序就拒绝。它不需要一直尝试同时满足两个要求。

## 4.5 圆环悖论

### 悖论内容与用户判断

从圆上拿掉一点得 `M`，展开为两端分开的线 `N`。为什么 `M→N` 容易，而 `N→M` 似乎无法让两端只差一个无大小的点？

用户抓住的是：当初确实从 `M` 得到 `N`；为什么反向恢复失去资格；点无大小、连续统稠密性和过程不可逆可能是被抽象前提；“曾经有共同来源”不该被当前裸形态抹掉。

### HoTT/拓扑怎样处理

纯拓扑上，穿孔圆 `S1\{p}` 与开区间/实线同胚；若保留具体同胚，当然可以反向映射。HoTT 的圆是一个 HIT：

~~~
base : S1
loop : base = base
~~~

圆的闭合不是从裸区间自动猜出的，而是由 `loop`/端点识别等结构给出。

若把“带缺失点、共同端点来源、展开历史”的丰富对象忘成裸区间，裸区间确实不能决定两端是两个不同边界，还是应被识别成同一个缺口。

### 到底解决了什么

- `DISSOLVED_BY_DISTINCTION`：拓扑同胚与物理复原过程不是一回事；
- `MODELED_WITH_EXPLICIT_STRUCTURE`：闭合、端点识别、同胚和 provenance 必须显式保留；
- 用户最有价值的残余是“来源历史忘掉后不能免费恢复”，不是“开区间拓扑上无法回到穿孔圆”。

人话结论：

> 如果你把“这两个端原来来自同一个缺口”的纸条一起带着，HoTT 能按这张纸条重新粘合；如果只剩一条裸线，理论不会假装知道该怎么粘。

## 4.6 shenchensh 平行线转动悖论

### 悖论内容与用户判断

一条相交直线绕定点转到平行。仿射交点沿另一条直线越来越远；到了平行时，交点怎样从一侧“跳”到另一侧？若转角连续稠密，最后时刻怎样完成？

用户把它与芝诺归为同病：数学要求交点无间隙移动；平直、无限、稠密空间是隐藏前提；可以通过圆型闭合空间或离散转角否定其中某项前提；用户倾向把时空稠密性视为病根。

### HoTT/标准几何怎样处理

先分模型：

1. **仿射几何**：平行配置没有有限交点；“交点位置”是部分函数，在平行参数处未定义；
2. **射影几何**：加入无穷远点/方向，平行线在射影完备化中相交；
3. **旋转参数**：直线角度可以在有限参数时刻到达平行角；交点坐标趋于无穷不等于某个物体跑完无限距离；
4. **离散转角模型**：是另一套物理/计算模型，需要给出步长和可观测预测。

HoTT 可以形式化这些空间、路径和完备化，但不会把三个模型自动认成同一物理宇宙。

### 到底解决了什么

- `DISSOLVED_BY_DISTINCTION`：配置路径、交点部分函数和物质运动分开；
- `MODELED_WITH_EXPLICIT_STRUCTURE`：仿射/射影/离散模型各自明确；
- `INTERPRETATION_OPEN`：不能从该悖论单独推出物理时空离散、宇宙闭合或普朗克长度为最小单位。

人话结论：

> 直线可以在有限时间转到平行；只是“有限交点在哪里”这个问题在那一刻没有答案。没有答案的是交点函数，不是转动本身卡在无穷远。
