# C11：HoTT 理论经济账本与悖论位置判别

## 0. 结论

1. 需要这张账本，是因为此前的研究顺序是**题目驱动**：C5 的升级链从 E1“同一现实任务”起步，C10 从候选资格筛起步，因此从来没有先系统列出“HoTT 为了理论经济性，做了哪些悬置现实因子的动作”。
2. 账本的一行 = 一个**规则级经济决策**，固定五列：收入 / 被悬置的现实因子 / 支付装置 / 复活条件 / 现有机器判词。
3. 总账不变量（本文中心的**可反驳假设**）：每当理论为了经济性悬置一个现实因子，它必须在某处支付；**悖论不会出现在“理论忘了某个因子”的地方，只会出现在“支付装置在任务所需的同一阶段、或同一层级上不可用”的地方。**
4. 由此得到两条可用性判据（同阶段？同层？）与一个 2×2 判别格；结构性预测是：现实相对悖论应出现在“同阶段不可用”或“同层不可用”的格子里。
5. 回溯检验表（§5）显示：现有 18 个机器包**全部**落在“支付装置可用”的格子里——这正是它们判词停在 `DEFENSE_WORKS` / `REPRESENTATION_BOUNDARY` 的账本解释；而唯一“支付装置不存在”的已证结果（`MP-NOCANONICAL-001`）恰好缺一个真实任务（E1/E6）。
6. 下一工作包：用判别格挑 1–2 个“两问皆不可用”的候选，按 `MATH_PROOF_BEFORE_DELIVERY_V1` 做机器化。本文不预判哪个候选会成功。

## 1. 方法诊断：为什么需要“先立账、再找题”

`audit/astra-1-astra-2会话轨迹审计-20260913.md` 记录了另一个 AI 的失败形状：问题意识被准确复述，实际选题却持续落在“熟悉、清楚、能够形式化的小问题”上。把它与 C5、C10 对照，方法原因可以被精确定位：

- C5 §3 的升级链从 **E1 同一现实任务**开始，E2/E3 才轮到理论配置与抽象；也就是说，**任务先于理论经济被枚举**。
- C10 §1 把“关键 HoTT 规则至少一条不可被普通类型论替代”设为候选必填门槛；它筛的是候选，不是理论的经济结构。
- 两者共同的结果：我们知道“理论在某个抽象上失真”的形状，但不知道**该去哪些抽象上找**。于是只能在已有题型附近反复采样。

本文做一次方向倒转：**先列理论端的经济账本，再由账本生成任务形状**。这与三问 §二“从现实任务反推”并不冲突——它补上的是三问没有规定的**枚举顺序**：先枚举理论的经济决策，再为每个决策生成“同一任务”的判别测试。

## 2. 账本结构

### 2.1 五个字段

| 字段 | 含义 | 质量要求 |
|---|---|---|
| 收入 | 这条规则让理论使用者**不再需要做的现实记账** | 必须锚在具体规则（形成/消去/计算/相等/宇宙/HIT） |
| 被悬置的现实因子 | 因该经济决策而不再起作用的现实要素 | 必须能落到用户词汇：时序、过程、代表元、成本、来源、观察者、准入 |
| 支付装置 | 当该因子重新变成必需时，理论用什么把它带回来 | 必须是**理论内可用**的机制（显式参数、命题消去、canonical section、层级、扩展类型论、外部假设） |
| 复活条件 | 哪类任务让被悬置因子重新承重 | 必须是任务形状，不是文献结论 |
| 现有机器判词 | 本 repo 已证明的结论落在本行哪一格 | 必须给出 claim/run 索引；无证据写 `UNTESTED` |

### 2.2 总账不变量（可反驳假设）

> **当理论为了经济性悬置现实因子 F 时，必须存在一个支付装置 P 把 F 在需要时带回来。若某个任务要求 F 在“同一阶段”或“同一层”可用，而 P 只能在更晚阶段或更高层提供 F，则该任务在理论内不可完成，而现实侧可能仍然可完成——这就是现实相对悖论的位置。**

这条不变量同时给出**证伪条件**：如果一个候选的 F 能在同阶段同层被 P 提供，并且原任务的输入/输出/完成标准不变，那么该候选必须停在 `REPRESENTATION_BOUNDARY`，不构成悖论。

### 2.3 两条可用性判据

对每个支付装置问两个正交问题：

1. **同阶段吗？** 任务是否要求在某个阶段上就交出结果/凭证？被悬置因子是否只在该阶段之后才可获得？
2. **同层吗？** 任务是否要求用理论自身的判断/担保来完成？被悬置因子是否只能在元层、更高宇宙层或扩展类型论中获得？

### 3.1 每行的“最小放回改动”与“是否改变任务”

| # | 把因子放回表示的最小改动 | 该改动是否改变原任务？ |
|---|---|---|
| 1 | 把 `∥A∥` 换成带见证的类型（或把 h-level 提升为数据） | 不变（只是表示更细）→ 因此判词停在表示边界 |
| 2 | 改用带代表元/路径的表示，或加 canonical section | 不变 → 表示边界；若任务禁止使用代表元，则性质改变（尚未有此类任务） |
| 3 | 把被观察量加入结构签名（如把 modulus 纳入同一性） | 不变（C-129–C-133 即此正控制）→ 表示边界 |
| 4 | 用程序语法 + 成本结构替代裸函数 | 不变 → 表示边界 |

## 4. 判别格与结构性预测

### 4.1 2×2 判别格

| | 同一层可用 | 同一层不可用 |
|---|---|---|
| **同阶段可用** | 现有 18 个机器包全部在此：`DEFENSE_WORKS` / `REPRESENTATION_BOUNDARY` / 正结构结果 | 自指类候选（账本 #8）：担保只能由被担保者自己提供，升层即出理论 |
| **同阶段不可用** | 时序类候选（账本 #5/#6）：因子“以后才有”，此刻无法细化表示 | **最强形状**：任务同时要求“此刻必须落定”与“凭自身担保落定” |

### 4.2 三条候选路径

| 路径 | 形状 | 现有最接近的机器证据 | 缺环 |
|---|---|---|---|
| P1 时序线（同阶段不可用） | 现实的完成靠“此刻就能交出有限结果”，而理论只保证“存在某个完成”，该存在在指定阶段还不能当交付 | C-106–C-109（时刻 0 无前视、分时刻正例）；C-118–C-123（strict/partial 边界） | 一个**同一任务**下“现实当下可交付、理论在该阶段不可交付”的正面任务；目前只有边界，没有该反差 |
| P2 自指线（同层不可用） | 理论对自己的担保只能由自己提供；支付装置（升层）把担保推出理论 | S053 对角核机器核查；S054 路线 (a) 语法层可行；ERCF-3 保持 `GATED` | 一个真实要求“内部总自证”的消费者（P8/B01-TARGET）；否则只是通用 Gödel/Tarski 边界 |
| P3 交叉线（两问皆不可用） | 任务要求在**当前阶段**用**理论自身的判断**交付一个**代表元** | C-142–C-148（无统一选点，支付装置不存在）+ C-106–C-109（阶段限制）同时成立 | 一个把二者合并的真实任务；这是账本给出的最锋利搜索目标 |

P3 值得单独说明：`MP-NOCANONICAL-001` 已经机器证明“unlabeled 二元素呈现没有统一选点”，按账本这属于“**支付装置不存在**”的格子；它之所以没有升级为悖论，不是因为矩阵错了，而是因为**缺一个承诺统一选点的真实任务**（E1/E6）。账本与已有证据在这里互相印证，而不是互相替代。

## 6. 执行流程与停止条件

### 6.1 四遍

1. **收账**：只从规则写行（形成、消去、计算、相等、宇宙、HIT/截断、库层便利），不引文献措辞；新行必须给出“收入”对应的具体规则。
2. **支付**：每行写出“把因子放回表示的最小改动”，并判断它是否改变原任务的输入/输出/完成标准。
3. **判别**：对每行做“同阶段/同层”两问，标出不可用的格子；预测必须落到具体任务形状。
4. **回溯**：把现有全部机器判词逐条映射到格子；映射失败就修正账本。

只有通过第四遍，才挑 1–2 个“两问皆不可用”的候选进入机器化。

### 6.2 停止条件

- 新行只改命名、不改变规则或支付装置；
- 候选的反差只在“同阶段同层可用”的格子里出现（应判表示边界）；
- 反差需要额外添加神谕、全知未来或额外输出才能制造；
- 结论完全由一般停机/一般商/一般复杂度给出，HoTT 规则未进入关键步骤。

### 6.3 防过度设计

一张表、一个 owner（本文件）、一份判别格。**不**建数据库、**不**建评分平台、**不**建新 Gate、**不**建常驻审计；账本的增长只由“出现新的规则级经济决策”驱动。
