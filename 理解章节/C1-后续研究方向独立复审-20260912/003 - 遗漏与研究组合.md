# 遗漏与研究组合

## 4. 这份建议遗漏了什么

## 4.1 遗漏 W51×RP-B01

KC-000027 是用户在交接前的最新认知修正：

> HoTT 是“逻辑+几何+程序”；它对齐程序以后，程序无法全域验证所有程序可计算性/合法性的界限也成为它的界限。

`理解章节/A11` 已指出，W51 与 RP-B01 互为表里：

- W51 给出哲学命名；
- RP-B01 给出数学分类与无神谕有效总实现分离的骨架；
- 缺的是自然 Think-in-HoTT 使用过程把“数学分类资格”提升为“有效交付资格”的第三层实例。

附件的两条主线都偏向 A 方向或表示/组合边界，没有正面推进这条 B 方向。因此它的 portfolio 不完整。

## 4.2 遗漏用户反复押注的自指/反射线

KC-000025/KC-000026 明确保留：

~~~
为什么自指型悖论找得这么慢？
HoTT 难道可以越过对自身的自指吗？我不相信。
~~~

历史 R029–R032 只得到条件边界，没有完成构造。自指线与 W51 的自然交点是：

> 一个程序性基础是否能在同一层内有效地编码、运行并担保自己的全域 ASK？

附件完全没有把这条用户押注放入主攻组合。这不是“少列一个备选”，而是漏掉了核心认知中的最新深层方向。

## 4.3 把“已知边界研究”放在“目标实例研究”之前

部分性 monad 的构造、商、选择与分配律有成熟文献。研究它很有价值，但很可能首先产出：

~~~
这套表示支持这些操作，不支持那些操作。
~~~

这仍属于能力边界。用户最终要的是：

~~~
为什么一个自然 Think-in-HoTT 使用过程会把不足的能力当作足够，
并由此制造现实本无的困难或虚假的完成。
~~~

所以文献边界不能再次挤掉“自然使用桥梁”的构造。

## 5. 经复审后的研究组合

未来真正恢复数学研究时，建议采用**两条用户目标主线 + 一条探索探针 + 一条验证线**。

| 层 | 方向 | 下一项最小成果 | 继续条件 | 收束条件 |

| 证据 Gate | 补齐数学 R041 执行谱系 | 取得源码、25 项测试原始输出、`cf58f27`、容器 manifest；核文件 hash 与 R039 基线 | 代码/运行/Git 与正文一致 | 只有正文时保持 paper-only，不重复其有限枚举 |

### 推荐实际顺序

1. **先补 R041 源码/运行/Git 身份。**正文已经有了，不应再重复证明同一个有限模型。
2. **主线 B 先取得一个最小自然使用桥梁。**它最忠实于 KC-000027 和 A11.1/A11.2。
3. **主线 A 从 R041 已完成的代表层分离推进到真实 quotient/QIIT 接口。**
4. **在线因果性进入探索位。**它负责引入新的机制，防止只研究商与信息遗忘。
5. **R034 验证线独立推进。**环境准备不应吞噬全部发现工作。
