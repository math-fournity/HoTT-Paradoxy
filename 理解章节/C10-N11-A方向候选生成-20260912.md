# C10：N11 A 方向候选生成与有界负结论

> 文档身份：`CURRENT CANDIDATE GENERATION / A_DIRECTION_BOUNDED_NEGATIVE`
> 日期：2026-09-12
> 触发：S055 路由的第一工作包 N11（A 方向候选生成，要求 HoTT 特有规则参与关键步骤）
> 输入：N1–N10 的十四个机器包与四层审计、C5/C6/C7/C8/C9、`A11.3`（A 方向荒置诊断）、用户 KC-000003–000006/000010–000013/000022/000024、本地操作手册 OP01–OP08、固定工具链（Agda 2.8.0-3d04bac + Cubical v0.9）
> 结论：**`A_DIRECTION_BOUNDED_NEGATIVE`**——在本轮固定的候选空间与工具链内，A 方向候选全部归约为三类：表示/资格边界（已有机器结果）、通用边界（Turing/Gödel/LEM 型）、或元层/工具链观察（不是理论定理）。没有找到需要新增机器的 A 方向候选；与 C8/C9 一致，所有路线的唯一升级口都是 E6（真实自然使用链）。

## 1. 生成方法与判据

每个候选用固定字段登记（与 C6/N4 一致，便于机器检查与后续复用）：

```text
候选 ID / 操作（OP01–OP08）/ 关键 HoTT 规则 / 任务（现实侧与理论侧须同名同规格）
/ 现实侧的"完成"是什么 / 关键步骤在哪 / 预测判词 / 映射到已有结果或缺口 / 最小判别任务 / 停止条件
```

三个**必填门槛**（缺一不构成 A 方向候选）：

1. **HoTT 规则参与关键步骤**：`ua`/`Id`（含高阶 path）/HIT/truncation/高阶相干/宇宙中至少一条不可被普通类型论替代；
2. **同一任务**：现实侧与理论侧的任务输入、输出规格、完成判据一致（不是"现实做别的、理论做别的"）；
3. **可机器化判别**：存在固定工具链中可核查的最小判别任务（或明确的 NOT_RUN 理由）。

## 3. 归约类型

上表 13 个候选全部落入三类（并已在至少一个方向上有机器证据或明确判定）：

1. **表示/资格边界**（A-01–A-05、A-08、A-09）：理论在正确的表示层可以完成任务；"困难"只出现在把较弱表示当作完整交付时。这类已在 C5–C7 中被固定为第二级 `REPRESENTATION_BOUNDARY`，其正控制（细化表示可恢复）也已机器化。
2. **通用边界**（A-10、A-13）：结论不依赖 HoTT 特有规则（密集连续统是模型选择；自证边界是 Turing/Gödel 型）。
3. **元层/工具链观察**（A-11、A-12）：结论是关于工具链行为（stuck 项、编译拒绝）的观察，不是对象理论的定理；把它们写成悖论会违反"范围准确"的要求。

对照 C6/N4 的候选池：`CAND-REGULARITY` 已实测排除；`CAND-TYPEQUOT-SECTION`、`CAND-CAUCHY`、`CAND-SIP` 已分别由 N8/N9 与 `MP-QUOTIENT-MONAD-001` 覆盖；有限/无限选择类由 N6 与 `MP-PARTIAL-DECISION-001` 覆盖。本轮新增的 A-11/A-12 是两个**新形态**，但它们的判词是元层/工具链，而不是理论悖论。

## 5. 判定与统一结论

- **判定：`A_DIRECTION_BOUNDED_NEGATIVE`**（限定范围：本轮 13 个候选 + 固定工具链 + 已有四层审计集合）。含义：**没有找到同时满足三门槛、且需要新增机器证明的 A 方向候选**。
- 与 C8/C9 的统一：ERCF 线（C8）与 W51 线（C9）的升级口都是 `P8 = B01-TARGET = E6`；A 方向的 13 个候选里，凡是"理论无法完成"的机器化形态（A-01–A-09）也都在等待同一个东西——把边界当交付的真实使用链。**三条研究线在本轮汇合到同一个缺口**。
- 因此当前最优策略不再是继续生成同型候选或新增同型审计，而是：要么找到 E6（真实、固定版本、可回查的接口/承诺），要么把证据队列中尚未复核的历史主张按固定规则收口，让未来 AI 不必重走已闭合的搜索空间。

## 6. 停止条件（本轮自身）

- 若未来出现新的 HoTT 特有规则/变体（如更高模态、新的 HIT 语义、2LTT 内层新原语）进入关键步骤，重开 N11 的候选生成；
- 若用户给出新的元数学原文（尤其涉及时间/完成/自指的新机制），进入 core 新 generation 并重开候选空间；
- 否则 A 方向的候选生成停止在本有界负结论，工作包转证据队列（见 §7）。
