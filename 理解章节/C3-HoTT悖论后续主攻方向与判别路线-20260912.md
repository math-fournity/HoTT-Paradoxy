## 0. 一句话结论

后续不应继续笼统地搜索“HoTT 缺少时间”或把传统自指悖论换成 HoTT 术语，而应集中搜索：

> **HoTT 的构造、截断、商、同一化、经典分类或反射接口，只取得了某一种数学资格；当后续推演、程序接口或现实任务把它当成更强的上下文、计算、时序、因果或交付资格时，这种资格是否仍然保持？如果不保持，究竟是谁作出了非法升级？**

我把这条总方向命名为：

> **ASK／完成资格的保持性研究**  
> `Qualification Preservation under Abstraction and Composition`

它同时统摄用户的两个目标：

- A 方向：现实过程本来能完成，抽象或理论化后却丢失了完成该任务所需的资格；
- B 方向：理论只取得较弱的数学资格，却在使用中被提升为现实并未取得的有效完成资格。

在这一总方向之下，应明确区分两种“第一”：

1. **战略主论题**：`W51 × RP-B01 × self-reference`。目标是研究“HoTT 作为逻辑、几何与程序的统一系统，如何继承而不能豁免程序的有效性和自反界限”，以及数学分类资格如何被误当作有效交付或有效自我校验资格。
2. **第一个可执行研究对象**：数学 R041 所打开的 `partiality quotient × bind/race/timeout`。它已经有最小正例、最小反例、组合完成性反差和黑箱不可能三角，最适合马上推进到一个真实 HoTT 商／QIIT／guarded 接口，检验“结果相同”是否足以支持真实竞争上下文。

这不是排序矛盾。B 线更接近最终理论目标；A 线证据链更成熟，适合先建立一条从对象、定理、反例、HoTT 形成规则、现实操作到停止判据都完整的样板。

## 1. 为什么需要从“主题搜索”转为“资格保持性搜索”

过去工作已经表明，仅按名词搜索很容易重复失败：

- 看到“时间”，就不断枚举延迟、自环和 timeout；
- 看到“自指”，就复活 `Map(1,G)`、宇宙角色相似或“元证明也是一个点”；
- 看到“截断”，就假设它偷偷给出了见证；
- 看到“单价性”，就假设所有被等同的对象在任何现实上下文中都可替换；
- 看到一个不可计算分类，就立刻宣布 HoTT 内部矛盾。

这些路线共同遗漏了一件事：**一个数学对象具有什么资格，取决于它是怎样形成的、保留了什么数据、允许怎样消去、对哪些操作是同余的、承诺怎样的计算行为，以及下游究竟要求什么。**

因此，未来每个候选都必须先拆成一条资格链。下列各层是审计顺序，不声称它们在所有理论中构成无条件线性蕴含：

| 层 | 资格 | 必须回答 |
|---|---|---|
| `Q0` | 形成资格 | 这个类型、项、商、HIT/QIIT、递归或自指对象在指定 Theory Schema 中能否合法形成？ |
| `Q1` | 命题存在资格 | 是否只知道某个命题被居留，例如 `‖Σx.P(x)‖`？ |
| `Q2` | 可取见证资格 | 是否真正有 `Σx.P(x)`，且当前目标允许消去并取得 `x`？ |
| `Q3` | 统一数学函数资格 | 是否有对所有输入定义的数学函数或分类，而非逐实例常量的存在？ |
| `Q4` | 有效实现资格 | 是否有同输入、同输出、无未声明神谕且对所有输入有限完成的统一程序？ |
| `Q5` | 上下文替换资格 | 所用等价／路径是否对当前语言的全部后续操作构成同余？ |
| `Q6` | 时序与因果资格 | 是否保留完成先后、在线可用性、调度、deadline、历史和因果依赖？ |
| `Q7` | 现实交付资格 | 是否在指定资源、环境、观察协议和现实任务中真正可完成？ |

最有价值的“悖论候选”不是两个句子表面冲突，而是有一条可定位的资格跃迁：

```text
理论实际证明：Q_i
下游实际需要：Q_j，且 j 更强或包含 Q_i 未保留的维度
可疑步骤：把 Q_i 当成 Q_j
现实后果：任务改变、完成性改变、结果改变，或系统必须增加原任务没有的前提
```

这正是 ASK 的动态版本：ASK 不只在入口问一次，也要追踪资格在截断、运输、商消去、组合、提取和自我应用中是否失效或被替换。

## 2. A、B 两个方向其实是同一断层的两面

| 方向 | 资格断层 | 要找的最强结果 |
|---|---|---|
| A：现实可完成，理论中反而困难 | 现实任务具有 `Q5/Q6/Q7`；理论抽象只保留较弱身份，或为恢复现实操作被迫增加原任务没有的全域见证、选择、时钟或可判定性 | 构造同一任务的现实过程与理论过程，证明理论化步骤本身丢失必要资格或绑定额外困难 |
| B：现实未完成，理论中被说成完成 | 理论只取得 `Q1/Q3`；解释、接口或哲学叙述却把它提升成 `Q4/Q7` | 构造数学对象与现实交付的严格分离，并找到一个自然使用点实际作出了这次升级 |

因此，未来不应把 A 线理解成“时间例子库”，也不应把 B 线理解成“再讲一遍停机定理”。二者共享同一个判别问题：

> **当前抽象所得身份或存在性，是否足以承担下游实际操作的完成责任？**

这个统一视角还有一个重要优点：它允许 HoTT 作出正确防御。若截断消去器拒绝取见证、商递归拒绝不相容的 race、编译器拒绝带经典公理的直接提取，那么研究结论应是“防御成立”，不能为了得到悖论而绕过规则。

## 3. 对候选结论设置四级判词

任何候选最终只能进入下列四种结论之一，不能从低一级跳到高一级：

| 判词 | 含义 | 是否已经是用户目标 |
|---|---|---|
| `DEFENSE_WORKS` | HoTT 的形成／消去／同余／提取规则准确拒绝了非法升级 | 不是悖论，但它告诉我们攻击为什么失败 |
| `REPRESENTATION_BOUNDARY` | 某个合法抽象不能表达某个现实操作；换成富化表示即可 | 是重要边界，尚不是 HoTT 整体问题 |
| `NATURAL_USAGE_MISMATCH` | 一个自然、明确、可回查的 HoTT 建模或使用流程把较弱资格当成更强资格，并使同一现实任务的完成性或结果失真 | 这是当前最现实的“现实相对悖论”目标 |
| `INTERNAL_INCONSISTENCY` | 指定 HoTT 配置内部可推出不相容判断或 `⊥` | 证据门槛最高；当前没有证据支持 |

未来工作最容易犯的错误，是从 `REPRESENTATION_BOUNDARY` 直接写成 `INTERNAL_INCONSISTENCY`。本方案的主攻目标是先争取 `NATURAL_USAGE_MISMATCH`；若只能得到前两项，也要诚实保存。

## 4. 战略主线与战术先手

### 4.1 战略主线：数学分类—有效交付—有效自反的三级断裂

战略主线选择 `DIR-W-RP-B01 × DIR-L-SELF-REFLECTION`，原因是：

1. 它直接回应 KC-000025—KC-000027：HoTT 对齐程序后不会神奇地越过程序的自反和计算界限。
2. 它把用户的“逻辑 + 几何 + 程序”认识转化为可检验命题，而不是继续把 HoTT 当成纯静态空间语言。
3. RP-B01 已经给出一个清楚骨架：命题 LEM 可给数学停机分类 `χ`，但没有同规格的无神谕统一有效总实现。
4. 现有材料最关键的开放项 `B01-TARGET` 恰好不是再证明经典对角论证，而是找到“自然 Think in HoTT 使用方式究竟在哪里把数学函数资格提升成有效交付资格”。
5. 自指线可以把一般停机分离推进到理论自身的 syntax、substitution、evaluation、provability 和 reflection，而不是停留在外部程序例子。

但它现在还不能直接称为 HoTT 特定悖论，因为 RP-B01 的对角核心使用的是命题 LEM 和通用有效程序模型，尚未用到单价性、HIT 或 HoTT 特有的 identity 结构。下一步必须补的是 HoTT 特定的自然接口，不是更多有限样本。

### 4.2 战术先手：部分计算抽象对后续操作是否封闭

第一个实际研究包选择 `DIR-W-RACE-TIMEOUT`，原因是：

1. R041 已经提供最小反例：`p0 ≈ p2`，但与 `q1` 竞争后返回不同值。
2. 它同时提供正向控制：顺序 `bind` 尊重结果等价。这能排除“所有组合都失败”的粗糙叙述。
3. 它提供整项完成性差异：相同 continuation 下，`C(p0)` 返回 7，而 `C(p2)` 发散。
4. 它提供不依赖“必须选择最快者”的黑箱不可能三角：值可靠性、只要一方返回就响应、独立结果外延性不能同时满足。
5. 它天然连接 HoTT 的商／HIT/QIIT 消去与同余责任，也天然连接现实中的 race、timeout、调度和在线可用性。
6. 它有明确停止条件：若真实 HoTT 接口从未承诺 race，或准确要求携带时钟／trace，那么结论就是边界或防御，不继续换延迟数字制造“新例子”。

所以，A 线是我们建立完整研究方法的最佳试验场；B 线是最终要攻克的更深理论主线。

## 5. 第一研究包：`Partiality–Contextual Adequacy`

建议给第一个实际研究包使用工作名：

> **部分性抽象的上下文充分性：结果等价何时足以支持组合，何时必须保留完成时序？**

### 5.1 必须固定的理论对象

至少同时固定三层，不能只在纸上使用同一个 `Q` 字母：

1. 具体对象 `Delay(A)`：包含 `now(a)`、`later(p)` 和明确的无限等待对象／余递归语义；
2. 结果等价 `≈result`：只保留“是否有限返回、返回什么”，忽略有限停顿次数；
3. 一个真实 HoTT 部分性对象 `P(A)`：从下列候选中只选一个并固定版本、构造子、等式和消去原则：
   - 集合商 `Delay(A)/≈result`；
   - 文献中的 partiality QIIT；
   - 明确的 guarded/clocked partiality 后再取某种商。

在没有核对真实签名以前，不得把 setoid 层 `bind` 自动升级成

```text
P(A) × (A → P(B)) → P(B)
```

因为 continuation 只给商上的值时，可能没有统一代表提升；选择原则、setoid 构造和 QIIT 构造必须分开。

### 5.2 固定操作语言和观察协议

操作集至少分为两组：

- 正向控制：`return`、顺序 `bind`；
- 时序探针：公平 `race`、有限 `timeout`。

观察协议也必须显式分层：

| 观察 | 问题 |
|---|---|
| 返回值 | 最终返回什么？ |
| may-complete | 是否存在有限返回证据？ |
| must/respond | 在声明的调度下，只要条件满足是否保证响应？ |
| completion round | 第几个逻辑回合可用？ |
| contextual termination | 放入允许的程序上下文后，整项是否完成？ |

不能把物理秒偷偷代入逻辑回合，也不能把 timeout 的替代值写成“证明原过程发散”。

### 5.3 要形成的定理阶梯

本研究包不是再跑一组示例，而应按下列阶梯逐级闭合：

1. **关系层**：证明 `≈result` 的精确定义和等价关系性质。
2. **顺序正例**：证明 `bind` 对输入和 continuation 的点态 `≈result` 相容。
3. **竞争反例**：用 `p0=now(0)`、`p2=later²(now(0))`、`q1=later(now(1))` 证明 `race` 不相容。
4. **商下降不可能**：若 `race_P` 对所有代表忠实，则由 `[p0]=[p2]` 推出不同返回值商类相等，形成指定模型中的矛盾。
5. **整项完成性反差**：固定 `k(0)=now(7)`、`k(1)=ω`，证明替换单个“结果等价”组件可令整个组合从完成变为不完成。
6. **黑箱不可能三角**：在明示查询接口下，证明值可靠性、响应性和独立结果外延性不可兼得。
7. **最小富化**：分别检验保留完整 Delay、完成轮数、因果 trace、clock/grade 或改成集合值非确定结果，哪一种最小改变能恢复目标操作。
8. **上下文等价**：对包含 `bind + race/timeout` 的小语言定义观察上下文，证明结果等价严格粗于该语言的上下文等价；再问商掉哪一种关系才真正对全部操作封闭。

前五项已有 R041 纸笔骨架；第六项已有条件论证；真正的新工作集中在第七、八项和真实 HoTT 构造。

### 5.4 这条线怎样从“边界”升级为“现实相对悖论”

仅证明 `race` 不下降还不够。必须补一条自然使用桥梁：

```text
现实任务：运行两个实际部分程序并在一个可用结果出现时继续
        ↓
HoTT 表示：把部分程序只按最终结果取商／同一化
        ↓
自然承诺：商类是“该部分计算”的完整身份，因此可在程序语言中替换
        ↓
后续上下文：race 或 timeout 需要被删掉的完成先后
        ↓
反差：两个被称为相同的组件使整项分别完成和不完成
```

要核查的关键不是“HoTT 能否写 race”，而是：

- 该 partiality 构造的论文、库或语义实际承诺哪些操作？
- “部分计算的自由 ω-cpo／monad”之类身份是否只服务顺序组合？
- 并发或 timeout 的 consumer 是否另行要求更强等价？
- 使用者是否在没有证明同余时，把 quotient path 当作全语言 substitutivity？

若真实接口明确不承诺竞争操作，结论是 `DEFENSE_WORKS` 或 `REPRESENTATION_BOUNDARY`。若一个自然的 HoTT 程序语义把该 quotient 当成含竞争语言的完整程序身份，才可能达到 `NATURAL_USAGE_MISMATCH`。

### 5.5 这一研究包的正反分支

| 结果 | 应如何解释 | 下一步 |
|---|---|---|
| `bind` 和真实 QIIT monad 都成立，race 被形成规则拒绝 | HoTT 正确区分了顺序计算与竞争上下文 | 保存防御；转向最小富化或 B 线 |
| race 只能在保留 clock/trace 后定义 | 证明时序是该操作的必要结构，不是从结果身份免费恢复的数据 | 比较富化前后是否仍是同一现实任务 |
| 某自然 consumer 无证明地把商路径用于 race | 找到现实相对使用失配的候选 | 固定版本、接口、调用链和整项反差，进入形式化 |
| 所有自然接口都明确区分两种等价 | 没有悖论，只有已被理论正确治理的边界 | 停止该族，不再增加 delay 枚举 |
| 反例依赖人为平局政策或人为预知未来 | 候选不自然 | 修正合同；仍不自然则淘汰 |

## 6. 战略研究包：`Classification–Delivery–Reflection`

建议把战略包命名为：

> **从数学分类到有效交付，再到有效自我 ASK：HoTT 的程序性资格边界**

### 6.1 RP-B01 已经真正得到什么

在固定通用有效程序模型并加入命题 LEM 后，可定义：

```text
Halt(p,x) := ‖Σ n v. T(p,x,n,v)‖
χ(p,x) : Bool
```

其中 `χ=1 ↔ Halt`、`χ=0 ↔ ¬Halt`。这给出一个合法的数学分类函数资格 `Q3`。

RP-B01 的对角论证说明：不存在一个同输入、同输出、无神谕、对所有输入有限完成的统一程序 `h` 来实现 `χ`。也就是 `Q3` 不自动给出 `Q4`。

必须保留三层区分：

1. 每个固定 `(p,x)` 有一个正确常量程序；
2. 数学上有统一分配函数 `χ`；
3. 有一个从任意 `(p,x)` 有效取得正确结果的统一程序。

前两项都不能冒充第三项。`noncomputable` 标记也不能代替对角证明。

### 6.2 下一步不是重证停机定理，而是寻找自然升级点

真正未完成的是 `B01-TARGET`。需要固定一个可回查的 HoTT 使用接口，逐项问：

- 它是否声称每个 `ℕ→Bool` 的内部数学函数都能提取为同规格程序？
- 它怎样处理命题 LEM、选择、公理化 univalence 或 opaque constant？
- 它区分证明层命题、数据层和运行层吗？
- 用户提供实现、外部 oracle、unsafe 映射或 `implemented_by` 一类机制是否改变了原合同？
- 它是否把“理论中可定义”叙述成“现实中可求值”，还是明确拒绝？

这里可以得到两种同样有价值的结果：

- 接口明确拒绝或要求额外实现：`DEFENSE_WORKS`；
- 接口或其自然哲学解释确实作出统一有效交付承诺：用 `χ` 给出反例，形成 `NATURAL_USAGE_MISMATCH`。

不得因为普通 Lean/Rocq 中存在类似机制，就直接称为 HoTT 结果。要固定 exact theory、library、axioms、extraction/backend 和输出规格。

### 6.3 与自指／反射线合流

当普通分类—交付断层固定后，再进入“有效自我 ASK”：

1. 固定一个 HoTT 对象演算 `T` 的有限语法编码 `Code_T`；
2. 固定 substitution、有限步 evaluation、typing/provability judgment；
3. 区分外部元理论定义的 checker 与 `T` 内部可调用的 checker；
4. 明确 checker 是证明产生器、Bool 分类器、部分求值器，还是 soundness/consistency 断言；
5. 只有具备 quote／self-application／evaluation 的真实闭合接口后，才应用 Gödel、Tarski、Lawvere 或停机式对角方法；
6. 检验 universe hierarchy、strict outer layer 或 two-level type theory 是防御、富化还是任务改变。

这条线最有希望把“HoTT 继承程序的界限”变成 HoTT 特定研究，因为困难不再只是外部机器停机，而是：

> 单层 univalent/homotopical equality、对象内语法商、严格 substitution/evaluation、可判定 type checking、总反射和自包含 universe 能否同时承担所需资格？

但在 exact calculus 和接口固定以前，这仍是研究问题，不是已证不可能定理。

### 6.4 战略线的 HoTT 特异性 Gate

每个结论必须回答：

| 检查 | 若答案为否 |
|---|---|
| 单价性、identity/path、HIT/QIIT、universe 或 HoTT 元理论结构是否进入关键推导？ | 只能称一般计算／逻辑界限的 HoTT 实例 |
| 是否固定了 HoTT 变体和额外公理？ | 不能泛称 HoTT |
| 是否有自然的对象层→执行层或对象层→元层接口？ | 只能称条件模型 |
| HoTT 自己是否承诺了被反驳的强资格？ | 若没有，只能称外部误读或防御成功 |
| 同一现实任务是否保持，而不是中途加入 oracle、deadline 或全域 checker？ | 若改变任务，不构成用户要求的反差 |

## 7. 探索线：在线因果与 guard 擦除

这两条线保留，但不与主线并行铺开。

### 7.1 完整流函数与在线策略

最小自然问题可以写成：

> 数学上给出 `F : Stream(A) → Stream(B)`，是否足以在输入逐步到达的现实中在线产生输出？

在线资格应由 prefix causality 明确表达，例如输出前 `n` 步只依赖输入有限前缀，而不是只凭函数类型。一个需要“明天输入”才能决定“今天输出”的完整流函数，可能是合法数学函数，却不是当前观察协议下的在线策略。

这条线的价值是把用户的时间怀疑从“运行多久”推进到“信息何时可用”。但必须先选真实 guarded/clocked/coinductive 接口；若该理论本来就通过 `later`、clock 或 causal morphism 强制因果性，结论应是防御成立。

### 7.2 guard 擦除

只有在固定以下四项后才重开：

1. source calculus 的 guard/clock 规则；
2. target HoTT 片段；
3. 明确的 forgetful translation；
4. 应被保持却被擦除的 observable。

研究问题不是“删掉时间会不会出错”这一口号，而是：翻译能否同时保持值、固定点方程和在线／完成性质。若不能，哪一项是不可兼得的？

### 7.3 同函数异时

“两个实现外延上算同一个函数但成本不同”本身并不构成悖论；函数外延性从未承诺复杂度相同。它应被并入 race/timeout/contextual-equivalence 研究：只有当一个实际 consumer 需要 deadline、竞争、取消或资源观察，却仍把函数 path 当作完整替换依据时，才有新的资格断层。

## 8. 独立验证线：R034 Cubical Agda

R034 的原生 Cubical Agda 核查值得做，但它是**验证线，不是发现主线**。

它能回答：

- path-indexed certificate 的具体陈述是否在真实 Cubical Path/Univalence/Truncation 下成立；
- 固定 Bool 对、实际 transport 和 `¬MereMove` 边界是否被纸笔说明准确表达；

它不能单独回答：

- A/B 哪条现实相对悖论已经成立；
- 数学 R041 的 race 是否在某个 partiality QIIT 上下降；
- RP-B01 的自然交付接口是否存在。

因此，环境可得时做原生验证；环境不可得时保持 `NOT_RUN`，不让安装或工具链问题长期占据数学主线。

## 9. 明确冻结或禁止作为主攻的路线

### 9.1 冻结重复性有限样本

- 不再增加 `later^n(now a)` 的同类枚举；
- 不再用 timeout 耗尽推断真实发散；
- 不再用更多自环图冒充一般余归纳定理；
- 只有引入新操作、新等价或新真实接口时才重开。

### 9.2 永久撤销错误自指公式

- `Map(1,G) ≃ G` 不是 loop space，也不提供 Gödel 编码；
- “元证明属于被证明对象的点”没有一般依据；
- “相邻宇宙角色相似所以等价”不能触发 univalence；
- 没有 syntax、substitution、evaluation、provability 和对角闭合就不能声称 HoTT 自指悖论。

### 9.3 不把一般定理换标题

- 一般停机不可判定不自动成为 HoTT 独有悖论；
- 一般 quotient 不支持非同余操作不自动成为 HoTT 核心错误；
- 函数等价不保存复杂度是一般事实；
- 只有 HoTT 的具体规则、构造或自然解释进入关键桥梁，才称 HoTT 实例；只有确有新机制，才讨论原创性。

### 9.4 不从物理隐喻直接得数学结论

Planck 尺度、宇宙离散、旋转、圆环和 Matrix 直觉可以提供候选形状，但必须给出真实物理 observable、数学模型和桥梁。没有桥梁时不得把物理叙述当作 HoTT 反例。

### 9.5 不让治理替代构造

来源审计、逐 claim 裁决和 R041 执行谱系补齐很重要，但它们不是新的悖论。每个数学研究单元必须交付至少一种实质增量：

- 一个新合法构造；
- 一个新正例／反例；
- 一个真实接口的保持或不保持定理；
- 一个被直接证据关闭的关键未知。

## 11. 决策树与停止条件

```text
候选是否固定了现实任务、HoTT 配置、抽象和后续操作？
├─ 否：不进入研究；先补合同
└─ 是
   ├─ 操作尊重抽象等价吗？
   │  ├─ 是：保留为正向控制，寻找真正丢失的资格
   │  └─ 否
   │     ├─ HoTT 规则拒绝形成/下降吗？
   │     │  ├─ 是：DEFENSE_WORKS
   │     │  └─ 否：检查是否有真实不健全性
   │     └─ 富化表示能恢复吗？
   │        ├─ 是：REPRESENTATION_BOUNDARY
   │        └─ 否：形成更强 no-go 候选
   └─ 是否存在自然 consumer 把较弱资格当成较强资格？
      ├─ 否：停止，不靠换例子维持活跃
      └─ 是：构造同任务现实/理论成对证据
         ├─ 反差只来自任务被改写：淘汰
         └─ 反差来自自然资格越级：NATURAL_USAGE_MISMATCH
```

全局停止条件：

- 三个连续变体只改变数字、命名或调度细节而没有新操作／新接口；
- HoTT 形成或消去规则已经清楚拒绝可疑步骤；
- 找不到自然 consumer，只有研究者人为强加的错误承诺；
- 结论完全由一般停机、一般商或一般复杂度事实给出，且 HoTT 没有进入桥梁；
- 无法保持“同一现实任务”，必须靠增加 oracle、全知未来、全域 checker 或额外输出才制造冲突。

## 14. 最终判断

如果只允许我选择一个总方向，我选择：

> **研究 HoTT 抽象所得“身份、存在、分类”在程序组合、时序使用、现实交付和自我反射中的资格保持性。**

如果只允许我选择下一个具体数学对象，我选择：

> **一个真实 HoTT partiality quotient/QIIT 上的 `bind` 与 `race/timeout` 对照，以及对应语言的 contextual equivalence。**

如果只允许我选择最终最值得追求的理论命题，我选择：

> **HoTT 作为逻辑、几何和程序的统一基础，可以合法拥有数学分类与内部结构，却不能无代价地把这些资格提升为统一有效交付和总的有效自我 ASK；任何自然流程若作出这种提升，都必须在明确实例上暴露其责任断层。**

这条路线的优势不在于它保证找到悖论，而在于它能保证每次研究都产生可判定的结果：要么找到自然资格越级，要么证明 HoTT 的防御生效，要么确定某种表示必须富化，要么关闭一个错误方向。它因此既保留用户要求的理论创新，也不会为了“必须发现”而牺牲数学诚实。
