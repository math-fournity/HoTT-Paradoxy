## 0. 摘要

1. W51（用户 `KC-000027`）是一句方向性判断：HoTT 把自己对齐到"逻辑+几何+程序"，因此程序的计算界限成为它自己的界限。本轮把它拆成三个可分别判定的强度：**W51-1**（局部经典分离，纸笔 + 抽象核机器化）、**W51-2**（一般"继承"命题，通用边界）、**W51-3**（HoTT 特有自然使用失配，= `B01-TARGET`，开放）。

4. 第三层验收判据（四条件）与判词阶梯被固定；A11.1 转 `PARKED`（重开条件=新版本/新接口/新消费者出现并满足四条件）。

## 1. W51 的精确命题化

### 1.1 固定配置（与 RP-B01 一致）

| 组件 | 内容 | 来源 |
|---|---|---|
| 理论片段 | HoTT 相应片段（含 ℕ、Bool、Π、Σ、空类型、命题截断）+ 命题排中律 `L : Π(P:U) isProp(P) → (P + ¬P)`，`L` 是给定项/公理数据，不是有效测试器 | RP-B01 `CONSTRUCTION.md` §2 |
| 计算模型 | 确定性的通用有效程序模型：有限代码 ↔ 自然数、输入编码、一步关系、有限步解释谓词 `T(p,x,n,v)` 可判定；`Halt(p,x) := ∥Σ n Σ v T(p,x,n,v)∥` | `CONSTRUCTION.md` §1 |

| 有效交付要求 | `Rep(χ)`：存在无神谕程序 `h`，使一切 `p,x` 上 `φ_h(〈p,x〉)` 有限步返回 0/1 且等于 `χ(p,x)` | `CONSTRUCTION.md` §4 |

### 1.2 三个强度的命题

**W51-1（局部分离，可交付）**
> 在固定配置下：`χ` 有合法数学规格；`¬ Rep(χ)`。

状态：纸笔推导（RP-B01 §3–§5）已存在；其**抽象核**已由本 repo 机器化——S053 的 T1 探针给出 Lawvere 不动点与"无精确自编码"；`MP-ERCF-001`（C-59–C-66）给出一般因子化的必要/充分方向、witness no-go、分离观察族 no-go（C-63）与 identity 观察控制（C-66）。具体 χ/`Rep` 在固定 HoTT 片段中的机器化仍 `NOT_RUN`（属 RP-B01 `PLAN.md` WP1/WP2）。

**W51-2（一般"继承"命题，通用边界）**
>  schema：若理论 `T` 具有有效呈现、能在内部表示 `χ` 与 `Rep(χ)`（可表示性条件），且 `T` 一致，则 `T` 不能内部证明 `Rep(χ)`。

状态：这是 Turing/Gödel 型标准结果在本配置下的实例化读法；本 repo 不把它作为新定理交付（C4 §13 已把"足够强 HoTT 拥有内部健全完备总真理判定器"判为 `NO_GO_UNDER_STANDARD_CONDITIONS`）。**它的成立与否不依赖 HoTT 特有规则**——RP-B01 §7 与 C4 §13 都明确这一点。

**W51-3（HoTT 特有失配，开放）**
> 存在真实、固定版本、可回查的 HoTT 使用方式（接口/工程/论文承诺），把 M 层数学分类（如 `χ`）当作 E 层有效交付，且其失败可在本 repo 工具链中核查。

状态：`B01-TARGET` 原文即"OPEN_ACTUAL_INTERFACE_NOT_IDENTIFIED"；N1（核心库/论文）、N2（提取接口，判 scoped `DEFENSE_WORKS`）、N5（派生开发自述）、N10（编译后端）四层审计后仍无候选。**W51-3 是本条线上唯一能升级为项目悖论候选的形态**。

## 4. 第三层（`B01-TARGET` / E6）验收判据

一个候选只有同时满足下列四条件，才允许把 `A11.1`／`DIR-W-RP-B01` 从 `PARKED` 升级为 `NATURAL_USAGE_MISMATCH` 候选：

1. **真实性**：固定版本、可回查的接口/工程/论文承诺（URL/commit/版本/行号可定位）；
2. **资格越级**：把 M 层数学分类或存在（LEM 或等价经典承诺）当作 E 层有效交付（同输入、同输出、同任务）；
3. **无新增假设**：不引入神谕、`Classical.choice` 之外的额外选择、用户实现映射、unsafe/外部运行或削弱后的输出规格；
4. **可核查性**：失败链（或防御链）能在本 repo 工具链中机器核查，或至少以固定来源 + 实际运行原始输出留证。

判词阶梯：满足四条件 → `NATURAL_USAGE_MISMATCH` 候选（进 F-011 机器化）；部分满足但带显式围栏 → 维持 `DEFENSE_WORKS` 并把围栏记入审计；不满足 → 维持 `PARKED`（重开条件=新版本/新接口/新消费者出现）。

保留 RP-B01 §6 的三条关键反校准（不得丢失）：

- `if H then 0 else 0` 有常值实现——**语法中出现 LEM 不证明输出不可计算**；
- 每个固定 `(p,x)` 的答案都是某个 Bool，因此存在返回该值的常量程序——**逐实例数学存在 ≠ 统一有效算法**；
- `noncomputable` 是特定声明的编译状态，**不是 `¬Rep(χ)` 的证明**。
