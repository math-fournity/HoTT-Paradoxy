## 2. Same-contract 审计

### `Q_CD` 与 `Q_Zeno`

```text
Q_CD   = 物理 determinism / robust continuation / canonical representation
Q_Zeno = 固定 runner 的过程完成：输入、操作、观察和 OriginDone
```

两者都牵涉 completion、continuation、极限／统一性和物理应用，但 source 自己在 §6.5 将 “code for same germ” 与 “recover a unique future” 拆开；因此更不能把它同用户的 runner completion 直接相同化。

### `M_CD` 与 bare ZFC

```text
M_CD = ZFC plus competing extensions (V=L / LC/PD)
```

v4 明确把 ZFC 称为标准基础，却以 extension differences来建论。它支持“physical predicate可对 set-theoretic metatheory 敏感”的 source candidate；它不支付“bare ZFC本身应有 Q_norm process audit”或“bare ZFC已犯错误”。

### `Bridge_CD`

最强正线索是 §5.5：source 自己使用 missing bridge语言。最强负控制同样来自该 source：它说 finite preparation→physical microstate completion尚未建立。由此得到：source 没有把 formal completion冒充现实 bridge；它把这一缺口留作独立义务。
