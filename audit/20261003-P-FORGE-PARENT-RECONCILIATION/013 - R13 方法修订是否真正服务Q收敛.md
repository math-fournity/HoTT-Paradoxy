## 3. P/Q影响：两项方法决定的共同范围

N33和N34各自保护不同、互补的误报风险：

```text
N33:
  CAL / source layer / station state
  prevents: fixture → new theory finding; proof layer → semantic/practice; round stop → station switch

N34:
  fixed Target-Q / Candidate-Q / Control-Q / Q-state transition / same-task falsifier
  prevents: tool, prompt, guard, Git or CAL accumulation → “Q is getting found”
```

它们一起使“锻刀＝发现Q”成为受来源约束的审计要求：每个方法修订都必须改变一张固定Q卡的状态、缩小候选空间、
补同卡bridge、淘汰候选，或有回归地防止固定卡被误报。否则它是`TOOL_ONLY_DRIFT`，不能消耗 P-FORGE 的研究迭代。

```text
Target-Q               = 防止方法演化脱离固定候选Q的发现／收敛过程
R13 Candidate-Q        = NONE
R13 Control-Q           = N33 CAL/layer/station contract + N34 QConvergenceLink contract
theory-Q delta          = NONE
Power Set state          = ZFC_SITE_SELECTED / Q-0 UNFORMED / ZFC_Q_NOT_LOCATED
```

“共同涌现”在此是工作流与证据成熟度概念，不是数学对象层状态机或自动发现保证。只有将来一张同一来源卡达成三刀
会合，才可据现有合同讨论`Q-4`；这仍不推出ZFC不一致、UR或数学定理。
