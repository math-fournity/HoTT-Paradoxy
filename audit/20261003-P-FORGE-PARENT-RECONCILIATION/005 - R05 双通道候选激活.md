## 3. P/Q影响：从单一 gate 到双通道的准确谱系

R05成员的可复算结果是两个不同的安全结论：

```text
H036/H037:  existence assertion ≠ source-declared supplied-object judgment
H038/H039:  declared formation operation ≠ automatically unpaid completion task
H040--H042: consumer-only balanced profile may return NONE within its fixed six-site bound
```

它们共同说明 R04 的单一 consumer-first Gate 有一个需要审查的边界，却不独立推出 F-lane 的合格条件。后来的
H048 才将原初“从已声明核心 formation 本身提出非存在重述的完成／资格／上升追问”的要求回写为 D-L10F；H049随后
验证该入口在 bare all-subobjects profile中可见，但仍诚实返回 `DIRECT_PAYMENT_ONLY`。这条时间与归属链必须保持：

```text
R05 child evidence       → consumer-only scope becomes visible
H048 (R06→R07 bridge)   → IDEA_SPEC_INCOMPLETE / EXECUTION_DEVIATION diagnosed and repaired
H049 (R07)               → F_LANE regression: restored, but no bare Power Set Q
```

在当前方法的词汇中，双通道的范围是：

```text
C_LANE = same-layer source C/I/O/Done + active demand + unpaid positive obligation
         → at most Q-2 after full source validation
F_LANE = profile/source-declared core u/F + non-existence-restatement completion/qualification/self-ascent probe
         + nearby control + specified future P2/P3 or consumer source
         → at most Q-1 / FORMATION_ORIGIN_PROBE; C/I/O/Done may remain UNKNOWN
```

因此 `F_LANE`不是“formation一出现就有Q”，也不是把静态存在公理解释为运行过程。它只恢复一条必须再被来源和
控制审查的发现入口。

```text
Target-Q               = 一个理论内声明操作是否留下未直接支付的资格／完成追问
R05 Candidate-Q        = NONE after H037/H039 and within H042's consumer-only profile
R05 Control-Q           = supplied-r source mismatch; RepFun direct payment; bounded no-candidate oracle
theory-Q delta          = NONE
ZFC_Q_LOCATED           = NO
```
