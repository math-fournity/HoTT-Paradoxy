## 2. H099-A：reversal 模型是强相关来源，仍未给 fixed H0 transport

### 2.1 一手来源的实际推进

Cavallo–Sattler 2026 已不只是一般的“有 cubical model”材料：

- 它直接指出原始 CCHM theory 含 `¬`、`∧`、`∨`，而 Cubical Agda 建基于它且标准库大量使用这些 interval operations；
- 它构造 strict cubical theories with reversals 的模型，并给出第一条其 homotopy theory 对应 spaces 的模型路线；
- 它同时明确限制：要得到带 reversal **和 connections** 的 strict theory 的相应空间模型，仍需要一个带 connections 的 input model；论文当时声明这种 input 尚未知。

这比 H098 的 CCHM family evidence 更贴近 `T_H`：H0 的 Cubical Agda environment 确实使用 reversal 与 connections。但它仍不能被改写成 full H0 translation。论文并未把 fixed `cubical v0.9` library、`EM₁`、`QuestioningDelay`、finite fuel、`never` 或 halt witness 放进其 theorem statement。

## 3. H099-B：foundation-language 不是 H0 的完成合同

- 它认真把 replacement 和 univalent completion 作为 foundational type-theoretic principles，并讨论 EM spaces、material set theory 与 cubical interpretations；
- 它给 `univalent completion` 的精确定义是一个 structural cartesian morphism 到 univalent family，底图为 surjection。它的 `Done_meta` 是结构性构造／image-completion 的完成，不是某个 Delay program 是否返回 `now k`。
