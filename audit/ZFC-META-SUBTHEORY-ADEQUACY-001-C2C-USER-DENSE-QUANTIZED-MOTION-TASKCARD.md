## 1. 要固定的任务

```text
Q_dense:
  state       = remaining distance in a dense continuum;
  operation   = move half of the remaining distance;
  observation = every finite natural stage has positive remaining distance;
  done        = exact endpoint reached by finite process stage.

Q_quantized:
  state       = remaining distance in a discrete lattice with minimum unit;
  operation   = quantized half-step rule;
  observation = finite remaining-unit count;
  done        = remaining distance is zero.
```

The purpose is not to claim a physical theory. It is to provide a mathematical control for the user’s proposed reality-relative contrast: an infinitely divisible model can retain nonzero remainder at every finite stage while a fixed discrete control can reach zero.
