## 1. 必须重新选择的原因

C5 不再是一个空字段。它现在已经分辨了：

```text
foundation's mathematical-representation role
≠ logical-model truth
≠ applied representational-model target/accuracy responsibility.
```

并且 Norton/IEP 对 fixed strict Q 的来源路线给出 explicit task switch。因此，继续把当前 Mizar component 或 C-364 fixture 当作 bare-ZFC failure 的“下一步”会构成 `SURROGATE_INTERFACE_DRIFT`。

## 3. 下一最高判别行动

当前最有价值的缺口不是再找一篇“数学可以解芝诺”的说明，而是测试 `F-B` 是否能给出一个可进入同一来源链的 **版本固定 ZF 实分析 sequence/limit resource**。理由：

1. 若这条资源存在，它会首次使 `M → S → FormalDone` 从“real model”推进到实际连续统 theorem，并可随后严格审 P consumption；
2. 若它不存在或只给一般 topology/metric infrastructure，这个结果会收紧 F-B，而不是增加一个新的 toy proof；
3. 它不预设 bare ZFC failure，也不重复已经排除的 proof-checker / generic Gödel 路线。

因此唯一选中的后继为：

```text
C1C-ISAR-ZF-CONTINUUM-SEQUENCE-INGRESS

在已冻结 IsarMathLib commit 的实际 ZF library tree 中，
基于 Real/Metric/Uniform/Topology paths 做有界 source search：
寻找 sequence, Cauchy, convergence, limit 或 geometric-series theorem。
若只找到 real/metric/topology/supremum infrastructure，记录
FORMALDONE_IDENTITY_UNPAID，而不把 infrastructure 重命名为 Zeno theorem。
```

## 4. 固定合同与停止条件

| 字段 | C1C 预定值 |
|---|---|
| `M` | `IsarMathLib@e0d7f7d8… / Isabelle-ZF`，仅 source-reported，除非本地 checker 得到资格化。 |
| `S` | 固定 commit 中 real/metric/uniform/topology modules。 |
| `Q` | 仍是 IEP runner task；不因 source search 自动获得 payment。 |
| `FormalDone` | 仅当 actual sequence/convergence theorem 被发现才写入。 |
| `P` | IEP P；须与发现 theorem 明确对齐，不能默许。 |
| `Bridge` | strict/revised split 保持为来源控制。 |
| `Adequacy` | C5A–C5C 已给双层角色与分层控制。 |
| 最强 falsifier | 发现 exact theorem 已被 IEP/Norton P 明确消费且同源支付 bridge，或发现 source 明确禁止此类 search inference。 |
| local stop | 源树中的已选 sequence/limit ingress 要么给出 exact theorem，要么只给 infrastructure；无论结果都转 successor scan。 |

## 5. 禁止外推

- filename / keyword absence 不能证明整个 IsarMathLib 或所有 ZF formalization 没有可用 theorem；
- Isabelle source 有 complete reals、metric 或 topology 不能证明 runner arrival、IEP promotion 或 bridge；
- 新的 source gap 只能关闭 C1C leaf，不能结束 C0–C6 Goal；
- 不把 C5 的 application responsibility split 写成“bare ZFC 已无问题”或“bare ZFC 已有问题”。
