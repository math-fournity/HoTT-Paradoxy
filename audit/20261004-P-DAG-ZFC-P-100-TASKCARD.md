## 1. 唯一问题

将已经形成的候选

```text
CompletionSubstitutionP =
  a source uses a formal/model completion outcome to declare an origin process
  task resolved, while no source-defined bridge proves that the formal Done
```

## 3. P 的精确工作定义

本轮不将 P 定义成“极限错误”或“任何完成定义变更都非法”。本轮只检查以下三项能否由来源逐项填实：

```text
R1. SourceResolution:
    source calls the named/origin problem resolved or completed.
R2. CompletionReplacement:
    source's admitted Done differs from a stronger origin-Done field.
R3. SameTaskPayment:
    source supplies a bridge/preservation condition showing the admitted Done
    discharges that same origin task.

P-source-candidate = R1 + R2 + absence/unavailability of R3 in the frozen
source scope.  “absence in scope” is not a proof that no bridge exists.
```

若 `R2` 被明确写出，这是一张 `SOURCE_DONE_REPLACEMENT_EXPLICIT` 卡。只有用户的 `Done_origin` 与来源要求的原任务经同一任务审查后仍保持，才可讨论“数学幻觉”的现实相对归因。若来源明确改题，则本轮正确判词是 `TASK_SWITCH_EXPLICIT`；若来源还支付了同一任务保持桥，则是 `PAYMENT_VISIBLE`。

## 5. QConvergenceLink、站位与停止

```text
Target-Q      = source-defined actual completion substitution that is still
                claimed to settle an origin task.
Candidate-Q   = ZFC-CIRCLE-Q0/Q1 completion-contract bridge question.
Control-Q     = explicit task switch/payment and explicit interpretation-bridge
                requirements.
activation     = C_LANE source comparison; no F_LANE or Power Set formation.
Q before/after = Q-1_SEED; expected result is Q_NARROW or Q_BRIDGE diagnosis,
                 never Q_CONVERGE from this pair alone.
same-task falsifier = a source-provided statewise preservation/equivalence
                       bridge, or a source that explicitly says it solves only
                       a different task without reusing the origin label.
station impact = Power Set remains STATION_EXIT_REVIEW_PENDING / NO_CHANGE.
CAL impact     = no blind calibration change; `CAL-*` unchanged.
```

Stop this unit if either source card does not supply `R1/R2/R3` facts beyond existing records, or if the cards cannot be compared without silently imposing the user’s origin-Done on a source that explicitly owns a different task. A resulting source mapping can refine P's definition and source frontier; it cannot establish `ZFC_Q_LOCATED`, actual ZFC inconsistency, or `P → B` without a further shared task card.
