## 4. 证据边界

本综合不把下列事实合并：形式来源的定理／证明包、模型或内模型解释、实际数学消费者、运行时程序行为、现实过程、blind model output与Master方法决定。App Server trajectory只支持可见session、turn、权限、输入与terminal等范围；隐藏推理保持不可见。没有一张卡单凭超时、循环、proof-theory stage、rank successor、代码引用或历史AI自述而被升级为理论矛盾。
