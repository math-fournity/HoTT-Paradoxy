## 3. 研究型工作方式的判定

本次历史审计符合 `RESEARCH_PROFILE_GOVERNED / COMPOSE_FROM_OWNERS`：它跨多个会话、来源层和方法修订，结论会改变
未来ForgeIntent的准入、Power Set station与Q分类；但现有SOP、账本、campaign、父级回接、Feature/rulings/MEMORY
已经承担Program/Topic/plan、证据与恢复职责。因此没有新建第二张研究地图、Host Goal、worktree、worker或后台监控。

当前活跃方向在本任务内已经闭合。新的理论研究只有在研究发起人另行恢复`P-FORGE-SOP`后，才由一张新的、最小的
ForgeIntent进入；A3不授权它。

## 4. 停止、重开与下一次有效入口

本次审计现在停止于`ATOMIC_AUDIT_COMPLETE_WITH_SCOPE`。重开只能由相称事实触发：

1. 新发现的实际P-FORGE执行、pre-sampling attempt、可辨认的child session或改变P/Q准入的Master decision；
2. 已登记source、raw identity、终态、parent归属或同一任务判词被直接推翻；
3. 未来来源提供本表某项财富所要求的同层对象、consumer、bridge、state或Done，且能以新的ForgeIntent冻结。

新的ForgeIntent至少要写：`Target-Q`、`Candidate-Q`、`Control-Q`、当前与预期Q状态、C/F lane、
`SourceLayerTarget`、CAL、Power Set station影响、同一任务反证、来源／权限、停止和重开条件。若它只补字段、加
guard或重复已关闭来源而没有固定卡的Q状态变化或`Q_SAFETY_REPAIR`，必须停止为`TOOL_ONLY_DRIFT`。

**A3最终判词：** `ATOMIC_AUDIT_COMPLETE_WITH_SCOPE / P_Q_CO_FORGING_METHOD_SUBSTANTIATED_WITH_SCOPE / ZFC_SITE_SELECTED_Q0_UNFORMED / ZFC_Q_NOT_LOCATED / NO_NEW_BLADE / NO_AUTOMATIC_NEXT_NODE`。
