## 2. `AS_RUN`：包接口拒绝把 `Pow` 当作其自身的有界固定点生成器

`Fixedpt.thy`定义的关键前提是：

```text
bnd_mono(D,h) ≡ h(D) ⊆ D ∧
  ∀W X. W ⊆ X ∧ X ⊆ D → h(W) ⊆ h(X)

lfp(D,h) = ⋂ {X ∈ Pow(D) | h(X) ⊆ X}
bnd_mono(D,h) → lfp(D,h) = h(lfp(D,h))
```

因此当前source package并不是把任意单调算子直接自用。对于`h=Pow`，冻结Source B卡报告没有一个满足`Pow(D)⊆D`的合适集合域；`Fin(A)`则是输出仍限制在`Pow(A)`的另一个生成器。前者由guard阻断，后者是不同的control task，不能支付前者的guard。

```text
Target-Q (overall theory target) = ZFC/Power Set仍为Q-0
Candidate-Q (as run)             = NONE
Control-Q (as run)               = `h=Pow`能否在保持Fixedpt guard时成为同层未支付义务
Q state before/after             = Q-0 UNFORMED / Q-0 UNFORMED
as-run Q delta                   = Q_NARROW_WITHOUT_CANDIDATE_Q
```

H060的有界结论是`CANDIDATE_GUARD_BLOCKED / PACKAGE_SCOPE_ONLY`：这是proof-package中的域闭合门，而不是罗素式Q、标准ZFC的整体解释或一个时间／时序过程。
