## 2. `AS_RUN`：同一卡上的 L6/L7 直接付款与普通 false branch

H022没有重选对象。其公开 MatchTrace 的三个有关事实是：

1. `f ∈ powerset(prod x y) ↔ f ⊆ prod x y` 已是 `F` 给出的 membership translation，故不是独立 L6 问题；
2. `IsFunc x y f` 与 `f ∈ funs x y` 是 ordinary classification query，false 分支可正常结束，故没有 L7 所需的正义务；
3. source card没有 existential/function-construction action，也没有必须以一个新事实才能完成的 source-level Done。

```text
Target-Q (as run)    = H021 formal-model consumer 是否要求 distinct, non-direct, positive Q
Candidate-Q (as run) = NONE; tested membership/classification readings are directly paid or normally false
Control-Q (as run)   = mem_powerset payment + ordinary false branch + source card's absent positive obligation
Q-state delta        = Q_NARROW_WITHOUT_CANDIDATE_Q
```

终态 `QUALIFYING_FORMAL_MODEL_CONSUMER_WITH_SCOPE / NO_DISTINCT_Q / Q_UNSET / NO_COMMON_Q` 因而只覆盖版本固定的 Mathlib API excerpt。它没有证明 ZFC 没有候选 Q，更没有给出 ZFC 不一致或现实对应结论。

## 3. 当前 P-FORGE 合同下的反事实

今日重放会通过 input-contract：父 `T/u/F/C/I/O/Done` 已完整冻结，source layer 也被明示。它会在 L6/L7 的同一卡检查中排除已付 membership 和 ordinary false-branch 读法，故依然不生成 Candidate-Q。
