## 2. `AS_RUN`：lineage被携带时，特定快照塌缩被直接支付

H055的公开D1把完成条件写成：同一`S`、不同`L`的endpoint仍然可区分。D3进一步说明，旧的snapshot-only扭曲只有在一个额外、未给定的projection再次丢弃`L`，或禁止consumer检查`L`时才会重现。因此该synthetic task中，`L`是对原题所述身份信息的直接支付，而不是P1/P2/P3的会合。

```text
Target-Q (overall theory target) = ZFC/Power Set仍为Q-0
Candidate-Q (as run)             = NONE
Control-Q (as run)               = H054的snapshot-only identity clue能否在携带L后保持
Q state before/after             = Q-0 UNFORMED / Q-0 UNFORMED
as-run Q delta                   = Q_CAPABILITY_CALIBRATION_WITH_SCOPE
```

这项校准的正向半边是H054的“same snapshot may erase lineage”，反向半边是H055的“full `(S,L)` lets the task distinguish endpoints”。它只证明在这对冻结合成输入上，模型能区分表示塌缩与直接支付；它不证明所有集合式表示都保存历史，也不产生理论级Candidate-Q。

## 3. 当前 P-FORGE 合同下的反事实

现行合同会保留该反控制，但会把它的结论再收紧一层：

```text
P1 = 这里的identity task是合成consumer，不能填成实际理论C/I/O/Done
P2 = 表示已保留lineage；不存在由snapshot equality强制的same-object collapse
P3 = 过程步骤和endpoint完成都已给出；无未付admission/Done
Candidate-Q = NONE
theory-Q delta = none
```

因此`DIRECT_PAYMENT_ONLY`只针对本题设的identity gap。它拒绝两种越界：把H054写成“集合论不能表达历史”，或把H055写成“所有历史身份问题都已解决”。未来的真实来源若明示consumer只能见`S`、却仍要求按历史区分continuation/reconstruction，H055正是那个来源必须跨越的反控制。
