## 2. `AS_RUN`：被提出、被拒绝的候选

代理固定一个带层级 Tarski universe、W-types、命题截断和 univalence 的 predicative HoTT 变体，选取

```text
u = W_U = W(a : U_i). El(a)
```

然后额外引入一个向下 smallness／resizing 证书 `s`，并条件性地构造自子树边。它把“`s` 是否存在”写成
`ACTIONABLE_CANDIDATE`。Master 当时已经逐项拒绝该候选：

1. `W_U` 只在代理自定的局部内部迭代树变体中变得不可省，不能替代 HoTT 的明显 identity／universe 主线；
2. `s` 不是冻结理论本身承诺的 formation 规则；
3. W-elimination 使用的是已经取得的 `W_U`，而 Q 却改问外加 `s`，没有“尚未落定却被同一理论预支使用”；
4. Done 从原理论任务换成“若添加 resizing，子树环是否出现”。

```text
Target-Q (as run)    = HoTT 原生对象／formation 在同一任务中是否留下未付完成追问
Candidate-Q (as run) = W_U + external resizing certificate s
Control-Q (as run)   = predicative universe hierarchy / no-resizing boundary
actual delta          = candidate rejected with the declared task scope
```
