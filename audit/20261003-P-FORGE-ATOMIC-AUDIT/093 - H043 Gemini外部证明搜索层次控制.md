## 2. `AS_RUN`：外部 proof search 不是 ZFC native consumer

H043固定五个不能混写的层：被提及的 ZFC 公理／规则、外部 `TM_zeta`、外部 `Verify`、换目标后的 `M_prime`、以及独立 UA 段。来源没有声明 ZFC object-language service、输入输出 Done、construction-admission state或 native Q。

```text
Target-Q (as run)    = Gemini草稿是否为ZFC提供同层 P1 consumer / Done / active Q
Candidate-Q (as run) = NONE
Control-Q (as run)   = external proof search/verifier, changed target, and later UA extension
Q-state delta        = Q_NARROW_WITHOUT_CANDIDATE_Q
```

`TM_zeta`的 halt 即使作为外部程序事件，也不是来源声明的 ZFC Done；把固定 `¬RH`的程序与`T_M_I`目标的程序拼接，会改变目标和任务。草稿说 `Verify`或`TM_zeta`“图灵完备”、或把扩张的不自洽归到ZFC，都没有在其已写出的接口中补齐所需桥梁。H043不替这些缺口发明证明或反例。
