## 2. `AS_RUN`：P映射可读，PowerSetDefenseLedger失去字段语义

H065的E3忠实保留：`u=Vrec(a,H)`、`F=Vrec/Vfrom`、`C=source recurrence/recursor proof use`、`I`仅为lower-rank `x∈Vset(rank(a))`、`Done`仅为proof use。E4/E5随之给出来源支持的有限读法：

```text
Vrec(a,H) = H(a, λx∈Vset(rank(a)). Vrec(x,H))
x ∈ Vset(rank(a)) → rank(x) < rank(a)
```

这不构成same-`a` reentry、negative bridge或P3 lifecycle。可是E6没有回答诸如“实际guard是什么”“guard scope何在”“PS4是否有candidate surplus”等问题，而是把`Vfrom`、successor、limit、rank和guarded inclusion依次排为PS0–PS6。这是ledger字段职责漂移。

```text

P1/P2/P3 delta                   = Q_NARROW_WITHOUT_CANDIDATE_Q, source-P-map scope only
PowerSetDefenseLedger             = Q_STATUS_UNINFERABLE_FROM_EVIDENCE
```


因此H066的最小回归修复不是重问Vrec数学，而是锁定E6字段语义。它既不能把H065的E6伪装为PASS，也不应否定H065已经产生的受限P1/P2/P3来源读法。
