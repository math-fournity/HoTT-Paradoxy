## 2. `AS_RUN`：关系本身没有自动成为任务消费者

重跑明确把card中的集合、membership、Power Set existence、有界Separation、Replacement、Foundation限定为可用材料。
它提出两个路线：

| 路线 | `u/F` | `C` | `Q` | 结果 |
|---|---|---|---|---|
| A | 已给 `a` 与card提供的 `p` | 无source-defined consumer | `b∈p` | L0/L1/L4可过；L2b/L5/L7失败。 |
| B | `a` 与 `p` | 无source-defined consumer | `p∈p` | direct self-loop exclusion。 |

最小链 `a set → card supplies p → atomic query b∈p` 只有关系事实：true是positive fact，false没有被写成任务失败，
任何要求构造p、决定query或消费结果的程序都超出card。因此不是“membership这个词不允许问”，而是这张来源卡未给
input/output/Done contract，不能让裸relation占据 `C`。

```text
Target-Q (as run)    = Power Set站位中由source-defined consumer提出的、未支付的positive obligation
Candidate-Q (as run) = NONE；路线A/B均未取得C/I/O/Done
Control-Q (as run)   = membership relation-only、self-loop route、true/false/blocked分支
theory-Q delta       = Q_NARROW_WITHOUT_CANDIDATE_Q
```

## 3. 当前合同下的 QConvergenceLink

N23把P1的入口门从“对象存在＋relation可写”收紧为“source-defined consumer contract”：

| 项目 | 当前反事实判词 |
|---|---|
| L2b | `C`必须有来源定义的input/output/Done；裸predicate/relation不自动是consumer。 |
| Candidate-Q | `NONE`；路线上没有可冻结的I/O/Done，不能交给P2/P3。 |
| QConvergenceLink | `Q_NARROW_WITHOUT_CANDIDATE_Q`：收窄中性Power Set card可承担的候选空间，并保护未来卡不把静态relation伪装为任务。 |
