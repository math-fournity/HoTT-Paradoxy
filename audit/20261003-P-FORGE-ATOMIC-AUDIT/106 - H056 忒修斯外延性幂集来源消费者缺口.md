## 2. `AS_RUN`：外延相等不是历史身份consumer

冻结source card只有两类正面事实：`ax-ext`说对所有成员的agreement推出集合相等；`pwex`报告以class notation写出的幂集membership assertion及其proof-system derivation。公开E2--E7正确分层：前者给静态对象与memberwise equality，后者给formal proof acceptance；二者都没有给出“一个下游任务以extensional equality完成diachronic identity”的规则。

```text
Target-Q (overall theory target) = ZFC/Power Set仍为Q-0
Candidate-Q (as run)             = NONE
Control-Q (as run)               = H054的trace/snapshot/identity花纹能否落在ax-ext/pwex source
Q state before/after             = Q-0 UNFORMED / Q-0 UNFORMED
as-run Q delta                   = Q_NARROW_WITHOUT_CANDIDATE_Q
```

这个`Q_NARROW`排除的是窄读法：“只凭该extensionality／power-set packet就可说历史被压成当前快照、且仍被同一身份任务消费”。它没有排除其它来源、其它消费者或Power Set的所有可能研究路径。

## 3. 当前 P-FORGE 合同下的反事实

若按现行P1/P2/P3会合合同重放，H056的ledger应保持：

```text
P1 object/task             = static set/class objects; no source-defined diachronic task C/I/O/Done
P2 equality/representation = memberwise extensional equality; no trace/provenance type or projection
P3 trace/admission         = not supplied; no stages, scheduler, admission, lifecycle or Done

```

这张来源卡能支持`SOURCE_TRACE_CONSUMER_ABSENT_WITH_SCOPE`，不能支持“ZFC已经防住了历史身份问题”。形式化证明页的Done属于其proof-system层；它不应被移作对象层历史身份的Done，也不能因`ax-ext`涉及同一性就自动填入P2的same-object reentry。
