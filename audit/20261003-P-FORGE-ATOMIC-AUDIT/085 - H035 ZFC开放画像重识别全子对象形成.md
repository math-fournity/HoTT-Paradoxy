## 2. `AS_RUN`：正确重识别位置，未形成合格 secondary selection

H035的输入是开放画像，故输出“全子对象形成”可能来自 profile 中未穷尽的理论知识，而不是对给定菜单的二次排序。它的实际价值是测试 P1能否在不泄露名称时回到显眼 formation；它没有固定 `T/u/F/C/Q/I/O/Done` 来源卡，也未给出合格终端格式。

```text
Target-Q (as run)    = P1能否无泄漏重识别一个明显基础承诺
Candidate-Q (as run) = NONE; no source card or active native task was fixed
Control-Q (as run)   = deidentified open profile with Power Set phrase withheld
Q-state delta        = Q_CAPABILITY_CALIBRATION_WITH_SCOPE
```

报告的正确有限判词为：

```text
MODEL_RECALL_POWERSET_REIDENTIFICATION_WITH_SCOPE
FAIL_OUTPUT_OR_TOOL_CONTRACT
NOT_A_SECONDARY_TARGET_SELECTION
```

它不能推翻 H019的 direct-payment control，也不能证明 Power Set已经进入 `Q-1`。

## 3. 当前 P-FORGE 合同下的反事实

今天若测试“secondary selection”，profile必须成为闭合菜单，并清楚说明哪些站位暂时不可选；terminal还须满足 D0--D5与 literal candidate/no-candidate token。H035原始运行在今天只能保留为：

```text

station impact   = Power Set reidentification, not secondary-site selection
Candidate-Q       = NONE
```

它不能在当前合同下升级为 `ZFC_SITE_SELECTED`的新证据，因为 H019已经完成该站位选择；H035只是一个无泄漏重复校准。H036才以关闭菜单测试条件性第二选择。
