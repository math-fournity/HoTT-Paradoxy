# H024 ZFC相对模型幂集层级控制

> **AtomicAuditCard：** `H024 / H_NUMBERED_NODE / R04_RELATIVE_MODEL_SOURCE_MATCH / ATOMIC_AUDIT_COMPLETE_WITH_SCOPE`。

H024以 H023 的唯一 marker 修复重跑 Isabelle2013-1 的 relative-powerset source。它正确把“内模型 `M` 的 powerset 与外部 `Pow(x)` 的一向关系、且不绝对”归为相对模型的层级边界：外部 `Pow(x)` 是比较项／证明见证，不是 `M` 内部的下游消费者任务。因此它是 P1 的层级控制，不能作为 standard-ZFC Q 的候选或反例。

## 2. `AS_RUN`：外部比较不是内部 consumer

H024的公开 MatchTrace 给出：relative-model／one-direction powerset correctness 是 source-supported，但 same-layer internal consumer with `I/O/Done` 与 L6/L7 后仍存活的 positive Q 均为 `NOT_SUPPLIED`。其关键同一任务区分是：

```text
Target-Q (as run)    = relative-model powerset difference 是否是 M 内部 consumer 的正义务
Candidate-Q (as run) = NONE
Control-Q (as run)   = external Pow(x) comparison/proof witness versus internal M-level consumer
Q-state delta        = Q_NARROW_WITHOUT_CANDIDATE_Q
```

`powerset(M,x,y) ∧ M(y) ⇒ y ⊆ Pow(x)`是一向包含，并不令 `y` 与外部幂集相等。没有 source-supplied internal downstream consumer、输入输出 Done 或 source-positive obligation 时，不能从“Powerset is NOT absolute”跨层推出 ZFC 的 Q。

今日 H024会通过 input-contract：frozen source delimiters正确，H023的失败与 H024的理论判词仍严格分离。当前合同会先标：

```text
SourceLayerTarget = relative-model / metatheoretic comparison
C/I/O/Done        = NOT_SUPPLIED for an internal M-level consumer
Candidate-Q        = NONE
P2/P3              = NOT_ADMISSIBLE_ON_Q_UNSET_CARD
```

它因而仍是一个 `Q_SAFETY_REPAIR` 和层级判定控制：防止模型内外差异被无声提升为对象层、standard-ZFC 或现实任务。它不说 relative-model theorem 没有数学价值，也不说所有未来来源都不能给同层 consumer。
