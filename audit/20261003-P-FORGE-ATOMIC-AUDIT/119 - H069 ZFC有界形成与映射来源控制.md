# H069 ZFC有界形成与映射来源控制

> **AtomicAuditCard：** `H069 / H_NUMBERED_NODE / R10_COLLECT_REPLACE_REPFUN_BOUNDARY_SOURCE_CONTROL / ATOMIC_AUDIT_COMPLETE_WITH_SCOPE`。

H069 直接考察 documented Isabelle ZF 的set formation interfaces：`Collect(A,P)`、`Replace(A,Q)`、`RepFun(A,f)`与`Pow(B)`。它们都以已给set domain为边界，Replacement还要求在该domain上single-valued，`RepFun`需要给出domain才能得到set。保留这些条件后，冻结来源没有actual same-task Q、negative reentry、lifecycle或未支付formation remainder。这是对“任意predicate/class-function会一次性形成set”的具体来源控制。

## 2. `AS_RUN`：形成接口有domain／single-value／subset guard

H069的E4/E5没有把P或Q/f偷换为无界class formation。它把source的每项承诺严格写为：

```text
Collect(A,P)  = subset formation inside supplied A
Replace(A,Q)  = image/replacement over supplied A under single-valuedness
RepFun(A,f)   = functional image over supplied A
Pow(B)        = subset-bounded membership
```

没有来源事实提供一个与之不同、仍在同一TaskCard中active的“形成所有满足任意条件者”的Q。

```text
Target-Q (overall theory target) = ZFC/Power Set仍为Q-0
Candidate-Q (as run)             = NONE
Control-Q (as run)               = bounded separation/replacement留下的formation residue是否构成same-task Q
Q state before/after             = Q-0 UNFORMED / Q-0 UNFORMED
as-run Q delta                   = Q_NARROW_WITHOUT_CANDIDATE_Q
```

`PS1`在该冻结摘录中并没有直接说明某个Russell feature；源可支持的是操作接口被given-domain、single-value或subset条件约束，不能从这个缺失的历史机制说明外推“ZFC已经全面防住罗素”。

## 3. 当前 P-FORGE 合同下的反事实

当前P1/P2/P3会将卡保持为：

```text
P1 = documented formation interface, no separate active consumer C/I/O/Done
P2 = no source-defined negative self-reentry or same-object bridge
P3 = no runtime construction/admission lifecycle
PS2 = explicit domain/single-value/subset guards
PS4 = ABSENT/UNSUPPORTED on frozen source card
Candidate-Q = NONE
```

移去`A`的set-domain或把Q/f换成任意unrestricted class-function会改变文档描述的interface；冻结来源不授予这种改变后的set formation，也不自动把它变成active Q、运行过程或理论缺陷。
