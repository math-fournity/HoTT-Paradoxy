## 2. `AS_RUN`：单项权限修复不足以资格化来源节点

H026没有改变来源和候选，却仍在模型采样前停止。它的可审信息不是“inner-model source 没有 consumer”，而是单项 safe-home 许可不足以让这一运行链达到 source-match。

```text
Target-Q (as run)    = H025 concrete inner-model card是否产生same-layer positive Q
Candidate-Q (as run) = NOT_SAMPLED
Control-Q (as run)   = safe-home readability repair versus still-unqualified workspace ancestry
Q-state delta        = Q_SAFETY_REPAIR; all source/theory Q states unchanged
```

H026因此不能补写 H025缺少的 E0--E7，也不能用“配置显示 allowed”代替 terminal evidence。

## 3. 当前 P-FORGE 合同下的反事实

当前 App Server isolation contract要求两个正面条件同时满足：run-generated safe home instructions 可读，且 experiment root、`CODEX_HOME`和text-only workspace都在业务项目根之外；后者用于避免从祖先目录发现项目 `AGENTS.md`。H026若按今天合同启动，应当在 source worker启动前被拒绝或改用项目外 root：

```text
INPUT/ENVIRONMENT_CONTRACT_FAILURE / NO_AGENT_OUTPUT
reason = project-descendant experiment root remains disallowed
```

这将 H026定位为运行链修复的反控制，而非 source source-match。H027对两个环境条件同时满足的实际重试才能承载来源判词。
