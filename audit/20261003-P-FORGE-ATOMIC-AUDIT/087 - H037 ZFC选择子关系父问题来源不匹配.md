## 2. `AS_RUN`：保存 parent，而不是重选更容易的存在式

H037的价值恰在于没有把“是否有某个 selector”拿来替代“给定 r 是否选择”的父问题。来源中的 `∃z∈Pi(A,B)` 可能支付存在式，但它没有激活、判断或完成 H036的 supplied-r task。

```text
Target-Q (as run)    = H036 supplied-r selector judgment是否有source-native consumer
Candidate-Q (as run) = NONE after source validation
Control-Q (as run)   = source existential selector assertion versus parent supplied-r judgment
Q-state delta        = Q_NARROW_WITHOUT_CANDIDATE_Q
```

这形成有限结论：`PARENT_Q_NOT_SOURCE_NATIVE / SOURCE_CONSUMER_GAP`。它不是“Choice 没有数学用途”、不是 bare ZF 结论，也不是 ZFC Q 的反证。
