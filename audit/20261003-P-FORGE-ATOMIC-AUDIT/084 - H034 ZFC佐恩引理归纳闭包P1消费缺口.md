## 2. `AS_RUN`：对象语言构造与 theorem witness 未会合为同一 consumer

H034可以指出显眼的 object/interface 位置，也可以描述 `Power Set → choice function → next → TFin → Union` 的静态证明关系。但 source没有将这些关系封装为一个当前 consumer任务及其输入、操作、输出和 Done：

```text
Target-Q (as run)    = Zorn/TFin card 是否含同层 consumer的当前未支付正义务
Candidate-Q (as run) = NONE
Control-Q (as run)   = object-language definitions/static closure versus proof-system theorem witness
Q-state delta        = Q_NARROW_WITHOUT_CANDIDATE_Q
```

`c∈maxchain(S)`是Hausdorff theorem的proof conclusion，不能在没有来源任务合同的情况下承担 P1 consumer Done。把 object-level set expression和proof-system acceptance拼接在一起会违反 L2c；把它们写成单一 process会改变输入／Done。
