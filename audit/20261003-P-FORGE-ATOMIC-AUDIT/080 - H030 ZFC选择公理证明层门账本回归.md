## 2. `AS_RUN`：同一 proof-system 卡中 Q 已被支付

H030保持 source layer 与任务不变，公开 ledger 给出完整的限制：

```text
AC → AC_Pi → AC_func → AC_func0 → AC_func_Pow = Q
```

`Pow(C)-{0}`只形成 choice domain，不能单独构成 choice function；若把 formal derivation的完成当作任务，Q具有历史的 positive-obligation 形状，但 source packet里的 AC链已交付其 proof-system conclusion。因此：

```text
Target-Q (as run)    = proof-system choice-function theorem 是否有当前未支付义务
Candidate-Q (as run) = NONE for a current P1 tension; Q is a completed theorem conclusion
Control-Q (as run)   = visible AC-to-AC_func_Pow proof/payment chain
Q-state delta        = Q_SAFETY_REPAIR / Q_REJECT_WITH_SCOPE at the proof-system P1 path
```

这不等于对象层的 `f` 被构造，也不等于任何现实／计算任务完成。它只关闭该 source packet 内“P1当前未支付义务”的解释路径。
