## 2. `AS_RUN`：编码或换目标不构成同一对象再入

H047逐项区分 represented object、code、evaluator、result和result是否回流。外部 verifier只检查输入公式；`M_prime`改用不同目标不是固定点；`G(RH)`与UA文字没有建立可执行的对象语言再入。

```text
Target-Q (as run)    = 历史草稿是否给出同一ZFC对象的P2 logical re-entry
Candidate-Q (as run) = NONE
Control-Q (as run)   = formula input, target substitution, Gödel-code reference, and UA prose
Q-state delta        = Q_SAFETY_REPAIR / P2_NOT_APPLICABLE_ON_THIS_SOURCE
```

这不否认可存在真正的对角化、Kleene固定点、quotation或证明谓词；只是该固定草稿没有供应其精确接口，也不能用外部目标替换拼出它们。

## 3. 当前 P-FORGE 合同下的反事实

当前 P2要求 source给出表示、bridge、reentry、polarity/guard与同一对象消费链。H047在现行合同下仍为：

```text
CURRENT_CONTRACT = ALIGNED_P2_DIFFERENTIAL_CONTROL
P2               = REIFICATION_WITHOUT_SAME_OBJECT_REENTRY /
                   P2_LOGICAL_REENTRY_NOT_SUPPLIED
Candidate-Q       = NONE
```

将草稿的 `¬RH`、`T_M_I`、`G(RH)`和UA段合并为同一个系统或对象，会改变任务、语言与证据层；这是当前合同明确禁止的拼卡。
