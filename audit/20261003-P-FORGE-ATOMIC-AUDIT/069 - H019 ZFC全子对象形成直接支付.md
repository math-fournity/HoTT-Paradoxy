> **AtomicAuditCard：** `H019 / H_NUMBERED_NODE / R04_ZFC_DEIDENTIFIED_P1_DISCOVERY / ATOMIC_AUDIT_COMPLETE_WITH_SCOPE`。

## 2. `AS_RUN`：明显 formation site 被直接支付

冻结 profile 给出 total closure：对每个集合 `a`，形成接口交出 `B(a)`，并规定 `x ∈ B(a)` 当且仅当 `x` 的每个成员都在 `a` 中。它没有给 concrete consumer、成员枚举算法、任意 membership query 的答复或既有候选。D-L5--D-L9 和 D-L6b 已在当时 prompt 中；D-L6 明确要求：若 `F` 本身给出所问任务的答案，输出 `DISCOVERY_DIRECT_RULE_ANSWER`。

实际公开终态恰好如此：

```text
formation task B(a): DISCOVERY_DIRECT_RULE_ANSWER
terminal: NO_MODEL_RECALL_CANDIDATE / DIRECT_PAYMENT_ONLY
```

```text
Target-Q (as run)    = 在脱敏集合论 profile 中，P1 能否区分明显核心 formation site 与尚未支付的候选 Q
Candidate-Q (as run) = NONE；“形成 B(a)”已由 F 直接给出
Control-Q (as run)   = F: 对每个 a 交出 B(a)，与 formation task 是同一输入、同一任务的短付款路径
Q-state delta        = Q_CAPABILITY_CALIBRATION；ZFC_SITE_SELECTED 保留，Q-0 仍为 UNFORMED
```

这是针对同一任务的有效反控制：不是因为“以后也许会有别的消费者”，而是因为这次提出的 formation task 正好被该次 profile 的 total closure 支付。它不能支持 `ZFC_Q_LOCATED`、UR、形式矛盾或对标准 ZFC 的一般判词。

## 3. 当前 P-FORGE 合同下的反事实

若今日重新提交同一内容，卡须显式标作 `SourceLayerTarget = deidentified theory profile / discovery calibration`，并冻结 `PCalibrationConvergenceCard`、station impact 与同一任务的 `F → answer(Q?)` 付款路径。它会通过当前 D-L5、D-L6、D-L7、D-L8、D-L9 的发现层筛查：具体 formation 是 all-subobjects interface，而非输入变量 `a`；但它在 D-L6 被拒绝，故不会进入 source tracer、P2、P3 或 Battle。

后来的 D-L10F 形成起点并不改写这一历史：它只允许已声明 formation 作为受控 probe 的入口，不允许把 F 已经直接交付的 `B(a)` 再描述成未清偿的 Q。当前分类因此仍是：

```text

QConvergenceLink = Q_SAFETY_REPAIR for the fixed formation task
Candidate-Q       = NONE
No-auto-start     = true
```
