## 2. `AS_RUN`：Power Set 不等于无限制理解原则

给定的中性 card 只允许集合对象和 membership；`P(a)` 是对已经给定的 `a` 取得 subsets，bounded separation 的
bridge 只在 `x ∈ a` 的范围内。外部实例因此拒绝补造：

- arbitrary predicate binder 与 formula reification；
- satisfaction 与 universal bridge；
- legal same-object reentry；
- diagonal normalization，及由此得到的 `q ↔ H(q)`。

这正是 P2 应在此处拒绝的错误类比：不能因为 Power Set 名称听起来像“更强的朴素集合论”，就把它误译成无限制
`Bind/Form/Bridge/Reenter`。它只关闭这张中性卡的 P2 encoding，并不证明 ZFC、Power Set或所有反射/语法扩展没有其他可审位置。

```text
Target-Q (as run)    = Power Set核心承诺是否能在同一来源卡上供应P2的formula-level formation / bridge / reentry
Candidate-Q (as run) = NONE；该中性card不能合法形成 q↔H(q) 问题
Control-Q (as run)   = N02/RK-0无限制formation正控制；P2-FORGE正负fixture；后续Power Set实际来源卡
theory-Q delta       = NONE；仅保持 ZFC_SITE_SELECTED
```
