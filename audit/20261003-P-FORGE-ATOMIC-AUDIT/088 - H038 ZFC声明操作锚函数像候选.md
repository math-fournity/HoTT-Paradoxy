## 2. `AS_RUN`：从未声明检查转向已声明 formation

H038不是对函数像的来源判词。它只说明在此隔离、闭合菜单与 D‑L10下，模型没有继续造出`judge(r)`，而把候选限定为 profile 真实给出的 functional-image formation。

```text
Target-Q (as run)    = D-L10后，闭合菜单是否仍能生成一个由声明操作支撑的条件性候选
Candidate-Q (as run) = functional-image formation over an admitted set and functional relation
Control-Q (as run)   = selector site rejected as DISCOVERY_UNDECLARED_OPERATION
Q-state delta        = Q_GENERATE_WITH_SOURCE_GAP; conditional menu only
```

功能像 formation是否直接完成所问任务、是否有同层 C/I/O/Done、是否有正义务，H038均未声称；这些留给 H039固定 source card。
