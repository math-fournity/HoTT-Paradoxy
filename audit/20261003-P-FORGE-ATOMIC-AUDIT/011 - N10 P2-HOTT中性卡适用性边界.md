## 2. `AS_RUN`：不能由 HoTT 名词补造 P2 余式

给定的中性 HoTT theory card 只提供 ambient type formation：universe、`Id`、`J`、`Pi`、`Sigma`，以及可选的
`ua`。外部实例逐字段拒绝把这些名称改写成 P2 的 formation--reentry--polarity 结构：

- `ua` 只把已经给出的 equivalence 转为 universe identity；
- 未指定的 HIT 不能充当 formula reification；
- 没有对象语言 binder、`Form`、`R`、bridge、合法 reentry、`q = R(u,u)`、diagonal normalization 或 polarity。

因此它没有产出一个 P2 residual，更没有把 identity path、univalence 或高维术语误报为罗素式 feedback。

```text
Target-Q (as run)    = HoTT来源卡是否实际含有可由P2审计的 object-language formation / bridge / same-object reentry 结构
Candidate-Q (as run) = NONE；中性卡不许可形成该问题
Control-Q (as run)   = P2-FORGE的正负夹具，以及随后H016的同一HoTT discovery-source链P2排除控制
theory-Q delta       = NONE
```

这张卡拒绝的是**该中性卡上的 P2 encoding**。它不证明 HoTT 的任何扩展都没有 quotation、syntax、reflection或其他可被
P2审计的结构，也不消除后来以具体 `U`、completion question和来源证据形成的 HoTT A-direction candidate。
