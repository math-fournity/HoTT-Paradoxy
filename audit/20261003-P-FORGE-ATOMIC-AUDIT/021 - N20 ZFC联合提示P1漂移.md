## 2. `AS_RUN`：同一提示先制造了不该有的“共同性”

联合prompt让代理选择 bounded separation instance，而此前P1独立盲测定位的是 Power Set。此次卡中：

```text
u = 有界子集
F = schema-level bounded separation
Q = 外部 formula predicate
P2 = formula binder / representation / reentry not supplied
P3 = lifecycle not supplied
```

P2/P3的拒绝在该卡自身范围内是合理的，但P1的候选已经不是独立地从显眼承诺产生。来源将这一差异记录为
`JOINT_PROMPT_P1_DRIFT`：P2/P3字段的易填性可能把P1从Power Set牵到bounded separation。这里的因果强度必须保持有界：
它是本次冻结prompt与此前独立P1输入的对照性诊断，不是关于任何模型、所有联合prompt或ZFC本身的普遍定律。

```text
Target-Q (as run)    = ZFC中由三刀在同一T/u/F/C/Q/I/O/Done共同定位的理论级候选
Candidate-Q (as run) = NONE；bounded separation没有形成共同Q
Control-Q (as run)   = 先前独立P1 Power Set选择；N12/N13中性ZFC P2/P3边界
theory-Q delta       = NONE；仅为 ZFC_SITE_SELECTED_ONLY
```

## 3. 当前合同下的 QConvergenceLink

N20是“锻刀与发现Q同一过程”的负面方法证据：若P1的站位被P2/P3需求预先选择，则表面上的三刀填写根本不是会合。
当前反事实因此不是重跑同一联合prompt，而是冻结接力：

1. P1在独立无泄漏session选并冻结 `u/F/C`；
2. P2/P3只消费这张冻结卡和同一source，不得重选候选；
3. Master才比较同一 `Q/Done` 是否会合。

| 项目 | 当前反事实判词 |
|---|---|
| P/Q偏差 | `EXECUTION_DEVIATION / JOINT_PROMPT_P1_DRIFT`：联合输入违反三刀不同惯性的独立选靶要求。 |
| Candidate-Q | `NONE`；bounded separation输出不能提升为更好靶、P2/P3拒绝也不能变成ZFC防御。 |
| QConvergenceLink | `Q_SAFETY_REPAIR`：保护后续 `POWERSET-CANDIDATE` 免于被prompt内字段需要替换为另一个站位。 |
| 修复的可检验后继 | N21的冻结接力P1需独立回到Power Set并冻结卡；N22/N23再消费同一P1卡。 |
| 停止条件 | 若冻结接力仍不能在同一 `u/F/C/Q/I/O/Done` 上会合，保留明确gap，不用另一站位填补。 |

该修复没有把锻刀与找Q重新拆开。恰恰相反，它把“同一Q”变成可反证的输入不变量：P1先确定究竟在打哪一个
理论承诺，P2/P3再对那个承诺工作。
