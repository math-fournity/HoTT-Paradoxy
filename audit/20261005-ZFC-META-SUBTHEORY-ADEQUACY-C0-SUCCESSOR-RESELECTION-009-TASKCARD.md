# C0 successor reselection 009：ZFC-specific temporal-operation contract

> **身份：** `CORE_ADEQUACY_TASK_CARD / ACTIVE_SUCCESSOR_SELECTION / NOT_A_MATHEMATICAL_RESULT`。
> **前序：** [C0R8 real consumer screen](20261005-ZFC-META-SUBTHEORY-ADEQUACY-C0R8-DACOSTA-SANTANNA-REAL-CONSUMER-SCREEN.md) 与 [phase-order source-to-spec control](20261005-ZFC-META-SUBTHEORY-ADEQUACY-C0R8-MSS-PHASE-ORDER-SOURCE-TO-SPEC-CONTROL.md)。

## 已知而未付的精确缺口

当前 source chain 已经得到：

```text
ZFC-MSS representation            (Sant'Anna--Bueno 2014)
→ time domain recovery            (same source; C-375 control)
→ source-side goal/operational qualification
                                (da Costa--Sant'Anna 2001)
→ parameter/range order control   (C-377/C-378)
```

但它还没有一个同一来源合同说：

```text
M = ZFC or a fixed ZFC-founded foundation
S = a fixed continuous physical subtheory
Q = a concrete operational/prediction/process task
P = the actual promotion from formal/state description to task completion
Bridge = an explicit order/endpoint/completion preservation condition
Adequacy = who must check it
```

## 目标

找一个 **ZFC-specific temporal-operation contract**，而不是再找“time is eliminable”的论文。
优先源必须同时明示：

1. ZFC 是实际模型／foundation context，而不是背景术语；
2. 连续 trajectory、phase flow、thermodynamic history或另一个 time-indexed physical model；
3. 一个具体 operational consumer：prediction、initial-value recovery、endpoint reachability、measurement
   protocol、irreversible history，或同等明确的 task；
4. representation/reformulation到该 consumer verdict 的 preservation / interpretation / adequacy rule，
   或 source 明确承认它缺失。

## 最小判别行动

```text
C0R9-ZFC-TEMPORAL-OPERATION-CONTRACT-SCREEN

冻结三类搜索入口：
  "ZFC" + (phase space | trajectory | prediction | initial value | thermodynamics)
  + (operational | interpretation | representation | preservation | adequacy).

每一个命中先填 M/S/Q/P/Bridge/Adequacy。
任何出现 generic set theory、一般 time eliminability、或只是 state description而无
concrete task/bridge 的来源，登记为 control/source seed后退出，不再扩写为Q。
```

## 强制控制

- `C-375`：domain recovery已经排除“无 explicit T 必然丢时间”的结论；
- `C-377/C-378`：range-only order loss是有限表示控制，不能替代 actual phase-space semantics；
- 2001 thermodynamics的 operation caveat说明 practical usefulness 与 logical eliminability可以分层，
  但它没有 ZFC-specific M 或 fixed Done；
- Earman--Norton的 physical bridge正控制禁止把连续模型一概判为不完成。

## 第一 source screen outcome（Benveniste et al. 2012）

`Non-Standard Semantics of Hybrid Systems Modelers` 已支付一个有价值但受限的比较控制：

```text
basic ZFC + three non-standard-analysis axioms
→ ordered infinitesimal time base T={n∂}
→ operational/constructive/Kahn semantics for hybrid-system programs
→ explicit handling of zero-crossings, program acceptance/rejection and Zeno-related execution issues.
```

这满足 `S/Q/FormalDone/P` 的 extension-level source contract，并明确把执行语义、离散步和
adaptive discretization作为同一问题。但 `M` 是 ZFC extension，source没有证明 bare ZFC 本身不能
承载等价语义，也没有把其 language-level task接到 Zeno/圆环 `OriginDone`。判词为：

```text
ZFC_EXTENSION_TEMPORAL_OPERATIONAL_SEMANTICS_POSITIVE_CONTROL
BARE_ZFC_SUBTRACTION_COMPARISON_UNPAID
```

详细字段见 [C0R9 comparative-control card](20261005-ZFC-META-SUBTHEORY-ADEQUACY-C0R9-HYBRID-NONSTANDARD-COMPARATIVE-CONTROL.md)。
