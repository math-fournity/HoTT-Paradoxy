# 两枚导弹：第一击的反弹机制与齐射结构

> 修订对象：本方案 022 片 §3 判据纪律（"理想元素的形式可构造 ≠ 过程的完成"）
> + 006 片 §3 供给策略。
> 触发来源：用户 2026-09-17 战术判定（`source=user`）：单发攻击必被反弹，
> 必须两枚齐射。本片把 022 片中"我的一处错误"升级为一个**普遍的、可预期的
> 反弹机制**，并据此把供给交付从三标注扩展为四标注。

## 1. 反弹机制不是我的个人失误，是系统性反驳形态

022 片把"把紧化当作可以做到"记作我的一处判据错误。用户 2026-09-17 的进一步判定：
**任何 Think in 该理论的人都会生成这个反驳**。这不是偶然失误，而是形式层保护
自身的标准反应：

> 每当第一击指出"过程 P 在理论内不可完成"，形式层会立刻供给一个**理想元素**
> （极限点、紧化点、无穷远点、完备化、存在量词见证、选择函数）并附一条
> 定义/规则，声明 P "已被处理"。

在圆环案例里，这个反弹就是单点紧化：添加 ∞，规定两端收敛，得到 S¹，于是
"无法还原"看起来被解决了。反弹的力度足以让单发攻击失效——因为形式上它
确实"做到了"。

**战术后果**：单发的"过程不可完成"攻击**先验地预期会被反弹**。把它当作完整攻击
是错误的，无论它本身的证据多硬。

## 2. 齐射结构：两枚导弹与各自的证据

| | 目标层 | 弹种 | 证据 | 反弹 |
|---|---|---|---|---|
| **第一枚** | 过程层 | P 在 T 内不可完成 | **机械证据**：不可停机归约 / 非紧性 / 收敛失败 / proof search 不完成 | **必被反弹**（理想元素 + 定义声明已完成） |
| **第二枚** | 声明层 | 反弹所用的理想元素**不对应任何过程完成**；理论在此处**绕过 ASK** | 形式可构造的逐字定位 + 它未执行过程的论证（圆环案例：紧化未让任何点真正重合，只是规定收敛） | 无——它击穿的是反弹本身 |

第二枚不是独立的新攻击，它**以第一枚的反弹为靶**：反弹暴露了理论用理想元素
冒充完成的位置，第二枚正好打在这个位置上。这就是"第一枚打上去被反弹一下，
然后再和第二枚一起将其彻底击落"的结构。

## 3. 为什么必须齐射才成立

- **只有第一枚**：被反弹，攻击失效（022 片记录的误用，正是只信了第一枚的反弹）。
- **只有第二枚**：没有"不可完成"的硬证据，"绕过 ASK"的指控无锚点——理论可以
  合法地说"我们就是用理想元素工作，这是工具性，不是欺骗"。
- **两枚齐射**：第一枚钉住**过程层的不可完成**（机械证据，不可反驳），第二枚
  钉住**声明层的不对应**（理想元素未执行过程）。两者之间的落差正是 022 片的
  `PROCESS_DECLARATION_GAP`——此时它不再是一个静态结构，而是被两枚导弹
  同时照亮的**战场**。

## 4. 供给单元的执行形态：三标注 → 四标注

每个按本模式供给的候选，交付物从 022 片的"三标注"扩展为**四标注**：

1. **过程层证据**（机械）。
2. **预期反弹的显式构造**：供给者必须**先替防守方生成反弹**（理想元素 + 定义），
   不能等外部反驳才补——未预先生成反弹的供给按未完成处理。
3. **第二击**：反弹所用的理想元素不对应过程完成的论证。
4. **现实侧对照**（用户哲学层判断，不冒充物理定理）。

"预先替防守方生成反弹"是本片新增的**硬性交付项**：它把 022 片中我事后才识别的
反弹，前移为供给时的必填项。反弹未被预先生成 = 供给未完成，不予登记
（与 022 片"缺一即误报"同一纪律）。

## 5. 与既有链的接口

- **022 片**：提供**目标模式**（`PROCESS_DECLARATION_GAP`）；本片提供**攻击序列**。
  二者关系 = 目标与战术。
- **006 片方向 B**：方向 B 从此不只是"理论绕过 ASK 假装已完成"的静态描述，
  它有了两步的论证顺序（先钉过程层，再钉声明层）。
- **020 片自我审计**：本片来自一次被我漏判、被用户纠正的推理；按 020 片纪律，
  此类"我的错误"在审计中须作为**证据**保留，不得事后美化。022/023 两片
  保留了这次错误的完整轨迹（dev-notes 0010 两轮归档 + 本两片）。

## 6. 未闭合项（不静默丢弃）

- **反弹族不限于"加理想元素"**。已知至少还有三类反弹：
  (a) **改判据**——"你说的不是同一个等价概念"（圆环案例中 M≠N 路线遇到的正是这一类）；
  (b) **改承载层**——021 片 EXP-001 记录的 `Partial(φ)` 层迁移；
  (c) **改作用域**——"该结论只在某工具链成立"。
  三者的第二击形态尚未分别形式化，登记为 unknown。
- **"第二枚无法被反弹"是预期，不是已证定理**：它依赖"形式可构造不对应过程完成"
  能在具体案例中被固定成论证；该论证仍须逐例构造。
