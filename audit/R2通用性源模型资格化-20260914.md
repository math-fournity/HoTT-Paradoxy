## 三、语义逐项审读

两代 `MM2.v` 的排版、模块范围、许可证和附加问题不同，但下列核心保持：

1. `mm2_instr` 恰有 `inc_a`、`inc_b`、`dec_a j`、`dec_b j`；
2. 状态是 `(pc,(a,b))`；程序第一条指令位于 label 1；
3. INC 把相应计数器加一并转到 `pc+1`；
4. DEC 在计数器为后继时减一并跳到 `j`，为零时不减并转到 `pc+1`；
5. `mm2_step` 只在当前 label 对应程序中的一条指令时存在；
6. `mm2_stop` 是不存在后继步；`mm2_terminates` 是有限关系闭包到某个 stop 状态；
7. `MM2_HALTING (P,a,b)` 从 `(1,(a,b))` 开始。

当前 `rocq-9.2` 增加 `MM2_ZERO_HALTING`、可逆性、uniform boundedness/mortality 等入口；这些不是本轮 seed 的必需部分。`MM2_HALTING_undec` 的核心仍从 `MMA2_HALTING_undec` 和 `MMA2_MM2_HALTING` 得到。

## 四、必须保留的 synthetic 定义边界

上游 `Synthetic/Definitions.v` 定义：

```coq
decidable P := exists f : X -> bool, forall x, P x <-> f x = true
```

`Synthetic/Undecidability.v` 定义：

```coq
undecidable P := decidable P -> enumerable (complement SBTM_HALT)
```

因此 `MM2_HALTING_undec` 的精确含义是：如果存在 MM2 停机的总 Bool 判定器，就能枚举单带二符号图灵机停机问题的补集。该库没有在这条定理中无条件证明该补集不可枚举，所以 C-208 不能表述为纯构造内部的 `¬ decidable MM2_HALTING`。

这不是措辞细节，而是本研究的 ASK 核心：外部“所有 Coq 可定义函数都可计算”的合成解释与内部可证明的函数不存在命题处在不同层级。要升级为内部否定，需要另加相称的 Church thesis／EPF 原则，或在一个可编码的计算类上证明 diagonal contradiction。
