## 1. 触发：一个成功 session 不等于一次实际执行

在准备 N06 时，`P2-FORGE-001` 明示两次不同的命令尝试：第一次因全局 CLI 参数位置错误在模型启动前退出；第二次才以
session `01a0fca3-9498-71f0-b8d6-255b9a65648b` 成功启动并给出夹具分类。第一次虽没有模型输出，却改变了第二次的
实际命令形状，因此按 SOP 的 pre-sampling 规则不能被 N06 覆盖。

| atomic ID | 事件 | 证据 | 分母判词 |
|---|---|---|---|
| `N32` | P2-FORGE 首次 CLI 参数位置错误 | `audit/20261002-P2-FORGE-001-外部CLI-Terra-Max.md` 运行身份段：第一次在模型启动前退出，第二次修正 `--no-daemon`、`-m`、effort/sandbox/approval 参数。 | `UNIQUE_DOCUMENTED_EXECUTION(1)` |
| `N06` | 修正参数后的 P2 fixture run | 同报告中保存的 session `01a0fca3-9498-71f0-b8d6-255b9a65648b` 与三项终态。 | `UNIQUE_ATOMIC_RUN(1)` |

这不是把命令行 parse error 写成理论错误。N32 的未来 AtomicAuditCard只审 runner／证据边界和它是否保护某个固定卡免于
误报；它不产生 P2、ZFC 或 HoTT 的理论 Q。
