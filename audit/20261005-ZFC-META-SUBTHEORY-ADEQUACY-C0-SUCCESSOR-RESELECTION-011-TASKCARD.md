## 已得出的双重控制

```text
ZFC can define an appropriate non-standard extension       (representability positive)
but a hybrid operational semantics uses added time/order interface
and a source-specific program/zero-crossing consumer       (consumer bridge local)
```

所以 bare-ZFC 的候选问题被进一步收紧：不再是“能否表达时间”或“能否构造超结构”，而是
**谁在实际应用中负责选择、暴露并验证所需的 temporal operational interface。**

## 目标

寻找同一个物理／计算任务的两个版本：

```text
S_std    = standard-continuum mathematical presentation
S_op     = operational-time / non-standard / discrete-step repair
Q        = same source-defined task, input, observation and Done
P_std    = standard presentation's actual completion/prediction/simulation claim
Bridge   = source-specified relation between S_std and S_op verdicts
M        = exact ZFC / ZFC-founded location and responsibility
```

最有希望的题材是 source 已点名的 zero-crossing、bouncing-ball、hybrid Zeno、adaptive
simulation或initial-value task；但 “都叫 Zeno” 绝不是同一任务的证据。

- ZFC 可构造 `*V`：不得把 extension 的出现当成 representability impossibility；

  Zeno runner or circle completion；
- Earman--Norton：连续Newtonian process可有条件性物理 bridge；
- C-375–C-378：carrier/order observation的有限控制不能自动给 physical Q。
