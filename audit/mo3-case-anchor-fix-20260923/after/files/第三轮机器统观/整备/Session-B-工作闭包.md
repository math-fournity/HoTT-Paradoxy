```bash
python3 第三轮机器统观/整备/handoff_snapshot.py verify --seal 第三轮机器统观/Session-A/交付/final-001
```

返回身份后固定manifest hash，将包复制到B自己的输入目录，使用`--expected-sha <已固定hash>`复核。这个参数固定信任锚，不能每次都从变了的SEAL重新取hash来掩盖漂移。工具不是数字签名，无法证明A诚实或清单无遗漏。独立核强结论的传递依赖与来源成员。
