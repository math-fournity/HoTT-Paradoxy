# Goal 5：第三轮 HoTT 机器统观的执行 SOP

> HUMAN_EDITED；版本 1.0；2026-09-23。方法与验收 owner；启动入口是 `第三轮机器统观/整备/Session-A-goal提示词.txt`。当前仅整备，尚未启动 A。用户在新 Session A 注入提示词后才激活。本轮编号 MO3 是用户指定的工作称呼，不认证此前已有两轮全理论完备证明，也不是计算阶梯 R3。

本轮研究 HoTT 的理论经济性、工具普适性及可能引入的非现实条件。方法是忠实使用用户原意，对规则、机制家族、组合、共同取舍和理论整体作多层次检视，再由具体取舍反向构造敏感过程，必要时执行原生形式证明与现实同任务审计。结果可以是新候选、已证的有范围性质、现有防线、精确未知或本轮无合格命中；未闭合的候选不得写成 HoTT 内部矛盾。

## 1. 目标、完成边界与旧任务的关系

本轮必须交出可由另一 Session 独立复查的完整研究结果，不能只交 SOP、地图、读书摘要、审计表或旧证明复跑。完整结果包含：具名理论范围的语义检视、多尺度关系覆盖、实际针对性构造及验证、失败与未知、逐结论证据、可重放交付包。

先进入用户的研究视角：理论为何好用；它为此添入、省去、合并或提前处理了什么；什么具体过程会使那项条件重新重要。允许先生成大胆但可区分的假说。核证阶段再检查实际规则、邻近正常任务、最强反解释与证据等级。研究方向不需要每轮先被辩倒或证明为普遍哲学定律，具体结论仍接受证据约束。

`goal.md`、`goal-1.md`、`goal-3.md` 和旧路径树是历史范围与复用入口，不自动成为本轮队列。保留其有靶过程、同任务、反思、查重、证明纪律；本轮范围、波次和完成条件由本文拥有。尤其不直接继承旧 goal.md §3.11“必须先找到合格悖论才可完成”的历史目标。本次 `/goal` 是完成下面全部研究义务的一轮统观，最终寻找目标与本轮完成状态分别报告。

有界完成不等于任意缩减任务：八大领域不能以无理由的 N/A 清空，五尺度不能只改标题，已承诺的高价值判别不能改成“未来工作”后宣布完成。新发现的重大范围缺口必须在本轮补审；范围外开放世界和需要独立长期研究的新问题可以登记为后继。没有合格命中时仍须完成主动发现、实际验证和反遗漏义务，不能以谨慎措辞代替尝试。

## 4. 理论范围与五尺度覆盖

先固定书式 HoTT 的源版本、具体 Cubical 演算/实现和相关扩展；不能把彼此不兼容的规则放进一个虚构“大 HoTT”。以现有 Schema 的 C/D/S/E、Book section 与 TC/OP 为基底，在 `Session-A/覆盖与关系.md` 建立可回源的映射。

|必审领域|至少回到哪些语义|
|---|---|
|判断、上下文、结构规则|形成、假设可用性、替换、依赖、复制与弱化。|
|基本类型与构造/消去|构造、存在、消去、计算及完成的不同条件。|
|同一性、等价、单价性、运输|何种同一、允许替换什么、哪些观察/结构被保留。|
|HIT、截断、商与层级|形成与消去、相干、信息与资格、组合使用。|
|逻辑、公理、宇宙、实数|核心/派生/可选前提、choice/LEM/resizing及表示。|
|同伦与范畴的派生使用|真实调用链、结构同一性、局部到整体的义务。|
|计算、元理论与模型|检查/搜索/归约、模型、可计算性与自反的确切系统。|
|Cubical及相关扩展|区间/面/composition/Glue；guarded、clocked、directed、cohesive、2LTT、cost等相关边界。|

这些是最初八域，不是穷尽性定理。每域的具体分母从当前来源清单重建；新增独立来源发现遗漏时扩充并重评。扩展中不相关的部分可有理由排除，不能把主域整体排除。

每域按以下五种**观察尺度**检查：S1具体规则/使用实例；S2局部机制家族；S3跨构造组合；S4共同抽象取舍；S5固定理论整体。五尺度不等同于 universe、h-level，也不等同于八轴中的 ObservationLayer。S5可由多个领域共同指向一项整体问题，无须硬造八份同文报告。

第一遍对所有领域建立真实的来源/问题/缺口；之后每个尺度都须有独立问题和实际语义审查。覆盖状态区分 `SOURCE_LOCATED / SEMANTICALLY_REVIEWED / PROCESS_CONSTRUCTED / FORMALLY_CHECKED_WITH_SCOPE / REALITY_BRIDGE_REVIEWED / OPEN / EXCLUDED_WITH_REASON`。这些不是一个自动直线升级序列；某阶段不适用须解释。引用旧结果写其精确适用范围，不能自动继承旧 PASS。

## 5. 语义网络、格化启发与关系覆盖

研究单元按功能和抽象取舍组织，允许重叠、多父节点、跨章节。每单元写：ID、尺度、成员/locator、共同功能、为什么一起考察、本层独立问题、相关原意、现有证据、未覆盖部分。

关系必须标类型并带侧条件：范围包含、真实理论依赖、操作先后、并行/多输入合成、反馈、模型/翻译。共属性不等于操作相互作用；不能拿目录树、相似词或箭头代替关系证明。三项以上组合按真实语义选择，不设“做到两两/三元就完备”的默认结论。

借鉴 FCA 时，明确对象集、属性集、关联和 unknown；没有固定 formal context 与闭合关系时称语义网络，不冒称严格概念格。即使计算完整概念格，也只覆盖那个输入 context。未登记属性不等于属性为假；需要把分类关系与依赖/过程关系同时保留。

原八轴继续使用：`TheoryConstruct × AbstractionChange × RealityOrTask × ConsumerOrContext × ObservationLayer × CompletionProperty × Oracle × FrameworkOrModel`。TheoryConstruct可以引用多成员语义单元；不要建立无意义的巨大笛卡尔积。语义归属用文档关系或 related_records/research_parent；STATE.depends_on只放真实 stale-propagating 验证依赖。

同时执行两条选题通道：**信号驱动**沿局部现象深入；**结构驱动**从共同取舍、重要接口或整体任务向下构造，即使所有已审成员都没有异常。每轮调度不得只选前一类。至少实际检查一项跨章多构造过程、一项共同取舍和一项整体问题，并明确各自不由单点结论解决的部分；数量是最低反形式主义检查，不是全域覆盖证明。

## 6. 从理论取舍到针对性过程

每个值得继续的取舍先用普通语言写一句：**理论为了 E，把 T 改为 T′；过程 P 恰好需要其中的差别，预计在 O/Done 上出现可区分结果。**有出处的作者动机与研究者的功能解释分开。不能仅因原文没有时间变量就断定理论否认时间。

候选卡至少含：原问及未承接部分；精确规则/版本/侧条件；E与T→T′；X、Input、Operation、Observation、Done；有靶过程；预测；改变T的对照；邻近正常任务；证明义务；来源/历史查重；尺度/八轴位置；下一判别与停止条件。理论检视阶段允许尚无过程，但送入生成器前必须有靶且模型能表达它。

生成角度可来自：局部成立与整体完成的连接；构造过程与完成结果；未来/当前可用；同一与替换；形成与消去；正反过程；无限层级/逼近/相干；验证器成为对象；现实任务与模型资格的交接。机制由来源决定，不把所有问题压成 Delay Bool、信息损失或一般停机。

发送程序或证明器前做前提敏感性检查：改变/补回/移除T时，哪个表达、推导或观察应变化？模型根本不含T时标 `MODEL_TARGET_LINK_OPEN`，先补桥或换模型，不能扩大枚举。过程被正确拒绝只关闭该用法，不能关闭原问题其他合法分支；真实正常构造成功则撤回被反驳的强句。

每轮至少形成两种机制不同的过程尝试；其中包含一条结构驱动的高层过程，以及一个不以存在/交付为中心的留出主题。时间/运动/逼近/变形复原可作后者，必须保留原问而不预置“只是来源”。若无法形成有效过程，记录实际尝试与卡在哪项约束，再换未审机制；不能用两张同义卡完成此要求。

## 7. 方法资格化和反遗漏控制

先跑一条薄而真实的链：源规则→取舍→敏感过程→判据→证据→结论记录→复查。它用于暴露方法缺口，不能成为本轮唯一深挖支线。其余领域的来源/问题/关系首遍仍须尽早完成。

方法控制与真实候选分开登记，至少执行以下四项：

1. **无单点异常的组合控制**：预置一个只有共同侧条件、三项或有序过程才显现的合成例，检验调度是否会主动访问组合；同时给一个组合后正常的正控制。合成例只验证研究流程，不能报 HoTT 命中。
2. **同源重新切分**：对同一来源集合改变文件分片/阅读顺序，重新构造关键语义单元和关系；报告保留项、变化及遗漏。无需写通用解析平台。
3. **异机制留出**：在主要方法形成后选择另一真实主题，以原典生成过程，不给它套已知答案；区分自行发现与最高指示提示后的表现。
4. **认知偏差回归**：混合正确精化、原意替换、合理定量假说和未经支持的定量断言。针对圆环和“助力/阻力”两种真实错误核对，也在新总结中查是否复发。A自测是有提示的纪律检验；B独立抽取原始材料复查，不称双盲或模型权重改变。

每个 bounded pass 结束使用至少一个不同 taxonomy、来源、框架或留出主题查 out-of-envelope。看不到的轴、关系、任务、oracle假阳/假阴、模型换题风险都须显式记录。若发现会改变本轮结论的重要遗漏，修分母并处理；仅增加案例不修分类不算补漏。

## 8. 原生核证、现实对应与证据等级

程序化方法按问题选：typed term/proof enumeration、规则变异/消融、层级提升/擦除、consumer/context synthesis、组合/反馈/自反、差分/metamorphic/property-based、模型搜索、termination/productivity/proof search、版本化论文/源码。先作 omission scan，再选择适用方法；不要求把每一种都形式化实现，但每个跳过理由必须与本轮问题有关。

固定 exact calculus、CandidateClass、generator、reducer、consumer、observation、completion、denominator、controls、coverage level、unknown ingress、失效与停止。有限穷举须有真实成员分母、remainder和独立重算/覆盖论证；无限枚举须说明公平性与实际执行前缀；类级外推须有保类型、任务、观察和完成的归约证据。没有这些只能报告已检范围。

原生 HoTT/Path/HIT/univalence 命题使用相应系统。Python、Lean普通Eq或有限图模型只能支持其实际语义；未经证明的翻译不能冒充原生HoTT。timeout只报告观察窗；无效输入不能证明理论矛盾；物理时空离散性不从数学工具的拒绝或用户工作假说中推出。

按 [数学结论交付规范](docs/quality/数学结论机器证明与证据留存规范.md) 固定命题、量词、前提、宇宙、禁止外推；保存源码/依赖、实际kernel运行、唯一索引、版本闭合。复用工具命令见A闭包。新事实未过门禁只能是 QUESTION/CONJECTURE/HEURISTIC/PAPER_ONLY/COUNTEREXAMPLE_CANDIDATE 等，不阻止继续有范围的探索。

现实桥单列：原现实/假想任务、模型如何承接、理论真正承诺、允许操作、观察与完成是否一致、HoTT规则是否必要、补条件的代价是否改变任务。来源字段可精化复原问题，但不能代替零大小点/逼近/先前已得到M的原问；表示能力与实际取得能力分别记录。

## 9. 逐结论记录、自审与修正传播

`Session-A/结论账本.md`拥有本轮公开结论登记，按最高指示§7.4六组24维作适用性审计。每个可独立撤回的判断有 `MO3-J-*` ID，保存原句/当前句、类型与范围、正文位置、exact来源、AI新增前提、适用维度与理由、处置、依赖和复核条件。复用同一ID引用，不把所有句子硬拆成机器数据库。

包括过渡句、因果句、来源归属、量词/数量、覆盖和完成声明；疑问句暗含的事实也检查。纯操作命令和纯疑问不用强造断言。高风险逐句核，低风险可同一行列多个重复位置，但不同断言不能一锅ALIGNED。`待查`不得在下游当事实。

每个单元从正文反查账本，再从账本回查正文；缺结论补登记，表达过强原位改正文及摘要/标题/后继，而不只改审计栏。24维是开放初始框架，发现新偏差增加有具体触发问题的维度并说明对旧结论的影响。表格齐全不能自己认证思考全面。
