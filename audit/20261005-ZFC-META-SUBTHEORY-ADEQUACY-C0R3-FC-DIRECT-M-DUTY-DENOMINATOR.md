# C0R3 / F-C：bare set-theoretic foundation 是否直接承担 physical bridge 的来源分母裁决

> **身份：** `CORE_ADEQUACY_SOURCE_AUDIT / SOURCE_DENOMINATOR_BOUNDARY / DIRECT_M_DUTY_UNPAID_WITH_SCOPE`。
>
> **来源：** [C5A](20261005-ZFC-META-SUBTHEORY-ADEQUACY-C5A-FOUNDATION-ADEQUACY-SOURCE-CARD.md)、[C5B](20261005-ZFC-META-SUBTHEORY-ADEQUACY-C5B-APPLIED-MODEL-BRIDGE-RESPONSIBILITY-CARD.md)、[C5E](20261005-ZFC-META-SUBTHEORY-ADEQUACY-C5E-FOUNDATION-OBSERVATION-SCOPE-SYNTHESIS.md)。

## 问题

在已冻结的 set-theoretic-foundation / scientific-representation source denominator 中，是否有任何 source 明确规定：

```text
bare ZFC foundation role
  must audit a ZFC-founded continuum model's physical-process
  FormalDone ↔ OriginDone bridge?
```

## 分母内来源支付

- Maddy 的一手文本将 ZFC 类 foundation 的实际用途描述为 mathematical surrogacy、consistency risk assessment、proof/ontology standards，并明确拒绝把 set-theoretic reduction当作 metaphysical insight；
- IEP Foundations 将 mathematical surrogate relation同 physical sciences的更直接模型实践分开；
- SEP Scientific Representation / Models 将 target、accuracy和mathematics-to-physical-world applicability放在 representational model / interpretative model层，并明确 logical model不自动是 representational model；
- SEP Zeno 要求 physical applicability另行论证，但没有把这种义务回写为 ZFC object-language 或 foundation-specific rule。

所以，这个来源分母实际给出的不是 `M must audit bridge`，而是：

```text
M supplies mathematical formal / representation / proof roles;
P as applied model must carry target / accuracy / applicability work.
```

## 判词

```text
DIRECT_BARE_ZFC_PROCESS_BRIDGE_DUTY_NOT_SOURCE_PAID_WITHIN_DENOMINATOR
FOUNDATION_ROLE_AND_APPLICATION_ROLE_SOURCE_SPLIT_ESTABLISHED
NO_SOURCE_BASIS_FOR_CORE_ADEQUACY_FAILURE_FROM_F_C_CURRENT_DENOMINATOR
NO_GLOBAL_ABSENCE_CLAIM
```

这里“not source paid”不是说没有人能够主张那项 duty，也不是说研究发起人的 Meta-Theory norm 无意义。它只说这项 norm **不是当前标准 set-theoretic foundation sources已承诺的 bare-ZFC role**。

## 对用户规范的正确位置

研究发起人的 primary source 另提出：Meta Theory 应检验 Sub Theory 的时间／过程边界。这可以作为一个明确的、外加的 `ProcessCompletionAudit` 规范。

它会定义一个新对象：

```text
ZFC+Q_norm
  = bare-ZFC mathematical foundation role
    + explicit process-completion audit obligation.
```

对此对象可以机器化“若 coarse FormalDone view无法决定 OriginDone，就必须返回 task-switch / bridge-needed，而不能未经检查宣称原任务完成”。但这将是 **user-normative extension** 的定理，不能伪称为 bare ZFC 当前已经含有的公理或现成数学共同体政策。

## successor

实际 bare-ZFC source 路线在当前 F-C denominator内没有 direct duty payment。下一最小、可形式化行动是：

```text
NORMATIVE-PROCESS-AUDIT-EXTENSION-ADMISSION

把用户的 MetaTheory→SubTheory bridge-audit norm作为显式前提，
与 C-359/C-362/C-364 的已核 Lean controls逐字段对照；

形式化该规范的逻辑后果。结果必须保留为 `ZFC+Q_norm`，
不得升级为 bare ZFC verdict。
```
