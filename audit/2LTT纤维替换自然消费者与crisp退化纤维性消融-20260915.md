## 1. 问题与结论

上一工作单元已经机器证明：在边界保持的两层接口中，把任意 outer type 通过 context-uniform `R` 送入 inner 层，配合 outer UIP，会迫使 inner UIP。尚缺的问题是：社区中是否真的有人需要这类能力，还是它只是人为拼出的不相容 axiom。

本轮找到四类真实消费者，并取得两组新机器重放：

1. **fibration universe classifier**：LOPS 2018 要把 CCHM/CCTT fibrations 打包进 universe，以支持内部模型、univalent universe、HIT 与 directed/cubical type theory；
2. **universe of all types 上的 model structure**：Boulier–Tabareau 用 fibrant replacement 构造 weak factorisation systems、pushout/HIT 与 pre-model structure；
3. **HIT 构造**：Swan–Uemura 用 local fibrant replacement 构造 suspension、propositional truncation及后续 HIT；
4. **Reedy fibrant diagrams / semisimplicial types**：2LTT 只从 pointwise fibrant diagrams 构造 Reedy fibrant replacement，明确拒绝从任意 outer diagram 开始。

消费者因此真实存在。更关键的是，成功路线都没有使用 C-227–C-230 所拒绝的完整 open-family/context-uniform promotion。它们分别保留 global/local 区分、把 regular fibrancy拆成 degenerate composition与 transport、或把输入限制为 pointwise fibrant objects。

### 3.1 普通 internal weak classifier 为什么失败

`IntUniv` 提供 `U`、universal fibration `El`、对任意 context `Γ` 和 fibration `Φ` 的普通 `code Φ : Γ → U`，以及 `El[code Φ] ≡ Φ`。`fiberwise-fibrant-is-fibrant` 对 family `P : I → Set` 逐点调用：

```text
code ((λ _ → P i) , π i) tt
```

这里 `i : I` 是 local variable。抽象成 `I → U` 再 pull back `El`，就把每个 `P i` 在 terminal base 上的 fibrancy 拼成整个 `P` over `I` 的 fibrancy。取 `P i = (O ≡ i)` 后，composition 的 transport把 `refl : P O` 运到 `P I`，得到 `O ≡ I`，与 `O≠I` 冲突。

run `20260915-MP-AGDA-FLAT-INTERNAL-UNIVERSES-REPLAY-001-01` 在作者的 clean Agda-flat `2.6.0.1-70899fb` 中接受 `NoIntUniv`、`NoIntCCHMUniv` 和 `NoIntCCTTUniv`（C-233–C-235）。

### 3.2 crisp 如何支付并恢复

crisp type theory 将 judgement 分成 global/crisp 与 local 两个 context zone。Theorem 5.2 的 `code` 要求 base `Γ` 和 fibration `Φ` 都是 crisp；因此不能把依赖 local `i : I` 的 `((λ _ → P i), π i)` 传给它。作者在 tiny interval/right-adjoint 的显式假设下仍构造 `U`、`El`、`code`、`Elcode` 与 `codeEl`（C-236）。

本项目控制直接运行同一编译器：crisp argument 版本通过；将 argument 改为 local variable 后，Agda-flat 拒绝并给出：

```text

```

## 4. Boulier–Tabareau：regular/degenerate/transport 的同源对照

一手入口：[论文](https://doi.org/10.1017/S0960129520000213)；源码 `https://gitlab.inria.fr/sboulier/thesis-formalizations.git`，paper-linked `emptyctx@28a2568`。`InternalCubical-Coq` subtree 未发现 license 文件，因此本项目只保存外部 archive/tree/hash 和 probe，不复制源码正文。

### 4.1 负向 regular replacement

`Inconsistency.v` 显式假定：

- `repl : Type → Type`；
- `η`；
- 对 fibrant target 的 `repl_rec'`；
- 对任意 open family `P : A → Type`，整个 `repl ∘ P` 是 `RFib`。

它构造 `P i = (i = 1)`，从 `P 1` 的元素经 regular family composition 得到 `repl(P 0)`，再由 recursor 映到 `False`。C-240 的 `Print Assumptions` 明确含 `RFib_repl`，所以矛盾不能转嫁给实际 QIT replacement。

### 4.2 正向 degenerate replacement

`FibRepl.v` 用 private inductive/QIT `repl`、`η`、`hcomp` 与 reduction `qq` 自由加入 composition，并证明：

```text
Fib_repl : DFib repl
```

它没有证明对任意 open family `P` 的 `RFib (repl ∘ P)`。`repl_ind'` 只接受 `RFib` motive；`repl_J` 的 assumptions 还显式出现 `extension_rule__emptyctx`（C-241/C-243）。

`Fibrations.v` 的 C-242 机器固定：

```text
RFib P → DFib P
RFib P → Trans P
DFib P → Trans P → RFib P
```

也就是说，replacement 只免费补 `DFib`；沿 base path 的 transport 必须由输入 family 另行提供。论文对 pushout 的构造正使用这一分解：naive strict quotient取 replacement得到 degenerate fibrancy，再单独证明原 family有 transport，才得到 regular fibrancy。

## 5. Swan–Uemura 与 2LTT Reedy：独立消费者对照

[Swan–Uemura](https://doi.org/10.1017/S0960129522000068) Definition 9 的 local fibrant replacement `LFR(A)` 是带 reductions 的 W-type：保留 `inc(a)`，自由加入 homogeneous `hcomp`。它被实际用于 suspension 与 propositional truncation，并强调 homogeneous composition还需和 transport组合才能得到 Kan composition。该论文的本地 MinerU 全文在 `audit/literature/LIT-CLASSICS-001/mineru/Swan-Uemura-2019-Church-Thesis-Cubical-Assemblies/full.md`；本轮只作 primary-text mapping，没有重放其 W-type model。

2LTT §4 的 Reedy fibrant replacement同样只接受 pointwise fibrant diagrams。论文明确说，若从 arbitrary outer diagram 开始，单对象离散 index 已退化为被 Theorem 2.20 排除的任意 outer-type fibrant replacement。这个限制保留了消费者任务真正使用的 fibrant-valued输入。

## 6. 与“时间/时序”的关系

这里攻击的不是物理时间、运动连续性或数轴稠密性。精确变量是**上下文来源与依赖时序**：一个 code/replacement是在 global data 已给定后使用，还是可在当前 local variable `i` 仍开放时调用。ordinary internalisation抹掉了“先固定 global object，后编码”的资格顺序，使 `code` 能消费依赖当前 local stage/context 的 family；crisp zone把这条先后约束重新写进类型。

因此本候选主要属于“时序”而非“时间”。它可以与用户关于理论抹去形成/验证顺序的认识对齐，但不能替代芝诺问题中物理时空连续性与数轴稠密性的“时间”含义。
