# C0 successor reselection 005：Clarke‑Doane v4 的同源 contract 深化

> **身份：** `CORE_ADEQUACY_TASK_CARD / ACTIVE_SUCCESSOR_SELECTION / NOT_A_MATHEMATICAL_RESULT`。
>
> **前序：** [C0R5 Clarke‑Doane candidate card](20261005-ZFC-META-SUBTHEORY-ADEQUACY-C0R5-CLARKE-DOANE-SETTHEORY-PHYSICS-CANDIDATE.md)。

## 目标

在不把 physical determinism 偷换成 Zeno completion 的条件下，固定 Clarke‑Doane v4 中最强的同源 source-to-spec fragment，检查它是否真的给出：

```text
M = a specified set-theoretic metatheory
S = a specified physical/mathematical model
Q = a specified physical verdict
FormalDone = an exact mathematical property
P = source's promotion rule
Bridge/Adequacy = required physical interpretation / robustness fields
```

## 优先 fragment

1. **Theorem 6.2 / §6.5**：`Egerm` representative selection。source 已明确说它不是从 interior state恢复 unique future；这应成为不同任务控制。
2. **§5.5**：`β` only formal completion，未支付 finite preparation→physical microscopic completion bridge；这应成为与项目 `FormalDone → OriginDone` 最接近的 source-local boundary。
3. **§9.1**：`Tphys ⊨M Φ` 及五项 reverse-physics record，检查它是否是 M 的实际 adequacy method，而不是作者提议的研究 agenda。

## 最小判别行动

```text
C0R5-SOURCE-TO-SPEC-CARD

逐页核对上述 fragment，分别写出：
  source assertion / paper-reported theorem / source-stated limitation /
  project translation / forbidden extrapolation。

随后决定它是：
  A. same-contract candidate（才进入 C1–C5）；
  B. different-Q physical-foundation control；或
  C. source only，缺少实际 theorem/consumer/bridge。
```

## 判别规则

- `Tphys ⊨M Φ` 的定义或研究建议不自动是 bare ZFC 的既定职责；
- source 说“formal completion only”会支持 bridge gap，但只有原 task/physical target相同才支持本项目 Q；
- paper称“unconditional theorem”只说明作者报告的 theorem，除非重放，不称本项目 machine proof；
- v4 是 draft，不能用作数学共同体共识。
