## 2. "缺口缩小到 keyE" ≠ 难度缩小

原始缺口（`Z0Blocked.lean:31`，也即 `Z0Full.zfc_z0_full_of_D3_internalize` 的假设 `h`）：

```lean
theorem zfcTr_D3_internalize {V} [V↓[ℒₒᵣ] ⊧* 𝗜𝚺₁] (τ) (h : Provable 𝗭𝗙𝗖 (⌜translate τ⌝ : V)) :
    Provable 𝗭𝗙𝗖 (⌜translate (zfcTr τ)⌝ : V) := sorry   -- 原始缺口
```

Codex 的 `keyE`（`Z0D3Skeleton.gap`）：

```lean
lemma gap (σ) : 𝗜𝚺₁ ⊢ zfcTr σ 🡘 provabilityPred (Theory.craig Sh) σ := sorry
```

- `zfcTr σ` 在模型层 = `Provable 𝗭𝗙𝗖 (⌜translate σ⌝ : V)`（`models_zfcTr_iff`）。
- `provabilityPred Sh.craig σ` 在模型层 = `Provable Sh.craig (⌜σ⌝ : V)`（`models_provabilityPred_craig`）。
- 两者在标准模型 ℕ 下都表示"**ZFC 证明了 translate σ**"，故语义相等。

**但要"在 𝗜𝚺₁ 中可证等价"，必须做证明的内部化**：把元层的
`Sh_provable_iff : Sh ⊢ σ ↔ 𝗭𝗙𝗖 ⊢ translate σ`（真实推导）搬进公式语言，并对任意（可能非标准的）模型 V 成立。
这正是 `zfcTr_D3_internalize` 缺的那一步。`keyE` 与它**撞同一个数学核心**，因此难度未降。

`Z0Blocked.lean` 自己解释了为什么难（注释第 27–29 行）：Foundation 的 `of_provability` 用**完备性定理语义地**
证明 `U ⊢ σ → T ⊢ translate σ`，它"不经过一条可搬进 𝗜𝚺₁ 的语法证明翻译"。

## 3. 组装链 `keyE → Provability.ext → zfcTr.HBL3` 在真实 API 下不成立

- `zfcTr : Provability 𝗜𝚺₁ Sh`（载体理论 `Sh`，`Z0Full.lean:60`）。
- `Sh.craig.standardProvability : Provability 𝗜𝚺₁ (Sh.craig)`（载体理论 `Sh.craig`，`StandardProvability.lean:42`）。
- 二者**载体理论不同**（`Sh` vs `Sh.craig`），`Provability.ext`（结构扩展性）只能在**同载体理论**下 equate 两个
  `Provability` 值，故**无法**把 `keyE` 推成 `zfcTr = Sh.craig.standardProvability`。
- 进一步，`HBL3` **不是** `Provability` 结构的字段（`structure Provability` 只有 `prov` 与 `bew_def`，
  `ProvabilityAbstraction/Basic.lean:25`），所以即便结构相等，也不会"自动转移" `HBL3`。
- 我在 `Foundation/FirstOrder/Incompleteness` 下**未找到**任何可用的 `Provability.ext` 桥接引理。
- 骨架本身**从未实现**这一步：它只把 `keyE` 写成 `sorry`，根本没有 `Provability.ext` 那一行。

**结论**：Codex 的"一旦 keyE 成立，`Provability.ext` 立刻给 `zfcTr.HBL3`"是未实现的、且按当前 API 不可实现的叙事。

## 4. 单向 keyE 的 Lean 实测（证据：编译错误）

我写了 `Z0D3Attempt.lean` 试证单向 `𝗜𝚺₁ ⊢ zfcTr σ 🡒 provabilityPred Sh.craig σ`，把 `complete 𝗜𝚺₁` 展开到模型层后，
目标化为：

```
hzfc : Provable 𝗭𝗙𝗖 (⌜arithTrln.translate σ⌝ : V)
⊢ Provable (Theory.craig Sh) ⌜σ⌝
```

唯一元层桥 `Z0D3Skeleton.shCraig_iff ∘ Sh_provable_iff` 给出的是**真实推导** `Sh.craig ⊢ σ`，
编译报错（类型不匹配）：

```
(Z0D3Skeleton.shCraig_iff σ).mpr ((Sh_provable_iff σ).mpr ?realDeriv)
has type  Theory.craig Sh ⊢ σ
but is expected to have type  Provable (Theory.craig Sh) ⌜σ⌝
```

这恰恰证明：目标要的是**模型内可证性** `Provable Sh.craig (⌜σ⌝ : V)`，而可用桥只给**真实蕴含** `Sh.craig ⊢ σ`
（不同层）；并且我们连真实推导都拿不到——`hzfc` 只是模型内 `Provable`，而 `Provable.sound` 只在标准模型 ℕ 上把
`Provable _ (⌜·⌝ : ℕ)` 折回真实推导，对**任意** `V ⊧* 𝗜𝚺₁` 失效。
=> 单向 `keyE` 与原始 `zfcTr_D3_internalize` 在同一处（非标准 V 推导消去）卡死。
