## 2. 对 C6A 的真正影响

C6A 的两个 control不是虚构反例：它们对应来源中确实可区分的路线。

```text
若 Q = Norton strict last-action task：
  explicit task revision  →  C6A TaskSwitchControl applies.

若 Q = IEP's physical application claim：
  source asserts application, but denominator lacks formal bridge payment
  →  C6A ApplicationUnpaid fixture remains applicable with its stated scope.
```

这不是同一个 Q 的相反结论。它是同一 Zeno discourse 内两个不同完成合同的来源事实，恰好验证本 SOP 为什么要求先固定 `OriginDone`。

## 3. 结论范围

本叶找到 actual defense，却没有得到 actual paid physical bridge。它不能把 C6A failure fixture提升为 bare-ZFC failure，也不能把 Norton defense扩大为所有物理完成问题都已解决。它只让下一阶段有资格审计 H0 是否能在**同一个完整 Q**下进入推论；若不能，就必须把 H0永久排出本核心 verdict。
