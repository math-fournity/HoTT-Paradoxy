# ZFC-HoTT-Q2：基础验收、模型语义与过程完成的来源阅读

> **身份：** `PRIMARY_SOURCE_READING / Q2_SOURCE_REFINEMENT / FOUNDATION_ADEQUACY_Q-1_SEED / NOT_A_ZFC_INCONSISTENCY_OR_ACCEPTANCE-CONTRACT_THEOREM`。
>
> **问题：** 当一个基础框架以“可建模型”“相对一致”或“可表示全部数学”为验收理由时，这种验收是否也已经对该理论中一个指定的过程完成问题作了判断？

## 1. 本次不再问错的问题

研究发起人的方向不是要证明 ZFC 不能表示时间、步骤或计算。那会被 ZFC 对序列、递归和机器计算的常规编码能力反驳。本次要审的是更窄的基础验收问题：

```text
Done_meta = 一个模型构造、规则解释或相对一致性结果已经完成
Done_Q    = 固定 HoTT universe questioning Q 是否在有限阶段完成
```

二者只有在一份来源明确提供 `Done_meta → Done_Q`、或把前者提升为对过程／现实任务充分的 `AdequacyLift` 时，才是同一条可归责的链。没有这个桥，不能把“ZFC 允许建模”改说成“ZFC 已把 Q 判为可完成”或“ZFC 放过了 Q”。

本卡在 H083 的范围控制之后，直接阅读三份一手材料，确定它们实际承诺什么。

### 2.1 精确来源锚点

- KLV 的摘要和导言把工作说成模型构造与相对一致性；其主要定理把对象理论明确限定为附录 A.2 的 logical constructors 与 univalence，并假设两个不可达基数。见 [作者公开 PDF，第 2–3、39 页](https://www.math.uwo.ca/faculty/kapulkin/papers/simplicial-model.pdf) 和 [EMS 的正式版本摘要](https://ems.press/journals/jems/articles/274693)。
- HoTT Book 说 ZFC 内模型构造“超出本书范围”，而非在该处给出一种过程／现实充分性定理。见 [Book，第 423 页](https://homotopytypetheory.org/wp-content/uploads/2013/03/hott-online-611-ga1a258c.pdf)。本地固定版本的对应原文在 `HoTT/theory-schema/upstream/book-578b85cc/reals.tex:3012–3023`。
- Book 的导言把 ZF 的基础性说成对象与构造可以编码，并以 ETCS 式可表示性支持 HoTT 的基础比较；它没有把这个标准写成完成某个运行过程的 oracle。见 [Book，第 17–18 页](https://homotopytypetheory.org/wp-content/uploads/2013/03/hott-online-611-ga1a258c.pdf)。
- 该书也明确说，set-built concrete model 可能具有抽象理论并不内在具有的性质。见本地固定原文 `HoTT/theory-schema/upstream/book-578b85cc/homotopy.tex:2363–2369`。

## 3. 这对“ZFC 的时间观察力”意味着什么

从这些来源得到的不是“ZFC 看不见时间”，而是一个更准确的分层结果：

```text
ZFC 可作为语义元理论，表示并证明许多过程性事实。
KLV 的 model/consistency Done 是关于一组被列出的规则的语义模型。
固定 Q 的 Done 是关于一个具体 Cubical Agda 过程的有限停机。
目前没有来源把这两个 Done 识别为同一义务。
```

因此，模型论的成功本身不是本研究所说的“放过 HoTT”。它正确完成了自己的语义任务。真正可继续进攻的地方是更上层的**基础充分性判准**：当文献把“可表示”“有模型”或“相对一致”用作某理论可充当基础的理由时，那个判准是否需要声明自己对哪些过程完成问题没有判断力？

这使研究发起人的“不是没有时间维度，而是观察力不完备”获得一个可检验的版本：不是指 ZFC 的语言能力，而是指**基础验收标准是否包含过程完成的观察接口**。当前原典还没有提供把这一缺口升级为对 ZFC 的定理性判词的 `AdequacyLift`，所以它仍是 `HYPOTHESIS_UNTESTED`。

## 4. C-357 在这里到底证明了什么

`C-357` 是这个来源问题的形式控制，而不是对 KLV 或 ZFC 的替身。它在固定 Cubical Agda universe 上机器证明：

```text
Q(original universe)        = never
Q(set-truncated universe)   = stage-one success
no uniform recovery         = true
```

因此，若将来有某个实际基础验收器被来源显示为：它把原对象映到会让 Q 停止的粗观察，随后又把这一停止当作原 Q 已完成，那么它必须支付一个保持／恢复桥。没有这笔 payment，不能把粗完成写成原完成。

`C-357`没有显示 KLV 的单纯集模型做了这个映射；事实上 KLV 的已声明对象语言并没有覆盖 C-357 中使用的完整 Cubical Agda / HIT 过程包。这一点是反过来的重要控制：不能把不同理论变体偷换成“ZFC 已经验收了同一个 H0”。

## 5. 现在形成的真正 Q 候选

```text
Q_foundation-adequacy:
当“理论 T 可以作为数学基础”的判断，以可表示性、模型或相对一致性为 Done 时，
它是否必须对 T 中被当作构造／确认的指定过程 P 说明：
P 的完成观察被保留、被反映、被有意排除，还是根本不在验收范围？
```

这是 `Q-1_SEED`，因为它已有基础性来源的真实消费者（“foundation / representability / model”语句），却还没有同一来源把基础资格提升为“每个过程已经现实充分”的强 claim。它不等于 ZFC 的内在矛盾，也还不是罗素式 `Q-4`。

## 6. 同理论变体方向的正控制：过程语义不是不可得的

同理论变体搜索已经找到一个重要的反向控制。Cubical computational type theory 的文献不是只给模型存在性；它把“项如何求值到 canonical value”直接写进语义对象。

- Cavallo–Harper 的 2019 论文给出 cubical inductive types 的 0-truncation，并以 canonicity theorem 说明其元素会求值到值；论文明确将其工作放在 operational semantics 的问题中。[论文 PDF，第 1–4 页](https://www.cs.cmu.edu/~rwh/papers/higher/paper.pdf)
- Cavallo 的后续论文／论文集材料给出了 set truncation 的二维 `squash` 规格，说明这种过程性处理不是只能谈 propositional truncation。[论文 PDF，第 115 页](https://staff.math.su.se/evan.cavallo/works/phd-thesis-latest.pdf)
- Cubical Agda 的公开说明与论文则说明它实现的是 CCHM 的一个变体，具有原生 univalence 与 HIT 支持；但这不是一条“它与 Cavallo–Harper 的计算演算逐定义相同”的定理。[Agda 文档](https://agda.readthedocs.io/en/latest/language/cubical.html)；[Cubical Agda 论文](https://staff.math.su.se/anders.mortberg/papers/cubicalagda.pdf)

这给出了三项范围明确的结论：

```text
PROCESS_SENSITIVE_META_SEMANTICS_EXISTS
SET_TRUNCATION_COMPUTATIONAL_SEMANTICS_EXISTS_IN_A_RELATED_CUBICAL_CALCULUS
EXACT_QUESTIONING_DELAY_TRANSLATION_NOT_YET_ESTABLISHED
```

它反驳了“所有基础性语义必然只能静态化地接受 HoTT”的宽读法。反过来，它也没有证明 ZFC/KLV 隐藏了 Q：Cavallo–Harper 的演算、CCHM/Cubical Agda 变体、guarded Delay 和本项目的精确 `QuestioningDelay` 还没有被一条保过程的翻译接起来。

这里出现了对研究发起人直觉最有用的对照：**ZFC 可以编码过程；而计算型 cubical 语义把求值／canonical value 本身列为验收对象。** 所以“时间观察力”应当被定义为某个验收契约有没有这类过程完成的观察，而不是误说为某个系统能否写下时间变量。

## 7. 下一项可证伪工作

下一项不是继续把 KLV 当作同一理论的模型，而是二选一的有界研究：

1. 找一份版本固定的基础文献，明确把模型／相对一致或“可表示一切数学”升格为过程／实践充分性；它将成为真正的 `AdequacyLift` consumer，随后可用 C-357 的保持／恢复测试审它。
2. 从已找到的 cubical process-semantics 文献出发，固定它的 0-truncation、canonicity、univalence 与本项目 `QuestioningDelay` 的逐项翻译表；若可以覆盖 exact Q 并在模型端同样证明 Q 为 `never`，那是反控制，说明模型没有把该过程悄悄抹平。

两条路都可能反驳现在的猜想。它们的共同要求是保住同一理论变体、同一过程和同一个 Done。
