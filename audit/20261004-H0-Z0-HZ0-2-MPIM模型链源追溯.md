### 1.1 这次题名检索实际补上的东西

研究发起人指出该题名在 Google 中会展开出大量语义相近的页面。这个现象本身不减少它的价值：它迫使我们从“题名相似”回到可核验的模型关系。2026-10-04 的重查现在给出两条更强、但仍有范围的原典锚点：

1. Agda 官方文档明说，Cubical Agda 实现的是 **CCHM cubical type theory 的一个变体**，并列出计算性单价性、HIT、`transp` 与 `hcomp` 等语法面；它没有把任意版本的完整库等同于一个已列出的 cubical-set model。
2. Mörtberg 的讲座材料明说：standard CCHM cubical type theory 的 model structure 是“Cubical Agda is based” 的那条路线，且该 model structure **不**与 spaces Quillen equivalent；同一材料把 equivariant cartesian model 单列为与 spaces equivalent 的模型，又把“Cubical Agda 对 cartesian cubical type theory 保守”列为一个 *seems very hard* 的 dream，并说定义翻译与证明翻译的难度不同。

这把原先的 `HIGH_CONFIDENCE_INDIRECT_IDENTIFICATION` 收紧成下列、较准确的判词：

```text

EXACT_CUBICAL_AGDA_2_8_0_LIBRARY_SEMANTICS_UNPAID
CCHM_TO_CARTESIAN_PROOF_TRANSPORT_NOT_ESTABLISHED_WITH_SCOPE
```

第三行不是“不可能性定理”。它记录的是来源自己没有给出、且将证明翻译描述为困难的那一步。尤其要分开两件事：MPIM 第一段的“转成集合论中的证明”，和第二段的“在 classical homotopy theory of spaces 中呈现”的模型目标，并不因都出现 `cubical sets` 而成为同一支付。
