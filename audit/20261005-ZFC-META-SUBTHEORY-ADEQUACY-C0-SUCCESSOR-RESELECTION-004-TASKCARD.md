# C0 successor reselection 004：F-C 的 direct-M adequacy-duty 来源

> **身份：** `CORE_ADEQUACY_TASK_CARD / ACTIVE_SUCCESSOR_SELECTION / NOT_A_MATHEMATICAL_RESULT`。
>
> **前序：** [C0R4 Earman–Norton physical-model control](20261005-ZFC-META-SUBTHEORY-ADEQUACY-C0R4-EARMAN-NORTON-PHYSICAL-CONTINUUM-CONTROL.md)。

## 目标

不再问“能否给某个连续物理模型补出 bridge”：C0R4 已经给出一个条件性 Newtonian positive control。现在只问更窄、也更接近 bare ZFC 的问题：

```text
是否存在版本固定的 foundation source，明确把
  物理过程的 target / operation / observation / OriginDone bridge 审计
列为 set-theoretic foundation M 自己的 adequacy responsibility？
```

## 所需字段

| 字段 | 本卡所需 |
|---|---|
| `M` | bare ZFC、ZFC with Choice，或明确以 ZFC/set theory 为其基础框架的 foundation source；版本与文本身份固定。 |
| `S` | 明确的物理／连续统 subtheory或科学模型，而非纯数学 surrogate。 |
| `P` | source实际从 mathematical representation/derivation走到physical application或完成判词的规则。 |
| `Bridge/Adequacy` | source明确由 M 本身承担检查、解释、保真或拒绝该 application bridge的责任。 |

## 最小判别行动

```text
C0R5-F-C-DIRECT-M-DUTY-DENOMINATOR

先做一个小而版本固定的 source screen：
  set-theoretic foundation / ZFC / scientific representation / physical model /
  interpretation / adequacy / application / motion / process completion。
只留下同时出现M、具体physical S和M自身责任句的来源。
```

## 假阳性排除

- 哲学家说数学模型须有 target/accuracy/applicability，但没有把该责任赋给 set-theoretic foundation本身；
- 物理教材给 trajectory/endpoint，却未出现 ZFC / foundation role；
- ZFC 能编码模型或序列，却未把 encoding提升为实际 process adequacy；
- AI 自己提出 `Q_norm`，却没有来源显示 bare ZFC 已经采用它。

## controls 与停止

| 项 | 含义 |
|---|---|
| `Control+` | C0R4：物理理论可以自己给出条件性 process bridge；这说明研究对象不是“bridge 不可理论化”。 |
| `Control−` | C5A–C5E：数学 foundation 的 representation/risk/proof role 与 applied-model target/accuracy 已被来源分层。 |
| local stop | 若筛选结果只得到上述任一单层，记 `DIRECT_M_DUTY_SOURCE_NOT_FOUND_WITHIN_FROZEN_DENOMINATOR`，转下一个未穷尽 C0 family；不得据此称 bare ZFC 已无责任或无问题。 |
| bridge payment | 若发现同一 source明确赋权 M 审计 physical bridge，进入 C1–C5 same-contract card；不得跳进C6。 |

## 成功／重开

- 成功不是“找到 ZFC 文献”；成功是 source 把 **M 的 foundation role** 和具体physical `S/P/Bridge` 明确接在一起。
- 新版 source、源文明确的 foundation-to-physics semantics、或用户重定 M/OriginDone 时重开。
