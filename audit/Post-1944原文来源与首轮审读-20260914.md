## 三、全文结构与决定性主张

### Introduction 与 §1

Post 把 r.e. 集合定义为一元递归函数的值域，并用“生成过程”给出直观解释：元素一旦生成就保持在集合中。他明确把一般递归、Church λ-definability 与 Turing computability 当作已经证明等价的技术形式，同时把“它们穷尽直观有效可算”作为有强证据支持的原则，而不是形式定义本身。

§1 给出经典双半判定桥：集合 recursive 当且仅当集合及其补集都 r.e.。反向算法交错两边的枚举，有限时间内必在一边发现输入。这直接映射到本项目的 `R2-SEMIHALT`：一个正半判定不等于总判定；互补正半判定才产生总答案。

### §2–§4：Gödel miniature、complete/creative sets 与 reductions

Post 有效枚举所有 r.e. sets 的 bases，并构造 complete set `K`。§2 的对角构造被他称作 Gödel theorem 的微缩形式：对任何 r.e. subset of the complement 都有效给出一个仍在 complement 但不在该 subset 的元素。

§3 抽象出 creative set：r.e. set 的 complement 具有统一 productive operation；`K` 是 creative。§4 定义 one-one 与 many-one reducibility，并证明任意 r.e. set one-one reducible to `K`，creative sets 处于同一最高 r.e. unsolvability degree（在这些 reduction 口径下）。

这些内容为机器统观提供两个不同 obligation：

1. 可数代码／统一枚举／self-application 的构造；
2. reduction 必须保持同一个 membership decision task，而不是只保持“都很难”的叙述。

### §5–§10：simple/hyper-simple 与 reduction 强度

§5 构造 simple set：它自身 r.e.，补集无限但不含无限 r.e. subset，因此其 decision problem 不 recursive。随后：

- bounded truth-table reduction 下，creative set 不能 reduce 到 simple set；
- unrestricted truth-table 下，某 simple set 又可与 complete `K` 同 degree；
- hyper-simple set 加强 complement 的稀疏结构；creative set 不能 truth-table reduce 到 hyper-simple set。

这说明“不可判定”不是一个足够细的统一标签；选择 many-one、bounded truth-table、unrestricted truth-table 或 Turing reduction 会改变 degree 结论。对应本项目，`certified reduction` 必须冻结 oracle 能力、查询是否自适应、完成条件和允许的观察层。

### §11：general Turing reducibility、oracle、时间序列与完成识别

§11 是本研究最直接的经典前提。Post 把单生成过程描述为 “act succeeds act in one time sequence”，并解释 Turing reduction：机器在运行中可向另一个 decision problem 提问；后续所问整数通常依赖先前问题的正确答案，所以 oracle 查询具有真实时序依赖，不是预先固定的 truth table。

更关键的是，Post 区分：

- 一个 basis 生成的 r.e. set **事实上有限**；
- 把过程排成单一序列后，**存在**某个最后成员已经出现的 stage；
- 一般并没有有效方法为每个 basis 指出何时可以宣布全部成员已经获得。

这三层分别是对象性质、存在量词和当前可确认的 completion certificate。它们不能互换。该例与用户的“时序”定义高度对齐：问题不是抽象的物理时间稠密性，而是依赖回答的先后、证据何时可用、以及理论对象的完成是否已经在计算过程中落定。

Post 最终仍未解决后来所谓 Post’s problem：在 Turing reducibility 下，是否存在介于 recursive degree 与 complete r.e. degree 之间的 r.e. degree。他诚实把它留作问题；不能把文中的 candidate simple/hyper-simple constructions 写成已经解决。

## 四、对当前三条薄切片的作用

### `R2-INTERNAL-UNDEC-001`

Post §1 证明“正枚举 + 补集正枚举 ⇒ 总判定”；本项目 Coq synthetic `undecidable` 恰把假设 target decidable 推到 `complement SBTM_HALT` enumerable。要得到内部矛盾，还需要一个明确的“该 complement 不 enumerable”原则／模型定理。Post 的 paper 本身不为当前构造元理论提供这个最后否定。

### `G-HOTT-SYNTAX-001` / R3

§2 的 Gödel miniature 需要：可数 basis、有效 enumerator、对角 membership/self-index、productive operation。映射到 exact HoTT calculus 时，必须分别提供 syntax code、proof enumeration、substitution／quotation、representability 和 inner/outer theorem transport；“HoTT 有 Nat”并不足够。

### HoTT completion candidate

Post 的 finite-r.e.-set completion gap 可映射到：

```text
mere finiteness / truncated finite presentation
    versus
chosen enumeration + a stage certified complete
```

本项目 C-141 已证明一类 `isFinSet` 形状接口不能统一恢复枚举；那是防御结果，与 Post 的警告同向。新的候选只有在社区 natural consumer 把 mere finiteness 当作“当前枚举已完成”时才成立。Post 的 reduction analysis 是自然**问题来源**，还不是 HoTT consumer，也不是现实桥梁。

## 五、时间与时序

本 paper 对“时序”的贡献可以精确记录为：

- monogenic computation 的一步接一步；
- adaptive oracle query 的后问依赖前答；
- positive enumeration 的信息只增不减；
- finite extension 的最后元素已经出现，不意味着过程能识别完成点。

它不讨论运动、时空连续性或数轴稠密性，所以不能替代“时间”轴上的芝诺／连续体问题。它为时序轴提供一手计算理论来源。
