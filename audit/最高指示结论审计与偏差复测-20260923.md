# 从两项理解偏差到逐结论审计：方法设计与复测

对象是AI在HoTT现实相对研究中的理解、精化与表达行为。当前要判断：AI能否保住原问题、识别解释中的加码、记录自己的结论并主动防止同形偏差重现。采用原文对照、单体指令修订、预注册病例与实际Astra Ultra任务；这些证据不证明数学命题、神经网络权重变化或永久能力。

## 1. 本轮要求与直接回应

用户标注一：来源／复原合同可以帮助精化圆环问题，不能替代零大小点、反向逼近与此前已得到M的原问。应测试AI是否能自己识别这种替换，而且能区分合理精化与侵占原意。

用户标注二：AI阐释将助力／阻力观察写成“定量断言”等表述，需要检测解释是否增加了量化关系、普遍性或确定性。同时审查自己的纠错：仅凭“定量断言”与“不是定律”两个名称，不能推断形式逻辑矛盾；应逐句定位实际新增的语义及证据。原始用户强式表达按来源身份保留，不借审计暗中弱化或争辩其研究视角。

本轮结果 owner：[最高指示](../最高指示.md)第四稿§7.4。旧第三稿字节保留在上一试验的directive-B及本试验directive-C；不会以本次修改追溯认证旧稿。当前档位T1，STATE仍revision268；无数学结论、core、扩展原文或研究checkpoint更新。

## 2. 为什么需要逐条、逐链和整体三个层次

逐句真实，不保证整体回答了原问题。几句关于来源字段的局部真话若被用来替代圆环整个问题，偏差发生在选题与推断关系。故审计同时看：单条表达有什么依据；表达之间怎样推导、是否偷加前提；整个回答还保留了原问题的哪些部分与未覆盖面。

所谓“全面”，在本设计中指会改变本次判断的重要角度可见并得到处理；不是所有模型同时使用，也不是不能选择一个有界分支。所谓“主动对抗复发”，要看换题后的实际输出、修正传播和新结论记录，不能只测是否能背诵警句。

## 4. 结论记录怎样工作

断言单位按可独立保留／撤回划分，不按句号机械切割；并列断言拆开，同义重复共用ID并关联全部位置。对原意、来源、因果、效果、覆盖和完成作判断都登记；假设藏在问句里也检查。每条有原句／位置、身份范围、依据及AI新增内容、具体审计理由、处置、依赖与复核。使用当前任务Markdown表，所有D维度考虑适用性；相同理由可合并N/A，不要求24份重复长文。

纠正必须进入正文、摘要及依赖结论。未知可保留，但不得被下游当作事实；“全写成未知”会使发现产物考核失败。只记录公开结论与可检查理由，不记录私有思维；已有审计理由复用原证据，新增独立断言才另登记，避免无限自审。

本次也发现第三稿的一处跨段残留：§4.5已恢复圆环原问，六例汇总行仍列“来源复原”。第四稿已改为“反向逼近与复原”。这是D20所针对的实际问题，说明前次结构PASS不等于全文语义已无残留。
