## 设计结果

独立 probe 提出 P2 的最小中间表示：

```text
Bind(φ) → Form(φ)=u → Bridge R(x,u)↔κφ(x) → Reenter x:=u
→ normalize φ(u) to H(q), q:=R(u,u) → Polarity / Guard / Trace
```

P2 的正匹配不由“自指”一词决定，而由六项可审事实决定：条件在对象语言可绑定；形成规则真交付对象；bridge 的域和方向明确；`u` 可合法回代；回代后能证明归约到同一局部判断 `q`；理论专属逻辑可评价 `q↔κH(q)`。缺任一项即应报告 `PARTIAL`、`GUARD_BLOCKED` 或 `UNKNOWN`。

## 关键分层

- `FINITE_SPECIFICATION_CONFLICT_CANDIDATE`：在同一已准入域中，形成、双向 bridge、合法回代和负极性归约产生有限局部反馈式，例如 `q↔¬q`；是否成为理论内不相容仍需理论专属 `ConflictOracle_X`。
- `ADMISSION_UPWARD_PROCESS_CANDIDATE`：回代或下一形成需要新层级、证书或准入，且理论未给出终止／闭包规则；这不能自动升级为矛盾或不终止定理。
- `GUARD_BLOCKED`：类型、域、阶段、界或证书阻止自代／闭合；这是反控制，不是全理论负结论。

## 正负控制

无限制条件形成、全域双向 bridge 和负极性条件能形成有限反馈正控制；有界或分层形成将输出移出 bridge 的输入域，故回代被 guard 阻断。将负极性改成正极性应保留反馈而拒绝冲突候选。

## 与 P1 的关系

P1 从理论 X 的基础对象、形成接口和真实消费者出发，判断位置、同一任务和使用次序；P2 从脱敏的计算／逻辑语法结构出发，判断 formation–reentry–polarity 的可编译形状。任一单独命中都只能产生线索；只有在同一理论变体、同一对象、同一消费者和同一任务中会合，才可进入来源、过程或机器验证。
