## 当前状态

本目录不是新的候选档案。它把既有九个 run 和十一份预检当作已读种子／控制语料，建立领域级检索的可重算协议。M0 已完成：问题、地图轴、数据库／作者／引文来源、纳入排除、去重、语言和停止规则已冻结。M1 已记录 OpenAlex、Crossref、IAS author-primary 与 OpenAlex forward-citation 的初始检索；它只证明地图执行已经启动，不证明领域覆盖或饱和。

当前不得声称：

- 已完成 HoTT、ZFC、逻辑史或数学哲学的领域文献地图；
- 当前 candidate-admission frontier 证明领域中没有新来源；
- 任何 M-Record 是 ZFC Q、H0→Z0 传输或数学结论。

## 目录和读取顺序

1. [PROTOCOL](PROTOCOL.md)：冻结问题、范围、来源宇宙与方法；
2. [SEARCH-LOG](SEARCH-LOG.md)：每次实际检索的原样 query、日期、平台、命中和导出范围；
3. [CANDIDATE-RECORDS](CANDIDATE-RECORDS.md)：去重前后的 work family；
4. [SCREENING](SCREENING.md)：纳入、排除、暂缓和原因；
5. [CITATION-NETWORK](CITATION-NETWORK.md)：backward、forward、作者和 bridge 追踪；
6. [COVERAGE-MAP](COVERAGE-MAP.md)：M-A 至 M-E 的覆盖和余项；
7. [FINDINGS](FINDINGS.md)：仅在地图范围内可支持的综合和下一触发。

## 与候选调查的接口

M-Record 只是“为什么发现并需要评估这篇文献”。一篇来源被地图纳入后，仍要经过 R/Z/Q/E 卡、同一任务、source payment 和模式 P 的门；地图扩大的是可见来源宇宙，不降低候选资格要求。
