## 来源报告的桥

`HMZ-S-028` 逐层区分并再连接：

1. 有限实物分类的完成条件是“所有初始集合中的对象被放入适当类别”（printed pp. 2–3）；
2. 对无限 set，作者说这种 partition “difficult to formalize”，并区分“对每个给定 \(x\) 能证明其属于一类”与把该过程理解为有 complete object-level classes 的 complete partition（printed pp. 7–8）；
3. 作者用 “apply the relation to all elements simultaneously” 与“all at the same time, keeping track”描写这一概念转换，并明确称之为 conceptual metaphor（printed p. 8）；
4. 紧接着，文章把 set-theoretic justification 写为：每个 class 由 subset axiom 给出，全部 classes 是 \(\mathcal P(A)\) 的子集，因此 Power Set axiom 给出一个 set（printed p. 9）；
5. 随后的 rational-number case 把 equivalence classes 作为 object，并称 classes 的 set 为 rational numbers（printed pp. 9–10）。

这比“Power Set”字面相邻强：它明确包含有限过程的 Done、无限 totality 的 conceptual hand-off、Power Set formation 与 object-level quotient use。
