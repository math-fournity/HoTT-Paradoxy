# HMZ-012：消费者、标准防线与竞争读法

## 1. 同一任务矩阵

| Field | finite categorization source | set-theoretic quotient source | Verdict |
|---|---|---|---|
| subject | a finite given collection of physical/cognitive objects | a set \(A\), relation \(R\), classes and a class collection | not source-proved identical |
| operation | place each item in a category | form/prove a set of classes, derive partition facts | different mechanism |
| observation | an object has been placed | membership/equality/partition assertion | different observation layer |
| Done | every original item placed | an object E exists with stated properties | different source-stated completion condition |
| bridge | Dochtermann calls the generalization a conceptual metaphor | Power Set/subset sethood is the stated formal resource | analogy is not same-task proof |

## 2. Positive controls

| Control | Source effect |

## 3. Standard defenses / payments

| Defense/payment | Direct source support | Limit |
|---|---|---|
| Power Set / subset formation | Dochtermann, Shulman, Metamath. | It pays formal sethood; it does not by itself establish a real-process equivalence. |
| `RepFun` / functional replacement | Paulson manual + EquivClass source. | It changes formation route relative to the \(\mathcal P(A)\) bridge. |
| `equiv`, congruence, membership and typing guards | EquivClass source. | Shows one formal consumer’s local discipline; not a global ZFC theorem. |
| “conceptual metaphor” qualifier | Dochtermann source. | Prevents silently identifying formal and finite cognitive Done. |

## 4. What would change the result

One source must be able to show all of the following in one stable layer: a quotient consumer using the Power Set-subset route, a declared completion condition that remains the finite-style process completion, and a use/formation or admission structure that does not already have an explicit formal payment. Without that, the result remains a valuable `P_REQUALIFICATION_REQUIRED` construction bridge, not a Q.
