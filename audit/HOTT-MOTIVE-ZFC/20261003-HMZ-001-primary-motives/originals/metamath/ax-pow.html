Axiom ax-pow 5327
Description: Axiom of Power Sets. An axiom of Zermelo-Fraenkel set theory. It states that a set 𝑦 exists that includes the power set of a given set 𝑥 i.e. contains every subset of 𝑥. The variant axpow2 5329 uses explicit subset notation. A version using class notation is pwex 5342. (Contributed by NM, 21-Jun-1993.)
Assertion
Ref Expression
ax-pow ⊢ ∃𝑦∀𝑧(∀𝑤(𝑤 ∈ 𝑧 → 𝑤 ∈ 𝑥) → 𝑧 ∈ 𝑦)
Distinct variable group:   𝑥,𝑦,𝑧,𝑤
