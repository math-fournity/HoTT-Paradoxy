# HMZ-002：消费者与标准防线

## HMZ-C-007 — Ahrens/North 的 equivalence principle 语言控制

| 字段 | 来源支持的内容 |
|---|---|
| 输入 | set-coded objects / structures，及相应同构或等价。 |
| 普通可写语句 | 例如 `1 ∈ ℕ`，其不随集合同构保持。 |
| 结构性任务 | 只讨论适当 domain 的 equivalence-invariant properties/structures。 |
| 观察 | property 是否保持；construction 是否随 equivalence transport。 |
| Done | 已指定满足 preservation criterion 的语言／性质类。 |
| 标准支付 | 类型化语言或 FOLDS 的 syntactic criterion，而非要求 ZFC 自动对一切公式作决定。 |
| 处置 | `EXPLICIT_LANGUAGE_PAYMENT / TASK_SPLIT_CONTROL`。 |

## HMZ-C-008 — representative payment chain

| 来源 | 支付 |
|---|---|
| Voevodsky Notes on Type Systems | 在指定技术模型中加入 well-ordering，使 standard isomorphism 至多唯一。 |
| Shulman 2008 | large category product functor / inverse equivalence / skeleton 明示 ordinary/global Choice。 |
| Mumford 1965 | universal family / automorphism 情形保留 maps 与 family 数据。 |

这三条不是同一理论的同一证明；它们共同阻止把“equivalence-aware”写成“无标记、无选择、无映射的免费行动”。

## HMZ-C-009 — ZFC consistency benchmark

Voevodsky 2013 ASL 的技术叙述和 Göteborg 讲演均把 ZFC 保留为 univalent model / 新 type-system extension 的
consistency benchmark。它不能证明 ZFC 没有局部表示边界；它阻止把作者提出的 UF 优势夸张成“ZFC 已被数学上击败”。
