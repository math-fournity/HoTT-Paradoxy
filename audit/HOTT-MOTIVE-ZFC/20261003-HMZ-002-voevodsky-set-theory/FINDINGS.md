# HMZ-002：equivalence problem 的有界判词

## 1. 来源支持什么

Voevodsky 2011 的确把 ZFC-based formalization 的 practical problem 描述为 equivalence problem；这不是
后来的 AI 猜测。Ahrens/North 的独立论文也确认一个更精确的版本：set-theoretic foundations 允许不随同构保持的
表述，而 equivalence principle 需要选择合适的 domain、性质／结构类别和语言约束。

因此本轮得到的是一条真正来源支持的 **表示与抽象纪律边界**：

```text
set-coded statement may be mathematically meaningful
≠ it is automatically a structural/equivalence-invariant statement
```

## 2. 为什么它没有进入 P/Q

模式 P 需要理论内对象、formation、consumer、active unpaid obligation，以及 source-supported reentry 或
completion/admission structure。当前来源恰好显示相反情形：

- 非不变性质没有被来源误认为结构性质；
- 结构语言的限制被明确付出为 typed language / FOLDS / UF 的语言设计；
- class、Choice、maps、well-ordering 和 practical syntax 都由来源显式标出；
- 没有一项来源让尚未形成或尚未合法的同一对象被其后的算符消费。

所以 `HMZ-Q-006`、`Q-007` 和 `Q-008` 都是控制／任务切换／反类比结果，而非候选种子。

## 3. 对 ZFC 方向真正保留下来的东西

这轮没有证明 “ZFC 没问题”。它保留了更精确的、可继续检验的问题：

> 是否存在一个版本固定的 ZFC-side consumer，声称一个 representation-sensitive construction 已经具有
> structural/equivalence-invariant 的同一 Done，却没有标出 language、Choice、maps、marking 或 formation payment？

这是下一轮可接受的入口。它必须从真实 consumer 原典来，不可由 “ZFC does not naturally distinguish” 这句
作者表述单独推出。

## 4. Stop / successor trigger

`HMZ-002` 已完成它的冻结来源分母。仅有新证据才应重开：

1. 一个真实 consumer 将 non-invariant 结构处理误报为 invariant delivery；
2. 一个来源使这种误报保持同一 `u/F/C/I/O/Done`，并带有 P2/P3 的结构；
3. 或一个新的 HoTT/UF 作者文本给出不同于 equivalence-language 的 ZFC 形成义务。

没有这种证据时，继续堆叠 equivalence 文献只会重复已归档的语言支付，不能推进 Q。
