# HMZ-008：消费者与标准防线

| 控制 | 来源支持的内容 | 阻止的误报 |
|---|---|---|
| `HMZ-C-016` semantic stability | Lumsdaine–Shulman 列出 fibrancy、fibrant replacement、pullback/substitution stability、strict stability、语法限制。 | 不把“模型存在”写成无条件、无成本的 native formation。 |
| `HMZ-C-017` Set/ZF positive class | Swan 在 ZF 无 Choice／无 unbounded regular cardinals下构造一类 image-preserving QW-types。 | 不把 R-HIGHER 的 `directly` 写成 ZF 连某类 HIT 都不能表示。 |
| `HMZ-C-018` Set/ZF negative class | Swan/Blass/Gitik 的边界说明某 QW-type 在 ZF 中不 provably exists；广构造需要 regular-cardinal/weak-choice assumptions。 | 不把一类 ZF existence gap 写成 ZFC 的自指／formation defect。 |
| `HMZ-C-019` directness split | HoTT Book 的 type-forming rule与两个来源的 semantic initial-algebra/model Done 不同。 | 以改变 Done 的模型困难制造“HoTT做得到、ZFC做不到”的 UR。 |

这些控制为 `R-HIGHER` 保存了一条真正开放的检索式：寻找一个 **ZFC-level实际消费者**，它既要求 native/direct HIT
formation Done，又在没有声明 stability/cardinality/choice/representation payment 的情况下把语义模型当作同一交付。当前分母没有这样的来源。
