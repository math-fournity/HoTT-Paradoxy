# 第三轮机器统观独立审计工作法

## 目的与前置

审查A是否真的用用户的认知高度发现问题，是否保住原問和不同尺度，结论有无相称证据。正确证明一个换过的问题也可能不满足原任务；A存在缺点不抹去其正确局部成果。

先执行repo-cognitive-closure和项目共同治理，完整读TASK_ROUTING、[B单体闭包](../../../goal-6-audit.md)、[A单体闭包](../../../goal-6.md)、[审计细则](../../../goal-5-audit.md)及A研究范围。核用户授权的B身份与唯一输入，不能仅因文件存在启动审计或其它Agent。

## 输入与认知顺序

首次按核心→方向→全景→扩展全文读所有分片、最高指示及程序化规划。最高指示在新Session/压缩/角色变化/每个理论审计单元前全文重读；按INDEPENDENT_AUDIT作可见复述和必要生成/迁移检验。原意和证据等级不从A摘要继承。

先从原文、SOP和源分母形成独立问题，再读A总判词。核seal/manifest hash/subject commit，把输入复制到自身目录并固定信任锚。多代次有歧义先明确；A未交付则INPUT_NOT_READY，不能审空目录给PASS。live取证与封存证据分开，源缺件不得静默用新文件顶替。

## 审计循环

1. **原意与发现**：区分总目标、候选X_i及实际引用/承接的历史X_h，核理论收益、条件变化、敏感过程的实质联系。仅实际涉及原案时核相应原文：声称回答圆环不能用来源侵占点/逼近/返回已有M；AI展开不能加成用户的定量/全称断言。保留合理精化与明确假说。
2. **覆盖重建**：独立从理论源、Schema/TC/OP重建八域与可递归重叠的语义单元；五种方式不是固定深度。先形成自己的关键中层，再对照A的成员/关系/本层问题，核全部已接受中高层结案依据；全审排除/N/A/无命中/旧结果复用。无低层异常也审上层，不能用一例抵全层。
3. **关系与范围**：概念包含、依赖、顺序、多输入、反馈、翻译不混；局部无异常不自动上推全理论，整体怀疑不自动给成员定罪；FCA context外未知保留。
4. **数学与现实**：全审新强数学结论、决定性桥、范围和完成句；核精确命题/量词/前提/演算与source-run-index，必要原生复跑；现实桥保持X/Input/Op/O/Done。
5. **逐结论差集**：从正文/过渡/摘要独立提取断言，对照A账本，按D01–D24核漏记、加码、换题、归因、负结论和修正传播。B的新判断也登记来源/范围/依据。
6. **方法与治理**：核重新呈现、上下往返、无信号结构驱动、真实HoTT重组及删中层/漏联合/抹顺序等负例与正常控制、留出、恢复和证据链。分别审共同背景、联合/有序/反馈、参数族与配置边界；只给五层标签或子项PASS不算高层审查。脚本检测预给组合不证明AI自主发现。
7. **形成问题与复核**：逐finding给原句/locator、直接证据、严重度、影响依赖、最小修正与重验条件；不以新发现一个范围外问题否定一切有界完成。

不得因A没有历史类比、圆环对应或固定题材配额判失败；也不得因它研究圆环/环路就判锚定。按实际机制、来源、X_i、过程及父级覆盖判断。留出须相对当前主机制有实质差异，题材名称不同不足以证明，题材相同也不足以否定。专门偏差回归可用历史案例，但不能使每个研究候选都承担历史桥。方法版本改变时分别审当时行为与新版后继义务，不据新措辞伪造旧违规。

引用准确、局部类比有效、声称回答原案的任务桥是三种不同义务；按最高指示§0B判定，不把“受到启发”或单纯引用升级成必须解决历史全案。

## 副本重放与权限

B只写`第三轮机器统观/Session-B/`、明确获准的自身`.codex/research/hott/sessions/S-AUD-MO3-*`审计记录和强制dev-notes。A证据、STATE/投影、core、proof矩阵/registry、历史收据只读；不checkpoint、commit/tag/push，不发消息给A，不spawn。

Agda等会生成缓存，复跑在B独占副本与缓存中。核工具/库/源hash，保留argv路径重映射、flags、stdout/stderr/exit/观察窗；不改A原件，不调用注册primary/replay等有副作用的writer。语义复跑与字节exact输出分别说明。

## 恢复、输出与完成

压缩后重新读本Skill、B闭包和最高指示，恢复固定输入hash、待审分母、已决finding、未证项和下一动作；角色不可从A切入。源、SOP或交付代次变化标stale，按delta重审，不复用旧PASS。

输出审计报告、问题清单、结论账本及实际复跑证据。裁决为PASS_WITH_SCOPE/REVISION_REQUIRED/FAIL_WITH_EVIDENCE/INCONCLUSIVE_MISSING_EVIDENCE；A不合格可成为已完成审计的结果，关键必审证据或复跑缺失则审计未完成。报告绑定该seal，不永久认证AI能力。不得为完成审计反向降低用户研究要求或替A补产物。
