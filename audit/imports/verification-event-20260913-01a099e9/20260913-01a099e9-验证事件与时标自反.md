## 我现在能给出的判断

我们已有的认识，足以使研究者迅速提出一个很短、很有针对性的构造。不能再把“尚未掌握整个理论”当作无限准备的理由。但是，“能一眼看见一个值得推演的结构”“能证明它在 HoTT 中产生所要求的现象”“这个结构没有人想到过”，是三个不同的判断。

我愿意正面提出一个候选，而不是继续列出宽泛方向：

> **让“某个命题已经被验证”成为理论能够谈论的事实，再让验证过程处理一条关于它自己尚未完成验证的陈述；检查理论是否在抽象中把验证前、验证后，以及关于过去的陈述混成了同一个对象。**

这个思路的机巧，不在于要求一个万能停机判定器，也不在于先假设一个不可能的全域自证器。它把注意力放在一个极小、现实中很普通的变化：一次验证发生了。接着追问，理论是否忠实保留了这次发生前后，待判断命题的身份。

它与我们的 ASK、自反、理论经济和时序认识有直接联系。不过，文献核对已经揭示了明确的先例：Church–Fitch 可知性悖论、Moore 型陈述和动态认识逻辑都讨论过相近结构。因此，我不能把下面的思想骨架说成“众人从未想到”。可能值得做的新工作，是一个精确的 HoTT 表达与翻译问题；其新颖性和有效性目前均未成立。

这不是把候选压回去。它是把真正可能产生研究价值的位置标出来，避免再把一个旧论证换上 HoTT 的名字就宣布发现。

## 先用一个普通情境看见问题

考虑某个固定的事实 P。我们关注一位观察者在两次事件之间的变化：

- 在 s₀，观察者还没有取得并登记 P 的有效证据；
- 在 s₁，观察者取得证据，完成核查并登记结果。

这只是一个拟用于形式化的场景。暂不把“存在一份证明”“观察者已经持有证明”“本次核验已完成”当成同一个状态。

现在构造两种句子：

**固定过去的句子：**

> P 成立，而且在 s₀，观察者尚未验证 P。

**随当前状态重新解释的句子：**

> P 成立，而且观察者现在尚未验证 P。

它们在某个时刻可以看起来一样，但在验证发生之后，需要检查它们是否仍然在说同一件事。验证后回顾“刚才还没验证”，与验证后断言“现在仍没验证”，承担的语义责任不同。

这个候选要抓的就是这里：理论如果为了得到一个可反复使用的静态命题，省去了状态、时标或验证事件的归属，后续推演有没有把对过去的正确判断，错误地变成对当前的判断？或者反过来，是否把一个本来可以回顾核查的历史事实，变成了理论里不能被验证的对象？

请注意，**“验证会改变对象”仍需说得精确**。它未必改变 P 所描述的外部事实；可能改变的是观察者的证据状态，以及含有“现在未验证”的陈述在当前状态下的解释。若把这两种变化混同，候选本身就已经换了题。

## 机巧在哪里：把验证条件放回被验证内容

普通验证的注意力集中在 P。我们现在把注意力转移到“P 与验证 P 这件事之间的关系”。

这和哥德尔式研究的联系，是方法上的：允许理论谈论自己的证明或验证活动，再考察这些活动进入对象范围之后发生什么。这里并没有完成哥德尔编码、对角引理或 HoTT 内部不完备性证明；甚至不需要把初始候选写成一句引用自己代码的句子。先从谈论观察者自身的验证状态开始，就可能得到一条很短的检验路径。

为什么这比不断增加“删去信息后无法恢复”的例子更值得试？因为这次被省略的东西参与了后续动作本身。我们不只是拿两份静态数据作比较，而是让一次验证发生，再检查理论是否仍然处理原来的问题。

设想一个研究者声称，他提供的表示足以描述验证过程，并且能把真实证据转化成可使用的判断。那么我们可以要求他只回答这一小段历史：取得证据以前怎样，取得证据以后怎样，后来能够证实的关于过去的事实是什么。若这种最小过程已经需要改变表示的语义，研究者就应解释改变了什么。

但我不把“某人声称表示完整”偷偷当成 HoTT 的公理。这个承诺必须来自具体的表达、翻译或任务，并在推演中有明确位置。候选的锋利程度取决于把这一位置找出来，而不是把指控说得更强。

## 最近的已知亲缘：不能把熟悉的悖论认作原创

Church–Fitch 家族提供一个简短的校准。以下只是文献论证的转述，SOURCE_REPORTED_NOT_REPLAYED，不作为本轮新证明。

令 K 表示文献中固定语义的知识算子。对 q = p ∧ ¬Kp，若假定 K 对合取消去封闭且具有事实性，则文献考察：

    K(p ∧ ¬Kp)
      → Kp ∧ K¬Kp
      → Kp ∧ ¬Kp.

再加上相应的可知性原则与模态规则，就得到熟悉的可知性问题。不能只用这三行替代全部前提，也不能把没有时标的 K 任意翻译成“今天已经知道”。关于这一论证与类型化方案，可参见 Lucas Rosenblatt 的论文《The Knowability Argument and the Syntactic Type-Theoretic Approach》（2014）：[论文来源及信息](https://philpapers.org/rec/ROSTKA-4)、[期刊论文 PDF](https://www.redalyc.org/pdf/3397/339732249002.pdf)。本轮读到了检索返回的论证段及脚注，PDF 的后续打开失败；不声称全文精读。

更直接相关的是 Hans van Ditmarsch、Wiebe van der Hoek、Petar Iliev 的《Everything is Knowable》。论文把宣告前后的认识状态纳入动态分析，也明确区分“更新后知道某事是否成立”与“知道它在更新前是否成立”。因此，观察与更新怎样影响含认识算子的命题，并不是一个未经研究的方向。[作者版论文，尤其 §§2–4](https://personal.us.es/hvd/newpubs/Theoria_final.pdf)。

这些先例有两个作用：一是表明这个短构造有严肃的研究背景；二是当场阻止我声称“我刚刚发现了没人想到过的全新悖论”。我们需要寻找的是更精确的 HoTT 问题，而不是掩去先例。

## 必须先通过的反向检查：时标有没有使我们换了命题

用 Kₛ(P) 暂记“在状态 s，观察者具备指定意义的 P 验证资格”。这还是记号草案，真正的语义需要由下一节固定。

对固定的过去状态 s₀，候选陈述写为：

    Q₀ := P ∧ ¬Kₛ₀(P).

后来我们研究 Kₛ₁(Q₀)。即使允许相应的合取消去和事实性，从中需要追踪的也应是：

    Kₛ₁(P) 与 ¬Kₛ₀(P),

而不是把第二项改成 ¬Kₛ₁(P)。这指出一个需要保留的正向情境：后来取得 P 的证据，同时确认先前尚未取得。

因此，本轮首先要排除的伪路线是：

    关于 s₀ 的“尚未验证”
        被无说明地改成
    关于 s₁ 的“仍未验证”.

若所谓 HoTT 悖论只靠这一步出现，它目前揭示的是命题身份被改写，不能据此判定 HoTT 有问题。

也不能由这个局部时标分析宣布“Fitch 悖论已经被时间彻底解决”。文献还会考虑不同的时间、主体、可能性与量词范围。例如“在 s₀ 未知”与“从未、也永远不会被任何人知道”不是一个命题。把一种表达中的伪冲突澄清，不等于反驳全部可知性论证。

这项反向检查不会消灭候选的价值。它使真正要寻找的步骤变得具体：**HoTT 中哪一种合法抽象、替换或表达习惯，会使原任务需要的状态归属不再可用；这种变化是否仍被允许承担原来的验证任务？**如果没有这样的步骤，就应停止把这个候选称为 HoTT 的现实相对问题。

## 怎样把它变成 HoTT 的问题，而不只是在 HoTT 中写几个字母

最重要的决定，是不要直接规定 K(P) = ∥P∥，然后把“命题可居留”读成“某个人此刻已完成验证”。

《HoTT Book》在命题截断一节给出构造子与受限消去规则，并在标签为 thm:prop-equiv-trunc 的引理中说明：若 P 本身是 mere proposition，则 P 与 ∥P∥ 等价。这是书中结果的来源转述，本轮未在内核重放。它提示我们，单靠对一个 hProp 再作截断，并没有自动表达观察者、获取事件与截止状态。[官方原文，logic.tex 的命题截断及相关引理](https://raw.githubusercontent.com/HoTT/book/master/logic.tex)。

也不能忽视已有认识逻辑对“知识”的不同解释。Artemov 与 Protopopescu 的《Intuitionistic Epistemic Logic》把验证、严格证明和知识的关系分开，讨论了截断解释及不同的反射强度，并以此回应可知性问题。这是需要比较的理论选择，不能摘掉作者的语义限定，把其 K 直接当成现实的“已经验证”。[arXiv:1406.1582v4，§§2、5](https://arxiv.org/html/1406.1582v4)。

我建议的 HoTT 候选，应从**验证事件的表示**开始。下面是待实现的规格草案，不是已通过类型检查的源码：

    T                 一个固定的对象理论片段
    Code(T)           该片段的命题/表达式代码
    Certificate(T,p)  针对代码 p 的证书数据
    State             观察者的事件状态
    Issued(s,c)       证书 c 在状态 s 已取得或登记的证据
    Accepted(T,c,p)   固定检查规则接受 c 对 p 的证据

拟考察的对象是：

    Kₛ(p) := ∥ Σ c . Issued(s,c) × Accepted(T,c,p) ∥.

这份规格把三件事分开：有某种数学证据、该证据被固定检查规则接受、该观察者在指定状态已经取得它。状态可以来自一段有限事件历史，初始实验不需要物理连续时间。

这里有几项真正的义务，不能用名字补掉：

1. Code(T) 必须是实际定义的有限语法，不能直接假设一个能评价全部 HoTT 类型的语义函数。
2. Accepted 必须对应可检查的证书规则。接受与真值之间的桥梁，要按固定片段另外证明；不能把 T 的全局健全性免费塞入 T 自身。
3. Issued 必须对应所声明的事件历史，不能从“某处存在证书”直接推得“现在已经取得”。
4. 关于 Kₛ(p) 的陈述是否能回到 Code(T) 中，要检查类型层级、语法形成与解释范围。若只能在外部 HoTT 元理论中表达，应如实保持这个范围。
5. 同一状态下的知识是否对合取消去封闭，需要按 K 的意义检查。现实提取或核验可能花费步骤，不能把逻辑闭包自动读成零成本即时交付。

这些义务不要求先把整个 HoTT 形式化一遍。最小目标可以是一个含少数原子命题、合取、否定和有限验证事件的片段，先看候选能否在忠实规格下存活。

但“用 HoTT 形式化了这个片段”仍不等于“找到了 HoTT 自身的非现实性”。后者还要固定一个与 HoTT 具体构造、理论化或解释有关的步骤，而不仅是让 HoTT 充当证明另一种逻辑性质的语言。

## 一个真正有判别力的最小研究单元

我会把第一个单元限制在两个事件状态和一项明确的证书交付任务，避免立即展开成庞大的 Gödel 内部化工程。

**原任务。**记录某个固定证书在何时取得，后来能够回顾核查“在先前状态尚未取得”。任务在建模之前固定，不能看到模型的区别以后再另造观察量。

**过程正控制。**显式保留 s₀、s₁ 和证书取得事件，尝试构造关于过去状态的正确回顾证据。其作用是确认我们没有把“后来知道过去未知”本身错误判为非法。

**候选抽象。**选择一个明确的 HoTT 构造或表达，把事件/时标信息映射为较简化的对象。它必须有研究动机和准确签名，不能仅为制造失败随便删除数据。

**决定性比较。**检查这个抽象是否仍能承担原任务。如果恢复状态归属需要新增数据，说明新增了什么；如果 HoTT 规则直接拒绝所需的错误替换，保存拒绝的具体原因；如果它支持一条保持原任务却产生不正确判断的合法链条，再进入更强的形式化。

这一步的可能产出必须分开：

| 实际发现 | 可以怎样交付 |
|---|---|
| 所谓冲突只是把 Q₀ 换成 Q₁ | 该构造失效；命题被换了 |
| 显式状态模型可以保留原任务 | 正控制成立的候选；不证明所有抽象都合适 |
| 某一抽象丢了状态归属，但不再承诺原任务 | 有范围的表达/表示问题；是否命中用户目标仍需具体说明 |
| 一种有根据的 HoTT 理论化仍承担原任务，却导出非现实的验证判断 | 现实相对悖论候选，固定完整推演后交机器验证 |
| 指定 HoTT 配置内部出现不相容推导 | 更强的内部一致性问题，需独立且更严格的检查 |

这个表允许自主构造，不把“必须已有某个软件事故”当成普遍前置。但自主构造仍需忠实于原任务和真实规则，不能靠研究者自加的不相容承诺完成指控。

## 它与时间、时序，以及两类悖论的关系

本候选明确位于**时序线**：验证前后、信息取得顺序、过去状态与当前状态，以及反思活动的依赖。它不研究数轴稠密性，也不把芝诺的运动/时空结构问题解释成同一种时序失误。时间结构异化是另一条应继续保留的研究线。

在用户的 A 方向上，这个候选要寻找：一个现实中可以执行的回顾核查过程，是否被某种理论化附加了不必要或无法满足的完成条件。

在 B 方向上，它要寻找：理论是否把证书的数学存在、可验证性或某一未来状态的可取得，提升成当前状态已经交付的事实。

两种方向可以共享同一套事件表示，但必须各自固定要证明的现象。不能只证明一个截断对象恢复不了标签，就宣布 A/B 同时成立。

理论经济也在这里有了具体落点：不再携带谁、何时、怎样取得证据，确实可能简化表达。接下来应观察，当问题开始谈论验证活动自身时，这些被省去的条件是否重新成为必要条件。我们要追踪的是这次具体的简化及其后果，而不只是给一般信息损失换一个认识论故事。

## “众人没有想到过”目前能说到哪里

本轮公开检索使用了 Church–Fitch、knowability、temporal indexing、type theory、homotopy type theory 等组合，并读了上面列出的决定性论文段落。局部 repo 的精确检索在核心、方向、全景、理解章节、研究 Skill 和自反调查入口中，没有命中 Fitch 或所检索的中文名称；语义检索工具出现 Transport closed，未提供额外语义覆盖。

这只能说明：它在本轮检查的项目入口里不是一个已显式命名的方向，不能说明整个来源库没有相关思想，更不能说明 HoTT 社区无人想到过。公开检索已经找到相近的类型化和构造性认识论研究，所以“大方向前所未见”是不合证据的说法。

真正尚可比较的新意，应当具体到：哪一种 HoTT 验证事件表示、哪一种带状态的命题身份、哪一种有动机的抽象，以及哪一个精确的过程反差。必须与已有工作逐项比较这些内容，不能按题目里是否出现 HoTT 判断原创性。

因此，我当前的回答是：**能迅速看见一个值得追的机巧；目前不能说已经一眼看见了 HoTT 众人未想到的 BUG。**这个候选把原来的宽泛怀疑压缩成一个可以认真尝试的结构，同时也暴露了最可能使它失败的地方。接下来需要让它经受具体构造，而不是增加对它的确信程度。
