# 参考文献与本地依据

正文的编号链接指向下列来源。外部研究用于支持方法和理论配置的选择；它们没有在本项目重新运行，因此论文中的数学结果均按来源身份使用。本方案的 HoTT 适配、系统结构、实验顺序和工程合同属于明确的设计建议。

**学术文献与官方资料。**

1. The Univalent Foundations Program. [Homotopy Type Theory: Univalent Foundations of Mathematics](https://homotopytypetheory.org/book/), 2013。用于核心规则、类型与派生结构的来源地图。项目已有锁定来源快照；本方案未逐证明审计全书。
2. Cyril Cohen, Thierry Coquand, Simon Huber, Anders Mörtberg. [Cubical Type Theory: a constructive interpretation of the univalence axiom](https://arxiv.org/abs/1611.02108), 2016 年预印本。用于区分书式公理化与特定 Cubical 计算配置；本次采用作者摘要及来源说明的范围，不重证元理论。
3. Andrea Vezzosi, Anders Mörtberg, Andreas Abel. [Cubical Agda: A Dependently Typed Programming Language with Univalence and Higher Inductive Types](https://staff.math.su.se/anders.mortberg/papers/cubicalagda.pdf), PACMPL 3, ICFP, Article 87, 2019；DOI 10.1145/3341691。读取摘要与相关实现说明；支持选择原生后端，不构成所有变体的资格证明。
4. Nicholas Smallbone 等维护者. [QuickSpec: equational laws for free](https://github.com/nick8325/quickspec)，官方项目说明。读取函数输入、测试、候选规律及条件等式说明；工具输出规律不自动是已证定理。
5. Moa Johansson, Dan Rosén, Nicholas Smallbone, Koen Claessen. [Hipster: Integrating Theory Exploration in a Proof Assistant](https://arxiv.org/abs/1405.3426), 2014。采用摘要对探索与辅助证明两模式的说明；未将其全部算法实现移植到 HoTT。
6. Eytan Singher, Shachar Itzhaky. [Theory Exploration Powered By Deductive Synthesis](https://arxiv.org/abs/2009.04826v2), CAV 2021, pp.125–148；预印本 v2 为 2021-11-25。读取论文 §1–2 与流程说明，尤其区分符号猜想推断与最终归纳证明。本文不声称完整重现实验。
7. Rajeev Alur 等. [Syntax-Guided Synthesis](https://www-cad.eecs.berkeley.edu/~sseshia/pubs/b2hd-alur-fmcad13.html), FMCAD 2013。作者官方出版入口的检索文本支持“背景理论＋语义规格＋语法候选”的输入形态；直接页面／PDF 抓取未完成，故实现接口另以第 19 项官方文档核对。
8. Armando Solar-Lezama. [Introduction to Program Synthesis, Lecture 10](https://people.csail.mit.edu/asolar/SynthesisCourse2020/Lecture10.htm)，作者课程材料。读取规格、CEGIS 循环、反例作用及失败示例；不将有限样本通过误称普遍证明。
9. Edmund Clarke, Orna Grumberg, Somesh Jha, Yuan Lu, Helmut Veith. [Counterexample-Guided Abstraction Refinement for Symbolic Model Checking](https://www.cs.cmu.edu/~emc/papers/Papers%20In%20Refereed%20Journals/Counterexample-guided%20abstraction%20refinement.pdf), JACM 50(5), 752–794, 2003。读取引言、虚假轨迹与精化相关段落；本方案把对应失败作为研究材料是适配判断，不是原文关于 HoTT 的结论。
10. Max Willsey, Chandrakana Nandi, Yisu Remy Wang, Oliver Flatt, Zachary Tatlock, Pavel Panchekha. [egg: Fast and Extensible Equality Saturation](https://arxiv.org/abs/2004.03082v3), POPL 2021；DOI 10.1145/3434304。读取作者摘要及会议说明；只借用相容等式去重，不把 e-graph 当高阶路径模型。
11. Alloy 项目. [Alloy Language Reference](https://alloytools.org/spec.html)，官方规范；另参见 [checking assertions](https://alloytools.org/tutorials/online/sidenote-format-check.html)。用于模型寻找、trace 与 scope 边界。动态文档须在实施时重新锁定版本。
12. Bernardino Romera-Paredes 等. [Mathematical discoveries from program search with large language models](https://www.nature.com/articles/s41586-023-06924-6), 2023-12-14 在线发表，Nature 625, 468–475, 2024。读取摘要、Specification/Evaluation 与流程相关正文；借用 LLM 程序生成和独立评价反馈，不声称其可直接判定本项目的现实相对目标。
13. Kaiyu Yang 等. [LeanDojo: Theorem Proving with Retrieval-Augmented Language Models](https://arxiv.org/abs/2306.15626v2), NeurIPS 2023 Datasets and Benchmarks。采用摘要对程序化环境、前提检索和基准的说明；不借其 Lean 结果认证 Cubical 能力。
14. Thorsten Altenkirch, Nils Anders Danielsson, Nicolai Kraus. [Partiality, Revisited: The Partiality Monad as a Quotient Inductive-Inductive Type](https://arxiv.org/abs/1610.09254), 2016 年预印本。采用作者摘要中的构造与假设边界作为研究路线，未在本轮重放完整 QIIT 构造。
15. Lars Birkedal, Aleš Bizjak, Ranald Clouston, Hans Bugge Grathwohl, Bas Spitters, Andrea Vezzosi. [Guarded Cubical Type Theory](https://arxiv.org/abs/1611.09263), 2016；相关会议版本 [Path Equality for Guarded Recursion](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.CSL.2016.23)。用于独立 guarded 配置的来源；不把论文里的具体元理论边界改写为所有当前实现性质。
16. Yue Niu, Robert Harper. [Cost-Aware Type Theory](https://arxiv.org/abs/2011.03660v2), 2020。采用摘要中的原生成本与函数类型设计说明；本方案未运行 CATT 实现。
17. Danil Annenkov, Paolo Capriotti, Nicolai Kraus, Christian Sattler. [Two-Level Type Theory and Applications](https://arxiv.org/abs/1705.03307), 2017 年起的预印本；期刊版 MSCS 2023。采用内外理论区分及动机说明，不将其特殊表达问题推为 HoTT 全局不可表达性定理。
18. Marcus J. Min, Mike He, Zhaoyu Li, Zixuan Yi, Sharad Malik, Aarti Gupta, Xujie Si, Osbert Bastani. [Theory-Level Autoformalization: From Isolated Statements to Unified Formal Knowledge Bases](https://arxiv.org/abs/2607.13292v2), 2026；v1 2026-07-14，v2 2026-08-05，作者标注 ICML 2026 Spotlight。属于立场论文；用于说明理论层组织的研究方向，不当作现成系统验收。
19. cvc5 项目. [SyGuS: Functions](https://cvc5.github.io/docs/latest/examples/sygus-fun.html)，官方文档。读取 grammar、synthFun、约束与 checkSynth 示例；说明接口可用，不代表本机已安装或 HoTT 适配已完成。
20. Agda 项目. [Reflection, Agda 2.8.0](https://agda.readthedocs.io/en/v2.8.0/language/reflection.html) 与 [Cubical, Agda 2.8.0](https://agda.readthedocs.io/en/v2.8.0/language/cubical.html)。用于类型／定义访问与 Cubical 模式边界；具体支持构造和选项须以实际实现资格化。

以上网页与文献的本次核查日期为 2026-09-13。资料中显示的抓取日期不作为论文发表日期；相同工作的预印本、会议版与期刊版分别说明。没有把搜索结果数量当作系统性综述的穷尽分母；所选来源覆盖本文采用的主要方法，未检索到某项工作不证明它不存在。
