# 六条研究线与首轮实验

研究线用于保持搜索广度，不构成“所有悖论只能属于这六类”的假设。每条线同时支持任务驱动和规则驱动；新发现无法归类时可新增方向，不先把它改写成已有模板。以下内容是实验设计，均未由本方案实际执行。

| 研究线 | 主要问题 | 主要后端 | 初始观察 |
|---|---|---|---|
| L1 抽象与操作组合 | 局部抽象进入复合过程后，哪些行为不能保持 | 有限枚举＋集合商原生核验 | 值、时序、完成、上下文 |
| L2 局部存在与整体完成 | 有限阶段、逐例存在和统一相容整体如何连接 | 符号探索＋原生证明 | 相容性、量词、稳定与完成 |
| L3 时间与运动结构 | 结构理想化是否改变原活动的完成过程 | 分析构造＋符号证明 | 连续、稠密、尺度、近似与精确 |
| L4 同一性与操作身份 | 现实动作在类型同一性下承担什么额外要求 | 原生 Path／ua／依赖项搜索 | 自同构、呈现、来源、成本 |
| L5 自描述与内部担保 | 理论描述或核验自身时形成什么依赖 | 编码／替换＋证明谓词＋元层论证 | 检查、搜索、反射、总性 |
| L6 补偿与新增义务的组合 | 局部可用的补偿能否在同一任务中共同使用 | 约束合成＋原生组合证明 | 共享资源、相干、依赖与可用性 |

**L1：从操作语法搜索复合过程。** 输入为固定 process 类型、组合操作、等价关系、观察者及截止／交付标准。生成器枚举操作上下文，不只替换已有样例的数字；它寻找两种被某项抽象识别的输入，在复合上下文中的结果差异，并尝试生成尊重抽象的正操作。

首轮校准可使用现有 partiality-race-timeout 包。只向确定性枚举器提供模型定义与操作，不把 p0、p2、q1 写成唯一候选答案；由它寻找分离见证，再接原生证明。已知结果仅作为外部比较基准。当前包的既有范围是固定 delay 片段，不能据此声称覆盖真正的一般部分性单子。[本地模型与原结论范围](/Volumes/D/HoTT_AI_HANDOFF_20260911/HoTT/formal/partiality-race-timeout/README.md)

真正的后续未知是：改变操作语言、环境或完成语义后，能否产生新的、合理理论化所引入的困难。如果候选只是再次要求已知非同余操作下降到同一个商，标为已知机制；如果 HoTT 正确拒绝了伪消去器，不记为目标成功。

**L2：搜索跨阶段和跨量词的连接义务。** 输入包括前缀族、兼容关系、连接映射、阶段观察与整体完成规格。系统分别尝试生成完整相容对象、证明不存在该对象、以及发现“每个有限片段可取得”与“存在统一整体”的差异。任何量词交换只作为待证目标，不作为改写规则。

校准使用现有 transition-lift 与 current-state-lift 的精确命题及正反控制。新实验改变的是约束依赖或构造义务，不能仅给同一反例重命名。对无限族，有限反例可以反驳某个有限前提，但有限无反例不能证明相容整体存在；需要归纳、极限或相应原生论证。

本线对 B 方向尤为重要：系统必须定位究竟哪一步把局部可获得性解释为整体已经取得。如果全部差异来自额外加入的选择公理，结果应写成公理相对能力分析，并继续判断现实解释，不能隐去该公理。

**L3：独立处理时间和运动结构。** TaskSpec 从一个实际可描述的活动出发，分别记录路径、时间参数、局部推进规则、允许观察和完成标准。搜索器可改变细分规则、参数化、极限构造或表示，但每次变化必须显示它改变的是模型结构、执行过程还是验收目的。

第一组实验比较“在有限观测精度达到目标”与“在某个理论过程内精确落定”，同时保留误差、阶段和运动模型。精确与近似不同必须先被承认；不能通过把现实侧设为近似、理论侧设为精确直接制造悖论。目标是寻找一个合理理论化为何增加精确完成要求的具体步骤。

第二组实验比较不同时间结构下同一活动的合法描述及所需额外假设。HoTT 中含有路径或区间构造，不直接意味着采用物理时间的稠密数轴；连续模型也不能凭名称自动对应运动。相关分析构造回到 HoTT Book 的实数等章节，物理对应另行给证。[1 · HoTT Book](https://homotopytypetheory.org/book/)

本线的首个可验结果可以是一个忠实的符号规格和一对可核比较构造，即使最终未找到失配。将所有问题改写为状态先后关系，或以“并非 HoTT 独有”结束全部探索，都不满足本线覆盖要求。

**L4：搜索同一性引入的操作义务。** 输入是带结构对象、允许的等价、自同构、依赖族，以及有独立意义的选取／迁移／标识任务。搜索器枚举依赖函数和路径作用所要求的相干关系，寻找局部动作与统一理论表达之间的条件差别。

无标签二元素统一选点与带标签正控制是校准材料，不能再被当成新突破。新的实验必须改变实际任务或关键作用结构，并说明新增关系。现实中的一次任意选取、借助外部标签的选择和对全部呈现相容的统一选择不能互相冒充。

成本也在本线中作为操作身份的一种观察进入，但单次硬件计时只支持该次测量。若采用语法计步模型，源码须定义成本语义；若参考 CATT，必须保持它作为独立理论配置的身份。[16 · Cost-Aware Type Theory](https://arxiv.org/abs/2011.03660v2)

**L5：让自指成为真实的形式连接。** 起步配置至少包含精确的对象语言、上下文、构造子、有效编码、解码范围、无捕获替换、给定证明的核查关系和元层解释。编码往返与替换保持须先验证，否则碰撞或假编码会产生伪自指现象。已有 T3 资产是可重验的输入候选，其活跃进度不能仅凭旧 README 认定。

随后分别提出四种任务：核查给定有限证明；搜索证明；判断某个命题域的真值；为验证器自身提供指定范围的可靠性担保。它们必须使用不同的规格与输出状态。只有具体验证器／评价器进入自身所声明的对象域时，才叫作实现了相应自应用；给函数取名 selfCheck 不算。

搜索可从有限且有正面解的反射片段开始，逐步扩大对象域，定位哪个扩大步骤增加了新义务。若结果只是一般对角或不完备边界，准确登记为其 HoTT 实例；要形成现实相对目标，还需解释原任务为什么合理要求这项担保，以及实际侧完成与之如何比较。

Universe 升级、元理论外移、2LTT 外层与程序阶段分别记录。不能把一个更大 universe 的形式表达自动看成完成同理论自证，也不能把所有分层方法统一拒绝。[17 · Two-Level Type Theory](https://arxiv.org/abs/1705.03307)

**L6：搜索补偿之间的相互条件。** 输入是两个或多个有精确类型和前提的补偿操作，以及同一任务中的共享资源、顺序与相干要求。系统首先分别检查各操作，再尝试合成一个满足共同条件的组合；失败时缩减为最少冲突条件。

需要逐项回答：补偿依赖原输入还是新信息；是否要求互相等待；是否使用同一份只能消费一次的资源；是否只能在不兼容的观察或身份下成立。原生模型支持的资源结构与外部调度模型应分开，不得把普通调度困难写成 HoTT 特有缺陷。

本线只是开放问题。不能从“两个补偿都复杂”推断它们不可共同实现。通过调整过程、保持原任务而解决冲突的正例，必须被保留；只有换了输入、规则或完成标准才能解决的情况，则记录变更并继续审查原反差。

**第一项完整试验的执行单。**

| 环节 | 输入 | 真实动作 | 验收输出 |
|---|---|---|---|
| 固定实验 | 一份 profile、L1 的 TaskSpec 和只含定义的语法 | 保存哈希及已知控制来源 | 没有目标答案硬编码到候选生成器 |
| 自动生成 | 操作集与范围 | 枚举类型正确的上下文和输入 | 可复跑的候选队列 |
| 发现与反驳 | 候选 | 运行原模型和抽象模型，并尝试保任务正例 | 具体差异或范围内无结果 |
| 缩减 | 一个差异候选 | 移除冗余步骤与条件，逐次重验 | 局部极小见证与失败位置 |
| 原生核验 | 生成的精确命题 | 生成 Cubical 源码、实际内核运行 | proof/run/index 完整 |
| 解释 | 两侧过程与规则来源 | 独立检查同任务关系、现实对应及旧机制 | 准确判词与未解决义务 |
| 保存 | 所有输入与结果 | 持久化后重新查询并恢复 | 下次执行不靠聊天记忆重建 |

这项试验只验证搜索链能否发现已知校准现象。第二项试验必须使用在冻结搜索器之后确定的变体或留出任务，检查它是否获得新关系。即便只得到新的精确负结果，也可能减少关键未知；但候选数量增加、重复旧定理和证明模板通过都不单独构成研究进步。

六条线的首版覆盖不要求一次完成所有深层证明，但要求每条线都有可定位的输入规格、至少一种可执行或明确待适配的搜索路径、正反控制与下一项最小实验。把未实现的后端标为未实现，不把它们删出统观。
