## 4. C-245：发散的精确含义

`self_halting_diverge` 的结构是：给定 universal step-indexed partial function family `theta`，以及正确识别 self-halting 的 partial Boolean classifier `f`，存在 `c`，使 `f c` 对 `true/false` 都不收敛。

`recursively_separating_diverge` 把前提改为：`f` 对两个 `theta_self_return` 集分别返回对应 Boolean；同样构造一个两边都不收敛的 `c`。

因此“机器证明不能停机”在这里不是观察 timeout，而是 kernel 接受的条件性存在定理：在 universality 和 classifier correctness 下，可构造一个对任一 Boolean 都无 `part_eval` 见证的 index。它不说明任何普通 proof checker 或 HoTT kernel不终止。

## 5. C-246：抽象 essential incompleteness

资格化输出固定：

```text
forall theta, is_universal theta ->
forall S neg (fs fs' : FS S neg), extension fs' fs ->
forall r,
strongly_separates fs'
  (theta_self_return theta true)
  (theta_self_return theta false) r ->
exists n, independent fs (r n)
```

这把 classifier divergence 转译为独立句，但 `is_universal`、extension、strong separation 都仍是 theorem 参数。当前本地 C-157–C-187 的小型 proof code 只复现了部分骨架；没有为 exact HoTT syntax提供 strong separation。

## 6. C-247/C-248：CTQ 与 Robinson Q

`epf_mu_ctq`：在隐式 Peirce 参数下，`is_universal epf_mu.theta_mu → CTQ`。它没有机器证明 universality premise。

`Q_incomplete` 的完整前提是：Peirce、CTQ、`Qeq ⊑ T`、`enumerable T`、`~ T ⊢T ⊥`。结论是存在 bounded closed `Σ₁` 公式 `φ`，使 `T` 不证明 `φ`，也不证明 `Impl φ falsity`。
