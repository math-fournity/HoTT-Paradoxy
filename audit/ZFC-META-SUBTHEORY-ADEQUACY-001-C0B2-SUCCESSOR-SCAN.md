## 1. 为什么不立即搜索第三个库

当前最可能改变 C6A 条件 verdict的证据，不是又一个包含 reals 的 theorem library，而是对同一 application P 的 **actual paid bridge 或明确 defense**。继续同型 library inventory会增加 S 的分母，却不会判定 physical promotion/bridge。

## 2. 自动选择：`C0E1-ACTUAL-DEFENSE-AND-PAID-BRIDGE-SOURCE`

它将分开审计：

```text
E1a  source for a completion-preserving model-to-physical bridge;
E1b  source that explicitly revises the task and disclaims original resolution;
E1c  source that merely asserts the application without either payment.
```

Norton already supplies an E1b control for strict completion. C0E1必须寻找是否存在同一 Standard-Solution / physical-model分母内的明确 E1a 或 E1b；若无，则记录 `NO_SOURCE_PAID_DEFENSE_IN_CURRENT_DENOMINATOR`，但仍不可把 source gap当作 bare-ZFC verdict或停止 Goal。
