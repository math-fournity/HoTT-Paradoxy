> **状态：** `COMPLETE / Q_CAPABILITY_CALIBRATION_AND_Q_NARROW / NO_ZFC_CANDIDATE_Q / NO_NEW_BLADE`。

R10 重放 [`H069–H072`](<../20261003-P-DAG-H069-H072-BOUND-FORMATION-SELFREF-Terra-Max.md>) 的两条故意并列、
但不能混成同一卡的线：ZF 的实际有界 formation interfaces，以及 HF calculus 的 diagonal／proof-predicate
形式化来源。

```text
Target-Q     = 一个受界的ZFC set formation在保留domain/subset/single-value guard后，
               是否仍有同一任务的未付形成、同对象reentry或construction completion义务。

Control-Q    = H069 bounded formation source；H070 negative self-reference profile；
               H071 declared diagonal-certification positive control；H072 HF source-layer validation.
Starting state = Power Set Q-0 UNFORMED.
```

## 3. 兵棋推演：当前规则会怎样保存两条线

```text
H069 card:
  activation lane = F_LANE attempted on declared formation; Candidate-Q remains NONE
  because the source directly supplies the bounded formation and no unpaid task.

H071/H072 card:
  activation lane = NONE for ZFC; Control-Q for P2's reentry calibration
  because H071 is synthetic and H072 belongs to HF/Isabelle proof layers.
  P2 = positive syntax-level bridge; P1/P3 = not supplied for an active same-task Q.
```

如果把 H071 的成功回填给 H069，便会将不同理论、对象、输入和Done拼成一张“ZFC 自指”卡。反过来，若把
H072 的层级限制写成“P2 对自指无用”，也会丢失一个对模式 P 至关重要的正控制。当前三层Q字段和layer纪律
使这两种误报都不可成立。
