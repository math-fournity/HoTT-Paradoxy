# R01 第一轮夹具与发现能力

> **状态：** `COMPLETE / IDEA_SPEC_INCOMPLETE_IDENTIFIED / METHOD_REPAIR_PENDING`。

## 1. 本轮证据与当时目标

R01 的实际资产是第一轮锻坯 006、验收 007、V1 范围 008，以及四个独立外部分类收据：
`P2-FORGE-001`、`P3-FORGE-001`、`P1-FORGE-001`、`P3-CIRCLE-001`。当时的目标不是直接定位 ZFC Q；
它是验证三把刀能否分别：

1. 识别无限制负极性 reentry 与有界 guard；
2. 区分 admission-order cycle、有限未完成和带终步的 completion control；
3. 保持芝诺／圆环的前提、操作和强 Done，而不把紧化或极限改写成原任务答案；
4. 在缺 repair transition 的圆环来源卡上拒绝伪造 P3 状态机。

外部输出均属于固定 prompt／fixture 的分类行为证据；它们没有提出 ZFC source card、consumer或同一任务 Q。

因此它们不应被重写为“已经逼近 Power Set Q”。它们的真实贡献是：为**将来**的 Candidate-Q 建立了
正／负的识别边界和 task-fidelity controls。

## 3. 兵棋推演：现行 Q 状态机暴露的缺口

若 R01 当时已经使用目前的`QConvergenceLink`，它无法诚实选择以下任一种：

```text
Q_GENERATE / Q_NARROW / Q_BRIDGE / Q_CONVERGE / Q_REJECT
```

因为还没有固定理论 X 的 candidate card；`Q_SAFETY_REPAIR`也不足以完整表达P2/P3的**正控制**——它们不仅
避免误判，而且给出了“何种结构是未来Q可识别的”这一发现能力。把R01统称为`TOOL_ONLY_DRIFT`同样错误：
它会把用户要求“锻刀使Q发现规范化”的必要能力校准排除在锻造过程外。

这说明当前合同还缺一个受限 verdict：

```text
Q_CAPABILITY_CALIBRATION
```

它只在下列条件都满足时合法：

1. 明确指向未来理论Q所必需的一种可辨认结构，例如 domain/reentry、payment、state/admission或Done；
2. 同时有正控制与能阻止假阳性的负控制；
3. 写明它不改变任何特定理论卡的 Q 状态；
4. 写明下一张实际 source card 会如何消费这项能力，或何时应停止继续校准。

它可以证明 P 的发现能力受控增长，不能被报告为某理论 Q 的产生或收敛。

```text

actual delta              = Q_DISCOVERY_CAPABILITY (not theory-Q progress)

specification finding     = IDEA_SPEC_INCOMPLETE: QConvergenceLink lacked this bounded capability verdict

```

R01 不是重新打开“工具箱 V1 是否完成”的旧问题。它把 V1 的准确身份收紧为：用于发现 Q 的受控能力基线。
没有这个基线，未来 P 对 ZFC 的候选生成无法区分“模型看到一个像自指的词”与“模型遵守了形成、guard、
Done 和任务忠实性”。
