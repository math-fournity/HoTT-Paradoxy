# R00 原初目标与锻造起点

> **状态：** `COMPLETE / PRE_FORGE_BASELINE / NO_THEORY_Q_VERDICT`。

## 1. 当时可用的原初要求

R00 不审一张已有的 ZFC card；它审“为什么要开始锻刀”。直接来源给出四个不可混写的要求：

| 来源 | 当时已经要求的内容 | 对 Q 的含义 |
|---|---|---|
| S07 | 理论无法把论域元素的存在性问题完全外置；若现实计算中追问无终点，形成研究成功候选。 | Q 必须指向理论自身无法拒绝的对象资格／存在追问。 |
| S08 | `S`资格尚未落定时，算符已用它做讨论；合法性追溯成为张力。 | Q 不能只是“大对象”或普通递归；须有形成—使用—再追问的同一任务次序。 |
| S12 | 后续靶应是基础理论；从极其明显的核心承诺起步。 | 先选理论的承诺，再用P深读，不能枚举式搜寻。 |
| S13 | 写清P后，模型应利用已有理论知识给首轮可检验线索。 | P 是发现态启发，不替代来源、controls或数学证明。 |

当前用户的 P/Q 纠正把这些要求连成一个总动作：P 的修订须改变 Q 的可发现性，而不是成为独立的
元层成果。它是 R00 之后的审计镜头；不倒灌为旧来源的逐字要求。

## 2. 实际起点的兵棋重演

### 实际路径

早期系统先把原初张力拆为 P1 的位置／consumer、P2 的 formation–reentry–polarity，以及 P3 的
构造状态／准入次序，再以芝诺、圆环、朴素集合论、HoTT 与 ZFC 建立夹具和实际来源控制。

### 若当时已有 `QConvergenceLink`

R00 会要求在任何夹具前先写出两个不同层次：

```text
Target-Q: 对理论 X 的哪一种“本来应可完成的追问”要寻找结构化实例？
Candidate-Q: 在某一冻结 T/u/F/C/Q/I/O/Done 卡上实际提出的具体追问是什么？
```

这会阻止两种相反错误：把抽象的罗素工作意识当作已经找到的 ZFC Q；或把一个局部
membership／程序问题当作整个目标。它不会替代后续P1/P2/P3的实际来源工作。

## 3. R00 判词

```text
Starting Q state          = no candidate card; Target-Q only
Actual Q delta            = PRECONDITION_FOR_Q_DISCOVERY
P/Q coforging status      = ALIGNED_AT_INTENT_LEVEL
Tool-only drift           = not applicable: tools not yet formed
Theory result             = none
```

R00 本身不能计为`Q_GENERATE`，因为没有固定理论变体、对象、consumer或Done。它却确立了所有后续
锻造的验收标准：刀具应使 Target-Q 转化成某个可来源核验的 Candidate-Q，而不是取代它。
