# 自主构造第三轮：表达/覆盖轴与身份轴的有界检查

> 文档性质：`CURRENT_WORK_PACKAGE_REPORT / PAPER_ONLY`（不新增数学 claim、不改判词；不含机器新证明）
> 判词：**`EXPRESSIBILITY_AXIS_NO_HOTT_SPECIFIC_GAP`**、**`IDENTITY_CHANGE_AXIS_REDUCES_TO_INTERPRETATION_CONFLICT`**、**`SEARCH_SPACE_REDUCES_TO_TWO_DOORS`**
> 直接前置：S107（线 A/B 第一轮）、S108（识别不敏感形状关闭）、C11 v2、C-142–C-148、C-67–C-70、C-134–C-141、S053/S054

## 0. 结论

1. **身份轴（b）判负**：在三个自有识别族（商、截断、ua 替换）上，任务对识别掉的差异的依赖只有两种形态——出现在答案里（→ 呈现依赖 → 解释冲突，S107 候选 #1 已判）或不出现（→ 由消去器义务自动接受，S108 已判空）。第三种"只在假设位置使用该差异"（例如按差异做分支）同样要求区分呈现，仍落回解释冲突。判 `IDENTITY_CHANGE_AXIS_REDUCES_TO_INTERPRETATION_CONFLICT`。
2. **表达轴（a）判负（就 HoTT 特有缺口而言）**：三个候选对象——自指真谓词、用户悖论理论本身（"现实因子的否定"作为对象）、有限阶段完成的无限过程——分别落在"语法可表达、自应用需换层"、"不是任何形式理论的对象，缺的是规格而不是 HoTT 能力"、"可表达（流/Cauchy 模型）"。因此本轮没有找到 **HoTT 特有**的表达缺口；已知的表达边界都同时是通用规格边界。判 `EXPRESSIBILITY_AXIS_NO_HOTT_SPECIFIC_GAP`。
3. **搜索空间收口**：把 C11 账本、P1–P3、triage、S107、S108 与本轮合起来看，**"合理任务 + 合法推演 + 不可完成"的候选只剩两扇门**：
   - **门 A（表达）**：任务必须在 HoTT 中**不可形式化**——而目前的每个实例都可被解释为"规格缺口"而非 HoTT 能力缺口；
   - **门 B（层级/自我担保）**：任务必须要求理论在**同一层**担保自身（ERCF-3 / W51 的 P8），它保持 `GATED`，缺一个真实或独立提出的自我担保消费者。
   其余全部形状已被机器结果或结构论证关闭。判 `SEARCH_SPACE_REDUCES_TO_TWO_DOORS`。
4. 这解释了 18 个机器包为何一致停在 `DEFENSE_WORKS` / `REPRESENTATION_BOUNDARY`：**在可形式化的范围内，HoTT 的消去器把"带回来的条件"变成了良定义性义务**，因此可形式化的候选要么被正确拒绝，要么可被细化表示修复。

## 1. 身份轴（b）的检查

问题：理论把两个现实上不同的对象识别为一，而**任务的对象身份**依赖该区别，且该区别**不可被"多带呈现"吸收**——这样的任务存在吗？

| 该差异在任务中出现的位置 | 后果 | 依据 |
|---|---|---|
| 出现在**答案**里（输出依赖它） | 答案对识别不良定义 ⇒ 与 S107 候选 #1 同形 ⇒ **解释冲突**（现实侧依赖被识别掉的呈现） | S107 报告 §2.4 判据 (iii) |
| **不出现**在答案里（输出对识别不变） | 消去器的同余义务自动满足 ⇒ **理论内可定义** | S108 §3 结构论证 |
| 出现在**假设/分支**位置（按差异分情况） | 分支条件本身要求区分呈现 ⇒ 良定义性不成立 ⇒ 回到第一行 | 同上（分支条件也是输出的一部分） |

结论：三种位置穷尽，"不可被携带呈现吸收"与"不区分呈现"是同一个条件，因此该轴不产生新候选。

## 2. 表达轴（a）的检查

问题：是否存在一个任务，其**输出规格要求 HoTT 无法表达的对象**？

| 候选对象 | 可表达的部分 | 不可表达/需换层的部分 | 判词 |
|---|---|---|---|
| 自指真谓词（ERCF-3 的对象层） | 对象语法、无捕获替换、Hilbert 证明谓词接口（S054 路线 (a)，纯 Agda builtins） | 自应用需要层级上升（2LTT / QIIT / 内部模型）——**换了理论**，属门 B | 不是表达缺口，是层级缺口 |
| 用户的悖论理论本身（"理论前提包含对现实因子的否定"作为对象） | 可形式化其中的**具体实例**（如阶段擦除、截断、商） | "现实因子"本身没有任何形式理论的对象；把它对象化需要**外部规格**（哪些现实量、如何比较） | **规格缺口**，不是 HoTT 特有 |
| 有限阶段完成无限过程（芝诺形状） | 流、Cauchy/极限、阶段索引、截止期模型都可表达（C-106–C-109、C-118–C-123、C-129–C-133） | 未发现不可表达的部分；不可完成性都是**任务侧**（截止/在线）而非表达侧 | 无表达缺口 |

结论：**在本轮检查的三个候选上，没有 HoTT 特有的表达缺口**；"不可表达"总是同时是"规格未给出"。这与 KC-000031/000035 的现状一致（coverage no-go 仍 `NOT_PROVEN`），并说明该轴的下一步不是找 HoTT 的缺陷，而是**先固定一个可对象化的现实量规格**。

**收口命题（`PAPER_ONLY`，可反驳）**：在 HoTT 的商/截断/ua/消去器语义下，一个**可形式化**的任务若"合理 + 合法推演 + 不可完成"，必须依赖某个被理论识别或悬置的因子；而消去器的义务恰是"该依赖良定义"的判据。因此可形式化的候选会被正确拒绝或被细化表示修复——**现实相对悖论只能出现在理论上不可形式化之处，或自我担保的层级要求之处**。

## 4. 下一步（登记，不预先承诺结果）

1. **门 A 的最小可验动作**：先给出一个**可对象化的现实量规格**（例如"阶段可用性 + 截止期"已可对象化，因此不能作候选；需要一个尚未被对象化、且能被严格书写的人工量），再检查 HoTT 能否形成该对象；若不能，判它是"规格问题"还是"HoTT 能力问题"。
2. **门 B 的最小可验动作**：构造或找到一个**自我担保消费者**（要求理论在同一层内担保自身的判断），按 C8 的 P1–P8 检查；这是 W51-3 = E6 的自指版本。
3. 两条门都需要**新的真实输入**（规格或消费者），不再由现有材料自动产生；本轮不再投入更多同型枚举。
