# 源码地址：怎么自己看到引用的每一处

> 你问"源代码在哪个 GitHub repo、怎么查看你引用的那部分、具体 URL 是什么"。
> 这份文件回答这个。**所有链接都已按 pinned commit 固定**，不会随上游漂移。

## 1. 三个仓库与精确 commit

| 仓库 | URL | 本包用的 commit | 工具链 |
|---|---|---|---|
| Foundation | https://github.com/FormalizedFormalLogic/Foundation | `1fb01b72de546e1b50821fd05b1314a8d958583f` | `leanprover/lean4:v4.34.0` |
| Mathlib | https://github.com/leanprover-community/mathlib4 | `5ed2965256430c3649e86755f9576b54eca72435` | 同上 |
| 本项目 | 本机 repo，非公开 | `dev` 分支 | 同上 |

Foundation 的 pinned commit 可以直接这样取：

```bash
git clone https://github.com/FormalizedFormalLogic/Foundation.git
cd Foundation
git checkout 1fb01b72de546e1b50821fd05b1314a8d958583f
```

**本包已经带了全部 308 个源文件**，所以你不必 clone 也能读：
`02-Foundation全量源码/` 的目录结构与仓库的 `Foundation/` 子目录**逐字对应**。
即 `Foundation/FirstOrder/Arithmetic/Bootstrapping/DerivabilityCondition/D3.lean`
在包里就是 `02-Foundation全量源码/FirstOrder/Arithmetic/Bootstrapping/DerivabilityCondition/D3.lean`。

## 4. 怎么查一个名字在 Foundation 里有没有

```bash
cd 02-Foundation全量源码
grep -rn "名字" --include="*.lean" .
```

例：

```bash
grep -rn "theorem sigma_one_complete" --include="*.lean" .
grep -rn "class HBL3" --include="*.lean" .
grep -rn "def Provable" --include="*.lean" .
```

这是**离线可做**的，不需要 Lean、不需要网络。

## 5. 怎么查 Mathlib

Mathlib 不在本包里（1726 个模块，太大）。需要时：

```
https://github.com/leanprover-community/mathlib4/tree/5ed2965256430c3649e86755f9576b54eca72435
```

或本机（若你有该构建树）：

```bash
grep -rn "名字" /Volumes/D/HoTT-toolchain-cache/astra-real-geometry-v4.34.0/mathlib4-*/Mathlib/
```

## 6. 完整模块清单

`MATHLIB_CLOSURE.json`（在 `03-项目模块/`）里有**全部 1893 个模块**的名字与 SHA-256，
以及 `lean_path` 指向的每个库根。想看某模块在哪个文件：

```bash
python3 -c "
import json
c = json.load(open('03-项目模块/MATHLIB_CLOSURE.json'))
for m in c['modules']:
    if 'Bootstrapping' in m['module']: print(m['module'], m['root'])
" | head -30
```
