**我对难点在哪的判断和 README §4 不同，所以"两个独立 AI 在同一处卡住"这个结论请先别记。**

- **Δ1 那条路：** `mkDelta trProv (∼trProv)` 本来就不是候选，Π1 那半应该是与 `trProv` 等价的 Π1 公式，不是它的否定。真正的原因更简单：只要 𝗭𝗙𝗖 一致，Sh 就是 𝗜𝚺₁ 的一致、可枚举扩张，因而不可判定，根本没有 Δ1 定义。
- **"界"：** 对 Sh 本身这样的界不存在，否则 Sh 可判定。Craig 填充后的理论已经把证明长度写进公理，所以 CraigTrick 模板不需要任何 D3 级别的界，repo 里也已有 `Sh.craig`。照 §4 走的人会去找一个既不存在、也不是障碍的东西。

**我认为真正的缺口是下面这个。** 目标是更自然的一般命题的特例：

```lean
-- 对 Σ1 句 σ：V ⊧ σ → TrProvable ⌜σ⌝   （目标取 σ := zfcTr τ，用 zfcTr_sigma1）
```

Foundation 的 `sigma_one_complete` 要求 Δ1 表示的算术理论。若对显式的 Σ1 定义 `trProv`（不是 `Sh.craig` 里用选择挑出的那个）做 Craig 化得到 T'，则 `V ⊧ σ → Provable T' ⌜σ⌝` 直接得到，`TrProvable x → Provable T' x` 应该也不难。缺的是反方向 `Provable T' x → TrProvable x`，即在 V 里对任意（可能非标准的）算术 Tait 推导归纳，把每条规则翻成 ZFC 推导。

- **命题规则：** 大体由 `iT_and`、`iT_or`、`iT_nrel` 给出。
- **量词规则：** 需要 `iT` 与 shift、项代入的关系。原子公式翻译成 `∀∀((A₀ ⋏ A₁) 🡒 R'(#0,#1))`，其中 `Aᵢ` 来自 `iVE`，所以 `θ(φ[t])` 与 `∃y(varEq_t(y) ∧ θφ(y))` 的 ZFC 内等价要对 φ 内部归纳证明。项的全性 `∃! y ∈ ω, varEq_t(y)` 要对 t 内部归纳，ω 对加法乘法封闭这类标准事实用 D1 灌进来。

这正是 `of_provability` 靠完备性语义地做掉、却搬不进 𝗜𝚺₁ 的那一步。绕开 D3 改走 `Con(𝗭𝗙𝗖) → Con(T')` 也不省事，它是同一个引理在 x = ⊥ 时的实例。较省的替代是不做任意推导的闭包，只对标准 Σ1 公式重走 Foundation 的 Σ1 完全性归纳，只需有限几条规则外加一条关于 V 中数字的 Σ1 归纳引理。我估计两条路的规模都不小于 Foundation 那约 1080 行，而且需要完整的 1893 模块构建来迭代。
