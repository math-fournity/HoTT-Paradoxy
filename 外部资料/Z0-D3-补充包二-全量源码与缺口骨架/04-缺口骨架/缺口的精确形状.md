## 1. 缺口的三层展开

```lean
-- (L1) 目标（Z0Blocked.lean:29，逐字）
theorem zfcTr_D3_internalize {V : Type*} [ORingStructure V] [V↓[ℒₒᵣ] ⊧* 𝗜𝚺₁]

-- (L2) 骨架里的等价形状（缺口骨架.lean 的 bwd）
lemma bwd {V : Type} [ORingStructure V] [V↓[ℒₒᵣ] ⊧* 𝗜𝚺₁] (σ : ArithmeticSentence)
    (h : V ↓[ℒₒᵣ] ⊧ ↑(provabilityPred (Theory.craig Sh) (zfcTr σ))) :

-- (L3) 展开 provabilityPred 后（这才是真正要证的东西）

```

## 2. 唯一实质障碍（本机 grep 确认）

**Foundation 有 `of_provability`，但它是语义的、不可内化：**

```lean
-- FirstOrder/LK/Interpretation.lean:443  [读码]
lemma of_provability {σ : Sentence L₂} (h : U ⊢ σ) : T ⊢ π.translate σ := by
  apply Theory.Proof.complete_on_eq_models   -- ← 完备性定理
  intro M _ _ _ hT
  exact Model.translate_iff.mpr <| models_of_provable (π.model_models_theory hT) h
```

它的证明体第一行就是**完备性定理**，产出的是**元层推导** `T ⊢ π.translate σ`，
**不产生 V 内部的证明编码**。

**本机 grep 全量 308 个 Foundation 源文件，确认不存在内化版本：**

```bash
grep -rn "Provable.*translate\|translate.*Provable" --include="*.lean" .
# → 无输出（[实测]）

grep -rn "of_provability\|interpret_theory" --include="*.lean" .
# → 只有 Interpretation.lean 里的 5 处，全是元层/语义的（[实测]）
```

**这就是缺口。** 要跨过的正是"元层推导 → V 内证明编码"这一步。

## 3. 已确认可用的零件（本机 exit 0）

| 零件 | 形状 | 用在哪 |
|---|---|---|
| `Sh.craig ⪯ Sh` → `Sh ⊢ σ → Sh.craig ⊢ σ` 及反向 | 元层弱化 | L2 的两侧 |
| `Sh_provable_iff` | `Sh ⊢ σ ↔ 𝗭𝗙𝗖 ⊢ translate σ` | 元层的桥（[实测] exit 0） |
| `tprovable_tquote_iff_provable_quote_sentence` | `T.internalize V ⊢ ⌜σ⌝ ↔ Provable T ⌜σ⌝` | V 层 `Provable` ↔ V 层 `⊢` |
| `sigma_one_complete (T := Sh.craig)` | `V ⊧ σ → Provable Sh.craig ⌜σ⌝`（Σ1 σ） | `fwd` 方向，免费 |
| `(Sh.craig.standardProvability).HBL3` | `inferInstance` | **D3 本身不必自己做** |

**本机实测的元层方向（exit 0）**——这是 `bwd` 的**元层影子**，说明元层是通的：

```lean
example (σ : ArithmeticSentence) (h : Sh.craig ⊢ σ) : 𝗭𝗙𝗖 ⊢ arithTrln.translate σ := by
  have h1 : Sh ⊢ σ := Entailment.weakerThan_iff.mp (inferInstance : Sh.craig ⪯ Sh) h
  exact (Sh_provable_iff σ).mp h1
```

**它为什么不能直接用**：`h` 是**元层**的 `Sh.craig ⊢ σ`（一个 Lean 命题），
而 `bwd` 拿到的是**V 层**的 `Provable Sh.craig ⌜zfcTr σ⌝`（V 中存在一个推导编码 `d`）。
`d` 在非标准 V 中可能对应非标准推导，元层的 `Sh_provable_iff` 接不上它。

## 4. 因此真正要证的是这一条（推荐起点）

```lean
-- 推荐目标：内化的解释定理（只对 𝗭𝗙𝗖 与 Sh 之间这一条链）
lemma internalized_of_provability
    {V : Type} [ORingStructure V] [V↓[ℒₒᵣ] ⊧* 𝗜𝚺₁]
    (σ : ArithmeticSentence)
    (h : Provable Sh.craig (⌜σ⌝ : V)) :
    Provable 𝗭𝗙𝗖 (⌜arithTrln.translate σ⌝ : V)
```

`bwd` 取 `σ := zfcTr τ` 即得。它的数学内容 = **在 V 内对任意（可能非标准的）Tait 推导
归纳，把每条规则翻成 𝗭𝗙𝗖 推导**。

**两条可行路径**（都不必重做 Σ1 完全性）：

1. **逐规则消去**：对 `Sh.craig` 的推导结构（`Proof/Basic.lean:412` 的 10 条规则）
   做 V 内归纳。`axm` 支是唯一用到 𝗭𝗙𝗖 的地方（由 `mem_craig_codes_iff` 拿
   `p = ρ.padding k` 且 `reWitness(k, ⌜ρ⌝)`，再由 `Sh.reCh` 的语义得 `ρᵗ` 的 𝗭𝗙𝗖 推导）；
   其余 9 条逻辑规则靠第 1 层的语法交换律 + `arithTrln` 的 `domain_nonempty`/`func_defined`。
2. **只对标准 Σ1 句重走 Σ1 完全性归纳**：不做任意推导的闭包，用
   `bold_sigma_one_complete`（`D3.lean:82`）的结构，把目标从 `T.internalize V ⊢ ⌜φ⌝`
   换成 `Provable 𝗭𝗙𝗖 ⌜translate φ⌝`，把 numeral/项引理换成翻译版。

**路径 1 更一般、路径 2 更短。** 先试路径 2（它对 `bwd` 的实例够用，
因为 `zfcTr τ` 是 Σ1 句）。

## 5. 不要重复的三件事

1. **不要**再论证 `Sh` 没有 Δ1 表示——上一轮已论证，已采纳。
2. **不要**去找"证明长度的界"——`Sh.craig` 已经把长度写进公理，不存在也不必要。
3. **不要**试图把 `provable_internalize` 推广到 `𝗭𝗙𝗖`（它受 `variable (T : ArithmeticTheory)` 约束），
   也不要在 `𝗭𝗙𝗖` 内证 `Prov_ZFC(⌜τᵗ⌝) ↔ (𝔅τ)ᵗ`（同样要跨语言，难度不低于本缺口）。

## 6. 实测补充：宇宙层级是一个真的前置障碍（[实测]）

骨架 `缺口骨架.lean` 里的 `bwd` 写的是 `{V : Type}`，这是**对的**。
但项目包里的目标定理 `zfcTr_D3_internalize` 写的是 `{V : Type*}`，
而 `models_zfcTr_iff` / `models_trProv_iff` 的签名是 `(V : Type)`。

**实测**：在 `V : Type*` 下，`rw [models_zfcTr_iff]` 直接失败：

```
error: Tactic `rewrite` failed: Did not find an occurrence of the pattern
  Semantics.Models.{1, 0} ?V↓[ℒₒᵣ] (↑zfcTr ?σ)
in the target expression
  Semantics.Models.{u_1 + 1, 0} V↓[ℒₒᵣ] (↑zfcTr (↑zfcTr σ))
```

宇宙层级 `u_1 + 1` 与 `1` 不匹配。

**在 `V : Type` 下同样的一步成功**，目标变成：

```lean
⊢ Provable 𝗭𝗙𝗖 ⌜arithTrln.translate (↑zfcTr σ)⌝
```

**这是外部复核 AI 已经指出的**（"目标里是 `V : Type*`，但 `models_trProv_iff`、
`models_zfcTr_iff` 写的是 `V : Type`。证明最好绕 `trProvable_quote`，或先把前两条推广"）。
**它说对了，而且这比它说的更靠前**：不是"最好绕"，是**必须**先处理，
否则 `rw` 这一步就过不去。

**两条出路**：

1. **把 `models_trProv_iff` / `models_zfcTr_iff` 推广到 `V : Type*`**（改项目包，动的是
   已收据钉死的文件，需谨慎——`Z0Full.lean` 的类型被收据固定，只能加不能改）；
2. **绕 `trProvable_quote`**（它是 `V : Type*` 的）：从 `V ⊧ zfcTr σ` 经
   `zfcTr_def` 得到 `V ⊧ trProv.val/[⌜σ⌝]`，再经 `models_iff` + `trProv_defined` 的
   `Defined.iff` 得到 `TrProvable ⌜σ⌝`，然后 `trProvable_quote` 给出
   `Provable 𝗭𝗙𝗖 ⌜translate σ⌝`。**全程宇宙多态。**

**推荐出路 2**：它不动任何已收据文件，且 `trProvable_quote` 已经是 `V : Type*`。

## 7. 本机已清除该障碍（2026-10-11，exit 0）

**§6 的出路 2 已实现并过核**。新文件 `Z0UniBridge.lean`（也在本目录的
`宇宙多态桥.lean`）：

```lean
-- 宇宙多态版：V : Type*（项目自带的锁在 V : Type）
lemma models_zfcTr_iff' {V : Type*} [ORingStructure V] [V↓[ℒₒᵣ] ⊧* 𝗜𝚺₁]

    (V ↓[ℒₒᵣ] ⊧ zfcTr σ) ↔ Provable 𝗭𝗙𝗖 (⌜arithTrln.translate σ⌝ : V) := by
  rw [zfcTr_def, ← trProvable_quote]
  simp [models_iff]
```

**证法**：同 `Z0Full.models_zfcTr_iff`，只是参数改隐式 `{V : Type*}`，
走宇宙多态的 `trProvable_quote`（`Z0Full.lean:46`）。**无新数学。**

**并把 `bwd` 精确归约为一条消去**：

```lean
abbrev ShCraigElim (V : Type*) [ORingStructure V] [V↓[ℒₒᵣ] ⊧* 𝗜𝚺₁] : Prop :=
```
