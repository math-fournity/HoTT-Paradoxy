# 编译与收据命令（给外部 AI）

## 1. 开发期增量编译（非收据工具，仅验证能编过）

```bash
cd <repo根>/HoTT/formal/claude-cg001/godel-q-zfc-z0-full
# 拓扑序：先依赖，后目标。失败的运行目录要先删再重跑同名。
python3 -B /tmp/d3build/devbuild.py . \
  GodelQ/ZFC/SeqTranslate.lean \
  GodelQ/ZFC/SeqTranslateFormula.lean \
  GodelQ/ZFC/InternalTranslate.lean \
  GodelQ/ZFC/ShCraigElimSetup.lean \
  GodelQ/ZFC/ShCraigElimBranches.lean \
  GodelQ/ZFC/ShCraigElimNegLaw.lean \
  GodelQ/ZFC/ShCraigElim.lean        # 你新增的最终定理文件
```

`/tmp/d3build/devbuild.py` 是增量编译脚本（持久 build 目录 `/tmp/d3build/devbuild/`），
失败 run 目录要先删再重跑同名。`EnvProbe.lean`（只 `import Z0Full`）是快速自检：
约 12 秒 exit 0 说明依赖链通。

## 2. 正式收据工具（仓库内，拒绝 `sorry`）

主运行驱动（复用 `zfc_lean_check.py`，对源做纯文本扫描，注释里出现 `sorry` 等禁用词判
`FORBIDDEN_SOURCE_MARKER`，含未证标记的文件**不能**进收据源）：

```bash
.claude/goals/CG-007-formalization-completion/tools/capture_run.py \
  --proof-id MP-CG001-GODEL-Q-ZFC-Z0-FULL-SHCRAIGELIM-001 \
  --source GodelQ/ZFC/ShCraigElim.lean GodelQ/ZFC/ShCraigElimSetup.lean ... \
  --run-dir HoTT/verification/runs/20261011-CG001-Z0-SHCRAIGELIM-01
```

`-source` 顺序必须是 import 拓扑序，否则 `object file ... does not exist`。

## 3. 重放校验

```bash
.claude/goals/CG-001-targeted-overview/tools/verify_cg001_run.py \
  --run-dir HoTT/verification/runs/20261011-CG001-Z0-SHCRAIGELIM-01 --rerun
```

`verify_cg001_run.py --rerun` 要求精确重放一致。**必须先在 CG-001 证据索引
`.claude/goals/CG-001-targeted-overview/证据索引.md` 里写该 proof/run/claim 的索引行**
（裸 claim id，如 `C-398`），否则校验器报 `GOAL_INDEX_ROW_COUNT`。索引行要裸 claim id，
写 "C-398（＝…）" 匹配不上。

## 4. 验收门禁（F-011，与 `zfcTr-D3-plan.md` §8 一致）

1. 精确命题（`ShCraigElim` 及其组装）落源码，无 `sorry`；
2. `#print axioms` 仅含 `propext`、`Classical.choice`、`Quot.sound`；
3. 正运行（拓扑序编译 exit 0）+ 至少一个负控制（内核应拒绝的变体，如把 `Sh.craig` 换成
   不可判定理论的同形陈述）；
4. `verify_cg001_run.py --rerun` 精确重放一致；
5. 更新 `HoTT/CLAIM_EVIDENCE_MATRIX.md`、CG-001 证据索引、`形式化追踪/`。

## 5. 禁令（务必遵守）

- 含 `sorry`/`admit`/`native_decide`/新 `axiom`/`unsafe`/`implemented_by`/`extern`/`opaque`
  或 kernel-skipping 选项的文件，**不进收据源**（`zfc_lean_check.py` 拒收）。
- 中文注释会让某些 zsh heredoc 转义坏掉——**用 Python 脚本写 `.lean` 文件**。
- Lean 源码里嵌中文注释可以，但注释里**不要出现 `sorry` 这个英文词**（会被文本扫描判禁用标记）。
- 只加文件、只精确路径 `git add -- <路径>` + `git commit`；不碰 `sources/`、`private-audit/`、
  他人未提交文件、`main`、其它 Session 工作树。
