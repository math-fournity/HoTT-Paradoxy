## 1. 为什么是 `ShCraigElim` 而不是别的

- 原阻塞引理 `zfcTr_D3_internalize` 在 `Z0Blocked.lean`，数学内容 = "经翻译的 Σ1 完全性"。
- 经 C-390（`Z0UniBridge.lean`）的归约，它已被精确等价于**一条更窄的、V 内的消去**
  `ShCraigElim`（见 `Z0UniBridge.lean` 的 `ShCraigElim` 定义与 `bwd_of_shcraig_elim`）。
- `ShCraigElim` 的"更窄"在于：它的假设是 `Provable Sh.craig`（Foundation 已对 `Sh.craig`
  直接 `inferInstance` 给出完整 D3，无需你重做），结论是 `Provable 𝗭𝗙𝗖 (translate σ)`。
  这把"处理 V 内部任意（可能非标准）证明编码"的真难题，收窄成"把一条 `Sh.craig` 推导
  的编码沿内部翻译 `iT` 变成 `𝗭𝗙𝗖` 推导编码"的结构归纳。

> 注意：Foundation 的 `DirectInterpretation.of_provability`（`LK/Interpretation.lean:443`）
> 是用**完备性定理**语义地证明 `U ⊢ σ → T ⊢ π.translate σ` 的，它不产生 V 内部的证明编码，
> 因此**搬不进 𝗜𝚺₁**，填不上这个缺口。你必须走"归纳 `Sh.craig` 的推导编码"这条路（即本包）。

## 4. 真正剩下的核心难点（请重点攻克）

`shiftRule`（`∀¹` 与 `setShift`）、`allIntro`/`exsIntro` 三支需要形如

```lean
iT (n+1) (setShift p) = setShift ℒₛₑₜ (iT n p)     -- 对 rel/nrel/verum/falsum/and/or/all/exs
iT (n+1) (substs1 p t) = substs1 ℒₛₑₜ (iT n p) (translateTerm t)  -- 同上
```

的相容律（`setShift`/`substs1` 是 `iT` 定义里 `all`/`exs` 支做层位移时用的运算）。
这些相容律的证明思路与 `iT_neg` 完全同构：用 `UformulaRec1.Construction.semiformula_result_induction`
（与 `isSemiformula_iT` 同样的原理）沿公式结构归纳。

- `iT_neg`（`ShCraigElimNegLaw.lean`）是**现成的、已编译通过的模板**：它就用这个原理、
  同样的 9 支形状，把 `neg` 换成了 `setShift`/`substs1` 就是你要写的引理。
  强烈建议你**照抄 `iT_neg` 的结构**来写 `iT_setShift` / `iT_substs1`。
- 需要的 Foundation 引理：`setShift` / `substs1` 的逐构造子展开，以及 `IsUFormula` 版本的
  `setShift_and` / `substs1_or` 等（仿 `neg_and`/`neg_or`，在 `ℒₛₑₜ` 侧）——
  在 Foundation 源码里按 §2 的 API 引用表定位。

`axm` 支：需要把 `Sh.craig` 公理的编码形状（Foundation 的 Craig 填充，形如 `ρ.padding k`）
沿 `iT` 翻译后，落到 `𝗭𝗙𝗖` 的公理。这是唯一用到 `𝗭𝗙𝗖` 公理的地方；其余 9 支只靠
逻辑规则 + `iT` 的相容律。Claude 的 W8 规格 §3 与 `zfcTr-D3-plan.md` §5.1 给了思路，
但最干净的做法是先证支持引理、再在 `induction_setup` 里组装。
