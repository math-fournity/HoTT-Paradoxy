# 九支归纳任务拆解（8 个待填 + 1 个组装）

`Derivation.induction1` 对 `Sh.craig` 的推导编码 `d` 给出 10 个规则支。
本项目已填 2 支（`hWk`、`hVerumIntro`），剩 8 支待填。本文件逐支给目标形状、可用引理与卡点。

所有支的归纳不变量都是
`Q d := Derivable 𝗭𝗙𝗖 (translateSeq (fstIdx d))`（`ShCraigElimSetup.lean` 已证为 Σ1 谓词）。
支体在 `induction_setup` 里被 `simp only [P, fstIdx_*]`（或 `[Q, fstIdx_*`）化简到
`Derivable 𝗭𝗙𝗖 (translateSeq s)`。

---

## 支 A：`andIntro`（投入产出比最高，优先）

目标：`∀ p q, p∈s → q∈s → (p⋏q)∈s → 两条子推导 → Derivable 𝗭𝗙𝗖 (translateSeq s)`。
- 子推导给出 `Derivable 𝗭𝗙𝗖 (translateSeq s₁)`、`(translateSeq s₂)`（归纳假设）。
- 用 `iT_and`：`<iT 0 (p⋏q)> = <iT 0 p> ⋏ <iT 0 q>`，配 `Derivable.andIntro`（Foundation 的合取引入）。
- 可用：`iT_and`（InternalTranslate）、`Derivable.andIntro`（Foundation Proof/Basic）。

**本机实测可用的精确写法（支 A）**：`induction1` 的 `hAnd` 分支在
`_hdp : DerivationOf T dp (insert p s)` 里给你 `dp` 的 conclusion，其 `.1` 即 `fstIdx dp = insert p s`。
填法：
```lean
intro s _hs p q dp dq _hpq hdp hdq ihp ihq
simp only [Q, fstIdx_andIntro]
have hpU : IsUFormula ℒₒᵣ p := (IsUFormula.and.mp ((_hs (p ^⋏ q) _hpq).isUFormula)).1
have hqU : IsUFormula ℒₒᵣ q := (IsUFormula.and.mp ((_hs (p ^⋏ q) _hpq).isUFormula)).2
have hmem : iT (0 : V) (p ^⋏ q) ∈ translateSeq s :=
  mem_translateSeq_iff.mpr ⟨p ^⋏ q, _hpq, rfl⟩
rw [iT_and hpU hqU] at hmem
rw [hdp.1, translateSeq_insert] at ihp
rw [hdq.1, translateSeq_insert] at ihq
exact Derivable.and_m (by exact hmem) ihp ihq
```
（`Q` = `Derivable` 版谓词；`Derivable.and_m` 是 Foundation `Proof/Basic.lean:798`。）
> 本机已实测：`iT_and` + `Derivable.and_m` 的链路类型完全对得上，唯一卡点只是 `fstIdx dp` 的归约，
> 而 `hdp.1`（`DerivationOf` 的 `.1`）正好提供它。**所以支 A/B 是可填的，不是死路。**

**重要架构提醒**：`ShCraigElimSetup.induction_setup` 目前用 `P`（= `Provable`，单层公式）作归纳谓词，
而 `ShCraigElimBranches.lean` 的 `hWk`/`hVerumIntro` 用 `Q`（= `Derivable`，sequent）。两者不同：
`Provable 𝗭𝗙𝗖 (translateSeq s)` 是"证明翻译后整个 sequent 的合取公式"，`Derivable 𝗭𝗙𝗖 (translateSeq s)`
是"导出该 sequent"。最终 `ShCraigElim` 要的是 `Provable 𝗭𝗙𝗖 ⌜translate σ⌝`（单层公式）。
**建议**：把 `induction_setup` 的归纳谓词统一成 `Q`（Derivable），支全填完后用
`internal_provable_iff_internal_derivable`（单公式情形）把结论从 `Derivable` 化到 `Provable`，
喂给 `ShCraigElim`。这比直接在 `P`（Provable）下填支更顺——LK 的 10 条规则都是 sequent 层的。

## 支 B：`orIntro`

目标：`∀ p q, p∈s → q∈s → (p⋎q)∈s → 子推导 → ...`。
- 同 A，用 `iT_or` + `Derivable.orIntro`。

## 支 C：`axL`（公理左：`p ∈ s` 且 `∼p ∈ s`）

目标：`∀ p, p∈s → ∼p∈s → Derivable 𝗭𝗙𝗖 (translateSeq s)`。
- `translateSeq s` 同时含 `iT 0 p` 与 `iT 0 (neg p)`；后者的处理需要 `iT_neg`（已证）把
  `iT 0 (neg p)` 化成 `neg (iT 0 p)`，得到一对互补公式，由 `Derivable.axL`（Foundation 的
  逻辑公理）得可证。
- 可用：`iT_neg`（ShCraigElimNegLaw）、`Derivable.axL`。**注意用一般版本 `iT_neg`，不是引号化 `iT_quote_neg`。**

## 支 D：`cutRule`（割）

目标：`∀ p, 两条子推导（含 p 与 ∼p）→ ...`。
- 用 `iT_neg` 把 `iT 0 (neg p)` 化成 `neg (iT 0 p)`，配 `iT_and`，再用 `Derivable.cut`（Foundation 割规则）。

## 支 E：`shiftRule`（层位移）

目标：`∀ d, 子推导 → Derivable 𝗭𝗙𝗖 (translateSeq (shiftRule ...))`。
- 需要 `iT` 与 `setShift` 的相容律 `iT_setShift`（**未证，核心难点**）。
- 模板：`ShCraigElimNegLaw.iT_neg`（同样的 `semiformula_result_induction` 9 支结构），
  把 `neg` 换成 `setShift`。

## 支 F：`allIntro`（全称引入）

目标：`∀ p, 子推导 → Derivable 𝗭𝗙𝗖 (translateSeq (allIntro ...))`。
- 需要 `iT` 与 `setShift` 的相容（同支 E 的 `iT_setShift`）。
- `iT` 的 `all` 支是 `^∀ (imp domZero ys.[0])`，层数 `+1`，与 `setShift` 对齐需 `iT_setShift` + 层数护罩。

## 支 G：`exsIntro`（存在引入）

目标：`∀ p t, 子推导（含 φ[t]）→ ...`。
- 需要 `iT` 与 `substs1` 的相容律 `iT_substs1`（**未证，核心难点**，与 `iT_setShift` 同构）。
- `iT` 的 `exs` 支是 `^∃ (domZero ⋏ ys.[0])`，需 `iT_substs1` 把项的代入翻译对齐。

## 支 H：`axm`（`Sh.craig` 公理支）

目标：`∀ p, p 是 Sh.craig 公理的翻译实例 → Derivable 𝗭𝗙𝗖 (translateSeq s)`。
- `Sh.craig` 公理形状来自 Foundation 的 Craig 填充（形如 `ρ.padding k`），其定义在
  `Foundation/.../Syntax/CraigTrick.lean`。翻译后需落到 `𝗭𝗙𝗖` 的公理。
- 这是**唯一用到 `𝗭𝗙𝗖` 公理**的支；其余 9 支只靠逻辑规则 + `iT` 相容律。
- 建议：先证 E/F/G 的支持引理，再处理此支；参考 `zfcTr-D3-plan.md` §5.1 与 Claude W8 规格 §3。

## 组装（收尾）

8 支全部无 sorry 后，在 `ShCraigElimSetup.induction_setup` 里把 `sorry` 换成各支引理，
得到无 sorry 的 `induction_setup`；再新增 `GodelQ/ZFC/ShCraigElim.lean`：

```lean
theorem ShCraigElim {V : Type*} [ORingStructure V] [V↓[ℒₒᵣ] ⊧* 𝗜𝚺₁]
    (σ : ArithmeticSentence) (h : Provable Sh.craig (⌜σ⌝ : V)) :
    Provable 𝗭𝗙𝗖 (⌜arithTrln.translate σ⌝ : V) := by
  rcases h with ⟨d, hd⟩
  exact ShCraigElimSetup.induction_setup d hd   -- 取出 Q d，再按 translateSeq 与 arithTrln 对齐
```

完成后按 `04-编译与收据命令.md` 编译；`Z0Blocked.lean` 的 `sorry` 届时改为引用 `ShCraigElim`。
