该单元先为实际消费者审计冻结一个新的、版本固定的候选分母；它不是泛泛全库搜索，也不是把任何 SIP/UA 实现叫作 K。

| 字段 | 固定要求 |
|---|---|
| 输入 | 已冻结 P1 `R_min`、P2 SIP 有界负结论、ABX H/R/K 整备及其 D_ABX_1/D_ABX_2/D_ABX_3 禁止重复表 |
| 问题 | 哪一个真实外部库、论文实现或应用可以作为第一个**未覆盖**消费者分母；它是否有版本、入口、调用链和关于任务完成的可核验承诺 |
| 本地资产侦察 | 先检查既有 `SIPRepresentation`、N5/derived-development 审计、ABX D1/D2/D3、WebGPT 历史会话、机器统观导入和项目已指向的只读目录；按 `EXACT_COVERAGE`/`PARTIAL_REUSE`/`HISTORICAL_UNVERIFIED`/`NEARBY_ONLY`/`NO_ASSET...` 分类 |

| 不得重做 | P1/P2、C-250–C-324、Flash、D_ABX_1/D_ABX_2/D_ABX_3、旧 SIP Bool proof、旧有限关系枚举或无版本关键词扫描 |
