# 令牌经济、反漂移与每单元复核

## 经济原则

令牌和运行时间按**判别力**分配，不按已经投入的文件数量分配。一个新单元只允许一条活动分支、一个新分母、一项精确主张和一组必要正反控制。没有改变任务、理论构造、观察、完成条件或消费者分母的行动，只是旧行动的重述，不应启动。

资料读取采用三层：先读本总体方案和相关 branch owner；再读该 branch 的 H/R/K 整备和精确历史 source/run；最后才读版本冻结的新外部来源。四件套与 STATE 的加载义务仍由项目治理承担，但不得在已水合后反复加载同一大规模历史材料来制造工作量。

## 每个工作单元的最小声明

在任何代码、网页检索或证明运行前，当前 AI 必须在该单元的计划记录中写出：

1. 分支与精确问题，例如 P2 的哪一种 `K_theory`；
2. 要改变的当前判词；
3. 新分母、版本、入口和为何不被既有 H/R/K 整备覆盖；
4. 固定的 X、`R_min`、H/U、Input、Operation、Observation 与 Done；
5. 一个正控制、一个最强反解释和停止条件；
6. 哪个原生 proof assistant、来源审计或运行 oracle 能判定结果；
7. 正结果、负结果和无效规格各自会把下一步送往哪里。

这不是额外审批层；它是把已经存在的 `判词改变凭据`、TaskSpec 和 SOP 反思压缩为一次可审计的起始声明。

## 单元内防漂移

- 发现必须先判定是不是当前分母外的真正新证据。若只是已知控制的另一种叙述，登记为重复并停止。
- 证明尝试改变了定义、量词、输入或 Done 时，立即重写候选卡并重新做正反控制；不得把换题后的通过结果接回旧主张。
- 每次失败先区分：理论拒绝、规格不足、实现配置、来源未命中、现实桥未定，不能统称为悖论或拒签。
- 一个分支得到有界负结论后转下一分支；不得把同一 no-hit 通过新增关键词、摘要或包装重复成新成果。

## 单元结束的固定复核

每个自然单元结束时，按既有 SOP 的反思清单逐项回看，并额外回答四句：

1. 本单元新增了哪条可定位的事实，而不是新增了哪份文档？
2. 它改变、收窄或保留了哪个判词？
3. 哪条分支因该事实获得资格，哪条分支失去资格？
4. 若没有新增事实，为什么现在停止而不继续消耗令牌？

只有第 2 或第 3 题的答案改变当前选择时，才更新 `goal.md`、STATE 和总体方案；否则保留必要收据并结束。连续两个单位若只产生同类无命中而没有新的分母、反解释或观察量，下一单位必须换分支或等待新 ingress。

## 组合层复核

P1、P2、P3 每完成一支的最小结束，才进行一次组合层复核：核对 P1 的 R 是否仍是 P2/P3 使用的同一规格，核对 P2/P3 是否将同一任务误换成不同任务，并决定 P4 是否出现真实触发。这个节奏避免每一次局部编译都重新规划整个项目，也避免长期沿同一条熟悉通道失焦。
