These three reviews were produced by the pre-audit coordinator (commit `e4ab45b`)
and were moved here after the external M1 audit (finding F4):

- `RV-MS-TASK-L1-RACE-COMPLETION-001-WV-0002.json` described a value-mismatch
  witness as "business continuation → divergence" although its context contained
  only `race_left` and no `bind`;
- `WV-0001` and `WV-0013` reviews were generated by the same mode-only logic and
  asserted `task_preservation` without checks.

The post-audit coordinator derives the mechanism description from the witness
structure and computes task preservation from explicit checks; new reviews are
written with ids that include the case revision, search run and witness AST hash.
The files are kept byte-identical for audit history; they are not indexed or
validated (the `.superseded` directory is skipped by `list` and `validate`).
