## 3. 更新后的短链（人话版）

1. **一个看似合理的取舍**：单价性让“对得上的就是同一个”，“相同”因而从一个会落定的事实变成一种结构。两个东西总是“以某种方式”相同，这些方式之间还能以不同的方式相同。
2. **一个专门碰它的过程**：写出“按面粘合、面的面也要对上”的一般规则。
3. **相同有几层，相干就补几层**：
   - 相同只是事实（各层是集合）：一行写完，六边形自动成立【证明，C-64；Lean 中 C-65】。
   - 相同有两层（各层是群胚，比如圆周）：要补六边形。它要么唯一地成立，要么不成立【证明，C-70】；在圆周上确实会不成立【证明，C-64、C-69】。补上以后，下一层自动成立，补法到此停止【证明，C-70】。
   - 相同有更多层（比如 2 维球面）：六边形的补法不唯一【证明，C-66】，下一层可能补不上【证明，C-68】。
   - 一般规律：各层是 t-类型时补到第 t+1 级即可【解释：h-层级的元层论证】。Herbelin–Ramachandra 2026 也写着：在集合上，构造“到此停止”【来源】。
4. **HoTT 自己的宇宙里，相同没有层数上限**：
   - 宇宙不是集合【证明，C-63】，连集合的宇宙也不是集合【证明，C-71】；
   - 宇宙对推出封闭时，宇宙不截断于任何层【来源：Buchholtz 2019 解析页 190】。
   - 所以在 HoTT 的宇宙上，“补到第 t+1 级”没有尽头：每一有限层都写得出【证明到第 5 层，C-62；任意 n 为来源】，统一的定义至今写不出【来源】。
5. **换题也消不掉的检查**：
   - “加一层字段”：加的正是下一级相干；
   - “改用集合”：换了任务。经典数学中，值为同伦类型的半单纯空间以严格等式为定律，一次写完【来源，工作台 §3.4】；
   - “换理论”：已知的每种成功定义都加回了事实式的相同。2LTT 与 HTS 还要加一条把外层（事实式）自然数与内层自然数绑定的公理 (A1)–(A3)，才能得到内层的“一切半单纯类型之型”【来源，工作台 §3.3】。
6. **它咬到理论自己**：HoTT 要用消去子解释自己截断成集合的语法，目标必须是集合。宇宙不是，连集合的宇宙也不是【证明，C-71】；在 UIP 世界里这条路是通的【证明，C-72】。

**与芝诺的对照**（只借“每一步都留下下一步”这一条关系）：芝诺每减半一次，还剩一段距离；A7 每多一层可以不同的相同，就多一级相干要补。

## 4. 归因（《最高指示-Claude版》§1.3 的四件事，更新）

**候选前提**：
- P-U（单价性：宇宙中的相同就是等价）；
- P-I（内涵恒等，语言内没有严格相等）；
- P-F（一切类型都是纤维的，没有事实式的层）；
- P-N（新）：内层自然数没有与外层（事实式）自然数绑定；
- P-C（统一性：定义要在理论内部，对变量 n）；
- 现实侧前提：面之面相合是一次落定的事实。

**区分证据**：
1. **按截断层级做消融**（C-64、C-66、C-68、C-69、C-70）：后退的长度随各层的相同层数而定，集合处停在第一步，群胚处停在第二步。这把病因定位到“相同的层数”，而不是笼统的“内涵恒等”。【证明，实例】
2. **UIP 对照**（C-65、C-72）：相同是事实时，后退在第一步就停。HoTT 不能加 UIP：单价性使宇宙不是集合（C-63），甚至集合的宇宙也不是集合（C-71）。这区分了 P-U 与 P-I。【证明】
3. **修复要加回什么**（来源，工作台 §3.3）：2LTT 要外层严格相等（去掉 P-F），还要关于外层自然数的公理（去掉 P-N）。只加严格相等而不绑定自然数，只能对每个外层的 n 写出第 n 层。【来源】
4. **撤回条件**：Herbelin–Ramachandra 2026 设想的用流继续的构造，若能在书式 HoTT 中实现，则 P-F、P-N 都不是必要的，A7 的强形式撤回。【来源 + 解释】

**我的判断**【解释，条件式】：
- 咬人的前提是“理论内部只有结构式的相同，而且在宇宙上层数没有上限”（P-U 与 P-F 合在一起）。
- 已知修复还需要绑定自然数（P-N）。这说明理论内部也缺一种事实式的、在理论之外进行的逐层计数，正如 C-62 那个在理论之外逐层计数的程序，也正如 KC-000011 所说：程序时刻让使用者考虑时序，而 Think in HoTT 的思考过程不想让时序参与。
- 这个判断的条件是：开放问题保持开放或得到否定答案；用户认可现实一侧（§6）。
