## 1. 一句话

（2026-09-25 修订）HoTT 里有两个圆：一个能拿走点、能量距离的点集圆，一个有环的合成圆；在“单射坐标 + 非平凡恒等环”的意义下，没有一个类型同时是二者（C-21）。用户的圆环故事只能在点集圆上讲；合成圆不是它的载体。在点集圆上，对 Astra 的固定复原映射，要证明“复原的 N 就是整个 M”，至少要 Markov 原则：这是一个条件性覆盖边界，属一般构造性分析，不是对原案的判词。

## 2. 原案

【原话，原文三，`HoTT/sources/user-originals/Z铁律-抽象-圆环-时间维度-用户原始论述-20260901.md` 第 31 行】

> 一个圆，其上取一点拿走，假设现在的形态是M。然后将两端展开成线段，假设现在的形态是N。此时，问：从M到N似乎没有什么障碍，那么从N复原到M我们可以做到吗？在过程中N的两端，何以，可以逼近到只剩一个点的距离？因为点没有大小，无限小，无论N的两端逼近到什么接近的程度，都无法再还原到M的状态。可是，可是，我们当初确实得到了M啊！为什么变成N之后就无法再回到M了呢？

要保住的三件事（《最高指示-Claude版》§7）：零大小的点；反向逼近；“此前已经得到 M”。

注意：**M 是拿走一个点之后的圆，不是整圆。**

## 3. 两副面孔

**这件事本身是已知的**【来源】：Shulman 在 HoTT 博客（2015-09-25，“Real-cohesive homotopy type theory”）明确谈到“两个圆”：高阶归纳的圆由一个点 base 和一条相等 loop 生成；拓扑的圆是 {(x,y)∈ℝ² | x²+y²=1}，是有无穷多个不同点的集合。在 real-cohesive HoTT 中，拓扑圆的形状 ʃ 就是同伦的圆（arXiv:1509.07584，MSCS 28(6), 2018）。本笔记的新意只在：用这两副面孔去读用户的圆环故事。

### 3.1 合成圆 S¹（点加环路）

- 它有环：`loop ≢ refl`（C-22）。“圆之为圆”在这里。
- 拿走一个点：`Σ[ x ∈ S¹ ] ¬ (base ≡ x)` 是空的（C-22；与 Astra C-251 同一事实）。得不到 M。
- 它上面没有距离、没有先后（C-15、C-16），“两端逼近到只剩一个点的距离”无从提起。
- 结果：故事在第一步就停了。咬住的前提是 P1 认同：连着的点都是同一个点，拿不走其中一个。

### 3.2 点集圆（实数平面上的单位圆，是一个集合）

Astra 在原生 Agda 的 Dedekind 实数上做出的结果（共享矩阵行，本会话未重放）：

- **拿走一个点有两种写法**：弱的，“不等于那一点”；强的，“与那一点分离”，即有正距离。弱 ↔ ¬¬强（C-283）。
- **从 M 到 N 没有障碍**：强去点圆与实数、与开区间 (0,1) 等价且双向连续，无条件成立（C-285–C-290）。
- **把 N 弯回去**：两端间距在 t < 1 时严格为正，到 t = 1 两端相遇（C-316；经典侧见 C-272）。逼近之所以能“完成”，靠的是时间也被当成连续统、t = 1 可以取到。
- **但是**，“复原后的 N 覆盖弱去点圆 M 的每一个点”（WeakFinalCoverage）：
  - 等价于 Lift，等价于“实数非零即分离”（C-319、C-307）；
  - 蕴含 Markov 原则（C-322）；
  - 在可数选择下与 Markov 原则等价（C-324）。
- **Markov 原则**说的是：一个不可能永远找不到的搜索，一定找得到。
  - 【来源】它在带自然数与一个宇宙的依赖类型论中不可推导（Coquand–Mannaa，LMCS 2017）。
  - 它在 Book HoTT 或 Cubical Agda 中是否可推导，本项目没有核查（**未知**）。HoTT 没有把它当作公理。
- **结果**：弱的 M 可以直接写出来，这正是“当初确实得到了M”；N 也在；但要证明“N 复原回去就是整个 M”，至少要一条关于无界搜索的原则。故事卡在最后一步。

**咬住的前提**是零大小的点：在稠密的连续统里，“不是那个点”并不等于“离那个点有正距离”。二者的差，要靠无界的逐级逼近才能弥合，这正是用户说的“无论N的两端逼近到什么接近的程度”。

## 4. 碰撞：两副面孔都说不出的那件事【解释】

现实中的事件是：把 N 弯回去，两端靠到只差一个点，M 回来了。

- 合成圆：没有“一个点”可以拿走，也没有“距离”可以逼近。
- 点集圆：能拿走，能逼近；但要证明回来的是 M 的全部，要 Markov 原则。
- 没有一个类型兼有二者：点被坐标化的类型里，环都是平凡的（C-21）。

在用户的量子化现实里【用户立场，AI 不代证】，点有大小。“不是被拿走的那一格”就等于“离它至少一格”，弱与强一致，Markov 的缺口不出现；两端的逼近在有限步内完成。

## 6. 自检（《最高指示-Claude版》§7）

- **精化有没有冒充原问？**
  - 承接了：零大小的点（弱去点，及它与“分离”的差）；反向逼近（t → 1 时端点间距 → 0，以及 Markov 中的无界搜索）；“此前已经得到 M”（弱去点圆可以直接写出）。
  - 没有承接：弯曲 N 这一操作类的忠实性（Astra C-320：曲线运动与环境同胚是两种不同的成功）；“两端只差一个点”作为完成判据；环境空间。
  - 所以这是一种读法，不是对 X_h 的回答。Astra 的结论“原整体击落论证未建立”（全景 `OUT-ASTRA-ASSUMPTION-INTEGRATION-35`）保持不变。
- **解释有没有加码？**
  - “Markov 不可推导”只对带自然数与一个宇宙的依赖类型论有来源；对 HoTT 是未知。
  - “用户的怀疑是对的”是 AI 判断，限于点集圆，而且这一半是一般构造性边界，不是 HoTT 特有。
