## 2. 模式匹配

两句人话：

- **芝诺**：从这里走到那里，本来走过去就到了。数轴理论为了好用，让距离可以无限细分。于是“走到”永远了结不了：先走一半，还剩一半；再走一半，还剩一半；每一步都确定地还没到，这段路永远走不完。
- **HoTT**：两个东西是不是同一个，本来是一句话的事：是就是，不是就不是，没有“以哪种方式是”这一说。HoTT 为了省事，规定同构的就是同一个（单价性）；又为了普适，让任意高维的形状在宇宙里一次齐备（高阶归纳类型）。于是在它的宇宙里，“是同一个”永远了结不了：以哪些方式是？这些方式之间又以哪些方式是同一个？每一层都确定地还有下一层，这个确认永远完成不了。

| | 芝诺 | HoTT 的追问 |
|---|---|---|
| 本来很简单的事 | 从这里走到那里 | 确认两个东西是不是同一个 |
| 简单的见证 | 走过去就到了（研究发起人：运动是量子化的，KC-000004） | 相同是事实的世界：第 1 问就停（C-80，Lean） |
| 理论为了好用改掉的条件 | 位置可以无限细分（稠密） | 相同可以无限细分：同构即相同（单价性，为经济）；任意高维一次齐备（高阶归纳类型，为普适） |
| 专门碰它的过程 | 每次走剩下的一半 | 每次问上一层“以什么方式相同” |
| 每一步看到什么 | 还剩一半：确定地没到 | 这一层还没了结：确定的“否”（C-75、C-81） |
| 过程的结局 | 永远走不完 | 追问程序等于 `never`，对任意判定器都如此（C-78、C-81） |
| 结果形式 | 可证：没有哪一个有限步到达 | 可证：没有哪一个有限层了结；问“有没有一层”，第 0 步就答“否”（C-78、C-81） |
| 推理本身 | 没有问题（研究发起人） | 没有问题，而且经过内核检查 |
| 离散或有界的对照 | 量子化的空间：有限步走完 | 高度封顶：第 2+b 问停（C-82）；目录的成员高度有界：第 1+n 问停（C-79） |
| 教科书消解 | 极限：1/2 + 1/4 + … = 1 | 截断：对集合截断 ∥X∥₀ 发问，第 1 问就停（按截断的定义；本仓库未单独跑内核） |
| 消解本身建在什么上 | 稠密性（KC-000003：极限理论以稠密性为前提） | 截断本身就是一个高阶归纳类型，它用一个构造子（任意两条相同的路径都相同）把“相同是事实”重新宣布回来 |

【判断】各行的对应：

- **完成的种类**：扩展认知 003 说“反复变化、一个指定程序不停止、每个有限阶段都还未精确到达、当前信息不足、缺少统一方法”不能混为一谈。芝诺属于“每个有限阶段都还未精确到达”，把减半写成程序，就是“一个指定程序不停止”。HoTT 的追问两样都有，而且都机器证明了：每个有限层都确定未了结（C-75、C-81），指定程序不停止（C-78、C-81）。它不是 A7 那种“缺统一方法”（002 §2 第 13 条），而是与芝诺同一种。
- **两副面孔**：芝诺有过程形式（永远走不完）与结果形式（没有有限步到达）；这里也有过程形式（`never`）与结果形式（没有有限层）。“第 0 步就答否”不消解 UR，它就是 UR 的定理形式，正如“没有有限步到达”就是芝诺的定理形式。
- **消解的对位**：两种教科书消解，都是用一条定义或一个构造子，把被改掉的现实条件重新宣布回来，而不是恢复离散的空间或事实式的相同。这与 CN-035、CN-037 的观察“每一种修复都加回事实式的相同”一致；按 CN-038，这种“凭定义宣布完成”正是 B 向读法所在。于是罗素线的 A、B 两向可以这样分工：书式 HoTT 里的现象是 A 向；修复里的“宣布完成”是 B 向（KC-000050、051 的存在性追问落在这里）。这是解释，不是定理。

## 3. 前提：相同可以无限细分

【判断】芝诺的被告是“位置可以无限细分”；这里对位的是“相同可以无限细分”。它由两件事合成：

- 单价性把“是不是同一个”换成“以哪些方式是同一个”，相同从此有了层；
- 高阶归纳类型让宇宙里有任意高维的形状，使每一层都不平凡。

对照已经分开了两件事的作用：相同是事实，第 1 问停（C-80）；保留单价性、给高度封顶，就在封顶处停（C-79、C-82）。

排序（条件式，同 CN-049 第 9 节）：单价性第一。经典数学里也有同样高维的空间（∏ₙ K(ℤ,n+1) 的同伦群在每一维都是 ℤ，来源级），变化出在“相同”指什么。高阶归纳类型第二，它是这批对象上永不停的必要一环。合取是逻辑形式，反证只否定合取整体。

## 4. 让外人一眼看出来，还差什么

- 芝诺的“简单的事”不用铺垫；这里要一句铺垫：“是同一个，本来就是一句话的事，没有‘以哪种方式是’。”第 2 节的第二句人话就是为此写的。
- 芝诺对每一段路都成立；这里是“在某种情况下”（研究发起人 0102 原话里就有这个限定）：宇宙，以及这类乘积。宇宙不是边缘情形，它是单价性说的那个对象，也是 HoTT 不能拒绝的论域元素（KC-000050）。
- 数学事实本身，HoTT 专家早就知道：宇宙与这类乘积没有有限层（HoTT Book 例 8.8.6；Kraus–Sattler 2015）。几何级数大家也早就会算；新的是把它读成 UR，并指出它指向哪一个前提（KC-000015：要找的是这种现象在 HoTT 中也存在）。这一读法我没有做过文献查重。
- 教科书消解（截断）要在正文里先答掉，答法见第 2 节表的最后两行。
