## 2. 顺藤摸到的来源

1. **Grandis，《The fundamental weighted category of a weighted space: From directed to weighted algebraic topology》**（*Homology, Homotopy and Applications* 9(1):221–256, 2007；arXiv:math/0604506，2006）。读 sciverse 全文。
   - 摘要：研究路径带“权重”或“代价”的空间，权重表示长度、时长、价格、能量等；**不假定权重在路径反向后不变**。加权代数拓扑是有向代数拓扑的加细：非法路径的代价记为无穷，合法路径被计量。
   - 引言：有向代数拓扑的总目标是对不可逆现象建模；加权版把“路径合法与否”这种真值式的做法换成代价的度量，目标变成度量（可能不可逆的）现象的代价。基本的广义度量区间：`δ(x, y) = y − x`（当 x ≤ y），否则为无穷。
   - 第 16 页：基本加权范畴的对象是点，箭头是路径的同伦类，复合由拼接诱导；**一个同伦类的权重，是其中各条路径长度的下确界**。
   - 【解释】这是“计步器住在有向结构里”的一个早期、非类型论的版本：长度与时长沿路径计量，反向路径代价为无穷，所以往返不会抵消。反过来看，若允许把往返 `p · p⁻¹` 同伦收缩为常路径，按下确界定义的权重就必然为零，这就是 T2 的度量形式。这句反推 Grandis 没有写，是我的推论。
2. **Rodin，《Axiomatic Method and Category Theory》书稿**（arXiv:1210.1478 v1，2012；Springer Synthese Library，2014）。读 ar5iv 的 HTML 版，章节号按书稿。
   - **§5.1《同一性悖论与数学的双重体》**：变化中的对象给逻辑学家带来“变化悖论”。青苹果变红：A = B，性质却不同，这与“同一者不可分辨”冲突。芝诺最早提出激进的出路，即取消变化。Rodin 说，数学比物理更像是站在埃利亚派一边，尽管数学家一直在谈变化、运动、变换与运算。
   - **§6.1《关系与变换》**：弗雷格把等价换成同一，这件事还可以另作解读：把等价看作把 x 变成 y、也能变回来的可逆变换，同一就成了“经过这一变换的同一”。
   - **§6.10《单价基础》**：
     - 用 HoTT 的同伦解释重读弗雷格的金星例子：“晨星 = 暮星”的证据，是一条从晨星到暮星的连续路径。
     - Rodin 说，这出人意料地恰好就是“物体持续穿越时间”的朴素直观；同伦解释很好地符合“穿越时间的同一”这一基本观念，而经典力学中粒子的同一靠的正是这一观念。
     - 随后他举广义相对论中的引力透镜与虫洞，说明在那里路径之间的同伦变得要紧。
   - 【来源】加【解释】：
     - 2012/2014 年的 Rodin **正面采纳**了“路径即穿越时间”的读法；2019/2024 年他转而强调 HoTT 是“可逆的”、对称化即去时间化（CN-032 §2）。同一位哲学家的前后两种态度，正好是 Q2 的两面。
     - 2014 年这一段没有谈方向：从暮星到晨星的逆路径同样是证据，这正是他 2024 年所说“可逆”的地方。这是我的读法，他没有把两段连起来。
     - §5.1 把变化悖论表述为与“同一者不可分辨”（莱布尼茨律）相冲突，可以看作 CN-012 那个观察的外部先例：“=”同时模仿共指与运动，而莱布尼茨律对运动不成立。
3. **Rodin，《Venus Homotopically》**（PhilSci-Archive 12116，2016 年预印本；*IfCoLog Journal of Logics and their Applications* 4(4):1427–1445，2017）。只读了 PhilSci 页面上的摘要：用 HoTT 的同一概念分析金星例子，讨论外延与内涵的区分及其本体论意义，**给出经典力学中一个基本运动学图式的同伦重建**，并讨论它与量子力学的关系。【解释】这与 A1（沿运动测量）直接相关。正文未读：PDF，244 kB，需许可（§6）。
4. **Dubut, Goubault, Goubault-Larrecq，《The Directed Homotopy Hypothesis》**（CSL 2016，LIPIcs 62，论文 9，DOI `10.4230/LIPIcs.CSL.2016.9`）。摘要要点：
   - 格罗滕迪克的同伦假设说，拓扑空间应“等价于”弱无穷群胚；
   - 此后改写、分布式系统、（同伦）类型论等计算模型都有了几何化；
   - 但并发理论的一个基本特征是时间应被视为不可逆，有向代数拓扑由此而生。
   【解释】这是一个明确的学术来源：它把群胚式的几何化（其中点名了同伦类型论）与不可逆时间对举（R-D / R-C，E3）。
5. **decalf 的有向结构**（sciverse 全文）：
   - §2：计步 `step^c(e)` 的意思是“付 c 的代价，再继续做 e”，满足 `step^0(e) = e` 与 `step^{c1}(step^{c2}(e)) = step^{c1+c2}(e)`，即代价幺半群的作用。由单调性，c ≤ c′ 时 `step^c(e) ≤ step^{c′}(e)`。
   - §4.2：给定带两点 0、1 的区间对象 𝕀，**路径定义为从 𝕀 出发的函数**；路径关系 `x ⊑ y` 指存在从 x 到 y 的路径（改编自 Fiore–Rosolini）。路径传递且“边界分离”（固定端点的路径空间是命题）的类型，称为合成预序（定义 4.16）。单纯集是它的模型，区间取表示层 Δ[1]（定理 4.32）。
   - 【解释】decalf 的“有向”，是用一条有向区间上的路径来定义项之间的次序，与有向同伦同属“用有向区间定义关系”的做法，只是截断在 0 层，没有高阶同伦。代价用没有逆元的幺半群作用，并沿次序单调。结构上，这是“计步住在不可逆的箭头上”的代价版；但它的动机是效应与上界，不是恒等可逆。
6. **Myers 2024 的真实内容**：见 §1 E-02。【解释】它不是往返计步（A6 一面），而是 A1 一面的独立再现：当“变化”的类型由数据类型自身的结构算出时（桥、路径、箭头都属这一类），离散的归纳类型上只有“没变”这一种变化。这与 C-01、C-38、C-45 的“离散读数沿路径或箭头冻结”同形。它的补救是把变化写成类型的构造子（`truefalse`、`falsetrue`），与 HPT 把补丁写成路径构造子、C-25 与 C-50 把步子写成独立生成元，是同一条出路。Myers 自己没有这样比较，这是我的读法。
7. **Choudhury–Fiore §7.5**：本文只处理 0-截断的多重集；不截断时，交换需要更高的相容性构造子（六边形）。【解释】这从旁支持 C-60 的诊断：HPT 作者代码中的 `MS` 有交换路径，既没有截断，也没有相容性构造子，所以不是集合；交换留下的“历史”落在自由的路径之间（C-60 证明 `Ex true true []` 不等于 `refl`）。
8. **James, Sabry，《Information Effects》**（POPL 2012，DOI `10.1145/2103621.2103667`）。摘要要点：
   - 计算与一切物理过程一样，从根本上是可逆的；
   - 由类型同构导出一个可逆的计算模型，其中信息是既不能复制、也不能擦除的线性资源；
   - 常规不可逆计算与逻辑可逆计算之间的差距，由一个类型与效应系统刻画：信息的产生与擦除是显式效应；
   - 不可逆计算来自与隐含信息环境的交互，是派生概念，类似物理学中的开放系统。
   【解释】这是反方的一种强形式：可逆才是基本的，不可逆是派生的效应。放回行走的故事，计步器正是一台产生信息、留下记录的装置；在严格可逆的模型里，它必须作为显式效应另外加入。这与 C-50（把回程写成另一条路径，即加入额外信息）、Q1“另记一本账”是同一处分歧的又一种说法，不是对它的裁决。
   - 同一组作者的综述：Carette, Heunen, Kaarsgaard, Sabry，《Compositional Reversible Computation》（RC 2024）。从可组合的可逆计算出发，以 rig 范畴为标准模型，连到类型同构、对称、置换、群与单价宇宙；再用单子与箭头恢复常规的不可逆编程。
9. **Kløvstad 论文的摘要**：见 §1 E-01。其中“把仓库建模为余等化子、没有成功”一事值得一读（与 002 §4 第 5a 条、Terra 的 O-015 相关），正文未读。

## 4. 对用户三问的意义（【解释】）

- **Q1 另记一本账，算不算完成**：两轮所见，凡以代价或时间为研究对象的路线，都让代价或方向改变“相等、同一”本身的结构，而不是保留可逆的相等、另开一个与它无关的数据结构：
  - Grandis：权重记在基本范畴的态射上；
  - calf/decalf：内涵相位中，代价不同的程序不相等，项之间有次序；
  - Rodin：有向类型论中的同一关系不对称；
  - James–Sabry 则把“记录”看作必须显式声明的效应。
  这是它们的设计选择，不裁决 Q1。但它说明，“时间只作为数据”与“时间进入推理结构”是文献中真实存在的分野；Rodin 2024 第 76 页明确主张后者。
- **Q2 教科书的讲法，算不算理论的一部分**：“路径即穿越时间”不只是 HoTT Book 的教学比喻；Rodin 2014 把它当作 HoTT 同一类型的正面哲学解释，写进了专著。它算不算“设计者的抽象”，仍由用户决定；但不能再说它只是教科书上的一句话。
- **Q3 早有人知道，还算不算**：已知的层次更清楚了：
  - 一般张力（可逆路径对不可逆时间）：有向代数拓扑自 1990 年代起以此为动机，Grandis 2007 已经在路径上计量长度与时长；
  - 应用中的局部实例：HPT；
  - 代价版本：calf/decalf、Niu–Harper；
  - 离散数据改不了的一面：Myers 2024；
  - **仍未找到先例的**：
    - T1 的一般陈述；
    - Delay 语义下“走满两步就停”的程序永不停机；
    - 作者 `MS` 的非集合性，以及交换历史上移一层；
    - 对 HoTT Book 第 2 章读法的直接批评。
  - 用户说“芝诺、罗素也是已知的”，这里有了具体对应：可逆路径抹掉时间，早已是有向拓扑与哲学的公开动机；而这个现象在 HoTT 里怎样具体发作，本项目手里有机器检查过的过程，两轮检索都没有找到它的先例。

## 5. 自查：CN-032 的一处过度表述

CN-032 §1 第 2 行说，decalf 的“有向”“与有向同伦无关”。读过 §4.2 后，我发现这话说得太满：decalf 的内在预序正是用有向区间上的路径定义的，单纯集是它的模型。

应改为：decalf 用有向区间上的路径定义项之间的次序（截断在 0 层，没有高阶同伦），与有向同伦同属一类做法；动机是效应与代价上界，不是可逆性。

已在 CN-032 文首加修订块，004 中它的状态随之改为 `REVISED → CN-033`。归类 R-B / R-C 不变。
