## 1. 一句话答案

**首选：Duminil-Copin（2022 年菲尔兹奖）与 Aizenman 证明的四维 φ⁴ 平凡性，以及它背后从 Schwartz（1950）到 Hairer（2014）再到 Duminil-Copin（2022）的“连续场论”这一条线。**【判断】

给外行的说法（这是我对 UR 的候选表述，“不合理”与否由研究发起人一眼判定）：

> 两个东西碰在一起会相互影响，这再简单不过。可是，只要像数学惯常的那样，把时空当作可以无限细分的连续体、把粒子当作没有大小的点，那么在我们生活的四维时空里，连最简单的一种相互作用都无法存在：格子分得越细，没有大小的“粒子”越难碰上彼此，相互作用就越弱；分到无限细，它恰好消失。在每一个有最小格子的版本里，相互作用明明都在。可是，可是，到了无限细分的连续时空里，它就没有了。

这就是 KC-000003 的原句结构：【原话】“可以构造芝诺悖论那么一个过程，也可以构造圆环悖论那么一个过程，来展现，在稠密性的空间中，无法完成现实可以完成事情。”现实可以完成的事是“相互作用”，稠密性的空间是“连续的四维时空”，那个过程是“把格子一次次减半”。

备选第二：Gromov–Witten 的虚拟计数（Kontsevich 1998、Okounkov 2006、Pardon 2026），UR 是“曲线的条数是分数”。备选第三：不可实效的有限性定理（Roth 1958、Faltings 1986、Tsimerman 2026；Baker 1970 为反方），UR 是“只有有限个，却永远不知道找齐没有”。理由见第 2、5 节。

## 4. 首选：连续场论这一条线

### 4.1 研究对象（说清是什么）

- 理论：欧氏标量量子场论。按 Osterwalder–Schrader，构造一个满足公理的玻色量子场论，等于在 Schwartz 分布空间 S′(ℝᵈ) 上造一个满足若干条件的概率测度（【来源】Hairer 的颁奖评述第 3 节；Duminil-Copin ICM 2022 §6.1）。
- φ⁴ 是其中最简单的“有相互作用”的理论（一种玻色子，自己和自己作用）。物理里最著名的这类场是希格斯场；ADC 的定理针对一分量的 φ⁴ 与 Ising 型模型，不直接覆盖标准模型。
- **定理**【来源】（Aizenman–Duminil-Copin，Annals of Math. 194 (2021) 163–235；勘误 Annals 199 (2024)）：四维最近邻铁磁 Ising 型模型在临界点或其附近的自旋涨落，标度极限是高斯的；对带格点紫外截断的 λφ⁴ 场，在无穷体积、格距趋于零的极限下，同样是高斯的。偏离高斯的程度有上界 C·z⁴/(log L)^c（ICM 报告 (6.21)）。高斯即“自由”：粒子之间完全没有相互作用。2022 年颁奖词点名了这一结果（检索摘要）。
- **维数阶梯**【来源】：二维、三维的 φ⁴ 测度在 1970 年代造出来了，是有相互作用的（Hairer 的评述）；五维以上，Aizenman 与 Fröhlich 在 1981–82 年证明平凡，偏离按 L^(4−d) 衰减（ICM (6.18)）；Duminil-Copin 的 ICM 报告说，这个结果让构造性量子场论纲领戛然而止。四维是临界情形：Hairer 的评述算出 |∇Φ|² 与 Φ⁴ 两项的标度指数分别是 λ^(−d) 与 λ^(4−2d)，恰在 d = 4 相等。
- **机制**【来源】：四维里，两条在距离 L 上连接各自端点的随机游走，相交的概率按 (log L)^(−c) 衰减，虽然期望相交次数是 1 的量级（ICM §6.4、§6.6）。没有粗细的路径在四维里越来越难碰上；ADC 把这个直觉搬到了随机流（random current）上。
- **前史**【来源，经检索摘要转述，未读原文】：1950 年代的“莫斯科零”：在点状的裸相互作用的极限下，物理的相互作用（重整化后的耦合）消失；Landau 据此宣布哈密顿方法已死。ADC 是这件事在四维 φ⁴ 上的严格版本。
- **这条线上的另两位得主**【来源】：Schwartz 的分布是整个舞台（场是随机分布，不是函数）；Hairer 的评述里有一句 “distributions cannot be squared”。Hairer 的 KPZ 论文把方程里的 ∞ 明写为抵消 (∂ₓh)² 发散所需的“无穷常数”，其正则化版本的常数 C_ε ≈ ε⁻¹∫φ²；他的正则结构给三维 φ⁴ 的动力学，靠的也是减去发散常数（论文目录 §1.4、§9.2）。

### 4.2 §6 对齐检查

1. **收益与取舍**（对象：欧氏标量场论的标度极限；尺度：格距趋于零）。省掉的是“选一个最小尺度”的任意性；换来的是平移、旋转（洛伦兹）对称、微积分与普适性，不必写“格子多大”。添进来的是两样理想化：时空无限可分；相互作用发生在没有大小的点上（φ(x)⁴ 在同一点相乘）。
2. **现实解释**。它模仿的是“粒子在空间里运动、相遇、相互影响”。有限格点上的场，是谁都能算的现实对象。宣布完成的是“标度极限”这一步。贴不上的那一句是“相互作用发生在一个没有大小的点上”：现实里两样东西要碰到才相互作用，而四维里两条没有粗细的随机路径几乎碰不上。
3. **种子句**。理论为了对称与普适（E），把“时空有最小尺度、相互作用有大小”（T）改成“时空无限可分、相互作用在点上”（T′）；若把格子一次次减半（P），原任务“相互作用存在”（Done）在极限里失败：四点联结函数趋于零，极限是自由场（O）。
4. **邻近对照**。同一个 φ⁴，在二维、三维也取连续极限（同样无限可分），相互作用保留（要做重整化）；在任何有限格点上（不无限可分），四维里相互作用也保留。差在“无限可分”与“四维”这一合取。
5. **注意转移**。最先跃入的熟悉答案（候选零）是：“这是物理学早知道的平凡性问题，有效场论早已消解。”我把注意移到这里：有效场论的消解方式，恰恰是保留一个物理截断，也就是放弃无限细分。它不是消解，而是承认了被改掉的那个条件。下一个动作见 4.8。

重讲（3 到 5 句）：为了让理论简洁、对称、哪里都适用，数学物理把时空想成可以无限细分的，把粒子想成没有大小的点。这在绝大多数计算里毫无问题。可是在我们生活的四维时空里，这两条合在一起就出事了：没有大小的粒子几乎永远碰不到彼此，于是格子分得越细，相互作用越弱，分到无限细就没有了。2021 年的一条严格定理证明了这一点，第二年它的作者之一获得菲尔兹奖。现实里东西当然会相互作用，不合理的是那幅无限细分的图景。

### 4.3 与芝诺、圆环逐行对照【解释】

| | 芝诺 | 圆环 | 四维 φ⁴ |
|---|---|---|---|
| 本来很简单的事 | 从这里走到那里 | 把剪开的圈接回去 | 东西之间相互作用 |
| 理论为了好用改掉的条件 | 位置可以无限细分 | 点没有大小 | 时空可以无限细分，相互作用在没有大小的点上 |

这张表是对位，不是数学上的同构。三处值得指出：

- **同一个呼喊**。圆环原话【原话】“可是，可是，我们当初确实得到了M啊！为什么变成N之后就无法再回到M了呢？”在这里是：格子上明明有相互作用，为什么到了连续时空里就没有了？
- **同一种“宣布”**。`main` README 说，极限用一条定义把“走到了”宣布回来。这里方向相反：连续极限宣布“没有相互作用”，而没有任何一个有限步是这样的。两者都是极限的判决与每一个有限阶段都不一样。
- **教科书的回答这一次站到了研究发起人一边**。对芝诺，教科书用极限保住了连续。对四维 φ⁴，物理学的标准回答是有效场论：承认存在一个物理的最小尺度。这正是研究发起人的立场（KC-000004：“运动存在最小的瞬移尺度——普朗克尺度”）。所以这条线可以把 `main` README 第 2 节里“这是研究发起人的物理立场，这份说明不替它作证”往前推一步：反证法这一次有一条菲尔兹奖级的定理做推演。推演的结论仍然只能否定前提的合取，见 4.5。

### 4.4 维数阶梯是现成的对照组【解释】

- d = 2：有相互作用，只需轻度的重整化（Wick 序）。
- d = 3：有相互作用，要减去发散的常数（Hairer 给出了它的动力学，2014 年奖）。
- d = 4：恰在临界；相互作用以对数的慢速消失（ADC，2022 年奖）。
- d ≥ 5：快速消失（1981–82）。

四维这一格有两点值得写进最后的短链。其一，它恰好是我们生活的维数。其二，它“死”得极慢：在任何现实能达到的尺度比（例如普朗克尺度到对撞机尺度，大约是几十次减半）上，相互作用都还在；只有在“无限细分”这个理想化里，它才归零。后一点是物理上的重整化群估计（【来源】启发式），ADC 证明的是上界，不是精确速率。

### 4.5 归因（KC-000049：候选前提、竞争归因、区分证据、判断）

**候选前提**

- P-cont：时空无限可分，没有最小尺度（芝诺的前提）。
- P-pt：相互作用发生在没有大小的点上，场在同一点相乘（圆环的前提“点没有大小”；分布不能平方）。
- P-4：维数恰好是 4。
- P-model：只有一种标量场、φ⁴ 型的相互作用（ADC 覆盖的模型类）。
- P-norm：用二点函数归一化取标度极限（ADC 的提法；换别的归一化，极限是零或发散）。
- 现实侧前提 P-real：现实中的相互作用是存在的（希格斯场的自相互作用、Ising 磁体的局部耦合）。

**竞争归因**

- (a) 研究发起人的读法（我按 KC-000003、KC-000004 推测，待确认）：P-cont 与 P-pt 合起来是非现实的抽象。
- (b) 物理主流（有效场论）：φ⁴ 不是终极理论，存在物理截断。它与 (a) 同向：截断就是最小尺度。
- (c) “模型选错了”：真实世界的强相互作用是渐近自由的规范场，φ⁴ 只是玩具。
- (d) “维数巧合”：毛病在 P-4。

**区分证据**

- 维数阶梯：P-pt、P-model 不变，d = 2、3 有相互作用。所以光有点状相互作用不够，是 P-cont 与维数一起起作用。
- 格点对照：保留最小尺度，任何维数都有相互作用。所以去掉 P-cont，对所有模型、所有维数都修好；去掉其他前提只修好一部分。
- 渐近自由的规范理论：四维连续极限预期存在，但至今没有严格造出来（Clay 千禧年问题；四维至今没有严格构造出非平凡的、满足公理的量子场论，偶有未获公认的新声明）。所以 (c) 也没有一个已造好的反例可用。
- 随机游走相交：没有粗细的路径在四维几乎碰不上，有粗细的能碰上。这是 P-pt 与 P-cont 在机制层面的合取。

**判断**【解释，条件式】：首先该审 P-cont 与 P-pt 的合取，也就是“无限可分加上点没有大小”。它是唯一一个“去掉就处处修好”的前提；P-4 决定它在哪里咬人，P-model 决定咬得多狠。这是排序，不是唯一的被告（KC-000019：一假即假，结果只否定合取的整体）。

### 4.6 最强的反对与撤回条件

1. **“物理学早就知道了”**（Landau、平凡性问题、有效场论）。回应：已知不构成否决（KC-000015；HoTT 那一次的数学事实也大多已知）。我们要的是：把它读成一个芝诺式的 UR，并指出它指向哪一个前提。这一读法没有做过文献查重。
2. **“φ⁴ 本来就不是对的理论”**。回应：UR 的量词照实写，“在某种情况下”。它是四维里最简单的那一种相互作用。
3. **“没人要求取连续极限，格点就是理论”**。回应：这正是研究发起人的观点。UR 说的是，那个连续的数学理想（S′(ℝ⁴) 上满足公理的测度）装不下它。
4. **撤回或降级的条件**：有人用 ADC 覆盖不到的办法（非格点正则化，或强耦合下的别种格点模型）严格造出非平凡的 φ⁴₄，这条 UR 就要降级；研究发起人判定“相互作用”不算“本来应该很简单的事”，就换靶。

### 4.7 它不是什么

- 不是说量子场论在数学上不一致；所有命题都是正当的数学。
- 不是说四维一切相互作用都不可能；渐近自由的规范理论是开放问题。
- 不是我们的发现。数学事实属于 Aizenman、Fröhlich、Duminil-Copin 等人；我们想加的只有读法、归因与机器检查的骨架。

### 4.8 机器证据怎样做（F-011 路线）【建议；可行性是我的判断，未验证】

HoTT 那一次，理论本身就是证明器的语言，所以每一步都能在理论里检查。这一次做不到：ADC 定理本身离形式化很远，只能按【来源】转述。可以机器检查的是 UR 的骨架：

- (M1) **临界维数**：两项的标度指数 −d 与 4−2d 相等当且仅当 d = 4（Lean 中是平凡代数）；“气泡”积分 ∫ |x|^(2(2−d)) 在无穷远处有限当且仅当 d > 4（预计可用 Mathlib 现有的幂函数可积性引理，未核）。
- (M2) **有限格点对照**：任何有限格点上的 φ⁴ 模型都不是高斯的，四点 Ursell 函数严格小于零。最小的情形是单点测度 e^(−x²/2 − g x⁴)：⟨x⁴⟩ − 3⟨x²⟩² < 0（g > 0）。要证实分析的积分不等式，可行但要花工夫。
- (M3) **重整化群的玩具**：gₙ₊₁ = gₙ − b·gₙ²，0 < g₀ < 1/b，则对一切 n 都有 gₙ > 0 且 gₙ → 0，即“每一步都还有，极限里没有”。Lean 中容易证。要写明它是玩具，不是 ADC。
- (M4) **复用现成的 Lean 项目**：OSforGFF（Douglas 等；Lean 4 与 Mathlib；v3.2，2026 年 8 月；任意维数 d ≥ 2 的有质量高斯自由场满足全部五条 OS 公理；0 个 sorry、0 条公理；约 25,500 行；Apache-2.0）。它给出的正是连续极限“宣布”出来的那个自由场。在它的框架里可以证明极限对象的四阶联结函数为零。它不含 φ⁴ 相互作用；二维 φ⁴ 另有两个进行中的 Lean 项目（据检索）。
- (M5) **只按来源转述的部分**：ADC 定理本身，以及 d > 4 的 Aizenman–Fröhlich 定理。

合起来是一条骨架：每个有限格点上相互作用都在（M2）；极限对象里没有（M4）；【来源】ADC：任何标度极限都是那个对象；中间的“每一步都有、极限里没有”的形状有玩具（M3）；为什么偏偏是四维有（M1）。

需要许可的事：本机现有的 Lean 4.34.0 只有核心库，没有 Mathlib（见本索引 003 的工具链登记）。除 M1 的整数代数可以马上做之外，M1 的积分、M2、M3（要实数）、M4 都需要 Mathlib。所以要先许可下载：OSforGFF 与它锁定的 Lean、Mathlib 版本（Mathlib 的预编译缓存约数 GB；它锁定的 Lean 版本可能不是本机的 4.34.0；按既有规则不经 elan 自动下载）。

## 5. 两条备选

### 5.1 第二：虚拟计数——“曲线的条数是分数”（Kontsevich 1998、Okounkov 2006、Pardon 2026）

- **种子句**：理论为了让“曲线的条数”在形变下不变、能用统一的公式算（E），把“条数是一条一条数出来的、互不相同的孤立对象的数目”（T）改成“条数是模空间上虚拟基本类的度数：每个对象按 1/|自同构| 加权，连成一片的族也给一个数”（T′）；若去数一族连成一片的曲线，或一个有对称的对象（P），答案是分数（O）。
- **实例**【来源，检索摘要】：五次三维流形上，二次曲线的 Gromov–Witten 数是 4876875/8 = 609250 + 2875/8；多出的 2875/8 来自 2875 条直线各自的二重覆盖，每条按 1/8 计（多重覆盖公式 GW_d = Σ GV_{d/e}/e³）。把整数找回来，要靠 Gopakumar–Vafa 整数性（Ionel–Parker 证明）；Pardon 证明的 MNOP 对应（颁奖词：在反典范丛为 nef 的情形），把有理的 GW 不变量的生成函数与整数的 DT 不变量的生成函数连起来。据我记忆（未回源），找回来的整数还可能是负数（局部 P² 的亏格 0 GV 数依次为 3, −6, 27, …）。
- **方向**：B 向最干净。一整族连成一片的曲线，“有几条”本来数不完（ASK 应当拒绝这个问题），理论却交出一个数。
- **与 HoTT 同根**：按自同构加权，就是“相同带着结构”。按相同归并的“二元集合”只有一个，却带着两种自我认同，加权计数是 1/2。这正是 C-74 的对象（“按相同计数恰好一个，收集本身不是集合”）。最简单的 Hurwitz 例子：球面在两点分支的二重覆盖，同构意义下只有一个，带一个对合，计数是 1/2。
- **为什么第二**：UR 一眼最强（“1/8 条”），机器证据最好做（Hurwitz 的有限群计算可在 Lean 里穷举；与 C-74 的桥可在 Cubical Agda 里做），与 HoTT 的结果接得最紧。弱点是专家会说“GW 不变量本来就不是条数”，即“换题”的反对（CN-051 第 2 节那一问的又一个实例）；而且它主要复现 HoTT 的同一个机制，按《最高指示》§4，换了现实域，但没有换前提。

### 5.2 第三：不可实效的有限——“只有有限个，却永远不知道找齐没有”（Roth 1958、Faltings 1986、Tsimerman 2026；Baker 1970 为反方）

- **种子句**：理论为了用反证法省掉构造（E），把“有限是能列出来、并且知道列完了”（T）改成“有限是不是无穷多”（T′）；若去把一条曲线上有限个有理点全部找出来（P），搜索没有停机判据：知道最多有几个，找到了几个，也永远不知道是否找齐（O）。
- **事实**【来源，检索摘要】：Faltings 定理的所有已知证明都不给有理点的高度界；点的个数已有可算的上界，高度没有。Pila–Shankar–Tsimerman 的 André–Oort 证明同样不可实效，来源有二：Tsimerman 的 Brauer–Siegel 型下界与 Pila–Wilkie 计数。
- **为什么好**：它正是 `main` README 对罗素幽灵的定义：“只要一个理论把某样东西一下子交到你手里，而确认它的那个过程却永远做不完，罗素的幽灵就会回来。”它也直接对上 KC-000011、KC-000018 对“没有时间的逻辑”的怀疑。
- **为什么第三**：“做不到”的身份最弱。Alpöge 与 Lawrence（2024，arXiv:2408.11653）给出一个算法：它若停机就输出全部有理点，并且在 Hodge、Tate、Fontaine–Mazur 猜想下总会停机。所以这里的“做不到”很可能只是暂时的知识空白，不是定理。若研究发起人更想追时间这一维，它的逻辑骨架可以在 Lean 里做成有范围的定理：一族集合每个至多一个元素，可以在极限里学到（至多改一次主意），却没有算法能确认学完（归约到停机问题，Mathlib 有现成的计算性库）。

## 6. 看过但不排在前面的【判断】

- **Cohen（连续统假设）**：最有名的“理论答不了”，在 Lean 3（Flypitch）与 Isabelle/ZF 里都已形式化。但“比自然数多、比直线上的点少的大小有没有”对外行并不“本来很简单”，读法也与谓词论者的老批评重合。
- **Hairer 单独作为靶**：KPZ 的“平均生长速度是无穷大，只能减掉”是很好的 UR，已并入首选线作为第二级。
- **Werner**：布朗边界维数 4/3 就是海岸线悖论，名气太大，读法不新。
- **Villani**：Landau 阻尼中弱极限宣布“平衡了”，分布函数却永远没有到达；UR 的“本来很简单”一侧不够清楚。
- **Yoccoz、Avila**：系统稳不稳取决于参数的无穷位小数。它与圆环线已经找到的“点的相等不可判定”是同一机制（CN-024），按《最高指示》§4 应换机制。
- **Yu Deng**（2026 年最新、主题正是“不可逆性的出现”）：现实一侧有争议。日常经验站在 Boltzmann 一边（鸡蛋打碎了不会复原），显得不合理的反而是有限可逆系统的回归。
- **Hong Wang**（Kakeya）：Besicovitch 的“零面积转针”是零宽度针的 B 向 UR，但早已著名；Wang–Zahl 的定理恰是给针加上粗细之后的修复（体积至少约 δ^ε）。它与 shenchensh 悖论（转动的直线）有缘，可作后备。
- **Smale**（球面外翻）：已经叫“Smale 悖论”。**Milnor、Donaldson、Freedman**（怪球、怪 ℝ⁴）：是惊奇，不是 UR；Casson 塔的 B 向读法有意思，但离形式化太远。
- **Grothendieck**（“点乘点得两个点”）：更像术语问题。**Selberg、Maynard**（奇偶性障碍：筛法到得了 6，到不了 2）：是一堵墙，不是一个过程。**Kontsevich 的形式量子化**（交出不收敛的级数）：B 向，有意思，次于 5.1。

## 7. 两项自检（《最高指示》§7）

- **精化有没有冒充原问？** 研究发起人问的是“下一个最值得进攻的菲尔兹奖目标”。我回答的是一个靶、一条 UR 候选句、一条证据路线。UR 是否成立，要研究发起人一眼判定；目标的正式确立，要研究发起人选择。我没有把“推荐”写成“找到了”。
- **解释有没有加码？** 四处照实收紧：ADC 证明的是偏离高斯的上界，不是精确速率（4.4）；定理覆盖一分量 φ⁴ 与 Ising 型模型，不覆盖标准模型（4.1）；“莫斯科零”与 Landau 只经检索摘要转述（4.1）；“四维没有严格造出非平凡理论”附了“偶有未获公认的新声明”（4.5）。
