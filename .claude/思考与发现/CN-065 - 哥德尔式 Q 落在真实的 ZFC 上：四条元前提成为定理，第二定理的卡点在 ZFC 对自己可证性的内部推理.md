# CN-065 哥德尔式 Q 落在真实的 ZFC 上：四条元前提成为定理，第二定理的卡点在 ZFC 对自己可证性的内部推理

## 1. 一句话

【证明】在 FormalizedFormalLogic/Foundation 里真实的 𝗭𝗙𝗖（ℒₛₑₜ 语法、LK 证明系统）上，“每一刻都看得见，‘永远’看不见”成了一条不带未证元定理前提的 Lean 定理：存在一个确实永不停机的过程 d，𝗭𝗙𝗖 对每个 k 证明“d 在 k 步内还没停”，却既证明不了“d 永远不停”，也证明不了“d 停”；补上“每一刻都没停就宣布永远不停”的规则 P，𝗭𝗙𝗖 要么不再可机械执行，要么自相矛盾。

## 2. 这一步改变了什么

CG-005 的定理对“满足四条元性质的有效理论”成立。读成关于 bare ZFC 的话，要以 ZFC 有效公理化（R）、Σ1/Δ0 完全、一致为前提，它们当时都是文献中的标准结果，没有在本仓库证明（CG-005 CLAIM §3）。现在：

- 【证明】R：`𝗭𝗙𝗖.Δ₁`（分离、替换两个模式的 Δ1 识别是新写的；BST 有限、AC 单句）与“𝗭𝗙𝗖 证明的永不停机句可枚举”（C-95、C-97）。
- 【证明】Σ1/Δ0 完全：𝗥₀ 的 Σ1 完全性 + `𝗭𝗙𝗖 ⊳ 𝗥₀` + Rayo 数字公式在每个 𝗭 模型里恰好定义 `ofNat n`（C-96、C-98）。这一步不需要可靠性。
- 【证明，Lean 元层】一致：Foundation 的 `zfc_consistent`（`Universe` 模型）；Σ1 可靠（只用于“⊬ d 停”）：`Universe` 中 ω ≅ ℕ（C-100）。这两件是 Lean 元理论里的事，不是 𝗭𝗙𝗖 内部可证。
- 【证明】在此之上：`zfcEffective`、哥德尔 I 过程形式含独立性、魔鬼交易、`Entailment.Incomplete 𝗭𝗙𝗖`、跑者与 𝗭𝗙𝗖 + A = 𝗭𝗙𝗖 + P（跑者部分以“到达句与永不停机句在 𝗭𝗙𝗖 中可证等价”为参数）。

## 4. 技术上值得记下的几点

- 【证明】分离与替换模式在 ℒₛₑₜ 上的 Δ1 识别，可以照 Foundation 对归纳模式的 `InductionR` 写成一个按元数 n 与“主体编码函数” F 参数化的通用构件；关键观察是 `φ ⇜ ![#0]`、`φ ⇜ ![#0,#1]` 这类代换只是 `castLE`，编码不变，于是主体编码函数里能直接放公式编码 k，界 `k ≤ F k` 结构性成立。替换模式里另两处代换（`![#1,#0]`、`![#2,#0]`）经通用引理化为内部 `subst`。
- 【证明】“永不停机”句里随 e 变化的只有数字部分，所以可枚举性不需要翻译函数本身可计算：数字公式的编码是一个四行的内部原始递归。
- 【证明】Foundation 没有“结构同构保持一切公式求值”的现成引理（只有 `ofEquiv` 版与开公式同态版）；本包补了一个通用的 `eval_equiv_iff`。
- 教训：ℕ 上 Foundation 的 `≤` 与 Mathlib 的不是同一实例；`Theory L` 是句子集合，成员判定要用 `Sentence`；`section universe` 会被当成宇宙声明。

## 5. 归因（KC-000049）

- 候选前提：P（用“每一刻都没停”宣布“永远不停”）；证明的有限可查性（Δ1 公理化）；一致性；Σ1/Δ0 完全；经典二值性与实无穷（“停或不停”被当作已落定的事实）。
- 竞争归因：与 CG-005 §6 相同。新增的区分证据是三个负控制：去掉模型，可靠性在模型实例处断开；去掉 Δ1 表示，可枚举性在 `Theory.Δ₁` 实例处断开；去掉一致性，一致性字段断开。它们表明三条前提各自承重，而矛盾只会落在主动加进来的 P 上。
- 我的判断（解释）：被告仍是“把完成的整体当作结局”这一族前提，P 是它的主动形式。现在它针对的是真实的 bare ZFC，而不是一个满足标准元性质的抽象对象。
