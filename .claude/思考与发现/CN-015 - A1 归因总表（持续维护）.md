## 1. 被归因的现象

A1【证明 C-01–C-07；解释见 CG-001 工作台 §4.1】：把运动读作恒等路径时，任何取值于集合的仪表沿运动都不变。现实中，温度计从冷镇到暖镇读数会升。

反证式的合取【解释】：P1 ∧ P2 ∧ P3 ∧ P5 推出“读数不变”，而现实观察到“读数变了”，所以至少有一个前提是非现实的。

## 4. 我的判断【解释，依据 C-01–C-18 与 Book 原文】

**咬人的是 P1。** 更准确地说，是“=”被用来同时模仿两种现实：

- **共指**：“这两个名字指同一个东西”。莱布尼茨律在这里是对的：同一个东西，一切性质相同。
- **运动与变形**：“这个能连续变成那个”。莱布尼茨律在这里是错的：变过去以后，读数可以不同。

PREMISE-001 A-04 给 Path 写的现实骨架，恰好同时列了这两种：“两个标签指同一件东西的凭据”，与“一根绳子从这种形状连续变形成那种形状”。只是那里没有指出二者会冲突。HoTT 的收益来自把二者合一；A1 就是把共指的逻辑用到了运动上。

**P2 与 P1 不是二选一。** 在本项目用的 Cubical Agda 里，“相等 = 区间上的路径”是语法，不是使用者附加的读法。MO3-C B02 的窄读法能否认的，只剩“区间是不是物理时间”。拒绝 P2 并不会让非现实元素消失，只是让运动在合成几何里无处安放。

**稠密性 P4 不是这里的靶。** 不仅“去掉稠密，困难还在”（C-05b），而且合成运动上放不下任何严格序，也就放不下稠密（C-15–C-17）。HoTT 把“有序、有距离、有稠密”放在集合上，把“能运动”放在连通类型上，二者互不相通。

## 4a. 与圆环悖论的关系（CN-018）

HoTT 有两个圆，没有一个类型兼有二者（C-21）。用户圆环在合成圆上被 P1 咬住（拿走一个点什么都不剩，C-22）；在点集圆上被 P4 咬住（弱去点与“分离”之差要无界逼近来弥合，复原的覆盖蕴含 Markov 原则，Astra C-319、C-322、C-324）。所以 P4 并非在 HoTT 中处处缺席：它不在合成运动里，而在 HoTT 从构造性分析继承来的点集连续统里；那一半属于一般构造性边界。
