## 1. 被归因的现象

A1【证明 C-01–C-07；解释见 CG-001 工作台 §4.1】：把运动读作恒等路径时，任何取值于集合的仪表沿运动都不变。现实中，温度计从冷镇到暖镇读数会升。

反证式的合取【解释】：P1 ∧ P2 ∧ P3 ∧ P5 推出“读数不变”，而现实观察到“读数变了”，所以至少有一个前提是非现实的。

## 4. 我的判断【解释，依据 C-01–C-18 与 Book 原文】

**在立场 S 下，咬人的是 P1。** 这个判断依赖立场 S，而立场本身是争点（CN-020 §4）。更准确地说，是“=”被用来同时模仿两种现实：

- **共指**：“这两个名字指同一个东西”。莱布尼茨律在这里是对的：同一个东西，一切性质相同。
- **运动与变形**：“这个能连续变成那个”。莱布尼茨律在这里是错的：变过去以后，读数可以不同。

PREMISE-001 A-04 给 Path 写的现实骨架，恰好同时列了这两种：“两个标签指同一件东西的凭据”，与“一根绳子从这种形状连续变形成那种形状”。只是那里没有指出二者会冲突。HoTT 的收益来自把二者合一；A1 就是把共指的逻辑用到了运动上。

**2026-09-25 第二次修订的判断（CN-022）**：把 P1 拆开看更准确。咬人的是三者的合取：P1 的运动一面（把变化写成理论自身的结构）、P8（一切函数自动尊重它）、P3（普通数值的结构平凡）。这就是理论为经济性买下的“不变性白送”：补丁律白送与编辑前后看不出区别是同一件事的两面。上面“共指与运动”的冲突，是这条规律在无向情形下的样子；有向理论去掉了可逆（P9），却留下了这条规律（C-38 + GWB 推论 3.20）。

**P2 与 P1 不是二选一。** 在本项目用的 Cubical Agda 里，“相等 = 区间上的路径”是语法，不是使用者附加的读法。MO3-C B02 的窄读法能否认的，只剩“区间是不是物理时间”。拒绝 P2 并不会让非现实元素消失，只是让运动在合成几何里无处安放。

**稠密性 P4 不是这里的靶。** 不仅“去掉稠密，困难还在”（C-05b），而且合成运动上放不下任何严格序，也就放不下稠密（C-15–C-17）。HoTT 把“有序、有距离、有稠密”放在集合上，把“能运动”放在连通类型上，二者互不相通。

## 4a. 与圆环悖论的关系（CN-018）

（2026-09-25 修订）用户故事里的圆是点集圆；HoTT 的合成圆 S¹ 不是这个故事的载体，“合成圆上被 P1 咬住”一说撤回（换了对象）。点集圆上，对 Astra 的固定复原映射，覆盖蕴含 Markov 原则（C-319、C-322；可数选择下的反向见 C-324）。这是构造性实分析中的一个条件性覆盖边界，不是关于 HoTT 或现实圆环的悖论判词。“没有一个类型兼有二者”（C-21）只在“单射的集合值坐标 + 非平凡恒等环”下成立；凝聚类型论里拓扑圆的形状就是 S¹。

（2026-09-25 第二次修订，CN-024）圆环这一线的归因现为：候选前提“点由无尽逼近给出、相等不可判定”（实数的完备性；用户“稠密、无限可分”怀疑的精确一面）与“构造逻辑不含 Markov 原则”。区分证据：换成离散点，复原无需原则（C-42）；在 Astra 的固定映射下，复原的覆盖 → Markov，可数选择下等价（C-322、C-324）；Markov 原则在带单价宇宙的类型论中不可证、其否定也不可证（来源报告；对 Astra 系统的适用是【猜想】）。不是 HoTT 独有；按 KC-000015 不排除。

## 6. 相邻候选 A6′（数步数）的归因（2026-09-25，CN-023）

> **2026-09-25 修订（Terra 007 的 O-021；CN-028）**：下表“P9 是必要病因”要收窄为 **P9 作用于过程的表示**，即 P-proc（把步子写成路径）与 P9 的合取。HoTT 恒等类型的群胚律本身不变，列表或台账照样在同一个 HoTT 里计数（C-41、C-47 (c)）。所以出路是放弃 P-proc，而不是删掉 P9 这条规则。A6′ 的判词见 CN-028：STRONG_CANDIDATE，判据 (e) 有争议。

A6′ 与 A1、A1′ 共用“把运动或编辑写成路径”这一表示，但观察的是过程本身（走了几步、改了几次），病因不同：

| 前提 | A1′（对状态的观察看不见改变） | A6′（对过程的观察看不见过程的长度） |
|---|---|---|
| P9 恒等可逆（两侧逆与消去律） | 不是必要病因：有向理论去掉它，冻结仍在（C-38 + GWB 推论 3.20） | **必要病因**：自由范畴或自由幺半群里步数可数（C-41 的列表） |
| P8 函子性 | 必要 | 必要（`ap` 与运输都尊重 `p ∙ sym p ≡ refl`） |
