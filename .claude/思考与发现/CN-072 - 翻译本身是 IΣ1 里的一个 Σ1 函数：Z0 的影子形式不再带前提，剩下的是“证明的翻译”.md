# CN-072 翻译本身是 𝗜𝚺₁ 里的一个 Σ1 函数：Z0 的影子形式不再带前提，剩下的是“证明的翻译”

> 本机会话 d58e0c0d（Opus 5.5），2026-10-09，目标包 CG-007 的 W4b。证明包 `HoTT/formal/claude-cg001/godel-q-zfc-z0-translate/`（CG001-C-119、C-120），CG-001 证据索引 §34，`形式化追踪/01-有哥德尔路线/02-Z0-条件形式与剩余三步.md`。身份标注：【原话】【证明】【判断】【来源】。

## 1. 一句话

【证明】把算术句翻译成集合论句的那个函数，在算术理论 𝗜𝚺₁ 内部就能写成一个 Σ1 函数，并且在 𝗜𝚺₁ 的每个模型里都恰好算出翻译的编码（C-119）。于是翻译可计算，𝗭𝗙𝗖 的算术影子可枚举。Z0 的影子形式（𝗭𝗙𝗖 证明不了它的算术影子的一致性句）不再带任何前提（C-120）。

## 2. 它在研究里的位置

- 【原话】十三条 [1]（KC-000063）：“……我们甚至还可以找到Q0（H0（Z0）），意思就是Q0是ZFC的Q，其实对应了H0在ZFC中的对应物Z0。”
- 【判断】Z0 是 𝗭𝗙𝗖 对自身矛盾的逐步搜索。它的 UR 是：“检查自己会不会自相矛盾，本来是很简单的事——一直查下去就行——甚至在 ZFC 中都做不到。”
- 到 W4b 为止，ZFC 一侧走到了这里：
  - 每一刻看得见（C-99）；
  - “永远”看不见（C-100、C-104）；
  - 跑者的“到了”就是“永远不停”（C-118）；
  - 对自己的搜索，𝗭𝗙𝗖 确认不了它在“影子”这一层永不停（C-120）。

## 3. 证明里值得记下的

- **内部路线比原始递归路线短得多。**
  - C-111 估计两条路线都要上千行。实际内部路线约 600 行。
  - 【判断】省下的是“代换在编码上原始递归”这一层：Foundation 的内部 `subst` 已是 Σ1 函数，并有与类型化代换对应的引理（`typed_quote_substs`、`val_substs`）。
  - 一条通用的经验：要证一个语法函数可计算，在 𝗜𝚺₁ 里把它写成 Σ1 函数，再用 `computable_iff_sigma1`，比在 Mathlib 里逐层证原始递归省力。
- **正确性是对每个具体公式的元层定理。**
  - `iT_quote` 对每个算术公式 φ 成立，在 𝗜𝚺₁ 的每个模型中都成立（包括非标准模型）。
  - 它不是 𝗜𝚺₁ 内部的一句“对所有公式编码”的断言。对 Sh.RE 来说这就够了，因为可枚举性只看 ℕ。

## 4. 剩下的一步：为什么不是一句话就能补上

【来源】两处 Foundation 的实现事实（本次读源码核对，`1fb01b72`）：

- Craig 版第二定理用到的 `Sh.craig`，它的公理集由 `reCh := codeOfREPred(…)` 定义，那是用选择公理挑出的某个 Σ1 公式。它在 ℕ 中正确，在非标准模型里的行为由这次选择决定。所以 C-120 中的一致性句，是“某一个”对 Sh 正确的一致性句（任何 Σ1 定义都使第二定理成立，Feferman）。
- 翻译保持可证性（`DirectTranslation.of_provability`）在 Foundation 里是用完备性定理证明的，属于语义证明，其中没有可以搬进 𝗜𝚺₁ 的语法证明翻译。

【判断】所以要把 C-120 读成“𝗭𝗙𝗖 证明不了 Con(𝗭𝗙𝗖)”，不能只在两句一致性之间加一条桥。比较干净的写法是：

1. 直接用“𝗭𝗙𝗖 证明 x 的翻译”作为 Sh 的可证性谓词 𝔅Z(x) := `Provable 𝗭𝗙𝗖 (iT 0 x)`。它是显式的，没有选择。
2. 用 Foundation 的抽象第二定理（`ProvabilityAbstraction.con_unprovable`）。它要的条件，按难度分开：
   - D1：可由 C-119 与 Foundation 的 `internalize_provability` 得到；
   - D2：同上，加 `modus_ponens_sentence`；
   - 对角化：Foundation 对 𝗜𝚺₁ 已有；
   - 𝗜𝚺₁ ⪯ Sh、Sh 一致：已有（C-110、C-103）；
   - **D3**：在 𝗜𝚺₁ 中，𝔅Z(σ) → 𝔅Z(𝔅Z(σ))。这就是“经翻译的形式化 Σ1 完全性”：在 𝗜𝚺₁ 的每个模型里，真的 Σ1 句子的翻译要有 𝗭𝗙𝗖 的证明，证明的长短随非标准数字增长。
3. 𝔅Z 的一致性句与 Foundation 对 𝗭𝗙𝗖 的一致性句在 𝗜𝚺₁ 中等价，因为 `iT 0 ⌜⊥⌝ = ⌜⊥⌝` 在每个模型中成立。

D3 是剩下唯一的实质步骤。Foundation 对算术理论的 D3 本身很短（179 行），但它依赖约 800 行内部 𝗣𝗔⁻ 证明演算，那是为算术项写的。到 𝗭𝗙𝗖 一侧要重做：数字是翻译后的公式，不是项。这是 W8 的内容；做不完，就把它写成精确的阻塞引理，并留下其余部分已证的最小可续状态。

## 5. 自检

- **精化有没有冒充原问？** C-120 承接了 Z0 的“确认不了自己永不停”，对象是算术影子的一致性句，不是 Con(𝗭𝗙𝗖) 本身。CLAIM 与追踪章节都写明了这一点。
- **解释有没有加码？** “ZFC 的问题”的判词仍以研究发起人的原话与已证命题为准；本笔记没有新增对 ZFC 的判词，只记录形式化的位置与缺口。
