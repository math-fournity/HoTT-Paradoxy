## 0. 一句话

HoTT 为了“对得上的就是同一个”（单价性），把“相同”从一个事实改成了一种结构；于是“按面粘合、面之面相合”这条在事实世界里一行写完、自动成立的规则，在 HoTT 里每补一层都长出下一层，有限的每一步都做得到，整体至今没人写完。

## 1. 短链（人话版）

1. **一个看似合理的取舍。**HoTT 最自豪的一步是单价性：同构的东西就是同一个。HoTT Book 导言说，数学家平时就这样做，只是靠“记号滥用”；单价性把它变成了正式规则（【来源】工作台 §1）。代价是：在 HoTT 里，“两个东西相同”永远是一种具体的对法，而且对法和对法之间还能有不同的对法，一层一层往上，不存在“只是相同、没有怎么相同”的相同。宇宙里连 Bool 与自身都有两种不同的相同（C-63 (a)）。
2. **一个专门碰它的过程。**写出用点、线、三角形、四面体以及更高维单形粘出形状的一般规则：每一维的“面”都要对上，面的面也要对上。小孩都能说出来，数学家平时一行写完（点、面映射、面之面相合的等式）。
3. **同一件事，两边的结果。**
   - 在“相同是事实”的世界里（Lean，所有相等证明都相等），这一行定义就是完整的定义：两种化简顺序自动一致，后退在第一步就停（C-65）。
   - 在 HoTT 里，同一行文字照样通过类型检查，却接受“对不上”的数据：一个每条面等式都成立的结构，两种化简顺序在圆周上一个绕 1 圈、一个绕 2 圈（C-64，绕数由内核直接算出）。
   - 把“两种顺序要一致”补成新规则，又出现两件事：一致的方式不止一种（在 2 维球面上，有两种不同的一致方式，C-66），而且各种一致方式之间还要再一致，这一条同样不自动成立（C-66 的 `Deg₃` 在 (0,0,0,1) 处被违反）。
   - 每一个有限层都写得出来：一个普通程序对每个具体的 n 打印出第 n 层，内核逐层接受（C-62，写到第 5 层）。可没有人能在 HoTT 内部一次写出所有层；2025 年的论文说每次尝试“似乎又导向一个无穷后退”，2015 年一次非正式调查中多数研究者认为写不完（【来源】）。
4. **换题也消不掉的检查。**
   - “加个字段就行”：加的正是下一层相干，它本身就是后退。
   - “改用集合”：那就换了任务，半单纯集合不是半单纯类型。HoTT 做半单纯集合毫无困难（C-64 `setsCohere`），困难恰好在“相同是结构”的地方。
   - “换一个理论”：已知的每一种成功定义（2LTT、Voevodsky 的 HTS、逻辑增强类型论、displayed type theory）都另外加回了一种“作为事实的相同”，正是被怀疑的那个前提（【来源】）。
5. **它咬到了理论自己。**HoTT 要解释自己的语法时卡在同一处：语法里的等式若是结构，忠实的解释存在，但语法本身不再是集合，它自己的相干又成了问题；若把等式截断成事实，语法干净了，却无法忠实地解释进单价宇宙（C-67）。Kraus 写道，一种可能的看法是，与许多其他编程语言不同，HoTT 用这种方法不能充当它自己的解释器（【来源】）。

## 3. 技术版

- **理论位置 T**：书式 HoTT 与 Cubical Agda（2.8.0，cubical 0.9）的单价宇宙；恒等类型证明相关；单价性推出宇宙不是集合（C-63 (a)，HoTT Book 例 3.1.9）；语言内没有严格相等。
- **任务 X₇**：在理论内部给出半单纯结构的统一定义。两种表述：
  - 预层式（`WildSST`）：点 `X n`、面映射 `d n i`、半单纯恒等式 `sid`。它在事实世界里完整，在 HoTT 中缺相干：`Coh₂`（六边形，置换多面体 P₃）不自动成立（C-64），在 UIP 中自动成立（C-65）；补上 `Coh₂` 作为数据后，第二级数据不唯一、下一层（P₄）在退化族中不成立（C-66）。
  - 索引式（`SST≤n`）：每个有限层可由外部程序写出（C-62）；理论内部的族 F : ℕ → U 是开放问题（Kraus 2021 §4 的表述）。
- **自指 X₇′**：标准解释的两难（C-67）；Kraus 2021 摘要与例 6。
- **现实一侧的身份**：实际的数学做法（半单纯集合的统一定义，已在 Coq 中形式化，Herbelin–Ramachandra 2025）与实际的程序（`gen_sst.py` 对每个 n 运行并停机）；自指一侧是实际存在的自解释器与 UIP 类型论中的“类型论在类型论中”。不是比喻。

## 4. 归因（《最高指示-Claude版》§1.3 的四件事）

**候选前提**：
- P-U（单价性）：宇宙中的相同就是等价，因而宇宙不是集合；
- P-I（内涵恒等、语言内没有严格相等）：与不带 K 的 MLTT 共有；
- P-F（一切类型同伦不变、没有非纤维类型）：HTS、2LTT 加入的正是非纤维层；
- P-C（统一性：定义要在理论内部，对变量 n）：任务自身的条件；
- 现实侧前提：面之复合相合是事实（严格恒等式）。

**竞争归因与区分证据**：
1. “病因是 P-I，普通 MLTT 也有。”区分：不带 K 的 MLTT 可以一致地加上 K，于是一切类型是集合、后退停止；HoTT 加不了，因为单价性推出宇宙不是集合（C-63 (a)）。所以 HoTT 的特殊之处在于 P-U **关掉了**这条退路。【证明】C-63 +【解释】
2. “病因是 P-F；2LTT 不动内层单价性，只加外层严格相等就解决了。”对，而且把病因说得更准：非现实的前提不是单价性本身，而是理论内部只有一种相同，而且它是结构。每一种修复都另加了一种事实式的相同。【来源】+【解释】
3. “病因是 P-C，统一性太强，每个 n 都行。”回应：统一定义正是“定义一个概念”的意思（KC-000031 的“覆盖”）；芝诺的每一次减半也都行（C-62 对应的正是这一半）。
4. “没有前提错了，只是还缺一个好点子。”区分证据：书式 HoTT 中的一个统一定义会推翻本候选；一个不可能性证明会坐实它。两者目前都没有；2015 年多数研究者站在后者一边（Buchholtz 2019，一次非正式调查）。

**我的判断**【解释，条件式】：咬人的是“理论内部只有结构式的相同”，单价性让它不可退出。它正是 HoTT 为经济性（不变性白送）做的抽象；无穷后退是它的非现实后果；每一种修复都加回了事实式的相同，这正是“站在反证法的视角中，我们设定错误的那个前提，就是理论设计者当初做的非现实抽象”（KC-000047）的回溯。条件：开放问题保持开放或得到否定答案；用户接受事实层的数学与外部程序作为现实一侧（CN-034 §8 第 3 条，用户已按推荐采纳，仍待明确确认）。

## 6. 它还说明了什么

- **与 Terra 的关口是同一前提的两面**（CN-034 §6）：对取值于集合的观察者，结构式的相同不可见，于是“做过什么”数不出来（A6、T1）；对在宇宙上统一进行的构造，它必须一层不落地带着走，于是写不完（A7）。
- **时间住在哪里**（CN-034 §5.7，KC-000011）：对每个具体的 n，面恒等式由计算定下（程序逐个运行，在时间中完成）；对变量 n，同样的恒等式只能用证明给出，而在 HoTT 中证明是结构，必须被上一层追踪。程序在时间里一层层做完的事，无时间的统一定义做不完。
- **KC-000028、029 的具体样子**：“持续性的、迭代性的、自我循环性的理论自身的内在要求导致的‘计算’路径的回环”，“最容易发生在……它想要理论的经济收益的地方”。A7 的后退正是如此：每一层的要求由上一层产生，而它出现的位置正是单价性带来的经济收益。
