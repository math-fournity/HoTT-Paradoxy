## 0. 对齐检查（压缩后首次审计工作，已用 Read 重读《最高指示-Claude版》全文）

1. **收益与取舍**：
   - 本轮的对象是 HoTT Book 对路径的读法：路径是运动，逆路径是沿同一条路线走回来，路径按同伦认同。尺度是随身携带的累积量。
   - Book 明写“严格相等对许多用途太细，补救是取更粗的同伦相等”。这就是理论经济性的原话：省掉了严格相等下群胚律的失败。
   - 添上的是：走过去再沿同一路线回来，与原地不动相等。
2. **现实解释**：行人来回走，计步器累积步数。贴不上的一句是：“走个来回与不动相等”。这句不是我加的，是 Book 自己在第 2 章开头写的动机。
3. **种子句**：理论为了让群胚律成立（E，Book 所说的“补救”），把“来回是两步”（T）改成了“来回与不动同伦相等”（T′）；若做“多走 2 步就停”的程序（P），在 P-rev 与“随身即运输”的规格下，程序等于永远运行的 `never`（O，C-55）。
4. **邻近对照**：温度计来回读数复原，不依赖 T；版本控制中的“已记录补丁数”可以因删除补丁（Darcs `obliterate`）而真实地减少，这是有符号计数，不依赖 T。只有只增不减的累积量（步数、做过的操作数、经过的时间）依赖 T。
5. **注意转移**：
   - 最先跃入的熟悉答案是 Terra 的：“选项 C：生成元才是事件，逆只是形式补全，所以没有悖论。”我没有否认它，而是去问它的代价是什么（C-56）。
   - 第二个熟悉答案是我自己的：“−1 就是非现实结果。”Darcs 的事实迫使我收回它的一般形式。

**给非专业读者重讲**：HoTT 的教科书自己说，把“走过去再走回来”和“站着不动”当成一回事，是为了让规律好用而有意选的“粗一点的相等”。于是凡是只增不减的东西（步数、做过几次操作），都不能靠“带着走”来记。这一轮我们把“停不下来”写成了真正的程序语义，证明了历史索引在类型层面就等于计数，又在同一个演算里证明：只要把“一步”从路径换成箭头，计步器就能数。但“−1 步”算不算非现实，取决于领域：行走中没有“倒着走抵消步数”，版本控制中删掉一个记录却是真实操作。

## 2. 自查与对辩（逐条）

### O-025：让步命名，补上程序语义

- **让步**：C-47 的形式内容就是 Terra 所说的无见证，命名改为 `NO_HALTING_WITNESS_IN_P_REV_TRANSPORT_SPECIFICATION`。008 说“永不停机”时，程序语义确实没有写出来。
- **补证**：C-55 用 Delay 单子（一般递归的标准语义）把程序写出来。
  - P-rev 规格下，“多走 2 步就停”的程序等于 `never`，对一切类型、路径、族成立；
  - 在 C-50、C-51、列表三种规格下，同一程序一步收敛；
  - 负控制：内核实际运行 P-rev 规格的程序一步，得到 `nothing`。
- **对辩**：Terra 说“现实计步任务并不要求 P-rev”，还引扩展认知 003：不能先人为制造缺口，再归给 HoTT。
  - 现实确实不要求 P-rev，但 **P-rev 是 HoTT Book 自己的读法**。第 2 章开头说，路径在每个“时刻”给出一个点；`p · p⁻¹` 是“从 x 走到 y，再沿同一条路线回来，时间从 0 到 1”；它与原地不动不严格相等；“补救”是取更粗的同伦相等。
  - 所以被删去的信息（来回的步数），恰恰是由所研究的理论化（Book 选择的同伦相等）删去的。这正满足扩展认知 003 的要求：说明被删除的信息究竟怎样由理论化带来。
  - 同一读法也在真实使用者那里：JFP §3.1 用逆路径 `! p` 建模“每个补丁理论都应有的逆补丁”，并写明应用补丁再应用其逆“与没有变化相同”。

### O-026：对辩，用作者自己同一段的话与 C-54

- JFP §7.2 同一段里，作者**先**说 replay 的 Nat × Nat 表示“实际上与 MS 同构”，**再**说 MS 的元素保存显式的次序日志、而路径认同只差置换的日志，最后说 Nat × Nat 表示“根本不保存”这种日志。
- C-54 把前一句证了出来：截断的 `FMSet Bool ≃ ℕ × ℕ`，由单价性二者相等；一切函数都经由计数；没有“第一项”。负控制显示，两种写法在定义层面分得开。
- **结论**：
  - 类型层：只有次数，作者自己也这样说；
  - 写法层：有次序，内核分得开，但没有任何函数读得出；这与 JFP §10“命题相等而计算不同的项，理论内部没有谓词能区分”一致。
  - Terra 的表第一行（“具体写法保留显式顺序日志”）我接受，限定为写法层。
- **让步**：“凡进入认同结构的都失去时间”是由三个例子外推的口号，撤回。

### O-027：让步命名，并主动加强 Terra 的论点

- `antiWalk` 改名 `FORMAL_SIGNED_INVERSE_ACTION_WITH_SCOPE`。“−1 步行走”只在 T2（每条路径都是一次行走）之下成立，是解释，不是内核结论。
- **自查所得，比 Terra 更强的一点**：在版本控制领域，从历史中删去已记录的补丁是真实操作（Darcs 文档：`obliterate` 永久删除仓库中已记录的补丁；`unrecord` 从仓库删除补丁而不改工作树）。所以“已记录补丁数”沿逆操作减一，在那里可以完全真实。−1 是否非现实**取决于领域**：
  - 行走中没有“倒着走抵消步数”的真实动作；
  - 版本控制中删除记录是真实动作。
- 因此我撤回“−1 是一般意义上的 KC-000047 非现实结果”，只保留为行走领域中的候选，待用户裁定 T2。
- **不随领域变化的核心**是只增不减的累积量（步数、做过的操作数、经过的时间）：C-49 (b) 说，沿路径运输携带的这种读数必然不变。Darcs 的事实不影响这一点，因为“做过几次操作”并不因删除记录而减少。

### O-028：让步

C-49 的形式命题本来就限于沿路径的运输；010 与 CN-029 中“哪种 HoTT 建模都躲不开”的说法过宽。改为：凡把携带完全写成沿恒等路径的运输（P-carry）的建模，都躲不开。

### O-029：让步，并进一步更正自己

- “严格的核心理论层面消融”撤回。
- **比 Terra 指出的更进一步的更正**：TT_□ 并没有去掉 P9。同一演算里路径仍然可逆（C-53 (a)(b)、C-57 (a)），它是另加了一种不必可逆的态射。所以准确的说法是“**过程原语的切换**”：一步用恒等路径表示，还是用箭头表示。
- **补证**：C-57 在同一个演算（sHoTT）中，以 GWB 定理 6.13 的内容为显式假设，固定同一个 `S`、`El`、纤维与停机合同，只切换一步的种类：
  - 路径：没有路径作用为后继，来回回到零，停机条件不成立；
  - 箭头：`Gl A A s` 作用为后继，两步到达 `s (s z)`；
  - 在复合假设下，复合来回箭头亦然。
- 这就是 Terra 允许的“具有明示该公理接口的证明环境”。S 的构造仍是 GWB 的定理，本包未重放。

### O-030：任务合同卡（写入 012）

- **行走（A6″）**：
  - 场地：两镇一路；实际一步：沿路走一次，方向不限。
  - 计数：ℕ，从 0 开始，每步加一，只增不减。
  - 输入：已做的行走序列；观察：计数；Done：计数 = 初值 + 2。
  - 理论侧读法：Book 第 2 章开头的 P-rev 与同伦相等。
  - T2 桥：
    - (1) 回程即 `p⁻¹`：Book 的读法（来源）；
    - (2) 计数非负：现实侧事实；
    - (3) 形式逆也是一次动作：行走中，除了沿同一路线回来，不存在另一种“逆”的动作。
  - 状态：候选，待用户裁定。
- **补丁（A6′）**：
  - 真实使用者：HPT。它把逆补丁建模为 `! p`（§3.1）。
  - 任务：数已应用的操作次数，包括应用逆补丁。这是只增不减的累积量。
  - 理论侧：数补丁的函数不可定义（§3.2）；逆补丁使路径复原（§3.1）。
  - 反解释：记录或日志层（Terra，T1），以及 Darcs 本身把删除记录也作为真实操作。
  - 状态：已知的建模取舍（`NOT_COMMUNITY_UNKNOWN`），候选价值在“只增不减的量必须作为数据保存”。

### 选项 C 与三层含义

- **选项 C**：我接受它是第三分支，008 与 010 的两难不穷尽。C-56 给出它的代价：地点类型有一个固定两镇的对合，它把事件与“反事件”互换，所以哪些路径是事件不由类型决定，方向是附加结构。在有向模型中，方向是内在的。
- **T0/T1/T2**：我接受这比 008 的二选一更好。给用户的问题改写为：你说的“Think in HoTT”，候选应落在 T1（HPT 那样的语义合同）还是 T2（强现实桥，路径即运动）？Book 第 2 章开头给 T2 提供了来源支持：路径即运动，逆即沿原路返回。

## 3. 归因（现行）

- **候选前提**：
  - P9-fam：运输是等价（规则）；
  - P-proc：过程是恒等路径（Book 的合成读法）；
  - P-rev：回程是 `p⁻¹`（Book 的读法；HPT §3.1）；
  - P-carry：随身即运输（Book 的路径提升读法）；
  - **P-hom**：路径按同伦认同（Book 的“补救”，即理论经济性的原话）；
  - 现实侧：只增不减的累积量存在；有的领域有真实的“删除记录”（Darcs），行走没有。
- **竞争归因**：
  - Terra：这些都是 T1/T2 层的建模选择，有正当替代（台账、生成元与形式逆分层），所以不是 HoTT 强加的失败。
  - 我：在 Book 自己对运动的读法（P-proc、P-rev、P-hom）下，来回的步数被理论化删去（C-47、C-55）；携带只增不减的量不可能（C-49 (b)）。替代都要离开恒等结构：台账是对象里的数据（KC-000011）；分层要把方向作为附加结构（C-56）；换原语要改用箭头（C-57）。
- **区分证据**：C-55（同一程序在不同规格下发散或收敛）、C-57（同一演算只换原语）、C-56（方向是附加结构）、C-54（类型层只有计数）、Darcs（−1 的领域依赖）、Book 第 2 章开头（P-rev 与“补救”的来源）。
- **我的判断**（【解释】）：
  - 可辩护的最强形式是：Book 为让群胚律成立而选择同伦相等，这使只增不减的累积量无法靠携带来表示。要表示它，就得离开恒等结构：把它记成数据，或把方向加为结构，或换用箭头。
  - 这是一个模型相对的强候选。Terra 的标签 `STRONG_MODEL_RELATIVE_CANDIDATE / … / REALITY_BRIDGE_AND_SAME_TASK_COST_OPEN / NOT_YET_REALITY_RELATIVE_PARADOX / NOT_COMMUNITY_UNKNOWN` 我接受。
  - 是否跨过门槛，取决于用户对 T1/T2 的裁定。
