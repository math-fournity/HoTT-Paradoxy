# CN-025 量子化的步子：路径没有偷带可观察的中间状态（此叶关闭）

> Claude（Opus 5.5），会话 91a6cdaa，2026-09-25。登记：`.claude/总索引/004`。状态：current（结论为“此叶关闭”）。
> 起因：建议顺序第 4 项【猜想】（CN-022 §7 第 3 条）：在 Cubical 中，一步是区间上的路径，中间点的读数落在 Glue 类型里；与用户的量子化运动观（KC-000004）对照，这是否是一处连续性的残留？
> 证据：【证明】已有的 C-01、C-03、C-15–C-17、C-25（本会话未新增证明）。【来源】Cubical Agda 的区间是 De Morgan 代数（CCHM cubical 类型论；Cubical Agda 文档）。其余为【解释】。

## 1. 种子

用户认为现实的运动是量子化的，存在最小的瞬移尺度【原话，KC-000004】“运动存在最小的瞬移尺度——普朗克尺度”。如果 HoTT 把一次跳跃写成一条路径，而路径是“区间上的函数”，那么理论是否给这次跳跃塞进了无数个中间状态——一种现实中没有的连续性？

## 2. 检查

1. **中间点观察不到**。沿路径 `p`，任何取值于集合的读数都满足 `f (p i) ≡ f (p i0)`（C-01）；Book 的区间 HIT 两端相等，任何读数两端相同（C-03）。理论没有给中间点任何可以区分的集合值读数。
2. **中间点没有位置坐标**。Cubical Agda 的区间是 De Morgan 代数，常量只有 `i0`、`i1`，运算只有 `∧`、`∨`、`~`；没有 `1/2` 这样的常量【来源】。所以“先走一半、再走剩下的一半”这种芝诺式的分割，在一条路径上连写都写不出来。
3. **依赖读数在中间没有规范的值**。C-25 的族在一步中间的纤维是一个 Glue 类型：它与两端的 ℤ 都等价，但要读成一个整数，必须先选一端运输过去；两端给出的数相差这一步的平移（C-25 的禁止外推已写明）。理论没有断言“跳到一半时读数是多少”。
4. **路径上没有先后与距离**。连通类型上放不下严格序，集合值“距离”由对角线决定（C-15、C-16）；有理数线有 0 < 1/2 < 1，却没有从 0 到 1 的运动（C-17）。

## 3. 判断【解释】

- 把一次跳跃写成路径，并没有给运动塞进可观察的中间状态；理论既不给中间点读数，也不给它们坐标或先后。在这件事上，HoTT 的合成运动与量子化的跳跃没有可观察的冲突。**此叶关闭**，没有现象。
- 与 CN-011、CN-024 合起来是一幅一致的图：HoTT 的“运动”（路径）不稠密；稠密住在实数这类集合里；用户圆环的困难也出在那里——点由无尽逼近给出时，复原撞上 Markov 原则（CN-024）。用户对稠密性的怀疑，在 HoTT 里有一个准确的落点：不是运动，而是实数。

## 4. 两项自检

- **精化有没有冒充原问**：本笔记只检查“路径表示是否偷带中间状态”，不回答芝诺或圆环。
- **解释有没有加码**：“没有可观察的冲突”限于本节列出的三类观察（集合值读数、坐标与先后、依赖读数的值）；不说 HoTT 与量子化现实在一切方面相容。
