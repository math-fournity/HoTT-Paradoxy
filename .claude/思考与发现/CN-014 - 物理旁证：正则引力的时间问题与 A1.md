# CN-014 物理旁证：正则引力的时间问题与 A1

## 1. 一句话

另一个成熟学科独立撞上了 A1 的结构：理论让不变性吞下“演化”，可观察量就被冻结。物理学家把它当作真问题，并且有一场与本项目同形、至今未决的归因之争。

## 2. 来源事实

- **Isham 1992**，*Canonical Quantum Gravity and the Problem of Time*（[arXiv:gr-qc/9210011](https://arxiv.org/abs/gr-qc/9210011)）。摘要说，时间问题源于量子论中“时间”的用法，与它在微分同胚不变的理论（如广义相对论）中所扮演角色之间的冲突。
- **Isham 与 Kuchař 的三分法**（经综述核对，例如 Anderson，[arXiv:1009.2157](https://arxiv.org/pdf/1009.2157)）：
  - *tempus ante quantum*：量子化之前先选定时间，例如隐时间、物质时钟、幺模引力；
  - *tempus post quantum*：先量子化，再从解出的关系里找出时间；
  - *tempus nihil est*：不要时间，例如历史表述。
- **Page 与 Wootters 1983**，*Evolution without evolution: Dynamics described by stationary observables*（[Phys. Rev. D 27, 2885](https://link.aps.org/doi/10.1103/PhysRevD.27.2885)）。可观察量须与哈密顿量对易，因而是定态的；可以认为整个宇宙处于定态。观察到的演化可以完全用定态可观察量描述，表现为对内部时钟读数的依赖。
- **Rovelli 2002**，*Partial observables*（[Phys. Rev. D 65, 124013](https://link.aps.org/doi/10.1103/PhysRevD.65.124013)）。区分部分可观察量与完全可观察量；部分可观察量之间的关系构成关系型的完全可观察量。
- **Earman 2002**，*Thoroughly Modern McTaggart*（Philosophers' Imprint 2(3)，[PhilPapers](https://philpapers.org/rec/EARTMM)）。广义相对论似乎推出：理论承认的真正物理量都不随时间改变其值。
- **Maudlin 2002** 的回应，*Thoroughly Muddled McTaggart: Or, How to Abuse Gauge Freedom to Create Metaphysical Monstrosities*（[PhilPapers](https://philpapers.org/rec/MAUTMM)）。标题即其立场：这是对规范自由的滥用。

## 3. 结构对应【解释；结构类比，不是等同】

| 物理（正则引力） | HoTT（A1 线） |
|---|---|
| 规范不变：物理可观察量在规范变换下不变 | 不变性白送：一切构造沿路径 transport |
| 时间演化由约束生成，因而被当作规范变换 | 运动被读作恒等路径 |
| 规范不变的可观察量不随时间变：“冻结的形式体系” | 集合值读数沿运动不变（C-01、C-02） |
| Page–Wootters：全局态是定态，演化只作为对时钟读数的条件依赖出现 | C-18：(起点, 0) 与 (终点, 1) 是同一个整体状态，只有按时钟读出的读数不同；C-14 同理 |
| Rovelli：变化只存在于部分可观察量之间的关系里 | 依赖族：变化只作为事先写进族里的改名出现（C-06、C-11） |
| Earman（理论本身推出无变化）对 Maudlin（这是对规范自由的误读） | 归 P1（理论把相同与运动合并）对归 P2（解释桥读错了），见 CN-015 |

**三分法与 HoTT 的三条出路**：

| 物理出路 | 做法 | HoTT 中的对应 | 代价 |
|---|---|---|---|
| tempus ante quantum | 在理论之前先固定一个时间 | C-05a：时间作为离散数据，运动是时间的函数，不是恒等 | 放弃“运动即恒等”，也就放弃合成运动的不变性白送 |
| tempus post quantum | 保留不变性，时间从关系里浮现 | C-06、C-11、C-18：变化只剩相对量，写进族里的改名，或按时钟读出的条件读数 | 变化是建模者预先写好的，整体状态仍然只有一个 |
| tempus nihil est | 不要时间 | 接受冻结：C-01、C-14 的字面读法，什么都没变 | 与现实中的变化直接冲突 |

## 4. 对研究的用处【解释】

1. **旁证 A1 的分量**：A1 不是温度计故事的偶然产物。“让不变性吞下运动，可观察量被冻结”是一个能在别处独立复现的结构。
2. **给归因一个外部参照**：物理学里的 Earman 对 Maudlin，与本项目的 P1 对 P2 同形。用户要“仔细探讨归因”时，可以对照这场争论是怎么打的，以及为什么至今没有结论。
3. **给出路列价目表**：物理学三条出路的代价，与 HoTT 三条出路的代价一一对应（上表）。
4. **可能的新种子**【猜想，未追】：物理学里关系型出路有自己的已知困难（例如该以哪个量作时钟）。C-18 中“按哪个时钟读”是由建模者预先写进族的，这与 CG-001 工作台 CE2 的“预写”批评同源。是否有一个 HoTT 任务，能把“时钟的选择”变成可观察的差别？

## 5. 不能推出的

- 它不证明 HoTT 的任何命题，也不说 HoTT 的路径就是约束的轨道。
- 时间问题在物理学中也未解决；不能用其中任何一派的结论来裁定 A1。裁定仍回到 CN-015 的证据。
