## 1. 两处解释加码，回源后更正

1. **模态**。研究发起人说的是“很可能已经找到了”。我在准备阶段收尾的 checkpoint 时，把状态标签写成了 `USER_VERDICT_FOUND`，抹掉了“很可能”。应用前逐文件看差异时发现，改为 `USER_JUDGED_LIKELY_FOUND`；A 向用户方向行改为 `A_LIKELY_HIT_USER_JUDGMENT_20260930`。收尾报告第 10 节“‘找到了’是研究发起人的判定”一句，同样改回“很可能已经找到了”。
2. **文献身份**。CN-050、扩展认知第 011 片、一页稿、社区稿 03、收尾报告与调研请求都写过“宇宙与这类乘积没有有限层，专家早就知道（HoTT Book 例 8.8.6；Kraus–Sattler 2015）”。回源的结果：
   - 乘积一侧是 HoTT Book 的例 8.8.6；
   - 宇宙一侧，书里（§8.8 末尾，PDF 第 304 页）写的是【来源】“We expect it should also be possible to show that a universe 𝒰 itself is not an n-type for any n … However, this has not yet been done.”；
   - Kraus–Sattler 2015 证明的是：单价宇宙层级里的第 n 个宇宙不是 n-型（不用高阶归纳类型）。

   含高阶归纳类型的单个宇宙对一切 n 都不是 n-型，本仓库有机器证明（C-75）；2013 年之后文献里有没有公开证明，交调研请求 Q0。CN-048 第 3.1 节当时照实转述过书里这句，后来的文字没有对上。更正的去处：checkpoint 管理的两处（扩展认知 011、全景视野罗素结果行）经 `S-GOV-20260930-CLAUDE-PHASE-CLOSE-SOURCE-CORRECTION`，社区稿 03 在首次提交前改好并重新钉住哈希，其余文件直接改，一页稿只在文首加注。

两处的形态相同，都是《最高指示-Claude版》§7 说的解释性加码：给模态或文献身份添了没有依据的强度。两处都在交付前被发现，靠的是两道工序：应用 checkpoint 之前逐文件看差异，改写 README 之前回读原文。【判断】这两道工序要留着。一个大单元收尾时，最容易在“总结”里把强度抬高一档。

## 2. 两条线共同的那一问【解释】

在 UR 之下，往返计步与罗素线最强的反对意见是同一种：

| | 往返计步（A6′／A6″） | 罗素线（UR） |
|---|---|---|
| 本来简单的事 | 走了两步，计步器显示 2 | 确认两个东西是不是同一个 |
| HoTT 的原生做法 | 一步写成路径：去而复返与不动相等，“走满两步就停”的程序等于 `never`（C-55、C-59） | 相同是结构：逐层追问的程序在宇宙上等于 `never`（C-78） |
| 换一种对象就做得到 | 把旅程当数据另记一本账（列表），数得出 2，程序一步停（C-41；C-55 的列表规格） | 对集合截断发问，第 1 问就停（C-83） |
| 换来的对象付了什么 | 时间只能活在账本里，HoTT 自己的推理仍把往返当作没动（CN-031） | 截断把相同的多种方式合成一种，而且解码不回宇宙（C-83） |
| 最强的反对 | Terra 的 Q1：能表示就算完成 | “换题”：对截断发问就是那件事的忠实做法 |

两条反对意见问的是同一件事：**HoTT 换一种对象，把那件简单的事做成了，算不算“在 HoTT 中做到了”？**

研究发起人以 UR 回答了“现实一侧是什么”（那件本来简单的事），还没有逐字回答这一问。【建议】下一次与研究发起人讨论归因（交接说明的 W5）时，先问这一问。一次回答，可以同时定两条线：

- 若“换一种对象做成”不算（被问的对象换了，或者时间只能住在旁边），往返计步的 Q1 按 Claude 的读法定，A6″ 也可以写成 UR 式的短故事；罗素线的“换题”反对不成立。
- 若算，罗素线要降为建模代价（HoTT 的原生问法做不到，截断问法做得到），往返计步也照 Terra 的读法记为已知的建模代价；研究发起人 09-30 的判断（“很可能已经找到了”）这时需要重新审视。

这一问不需要新的证明：两条线的形式事实都已机器检查，区别只在完成标准。它正是扩展认知 003 讲“完成的几种含义”时的那个分叉，落在两个具体任务上。【判断】我倾向前一种（不算），理由与 README 005 第 1 节相同：截断和账本都是凭定义把被改掉的条件（相同是事实、时间有次序）宣布回来，没有恢复它本身，这和用极限回答芝诺同形。这是判断，不是结论，由研究发起人裁定。

## 3. 第一阶段收尾意味着什么

（详见 README 006 第 4 节，这里只记一条提醒。）收尾的是第一阶段的查找，不是研究本身。研究发起人的判断要由数学社区与独立复核来检验；在那之前，任何 AI 都不要把它写成“已经找到”或“已证明”。

## 4. 自检

- **精化有没有冒充原问**：第 2 节的表把两条线放在一起，只借“换一种对象就做得到”这一组关系。两条线的现实任务不同，不说二者等价。
- **解释有没有加码**：第 2 节的倾向标为【判断】；“一次回答，同时定两条线”只在两条反对意见确实同形时成立。若研究发起人认为两件事的完成标准不同，就分开回答。
