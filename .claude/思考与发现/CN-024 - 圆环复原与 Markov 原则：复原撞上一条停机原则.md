## 0. 对齐检查（新单元：用户的圆环；已按 §9 回读 KC-000003、KC-000010、KC-000019、KC-000037、KC-000047 与圆环原文）

1. **收益与取舍**（对象：Book 式 HoTT 里的 Dedekind 实数与点集圆，逻辑是构造的；尺度：圆上的点）：省掉了逐一处理“近似”的负担——实数是完备的连续体，几何可以照常做；构造逻辑让每个证明都带计算内容。添上了：点没有大小，由无尽的逼近给出；“不等于”与“隔开多远”是两回事。
2. **现实解释**：有人把圆拿走一点、掰开成线段，再把两端对回去。谁宣布完成：两端对上，每一处都回到原来的位置。贴不上的一句：对于一个只知道“不是被拿走的那一点”的点，要把它放回线段上的位置，得先知道它离缺口有多远；而这个距离可能小到任何有限精度都看不出来。
3. **种子句**：理论为了“实数完备、几何可做、证明可计算”（E），把“点有大小，两端在有限步内对上”（T）改成了“点由无尽逼近给出，‘不等于’推不出‘隔开多远’”（T′）；若做“复原：让线段覆盖去点圆的每一个点”（P），则这种覆盖（在 Astra 的固定复原映射下）推出 Markov 原则，在可数选择下与之等价，而 Markov 原则是一条关于“不会不停的搜索是否停下”的原则（O）。
4. **邻近对照**：量子化的圆（n+1 个离散点）：去点、展开、复原全部可以完成，不用任何原则（C-42）。差别只在一项：点的相等是否可判定。
5. **注意转移**：最先跃入的熟悉答案是“这是一般构造性分析的边界，Coquand–Mannaa 的独立性只覆盖一个宇宙的 MLTT，搬不到 HoTT”（这正是 Terra 001 的说法）。我把注意移到：同一组作者后来把 Markov 原则的不可证推广到带单价宇宙的类型论；Markov 原则本身就是一条停机原则；用户原话里“无论两端逼近到什么接近的程度”恰好是那一次搜索。下一个动作：核对模型能否覆盖 Astra 证明链的全部公设；重放 Astra 的运行；告诉用户。

**给非专业读者重讲**：在实数的圆上，把拿走一点后的圆重新合上，要求线段上的点一个不落地回到原来的位置。对一个只知道“它不是缺口那一点”的点，你得先算出它离缺口多远，才能放回去；可它可能离得非常近，只有一直算下去才看得出差别。数学里有一条原则（Markov 原则）说：一个“不可能永远算不出结果”的计算，一定会算出结果。复原恰好需要这条原则；而 HoTT 自己既证不了它，也否定不了它（条件式，见 §3）。换成离散的点，这个困难就没有了。

## 1. 来源里已经知道的事【来源】

- **Coquand、Mannaa，The Independence of Markov's Principle in Type Theory**（arXiv:1602.04530，2016/2017；经 sciverse 全文库读摘要与引言）：Markov 原则在带自然数与一个宇宙的依赖类型论中不可推导；作者还给出强意义的独立性（原则与其否定都不可证），以及一个可证其否定的一致扩张。
- **Coquand、Mannaa、Ruch，Stack semantics of type theory**（LICS 2017）：给出带**一个单价宇宙**与命题截断的类型论的栈模型；命题 9：在 Markov 原则不成立的集合论（例如 CZF 的适当层模型）里，群胚模型中 Markov 原则不成立，由此 Markov 原则在带一个单价宇宙的类型论中不可证。脚注 3：用 Markov 原则不成立的集合论中的 cubical set 模型，同一论证给出 Markov 原则相对于**单价宇宙层级**的独立性。
- **Gratzer、Shulman、Sterling，Strict universes for Grothendieck topoi**：推论 6.1.2，Markov 原则及其否定在带累积严格宇宙层级的 Martin-Löf 类型论中都不可推导。
- **HoTT Book §3.4、§3.8**：排中律、（集合上的）选择公理都与单价性相容（单纯集模型）。排中律蕴含 Markov 原则，所以 Markov 原则的**否定**在 Book HoTT 中不可证。

## 3. 条件式结论【猜想，有强来源支持；不是机器证明】

若存在一个模型，同时解释上述 7 个公设，并且 Markov 原则在其中不成立（Coquand–Mannaa–Ruch 脚注 3 指向的 cubical set 模型是候选；它对圆、推出、n-截断与 replacement 的覆盖，本轮未核），那么：
- `BookMarkov` 在 Astra 的系统中不可证；由 C-322，Astra 固定复原映射的弱覆盖在该系统中**不可证**。
- 单纯集模型满足排中律与可数选择，也解释这 7 个公设（replacement 由集合论的替换公理给出——这一点本轮也未逐条核对）；由 C-324，弱覆盖在该模型中成立，所以它的**否定也不可证**。
- 合起来：在该系统中，这一形式的“圆环复原覆盖”既不可证也不可否。

按 F-011，这不能作为已证的数学结论交付：独立性是元定理，本项目没有它的机器证明；两个模型条件都未逐条核对。它的身份是 `CONJECTURE`，证据是来源报告加 Astra 的机器证明。

**模型条件的核对进展**（同日追加）【来源】：
- Cohen–Coquand–Huber–Mörtberg（cubical type theory）：单价性在 cubical set 模型中成立，语义在**构造性元理论**中给出。
- Coquand–Huber–Mörtberg，*On Higher Inductive Types in Cubical Type Theory*（LICS 2018）：在构造性元理论里，用带适当结构的预层拓扑斯给出圆、球面、环面、纬悬、（命题）截断与推出的语义，宇宙对这些类型构造封闭。
- Swan–Uemura，*On Church's thesis in cubical assemblies*（2019）指出一个机制：Markov 原则对应的类型被常值预层函子保持，所以它在这类预层模型中是否成立，归结为元理论本身。据此，在不含 Markov 原则的元理论里建 cubical set 模型，Markov 原则在模型中不成立——这正是 Coquand–Mannaa–Ruch 脚注 3 的论证。
- replacement：de Jong–Escardó（*On small types in univalent foundations*，LMCS 2023）与 Gylterud–Stenholm（*Univalent material set theory*，APAL 2025）都转述 Rijke 2017（join construction）的结果——在对推出封闭的单价宇宙中（并有函数外延性），“小类型到局部小类型的映射，其像是小的”可以证明。agda-unimath 的 `replacement` 公设正是这一陈述（本会话读了该模块：`is-locally-small l1 B → is-small l1 (im f)`）。所以宇宙对推出封闭的 cubical set 模型也满足它。
- 覆盖情况：函数外延性、单价性、圆、推出、命题截断、replacement，有来源覆盖；n-截断一项，Coquand–Huber–Mörtberg 摘要列有“truncations”，正文所见是命题截断，一般的 n-截断可由推出与序列余极限构造（一般知识，本轮未逐条核）。
- 结论身份不变：仍是 `CONJECTURE`（独立性是元定理，本项目没有机器证明），但支持已从“两个条件未核”收窄为“只剩 n-截断一项停在一般知识层面”。

## 4. 它与用户圆环原意的对应【解释】

- **用户的原话**：两端“无论逼近到什么接近的程度，都无法再还原到M的状态。可是，可是，我们当初确实得到了M啊！”
- **对应的数学事实**：要把一个只知道“不是缺口”的点放回线段，必须找到它与缺口之间一个正的距离。这是一次无界的搜索：一直逼近下去，直到差别显现。Markov 原则说：若这次搜索不可能永远没有结果，它就会有结果。在 Astra 的形式里，复原的覆盖恰好需要这条原则，在可数选择下与它等价。
- **与 KC-000010 的对应**：用户说时间相关的悖论“往往结果就是以‘不可计算性/不可停机性’作为特征”。这里的困难字面上就是一条停机原则。
- **A 与 B 的位置**：
  - 不加 Markov 原则，HoTT 完成不了复原的覆盖（条件式独立性），而量子化的圆可以完成（C-42）：这是 A 向的形状。
  - 加上 Markov 原则来完成它，等于断言那次搜索会停下，却不给出停下的计算：这有 B 向（绕过 ASK、当作已完成）的味道。
  - 圆环恰好坐在 A 与 B 的交界上。
- **归因的收窄**：
  - 用户怀疑的是“稠密、无限可分”（KC-000003、KC-000019）。证据支持这个方向，但把它收窄到更准确的一面：困难出在“点由无尽逼近给出，所以点与点的相等不可判定”。
  - 只要点的相等可判定，复原就无需原则（C-42 的证明只用了有限情况分析）。有理数也是稠密的，但相等可判定：在有理点圆上，复原所需的那一步——由“x 不是缺口 −1”求出参数 t，使 (1 + x)·t = y——不用任何原则就成立（【证明】C-43）。在实数上，同一步正是“不等于推出隔开”，要付 Markov 的代价（C-319、C-322）。所以决定性的不是稠密本身，而是相等不可判定。C-43 只证了这一步，没有证整个有理点圆的复原是双射。
  - 这不是 HoTT 独有的：一个宇宙的 MLTT 里就有同样的独立性。用户的判据【原话，KC-000015】是“它在HoTT中也存在具体的现象、表现”，所以共有不排除它。
- **对 CN-018 的影响**：CN-018 在 2026-09-25 的修订中撤回了“用户的稠密性怀疑在这里是对的”，改为“定位了一个构造性实分析中的条件性覆盖边界”。本笔记不恢复那句无条件的话，而是给出更精确的现行表述：
  - 在点集圆上，用户的怀疑指向了一处真实、可定位的困难：点由无尽逼近给出时，Astra 固定复原映射的覆盖等价于 Markov 这条停机原则（可数选择下）；
  - HoTT 本身既证不了也驳不倒它（条件式，§3）；
  - 换成离散的点，困难消失（C-42）。
