## 0. 重建与对齐检查

**重建**：开工先读总索引全文（索引与 001–005），再用 Read 重读《最高指示-Claude版》全文。因为本题要评价研究方向、并涉及用户的悖论观，按规则全文重读了《核心认知.md》（1–441 行，至 EOF）与扩展认知全部九片（索引与 001–009）。

**对齐检查**（《最高指示-Claude版》§6；针对本笔记 §5 提出的新单元 A7）：
1. **收益与取舍**：单元是书式 HoTT 与 Cubical Agda 的单价宇宙，观察尺度是“对一切维数 n 统一写出的结构定义”。单价性替使用者省掉的是：逐个证明构造尊重同构的义务，因为等价就是相等，运输白送。它添上的是：“相同”永远是结构（有证据、证据之间还有证据，层层不止），宇宙不是集合（C-63 (a)）。它不再携带的是：作为事实的相同，即唯一恒等证明（UIP）。
2. **现实解释**：它模仿“按指定方式对齐之后才算相同”的活动，像木匠粘合多面体时不但要求边相接，还要记下是怎样对上的，以及两种对法之间又怎样对上。谁宣布完成：内核一次接受一个对所有 n 成立的定义。解释在“面之面相合”这一句贴不上：现实里这是事实，HoTT 里是一条路径，它还要与上一层的路径相容。
3. **种子句**：理论为了让“等价即相等、构造对等价的不变性白送”（E），把“面之面相合是事实”（T）改成“相合是路径，路径之间还要路径，无穷多层”（T′）；若做“对所有 n 统一写出点、线、三角、四面体……的粘合规则”（P，即理论内部的族 F : ℕ → U），预计完成标准（内核接受一个统一定义）会变：事实层与外部程序都做得到，理论内部每写一层都要为下一层准备相干，出现无穷后退。
4. **邻近对照**：半单纯**集合**（面之面相合是命题）在 HoTT 中可以统一定义；每个外部固定的 n 也可以（C-62）。差别只在一项依赖：下一层是否依赖上一层所用的相同之证（C-63 (b)(c)）。
5. **注意转移**：最先跃入的熟悉答案是“这是已知的开放问题，2LTT、dTT 早有扩展，属于表达力边界，不是悖论”。我把注意移到两处：所有已知修复加回的是同一样东西（作为事实的相同）；过程的形状与芝诺相同（每一有限步都做得到，整体写不完）。下一个具体动作：机器检验有限层与前提敏感性，回源核对开放问题的原话。

**给非专业读者**：HoTT 好用，是因为它规定“能对上的东西就是同一个”，于是你永远不必检查自己的构造是否尊重这种对应。代价是：在 HoTT 里，“相同”从来不只是一个事实，而总是一种具体的对法，而两种对法本身又可以有不同的对法，一直往上。现在请写出用三角形、四面体以及更高维的“单形”粘出形状的一般规则：小孩也能说“按面粘，让面的面也对上”。在 HoTT 里，“对上”必须是指定的对法，它还要和上一层的对法相容，上一层又要和再上一层相容……至今没有人写完这条规则，2015 年的一次非正式调查中多数研究者认为写不完。已知的每一种补救，都是把“作为事实的相同”加了回来，而那恰好是 HoTT 为了好用而放弃的东西。

## 3. Terra 的路子对不对

### 3.1 对的部分

1. **关口找对了。**“发生过什么”与“最后是否等价”的分离，正是 HoTT 把相同做成路径的后果（C-39、C-49、C-55、C-59 都落在这里）。
2. **“不可兼得”比“函数不存在”更锋利。**这是真正的进步：候选必须是一次被迫的二选一，不能只是一个缺失的函数。
3. **第二种结局是方向 B 的种子。**Terra 在 `015` §8.2 写下“理论侧错误地宣布完成……‘净效果相同’被误当成‘过程没有发生’”。这一支后来没有被追（§4 R2）。
4. **防止稻草人接口。**“纯 `Code → Token` 双成功”若被当成 HoTT 的失败就太可笑了；Terra 把这类说法挡在门外，是对的。
5. **OAuth 的洞见属实。**一次性不是字符串本身不可复制，而是授权服务器记得它已被用过。由此可知：对经典信息而言，“变量可以用两次”并不是非现实的抽象。

### 3.2 四处结构性问题

**问题一：结案判据用芝诺一校准就失效。**MCS-4 的“H/D 成功即关闭”，实际上把 015 §4.2 已经承认“不是 KC-000047 条件”的“HoTT 内无正当替代”，重新变成了否决权。拿用户自己的参照来校准：
- 芝诺：同一任务“从 A 走到 B”，在同一个实数理论里，连续运动 x(t) = t 在 t = 1 时到达 B。H 胜，按 MCS-4，芝诺关闭为“减半描述是个坏接口”。
- 罗素：同一任务“按性质形成集合”，ZFC 的分离公理完成一切合法的形成，并正确拒绝 S。H 胜，按 MCS-4，罗素关闭为“已知建模取舍”。

一个会把芝诺、罗素都筛掉的筛子，不可能是找“像芝诺悖论、罗素悖论、圆环悖论一样精彩的HoTT引发的悖论”（KC-000015）的筛子。按 KC-000047，退回抽象之后任务就能完成，这正是“站在反证法的视角中，我们设定错误的那个前提，就是理论设计者当初做的非现实抽象”的回溯。H 的成功是**归因证据**，不是消解。（我在 014 T-034 用同一个校准反驳过“规则强迫”门槛，Terra 在 015 §4.3 接受了；同一个理由对 MCS-4 同样成立。）

**问题二：靶点从 HoTT 自己的抽象漂到了一切数学共有的规则。**T2 的靶是 `duplicate : A → A × A`，即笛卡儿上下文的收缩，这是集合论、一切直觉主义与经典数学共有的；T3（不可克隆）瞄的仍是它。KC-000047 问的是“HoTT理论为了理论经济性……做出的非现实抽象”，KC-000048 要求“紧紧瞄准”该理论的可疑前提。共享机制可以有 HoTT 实例（KC-000015 不排斥），但那样找到的是“笛卡儿数学的悖论”，答案早在 1987 年的线性逻辑里。

**问题三：现实侧选成了软件协议，也就是程序本身。**FHIR 与 OAuth 都是人设计的离散状态机，是 KC-000011 所说“程序（顺序、分之、循环）”那一侧。HoTT 装得下程序，所以“HoTT 能否模仿这台状态机”的答案在开题前就是“能”。C-61 进一步显示，胜出的模型连单价性都不需要。

**问题四：Q1 被默认裁定了。**每一次结案都预设“时间作为数据活着 = 候选被消解”，这正是用户尚未裁定的 Q1（014 §12）。若用户按 KC-000011 裁定（“并不是Think in HoTT的标的中不能存在一个时间变量，而是Think in HoTT的思考过程、结果并不想时间、时序参与到其中”），那么 T1、T2 不是两个失败的候选，而是两个新的实例：历史、消耗这类带时间的条件，只能活在 HoTT 的程序那一部分，从不活在它的恒等那一部分。

### 3.3 对 T3（未知量子态不可克隆）的预测

【解释，预测】按 Terra 自己的判据，T3 会第三次以同一机制结案：
- P 支是“把量子态写成某类型的值再用 `duplicate`”，与“纯 `Code → Token`”同为稻草人接口；
- H 支是“显式的世界状态加线性算子”，不可克隆是线性代数的定理，在任何类型论里都证得出；
- 判词会是 `KNOWN_RESOURCE_SENSITIVE_BOUNDARY / NOT_A_PARADOX`，并且已知（线性逻辑、QTT、量子编程语言的线性类型）。

按《最高指示-Claude版》§4，“连续两次只得到同一个机制”应当换理论层或现实域。Terra 换的是现实域（审计 → OAuth → 量子），被检验的理论层始终是“普通数据与状态”。所以我不建议把 T3 当作下一步；若要做，应先按 §3.2 修正判据与靶点。

### 3.4 我自己的更正（先查自己）

1. **我的 Q1 读法要收窄。**Terra 015 §4.4 说得对：只要 HoTT 内部的程序实际读取、计算 trace，时间就参与了 HoTT 内部的计算。所以 014 的“时间只能作为数据活着”应改写为：时间只参与 HoTT 的程序那一部分，不参与它特有的恒等那一部分（路径、单价性、运输）。结论不变，但界线要写清。
2. **A6 这条线的 HoTT 特有性本来就弱。**任何带恒等类型的内涵类型论都证得出 `p · p⁻¹ = refl`，任何函数都尊重它，所以“函数数不出往返”不是 HoTT 独有的。HoTT 特有的只是邀请：单价性让宇宙中的路径就是等价，Book 第 2 章把路径读作运动，HPT 把补丁写成路径。这一点 Terra 009 的 T0/T1/T2 分层早已点出，这里照实承认。它也说明，应当把探索移到 HoTT 特有性毫无争议的地方（§5）。

## 5. 推荐的主线：A7 无穷相干

### 5.1 候选卡

- **理论位置 T**：书式 HoTT 与 Cubical Agda 的单价宇宙 U；恒等是证明相关的；单价性推出 U 不是集合（C-63 (a)）；语言中没有严格或外层的相等。
- **收益 E**：不变性白送，同构的结构相等（HoTT Book 导言与 §9.8 结构同一原理，【来源】不引原句）。
- **候选任务 X₇**：输入是半单纯粘合的组合规则（点、边、三角……，面映射满足单纯恒等式）；允许的操作是在理论内定义类型与族；观察是理论内部是否有一个族 F : ℕ → U，使 F(n) 是 n 截断半单纯类型的类型；完成标准是内核接受这一个统一定义。
- **解释桥（现实侧）**：两种现实对照都完成同一任务。
  - 事实层的数学：半单纯集合作为 Δ₊ 上的预层，一个定义管所有 n；面之复合相等是事实。【来源】半单纯与半立方**集合**的统一索引式定义已在 Coq 中完整形式化（Herbelin、Ramachandra，MSCS 2025）。
  - 真实程序：一个外部生成器对每个具体的 n 打印第 n 层（C-62），对每个 n 都运行并停机。
- **敏感过程 P**：升一维。第 n+1 层要写出 n+1 维单形的边界类型，边界的良构依赖第 n 层的面恒等式；对变量 n，这些恒等式在理论内部只作为路径成立，而路径的相干又是第 n+2 层的要求，如此不止。
- **正控制（保留条件时应当成功）**：集合层（UIP）统一定义成功；每个外部固定的 n 成功（C-62）；在加回事实式相同的理论中成功（2LTT、HTS、逻辑增强类型论、dTT，【来源】）。
- **最强反解释**：“这只是理论内部的表达力缺口；HoTT 的语义（∞-topos）里有半单纯对象；HoTT 从未声称能内化自己的元理论。”回应见 §5.5。
- **证据等级**：现象为【来源】（开放问题，2012/13 年起；2015 年非正式调查；2025 年仍称“无穷后退”）；有限层为【证明】C-62；前提敏感性为【证明】C-63；“理论内部统一定义不可能”为【猜想】（未证）。

### 5.2 与芝诺逐项对照

| | 芝诺（用户读法） | A7 |
|---|---|---|
| 理论为何好用 | 运动放进连续数轴，用极限计算 | 相同即结构，不变性白送 |
| 被改的现实条件 | 运动与时空离散 → 无限可分 | 相同是事实 → 相同有无穷多层 |
| 专门碰它的过程 | 每次走剩下的一半 | 每升一维，都要为上一层的相同之证补相干 |
| 有限步 | 每一次减半都做得到 | 每一个有限层都写得出（C-62） |
| 整体 | 无穷多步，逐步描述里永远没走完 | 统一的 F : ℕ → U 至今写不出，多数研究者认为写不出 |

### 5.3 机器证据（本会话）

- **C-62**：外部生成器 `gen_sst.py` 对 n = 0..5 打印 n 截断半单纯类型的类型（第 m 层 2^{m+1} − 2 个面参数：0、2、6、14、30、62），Cubical Agda 逐层接受，每层有平凡居民；负控制（面 x013 取错边 x12）被拒，`x2 != x3 of type A0`。
- **C-63**：(a) `ua notEquiv ≠ refl`，宇宙不是集合；(b) 集合之上，沿任意两条证明的搬运相等（上一层分不出下一层用的是哪条证明）；(c) 宇宙之上，沿 `ua notEquiv` 与沿 `refl` 搬运 `true` 结果不同。负控制：`refl` 不能给出 `transport (ua notEquiv) true ≡ true`，被拒，`false != true`。
- 【解释】C-62 是芝诺式结构中“每一有限步都做得到”的一半；C-63 指出后退的燃料：在集合层相干走一步就停，在宇宙中不停；而单价性让宇宙不能是集合。

### 5.4 归因（候选前提、竞争归因、区分证据、我的判断）

**候选前提**：
- P-U（单价性）：宇宙中的相同就是等价，于是 U 不是集合，没有全局 UIP；
- P-I（内涵恒等、语言中没有严格相等）：与不带 K 的 MLTT 共有；
- P-F（一切类型都是纤维式的、同伦不变的，没有非纤维类型）：HTS、2LTT 正是加入非纤维层；
- P-C（统一性要求：定义必须在理论内部，F : ℕ → U）：任务自身的条件；
- 现实侧前提：面之复合的相合是事实（严格恒等式）。

**竞争归因与区分证据**：
1. “病因是 P-I，与普通 MLTT 共有，不是 HoTT 的。”区分：不带 K 的 MLTT 可以一致地加上 K，于是一切类型都是集合，后退停止；HoTT 不能加 K，因为单价性推出 U 不是集合（C-63 (a)）。所以 HoTT 特有的是：P-U **关掉了**这条退路。【证明】C-63 +【解释】。
2. “病因是 P-F；2LTT 不动单价性（内层仍单价），只加外层严格相等就解决了。”这对，而且支持更精确的说法：非现实的前提不是单价性本身，而是“理论内部只有一种相同，而且它是结构”（相同的一元论）。2LTT、HTS、dTT、逻辑增强类型论、Riehl–Shulman 的形状与 topes，都另加了一种事实式的相同。【来源】+【解释】。
3. “病因是 P-C，统一性要求太强，每个 n 都行。”回应：统一定义正是“定义一个概念”的意思，也就是 KC-000031 的“覆盖”；芝诺的每一次减半也都行。
4. “没有前提错了，只是还缺一个好点子。”区分证据：书式 HoTT 中的一个定义会推翻本候选；一个不可能性证明会坐实它。目前两者都没有；2015 年多数研究者站在后者一边（Buchholtz 2019）。

**我的判断**【解释，条件式】：咬人的是“理论内部只有结构式的相同”，单价性让它不可退出；它正是 HoTT 为经济性（不变性白送）做的抽象；无穷后退是它的非现实后果；每一种修复都加回了事实式的相同，这就是反证法的回溯。条件：(1) 开放问题保持开放或得到否定答案；(2) 用户接受“事实层的数学／外部程序”作为现实侧。

### 5.6 同一前提的自指实例 A7′：HoTT 吃掉自己

【来源】Kraus（*Internal ∞-categorical models of dependent type theory: towards 2LTT eating HoTT*，2021）摘要：在 UIP 成立的类型论中，“类型论在类型论中”运作良好；在 HoTT 中，它能否“吃掉自己”、充当自己的解释器，是长期开放问题，根本困难似乎是没有 UIP 时范畴不足以刻画类型论。同文例 6：HoTT 中宇宙不是集合，标准模型不是集合式 CwF；作者写道，一种可能的看法是，“与许多其他编程语言不同，HoTT（用这种方法）不能充当它自己的解释器”。Buchholtz 2019 第 7 章摘要把“在单价基础中发展 HoTT 自身元理论”与半单纯类型这类无穷相干层级并列讨论。

【解释】这正对着 KC-000026（“HoTT难道可以越过对其自身的自指吗？我不相信。”）与 KC-000027（“将自己对齐到了程序上，但是如此以来，程序的问题，也就成了它的问题”）：真实的编程语言可以写出自解释器，HoTT 恰恰在自解释这一步卡住，而卡住它的前提与 A7 相同（宇宙不是集合）。KC-000028 所说“持续增益的自馈结构”，在这里有一个具体的样子：每一层自我描述都要求更上一层的相干。

【待核】Codex／Astra 的 R 系列（C-223–C-249）已机器覆盖群胚截断的语法（C-223–C-226）、2LTT 的替换推出内层 UIP（C-227–C-232）、内部分类子不可能性（C-233–C-238）等，判为“受限接口完成来源任务，故仍是 defense/qualification boundary”（`MEMORY/002`）。我只读了矩阵行，没有读完整报告。按 §3.2 的校准，截断到群胚层是换了任务（截断语法对全层自解释），是否“完成来源任务”取决于来源任务是什么，需要回原报告核对。另：Session-C 父范围覆盖表中 S07“内部模型、反射与无限相干性”与 E14“内部模型与半单纯/有向扩展”均为 `UNREVIEWED / UNASSIGNED`（`第三轮机器统观/Session-C/父范围与覆盖/002` 第 53、69 行）。

### 5.7 时间在 A7 里住在哪里

【解释】对每个具体的 n，面恒等式由计算定下：类型检查器把项算到正规形，两边相同（定义性相等）；外部生成器就是一步一步地做这件事。对变量 n，计算卡在 n 上，同样的恒等式只能用证明给出（命题相等），而在 HoTT 中证明是结构，必须被后面的层追踪。所以：程序（在时间中对具体 n 逐个运行）用计算定下的东西，无时间的逻辑（对所有 n 统一）只能用结构补上，而结构又要求结构。这与 KC-000011 的程序—逻辑对照，以及 KC-000016 的“集合是有构造过程的”相接：构造过程在程序里逐层完成，在 HoTT 的统一定义里永远差下一层。

## 6. 为什么 R3 与 Terra 的关口是同一个前提的两面

【解释】HoTT 的前提是“相同即结构”。
- **下面一面**：对取值于集合的观察者，结构不可见（群胚律让 `p · p⁻¹` 与 `refl` 相连），于是“做过什么”数不出来。这是 A6、T1 所在的一面。
- **上面一面**：对在宇宙之上统一进行的构造，结构必须一层不落地带着走，每一层的“怎样相同”都要与下一层相容，于是写不完。这是 A7 所在的一面。

一句话：HoTT 把“相同”做得足够丰富，看起来像一个过程；但对下面的观察者，它不够丰富，承载不了历史；对上面的构造，它又太丰富，有限地写不完。【猜想】这一统一只是解释框架，不是定理。
