## 1. 猜想

### 1.1 忠实复述（CN-046 §5）

为了在理论内部说“永不停机”，类型论要把“一直在跑”做成一次交出的对象 `never`；按 KC-000018，这也是一种一次交出。区别在于 `never` 能由它的每个有限阶段完全刻画（C-59 (c)：`d ≡ never` 当且仅当对一切燃料 `runFor n d ≡ nothing`），而宇宙的“相同已落定”没有任何有限阶段能交出。【猜想】一次交出的对象若能被有限阶段完全刻画，就只是记账上的方便；若任何有限阶段都给不出它，就是“绕过 ASK”。

### 1.2 好在哪【判断】

它把用户对“一次交出”的批评（KC-000018：以静态的关系刻画一切）用到了我们自己的工具上。罗素线正是用 `never` 来说“永不停机”的；审计者一定会反问：你们批评一次交出，自己却靠一次交出的对象立论。这一问必须回答。

### 1.3 问题在哪【判断】

1. **两边比的不是同一种东西。** 左边说“对象 `never` 被有限阶段刻画”，右边说“性质‘相同已落定’不被任何有限阶段交出”。对齐之后：
   - `never` 的“已停机”同样没有任何有限阶段能交出；
   - 宇宙也有自然的有限阶段，即它的逐层截断 ∥U∥ₙ（第 n 个阶段在第 n 层落定）。问题变成“宇宙是否由这些阶段完全刻画”，也就是它是否等于自己 Postnikov 塔的极限。
2. **在标准模型里，答案是“是”。** 在单纯集合模型里，每个空间都是自己 Postnikov 塔的极限，宇宙的解释也不例外。按猜想的判据，宇宙在那里和 `never` 站在同一边。
3. **只有换成“能否在理论内部证明”，才重新分得开，但分出来的不专属于宇宙。**
   - 【来源】HoTT Book §8.8：Whitehead 原理（∞-连通的映射都是等价）在 HoTT 中不可证，有模型（非超完备的 ∞-topos）使它失败；书中把它看作一条与排中律、选择公理同类的“classicality axiom”。截断版本（n-型之间）可证（定理 8.8.3）；书中另说，对不是任何有限 n 的 n-型的类型，这个归纳无从起步。
   - 【判断】“一切类型都等于自己 Postnikov 塔的极限”蕴含 Whitehead 原理：∞-连通的映射在每个截断上都是等价，取极限即得等价。所以前者在 HoTT 中同样不可证。对宇宙本身能否证明，我没有查到结论。
   - 于是精确化的猜想说的是：`never` 可在内部证明由有限阶段决定（C-59 类型的结果），而一般的非截断类型不能。这条线与“超完备性”这一已知的基础分界重合，很有意思；但它涵盖一切非截断类型（例如例 8.8.6 的乘积类型，见第 3 节），不专属于宇宙；而且它是元层的独立性问题，不是一次内核运行能回答的。

### 1.4 两种更准的说法

- **(a) 用这条线自己的尺子（可机器检查）【建议】。** 把追问程序 Q 放到 `never` 所在的类型 `Delay ℕ` 上。`Delay ℕ` 是集合（预计可证：把 C-59 (c) 的 `runsNothingDiverges` 推广为“一切燃料上 `runFor` 相同则路径相等”，再用 HoTT Book 定理 7.2.2 一类的论证；仓库的 C-21 用过这个定理），所以 Q 第一问就停，与 ℕ、Bool 相同（C-79）。于是罗素线反对的不是“一次交出”本身，而是“一次交出一个相同永远落不定的东西”。这个正控制能直接回答审计者的反问。
- **(b) 扩展认知 003 已有现成的区分。** 那里写道：不停持续输出的过程可能正好完成了“持续服务”的任务，已给出一串输出的过程也可能尚未满足“需要最终稳定答案”的任务。【判断】`never` 完成的是前一种：它的完成标准就是“每个有限阶段都还没有结果”，每个阶段都兑现了这个标准。宇宙被形成规则交出时，是否被要求满足后一种（相同必须落定），正是第二道门（存在要求落定）。所以这个猜想若要成立，最后取决于第二道门，它不是独立于两道门的新判据。

另有一层【解释】：KC-000011 说问题不在于思考的对象里有没有时间变量，而在于思考过程和结果是否让时间参与。`Delay` 把步子放进了类型：不交出收敛的证据，就拿不出值。这是 HoTT 自己的、尊重 ASK 的接口（KC-000027：HoTT 把自己对齐到了程序上）。宇宙经形成规则交出时，没有经过任何这样的接口。

## 2. “最值得做”的宇宙塔版本

### 2.1 忠实复述（CN-046 §7 第 2 条；交接说明 W7 (a)）

不用高阶归纳类型，把 Q 写在宇宙塔上：第 k 问改问第 k 个宇宙 `Type (lvl k)` 是否在 h-层 2+k 落定；判定器的类型在 Agda 的 Setω；每一问都由 KS 定理 5.9 答“否”，证明对任何判定器都等于 `never`。交接说明已写明两项风险：判定器住在 Setω，书式 HoTT 里只有元层模式；主语变成宇宙塔，与 KC-000050 所说“论域元素”的对应要重新论证。

### 2.2 评价【判断】

1. **主语换了。** 宇宙塔不是一个论域元素，按 KC-000050 的字面它不能成为成功主张。云端会话自己也承认这一点（社区稿 02 第 8 节）。
2. **更要紧：永不停是提问方式造出来的。** 塔上的第 k 问恰好问在 KS 定理 5.9 能答“否”的那一层（h-层 2+k）。按 KS 宇宙塔包 `CLAIM.md` 第 4 节转述的 KS §6：不用高阶归纳类型时，“第 n 个宇宙在 h-层 n+3 落定”不可反驳（KS 原文自称没有已发表的证明，【来源转述】）。所以塔上的每一问，都恰好问在那一层宇宙可能落定的层级之下。换一种同样自然的问法（每层宇宙问在 h-层 3+k），判定器就造不出来。批评者可以说：你们挑了一个注定答“否”的对角问法。单个宇宙上的 Q 没有这个弱点：它对同一个对象逐层问下去。
3. **“写进内核”只对 Agda 成立。** 判定器住在 Setω；书式 HoTT 里只有对数字 n 的元层模式（KS 包 `CLAIM.md` 第 4 节）。
4. **附带观察【猜想】。** 不用高阶归纳类型时，单个宇宙的追问多半连判定器都造不出来：到 h-层 n+3，“是”“否”都证不出（同样依赖 KS §6 的相容性论断）。现实中的追问者（在理论里搜证明）会卡在那一问上，而不是一路往上问。这是另一种形状的不停机。但它有落进“一般的独立性／哥德尔”的风险（《最高指示-Claude版》§4 触发句），扩展认知 003 也提醒“未知不能自动被归为非法”。所以我不建议追。

## 3. 更有判别力的下一步：HoTT Book 例 8.8.6 的邻近对照

### 3.1 来源（HoTT Book §8.8，转述）

- 例 8.8.6：设有一族类型 B(n)，每个 B(n) 都有一个不等于平凡的 n 维环（例如 B(n) = Sⁿ）。乘积 C = ∏ₙ B(n) 在每个维数都有非平凡的环，所以 C 对任何 m 都不是 m-型。
- 书中接着说：预计宇宙本身也不是任何 n-型，理由是宇宙含有一切 Sⁿ；但书写成时还没有做出来。仓库的 C-75 做的正是这件事（用 Eilenberg–MacLane 空间与局部—整体环路原理）。

### 3.2 预测与可行性

- 【判断，未机器检查】取 C-75 包里的 `K n = EM ℤAbGroup (suc n)`，令 C′ = (n : ℕ) → K n。按例 8.8.6 的论证，C′ 对任何 m 都不在第 m 层落定；由 C-77（停机当且仅当有某个有限层），对任何判定器，Q 在 C′ 上等于 `never`。
- 所需引理在 `UniverseHasNoLevel.agda` 里都已有：`Ω^Πpt`（环路空间与乘积交换）、`K`、`sec`、`secNontrivial`、`hLevelΩ^`。`secNontrivial` 说的是整条截面非平凡，要换成在一点处非平凡，还需一步连通性论证。估计几十行，要走 F-011 才能交付。

### 3.3 为什么它更有判别力【判断】

- 它把宇宙从“被追问的对象”位置拿掉，只保留高阶归纳类型与单价性（后者用在 Eilenberg–MacLane 空间的环路计算里）。这正是《最高指示-Claude版》§6 第 4 项要的邻近对照：一个很像、但不依赖“宇宙作为被追问对象”的任务。
- 我预期 Q 在 C′ 上也永不停。若成立，罗素线要改两句话：
  1. “永不停”不是宇宙独有的；
  2. 宇宙在罗素线上的特殊之处要改说成两件事：它是理论不能拒绝的元素（KC-000050）；它是把“无界高度”装进一个对象的工具（C′ 的构造要用到类型族 ℕ → U；在这类类型论里，按 ℕ 递归定义类型族要用到宇宙）。
- 对归因（CN-047）的影响：B 向下“一次交出”的不只是宇宙的形成规则。Π 的形成同样一次交出了一个相同永远落不定的整体。罗素的幽灵可能从“宇宙”扩大到“一切一次交出的、高度无界的整体”，其中宇宙是不可回避的那一个。这是更强也更险的说法，是否合用户原意要由用户判断。
- 若预测落空（Q 在 C′ 上会停），那就说明宇宙在不停机上有别的作用，罗素线的宇宙专属性反而得到加强。两种结果都会改变某个判词，所以这一步有判别力。
- 仓库里此前只把 S² 当作“不要把‘每个成员’误读成宇宙的一切成员”的提醒提过（`universe-questioning/REVISIONS.md`、证据索引 §19 补注、CN-039 §5 修订），没有用例 8.8.6 做过邻近对照。
