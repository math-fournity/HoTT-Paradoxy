# CN-071 极限的“到了”在 ZFC 里就是“永远不停”：到达句逐个等价于永不停机句

> 本机会话 d58e0c0d（Opus 5.5），2026-10-09，目标包 CG-007 的 W5。证明包 `HoTT/formal/claude-cg001/godel-q-zfc-runner-arrival/`（CG001-C-117、C-118），CG-001 证据索引 §33，`形式化追踪/01-有哥德尔路线/03-跑者的到达句.md`。身份标注：【原话】【证明】【判断】。

## 1. 一句话

【证明】哥德尔–芝诺跑者的“到达”，按通常的数学写成“剩余距离趋于 0”（ε–N）。把它写进 𝗭𝗙𝗖 的语言之后，𝗭𝗙𝗖 对每个跑者都证明：这句话恰好等价于“驱动它的过程永不停机”（C-118 (1)）。到达句不是永不停机句本身，可两者在 𝗭𝗙𝗖 里可证地是一回事。

## 2. 它说明什么

【原话】研究发起人（十三条 [3]，KC-000065）：“芝诺悖论，从第一天开始，就是一个可计算性问题，因为每次走剩下的一半，永远走不完，这是结结实实的计算步骤、过程。”

【判断】这一句在跑者族上有了一个精确的形式版本。

- 极限理论交付的“到了”，是一句关于极限的话。
- 把它写进 𝗭𝗙𝗖 的语言，𝗭𝗙𝗖 自己就证明它等价于“这个过程在全部将来都不停”，一句 Π1 的话。
- 所以“完成”在这里不是在某一刻发生的事，而是对全部将来的一个断言。
- 𝗭𝗙𝗖 能逐刻确认“还没停”（C-99），却证明不了这类“全部将来”的断言的一般情形（C-100、C-104）。
- 这就是 C-101 的跑者现在不带参数地说的事：有一个跑者确实到了，𝗭𝗙𝗖 证明不了它到了。

## 3. 证明里值得记下的两点

- **分析的内容在桥上，不在 𝗭𝗙𝗖 里**。
  - 𝗭𝗙𝗖 里的等价只用到 ω 上两条序的事实：`N ≤ N`，`k < k + 1`。
  - 剩余距离为正、2⁻ᴷ → 0 这些分析事实，用在 Lean 元层：它们说明算术句 `arrF ⌜d⌝` 恰是“位置趋于 1”。
  - 【判断】一旦“剩余距离 ≤ 2⁻ᴷ”写成“已减半至少 K 次”，“到达”就只剩下“永远还在减半”。极限的全部重量都落在“永远”上。
- **旧的停机公式用不上**。
  - Foundation 的 `codeOfREPred` 用选择公理挑出，它在非标准模型里怎样表现无从推理。
  - 等价必须对一个与到达句同源的停机公式 ΦS 来证（负控制 `WrongArrivalOldPhi`）。
  - 这是一处形式化的细节，但它提醒：“𝗭𝗙𝗖 证明某句与永不停机等价”要说清是哪一句永不停机句。
