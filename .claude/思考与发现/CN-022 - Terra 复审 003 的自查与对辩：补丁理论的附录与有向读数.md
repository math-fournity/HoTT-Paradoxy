## 0. 对齐检查（《最高指示-Claude版》§6）

本轮进入了新的理论单元（补丁理论的最终设计；有向读数），先重读了《最高指示-Claude版》全文、核心认知全文、扩展认知 003、008、009，再写下面五项。

1. **收益与取舍**（对象：补丁理论的 HIT 表示，Book 式 HoTT + 单价性；尺度：上下文与补丁）：省掉了逐条验证补丁律与群胚律，模型自动是函子（原文 p.2、p.4）；添上了每个补丁都可逆，连通的上下文都被认同。
2. **现实解释**：一个用户改一个文件；系统应用编辑、打印文件、报告有没有改动、合并分叉。贴不上的那一句：“一次编辑是编辑前后两个状态相等的证明”。现实说前后不同；删除一行也无法撤销，除非保留被删的行。
3. **种子句**：理论为了“不变性与补丁律白送”（E），把“观察可以随变化而变”（T）改成了“一切观察必须尊重变化的结构”（T′）；若把变化写成这种结构，再问“变了吗”（P），理论内部的回答永远是“没变”（O）。
4. **邻近对照**：补丁本身就是全双射的语言（原文 §4、§5：整数加减、按行交换字符串）。那里对称性无害，不用细化上下文。差别只在一项依赖：真实操作是否可逆（原文 §7 也这样分）。
5. **注意转移**：最先跃入的熟悉答案是 003 的“已知建模取舍，作者用历史修好了”。我把注意移到两处：修复对上下文空间做了什么（附录：可缩）；作者自己把代价归给了哪条前提（§6.4、§8：对称性）。下一步：伪交换种子、有向版本、用户裁定。

**给非专业读者重讲**：同伦补丁理论把“改一下文件”写成“两个状态相等的证明”。这样做的好处是，各种编辑规律自动成立，不用一条条去验证。代价是每次编辑都必须能撤销，而且所有能到达的状态，在理论眼里都成了同一个状态。作者只好让每个状态随身带着自己的全部编辑历史，从历史里算出“现在的文件是什么”；理论自己的“相等”却一直说，编辑前后没有区别。

## 4. 这一轮看见的新东西

1. **补丁理论的最终设计就是 A1′ 在真实世界里最尖锐的样子**【来源 + 证明 + 解释】。作者经过机器检查的方案里，上下文空间是一个点，从空仓库出发的路径由终点历史唯一决定，路径不带任何额外信息；全部状态信息都在普通的数据（历史）里。HoTT 的路径结构在这里只剩“给补丁定类型、让补丁律自动成立”的作用。
2. **两层表述**〔2026-09-25 修订，见文首修订块第 1、2 条〕【证明 + 解释】：理论内部（全部非依赖观察）把改变前后的整体状态认同；区分只在理论之外存活——认同之前的索引数据，以及运行（定义性计算）。Cubical Agda 让第二层第一次可以直接检查：解释器真的算出 2；归一化优化器真的把绕路算成空补丁；两个优化器在理论内相等；而编辑前后的上下文、保留下来的绕路都不是定义性相等（两个负控制被拒）。补丁理论 2014 年缺的操作语义，今天有了。
3. **归因：病因是“函子性白送”这笔经济账，不是恒等的可逆**〔2026-09-25 降为候选归因，见文首修订块第 3 条〕【解释，条件于立场 S】。
   - 补丁理论列为收益的函子性，与 C-32 的 `observablesAgree`、`noChangeDetector`，用的是同一条规则：函数对路径的作用。补丁律白送与编辑前后看不出区别，是同一件事的两面。
   - 区分证据：去掉可逆性（有向理论），强加的逆消失，读数冻结不消失（C-38 + GWB 推论 3.20）。所以可逆性只对“强加的逆”负责；“观察看不见变化”由三条前提合取负责：把变化写成理论自身的结构、一切函数自动尊重它、普通数值的结构平凡。
   - 去掉“普通数值的结构平凡”，即让读数自带结构（依赖族 C-25；有向时的非离散读数类型 C-36、C-37），读数就能变。代价是读数不再是普通数值。
   - 这比 CN-015 的 P1（“=”同时模仿共指与运动）更一般：它把有向理论也包括进来了。P1 是这条一般规律在无向情形下的样子。
4. **有向读数的目标分类**【证明 + 来源】：离散或反对称的目标不能先升后降；互逆对塌缩的目标要不可逆回路（S 中 Bool → Unit → Bool）；余离散目标可逆回路即可。CN-019 原来的直觉“有向出路只买回了钟”，在正确的条件下部分成立：有向出路本身不解冻普通数值读数，解冻要靠读数类型自带箭头；自带有序箭头的读数（如 𝕀）只能单调，这才是“钟”；要先升后降，读数类型得有反向的箭头。
