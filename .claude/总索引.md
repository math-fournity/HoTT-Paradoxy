# Claude 工作总索引

本索引是 Claude 在本仓库的全部工作、思考与发现的唯一入口。目标包、交接、中继、探索工作台、思考与发现笔记、证明包、运行与命题，都从这里找到。

本索引只做路由与登记，不替代底层证据：
- 用户原意的权威仍是 `核心认知.md`；
- 数学结论的权威是各证明包的 `CLAIM.md` 与运行收据；
- Claude 的操作指令是 `最高指示-Claude版.md`。

**怎么用**
- 第一次接手：按下表顺序读全文，依次是 001 规则、002 现状、003 和 004 两份登记、005 日志。
- 每个工作单元结束：按 001 §3 维护。002 原位更新，003 与 004 追加登记行，005 追加日志。
- 思考与发现不要只留在对话里：先落盘，再在这里登记。
