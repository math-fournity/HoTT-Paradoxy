# .claude：Claude 在本仓库的工作区

任何接手 Claude 这条工作线的 AI（Claude、Codex 或独立审计者），请先读 **[总索引](总索引.md)**：按其分片表读完索引与 001–005。它登记 Claude 的全部工作、思考与发现，并写明怎样使用、怎样维护。

| 目录或文件 | 内容 |
|---|---|
| `总索引.md`、`总索引/` | 唯一入口：规则、现状、工作与证据登记、思考与发现登记、工作日志 |
| `思考与发现/` | CN 编号的笔记正文 |
| `goals/` | goal-x 目标包（CG-NNN） |
| `handoff/` | 会话交接文档 |
| `relay/` | 交给研究 integrator 的补丁与草稿 |
| `explore/` | 单次会话的探索工作台 |
| `rules/` | Claude Code 自动加载的仓库规则 |
| `goal-x/` | goal-x 的开工闭包与提醒配置 |

项目宪法仍是根目录 `AGENTS.md`，用户原意的唯一权威仍是 `核心认知.md`。本目录不写研究 STATE、MEMORY、方向追踪、全景视野与核心认知。
