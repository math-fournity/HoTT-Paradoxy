# 工作流程：从选靶到一条短链

> 九步对应 CG-004 的完成门（G0 至 G7；S8 是收尾）。每步写输入、动作、产出、验收。方法的权威是《最高指示-Claude版》（§2 种子句、§3 发现态、§5 核证态、§6 对齐检查、§7 结论诚实）；本片只把它落到菲尔兹靶上。原则不变：先发现，后核证；有了现象，归因就不再等待。

## S0 开工（G0）

- **输入**：研究发起人对 D1、D2、D3 的答复，原话记入工作台。
- **动作**：
  1. 绑定 CG-004（goal-x resume），写恢复说明；
  2. 声明档位：做研究是 T2，交付数学结论时升 T3，过 F-011（根 `AGENTS.md`“任务路由”）；
  3. 用 Read 重读《最高指示-Claude版》，写 §6 的五项对齐检查和给非专业读者的 3 到 5 句重讲。
- **产出**：工作台 §0（选靶原话、档位、对齐检查）。
- **验收**：五项都有具体内容：收益、现实解释、种子句、邻近对照、注意转移。只复述原文不算。

## S1 来源闭包与核证卡（G1）

- **动作**：
  1. 找到主定理的精确陈述：模型类、假设、量词、观测量、误差界、时间窗或尺度窗；
  2. 定版本（arXiv 版本号或期刊卷页）；
  3. 查论文库 `AUDIT-INDEX.md` 里对应文本的转码审计状态，未审完的，关键句对照 arXiv 原文；
  4. 把背景文献分成三层：已核对原文、只读摘要、凭记忆待回源。
- **产出**：工作台 §1 原典表（原句、节号或页码、来源身份）与核证卡。
- **验收**：每条主张都能指到页或节；没核过的标“待回源”。
- **为什么先做**：CN-055 第 2.3 节的教训。对方的过程在定理的初值类里根本不存在，读一遍 §1.1 就能看出来。

## S2 种子句与 UR（G2）

- **动作**：
  1. 写种子句：理论为了 E，把 T 改成了 T′；若做 P，原任务的 O（或 Done）会变；
  2. 写 UR 候选句，外行版，一句话；
  3. 定方向：A 向（现实能完成，理论做不到）、B 向（现实做不完，理论宣布做完）或新方向；
  4. 交研究发起人一眼判定。
- **产出**：工作台 §2；研究发起人的判定原话。
- **验收**：去掉理论名字，种子句仍让人听懂；放回名字，能落到定理或规则上（《最高指示》§2）。
- **不算**：“某某有没有被保住”这类信息损失式的问题句（006 片第 2 条）。

## S3 过程、对照与教科书消解（G3）

- **动作**：
  1. **过程 P**：专门碰 T 的过程，例如格距一次次减半、把速度全部反向、数一族连成一片的曲线、按高度搜索有理点；
  2. **正控制**：保留原条件时任务能完成，例如有限格点上相互作用在、有限硬球倒放回到起点、孤立无对称的曲线计数是整数、函数域里能给出界；
  3. **邻近对照**：一个很像、但不依赖 T 的任务，例如二维、三维的 φ⁴，差在哪一项依赖；
  4. **教科书消解**：逐条写它做了什么：恢复了被改掉的条件，还是凭定义宣布（极限、截断、重整化、有效场论、弱收敛、分子混沌、“有效性是另一个问题”）。
- **产出**：工作台 §3；每条对照注明证据身份（来源或机器）。
- **验收**：《最高指示》§3.4 的四件事同时满足：X 确实需要 T；P 让 T 决定结果；O 是原任务看得见的；T′ 能在定理或规则里定位。还要回答：为什么一个与 T 无关的普通过程不会显出同样的困难。

## S4 机器骨架（G4，F-011）

- **动作**：挑出能在证明器里忠实表达的部分，各做成证明包：
  - `CLAIM.md` 写命题全文、量词与禁止外推，捕获之后不再改；
  - 至少一个负控制；
  - 捕获运行，精确重放；
  - 登记目标内索引。
- **主定理**：能形式化的形式化；不能的（ADC、Deng–Hani–Ma、Faltings 等）一律按【来源】转述。
- **产出**：至少三个证明包；一张身份表，列出每句话是机器证明、来源转述还是解释。
- **验收**：收据齐全，`verify_cg001_run.py --rerun` 通过；没有一句把来源写成“已证明”。
- **注意**：玩具和代数要写明是玩具、是骨架（006 片第 5 条）。

## S5 归因（G5）

- **动作**：按 KC-000049 写四件事：
  1. 候选前提：理论规则、可选假设、模型类、解释桥、现实侧前提；
  2. 竞争归因；
  3. 能区分它们的证据或对照；
  4. 我的判断及其身份。

  然后与研究发起人讨论。
- **产出**：工作台 §5；研究发起人的原话。
- **验收**：判断写成排序，不写成“唯一被告”（反证法只否定合取的整体）。

## S6 短链与一页稿（G6）

- **短链**：一条人能跟着走的短链：一个起初看似合理的取舍；一个专门碰它的过程；在同一任务下确实改变的观察；一个换题也消不掉的反解释检查（《最高指示》§5）。
- **产出**：
  - 新的 CN 笔记（人话版与技术版、与芝诺和圆环的对照、归因、判词、两项自检）；
  - 一页稿草稿，放在 `.claude/社区稿草稿/`，体例照 `docs/社区审计提交/03-HoTT的芝诺.md`，末尾列审计问题。
- **验收**：两项自检（《最高指示》§7）：精化有没有冒充原问；解释有没有加码。

## S7 登记、交审计与交付（G7）

- **动作**：
  1. 维护总索引 002–005 与目标内证据索引；
  2. 给共享 owner 的内容写进 relay（共享矩阵行草稿、方向与全景候选）；
  3. 审计请求经研究发起人转交；
  4. 提交与发布按授权（D9、D10）。
- **验收**：`verify_governance_shards.py` 为 PASS；执行完成、候选判词、外部审计状态三者分开报告。

## S8 收尾或换靶

- **结局**（《最高指示》§5 的五种）：撤回；降为表示边界；换一个更敏感的过程；保留为条件命题；进入证明义务。“在这个范围内没有结果”照实写，并写清范围。
- **收尾**：在对话里列完成门审计表，然后 `goalx.py close`。
- **下一靶**：按 001 片第 2 节的排序；连续两次得到同一机制时，换理论层或现实域（《最高指示》§4）。

## 工作循环与登记

- **循环**：恢复 → 定位 → 执行 → 反思（新事实是什么，有没有换题，下一步因此改变什么）→ `goalx.py checkpoint CG-004 --phase … --next … --note …` → 选下一步。
- **登记**：每个自然单元结束都按总索引 001 §3 维护：002 原位，003、004 追加，005 只追加。思考先落盘成 CN，再登记。
