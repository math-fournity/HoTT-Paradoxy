# 陷阱、验收与停止

## 1. 十五条陷阱

前四条来自 CN-055 的比较，其余来自第一阶段与《最高指示-Claude版》§0、§4。

1. **模板误用。** 把第一阶段给 HoTT 写的题目照搬过来，硬要“HoTT 联系”。第二阶段的靶是菲尔兹工作本身的理论。
2. **信息损失式的候选。** “某某有没有被保住”是一个研究问题，不是 UR。先问丢掉的是哪一项原任务不可缺的条件、为什么平常可以省，再问哪件本来简单的事因此做不到。
3. **在定理的假设之内找反例。** 已证定理不会在自己的假设里被推翻，这样的过程注定为空。要读的是理论的抽象带来的后果，不是定理的错误。开工先读主定理的假设（S1）。
4. **把来源当证明。** 主定理没有在本仓库形式化，就只能写【来源】。骨架有收据，不等于主定理有收据。
5. **把玩具当定理。** 标度指数的代数、Kac 环、自旋块和，都要在 `CLAIM.md` 与正文里写明是玩具或骨架。
6. **把“已知”当否决，或当发现。** 已知不否决（KC-000015）；新的只是读法、归因与证据的组织，要照实说。
7. **把未审的转码当原文。** 先查 `AUDIT-INDEX.md`，关键句对照原文。
8. **把研究发起人的物理立场当证据。** “时空是量子化的”在这一阶段是被检验的前提。四维 φ⁴ 这条线最多能说：如果时空无限可分、相互作用在点上，那么四维里最简单的相互作用不存在；反证法只否定合取的整体。
9. **推迟归因。** 有了现象就展开四件事（KC-000049），不说“以后再定”“那是下一个故事”。
10. **教科书消解的条件反射。** “有效场论早就解决了”“这只是典型性”“有限性和可实效性是两回事”：先写清它恢复了什么、凭什么宣布了什么，再谈消解（《最高指示》§4）。
11. **用结构冒充洞见。** 先写一句外行能复述的话，再造表。
12. **连续两次同一个机制。** 换理论层或现实域，不是换候选的名字。虚拟计数与 HoTT 同根，要写明它换的是什么、没换的是什么。
13. **因工具缺功能而停下。** 拆层、换证明器、换方法（仓库外记忆 `feedback-no-stopping-on-tool-limits`）；但下载要先征得同意。
14. **经 elan 代理调用 Lean。** 会自动下载工具链（2026-09-25 事件）。一律用绝对路径。
15. **`cd` 之后路径漂移。** 会话的主工作目录会跟着变；一律用绝对路径。

## 2. 一个靶算“做成”：八条（对标 `main` 分支的 HoTT 结果）

1. **UR 句**：研究发起人一眼判定为“不合理”，原话记录在案。
2. **“做不到”有依据**：定理（来源或本仓库机器证明），量词与范围照实写；只是方法现状时，照实降级。
3. **对照**：至少一个保留原条件时任务完成的正控制，一个邻近对照；每个都有来源或收据。
4. **教科书消解**：逐条分析它恢复了什么、宣布了什么。
5. **归因**：四件事写成，并与研究发起人讨论过。
6. **机器骨架**：每个机器命题的 F-011 收据齐全、精确重放；有一张身份表分清机器与来源。
7. **短链与一页稿**：一条人能跟着走的短链；一页稿末尾有审计问题。
8. **两项自检**：精化有没有冒充原问；解释有没有加码。

“做成”之后，算不算研究发起人要的悖论、是否像第一阶段那样判为“很可能已经找到了”，由研究发起人判定。执行完成、候选判词、外部审计状态三者分开报告。

## 3. 判词与停止

- **判词**：沿用第一阶段的五档：合格命中（条件式）、强候选、表示边界、驳倒、开放并附下一步。外加研究发起人的判定。
- **允许的结局**（《最高指示》§5）：撤回；降为表示边界；换一个更敏感的过程；保留为条件命题；进入证明义务。正确的拒绝不是 BUG。
- **换靶**：
  - 研究发起人判 UR 不成立；
  - 主定理的前提读下来使过程为空；
  - 撤回条件出现（004 片各节末）。

  换靶顺序按 001 片第 2 节，并在工作台记下原因。
- **不停的理由不算理由**：预算、上下文或时间用尽，写检查点后停，目标保持 ACTIVE，不算完成。

## 4. 压缩与恢复

压缩之后、换会话之后，先恢复再动手：

1. 若绑定了 CG-004：goal-x resume，按 `GOAL.md` 的闭包用 Read 重读，写恢复说明。
2. 未绑定：读 `.claude/总索引.md` 全文（索引加 001–005）与本指导全文。
3. 涉及研究发起人的原意、UR 判定或归因时：全文重读核心认知与扩展认知（《最高指示》§9）。
4. 从 STATE 的“下一步”或总索引 002 §4 继续；发现记录与实物冲突时，以实物为准，并在下一个检查点写明。
