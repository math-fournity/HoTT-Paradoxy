# 一页读懂：要做什么、到了哪里、怎样读

## 1. 要做什么

研究发起人的 Z 铁律（KC-000015）说，抽象本身就蕴含“否定现实中的某个前提”，所以理论的推演必然能够引发非现实性的悖论；这件事“我们不是非要通过考察HoTT才能够确认”。第一阶段在 HoTT 里找到了一个：“是不是同一个”永远确认不完（`main` 分支 README 第 4 节）。

第二阶段要做的，是在菲尔兹奖获奖工作所依赖的理论里，再找一个同样的 UR（KC-000054：“本来应该很简单的事情，甚至在X理论中，都做不到”），并按 HoTT 那一次的标准做成一条短链：

- 一句外行一眼能懂的 UR；
- 一个专门碰那个被改掉的前提的过程；
- “做不到”最好是定理；
- 保留原前提时任务能完成的对照；
- 对教科书回答的分析：它恢复了被改掉的条件，还是凭定义把它宣布回来；
- 和研究发起人一起讨论的归因；
- 机器检查过的骨架。

研究发起人原话里的目标是：“我们要找到，下一个像芝诺悖论一样的，我们说定义的那种`不合理`的理论BUG，就像我们在HoTT中完成的main分支上的内容那样。”

## 3. 与 HoTT 阶段的五点不同

1. **理论在外面。** HoTT 本身就是证明器的语言，每一步都能在理论里检查。菲尔兹的这些理论（量子场论、动理学、曲线计数、丢番图几何）离形式化很远，主定理多半只能按【来源】转述；机器检查的是骨架：对照、机制、玩具模型、极限对象。这是本阶段最大的短板，必须照实说，不能让机器收据替主定理背书。
2. **不要求 HoTT 联系。** 靶是菲尔兹工作本身的理论。“找不到 HoTT 消费者就不算问题”是读错了题（CN-055 第 2.1 节）。
3. **来源有转码审计状态。** 论文库 `/Users/aurolafly/Collected-Papers-of-Fields-Medalists` 的 MinerU 文本有的审完了，有的还在审。引用之前先看它的 `AUDIT-INDEX.md`，关键句对照 arXiv 或期刊原文（005 片第 5 节）。
4. **“做不到”尽量是定理。** HoTT 那一次站得住，是因为“永远不停”是定理，不是“还没人做出来”。四个靶在这一点上强弱不同（004 片）。
5. **“现实”一侧常落在物理上。** 相互作用存在、有限系统可逆，这些属于 UR 的前半句。研究发起人的物理立场（KC-000003、004：时空与运动是量子化的）在这里是被检验的前提，不是证据。反证法只能否定前提的合取（KC-000019）。
