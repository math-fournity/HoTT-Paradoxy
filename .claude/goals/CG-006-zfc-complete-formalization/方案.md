## 2. 关键设计决定

- **D-A 句子形状**【设计】：
  - Num_n(z) 是 Rayo 式的冯·诺依曼数公式：Num_0(z) := ∀w ¬(w ∈ z)；Num_{n+1}(z) := ∃y (Num_n(y) ∧ ∀w (w ∈ z ↔ (w ∈ y ∨ w = y)))。
  - Φ⁺(x) 是 `arithTrln` 下 `φH` 的翻译，一个固定的 ℒₛₑₜ 公式；Ψ⁺ 同理对应 `ψN`。
  - Halts(e) := ∃z (Num_{⌜e⌝}(z) ∧ Φ⁺(z))；Never(e) := ∀z (Num_{⌜e⌝}(z) → ¬Φ⁺(z))；NotYet(e,k) 用 Ψ⁺，同法构造。
  - 这样只有“数字”部分随 e 变化，不需要翻译函数本身可计算。
- **D-B Σ1/Δ0 完全**【设计】：
  - 先由 `rePred_weak_representation` 对 T = 𝗥₀（或任一已知可用的算术理论）得到 `𝗥₀ ⊢ φH/[↑e]`；
  - 再用 `arithInterp.of_provability` 得到 `𝗭𝗙𝗖 ⊢ (φH/[↑e])ᵗ`；
  - 最后用语义等价 `𝗭𝗙𝗖 ⊢ (φH/[↑e])ᵗ ↔ Halts(e)`，经 `SetTheory.complete` 化成“每个模型中成立”。用到的模型事实：数字项的值是 `ofNat e`（`val_numeral`，已证）；Num_e 在模型中恰好定义 `ofNat e`（待证，按 n 归纳）。
- **D-C 一致性**：来自 `zfc_consistent`。外加 𝗭𝗙𝗖 ⊢ ∃z Num_e(z)，可得 Halts(e) 与 Never(e) 不能同时被证明。**EffectiveTheory 不需要 Σ1 可靠**；Σ1 可靠（S4）只用于“𝗭𝗙𝗖 ⊬ Halts(d)”和 `provesHalts_iff`。
- **D-D 可枚举**【设计】：沿用 S1 `never_re_nat` 的套路。证 `b ↦ Bootstrapping.Provable 𝗭𝗙𝗖' ⌜Never(b)⌝` 是 Σ1，再经 `provable_iff_provable` 与 `rePred_iff_sigma1` 得到 `REPred`。所需材料：
  1. `ℒₛₑₜ.LORDefinable`（函数符号集为空；关系符号是元数 2 的 = 与 ∈）；
  2. `ℒₛₑₜ.Primcodable`；
  3. `𝗭𝗙𝗖.Δ₁`：𝗕𝗦𝗧 与 𝗔𝗖 是有限集；𝗦𝗘𝗣 与 𝗥𝗘𝗣𝗟 仿 Foundation 对归纳模式的内部 Δ1 定义（`InductionR` 那一套）；或者先证 RE，再经 `Theory.craig` 得到 Δ1；
  4. `numSet`：在 Bootstrapping 的算术化语法里，用 `PR.Blueprint` 原始递归地定义 b ↦ ⌜Num_b⌝，并证明它是 Σ1/Δ1 可定义的；
  5. 拼出 ⌜Never(b)⌝ = qqAll(qqImp(⌜Num_b⌝, qqNeg ⌜Φ⁺⌝))，注意约束变量的移位。
- **D-E Z0**【设计】：
  - 𝗭𝗙𝗖 ⊳ 𝗣𝗔：每个算术公式的翻译在 M 中可定义，ω 归纳即给出归纳公理。
  - 算术影子 Sh := {σ ∣ 𝗭𝗙𝗖 ⊢ σᵗ}，有 Sh ⊢ σ ⟺ 𝗭𝗙𝗖 ⊢ σᵗ。
  - 对 Sh 用哥德尔 II 需要 Sh 可枚举，即翻译的内部可定义性。这一步最重：先评估；做不到就退而做“𝗜𝚺₁ ⪯ Sh.craig 前提下的版本”，或照实写明卡点（完成门 2）。
