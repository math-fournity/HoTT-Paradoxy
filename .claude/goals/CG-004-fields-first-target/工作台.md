### §0.2 《最高指示-Claude版》§6 五项对齐检查

1. **收益与取舍**（对象：一分量欧氏标量场论；尺度：格距趋于零的标度极限）。连续场论省掉了“选一个最小尺度”的任意性，换来平移与旋转对称、无尺度的普适性与微积分。它添了三样理想化：时空无限可分；相互作用发生在没有大小的点上（同一点相乘的 φ(x)⁴）；场是 Schwartz 分布，不是函数。
2. **现实解释**。它模仿的是“东西在空间里运动、相遇、相互影响”。有限格点上的场是谁都能算的现实对象。观察是抹平的平均 T_{f,L}，也就是有限分辨率的测量。宣布完成的是标度极限这一步。贴不上的那一句是“相互作用发生在一个没有大小的点上，而极限对象就是理论本身”。
3. **种子句**。理论为了对称与普适（E），把“时空有最小尺度、相互作用有大小”（T）改成“时空无限可分、相互作用在点上”（T′）；若把格距一次次减半并按方差重标度（P），原任务“相互作用存在”（Done）在极限里失败：四点 Ursell 函数相对高斯值趋于零，极限是广义高斯过程，也就是自由场（O）。
4. **邻近对照**。同一个 φ⁴ 在二维、三维同样取连续极限（同样无限可分），相互作用保留；任何有限格点上，四维也保留。差在“无限可分”与“四维”的合取。机制上，四维的气泡图（两点函数平方的和）恰好对数发散，ADC 的界正是用它压住四点函数。
5. **注意转移**。最先跃入的熟悉答案（候选零）是“这是物理学早知道的平凡性问题，有效场论早已消解”。我把注意移到：有效场论的消解方式恰恰是保留截断，也就是承认被改掉的条件；它不是消解。下一个具体动作：核证卡（§1），然后把 UR 句交研究发起人判定。

**重讲**：为了让理论简洁、对称、哪里都适用，数学物理把时空想成可以无限细分的，把相互作用想成发生在没有大小的点上。这在绝大多数计算里毫无问题。可是在我们生活的四维时空里，没有大小的东西几乎碰不到彼此，于是格子分得越细，相互作用越弱，分到无限细就没有了。2021 年 Aizenman 与 Duminil-Copin 严格证明了这一点，第二年 Duminil-Copin 因此等工作获得菲尔兹奖。现实里东西当然会相互作用，不合理的是那幅无限细分的图景。

### §1.2 主定理核证卡（ADC）

- **维数**：d = 4。
- **模型类**：一分量实标量格点场，最近邻铁磁耦合 J。
  - 单点测度：ρ(dφ) = e^(−λφ⁴ + bφ²) dφ；
  - 或 Griffiths–Simon 类（定义 2.1）：期望可以写成带铁磁耦合的 ±1 Ising 自旋之和，或这类测度的弱极限，并满足次高斯增长；
  - Ising 模型是其“硬”极限。
- **构造**（定理 1.2 所说的“上述构造”）：
  - 格距 a、盒子 R；
  - 参数 (J, λ, b) 调到临界流形附近，使关联长度发散；
  - 先取 R → ∞，再取 a → 0；
  - 场按式 (1.14) 重标度：T_{f,L}(φ) = Σ_{x∈ℤ⁴} f(x/L)·φ_x / √Σ_L，其中 Σ_L = ⟨(Σ_{x∈Λ_L} φ_x)²⟩，f 取紧支连续函数。
- **附加条件**：式 (1.10)，极限场的两点函数 S₂(x,y) 在 |x−y| → ∞ 时趋于零（无长程序；低温相被排除，见 Hairer 评述注 3.2）。
- **结论（定理 1.2）**：这样得到的任何随机场都是广义高斯过程。广义高斯过程即自由场：连通的高阶关联全为零，满足 Wick 律。
- **定量版**：
  - 定理 1.3（四维最近邻铁磁 Ising，β ≤ β_c，L ≤ ξ(β)）：|U₄| ≤ C·B_L(β)^(−c)·Σ_u ∏ 两点函数，其中 B_L(β) = Σ_{x∈Λ_L} ⟨σ₀σ_x⟩² 是气泡图；
  - 命题 1.4：特征函数与高斯的偏差不超过 C·‖f‖∞⁴·r_f¹²·|z|⁴ / (log L)^c。
- **不覆盖**：
  - 非格点的正则化、其他格点模型类（这是撤回条件的来源）；
  - 多分量场、规范场、标准模型；
  - 别的归一化（换别的重标度，极限是零或发散）；
  - 偏差的精确衰减速率（定理给的是上界）。
- **对 UR 的意义**【解释】：“相互作用存在”落在“四点 Ursell 函数相对高斯值不为零”上。定理说，只要从这类格点出发、按方差归一、没有长程序，四维连续极限里它一定为零。

- **UR 候选句（外行版）**：两个东西碰在一起会互相影响，这再简单不过。可是，只要把时空当作可以无限细分的连续体、把粒子当作没有大小的点，在我们生活的四维时空里，连最简单的一种相互作用都无法存在：格子每细分一次，相互作用就弱一点；分到无限细，它恰好消失。
- **精确版**【来源】：四维里，从最近邻铁磁的 φ⁴（或 Ising）格点模型出发，格距趋于零，场按方差重标度，参数在临界附近，没有长程序，所得的任何连续极限都是广义高斯过程，也就是自由场（ADC 定理 1.2）。在任何有限格点上，四点联结函数都不为零（待在 G4 用最小例子做机器检查）。
- **方向**：A 向。现实能完成（东西会相互作用），理论化之后做不到（连续极限里没有相互作用）。
- **与芝诺、圆环的对位**【解释】：
  - 芝诺：每一步都还剩一段，极限宣布“到了”；
  - 这里：每一步都还有相互作用，连续极限宣布“没有”；

### §2.1 人话版（2026-10-02，研究发起人【原话】“人话解释”）

1. **场与相互作用。** 物理学描述世界常用“场”：空间里每一点都有一个数，会起伏、会传开，像水面每一点的高度。起伏各走各的、互不影响，叫自由场，像两列水波穿过彼此、毫发无损。真实的东西会互相影响。最简单的一种，物理学家记作 φ⁴：场在同一点上和自己发生作用。希格斯场的自相互作用就是这一类（ADC 的定理只管最简单的那一种场，不直接管标准模型）。
2. **理论怎样搭。** 直接在连续空间上定义这样的场，数学上做不到：场在每一点抖得无穷剧烈，同一点上没法相乘（Hairer 的评述里说，分布不能平方）。所以先在格子上做，像屏幕的像素：格子上一切有意义，相互作用好好地在那里。再把格子越分越细，看极限是什么；这个极限才被当作“连续时空里的理论”。“时空可以无限细分”的假设，就在这一步起作用。
3. **定理说了什么。** 2021 年 Aizenman 与 Duminil-Copin 证明：在四维里，这样一路细分下去，得到的极限一定是自由场，相互作用一点不剩。二维、三维不会这样，那里的连续理论在 1970 年代就造出来了，相互作用保留；五维以上消失得很快；四维正好在分界线上，消失得极慢，但终究消失。
4. **为什么（一幅图）。** 在这类模型里，“相互作用”可以想成两条随机路线相遇时发生的事。纸上（二维）乱爬的两只蚂蚁，路线一定会交叉；房间里（三维）乱飞的两只蚊子，轨迹也会交叉。维数越高，空间越“宽敞”：到了四维，两条没有粗细的随机路线几乎永远碰不上。格子的大小给了路线一点粗细，所以格子上它们偶尔还能碰上；格子越细，碰上的机会越少；分到无限细，就再也碰不上，相互作用也就没有了。（这是 Duminil-Copin 自己在 ICM 报告里讲的直觉，定理的证明正是沿着它做的。）
5. **物理学家怎么办。** 不取那个“无限细”的极限，保留一个最小的格子（有效场论），相信在某个极小的尺度上，空间不再可以无限细分。物理学的标准做法，恰恰是放弃“时空无限可分”。
6. **为什么像芝诺。** 芝诺：每走一半都还剩一段，无限次之后，极限宣布“到了”。这里：格子每细分一次，相互作用都还在，无限次之后，极限宣布“没有了”。圆环的呼喊“我们当初确实得到了M啊”，在这里是：格子上明明有相互作用，为什么到了连续时空里就没有了？被改掉的条件正是芝诺与圆环的两条：空间可以无限细分，点没有大小。
