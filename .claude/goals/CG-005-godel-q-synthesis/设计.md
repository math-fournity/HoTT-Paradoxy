# CG-005 设计：哥德尔式 Q 的形式目标与逐项对照

> 本机会话 d58e0c0d（Opus 5.5），2026-10-07。本文定义“完全的形式化”到底形式化什么，并把每一条形式命题对到研究发起人的原话上。身份标注：【原话】【证明】（指 CG001-C-NN，见 `HoTT/formal/claude-cg001/godel-q/CLAIM.md`）【解释】【判断】。

## 1. 一个决定：原过程完成就是停机

【原话】KC-000010：“时间相关的悖论，往往结果就是以‘不可计算性/不可停机性’作为特征。”KC-000024：“悖论们都是在揭示理论由于对时间和时序的特殊对待，给自己制造了哥德尔不完备性，也就是在计算理论角度看，是不可停机的问题。”KC-000027：“程序的问题就是它的问题……这是程序、计算的哥德尔不完备性。”0109 第 45 轮：“芝诺悖论，从第一天开始，就是一个可计算性问题，因为每次走剩下的一半，永远走不完，这是结结实实的计算步骤、过程。”

【解释】所以“原过程完成”（OriginDone）取作一个逐步运行的过程的停机，“理论对时间维度的观察”取作理论对过程是否完成、在哪一步完成、是否永不完成的观察。这一取法来自研究发起人自己的框架，不是从外部文献借来的政策；它是解释桥，不是定理（CLAIM §7 第 5 条）。

有了这一决定，GPT 八条线未付的七座桥（dev-09 `GODEL-ZFC-CONVERGENCE-001` §4）有六座当场付清：

| 未付的桥（dev-09） | 本设计的支付 |
|---|---|
| Proof/Accept | bare ZFC 自己的可证性（最“实际”的接受接口） |
| Diag | Kleene 第二递归定理（Mathlib `Code.fixed_point₂`），在证明里实际构造对角点（C-85） |
| P/Q interface | `Done`、`DoneBy`、`provesNever`、`provesNotYet`、`OmegaClosed`（CLAIM §1） |
| SameFullQ | 同一个 ω 追问图式（C-93），芝诺、H0、Z0、哥德尔–芝诺跑者都是实例 |
| Attribution | 魔鬼交易作为反证法（C-90、C-94；§6） |
| H0Map | 不搬运 H0 的 Cubical 语义；H0 以“每一问都答否”这一停机事实接入图式（C-93，跨内核，CLAIM §4） |
| HoTT bridge（把哥德尔编码搬进 HoTT 对象层） | 不需要：目标是 bare ZFC，不是 HoTT 的内在不完备 |

## 2. “神似”：哥德尔的五个动作落在哪里

【来源】0112 中 GPT 对研究发起人那句问话的回答，把哥德尔证明拆成五个动作；研究发起人随后问“为什么你没有全部做完再停下？”（0112 第 3 轮）。下表是这五个动作在本证明包里的实际执行。

| 哥德尔的动作 | 本包中的执行 |
|---|---|
| 1. 找到理论最不能回避的内部对象 | 理论自己的接受接口：`T ⊢ ⌜e 永不停机⌝`（以及 Z0：`T ⊢ Con(T)`） |
| 2. 把它变成理论可处理的编码 | 过程即部分递归程序的代码 `Nat.Partrec.Code`；接受集可枚举（`REPred`） |
| 3. 可实行的回返操作 | `Code.fixed_point₂`：构造一个程序，它以自己的代码运行接受集的半判定过程（C-85 `diagonal_fixed_point`） |
| 4. 让回返命中理论自己的资格机制 | `Done d ↔ T.provesNever d`：d 停机，恰当理论接受“d 永不停机”（C-89 末项） |
| 5. 在元层证明一个有界结论 | 可靠的有效理论漏掉 d（C-89），P 不可兼得（C-90），A_general 不可得（C-94）；不推出 `ZFC ⊢ ⊥`（CLAIM §7 第 1 条） |

与 C-368 的区别：C-368 把动作 3、4 的结果（`step d = d` 与对角合同）作为假设写进定理；本包由递归定理把它们构造出来。

## 3. Z0：H0 在 ZFC 里的对应物

【原话】0109 第 37/42 轮：“……我们甚至还可以找到Q0（H0（Z0）），意思就是Q0是ZFC的Q，其实对应了H0在ZFC中的对应物Z0。”

【解释】dev-06 PF-B2 为 H0 列出的过程锚字段，逐项套到 ZFC 自己的证明搜索上：

| 字段 | H0（HoTT，C-77/C-78） | Z0（bare ZFC） |
|---|---|---|
| 被追问的对象 | 宇宙 `Type ℓ-zero` | ZFC 自身（它的定理集） |
| 原生操作 | 依次问“宇宙在第 k+1 层落定了吗” | 依次查“第 k 个推导是不是 ⊥ 的证明” |
| 局部判定 | 判定器给出是／否及证明 | 机械可判定（`DoneBy` 一类，C-84） |
| 一步 | 否则进入下一问 | 否则查下一个推导 |
| 完成 | 交出一个落定层 | 找到一个矛盾 |
| 有限观察 | `runFor n` | 运行 n 步 |
| 负性 | 任何燃料都没有输出，程序等于 `never`；**HoTT 证明了这一点** | ZFC 一致时搜索永不停；**ZFC 证明不了这一点**（C-92 `goedel_II_consistent`） |
| 有界正控制 | 有上界的目录恰在界处停 | 不一致的理论，搜索在某一步停 |

【解释】唯一的差别在“负性”一行：HoTT 看得见自己宇宙上的追问永不停；ZFC 看不见自己的矛盾搜索永不停。这是研究发起人所说“ZFC 在时间维度上的观察力不完备，不是没有，只是不完备”的最锋利的实例：ZFC 能确认每一步都还没找到矛盾（Δ0 完全），却不能确认“永远找不到”。

“Z0 是一件本来简单的事”【解释】：一个推理系统检查自己会不会自相矛盾——只要一直查下去——本来应该很简单（UR 的前半句，KC-000054）；甚至在 ZFC 中都做不到（UR 的后半句）。

## 4. Z0 填满文献线的 P0–P6

【来源】文献线（`codex/hott-motive-zfc-literature`，`P-ANTECEDENT-EVIDENCE-SYNTHESIS.md`）的净判词：社区对 P0/P3/P4 有先例，“ZFC SAME-CARD P1–P6 CONVERGENCE: NOT FOUND”。

| P 字段 | Z0 的同卡内容 |
|---|---|
| P0 计算/过程阅读 | 证明搜索是逐步运行的过程 |
| P1 必入对象 | 理论自己的可证性：任何有效理论都绕不开“这是不是一个证明” |
| P2 不可另账 | 把一致性移到更强的理论（ZFC-1）去“另记一本账”，同一任务在上一层原样重现（C-87 补丁塔、C-92 `extension_strict` 与 `goedel_II_consistent` 对每一层都成立） |
| P3 存在性追问 | “是否存在一个 ⊥ 的证明”；经完备性定理，等价于“是否存在 ZFC 的模型”——理论对自己论域的存在性追问（KC-000050/051 的形状） |
| P4 自指 | 对角点直接再入：d 查询理论对 d 的接受（C-85） |
| P5 预支使用 | 把“ZFC 证明了 e 停机”当作“e 确实停机”来用，就是预支 ZFC 自己付不出的可靠性（哥德尔 II）；把这份可靠性写成公理并让它覆盖理论自己，理论即矛盾（C-92 `self_consistency_collapse`） |
| P6 同一任务／UR | “检查自己会不会自相矛盾”本来简单，在 ZFC 中做不到；与芝诺的“跑到”、H0 的“落定”是同一个 ω 追问（C-93） |

## 6. 归因四件事（KC-000049）

【解释】【判断】针对 Z0 与哥德尔–芝诺跑者里出现的“不合理”（UR）：

1. **候选前提**：（a）P_ω：用完成的整体宣布无穷过程的结局；（b）有效性 R：证明是有限的、可机械检查的；（c）一致性；（d）经典二值性对无穷过程的结局（“d 停机或永不停机”被当作已落定的事实）；（e）无穷公理与实数完备性（给出完成的整体：极限总存在，全部证明构成一个集合）。
2. **竞争归因**：（i）“不合理”来自 (d)(e)：ZFC 宣称结局已有定论、整体已经存在，却交不出结局——这是研究发起人第二类悖论的形状（KC-000022：“理论中却绕过 ASK，假装它‘已完成’”）；（ii）“矛盾”来自 (a)：只有加上 P_ω 并坚持有效与一致，才会得到矛盾；（iii）最强反方：哥德尔现象是一切有效、一致、足够强的理论的共性，不专属于 ZFC 的“时间盲”。
3. **区分它们的证据**：C-90 的必要性控制（`consistency_needed`、`truthTheory`、`soundness_needed`）表明，去掉 (b) 或 (c) 都能消除矛盾而代价不同，去掉 (a) 也能（bare ZFC 本身一致，`toyTheory` 是具体例子）；(d)(e) 不产生矛盾，只产生“交不出”（C-89、C-91）。对反方 (iii)：本包的定理确实对一切满足前提的理论成立；研究发起人的 KC-000027 本就说 HoTT 继承了同一种程序的哥德尔不完备，KC-000024 把哥德尔不完备看作时间盲理论的共同签名，所以“不专属于 ZFC”与研究发起人的论点一致——论点是“bare ZFC 不能豁免”，而 ZFC 恰恰是本应裁决子理论边界的元理论（0109 第 45 轮）。
4. **我的判断（判断，不是定理）**：UR（本来简单的确认在 ZFC 中做不到）的直接来源是“理论把无穷过程的结局当作已落定的事实（d、e），而它观察事实的唯一方式是有限证明（b）”之间的落差；把这个落差用 P_ω 补上，就是魔鬼交易。按研究发起人的框架，(b) 与 Con 是现实的，(d)(e) 与 P_ω 是为经济性与工具性所作的、否定现实的抽象；被告是“把完成的整体当作结局”这一族前提，P_ω 是它的主动形式，二值性与实无穷是它的被动形式。

## 7. 形式化的边界（完整清单见 CLAIM §7）

- 机器证明的是：计算层定理（无条件）；有效理论层、跑者、证明论层与图式定理（以标准元性质为前提的抽象定理）。
- 没有机器证明的是：bare ZFC 满足 R、Σ1C、Δ0C、HBL、Diag（来源中的标准元定理）；Con(ZFC)（通行前提）；“时间维度 = 过程阶段”的解释桥；H0 与 Lean 图式之间的跨内核对应。
- 把 ZFC 层也做到机器证明的路径：在 Lean 中形式化 ZFC 的语法、证明系统与对 Q 的解释（工作量大）；或接入 Foundation（一阶算术已有第一、第二不完备），再补 ZFC 到算术的解释——都需要下载外部源码，要研究发起人许可。
