## 2. 同一定义两侧（G2）

### 2.1 设计

- **同一定义**：预层式的“野”半单纯结构 `WildSST`：
  - `X : ℕ → Type`；
  - `d n : Fin (n+2) → X (n+1) → X n`（第 i 个面）；
  - `sid n i j (i ≤ j) x : d n i (d (n+1) (suc j) x) ≡ d n j (d (n+1) (weaken i) x)`（半单纯恒等式，重编号形式：对 i < j，d_i d_j = d_{j−1} d_i）。
  - `Fin` 用归纳定义（zero、suc），`weaken` 按递归定义，使 `weaken (suc j) = suc (weaken j)` 定义性成立；两侧用同一套定义。
- **六边形相干 Coh₂**：对 i ≤ j ≤ k（Fin (m+2)）与 x : X (m+3)，把 d_i d_{j+1} d_{k+2} 改写成 d_k d_j d_i 有两条路线：
  - 路线 A：`cong (d m i) (sid (m+1) (suc j) (suc k) …)` ∙ `sid m i k …` ∙ `cong (d m k) (sid (m+1) (weaken i) (weaken j) …)`；
  - 路线 B：`sid m i j …` ∙ `cong (d m j) (sid (m+1) (weaken i) (suc k) …)` ∙ `sid m j k …`；
  - Coh₂ 要求两条路线相等。
- **Lean 一侧（UIP）**：两条路线是同一命题的两个证明，由证明无关性相等；对一切实例 Coh₂ 由 `rfl` 成立。
- **Cubical 一侧**：取 X n = S¹，d = id，除 `sid 0 zero zero` 取 `rotLoop`（在 base 处绕一圈）外全取 refl。m = 0、i = j = k = 0 时，路线 A 在 base 处绕 1 圈，路线 B 绕 2 圈，Coh₂ 不成立。

### 2.2 结果（2026-09-26）

- **C-64**（`HoTT/formal/claude-cg001/wild-sst/WildSST.agda`，Cubical Agda，零警告）：`setsCohere`——各层都是集合时 `Coh₂` 成立；`spin`——各层 S¹、面映射为恒等、唯一非平凡恒等式为 `rotLoop`，满足全部面恒等式；m = 0、i = j = k = 0、x = base 时路线 A 绕 1 圈、路线 B 绕 2 圈（`refl` 由内核算出）；`spinIncoherent : ¬ Coh₂ spin`。负控制（断言路线 A 也绕两圈）被拒 `1 != 2`。
- **C-65**（`HoTT/formal/claude-cg001/wild-sst-lean/WildSSTUIP.lean`，Lean 4.34.0，零警告）：同一定义，`coh2 : ∀ S, Coh2 S` 由 `rfl` 成立，零公理，`leanchecker --fresh` 通过。负控制（路线 A 最后一步颠倒面映射顺序）被拒。
- 运行：`20260926-CG001-WILD-SST-01`、`-NEG-01`、`-WILD-SST-LEAN-01`、`-LEAN-NEG-01`，全部目标内精确重放（证据索引 §16）。

## 3. 后退的第二级（G3）

### 3.1 设计（手推，待机器检验）

- 退化族：X₀ = 某个 2-型（优先宇宙中以 S¹ 为基点，其二阶环可由 `rotLoop` 经单价性造出；备选 S²），X_n = Unit（n ≥ 1），一切 `sid` 取 refl，于是每个六边形的两条路线都是同一个项 r（三个 refl 的复合），第二级数据是 r ≡ r 中的元素。
