## 4. 教训

- W1：开工前漏了翻查，写结论前补上了。以后开工的第一个动作就是翻查，与写文件分开。
- `run_cmd` 依赖检查可以把“没有用到某类论证”这种范围声明变成机器核对，并附正控制。以后凡是声明“没有用到 X”，都这样核对。
- zsh 不对未加引号的变量分词：多参数命令用 bash 数组，或用 Python 调用。
- W3：给一个已有翻译解释的类型再加 `ORingStructure`，会引出 Foundation 的 `standardModel` 与翻译解释两个 `Structure` 实例相争。用类型同义词加恒等双射（S4 的 `eval_equiv_iff`）隔开。
- W3：`naturalNumber_induction` 是 elab_as_elim，情形参数直接写项会把数字字面量的实例弄乱；一律留 `?_` 再逐个证明。
