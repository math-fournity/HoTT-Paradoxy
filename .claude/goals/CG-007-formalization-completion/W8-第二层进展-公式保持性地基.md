| 4 | 主定理：`IsSemiformula ℒₒᵣ n p → IsSemiformula ℒₛₑₜ n (iT n p)` | `semiformula_result_induction`（`Formula/Basic.lean:1578`） |

### 3.1 主定理的**归纳谓词**必须带 `param = n` 护罩（新发现，本轮实测）

`UformulaRec1.Construction.semiformula_result_induction` 的结论是

```lean
∀ {param n p : V}, IsSemiformula L n p → P param n p (c.result L param p)
```

`param`（**输出层**）与 `n`（**输入层**）是**独立量化**的。而 `iT` 的 `param` 就是输出层：
`iTR param k R v` 要求 `v` 在层 `param`，但 `hRel` 只给 `IsSemitermVec ℒₒᵣ k n v`（层 `n`）。
`param ≠ n` 时**证不出来**。

出路：把归纳谓词取成

```lean
P param n p q := param = n → IsSemiformula ℒₛₑₜ param q
```

结论实例化 `param := n` 即得目标；`hRel` 支由 `param = n` 把 `v` 的层搬过去。
`hall` 支的递归是 `P (param+1) (n+1) p …`，护罩 `param+1 = n+1` 自动保持。
**对照**：Foundation 自己的 `semiformula_subst_induction`（`Formula/Functions.lean:523`）
不需要护罩，因为它的输出层恒等于输入层（`subst` 不改层）。`iT` 改层，所以要。
