## 4. 深追与判词

### 4.1 A1 沿运动测量

**进入单元前的对齐检查**（《最高指示-Claude版》§6；2026-09-24 已用 Read 重读 L37–166；单元 = Book HoTT 与 Cubical Agda 的恒等类型 + 引理 2.2.1 ap + HoTT 的同伦解释；观察尺度 = 单条规则 × 共同取舍 × 整体）

1. 收益与取舍：一切构造自动尊重相等（免良定义检查）、直接操作空间（免点集拓扑）。代价是把“是同一个”与“能连续过渡到”合成路径一个概念。
2. 现实解释：路径模仿连续运动（intro L103–110：`p : a = b` 表示 A 中从 a 到 b 的路径，即单位区间的连续映射）。旅行者沿路径移动，观察者读仪表，到达终点即完成。贴不上的一句：basics L688–690 把“函数尊重相等”和“函数连续”说成同一回事。在拓扑里，连续函数沿路径可以变；在 HoTT 里，值域若是集合，沿路径就不能变。
3. 种子句：理论为了让一切构造自动尊重相等（E），把“运动会改变仪表读数”（T）改成“运动就是相等，相等者读数相同”（T′）。若携带取值于固定集合的仪表沿路径走一趟并逐刻记录（P），预计读数记录（O）在 HoTT 中全程不变，现实中会变。
4. 邻近对照：圈数计数器（读数在随路径扭转的纤维里）绕一圈 +1；离散时间的走法（运动不是路径）读数会变。差别只在“运动是否被当作相等”。

### 4.2 C1 实数的测量记录

**进入单元前的对齐检查**（压缩后已用 Read 重读《最高指示-Claude版》全文，`4a3dc51a1517`；回源 reals.tex（sha256 `f5e4803e…9e7`）L1–40、L660–800、L925–980、L1515–1536、L1795–1895。单元 = Book §11.3 的 HIIT Cauchy 实数 ℝ_c，定义 11.3.2（L739–790）；观察尺度 = 构造子 lim 与 eq × “直接给出自由对象”这一共同取舍（H3）× 整体的“不假设可数选择”（H5））

1. 收益与取舍：得到 Cauchy 完备的实数，既不用幂集，也不用可数选择（L12–16），还免去“取极限”的超限迭代（L700–703）和把实数序列提升为代表序列的那一步（L674–680）。添入的是：lim 是构造子，只要给出一个逼近（逼近者本身可以是实数），极限点立即存在；eq 同时把 ε-处处接近的逼近认作同一。省去的是：一个实数不再随身带着一串有理测量值。书中自己说 ℝ_c “may not be a quotient of the set of Cauchy sequences of rationals”，只是以实数为项的逼近的商（L937，引理 RC-lim-onto L951）。
2. 现实解释：模仿对一个量作越来越精的测量。实验者操作，取得各精度的读数；读数不唯一，同一精度重测可以差一点；需要读数的人观察。lim 这个构造子一次收下整条逼近规则，立即宣布“量已取得”。贴不上的一句：“手里的量可以按任意精度测，测出的读数可以列成一张表”。HoTT 里每个精度的读数只 merely 存在；要把无穷多个精度的读数一次列成表，自然的证明要用可数选择。
3. 种子句：理论为了不用可数选择就得到完备的实数（E），把“一个量由一串可以列出的有理测量值给出”（T）改成“量是自由完备化的生成元，逼近者可以是实数，ε-处处接近的逼近被认作同一”（T′）。若拿到一个量后要交出测量记录（P），预计每个精度单独可得、有限份记录可得，而整条无穷记录要靠可数选择（O）。
4. 邻近对照：setoid 实数，即把有理逼近作为数据带在身上（书中的办法 1，L684–687）。这时无穷记录就是这份数据，有限记录是它的截取，都不用选择。差别只在是否依赖 T′：setoid 保留了表示（T），代价是函数要逐个证明尊重 ≈，丢掉了“不变性白送”。
5. 注意转移：候选零有两个。一是“构造性分析早知道，没有可数选择时 Cauchy 实数就是这样”，二是“极限早就解决了芝诺”。我把注意移到：真实的实验者实际要完成的测量任务是什么，HoTT 在这个任务上是否失败。用户的现实前提（KC-000003、KC-000004：运动与时空离散，存在最小尺度）意味着现实的测量记录总是有限的。下一个具体动作：机器检查“任意有限份记录都可得”，再判断无穷记录的困难是否与现实相对。

**给外行的重讲**：HoTT 的实数有个方便之处：只要给出一种越来越精的逼近办法，这个数就立刻存在，不必真的一步步走完逼近，也不必额外假设“可以一口气做无穷多次挑选”。代价是，一个数不再随身带着它的测量记录。拿到一个数后，每个精度的读数都“有”，但不唯一；要把无穷多个精度的读数一次写成一张表，就得额外假设可数选择。可是现实里的测量总是有限次的，而有限长的表 HoTT 给得出来。HoTT 只拒绝交出无穷长的记录，而这种记录现实里也做不完。

### 4.3 I1 逐层一致推不出整体相同

**进入单元前的对齐检查**（新单元，已用 Read 重读《最高指示-Claude版》全文 `4a3dc51a1517`；回源 homotopy.tex（sha256 `c3b15506…af32`）§8.8 L2340–2520 全文。单元 = Book §8.8 Whitehead 定理与 Whitehead 原则；观察尺度 = 整体（H5 普适性：定理对一切 ∞-topos 模型成立）× 机制（超完备性，L2490–2500）× 单条定理（定理 8.8.3，L2426–2452））

1. 收益与取舍：HoTT 是同伦类型的“抽象理论”（L2366–2368），定理在一切 ∞-topos 模型里成立，并保持“计算动机”（L2364）。添入的是：必须容纳非超完备模型，书中描述为“sheaves of ∞-groupoids over ∞-dimensional base spaces”（L2355–2358），这是一类假想现实。省去的是：只在具体模型里成立的原则。Whitehead 原则在用集合搭建 ∞-群胚的世界里 “cannot fail to be true”（L2364–2365），在 HoTT 中不可证（L2353），只能作为可相容的 “classicality axiom” 加回（L2363）。
2. 现实解释：模仿“逐层比较两个形状”：先数连通块，再看环路、各维球面的缠绕。每一层有一张对照表；一张映射让每层都对上，就宣布两者是同一形状。比较者持有两个形状和一张映射，逐层检验，最后宣布“相同”。贴不上的一句：“每一层都对上，就宣布相同”。HoTT 只在层数有限（n-type）时能宣布（定理 8.8.3）；层数无限时，书中说 “there is no way for the induction to get started”（L2452）。
3. 种子句：理论为了让定理在一切 ∞-topos 模型里成立（E），把“每一层都对上就是同一个形状”（T，集合搭建的模型中成立）改成“只有层数有限的形状能这样判定，其余要额外公理”（T′）。若逐层比较两个形状并在每一层都对上（P），预计对层数无限的形状 HoTT 宣布不了“相同”（O：Done 达不到），经典空间里宣布得了。
4. 邻近对照：两个层数有限（n-截断）的形状。逐层比较后 HoTT 能宣布相同（定理 8.8.3，库中有）。差别只在是否依赖 T′：有限层时用不到 Whitehead 原则。
5. 注意转移：候选零是“抽象理论本来就比具体模型证得少，就像环论证不出整数是主理想整环，这是普适性的普通代价”。书 L2366–2370 自己就这样说。我把注意移到：现实里被比较的形状是什么样子？用户的现实前提是离散、有限，现实中比较的是有限个单元（胞腔）拼成的形状，检查也总是有限层。于是关键问题变成：对有限胞腔拼成的形状，HoTT 是否只需有限层就能宣布相同？下一个动作：机器检查截断 Whitehead（有限层形状），以及“有限胞腔”论证的核心一步（球面上连通度够的族有截面）。

**给外行的重讲**：HoTT 比较两个形状的办法是逐层对照：连通块、环路、各维的缠绕。它要在一切可能的“世界”里都成立，而其中有些世界里的东西在无穷多层上都对得上，却仍然不同，比如铺在无穷维底子上的层。所以 HoTT 不肯从“无穷多层都对上”推出“相同”。但现实里被比较的东西都是有限块拼成的，检查也总是有限层。对层数有限的形状，HoTT 做得到；对有限块拼成的形状，有限层也应该够，这一步我给出推导，并机器检查了其中填块的一步。HoTT 只在现实里没有的那种无穷维对象上停手。
