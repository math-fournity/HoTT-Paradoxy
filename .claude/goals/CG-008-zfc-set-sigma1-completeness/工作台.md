- 10-11 P2 **找到绕过自由变量障碍的通道：`Derivable` 原始层**（本轮最重要的进展）：

  **发现**：读 `Syntax/Proof/Basic.lean:935` 有一条此前未用的通道：

  ```lean
  lemma internal_provable_iff_internal_derivable {φ : V} :
      Provable T φ ↔ Derivable T (insert φ ∅ : V)
  ```

  `Derivable`（`Basic.lean:537`）是**原始层**的推导谓词：`∃ d : V, DerivationOf T d s`，
  其中 `s : V` 是**编码的序列**，不是 typed `Formula`。
  它的规则 API（`Basic.lean:786-937`）——`em`/`and_m`/`all_m`/`ex_m`/`wk`/`cut`/`by_axm`/
  `and`/`or`/`all`/`exs`/`conj`/`disj`——**只要求 `T.Δ₁Class`**。

  探针 6 逐条查实：这些规则对 `𝗭𝗙𝗖` + `ℒₛₑₜ` **全部可用**（`by_axm`、`and`、`all`、`exs`、`cut`）。

  **为什么这可能绕过 3.3 的障碍**：`Derivable` 层**没有「自由变量」这个概念**——
  它只有编码。算术版要 `toNumVec` 把自由变量的值命名成数字项才能落回闭句层；
  而 `Derivable` 直接作用在编码上，不需要「命名」这一步。

  **成果**：`CG008Raw.lean` 把两个层之间的**桥**形式化并编译通过：
  - `internal_derivable_of_tprovable`：typed 层内部可证性 ⇒ 编码层 `Derivable`；
  - `tprovable_of_internal_derivable`：反向。两者等价。

  **性能注记**（编译实证，探针 7）：两座桥（`tprovable_iff_provable`、

- 10-11 P2 **证伪一条候选路线（方向性）**：新建 `GodelQ/ZFC/CG008Probe12.lean`（`rc=0`）。

  `[∀ σ, 𝔅.FormalizedCompleteOn (𝔅 σ)] → 𝔅.HBL3`。

  **注意 `HBL3` 的类型约束**：`{T₀ T : Theory L}`（**同一语言**）+ `[L.ReferenceableBy L]`。
  `zfcTr : Provability 𝗜𝚺₁ Sh` 里两者都是 `Theory ℒₒᵣ`，正好满足。
  `ReferenceableBy L L₀ = GödelNumber L₀ (Sentence L)`，`ℒₒᵣ` 有 `ofEncodable` 实例。
