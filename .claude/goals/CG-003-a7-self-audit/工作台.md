## 0. 对齐检查（《最高指示-Claude版》§6）

1. **收益与取舍**：
   - 对象：书式 HoTT 与 Cubical Agda（2.8.0、cubical 0.9）中，预层式的半单纯结构（`WildSST`）及其逐级相干。
   - 单价性替使用者省掉了“同构后还要搬运一切结构”的证明义务：不变性白送。代价是“相同”只剩结构一种，宇宙不是集合（C-63）。
   - 于是半单纯恒等式成了路径；每一级路径之间的一致，又成了下一级义务。
2. **现实解释**：
   - 模仿的活动：用点、线、三角形等拼形状，并检查“面的面对得上”。
   - 在现实里，检查是一次比对，结果为是或否，只做一次。在 HoTT 里，“对上”是一条带内容的路径；两条对法之间还要再对，层层往上。
   - 贴不上的一句是：在现实里，“面之面相合”检查完就落定。
3. **种子句**：
   - E：不变性白送；
   - T：相同是会落定的事实 → T′：相同是结构，有无穷层；
   - P：逐级写出“面之面相合”的一切相干；
   - O：事实世界一步完成（C-65）；HoTT 中每补一级都长出下一级（C-64、C-66），统一定义至今写不出。
4. **邻近对照**：同一套定义，各层取集合（不依赖 T′）就一步完成（C-64 `setsCohere`）。本目标补上中间的一档：各层取群胚，应当恰好停在第二级。差别只在“相同有几层”。
5. **注意转移**：
   - 最先跃入的熟悉答案：“这是已知的开放问题，没什么新意”，以及“手推的 P₄ 大概没错”。
   - 我把注意移到两处：内核能确认什么，只有独立审计能确认什么（形式命题是否忠实）。
   - 下一个具体动作：写生成器，把一般的 P₄ 相干写成类型。

**给非专业读者**：HoTT 为了让“换个样子但本质相同的东西”自动通用，把“相同”变成了一种带着具体对法的关系，对法之间还能再有对法。拼形状时要求“面的面对得上”，在普通数学里比一次就完；在 HoTT 里，对上的方式本身还要彼此对上，一层接一层。本目标要检查的有两点：第二层到底是不是真的不自动成立；这种层层往上的长度，是不是正好等于“相同”的层数。

## 1. 设计：一般的 P₄ 相干（G1）

- **字与改写**：
  - 字母写成 `fsuc^f (weaken^w v)`（v ∈ {i,j,k,l}）；
  - 改写规则 (a, fsuc b) → (b, weaken a)（a ≤ b），即恒等式 `sid`；
  - `weaken (fsuc v)` 与 `fsuc (weaken v)` 由计算相等，所以规范形固定为 fsuc 在外。
- **面**：
  - 位置 0、2 的改写互不相交，构成正方形（库的 `homotopyNatural`）；
  - 位置 0、1 构成底部六边形（第 m 层的六边形数据，作用在 `d (m+3) A4 x` 上）；
  - 位置 1、2 构成顶部六边形（第 m+1 层数据经外层面映射推出，用 `topFace` 与 `congFunct₃` 调整）。
- **次序证明**：恒等式的次序假设改为不相关参数（`WildSSTᵢ`），同一条边从不同的面到达时是同一个项；证明项由 `wk≤fs`、`weaken≤N` 与三条假设组合而成，只需通过类型检查。
- **两个半球**：
  - 路线是六条边的右结合复合，末尾补 `refl`；
  - 一步移动是 `cong（前缀）(seg₂/seg₃ 面 尾部)`；
  - 从字典序最小的路线 (0,1,0,2,1,0) 到最大的 (2,1,2,0,1,2)，搜索到 `hem₁`（6 步）与 `hem₂`（8 步），二者用到的面互不相交且合起来恰好是全部 14 个面。
  - 起初按“每个半球 7 步”搜索失败，放宽上限后找到 6 + 8。
- **flat 上的证明**：
  - 原计划让内核直接算出两个半球的 Hopf 绕数，单步移动 100 秒以上都没有算完，放弃；
  - 改为结构化证明：13 步移动的面各等于 `refl`（`natConst`、`seg-refl`、`topFace-refl`）；唯一的例外 `seg₃ (sym σr) T` 由单射性推出 σr ≡ refl。

### 3.2 T-038：自攻 A7（书式 HoTT 中有没有统一定义）

- 检索：sciverse 关键词检索“semi-simplicial types homotopy type theory”（2019 年起，25 条）；语义检索三组（不可能性结果；截断层的半单纯类型；高阶观察类型论、参数性、display 等新路）。

  Aberlé 2024（*Parametricity via Cohesion*，ENTCS）称 dTT “solve[s] the previously-open problem of representing semi-simplicial types in HoTT”，但指的是扩展理论 dTT。
- **最近的威胁**：Herbelin–Ramachandra，*The very dependent recursive structure of iterated parametricity in indexed form*，arXiv:2602.12689（2026-02）（doc `c6129aa9…`），§6 Perspectives（offset ≈58100）：
  - 原文：“On HSet, coh²_FRAME is trivially provable and the construction stops here. If we were working in an untruncated universe U, the construction would continue recursively… Such an infinite process can again be represented using streams… This would solve the semi-simplicial type problem [14].”

### 3.3 CN-036 §4.4：2LTT 是否需要外层自然数（由凭记忆的线索升为来源）

- 2LTT，MSCS 2023（doc `87368dfa…`），摘要：“HTS has an axiom ensuring that the type of natural numbers behaves like the external natural numbers, which allows the construction of a universe of semisimplicial types. In 2LTT, this axiom can be assumed by postulating that the inner and outer natural numbers types are isomorphic.”
- 同文 page_no 12 的公理：
  - (A1)：内外层自然数同构；
  - (A2)：“countably infinite towers of (trivial) fibrations have (trivially) fibrant limits”，“still allows for the construction of inner types of Reedy fibrant semisimplicial types”；
  - (A3)：“the outer natural number type is cofibrant … This axiom has been suggested by Shulman.”
- Altenkirch–Capriotti–Kraus 2016，Remark 3.2（page_no 10）：“If we work in the strong 2-level theory (where ℕ_s and ℕ coincide), we can consider the homotopy limit SS … Then, SS is indeed a (fibrant) type that encodes (Reedy fibrant) functors Δ₊^op → U.”
- Kraus 2021，page_no 15：“It is possible to equip 2LTT with an axiom which ensures that the type Δ₊^op ⇒RF U is fibrant as well, e.g. by assuming axiom (A2)…”
- Kraus–Sattler 2017（doc `91e58e3d…`），page_no 3：“…a popular and sufficient assumption is that the natural numbers of the ‘strict’ fragment of the theory coincide with the ordinary (‘fibrant’) type natural numbers.”
- Annenkov 博士论文 2018，page_no 109：“…if we allowed for coercion from strict natural numbers ℕˢ to fibrant natural numbers ℕ then from the construction of type of the n-restricted semi-simplicial types, one would get a type family ℕ → U in the fibrant fragment.”
- **结论**【来源】：修复加回的不只是事实式的相等（外层 UIP），还有事实式的计数。不加公理时，2LTT 只对每个外层自然数给出第 n 层；要得到内层的“一切半单纯类型之型”，需要把外层自然数与内层绑定的公理 (A1)–(A3) 之一。【解释】这与 C-62（在理论之外逐层计数的程序）、KC-000011 相接，归因更尖锐。

### 3.4 CN-036 §4.2：HoTT 的半单纯类型与经典半单纯空间

- Kraus–Sattler 2017，page_no 3：“If I is an (externally fixed) finite inverse category, the type of Reedy fibrant diagrams over I can always be encoded in ‘standard’ homotopy type theory, see Shulman’s work [21]. If I is infinite, this is in general not the case. … For … Δ₊^op, the corresponding Reedy-fibrant diagrams are well-known as semisimplicial types in the community of homotopy type theory. Whether this construction can be internalised … is a well-known open problem.”
- Part–Luo 2015 摘要：“According to the interpretation of HoTT in Quillen model categories, SSTs are type-theoretic versions of Reedy fibrant semi-simplicial objects in a model category.”
- Shulman，*Univalence for inverse diagrams and homotopy canonicity*，MSCS 2015 摘要：“…Reedy fibrant diagrams correspond to contexts of a certain shape in type theory.”
- **结论**【来源】：HoTT 的半单纯类型就是 Δ₊^op 上类型值的 Reedy 纤维图式，即模型范畴中 Reedy 纤维半单纯对象的类型论版本。经典一侧，半单纯空间是严格函子，面的恒等式作为等式成立（数学常识）。所以“同一任务在经典数学中以严格定律完成”这一对照有来源支撑。
