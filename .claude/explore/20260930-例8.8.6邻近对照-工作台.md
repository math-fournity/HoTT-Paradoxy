## 1. §6 对齐检查（五项）

1. **收益与取舍**。对象：Cubical Agda 2.8.0 加 cubical 0.9；类型 `Prod = (n : ℕ) → K n`，其中 `K n = EM ℤ (1+n)`（C-75 包，高阶归纳类型）；观察尺度是追问程序 Q（C-77）对这个类型的逐层提问。Π 的形成规则替使用者省掉了“逐项构造、逐项确认”：无穷多个分量一次交出为一个整体。高阶归纳类型添上了“一切高度一次齐备”。宇宙在这里只当工具用（类型族 `K : ℕ → Type ℓ-zero`），不是被追问的对象。
2. **现实解释**。模仿的活动：一只“无穷工具箱”，第 n 格放一件 n+1 维的形状；追问的是“两只这样的工具箱以什么方式相同”，从第 1 层问起，每层问“相同在这一层落定了没有”。谁取得：Π 的形成规则一次交出整只工具箱。谁操作、观察：追问者 Q 与判定器。谁宣布完成：Q 在某层得到“是”即交出层号。解释贴不上的地方：现实里一只“每格维数没有上限的工具箱”算不算一个已取得的整体，正是第二道门（存在要求落定）要回答的，本单元不裁定。
3. **种子句**。理论为了“一次交出整体、一切高度齐备”（E），把“整体要在某一层落定才算已取得”（T）改成“整体一次交出，落不落定都算已取得”（T′）。若在一个不是宇宙的乘积上跑同一个追问程序（P），预计 O（停不停）与宇宙相同：永不停。再把成员高度设上限（改变 T′ 里“一切高度齐备”这一项），预计 O 变为在确定的一问停下。
4. **邻近对照**。本单元本身就是 C-78 的邻近对照：去掉“被追问的对象是宇宙”，保留高阶归纳类型、单价性与 Π 的一次交出。本单元内部再设一个对照：同一个 Π、同一种成员，只是高度有上限（`Bounded b = (n : ℕ) → K b`）。两者只差“成员高度有没有上限”。
5. **注意转移**。最先跃入的熟悉答案有两个：“例 8.8.6 是教科书已知结果，平凡”（审稿人姿态），以及“这只说明是高阶归纳类型的锅”（候选零，也是熟悉答案）。注意转到：这个结果对罗素线主张结构的改变——宇宙的角色从“唯一不停的对象”改为“不可回避的那一个，也是装进无界高度的工具”；以及对归因的改变（B 向下“一次交出”的范围）。下一个具体动作：写 `ProductQuestioning.agda`，复用 C-75、C-77 的引理；设四个负控制；在本机按 F-011 捕获与重放。

**给非专业读者的重讲**：HoTT 可以一次就把无穷多个东西装成一个整体，比如一只工具箱，第 n 格放一件 n 维的形状。我们之前发现，追问“宇宙里的成员以什么方式相同”永远问不完。这一次不问宇宙，改问这样一只普通的工具箱，看追问是不是照样问不完；再给工具箱里形状的维数设个上限，看追问是不是就在预期的那一问停下。如果前者不停、后者停，就说明让追问停不下来的是“维数没有上限”加上“整体一次交出”；宇宙的特殊之处，在于它是理论不能拒绝的那一个。

## 2. 设计

- 包：`HoTT/formal/claude-cg001/product-questioning/`，模块 `ProductQuestioning`。导入 `PedometerSemantics`（`Delay`、`never`、`runFor`）、`UniverseHasNoLevel`（`K`、`ΩⁿK`、`sec`、`trivSec`、`Πpt`、`Ω^Πpt`、`hLevelΩ^`）、`QuestioningDelay`（`Judge`、`Questioning`、`question`、`judgesAreEqual`、`whetherSettled`、`levelUp`），不复制源码。
- 关键一步：C-75 的 `secNontrivial` 陈述的是整条截面，但证明只在基点 x₀ 取值（`funExt⁻ p x₀`）。本包把同一论证写成基点上的非平凡性 `secAtBase≢triv`，这正是例 8.8.6 需要的“在一点处非平凡的 n 维环”。
- 例 8.8.6 的构造：第 m 维上取乘积环路空间中的元素“第 m 格放 `sec m x₀`，其余格放平凡环”；乘积的环路空间等于环路空间的乘积（`Ω^Πpt`）；若乘积在 h-层 2+m 落定，这个环路空间可缩，于是该元素平凡，取第 m 格得 `sec m x₀` 平凡，矛盾。
- 有界对照：`Bounded b` 在 h-层 3+b 落定（`isOfHLevelΠ` 加 `hLevelEM`），在 2+b 不落定（常值截面取第 0 格）；用 C-77 (d) 的 `exactHalt` 与 `silentUpTo` 得到恰好第 2+b 问停。
- 负控制四个：乘积第 1 步就答（应得 `nothing`）；用 `refl` 证乘积上的程序等于 `never`（计算看不出不停机）；有界乘积 b=0 在燃料 1 沉默（应得 `just 2`）；有界乘积 b=0 第 1 问就停（应得 `nothing`）。
- 运行：本机 macOS 工具链（`HoTT/formal/dedekind-omega-missile/TOOLCHAIN.json`）。规范捕获工具只收一个 include 根，所以派生 macOS 版 CG001 捕获工具（`.claude/goals/CG-001-targeted-overview/tools/capture_cg001_agda_macos_run.py`），与云端的 Linux 版只差默认工具链、Agda 资产的发布方摘要处理和会话标识。
