## 1. 对齐检查（§6 五项）

1. **收益与取舍**（对象：Cubical Agda 2.8.0 + cubical 0.9，`--safe --cubical --guardedness`；观察尺度：一个“目录”类型 C 的全部恒等层级，以及一个会跑的过程）。
   - 这一单元用到两项设计。其一，HoTT 的形成规则一次交出 `Type ℓ-zero`，单价性让成员的“相同”变成结构，高阶归纳类型让成员有任意高度；它省掉了“先弄清目录里的东西以什么方式相同，再拿目录来用”的义务。其二，Delay 类型（Capretta）让一个全函数的理论谈论可能不停的过程：`never` 是一个对象，“不停”可以写成路径 `≡ never`。
   - 它添了什么：Delay 把“一直在跑”表示成一个整体给出的余归纳对象。C-59 (c) 已证明 `≡ never` 恰好等于“任何有限步的运行都拿不到结果”，所以这个完成态的对象可以只经有限观察来读，不必把无限运行当作已经取得。
2. **现实解释**：模仿的活动是“问一份目录里的东西以什么方式相同”：两个成员以什么方式相同；这些方式之间又以什么方式相同；如此往上，落定就停下，并报告落定的层。
   - 谁取得目录：形成规则。谁操作：理论的使用者。谁观察：提问的人或程序。谁判断每一层：判定器，它每层交出“是”或“否”的证明。谁宣布完成：程序返回 `now k`。
   - 贴不上的地方：形成规则在任何一层落定之前就交出了宇宙（社区稿 02 第 6 节）；“存在性追问 = 这个过程”是解释桥，也就是 P1，尚未裁定。
3. **种子句**（本单元）：理论为了“让不停的过程也能成为一个可推理的对象”（E），把“不停机只能靠一直看下去来观察”（T）改成“不停机是一条到 `never` 的路径”（T′）；若把逐层追问写成这样的程序并证明它 `≡ never`（P），预计原任务的完成标准（交出落定的一层）对宇宙永远达不到，这一点从元层推论变成内部定理；同一个程序在 ℕ、集合目录和每一层落定者的目录上都按预期停下（O）。
4. **邻近对照**：同一个程序跑在“成员高度有上限”的目录上：ℕ、Bool 第 1 步停；命题的目录第 1 步停；集合的目录第 2 步停；(1+n) 型的目录恰好第 1+n 步停。唯一差别是成员高度有没有上限。另一个邻近任务是“问：有没有一层落定？”。它的完成标准是一个是或否的裁决，不是交出一层；对宇宙，它第 0 步就答“没有”。所以它是另一件事，不能拿来消解 Q。
5. **注意转移**：最先跃入的熟悉答案是“这是平凡的：对每层都否，无界搜索当然不停，教科书里的 Capretta 语义”（候选零），以及“HoTT 已经用有限证明回答了，所以追问停了”。我把注意移到四处：
   - 程序是否忠实于 Q，要看它该停处是否停，所以停机要恰好刻画为“有有限层”；
   - 判定器要对任意判定器成立，并证明判定器存在且唯一；
   - 内化之后元层还剩什么：一致性，以及对任意判定器的可计算性（典范性）；
   - 两个提问任务（“哪一层落定”“有没有一层落定”）的完成标准不同。
   下一个具体动作：写 `QuestioningDelay.agda`。

**给非专业读者的重讲**：HoTT 用一条规则直接交出“所有类型的目录”，使用者不必先弄清目录里的东西彼此怎样相同，就能拿它运算。可要是真的一层层去问“它的成员以什么方式相同”，每一层的答案都是“还没落定，再往上问”。以前我们只证明了“每一层的答案都是否”；“所以问不完”这一步，是在理论外面推出来的。这次把“一层层问”本身写成理论里的一个程序，让理论自己证明：无论让它跑多少步，都交不出答案。同一个程序跑在装着集合的目录上，第二步就交出答案。

## 2. 设计（形式命题的草案，以源码为准）

- **判定器** `Judge C = (k : ℕ) → Dec (isOfHLevel (suc k) C)`：每一层交出“是”或“否”的证明，与社区稿 02 第 3.1 节的伪代码逐行对应。
- **程序**（导入 C-55 的 `Delay`，不重抄；与 C-55 的无界搜索同形，但停机条件可以在任意宇宙层）：
  - `askFrom k .force = answer k (judge k)`；
  - `answer k (yes _) = now k`；`answer k (no _) = later (askFrom (suc k))`；
  - `Q = askFrom 1`。
- **C-77（程序与刻画，对任意 C 与任意判定器）**：
  - 燃料方程；
  - 与判定器无关的燃料方程（只看 C 在该层是否落定）；
  - 输出可靠（返回 j 则 C 在 j+1 层落定）；
  - 停机当且仅当 C 有某个有限层；`Q ≡ never` 当且仅当 C 没有任何有限层；
  - 精确停机时刻（前 n 层都否、第 n+1 层是，则燃料 n 返回、之前都是 `nothing`）；
  - C 在最低宇宙时，Q 就是 C-55 的无界搜索从 1 开始。
- **C-78（宇宙）**：
  - 对任意判定器，`Q (Type ℓ-zero) ≡ never`，任何燃料都返回 `nothing`，从不作答；
  - 判定器存在（`judgeU`，每层都答否）且唯一（判定器的类型是命题）；
  - 内核用 `refl` 实跑若干步；
  - 对照：问“有没有一层落定”的程序第 0 步答“没有”。
- **C-79（阶梯，同一程序的有上限实例）**：ℕ、Bool 第 1 步停，输出 1；(1+n) 型的目录恰好在燃料 n 返回 1+n，此前沉默（命题的目录第 1 步停，集合的目录第 2 步停）；各有判定器。
- **C-80（事实世界，Lean 4）**：同一组燃料方程；对任意判定器，`Type` 第 1 步停，输出 1。
- **负控制**：宇宙在燃料 1 返回 1（`refl`）；ℕ 在燃料 0 沉默（`refl`）；集合目录在燃料 0 返回 1（`refl`）；Lean 中 `Type` 在燃料 0 沉默（`rfl`）。

## 3. 内化之后元层还剩什么（预判，待写进 CLAIM）

- 【判断】内部定理说的是：对这个程序，任何有限步的运行都得不到结果（C-59 (c) 的观察刻画）。把它读成“现实中照这个程序去跑，永远停不下来”，需要两件元层的事：
  - 一是所用理论一致（否则它也能证明相反的命题）；
  - 二是对任意闭判定器，闭项会算到典范形（立方类型论的典范性【来源转述：Huber 2019，核心立方类型论】）。
  对本包给出的判定器 `judgeU`，每一步都是定义展开，内核已用 `refl` 实跑检查到一个固定步数。
- 【判断】解释桥（P1）与现实侧前提（P2）不因本包改变。
