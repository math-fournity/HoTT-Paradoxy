## 2. 问题一页纸（人话）

**用户在追什么**【解释，依据 KC-000010、022、047、048】：
- HoTT 为了好用（经济性、普适性），改掉了某个现实条件。
- 在这个条件上安排一件需要它的事，让 Think in HoTT 推出现实中没有的困难（A 向），或者把现实做不到的事当成已完成（B 向）。
- 要像芝诺瞄准稠密性、罗素瞄准“构造是过程”那样有靶；理论侧要机器证明。

**A1“沿运动测量”**：
- 取舍：HoTT 把“是同一个”和“能连续走过去”做成了同一个东西，即路径。
- 过程：带温度计从冷镇走到暖镇，沿路逐刻记读数。
- 按“运动 = 恒等路径”的读法，任何取值于集合的读数沿路都不能变（C-01–C-07）；现实中读数会升。
- 对照：同样四个位置，把“走一步”写成函数，读数 0,1,2,1,0 可以变；写成路径（Ring4），读数不能变（C-05）。

**对辩之前的归因**（CN-015）：
- P1 认同：“=”同时充当“同一”与“连续连接”。
- P2 读法：把路径读作运动。MO3-C B02 的窄读法否认这一点。
- P4 稠密：用户最早的怀疑。

之前的 AI 判断：条件于立场 S（即取 Book 自己的合成读法），咬人的是 P1。立场 S 与 B02 之争留给用户。

## 3. Terra 的审计（要点；全文逐字见 `.claude/handoff/20260925-Terra审计原文-逐字.md`）

【来源：Terra 原文，转述】

1. **总判词**：没有发现 HoTT 内部错误，也没有找到用户要的非现实性悖论。找到的是四条真实、正确、早为社区所知的结构性边界：
   - 图的边变成恒等后，丢掉沿边变化的集合值观察；
   - 同伦型不能同时当作带可分辨点、距离与实值场的点集空间；
   - 恒等路径可逆，不宜作为不可逆过程箭头的唯一表示；
   - 构造性实分析中的全称覆盖可能需要 Markov 原则或选择。

   标签应为“已核证的表示或语义保真边界”。Terra 独立重放了四个主运行，结果一致。
2. **A1 是“最关键的误建模”**：物理运动需要轨迹 γ : I → X 与温度场 T : X → ℝ；把运动写成 p : a ≡ b，再要求读数区分两端，内核拒绝是应当的。C-06 的类型族是合法出路，“预先写进模型”不构成反驳。要成为失配，必须有真实使用者把物理步骤建模为恒等，又声称能从中恢复读数。
3. **图实现 C-19、C-20**：是 HIT 递归原理的标准后果；适合作应用审计测试，不能单独成为悖论。
4. **圆环 C-21、C-22**：¬(base = x) 不是点集删点，换了对象；凝聚类型论本来就把拓扑路径与恒等分开，“两副面孔”只在附加条件下成立；Markov 部分只对固定映射成立，Coquand–Mannaa 不能搬到 HoTT。
5. **时序 C-23、C-24**：C-23 正确而已知。C-24 的单调性是 Opus 自己加的；有向时间轴当然可以承载 0,1,0 的信号。
6. **Terra 建议的下一步**：找一个真实的 HoTT 使用者，它把物理或程序过程形状化为恒等或 HIT，同时又把被丢掉的高度、方向或完成资格当作仍可从该表示取得。找到了，C-19 就是锋利的反证链；找不到，结论应是“HoTT 正确地区分了该抽象的适用范围”。

## 4. Claude 的自查与回应（要点；全文见 CN-020）

**形式层没有分歧。**

**四处让步**（都已改正，能证的已证）：
1. **A1 不满足合格命中判据 (e)。**
   - CE2 以“变化是预写的，不算测量”反驳类型族；这与 CN-016 否定种子 S1、S5 的理由（场在物理中同样预先给定）相矛盾，已撤回。
   - 【证明 C-25】四位置环上，按 +1、+1、−1、−1 粘合的类型族带有截面，其在四个具名位置的原始读数是 0,1,2,1。有限读数任务能以同等代价完成。
   - A1 降为 STRONG_CANDIDATE（条件于立场 S）。CG-001 `最终报告.md` 已追加勘误；relay 也已标明，不要按合格命中登记。
2. **CN-017 过强**：只对非依赖读数成立。
3. **CN-018 换了对象**：
   - 用户的圆是点集圆，S¹ 不是故事的载体；
   - “两副面孔”只在“单射坐标 + 非平凡恒等环”下成立；
   - Markov 部分只对 Astra 的固定复原映射成立；
   - “用户的稠密性怀疑是对的”一句撤回。
4. **CN-019“有向出路只买回了钟”**：单调性是假设。【证明 C-27】时间作为数据时，信号 0,1,0 存在；原结论降为条件式。

**四处反驳**：
1. **“误建模”不成立。**
   - Terra 的 γ : I → X 若取 Cubical 的区间，本身就是路径（Cubical 的 `Path` 就定义为区间上的函数），A1 照样成立；换成点集实数区间，就是 A1 自己写明的非合成出路。
   - 【来源 + 证明】真实使用者：同伦补丁理论（Angiuli、Morehouse、Licata、Harper，ICFP 2014）把仓库编辑写成 HIT 中的路径。在“更丰富上下文”一节里，作者报告：
     - 按行数分类、加一行是路径时，把上下文解释为该长度文件的类型行不通（C-28，原生重建）；
     - 所有状态都可达时，所有上下文都被认同，只能解释为可缩类型（C-29，原生重建）；
     - 他们的出路是让上下文由补丁历史来索引。

     所以“把状态改变写成路径”是实践中的读法，而且在实践中撞上了与 A1 相同的墙。（CN-021）
2. **B 向判据被用在了 A 向候选上。** “过强承诺”对应 KC-000022 的第二种；A1 属于第一种。KC-000010 对 A 向只要求 Think in HoTT 之后出现现实中没有的困难。补丁理论没有过强承诺，这一点 Terra 对；也正因为如此，它是 A 向证据，不是 B 向证据。
3. **新颖性不是用户的判据**（KC-000015）。让步：这些是设计者选择并声明过的抽象，不能说成“被忽视的漏洞”。
4. **C-24 的反例用的是作为数据的时间。**【来源：Riehl–Shulman，arXiv:1705.07442】Segal 类型之间的函数自动保持恒等与复合，读数必须把箭头送到箭头：
   - 读数类型只有恒等箭头时，读数不变；读数类型的箭头就是序时，读数单调；
   - 要先升后降，需要带非可逆回路的读数类型，或者放弃合成时间。

   集合在单纯类型论中是否只有恒等箭头：**未核**。

**剩下的真正分歧**：
- 【证明 C-26】即使用类型族取回了读数，走一步前后的整体状态 (r0, 0) 与 (r1, 1) 仍被认同，变化只以原始读数存活。记为新候选 **A1′**。补丁理论里“所有上下文都等于初始上下文”，是它在实践中的样子。
- 两边的立场：
  - Terra：路径不是运动，这是正确的适用范围。
  - Claude：条件于立场 S，理论自己的词典与实践者都这样读，于是状态改变变成了认同。
- 这与物理学的时间问题之争同构（Earman 对 Maudlin，CN-014），不是谁算错了。
- **需要用户裁定两件事**：
  1. Think in HoTT 是否包括把运动或状态改变读作恒等（立场 S）；
  2. 现实任务要求“运动者的状态改变了”，还是“在具名位置交出不同读数”即算完成。

  两项都取前者，A1′ 值得再审；取后者，A1 线结为已知表示边界，转为应用审计测试。
