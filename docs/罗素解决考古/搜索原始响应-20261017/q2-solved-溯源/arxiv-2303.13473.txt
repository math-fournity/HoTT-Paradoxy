VERY BASIC SET THEORY

arXiv:2303.13473v8 [math.HO] 28 Jan 2026

DOEKO H. HOMAN

Abstract. The naive conception of set is described as ”Any predicate has an
extension”. Then Russell’s paradox is used to prove the inconsistency of naive
set theory. If the only constituent of a set is that set itself we call that set an
‘individual’. We show Russell’s paradox permits sets that are individuals thus
that is not an inconsistency. Zermelo’s axiomatization also permits individuals.
Very basic set theory is a set theory with individuals and has a philosophical
foundation in Ludwig Wittgenstein’s Tractatus Logico-Philosophicus.

Introduction
Georg Cantor defined a set as (Boolos [1971] p.215)
• ”a ‘many, which can be thought of as one, i.e. a totality of definite
elements that can be combined into a whole by a law’.”
That means a set is ‘determined’ by its elements. Sets are denoted by s, t, u, . . . .
Symbol ∈ is the ‘membership relation’ symbol. Then s ∈ t means s is a ‘constituent’
(also called ‘an element’ or ‘a member’) of the totality t. The negation of s ∈ t is
denoted by s ∈
/ t. Set s is an ‘individual’ if the only constituent of s is s itself. A
set with only s and t as constituents is denoted by {s, t} (Zermelo [1908] p.263).
Often the terminology is: ‘set {s, t} contains only s and t’. But the totality {s, t}
is ‘thought of as one’ thus a set is a mental picture in your mind. Therefore we
prefer to write ‘constituent of a set’, not ‘is contained in a set’.
In (Oliver and Smiley [2006] §5.1) Alex Oliver and Timothy Smiley explain why
”numerous textbooks” prohibit individuals: individuals are not needed for
mathematical purposes.
In (Kanamori [2003] pp.285-288) Akihiro Kanamori describes that with the ‘empty
extension’ and the ‘axiom of restriction’ there is no need for individuals (also
known as atoms or urelemente). Individuals ”are objects distinct from the
null set yet having no members and capable of belonging to sets”.
In (Boolos [1971] pp.216-217) George Boolos notes ”individuals (= non-sets)”.
In section 4.6.5 (Mendelson [2015]) Elliott Mendelson explains
”The words ‘individual’ and ‘atom’ are sometimes used as synonyms for
‘urelement’. Thus, urelements have no members”. And in a footnote (p.304)
”Zermelo’s 1908 axiomatization permitted urelements”.
In (Zermelo [1908] pp.262-265) Ernst Zermelo describes in ”10. Theorem.”
”Für jedes Element x von M ist es definit, ob x ε x oder nicht; diese Möglichkeit
x ε x ist an und für sich durch unsere Axiome nicht ausgeschlossen.”
Thus ‘x ε x or not’ is definite; the possibility ”x ε x” is not excluded by our axioms.
Therefore Zermelo’s 1908 axiomatization permits sets ‘containing’ themselves.

1. What are individuals and sets?
At an early age you develop the mental picture of ‘what is a set’. You belong
to a family or a clan, to the inhabitants of a village or a particular region. Then
experience shows there are things that constitute a set. The members of a set are
the constituents of that set.
Set theory is a language that follows rules of logic to communicate the mental
picture of a set with the physical world. Then someone reading, seeing or listening
that language forms a mental picture of a set. Set theory is made up of ‘formulas’.
A formula is a proposition or predicate about the facts of sets. For every set s and
for every set t the fact is the definiteness of s ∈ t. A formula which is not complex
or not a combination of other formulas is an ‘atomic fact’. Formula s ∈ t is an
atomic fact, formula t ∈ s is an atomic fact. Formula s ∈
/ t is the negation of s ∈ t
thus s ∈
/ t is a complex formula therefore s ∈
/ t is not an atomic fact. Atomic facts
are what makes formulas true or false.
Definition. Set s is an individual if the only constituent of set s is set s itself.
A formula presupposes propositions or predicates while propositions or predicates
presupposes atomic facts. Then if an atomic fact is analyzed as fully as possible the
constituents finally reached are individuals. Individuals cannot be analyzed further.
In this way the naming of individuals is what is logically first in logic (Wittgenstein
[1999] prop. 3.26) and Bertrand Russell (Introduction p.12).

4.221), (Anscombe [1963] p.29-31). Thus individuals are ‘elementary propositions’.
Therefore in Very basic set theory the naming of individuals is logically first.

2. Logic and definiteness
In this section we prove logical formulas preserve definiteness. Formulas are
denoted by Φ, Ψ, . . . and are built up from formulas by means of negation ¬Φ (not
Φ) and conjunction Φ ∧ Ψ (Φ and Ψ). Negation takes precedence over conjunction.
If Φ is a formula then (Φ) is a formula. The parenthesis ( and ) preclude ambiguity
and improve legibility. Then s ∈
/ t is the formula ¬(s ∈ t).
If Φ is a formula then ∀s(Φ) and ∃s(Φ) are formulas. ∀s(Φ) means ‘for every set
it is the case Φ’. The negation of ∀s(¬Φ) is denoted by ∃s(Φ) thus ∃s(Φ) means
‘exists a set such that Φ’. The parenthesis following ∀s and ∃s are mandatory.
However, e.g. without ambiguity ∀s∃t(s ∈ t) is short for the formula ∀s(∃t(s ∈ t)).
If there is s in Φ not guided in Φ by ∀s or by ∃s then ‘s is free in Φ’. Thus s is
free and t is not free in formula ∀t(s ∈ t).
Set s in ∀s or in ∃s is not a ‘variable’. ∀s means ‘for every set’, thus also for a set
denoted by s. And ∃s means ‘exists a set’ denoted by s. Set theory is a language.
We define the logical connectives ∨, → and ↔.
: Φ ∨ Ψ (Φ or Ψ or both) is short for the formula ¬(¬Φ ∧ ¬Ψ),
: Φ → Ψ (Φ implies Ψ) is short for the formula (¬Φ ∨ Ψ),
: Φ ↔ Ψ (Φ if and only if Ψ) is short for the formula ((Φ → Ψ) ∧ (Ψ → Φ)).
There are many rewrite rules: ¬(¬Φ) is logically equivalent to Φ, ¬(Φ ↔ Ψ) is
logically equivalent to (Φ ↔ ¬Ψ) and ((Φ ∧ Ψ) ∧ ¬(Φ ∧ Ψ)) is logically equivalent
to ((Φ ∧ Ψ) ∧ (¬Φ ∨ ¬Ψ)). More rewrite rules in (Mendelson [2015] p.15).
Definition. Formula Φ is ‘definite’ if it is not the case that both Φ and ¬Φ.

The logical connectives ‘or’, ‘implies’ and ‘if and only if’ are expressed in terms
of logical ‘not’ and logical ‘and’. Thus if Φ and Ψ are definite then (Φ ∨ Ψ),
(Φ → Ψ) and (Φ ↔ Ψ) are definite.
If an atomic fact is analyzed as fully as possible constituents finally reached are
individuals. Atomic facts and elementary propositions are definite.
Therefore the building up of formulas preserve definiteness.

Conclusion
Very basic set theory is a set theory with the philosophical foundation in Ludwig
Wittgenstein’s Tractatus Logico-Philosophicus. It is a set theory with individuals.
The atomic facts are the membership relations and the elementary propositions are
the individuals. The formulas of set theory preserve definiteness. The naming of
individuals is logically first and the logic is capable to deal with transfinite numbers.
We list some differences with ‘mainstream set theory’.
• There is no ‘empty set’ (Kanamori [2003] §1).
• The singleton of an individual is that individual itself (Kanamori [2003] §2).
• Regularity is not an axiom but a theorem.
• The proof that ‘every set has a transitive closure’ requires no other axioms
or no ‘set of all natural numbers’ (Mendelson [2015] pp.286-287).
• Cantor’s Theorem (Zermelo [1908] p.276) reads
for every set s, the ‘number of members’ of s is less than the ‘number of
members’ of the powerset Ps.
However, there is no ‘empty set’ therefore P{s} = {{s}}.
Thus Cantor’s Theorem does not hold.
• Any pair of individuals is the first number of a sequence
of natural numbers.
S
Then transfinite ordinals are postulated. If e.g. ω = ω then ω is the first
number of a sequence of transfinite ordinals. Therefore ω is not a ‘limit
ordinal’, ω is the first number of a sequence satifying the Peano Axioms for
natural numbers.
