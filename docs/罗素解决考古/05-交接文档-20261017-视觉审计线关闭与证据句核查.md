### 1.2 两次干预的原文与研究发起人关切

1. **教科书页数质疑**（阶段 ②触发）：「这些 PDF 里面怎么还有 669 页的？我们文献考古
   用不到那么多吧？」——614 页教科书（enderton 289 + kunen 325）逐页审边际收益递减。
2. **视觉能力质疑**（阶段 ③触发）：「你先停下来，你在干什么？你作为 AI 模型，无法处理
   视觉啊。」——主模型确实无视觉（read 工具读 PNG 报错「this model does not support
   image input」，探针记录 §8 已实测）；此前会话用的是 `analyzeImage` **外部视觉工具**
   （委托另一个视觉模型看图、拿回文本转述），不是主模型自己看。研究发起人的质疑同时
   暴露了该工具的**记忆补全风险**：Zermelo 1908 是著名论文，视觉模型可能用训练记忆
   背书而非真的逐字读图——双次调用一致也排除不了「流畅的背书」。

**治理教训**：方案 04 初版写的「模型多模态直读」在当前宿主模型上根本不可行，这个前提
偏差本应开工前实测声明，而不是做了 1 页才被指出。未来会话设计「人工审计」类任务时，
第一步先实测宿主能力边界，把「谁能看图、怎么采信」写进方案再开工。

## 4. 方法论教训（未来会话直接复用）

1. **双栏学术 PDF 的跨管线覆盖测量陷阱**：公式表示差异（LaTeX `$\mathcal{P}(X)$` vs
   纯文本 `P(X) -> X`）会让指纹法双向失效，正反双向假缺失率 40–50%。有效方法：用
   **纯文字句**做指纹，或对目标句直接 grep 判定；散布式「部分缺失」数字不可直接采信。
2. **视觉模型三风险**（无视觉主模型 + 外部视觉工具记忆补全 + 网络超时）叠加时，
   「已有独立管线的文本互查」永远优于「新增视觉管线」——本轮 22 点里 20 个双文本管线
   即可确定，视觉只该在字符级分歧处做仲裁。
3. **MinerU 符号噪声模式**（不影响文字引用，引公式时注意）：普通词误转数学模式
   （Rieger `out`→`$\mathrm{out}^{\dag}$`）、V→`$\mathsf{V}$`、zermelo §1 Nr.3 的
   `\in` 误用于子集关系（原文应为 `⊆`）。
4. **zermelo OCR 管线噪声特征**：Vision OCR 的 `geiöst`（l→i）、`Wider-sprüche`
   （断词）、pdftotext 的 `3z Vx`（∃∀ 字体映射）——比对时先规范化（断词合并、字母流）
   再判定，避免把 OCR 噪声误报为内容差异。
