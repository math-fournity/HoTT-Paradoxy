## 2. IEP *Russell's Paradox*（唯一在抽样中用了「solves」的条目）

- URL：https://iep.utm.edu/par-russ/（抓取 2026-10-17T05:45:29Z）
- 第 3 节（Aussonderung）：

> „A quite different approach is taken in Zermelo-Fraenkel (ZF) set theory."
> „rather than having a naive class abstraction principle... ZF has a principle
> of separation, selection, or as in the original German, '**Aussonderung**'."
> „**This approach solves Russell's paradox**, because we cannot simply assume
> that there is a set of all sets that are not members of themselves."

**要点**：IEP 用 **solves**；SEP 用 **avoid / blocked**；Enderton 用 **blocked / avoided**。
同一件事三种措辞——「社区说的」内部并不统一，这正是步骤 4 对照表第一栏要呈现的。

## 3. SEP *Russell's Paradox*（§4, "Russell's Paradox in Contemporary Logic"）

- URL：https://plato.stanford.edu/entries/russell-paradox/（抓取 2026-10-17T05:45:29Z）

> „Zermelo replaces (NC) with the following axiom schema of Separation (or
> _Aussonderungsaxiom_):"
> „**How does (ZA) avoid Russell's paradox?** One might think at first that it doesn't."
> „Let \(B\) be any set. By (ZA), the set \(R_B = \{x \in B: x \not\in x\}\) exists,
> but **it cannot be an element of \(B\)**."
> „Thus something, namely \(R_B\), is 'missing' from each set \(B\). So again,
> \(V\) is not a set, since nothing can be missing from \(V\)."

**要点**：SEP 的表述（`R_B` 从每个 `B` 中「缺失」）与 C-433 的 `R_A ∉ A`
**逐字同构**——机器命题与主流百科表述在数学内容上一致。

### 6.1 无界概括不一致 → 「幸好」有分离（行 955–962）

> „Unfortunately, such a scheme is inconsistent by the famous Russell paradox:
> If ¢ is x ¢ x, then this axiom gives us a y such that ∀x (x ∈ y ↔ x ∉ x),
> whence y ∈ y ↔ y ∉ y. **Fortunately** in mathematical applications it is
> sufficient to be able to use a property P(x) to define a subset of a given set,
> so we postulate Comprehension as follows."

**要点**：教科书自己用了「**Unfortunately … Fortunately**」的叙事修辞——
从「无界概括不一致」到「幸好在应用上只要子集就够」，**中间没有定理，只有需求降级**。
这是步骤 4 第三栏「未支付的诠释跳跃」在**教科书内部**的直接显现。

### 6.2 Theorem 5.2：不存在全集（行 1004–1007）

> „**THEOREM. ¬ ∃z ∀x (x ∈ z).**
> PROOF. If ∀x(x∈z), then, by Comprehension, form {x∈z : x∉x} = {x : x∉x},
> which would yield a contradiction by the Russell paradox discussed above."

**要点**：与 Enderton Theorem 2A 同构，都归结为「不存在全集」——即本包 C-433
`R_A ∉ A` 的应用。**教科书层面，「解决了罗素悖论」的实际内容就是这条定理。**
