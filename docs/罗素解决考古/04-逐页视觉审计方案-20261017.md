## 4. 逐页审计循环（每页一个自包含工作单元）

```
read 二值页图（模型多模态直读；必要时 analyzeImage 辅助）
 → ① 人工提取该页文本（正文 + 页眉/页脚/脚注/公式/图注）
 → ② 定位 full.md 对应文本块（_content_list.json 或行号区间）
 → ③ 逐行比对：漏行、错字、公式排版错、页眉页脚混入、图注缺失、跨页断词
 → ④ 写一页审计说明（模板 §5），立即落盘
 → ⑤ 问题处置：
      需修 → 立即改 mineru_md/<name>.md + 文件头修订登记 + git 提交
             （格式："audit(<pdf>): fix p<NNN> <问题> …"）
      存疑 → 登记 UNRESOLVED 行；CN-082 OCR 交叉印证后裁决
      无问题 → 说明落盘即可
 → ⑥ 审计说明按批提交（每 10 页或每份 PDF 一批）
```

每页自包含：说明与修复立即落盘，会话压缩后凭账本恢复，不依赖对话记忆。
