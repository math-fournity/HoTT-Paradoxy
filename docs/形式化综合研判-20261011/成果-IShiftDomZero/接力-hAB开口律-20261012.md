## 0. 目标（一句话）

`hAll` 的唯一剩余前提 `hAB` 归结为码恒等式

```
iT 0 (free ℒₒᵣ p) = subst ℒₛₑₜ ?[^&0] (iT 1 (shift ℒₒᵣ p))          (p : IsSemiformula ℒₒᵣ 1 p)
```

它是下面**开口律**的 `m = 0` 特例：

```
iT m (subst ℒₒᵣ (QvecVOr m) q) = subst ℒₛₑₜ (QvecV m) (iT (m+1) q)     (q : IsSemiformula ℒₒᵣ (m+1) q)
```

其中 `QvecV m = QvecVOr m = [#0, #1, …, #(m-1), &0]`（长度 `m+1`），
即 `qVec` 对 `?[^&0]` 迭代 `m` 次。

## 1. 机制（为什么为真）

`subst` 下降一层绑定子时把代入向量 `W` 换成 `qVec W = ^#0 ∷ termBShiftVec W`
——**前置一个新的 `^#0` 并把所有索引 +1**。
`iTR` 内部有 `qqAlls … 2` 两层绑定，所以开口向量在那里已长到长度 `m+3`：

* 索引 `i < m+1` 处是 `^#i`（恒等）；
* 索引 `m+1` 处是 `^&0`。

而 `iVE (m+1) ^#z = eqAtom ^#(z+1)` 把源变量 `z` 放在索引 `z+1`——
于是**代入恰好落在变量槽上，不碰 `eqAtom` 自己的值槽（索引 0）**。
裸公式的"同索引交换"是**假**的（机器化反例：`ITSubstCounter.naive_law_is_false_shape`）；
这里的正确形式是"**在正确的槽上**交换"。

## 3. 剩余（按依赖顺序）

### 3.1 `nth_right`（func 支右侧逐项展开）

目标（`IVEOpenFunc3.lean` 中被我暂时移除的那段）：

```lean
lemma nth_right (mm i j : V) (hj : j < (mm + 1) + 1) :
    (termSubstVec ℒₛₑₜ ((mm + 1) + 1) (QvecV (V := V) (mm + 3))
      ((^#i : V) ∷ shiftVec 3 (mm + 1))).[j] =
      if j = 0 then (^#i : V) else if j = mm + 1 then ^&0 else ^#(j + 2)
```

**当前进度**：**已完成**（`nth_right`，`IVEOpenFunc5.lean`）。
`substVec_func_eq`（`IVEOpenFunc6.lean`）也已由 `nth_left`/`nth_right` 逐项比对得出。

**做法**：`nth_termSubstVec` → 得 `termSubst (QvecV (mm+3)) (V.[j])`；
再用 `nth_V` 把 `V.[j]` 拆成 `if j = 0 then ^#i else ^#(j+2)`；
然后 `nth_QvecV_three`（需先补：`QvecV (mm+3)` 在 `j ≤ mm+3` 处是
`if j = mm+3 then ^&0 else ^#j`）分三种情形：
* `j = 0`：源项 `^#i`，需 `i ≤ mm+3` 才能用 `nth_QvecV_three`——**这是新约束**，
  来自 `IsSemiterm.bvar`（`i < mm+4`，即 `i ≤ mm+3`）；
* `j = mm+1`：源项 `^#(mm+3)`，正好是 `QvecV (mm+3)` 的最后索引 → `^&0` ✔；
* 其它：源项 `^#(j+2)`，`j+2 ≤ mm+2 < mm+3` → 恒等 ✔。

**工程提示**（本会话踩过的坑）：
* `nth_termSubstVec`/`len_termSubstVec` 要 `IsUTermVec`（用 `.isUTerm`），
  而 `IsSemitermVec.termSubstVec` 给的是 `IsSemitermVec`——两者要接对；
* `mm+2` 与 `mm+1+1` 不是定义相等，需先 `rw [show ... by ring]` 归一；
* `if_pos`/`if_neg` 已废弃，建议直接用 `ite_eq_left`/`ite_eq_right`；
* 向量末项 `^&0` 是 **fvar**，`termSubst` 对它走 `termSubst_fvar`（不动），
  不是 `termSubst_bvar`；
* `termSubst_bvar` 要在 `nth_*` **之前**用——否则 `termSubst W (W.[j])` 形式
  对不上 `termSubst W ^#z` 的模式；
* `nth_right` 需要一个额外的假设 `hi : i < mm + 4`（`V` 的构造里 `^#i` 是合法 bvar
  的依据），比 `nth_left` 多一条。

### 3.2 `iVE_open` 的 func 支

`substVec_func_eq` 已证（§2）。剩余：把 `ve2` 在开口代入下拆开——
`ve2 (mm+1) k f w` 与 `subst ℒₛₑₜ (QvecV (mm+2)) (ve2 (mm+2) k f w')`
对接，其中 `w = iVE.construction.resultVec ℒₒᵣ ![mm+1] 2 v`、
`w' = resultVec … (termSubstVec … v)`。参照 `TranslateShiftCompat.shift_ve2`。

需要三条**代入版**的零件（`shift` 版已有对应物）：
* ~~`subst_QvecV_cDomN_subst`~~ —— **已证**（`IVEOpenFunc8.lean`）。
  走法记录（供后续零件复用）：`Bootstrapping.substs_substs` 的签名是
  `IsSemiformula L l p → IsSemitermVec L n m w → IsSemitermVec L l n v →
   subst L w (subst L v p) = subst L (termSubstVec L l w v) p`，
  **`n` 是外层向量的长度、`m` 是其层数**——本处 `l = 1`、`n = m = mm+3`。
  合成的向量 `termSubstVec L 1 (QvecV (mm+2)) ?[^#i]` 用
  `termSubstVec_cons₁` + `nth_QvecV_lt` 化简回 `?[^#i]`。
  坑：`hw : IsSemitermVec L 1 (mm+3) ?[^#i]` 需要 `i < mm+3`（由 `lt_add_one`），
  且 `mm+2+1` 与 `mm+3` 要显式 `ring` 转换（`simpa` 不够）。
* `subst_QvecV_subst_cFunc`（**前段已打通，末段未证**）。
  已可用的形状（本会话实测，除末段外全部通过类型检查）：

  ```lean
  lemma subst_QvecV_subst_cFunc {mm k f : V} (hk : k ≠ 0) (hn3 : 3 ≤ mm + 2) :
      subst ℒₛₑₜ (QvecV (V := V) (mm + 2))
          (subst ℒₛₑₜ ((^#2 : V) ∷ ?[^#0, ^#1]) (cFunc k f)) =
        subst ℒₛₑₜ ((^#2 : V) ∷ ?[^#0, ^#1]) (cFunc k f) := by
    -- ① cFunc 的公式性
    have hc : IsSemiformula ℒₛₑₜ 3 (cFunc k f) := isSemiformula_cFunc_arity2 hk f
    -- ② 外层向量 QvecV (mm+2)：长度与层数都是 mm+3
    have hw : IsSemitermVec ℒₛₑₜ (mm + 3) (mm + 3) (QvecV (V := V) (mm + 2)) := by
      have h := isSemitermVec_QvecV (V := V) (mm + 2)
      have e : (mm + 2 : V) + 1 = mm + 3 := by ring
      rwa [e] at h
    -- ③ 内层向量 [^#2,^#0,^#1]：层数要抬到 mm+3
    have hv : IsSemitermVec ℒₛₑₜ 3 (mm + 3) ((^#2 : V) ∷ ?[^#0, ^#1]) :=
      GodelQ.IVEOpenFunc9.isSemitermVec_two_zero_one (mm + 3) (by simpa using hn3)
    -- ④ substs_substs 把外层代入推进去（参数 l=3、n=m=mm+3）
    rw [show subst ℒₛₑₜ (QvecV (V := V) (mm + 2))
          (subst ℒₛₑₜ ((^#2 : V) ∷ ?[^#0, ^#1]) (cFunc k f))
        = subst ℒₛₑₜ (termSubstVec ℒₛₑₜ 3 (QvecV (V := V) (mm + 2))
            ((^#2 : V) ∷ ?[^#0, ^#1])) (cFunc k f) from
      Bootstrapping.substs_substs (L := ℒₛₑₜ) (l := 3) (n := mm + 3) (m := mm + 3)
        (p := cFunc k f) hc hw hv]
    congr 1
    -- ⑤ 末段（未证）：证 termSubstVec 3 (QvecV (mm+2)) [^#2,^#0,^#1] = [^#2,^#0,^#1]
  ```

  **末段 ⑤ 的精确目标**（`nth_ext' 3` 之后逐项）：
  对 `j = 0,1,2`，证
  `(termSubstVec ℒₛₑₜ 3 (QvecV (mm+2)) [^#2,^#0,^#1]).[j] = [^#2,^#0,^#1].[j]`。
  路线：先 `rw [show [^#2,^#0,^#1] = (^#2) ∷ ((^#0) ∷ ((^#1) ∷ 0)) from rfl]`
  与 `show (3:V) = 2+1 by norm_num`，再用
  `termSubstVec_cons` 拆成 `^#2 ∷ termSubstVec 2 (QvecV (mm+2)) [^#0,^#1]`，

  + `nth_QvecV_lt (mm+2) _`（界由 `hn3 : 3 ≤ mm+2` 得）。

  **坑（本会话实测）**：
  * `hw` 的 `n` 与 `m` 都是 `mm+3`（`QvecV (mm+2)` 长度 `mm+3`、层数 `mm+3`）；
  * `hv` 层数必须是 `mm+3`（不是 `mm+2`）——`substs_substs` 要求内外层数一致；
  * `rfl` 不能证 `len (^#2 ∷ ^#0 ∷ ^#1 ∷ 0) = 3`，要用 `nth_ext'` 或 `norm_num`；
  * `nth_termSubstVec` 要的是 `IsUTermVec`，`IsSemitermVec` 要先 `.isUTerm`。
* `subst_QvecV_conjunct`：`conjunct` 的代入版（对应 `shift_conjunct`）。

## 4. 不要重复的弯路

* **不要**尝试"同索引 `iT`/`subst` 交换"的等式形式——已三轮反例证伪并机器化。
* **不要**把 `QvecV` 写成语言参数化的单一定义——Foundation 的 `termBShiftVec`
  是逐语言的 `TermRec.Construction`，两语言版本只是**命题**相等；
  本分支采用"逐语言两份"（`qqVecsS`/`qqVecsO`），代价小、可控。
* **不要**在 blueprint 的 `succ` 子句里写 `!(qVecGraph L) y ih`——
  elaboration 会爆炸（数分钟不返回）；**内联 graph 本体**即可（~3 秒）。
* 内联后**仍需**给 `QvecV` 补 `Γᴬ_[m+1]-Function₁` 层级实例，
  否则 `definability` 在 `pi1_structural_induction` 上会卡住
  （先例：`shiftVec`、`disjSeqSubst`）。
