### ★ V 层算术的两个坑（**必读**）

1. **`m + 1 + 1` 不是 definitionally `m + 2`**（V 是任意模型，`2` 是字面量）。
   所有涉及 `m+2`/`m+3`/`m+4` 的目标都必须用显式
   `show ... by ring` 转换，或统一写成 `(m+1)+1` 形式。
   `ring` 能证等式，但**不能**在 `rw`/`exact` 里自动归一化。
2. **V 层没有 `omega`**：`m + 1 ≠ 0` 这类要手工推
   （`lt_add_one m` + `not_lt_of_ge zero_le`）。

## 3. 剩余：`iT_subst_open` 的归纳

### 3.1 归结到的核心引理 (★★)

对层 `m+1` 的项 `t`，以及满足
* `Vw.[0] = Ww.[0]`
* `k < m → Vw.[k+1] = Ww.[k+1]`
* `Ww.[m+1] = ^&0`

的项向量 `Vw`（长 `m+1`）、`Ww`（长 `m+2`）：

```
subst Vw (iVE m (termSubst (QvecVOr m) t)) = subst Ww (iVE (m+1) t)
```

**用途**：rel 支的 `conjunct` 部件（`Vw = ^#j ∷ shiftVec 2 m`、`Ww = ^#j ∷ shiftVec 2 (m+1)`）
与 func 支的 `ve2` 部件（`Vw = termSubstVec … (qVec² Vw₀)` 同形状）都归约到此。

### 3.2 归纳谓词的 definability（**关键，已机器核验可过**）

```
𝚷ᴬ₁-Predicate (fun t : V ↦
  ∀ Vw Ww : V, (∀ k ≤ m, Vw.[k] = Ww.[k]) →
    subst ℒₛₑₜ Vw (iVE m t) = subst ℒₛₑₜ Ww (iVE (m + 1) t))
```

**definability 通过**（探针实测）。要点：把向量关系作为**假设**（`∀ k ≤ m, …`），
不要让它在谓词里被**计算**（`Vw.[k] = ^#k` 那种形状 definability 会失败）。

### 3.3 func 支的向量变换

`ve2` 的体在 `qqAlls … 2` 下，`subst` 下降两层：
* 从 `Vw` 得 `Vw₁ := termSubstVec (m+1) (qVec² Vw) (^#i ∷ shiftVec 3 m)`
* 从 `Ww` 得 `Ww₁ := termSubstVec (m+2) (qVec² Ww) (^#i ∷ shiftVec 3 (m+1))`
* **关系在变换下保持**（待证：三条件逐项核验）

## 5. 给下一会话的提醒

1. **`definability` 的陷阱**：谓词里的向量关系必须是**假设**形式
   （`∀ k ≤ m, Vw.[k] = Ww.[k]`），不能是计算形式（`Vw.[k] = ^#k`）。
   前一份交接文档记录的"definability 绕不过去"是针对后一种形状的——**换形状即可**。
2. **V 层没有 `omega`**：所有算术要用 `lt_add_one`/`add_lt_add_right`/`ring` 手工推。
   `add_lt_add_right` 在 V 层给的是 `1 + j < 1 + n` 形式，需要 `ring` 转换。
3. **`nth_termSubstVec` 的第一个向量参数是「被代入的」**：
   `(termSubstVec k w ts).[i] = termSubst w ts.[i]` —— `ts` 是第二个。
4. 核验必用独立重编译（`verify-openhb.sh` 已是 31 文件版本）。
