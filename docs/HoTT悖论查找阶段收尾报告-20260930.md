# HoTT 悖论查找：第一阶段收尾报告

> 2026-09-30。写作：Claude（Claude Opus 5.5），本机 Claude Code 会话 `eadb3381`，按研究发起人的要求。【原话】“把所有该做的，全部做完，我认为我们要阶段性地收尾HoTT悖论查找工作了，因为我们很可能已经找到了。”
>
> 身份：标【原话】的是研究发起人的话；标【证明】的是有范围的机器证明（Cubical Agda 2.8.0 与 cubical 0.9；Lean 4.34.0），各有运行收据与精确重放；其余是 AI 的整理、解释与判断。本报告**不**宣称 HoTT 不一致。

## 0. 一句话

两个东西是不是同一个，本来是一句话的事。HoTT 为了省事，规定同构的就是同一个（单价性）；又为了普适，让任意高维的形状在宇宙里一次齐备（高阶归纳类型）。于是在它的宇宙里，“是同一个”永远了结不了：每一层都确定地还有下一层。研究发起人把这称为 HoTT 的非现实性悖论，形状与芝诺相同，并判断“我们很可能已经找到了”。

## 1. 我们在找什么

- 研究发起人从一开始就说：要找的不是 HoTT 内部的矛盾，而是理论的非现实性。最优雅的结果，是“Think in HoTT”之后出现一个现实里根本不存在的“无法完成的困难”（【原话】KC-000010）。
- 两类：现实中能完成、理论中却无法完成；现实中无法完成、理论中却绕过 ASK 当作已完成（【原话】KC-000022）。
- 方法：理论为了经济性与普适性做的非现实抽象，是反证法里要回头审的前提；找悖论要瞄准这样的前提，不要蛮干（【原话】KC-000047、KC-000048）。
- 2026-09-30，研究发起人给出了可操作的定义（【原话】KC-000054）：

> `UR`=`本来应该很简单的事情，甚至在X理论中，都做不到`，我想这就是一种类似芝诺悖论的`不合理`。

  “现实”指前半句，也就是本来应该很简单的事情；“悖论”指整句 UR。判定者是一眼看过去的人。
- 同日：项目目标始终是寻找 HoTT 的非现实性悖论，不再加“存在性”作定语（【原话】KC-000053）。

## 2. 找到了什么

**那件本来很简单的事**：确认两个东西是不是同一个。

**专门碰它的过程**：写一个逐层追问的程序，问“这份目录里的相同，到第 k 层了结了没有”（技术上：它是不是 h-层 k+1 的类型）。答“否”就问下一层，答“是”就停并报出层数；每一问都由判定器给出带证明的“是”或“否”。

**结果**【证明】：

| 情形 | 同一个追问的结局 | 命题 |
|---|---|---|
| 相同是事实（Lean，UIP） | 宇宙第 1 问停 | CG001-C-80 |
| HoTT，集合的目录 | 第 2 问停 | CG001-C-79 |
| HoTT，h-层 1+n 的类型的目录 | 恰好第 1+n 问停 | CG001-C-79 |
| HoTT，同一乘积、成员高度封顶 b | 恰好第 2+b 问停 | CG001-C-82 |
| HoTT，不是宇宙的乘积 ∏ₙ K(ℤ,n+1) | 永不停：对任何判定器，程序等于 `never` | CG001-C-81 |
| HoTT（含高阶归纳类型），宇宙 | 永不停：对任何判定器，程序等于 `never` | CG001-C-75、CG001-C-78 |
| HoTT，集合截断 | 第 1 问停；但截断把 Bool 与自己相同的两种方式合成一种，且解码不回宇宙 | CG001-C-83 |

程序本身、它“停机当且仅当有某个有限层”的刻画与精确停机时刻，是 CG001-C-77；三级阶梯与一般 n 的总体上升，是 CG001-C-71、C-73、C-74、C-76，另有 Kraus–Sattler 定理 5.9、5.10 的重放。

**芝诺的对位**：

| | 芝诺 | HoTT |
|---|---|---|
| 本来很简单的事 | 从这里走到那里 | 确认两个东西是不是同一个 |
| 理论为了好用改掉的条件 | 位置可以无限细分 | 相同可以无限细分 |
| 每一步看到什么 | 还剩一半，确定没到 | 这一层还没了结，确定的“否” |
| 结局 | 永远走不完 | 程序等于 `never` |
| 推理 | 没问题 | 没问题，而且经过内核检查 |
| 教科书消解 | 极限 | 截断 |
| 消解靠什么 | 一条定义把“走到了”宣布回来 | 一个构造子把“相同是事实”宣布回来 |

## 3. 为什么说“很可能找到了”

- **形状对**：第一类悖论。现实（相同是事实的世界）里一问就了结，HoTT 里永远了结不了（KC-000022）。它的“做不完”与芝诺同一种：每个有限阶段都确定未到达，指定的程序不停止。它不是“每层做得到、缺统一方法”那一种（扩展认知 003 区分过这几种“无法完成”）。
- **有靶**：各个对照专门碰被怀疑的前提，每次只改一处：
  - 相同换成事实，第 1 问停；
  - 高度封顶，在封顶处停；
  - 换成截断，第 1 问停，但对象已经换了（KC-000048）。
- **推理经得起检查**：永不停是 HoTT 里的内部定理，不是“跑了很久没停”；C-77 至 C-80 在 Linux 与 macOS 两个平台重放一致。
- **判定者**：按 UR 的定义，“不合理”由一眼看过去的人判定。研究发起人读完证据后说：【原话】“其实看了你捕捉到的HoTT的内容，我已经闻到了这种`不合理`的味道。”

## 4. 归因：被改掉的是哪个条件

- 候选前提：
  - 单价性：同构即相同，收益是经济；
  - 高阶归纳类型：任意高维一次齐备，收益是普适；
  - Π 的一次交出；
  - 宇宙是被追问的对象；
  - 解释桥：追问所承接的任务；
  - 现实侧前提：相同是一次检查的事实。
- 区分证据：
  - 把“相同是结构”换成事实，就停；
  - 高度封顶，就停；
  - 换成普通乘积（不是宇宙），仍然永不停，所以宇宙不是必要条件；
  - 封顶的乘积也是一次交出，却停了，所以 Π 的一次交出不是充分条件。
- 【判断】（条件于研究发起人对任务的认定）：首先要审单价性，其次是高阶归纳类型。同样高维的形状在经典数学里也有（这个乘积的同伦群在每一维都是 ℤ，来源级），变的是“相同”指什么。反证法只否定合取的整体，所以这是排序，不是唯一的被告。
- 最强的反解释是“换题”：对集合截断发问，第 1 问就停。回应：截断回答的是“有几个分支”，对象已经换了，而且回不去（CG001-C-83）。这与当年“另记一本账算不算完成”是同一类问题；研究发起人以 UR 回答了“现实一侧是什么”，就是那件本来简单的事。
- 两向分工：书式 HoTT 里的现象是 A 向（KC-000052）；修复里凭定义宣布完成，是 B 向，也就是罗素式的那一面（KC-000050、KC-000051）。

## 5. 它不是什么

- 不是 HoTT 的内部矛盾。所有推理都在 HoTT 里被机器接受。
- 数学事实大多不新：这类乘积没有有限层，是 HoTT Book 的例 8.8.6。宇宙本身，书里写的是预计可以证明它不是任何 n-型、但尚未做出（§8.8 末尾）；Kraus–Sattler 2015 证明了单价宇宙层级里的第 n 个宇宙不是 n-型（不用高阶归纳类型）。含高阶归纳类型的单个宇宙对一切 n 都不是 n-型，本仓库有机器证明（C-75）；此后的文献里有没有公开证明，交文献查重。新的主要是读法，以及它所指向的前提。这一读法也还没做过文献查重。（2026-09-30 回源更正：初稿写“宇宙和这类乘积没有有限层，专家早就知道”，对宇宙一侧说过了头。）
- 不是“在一切情况下”：它出现在宇宙与高度无界的对象上。但宇宙不是边缘情形：它是单价性所说的那个对象，也是 HoTT 不能拒绝的论域元素（KC-000050）。
- “永不停”读成现实执行时，需要理论一致性与对闭判定器的典范性（元层）；立方类型论有立方集合模型（来源转述）。

- **解释有没有加码？**

  - 归因排序是条件式判断；
  - 经典同伦的对照是来源级；
