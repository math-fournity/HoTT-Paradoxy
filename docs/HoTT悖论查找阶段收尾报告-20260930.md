## 0. 一句话

两个东西是不是同一个，本来应该是个简单问题。HoTT 为了省事，把结构相同的东西当成同一个（单价性）；又为了让同一套理论容纳更多几何，把圆周、球面和任意高维形状都放进理论里（高阶归纳类型）。两项设计合在一起后，“它们到底是不是同一个”会一层接一层地追问下去，在这里没有有限的最后一层。研究发起人把这读作与芝诺相似的非现实性悖论，并判断“我们很可能已经找到了”。

## 1. 我们在找什么

- 研究发起人从一开始就说：要找的不是 HoTT 内部的矛盾，而是理论的非现实性。最优雅的结果，是“Think in HoTT”之后出现一个现实里根本不存在的“无法完成的困难”（【原话】KC-000010）。
- 两类：现实中能完成、理论中却无法完成；现实中无法完成、理论却跳过“先问这件事是否有根据、能否完成”，直接当作已完成。这一步在研究材料里简称 ASK（【原话】KC-000022）。
- 方法：理论为了省事、让一套方法能用在更多地方，会简化或理想化某些条件。研究要问：是否有一件事恰好依赖被改变的条件，让这种变化显出后果？这比漫无目标地枚举例子更有针对性（【原话】KC-000047、KC-000048）。
- 2026-09-30，研究发起人给出了可操作的定义（【原话】KC-000054）：

> `UR`=`本来应该很简单的事情，甚至在X理论中，都做不到`，我想这就是一种类似芝诺悖论的`不合理`。

  “现实”指前半句，也就是本来应该很简单的事情；“悖论”指整句 UR。判定者是一眼看过去的人。
- 同日：项目目标始终是寻找 HoTT 的非现实性悖论，不再加“存在性”作定语（【原话】KC-000053）。

## 2. 找到了什么

**那件本来很简单的事**：确认两个东西是不是同一个。

**专门碰它的过程**：写一个逐层追问的程序：“这些东西之间的‘相同’，到第 k 层是否已经说清？如果还没有，就接着问更高一层。”每层都有一条带证明的规则回答“是”或“否”；数学上，这对应于检查对象是否属于某一层的 h-level。可以先把 h-level 理解为描述“相同关系还有几层”的标准数学语言，精确定义见 `CLAIMS.md` 和相应证明文件。答“是”就停并报出层数。这个程序是我们用来检验读法的精确模型，不等于已经完整形式化了研究发起人的圆环原案。

**结果**【机器核验】：下表保留了数学对象和命题编号，供专业读者复核。Lean/UIP 是把“相同”当作普通事实的对照；`never` 表示程序不会在任何有限步给出最终答案。

| 情形 | 同一个追问的结局 | 命题 |
|---|---|---|
| 相同是普通事实（Lean，UIP） | 宇宙第 1 问停 | CG001-C-80 |
| HoTT，装所有集合的目录 | 第 2 问停 | CG001-C-79 |
| HoTT，h-层 1+n 的类型的目录 | 恰好第 1+n 问停 | CG001-C-79 |
| HoTT，同一乘积、成员高度封顶 b | 恰好第 2+b 问停 | CG001-C-82 |
| HoTT，不是宇宙的乘积 ∏ₙ K(ℤ,n+1) | 永不停：对任何判定器，程序等于 `never` | CG001-C-81 |
| HoTT（含高阶归纳类型），宇宙 | 永不停：对任何判定器，程序等于 `never` | CG001-C-75、CG001-C-78 |
| HoTT，集合截断 | 第 1 问停；但截断把 Bool 与自己相同的两种方式合成一种，且解码不回宇宙 | CG001-C-83 |

程序本身、它“停机当且仅当有某个有限层”的刻画与精确停机时刻，是 CG001-C-77；三级阶梯与一般 n 的总体上升，是 CG001-C-71、C-73、C-74、C-76，另有 Kraus–Sattler 定理 5.9、5.10 的重放。

**芝诺的对位**：

| | 芝诺 | HoTT |
|---|---|---|
| 本来很简单的事 | 从这里走到那里 | 确认两个东西是不是同一个 |
| 理论为了好用改掉的条件 | 位置可以无限细分 | 相同可以无限细分 |
| 每一步看到什么 | 还剩一半，确定没到 | 这一层还没了结，确定的“否” |
| 结局 | 永远走不完 | 程序等于 `never` |
| 推理 | 没问题 | 没问题，而且经过内核检查 |
| 教科书消解 | 极限 | 截断 |
| 消解靠什么 | 一条定义把“走到了”宣布回来 | 一个构造子把“相同是事实”宣布回来 |

## 3. 为什么说“很可能找到了”

- **形状对**：第一类悖论。现实（相同是事实的世界）里一问就了结，HoTT 里永远了结不了（KC-000022）。它的“做不完”与芝诺同一种：每个有限阶段都确定未到达，指定的程序不停止。它不是“每层做得到、缺统一方法”那一种（扩展认知 003 区分过这几种“无法完成”）。
- **有靶**：各个对照专门碰被怀疑的前提，每次只改一处：
  - 相同换成事实，第 1 问停；
  - 高度封顶，在封顶处停；
  - 换成截断，第 1 问停，但对象已经换了（KC-000048）。
- **推理经得起检查**：永不停是 HoTT 里的内部定理，不是“跑了很久没停”；C-77 至 C-80 在 Linux 与 macOS 两个平台重放一致。
- **判定者**：按 UR 的定义，“不合理”由一眼看过去的人判定。研究发起人读完证据后说：【原话】“其实看了你捕捉到的HoTT的内容，我已经闻到了这种`不合理`的味道。”

## 4. 归因：被改掉的是哪个条件

- 候选前提：
  - 单价性：同构即相同，收益是经济；
  - 高阶归纳类型：任意高维一次齐备，收益是普适；
  - 把“对每种输入都要做的操作”一次性交给理论使用者（数学家用 Π 类型来表示这种能覆盖所有输入的函数）；
  - 宇宙是被追问的对象；
  - 对应关系：我们设计的逐层追问，是否真在问研究发起人说的那件简单事——“两个东西是不是同一个”；
  - 现实侧前提：相同是一次检查的事实。
- 区分证据：
  - 把“相同是结构”换成事实，就停；
  - 高度封顶，就停；
  - 换成普通乘积（不是宇宙），仍然永不停，所以宇宙不是必要条件；
  - 高度有上限的乘积也同样是一次交出，但程序会停；因此，“一次把所有输入交给理论”本身不足以解释永不停。
- 【AI 的解释性判断】（以研究发起人所说的“那件简单的事”为前提）：优先检查“同构的东西可以当作同一个”这条规则（单价性），再检查任意高维形状都能放进同一套理论的做法（高阶归纳类型）。高维形状本身并非 HoTT 独有：所用乘积在每一维的同伦群都是 ℤ；这是已有数学来源报告的背景事实，本项目没有为这句话另做机器证明。当前判断是，值得优先检查的差异可能在“相同”具体指什么。两项选择共同参与结果，因此这只是调查顺序，不是已经找准唯一原因。
- 最强的反解释是“换题”：对集合截断发问，第 1 问就停。回应：截断回答的是“有几个分支”，对象已经换了，而且回不去（CG001-C-83）。这与当年“另记一本账算不算完成”是同一类问题；研究发起人以 UR 回答了“现实一侧是什么”，就是那件本来简单的事。
- 两种方向要分开：这里讨论的是“现实里能做、理论里却问不完”；另一种问题则是“现实里还没做完，理论却把它当作已交付”。后者可以与用户的罗素式分析比较，但不因此成为本报告已证明的同一机制（KC-000050–000052）。

## 5. 它不是什么

- 不是 HoTT 的内部矛盾。所有推理都在 HoTT 里被机器接受。
- 数学事实大多不新：这类乘积没有有限层，是 HoTT Book 的例 8.8.6。宇宙本身，书里写的是预计可以证明它不是任何 n-型、但尚未做出（§8.8 末尾）；Kraus–Sattler 2015 证明了单价宇宙层级里的第 n 个宇宙不是 n-型（不依赖高阶归纳类型）。通俗地说，n-型是“相同性结构到 n 层为止”的技术分类。含高阶归纳类型的单个宇宙对一切 n 都不是 n-型，本仓库有机器证明（C-75）；此后的文献里有没有公开证明，仍待查。新的主要是读法，以及它所指向的前提；这项读法也还没有做过文献查重。（2026-09-30 回源更正：初稿写“宇宙和这类乘积没有有限层，专家早就知道”，对宇宙一侧说过了头。）
- 不是“在一切情况下”：它出现在宇宙与高度无界的对象上。但宇宙不是边缘情形：它是单价性所说的那个对象，也是 HoTT 不能拒绝的论域元素（KC-000050）。
- “永不停”首先是理论内部的证明。要再把它读成“现实电脑照此运行也永远不会结束”，还要假设理论本身没有矛盾（一致性），并假设理论对封闭计算的推理能对应预期的执行行为（典范性）。这些额外条件不是本报告证明的内容；立方类型论有立方集合模型则是来源材料报告的事实。

## 6. 另外几条线：它们不是本报告的结论

“无穷相干”是项目 AI 提出的另一条芝诺式候选，不是研究发起人 2026-09-27 所说“芝诺悖论的幽灵”的对象。它的有限层例子已经写出并检查；能否用一个定义一次涵盖所有层级，仍是开放问题，不能说已经证明做不到。

运动测量、状态是否相同、往返计步等其他话题也有各自的问题，其中部分具体判断仍等待研究发起人裁定；本报告没有重新判断它们。圆环原案能否被当前 HoTT 形式化忠实表达，也仍未解决；某个复原模型与 Markov 原则（一个关于搜索与存在性的逻辑原则）之间是否有可靠的对应，同样还是猜想。更广泛地检查 HoTT 还有哪些未覆盖的理论选择，是另外一项工作；本报告不宣称已经检查完整个理论。

## 9. 怎样理解文中的不同说法

本报告把三件事分开：研究发起人说“很可能已经找到了”，这是研究者的判断；证明器接受了表中的命题，这是有范围的数学证据；把这些命题读作现实相对的悖论，则是需要继续讨论的解释。命题编号和文件名只帮助读者找到证据，不能把其中一种说法自动升级成另一种。

原始对话和完整研究工作记录留在 `dev`，不属于这个面向读者的结论与证据包。当前发布包含什么、哪些过程材料留在 `dev`，见 [main README 的第 9 节](https://github.com/math-fournity/HoTT-Paradoxy/blob/dev/README.md)；形式命题与证据入口见 [`CLAIMS.md`](../CLAIMS.md)。
