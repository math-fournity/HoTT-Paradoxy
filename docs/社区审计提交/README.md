## 三份稿子共同的边界

- 都**没有**说 HoTT 不一致。这里的"问题"指理论对现实的非现实，不是内部矛盾。
- 每条结论都标了身份：用户原话、数学事实（附运行收据）、元层推论、来源转述、判断。
- 所引的全部文档与代码，都给出了仓库内的路径。
- 归因（是哪个前提的问题）在每份稿子里都是正题：写清候选前提、竞争归因、能区分它们的证据、判断和它的身份（用户 2026-09-24 的修正）。
