## 1. 直接结论

**卡在模型内部的证明搬运，不是 Lean 环境，也不是哥德尔第二定理本身没有机器证明。**

已经会把标准算术公式翻成集合论公式，也有显式可证性谓词、D1、D2、Σ1 性以及标准模型 ℕ 中的 D3。没有完成的是：在任意、可能非标准的 IΣ1 模型 V 中，把它手里的证明编码合法地变成 ZFC 证明编码。

“只剩一条引理”是接口上的集中，不是剩余工作已经小到一条补丁。现有路线至少还有两块必须先解决的设计内容：

1. **推导归纳的不变量缺少开放变量的定义域保护；**
2. **Craig 公理的选定枚举表示与显式 ZFC 证明证书之间，尚无所需的一般模型内部桥。**

随后还有一般内部码的否定、位移、项值代换与量词推导等实现义务。仅填旧骨架的几个占位不能视为有保证的收尾方案。

## 2. 终目标与已证范围

令 `τᵗ = arithTrln.translate τ`。真正待支付的是：


## 3. 第一块设计瓶颈：现有归纳不变量不是完整的内部解释合同

### 3.1 旧 P 用错了编码类别

[ShCraigElimSetup:40、61–101](../../../../HoTT/formal/claude-cg001/godel-q-zfc-z0-full/GodelQ/ZFC/ShCraigElimSetup.lean:40) 的模板取：

`P d := Provable ZFC (translateSeq (fstIdx d))`。

但 `translateSeq` 输出的是 **sequent 位集码**，`Provable` 接收的是 **单公式码**。证明这个 P 是 Σ1，并不证明它表达了正确的不变量。

后来 [ShCraigElimPredicate:65–73](../../../../HoTT/formal/claude-cg001/godel-q-zfc-z0-full/GodelQ/ZFC/ShCraigElimPredicate.lean:65) 已改出类别正确的：

`Q d := Derivable ZFC (translateSeq (fstIdx d))`。

两条已证规则用的是 Q。但旧总骨架仍用 P，十条规则仍全部是占位。P 与 Q 不是任意 sequent 上的同义写法；只有最终 singleton sequent 的 `Derivable T {φ} ↔ Provable T φ` 可以用于收尾。

### 3.2 把 P 改成 Q 还不够：自由变量必须受定义域保护

内部公式层数 `n=0` 限制的是绑定变量，不排除自由变量。全称规则会引入自由变量；存在规则的项也可以含自由变量。

算术被解释在集合论模型的 ω 内。Foundation 的翻译正确性只保证**自由变量赋值也在解释域内**时成立：其参数明确是 `ε : ξ → π.Model M`，不是任意 `ξ → M`。见 [Interpretation:227–230、277–297](../../../../Z0-D3-攻关包-最小完整版/05-源码/Foundation/FirstOrder/LK/Interpretation.lean:227)。

当前 Q 对所有开放 sequent 直接裸译，没有加入这些自由变量的域内假设。这需要先审清，而不能承诺“更换谓词后逐规则即可填完”。

**源码语义诊断（未作为新定理机器证明）**：正原子翻译是“对所有域内项值，如果这些值确实是各项的值，则关系成立”。若自由变量取到 ω 外，项值前件可能无解，使正原子真、它的否定假。因此普通开放公式的全称实例化不能不加条件地照搬。可考察源逻辑有效式 `(∀x ¬(x<x)) → ¬(a<a)`，把自由变量 a 赋为域外集合值：域内无自成员，但域外 a 的正原子翻译可能空真，否定为假。

这里没有宣告一个新的“Q 不可证”机器定理，也没有否定闭句版 `ShCraigElim` 或最终 D3。结论是：**先设计带自由变量域保护的内部推导不变量，并证明护罩的可定义性与规则搬运；在最终闭句处再去掉护罩。**

另外，算术项经 `iVE` 翻成的是描述其值的公式，不是集合语言的项。因此 `exs` 不能把 `iT 0 t` 当作一个目标项直接代入。见 [InternalTranslate:158–173、197–200](../../../../HoTT/formal/claude-cg001/godel-q-zfc-z0-full/GodelQ/ZFC/InternalTranslate.lean:158)。

## 4. 第二块设计瓶颈：Craig 公理的内部证书从哪里来

`Sh := {σ | ZFC ⊢ σᵗ}` 是外部可证性的算术影子。`Sh.RE` 证明该集合可枚举，但 Foundation 随后生成的 `Sh.reCh` 不是显式 `trProv`：

- `Theory.RE` 只存外部 RE 性质；[Theory:25–26](../../../../Z0-D3-攻关包-最小完整版/05-源码/Foundation/FirstOrder/Arithmetic/Bootstrapping/Syntax/Theory.lean:25)。
- `reCh` 用 `codeOfREPred (encode '' Sh)`；[CraigTrick:98–109](../../../../Z0-D3-攻关包-最小完整版/05-源码/Foundation/FirstOrder/Arithmetic/Bootstrapping/Syntax/CraigTrick.lean:98)。
- 下层 `codeOfPartrec'` 通过 `Classical.epsilon` 选择代码，选择条件只约束其 **ℕ 上的语义**；[Representation:268–277](../../../../Z0-D3-攻关包-最小完整版/05-源码/Foundation/FirstOrder/Arithmetic/R0/Representation.lean:268)。
- `codeOfREPred_spec` 也明确只对 `x : ℕ`；[Representation:347–359](../../../../Z0-D3-攻关包-最小完整版/05-源码/Foundation/FirstOrder/Arithmetic/R0/Representation.lean:347)。

**在 ℕ 中表示同一个集合，不自动意味着 IΣ1 能证明两公式等价。** `code_uniq` 只说同一个固定程序码的输出唯一，不能把两个外部等价的程序变成内部可证等价。

正确限缩：Δ1 公理表示已有“任意 V 对标准引号公理码识别正确”的引理，不是所有模型内部识别都毫无保证。问题在于推导归纳中可能出现**非标准中间公理码与非标准枚举见证**。

Craig 公理支拿到的是：`p = q ⋏ weight(s)`，模型 V 满足 `Sh.reWitness(s,q)`，其中 s、q 都是 V 元素。现成 `reWitness_spec` 只连回同一 `Sh.reCh`；还需要诸如：

`V ⊧ Sh.reCh(q) → Provable ZFC (iT 0 q)`

的受控内部证书桥，及非标准 padding 的推导处理。不能用仅在 ℕ 层的 `mem_craig_codes_iff` 抽出一个标准句子替代 q。

**现接口没有保证这条桥；本次也没有证明它对具体选定代码为假。** 因此应先判断如何支付它，而不是把 `axm` 当作“最后读一下 CraigTrick 就能补”的小 case。可评估显式带 ZFC 推导证书的 Craig 公理化，或采用固定明确的算术公理化／翻译 Σ1 完全性路线，以避免依赖任意选定的枚举程序；这些是建议，不是已证替代方案。

### 8.1 值得先核查的更短完成门：只支付 Gödel 句上的局部 D3

本次全文阅读 Foundation 的抽象第二定理发现，其证明体只在 `G := gödel zfcTr` 上使用一次 D3（[Basic:246–263](../../../../Z0-D3-攻关包-最小完整版/05-源码/Foundation/FirstOrder/Incompleteness/ProvabilityAbstraction/Basic.lean:246)）。因此，若目标只是不证明 Con(ZFC) 的最终 Z0，而非交付通用 D3／完整内部解释定理，可以评估先写局部化第二定理：只要求 `IΣ1 ⊢ B G → B(B G)`；已有 `fwd G : B G → P(B G)`，剩下只需 `P(B G) → B(B G)` 的特例。

**这是实际源码依赖支持的设计机会，不是已经完成的新机器证明。** 现有 `con_unprovable`／`Z0Full` 接口仍要求完整 HBL3；局部化接口及终局接线需新建源码、过核与收据。它也不自动解决该特例的内部证明证书来源。但它说明：不应把“完成全部标准句子的 ShCraigElim”说成最终 Z0 的已证必要条件。建议下一单元先比较局部完成门与完整解释合同的代价，再明确是否需要通用的全部推导搬运。

**这不是要求重启整个研究，也不是工具有限所以停下。它是把已经找准的目标，换成不会遗漏定义域与证书来源的真正可执行证明合同。**

若“完整”指所有更强研究目标，还应保留其他章节自己写明的开放边界：同一个 Q 的完整合同等同未做、Agda 中 Z0 仍为参数、部分解释与现实执行之间的元层桥未形式化。八方向来源包覆盖闭合，不等于这些更强目标都被证明。本次实际内核重放聚焦 Z0/W8，不重审其他全部线路。
