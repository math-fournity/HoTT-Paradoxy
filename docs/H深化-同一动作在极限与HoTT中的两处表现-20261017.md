### 1.1 第二轮深化（同日稍后）：终局读法 vs 过程读法

> 你知道我觉得问题可能是在这里：在极限或者说芝诺悖论那一侧，H之所以没有造成问题，
> 因为极限那里关注的是一头一尾，或者说是终局。但是在HoTT这边，考虑、考察，或者说
> 计算的不仅仅是一头一尾，而是过程中的内容，是HoTT要求回答的，一旦一个无限的过程
> 中的内容需要被回答（计算），而理论不仅仅只是关心这个过程的终局，那么H的问题，
> 就会成为这个理论（HoTT）的麻烦 —— 但是却不会成为极限理论的麻烦，因为它只考虑
> 总局，所以它没有成功地将H的问题，充分暴露出来。

〔我们的分析〕见 §4.1。

## 2. 〔我们的分析〕H 的精确刻画

**H ≡ 「宣布完成，而不支付该完成对应的构造」。**

| | 极限侧（ZFC/经典分析） | HoTT 侧 |
|---|---|---|
| 要完成的东西 | 无穷过程的结果（和/极限值） | 同一性判断（"是不是同一个"的答案） |
| 完成的操作 | **命名/定义**：级数的和 := 部分和的极限 | **截断**：压掉同一性的层次 |
| 操作性质 | **保守扩张**——不改变论域中任何已有对象 | **非保守**——从 A 到 ‖A‖ 一般不是等价，改变对象 |
| 实例语句 | `∑2⁻ⁿ = 1`：其中"lim sₙ = 1"是定理，"和 := lim"只是命名——完成感来自**命名**，不来自证明 | "相同是事实，第 1 问就停"——截断后对象已换（「再也变不回原来的宇宙」） |
| 底层"相等"结构 | **平坦**（a = b 是无层次命题）→ "完成"无结构可承载 → 命名即足，代价为零 | **分层**（同一性类型本身是类型）→ "完成"必须支付层次，付不完 |
| 命运 | H 免费兑现：想要的结果拿到，系统内无冲突 | H 二择一：保持对象→永不完成；宣布完成→对象已换 |

**"同一个 H、表现不同"的机制**：README §6 已诚实标注两处**形式上是两条不同的原则**（HoTT
那条不用排中律）。〔我们的分析〕这个差异不是 H 的分裂，而是**实例参数**：底层相等结构不同
（平坦 vs 分层），同一个"宣布完成"操作落在两种土壤上，长出两种命运。

## 3. 〔我们的分析〕为什么"强制完成"在 HoTT 中不可能（回答核心提问）

不是字面不可能（截断是合法构造，做得到），而是**两个断言的合取不可满足**：

> （对象不变）∧（宣布完成）——在 HoTT 中不可满足。

因为同一性的层次**就是对象的一部分**（机器已证的 README §4 事实：真/假类型与自己对照有
"原样"和"对调"两种方式，沿对调运输"真"得到"假"；问"以哪些方式相同"一层之上还有一层）。
宣布完成只能靠截断，而截断改变对象。**没有第三条路。**

对照：极限侧该合取**可满足**，代价为零——因为 ZFC 的相等是平坦的，"完成"没有结构承载，
**命名就够了**。"改名字"与"改对象"之差，就是两处命运之差。

## 4. 〔我们的分析〕"不明显"vs"无法忽视"（观测层论证）

- 极限的观测方式 = **逼近**（ε-δ 即"对任意有限精度"）。H 的缺陷恰好是"任何有限精度下
  不可见"（每步都没到，但每步都在精度内）——与观测方式**正交** → 不明显。
- HoTT 的观测对象 = **同一性判断的完成本身**。H 的缺陷恰是观测对象 → **无法忽视**。

**"超越"的精确含义**：不是 H 恶化，而是观测条件让 H 从"不可观测的妥协"变成"可检测的障碍"。
度量口径：以**可检测性**计，HoTT 侧严格强（有定理级检测）；以**H 的存在性**计，两侧同一个 H。

**推论（值得记录的强表述）**：**HoTT 不是"更严格的数学"，而是把 H 变成可观测对象的
第一台仪器**——这为"为什么 2400 年来没人这样看它"提供一个结构性解释。

### 4.1 〔发起人原话→我们的分析〕终局读法 vs 过程读法（2026-10-17 第二轮深化的精确化）

发起人第二轮观点（§1.1 原话）把 §4 的"观测方式正交"推进为**问题域选择**：极限理论
的问题域只有终局（一头一尾），过程内容不在回答义务里，所以 H 藏得住；HoTT 的问题域
包含过程内容本身且被要求回答（计算），H 无处可藏。〔我们的分析〕精确化：

| | 极限侧（ZFC/经典分析） | HoTT 侧 |
|---|---|---|
| 理论要求回答的问题 | **终局问题**：lim sₙ = L？ | **过程问题**：第 k 层的"相同"是什么？ |
| 问题的逻辑形式 | ∀ε∃N∀n≥N —— **∃N 把有限前缀整个装箱丢弃** | Ω 层级逐层递归连接，**没有跳层算子** |
| 过程内容的地位 | 可丢弃信息（终局问题不含它） | **对象的组成部分**（路径=过程，层在对象里，§2） |
| 典范性义务的范围 | 公式典范形式有限；`∑2⁻ⁿ=1` 是一条有限语句，谈无穷序列不产生逐项计算义务 | 闭项须计算到典范形式；路径的每一层都是类型、都有计算义务（canonicity，元定理） |
| H 的表现 | 终局断言**可满足** ⇒ H 不可检测 | 过程断言逐层确定为"否"（C-75）⇒ H 显形为永不停 |

**三层机器对接**（均〔机器已证〕，范围以各包 `CLAIM.md` 为准）：

1. **C-112 (d)：两种读法是同一事实的两面**。`arrivesOfNever`（永不落定 ⟹ 跑者到达）
   与 `neverOfArrives`（**单调时**，跑者到达 ⟹ 永不落定）；`monotoneNeeded`（单调前提
   不可去，负控制 NEG-003 以交替追问证伪无前提版）。终局读法（Arrives：对每个精度
   2⁻ᴷ，剩余距离终将不超过）与过程读法（Never：追问逐层答否）在单调条件下**等价**。
   这正是"同一个 H"的内核形式：**极限理论读到 Arrives 面（H 无害——它就是收敛性
   本身），HoTT 被迫读 Never 面（H 显形为永不停机的追问）。H 是同一个，读法是理论的
   选择。**这是"同一个 H、表现不同"目前最深的一条机器证据。
2. **C-113 (a)：芝诺实例两面并存**。永不落定的追问 ∧ 跑者每阶段减半剩余 2⁻ⁿ 并且
   **到达**——H 的无害面（到达）与显形面（永不落定）在**同一个实例**中同时成立。
   哪一面被读出，取决于理论的问题域朝向哪边。
3. **C-83 (d) + C-71：为什么 HoTT 被迫过程读法**。"对象包含过程信息"的内核形式 =
   同一性层次是对象部分（§2，C-71 `notPath≢refl`）；强行折叠过程 = 截断 = 换对象且
   不可解码（`noDecoding`）。对照极限侧：`∑2⁻ⁿ := lim sₙ` 的折叠不丢终局问题所需的
   任何信息（命名保守，§6 (a)）。**"过程信息不能被无损折叠"在 HoTT 里是定理
   （noDecoding）；"折叠过程"在极限理论里是定义的合法部分（∑ := lim）。**

**对 §4 的修订（发起人观点的增益）**：§4 说"H 的缺陷与极限的观测方式正交"是**偶然
语气**；发起人的版本是**设计语气**——这个正交不是碰巧，ε-δ 的 ∀ε∃N∀n 结构在定义层面
就把过程内容排除出问题域（∃N 是合法的跳层算子，CN-050 表中"理论为了好用改掉的
条件"那一条）。H 不是躲过了极限的观测，而是极限理论的观测**本来就不朝向过程**。
"没有成功充分暴露"的精确判据：终局断言可满足 ∧ 过程断言不可满足，而理论只对前者
有检测义务。

**边界**：
- `neverOfArrives` 的单调前提不能去（C-112 `monotoneNeeded`）；"两面等价"只对单调
  过程成立，芝诺跑者满足，本节不覆盖非单调过程；
- canonicity 是**元定理**（C-83 元层注记同款分层：对任意闭判定器还需典范性），不是
  包内命题；C-75 的"每层不落定"是包内定理，两者分层引用；
- ε-δ 的 ∃N 结构分析属教科书层逻辑分析〔教科书常识/我们的分析〕，不是 repo 机器命题；
- "极限理论没有充分暴露 H"是读法层判断（终局断言可满足 ⇒ 检测不到），**不是**"极限
  理论曾试图检测 H 而失败"的历史断言（后者归芝诺考古包 ZQ 系）。

## 5. 对"ZFC-1 蕴含 HoTT 中的问题"的精确化（必要的收紧）

两种读法必须分开：
- **逻辑蕴含**：过强，且与 C-431 澄清冲突（ZFC 免疫拆门论证；主语漂移是已识别的坑，

- **"同一个 A 的两张账单"**（README §6 既有表述）：忠实。精确说法 =
  **A 是两处共同的前提；坚持 A（= 不放弃微积分/极限/稠密性）就同时在两侧接受其兑现**。

另注："无法放弃微积分"是**现实/实用判断**（与量子化时空判断同类），README §2 已划界，
不是数学定理——它不进入形式化层。

## 6. 〔待证命题〕H 的桥接（候选 C-436 起，走 F-011 五步门禁）

- **(a) 平坦相等侧**：在相等无层次的框架（经典 ZFC 语义）中，"引入完成型命名"是

## 7. 可检验预测（供后续工作）

若 H 分析成立，则**任何为"同一性/完成"记账的框架**都应暴露 H（而平坦相等的框架应保持
H 不可观测）。这给出一个方向性的检验：挑一个第三框架（如构造性类型论的其他变体、
coinduction/非良基集合），预测其 H 表现并检验。

§4.1 追加的可检验预测：分野的载体是**典范性义务是否延伸到过程的每一层**（而不只是
语言里能不能谈论过程——极限理论当然能谈 sₙ，但公式典范形式有限，逐项不产生计算
义务）。据此预测：典范性义务逐层延伸的框架（构造性类型论变体、coinductive 观测）
被迫过程读法、暴露 H；典范形式有限的框架（经典一阶/集合论语言）终局读法自足、
H 不可检测。

2. **(a) 仍是真实缺口**。C-72/C-65/C-61 是"UIP 内核中恒成立"的**实例级**证据（`rfl` 级），

3. **(c) 的边界已经画好，且比本文更严**。追问侧的统一已被 C-112/C-113 机器证明；但
   C-113 禁止外推第 1 条明文排除「芝诺、H0、Z0 在数学内容上相同」的读法（只保证同一
