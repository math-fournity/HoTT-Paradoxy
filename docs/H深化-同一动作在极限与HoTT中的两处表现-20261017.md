## 2. 〔我们的分析〕H 的精确刻画

**H ≡ 「宣布完成，而不支付该完成对应的构造」。**

| | 极限侧（ZFC/经典分析） | HoTT 侧 |
|---|---|---|
| 要完成的东西 | 无穷过程的结果（和/极限值） | 同一性判断（"是不是同一个"的答案） |
| 完成的操作 | **命名/定义**：级数的和 := 部分和的极限 | **截断**：压掉同一性的层次 |
| 操作性质 | **保守扩张**——不改变论域中任何已有对象 | **非保守**——从 A 到 ‖A‖ 一般不是等价，改变对象 |
| 实例语句 | `∑2⁻ⁿ = 1`：其中"lim sₙ = 1"是定理，"和 := lim"只是命名——完成感来自**命名**，不来自证明 | "相同是事实，第 1 问就停"——截断后对象已换（「再也变不回原来的宇宙」） |
| 底层"相等"结构 | **平坦**（a = b 是无层次命题）→ "完成"无结构可承载 → 命名即足，代价为零 | **分层**（同一性类型本身是类型）→ "完成"必须支付层次，付不完 |
| 命运 | H 免费兑现：想要的结果拿到，系统内无冲突 | H 二择一：保持对象→永不完成；宣布完成→对象已换 |

**"同一个 H、表现不同"的机制**：README §6 已诚实标注两处**形式上是两条不同的原则**（HoTT
那条不用排中律）。〔我们的分析〕这个差异不是 H 的分裂，而是**实例参数**：底层相等结构不同
（平坦 vs 分层），同一个"宣布完成"操作落在两种土壤上，长出两种命运。

## 3. 〔我们的分析〕为什么"强制完成"在 HoTT 中不可能（回答核心提问）

不是字面不可能（截断是合法构造，做得到），而是**两个断言的合取不可满足**：

> （对象不变）∧（宣布完成）——在 HoTT 中不可满足。

因为同一性的层次**就是对象的一部分**（机器已证的 README §4 事实：真/假类型与自己对照有
"原样"和"对调"两种方式，沿对调运输"真"得到"假"；问"以哪些方式相同"一层之上还有一层）。
宣布完成只能靠截断，而截断改变对象。**没有第三条路。**

对照：极限侧该合取**可满足**，代价为零——因为 ZFC 的相等是平坦的，"完成"没有结构承载，
**命名就够了**。"改名字"与"改对象"之差，就是两处命运之差。

## 4. 〔我们的分析〕"不明显"vs"无法忽视"（观测层论证）

- 极限的观测方式 = **逼近**（ε-δ 即"对任意有限精度"）。H 的缺陷恰好是"任何有限精度下
  不可见"（每步都没到，但每步都在精度内）——与观测方式**正交** → 不明显。
- HoTT 的观测对象 = **同一性判断的完成本身**。H 的缺陷恰是观测对象 → **无法忽视**。

**"超越"的精确含义**：不是 H 恶化，而是观测条件让 H 从"不可观测的妥协"变成"可检测的障碍"。
度量口径：以**可检测性**计，HoTT 侧严格强（有定理级检测）；以**H 的存在性**计，两侧同一个 H。

**推论（值得记录的强表述）**：**HoTT 不是"更严格的数学"，而是把 H 变成可观测对象的
第一台仪器**——这为"为什么 2400 年来没人这样看它"提供一个结构性解释。

## 5. 对"ZFC-1 蕴含 HoTT 中的问题"的精确化（必要的收紧）

两种读法必须分开：
- **逻辑蕴含**：过强，且与 C-431 澄清冲突（ZFC 免疫拆门论证；主语漂移是已识别的坑，
  见记忆 `zfc-termination-gate-distinction`）——不采。
- **"同一个 A 的两张账单"**（README §6 既有表述）：忠实。精确说法 =
  **A 是两处共同的前提；坚持 A（= 不放弃微积分/极限/稠密性）就同时在两侧接受其兑现**。

另注："无法放弃微积分"是**现实/实用判断**（与量子化时空判断同类），README §2 已划界，
不是数学定理——它不进入形式化层。

## 6. 〔待证命题〕H 的桥接（候选 C-436 起，走 F-011 五步门禁）

把 §2–§4 的核心形式化，最有希望的两条：

- **(a) 平坦相等侧**：在相等无层次的框架（经典 ZFC 语义）中，"引入完成型命名"是
  **保守扩张**（不改变已有对象的性质）——可形式化/可证。
- **(b) 分层同一性侧**：在 HoTT/同伦论中，截断**不是等价**（A → ‖A‖ 一般不可逆）——
  这是同伦论的现成定理，可机器验证，与 README §4 的"再也变不回来"互证。
- **(c) 统一陈述（远景）**：定义"H-完成算子"的一个形式不变量，证明极限命名与截断是其
  两个实例（或共享该不变量）。此条依赖 (a)(b) 的先例，且**可能过强**——须先做可行性侦察。
