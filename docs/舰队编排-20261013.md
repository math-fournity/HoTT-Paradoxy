## 4.5 `ExsBlockerQ` 的拆解进展（004-Step，2026-10-13 上午，Master 核验）

**结构发现（Master 已核生产包源码）**：`Derivable.exs` 的形状与 `iT` 的 exs 支**不同形**
（后者给的是合取 `^∃ domZero ⋏ iT (n+1) p`），但 `Derivable.and_m` 正好对 `⋏`。
拆解为三件：
- ① 已证（exit 0）：`iT 0 (^∃ p) ∈ translateSeq s`（`mem_translateSeq_iff` + `iT_exs` 一步）；
