- **依据**：Master 逐字核对语句后发现四线在攻同一命题——

- **理由**：重复发现的成本远高于协调成本；这是"为什么舰队看着停滞"的直接机制之一。

### 决策 2：识别"一般律是承重的"，把 001-Step 升为主承重线

- **理由**：若只证 m=0，则 all/exs 支迟早会被一般律挡住；早承认承重点可避免二次返工。

### 决策 3：hExs 等式路线判死，改为可证蕴含

### 决策 10.5：C 的门槛更正为「前提差」，不是「Foundation 无此层」（002-Step 自我更正，Master 源码核验）
- **依据**：002-Step 撤回"`ℒₜ` 无 numerals"（`ec8eb833`），Master 核 `FirstOrder/SetTheory/Z/Z.lean:427`：
  `noncomputable def ofNat : ℕ → V`（`0 ↦ ∅`、`n+1 ↦ succ (ofNat n)`），且带
  `OfNat V n` 与 `NatCast V` 实例——**它存在**。但其所在段的 variable 是
  `[SetStructure V] [Nonempty V] [V↓[ℒₛₑₜ] ⊧* 𝗭]`（`Z.lean:16`），
  而算术侧 `ORingStructure.numeral`（`Arithmetic/Basic/Misc.lean:22`）只要 `[ORingStructure α]`。
  ⟹ **差别在前提强度**：集合侧"V 的元素 ↦ 常项"要 `V ⊧ 𝗭`，严格强于 C 的前提（`𝗜𝚺₁`）。
- **动作**：更正舰队文档与编排记录里 C 硬门槛的表述。
- **理由**：这把 C 从"一个不可能性"改成"一个确切的前提缺口"——**性质变了**：
  算术版 `term_complete` 能在 `𝗜𝚺₁` 下走通，正因为"换常项"在算术侧只要 `𝗜𝚺₁`。
  缺口现在有确切形状 = "在 `V ⊧ 𝗭` 下做集合侧 `toNumVec`"。
- **约束（重要）**：把 `V` 加强到 `⊧ 𝗭` **只能作为理解工具**，不能补进证明——
  Z0 的形式是"任意 `⊧ 𝗜𝚺₁` 的 V"，加强前提会改变结论适用范围。
