# 05 - 轨迹预判与建议

> 问题：WAI 继续工作下去会得到什么？所有者应当如何干预？
> 预判基于：goal.md 的契约结构（自设不可终止）、当前 successor 链（R4 → Oracle/物理时间）、
  五天实测速率（30–50 session/天）与盲区结构（04 号报告 B1–B10）。
> 概率为审计人主观置信度，非频率。

## 1. 短期（从 2026-09-15 起约一至两周，若不干预）

1. **R4 资格化完成（高，~85%）**：四候选（cubicaltt/redtt/cooltt/cctt）中选出一个
   （按其自设规则大概率 cooltt 或 cubicaltt），冻结 build + certified-input profile +
   正负 corpus。产出：合格的实现切片，无新数学。
2. **R4 Nat/Path/conversion 切片闭合（中高，~65%）**：`R4_EXECUTABLE_NAT_PATH_SLICE_
   COMPLETE_WITH_SCOPE`。十二义务矩阵更新为 4 present。
3. **proof-code 编码线重启（中，~50%）**：在受限方言上重建枚举/checker——注意 ERCF-3
   编码链（C-157–C-187）与 R2 ProgramCode 已经存在，可能出现第三份同型编码基础设施
   （B4 的直接代价）。
4. **文献线按剩余清单推进（高）**：Tarski/Löb/Rice–Shapiro/Chaitin/Kleene normal form
   逐篇 primary 审读；LIT-HOTT-COMPUTABILITY 收尾 Oracle Modalities 重放（Agda 2.6.4.3/
   Cubical v0.7 旧工具链有构建失败风险，失败会被如实登记）。
5. **治理事件持续（确定）**：更多 REPIN/REGRESSION 类 corrective session；STATE.json
   突破 1MB；下一个索引类重构（147 号 LOGICAL-SHARD-ORDER 的后继）。

**不会发生**：Goal complete（完成门不可达，03 号报告 §1）；HoTT 内部矛盾（R5 先验极低）；
E6 出现（检索空间错位，B2）。

## 2. 中期（约一至两个月）

1. **R4 独立句定理达成（中高，~60%）**：在受限方言内机器证明条件性 `T ⊬ G_T`。
   **预判终局判词 `GENERIC_GODEL_BOUNDARY_WITH_HOTT_INSTANCE`**（03 号报告 §3 的
   三点理由：有效公理化保持、Q 解释转移、ARITHMETIC-ONLY 消融）。按 goal.md §1，
   这被禁止计为完成——WAI 会诚实登记并转向下一 successor。
2. **候选空间进入长尾（高）**：CE-MAP 未覆盖 cell 逐个试；每个 no-go/defense 结果的
   边际信息量递减；`BOUNDED_NEGATIVE` 账本线性增厚。
3. **Oracle Modalities / 物理时间线被访问（中）**：物理时间线是唯一真正面向"现实侧"的
   返回口（goal.md §4 第 3 条）；预判其访问方式仍是文献重放 + Agda 探针，**不会**
   建立现实任务的形式模型（B4）——除非用户干预。
4. **上下文经济风险显现（中，~40–50%）**：加载集只增不减 + 治理税上升 + 压缩边界
   频繁。历史该 repo 已发生过漂移并被治理修复；本次风险形态不同——不是漂移而是
   **合法的空转**：每一步都合规，整体不前进。

## 3. 长期终态（不干预情景）

三种终态按概率排序：

- **T1（~55%）"诚实空转至资源耗尽"**：Goal 永不完成；产出一份极厚的、可复现的
  "HoTT 已知防线 + 一般元数学边界"机器验证图谱与海量有界负结论。学术上有残值
  （相当于一个 HoTT 防线验证库），对用户的哲学问题贡献趋近于已被现有结果决定的量。
- **T2（~30%）"治理吞噬"**：研究产能被 STATE/索引/re-pin/KC 模板的维护成本超过，
  实际数学产出率趋零；形式上 session 仍在推进。
- **T3（~15%）"意外突破"**：某次 consumer/context synthesis 或差分命中真实的
  NATURAL_USAGE_MISMATCH。存在但不能指望：它需要现实侧任务模型，而当前程序没有
  建它的动机结构（B2/B4）。

**关键不对称**：无论哪种终态，WAI 都不会虚报完成——这是其最可靠的性质；
最不可靠的性质是**停止条件**：goal.md 把停止权只留给"用户明确修改目标"。

## 4. 对所有者的建议（按杠杆率排序）

### R1【杠杆最高】改写 Goal 完成门，拆分"哲学交付"与"定理交付"两条验收线

把 goal.md §11 拆为：
- 线甲（定理线，保留现门）：继续寻找 NATURAL_USAGE_MISMATCH 级 witness，不设截止；
- 线乙（组装线，新设）：**限期组装 03 号报告 §4 的三层论证**（非因子化族 + 提升语义 +
  现实任务语义）为一份面向用户的"Z 铁律最强机器证据报告"，完成门 = 报告通过所有者
  评审，而非 E6。
这解开 B1/B2/B9：哲学命题按哲学标准交付，定理探索继续但不阻塞交付。

### R2 建"现实侧任务模型"为一个一等公民工作面

至少一个具名任务族（限时交付/流式/竞态裁决，任选其一）被形式化为观察量+完成标准的
操作语义，与 HoTT 恒等的失配在**该模型内**机器证明（而非在 Agda 库里找消费者）。
这是 B2/B5 的直接解，也是 T3 的唯一系统化路径。同时把计算分析/物理 CT 文献族加入
LIT 分母（03 号报告 §7 缺口 1）。

### R3 立即收敛版本风险

授权一次精确路径 commit（或至少把 `HoTT/formal/` + `HoTT/verification/runs/` 的新增
资产入 Git），消除 161 untracked 的单点风险（B8）。此建议零数学风险，收益确定。

### R4 给治理质量设预算

例：STATE.json 体积上限、KC 回评仅对 TOUCHED 行展开全文/NOT_TOUCHED 行合并为计数行、
corrective re-pin session 频率上限。防 T2（B7）。

### R5 要求一次"负结果综合"

让 WAI 写一份《为什么五天没有出现悖论见证：结构性原因分析》，明确回答"完成门是否
可达、E6 检索空间是否选错"。以该系统对外部审计的响应记录（F1–F7 全接受）判断，
它能完成这种自我分析——缺的只是有人要求。

## 5. 预判的可证伪性

本报告的预判可被如下事实证伪（列出以便未来复核）：

1. WAI 在无干预情况下于任一时点报告 Goal complete——证伪"不可达"分析（但需先核查
   是否违反其自身 §1 禁令）；
2. R4 终局判词不是 `GENERIC_*` 而含 `HOTT_ESSENTIAL`——证伪 03 号报告 §3 预测；
3. E6 在代码库语料中被找到——证伪 B2；
4. WAI 自发建立现实任务形式模型——证伪 B4 的"无动机结构"判断；
5. STATE.json 在 30 天内保持 <1MB 且 corrective session 频率下降——证伪 B7 趋势外推。

## 结语（审计人按所有者四问的最终浓缩）

1. **结果如何**：零悖论见证；换回的是一套诚实、可复现、防冒充的"未找到"证据体系和
   一批实为"验证 HoTT 防线有效"的机器结果。以工程与诚实度论是优等生，以目标送达论
   是零。
2. **是否存在问题**：存在，核心是目标契约的结构性缺陷（哲学命题误入定理验收门），
   而非执行力或诚信缺陷。
3. **继续下去会得到什么**：一段运行良好的空转——R4 的 generic 不完备定理、更厚的账本、
   更重的治理；Goal 大概率永不完成，直到用户修改目标或资源耗尽。
4. **是否有思维盲区**：十条（B1–B10），根在 B1；好消息是它是可被一次目标改写解开的结。
