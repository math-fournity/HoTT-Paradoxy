# 04 - 盲区清单（B1–B10）

> "盲区"定义：不是错误结论（未发现虚报），而是**系统性看不见的选择**——它们不违反
> WAI 的任何自设规则，因此其自检机制（遗漏审计、KC 回评、checkpoint）结构性地无法报出。
> 按对用户目标的危害排序。每条附证据锚点与影响分级。

## B1【高】把哲学命题塞进数学定理验收门（范畴错配）

- 表现：Z 强律是哲学命题（其权威文档自认不可在项目内形式化为普遍定理），却被套上
  F-011 机器证明 + E6 natural consumer + 最强竞争解释的定理级验收门。
- 后果：最强在手结果（非因子化族）被封存；Goal 不可达（03 号报告 §1–§2）。
- 自检为何失灵：门是 WAI 自己写的，"纪律执行良好"与"门选错了"在它的体系内不可区分。

## B2【高】在代码库里找"现实侧"消费者（检索空间错位）

- 表现：E6 检索全部发生在 Cubical v0.9 全库、agda-unimath、论文实现、派生开发
  （N1/N5/N10/S082/S083/S088），即**数学实践语料**。
- 错位：方向 B 的失配场景（把理论资格当已交付能力）发生在编译器、运行时、工程合同、
  物理时间中——那里没有 Agda 库。库内穷举必然产出 `BOUNDED_NEGATIVE`，且每轮
  `BOUNDED_NEGATIVE` 反过来强化"继续在库里找"的合法性。
- 证据：12 批抽样 482/2,396 无 E6；triage 队列 43 条开放；F5 确认队列里有真实截断消费者
  但不构成 E6。

## B3【中高】自指覆盖证书（分母=自产工件）

- 表现：CE-MAP 478 项中约 430 项为自产；"统观完备性"实为自产工件登记完备性。
- 后果：覆盖证书不能约束真实候选空间；但被排为 successor 的选择依据（"从未覆盖 cell
  选择"），于是搜索被自己的分类法围栏引导——分类法即命运。
- 缓解存在（69 UNKNOWN、OPEN_WORLD_NOT_CLAIMED），但缓解≠纠偏。

## B4【中高】基础设施偏好与边际收益递减（Gödel 编号现象）

- 表现：S067–S080 十四个"脉冲"从零重建 Gödel 编码/替换/对角化；S110–S118 再来一遍
  编码修复链；每步 exit 0、零 warning、不新增数学内容（自评 `PULSE_EVIDENCE_ONLY`）。
- 模式：验证侧（能机器核对的东西）持续扩张，假设生成侧（哪个抽象变换×哪个现实任务
  可能产生见证）几乎无对应机械投入；"有判别力的 successor"的选择始终在已知族内
  （下一个 no-go、下一个文献重放、下一个实现资格化）。
- 信号：C5（9/12）判定唯一缺环是 E6 后，三天内没有一次工作单元以"构造现实侧任务模型"
  为目标——全部投入 R2/R3/R4 与文献。

## B5【中】"HoTT 必然考虑过已知悖论"的正面含义未被吸收为搜索先验

- 所有者的预设其实是双刃：它既要求覆盖已知防线（WAI 做得好），也蕴含"新失配只可能
  出现在 HoTT 的**创新区**（univalence 恒等=等价、HIT、截断层、证明相关性、∞-groupoid
  恒等）与**现实交付链**的交叉处"。
- WAI 探过创新区（ua regularity 被探针排除、SIP、截断、HIT classifier），但一旦命中
  防线就回撤到通用线（Gödel/R4）——恰与先验指示的方向（更深的现实交付链建模）相反。
  见 03 号报告 §7 缺口 1：现实侧计算理论文献零登记。

## B6【中】截止日纪律缺失

- goal.md §5 以 2026-09-14 为具名截止日；该日已过，判词
  `COMPREHENSIVE_COVERAGE_NOT_ACHIEVED`，剩余义务清单仍在，但**没有任何逾期处置**
  （未改截止日、未降级目标、未向用户报告冲突）。
- 对照：WAI 对数学结论的期限纪律极严（禁止外推逐字执行），对自身计划的期限却无机制。
  这是"自主连续工作契约"的通病：时间预算函数不存在。

## B7【中】治理质量超线性增长，逼近上下文经济极限

- 数据：STATE.json 788.8KB；每 session 固定写 36-KC 回评（约 2/3 为 NOT_TOUCHED 模板）；
  157 个 session / 5 天；每次索引变动触发多 owner re-pin（S105/S106/S111 等 corrective
  session 的存在本身）。
- 后果：每个数学工作单元的治理税持续上升；压缩边界更频繁；而 goal.md §2 要求每次
  恢复全量加载——加载集只增不减。**该系统的记忆维护成本最终会吃掉研究产能**
  （历史漂移期的教训在该 repo 的治理自反馈分析中已出现过）。

## B8【中】未提交证据的单点风险被常态化

- `LOCAL_UNCOMMITTED_NOT_VERSION_CLOSED` 从 9/13 起持续挂在数十个 proof package 上
  （161 untracked + 38 modified），包含 807 文件 Coq 归档等不可再生重建的昂贵证据。
- WAI 的规范要求"移动/删除前必须有可恢复 commit"，却**没有对称规则要求"重要新增证据
  应及时 commit"**；诚实标注风险≠管理风险。

## B9【低中】判词阶梯的隐含单径假设

- 四级阶梯（DEFENSE_WORKS → REPRESENTATION_BOUNDARY → NATURAL_USAGE_MISMATCH →
  INTERNAL_INCONSISTENCY）隐含"悖论=沿此单径升级"。哲学目标允许的另一形态——
  **效应谱分岔的组装展示**（不需要越级消费者，见 03 号报告 §4）——不在阶梯上，
  因此无法被"完成"，只能永远停在第二级。
- 这是目标语言（Z 文档）与验收语言（判词阶梯）之间的翻译损失。

## B10【低】R4 实现路线的保真赤字

- 以社区原型（cubicaltt/redtt/cooltt/cctt）为"exact HoTT calculus"，再以自建 certified
  profile 划出受限方言：证明对象既非 HoTT 理论也非上游实现。WAI 承认边界但未承认
  推论（结构性赤字，非工程细节）。见 03 号报告 §6。

## 盲区之间的结构关系

B1 是根：验收门选错（哲学目标→定理门）导致 B2（在可机器核对的空间里找不可机器核对的
东西）、B9（阶梯没有哲学出口）、B4（转而做永远可核对的 infra）。B3/B7 是 B4 的放大器。
B5/B6/B8 是独立的管理性盲区。**要纠偏，改 B1 一处即可解开大半**（见 05 号报告建议 R1）。
