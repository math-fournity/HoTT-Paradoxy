## 2. 证明的形状（人话）

1. **U_n^{≤n}**（第 n 个宇宙里的 n-型组成的"子宇宙"）是 (n+1)-型（库引理）。于是它的 (n+1) 阶环路都是**集合**（KS Cor 5.6）。
2. **Loop_n** = "一个 n-型 X，连同 U_n^{≤n} 在 X 处的一条 (n+1) 阶环路 q"。它住在下一个宇宙 U_{n+1} 里。
3. **ξ 族**：Loop_n 的每个点 (X, q) 都自带一条环，把它原样还回去——ξ(X, q) := (q, d_q)。m = 0 时 d_q 是"q 沿自己滑动"的方块 q⁻¹·q·q = q；m ≥ 1 时纤维是集合，d_q 是唯一的（由 KS Lemma 5.1 以带点等价实现）。
4. **local-global**（单价性在这里起作用）：U_{n+1} 在 Loop_n 处的 (n+2) 阶环路 ≃ "给 Loop_n 的每个点配一条 (n+1) 阶环"的族。ξ 就是这样一个族，于是得到 U_{n+1}^{≤n+1} 在 (Loop_n, h) 处的一条 (n+2) 阶环 q′。
5. **非平凡性**：若 q′ 平凡，则 ξ 在每点平凡；在归纳假设给出的那个点 (W, q̃)（q̃ 非平凡）处取第一分量，得 q̃ 平凡——矛盾。
6. **收尾**：若 U_n 是 n-型，则其 n-型子宇宙也是 n-型，于是 (n+1) 阶环路可缩，与第 5 步的非平凡环冲突。

基例：hSet₀ 在 (Bool, isSetBool) 处的 ua notEquiv 环非平凡（swap ≠ refl）。

## 5. 这件事对罗素面意味着什么（桥到卷宗）

- 【数学事实】无 HIT 时，对每个 n，第 n 个宇宙不是 n-型；同时它的 n-型子宇宙恰是 (n+1)-型（严格）。
- 【判断】这给出罗素面的一条**无 HIT 路线**，但它的形状与 C-75 不同：C-75 说"同一个宇宙 Type₀ 在任何一层都落不定"（用 HIT）；无 HIT 路线说"**没有一层能让所有宇宙一起落定**：第 n 个宇宙至少高到 n+1 层，而且~~要证明第 n+1 个宇宙的这一点，必须用到它包含第 n 个宇宙这件事~~【2026-09-27 修订，见 `14-罗素面终局判词.md` §9、J-018：原句的"必须"越级。机器事实只是本证明的归纳步 `step` 从第 n 层宇宙的数据造出第 n+1 层的见证；"任何无 HIT 证明都必须如此"依赖 KS §6 的相容性评述，是来源级读法】本证明对第 n+1 个宇宙的这一点，是借它包含第 n 个宇宙的数据证出的"。KS §6 认为"每个 U_n 恰是 (n+1)-型"应当是相容的【来源转述】，所以无 HIT 时，单个宇宙的"落不定"证不出来；落不定的是**宇宙塔**。这改变了归因：在无 HIT 路线里，宇宙的**大小分层**（Opus CN-039 的 P-S）成了必要成分——它在 C-75 路线里被正确地排除，但在本路线里每一步都用到 `Loop_n : U_{n+1}`。详见卷宗 `07-…` §4。
