# 扩展认知与航向

## 1. 扩展认知逐片（三单元合并计量）

扩展认知是 AI 阐释层，不是用户原文权威；下表只记三个单元实际触及的语义，以及审计者据此给出的偏航诊断。

| 片 | 三单元的触及与姿态 | 实际结果、偏航诊断与下一条件 |
|---|---|---|
| 001 问题意识与理论的简化 | 触及"理论让世界更容易思考时让哪些条件退出"：单价性（同构即同一）是经济收益 | 方向对；GLM 的叙事把收益写成"发动机"，比喻没错，但归因强度越界（见 003 片 KC-000029） |
| 002 前提改变、结果与时间 | 触及"持续产生下一项是否等于整体完成"：M2 的门一、门二正是这个问题 | M2 如实把它交给用户；GLM 没有替用户回答，守住了边界 |
| 003 芝诺、圆环、ASK 与两种方向 | 触及 ASK（形成规则回答还是回避）与 B 方向；未触及芝诺/圆环 | 该片强调"完成的含义必须保有细节"：GLM 自己校准了"永不停机 = 对 m 的外部搜索"，这是按该片精神的校准；但工作日志"前两层"句把元素与塔、带 HIT 与不带 HIT 混在一起（已修） |
| 004 走进 HoTT 与理论自反 | 触及"理论的真实限制也应保留"（C-71 执照拒绝读作正确拒绝）与自反方向（GR-1） | 该片说"一项有力量的自反研究……不需要借助无限宇宙的修辞来显得深刻"；GN-002 §0 与 C03 的全称结论恰恰在退化片段上下了过强判断（已改读） |
| 005 表达界限、文章作为起点 | 触及"形式化要核对的，应当正是叙述所声称的命题；把较弱命题证明得十分漂亮，不能替代较强原问题的完成" | **C02 是这条原则的反例**：`valReflT` 证明的是较弱命题（端点定义性相等），叙述声称的是较强命题（路径构造子被送到 refl）；已由忠实形式补上 |
| 006 第三条发现路径 | 触及"把知识谱当作被考察对象而非判断权威"：M1c 预研读 KS 原文而不是凭记忆 | resizing 误判是"知识谱当权威"的反例，GLM 读原文后自纠；R2 降格是另一次没回原文逐项对照的判断 |
| 007 AI 数学的两件事 | 触及"熟悉判断可能过早固定问题形状" | GLM 的两类偏差（越界与过度更正）方向相反，但都是没有先固定"形式命题逐字说了什么"就下判断；这正是该片说的"惯性"的两种表现 |

| 009 从可疑前提到针对性过程 | 触及："原生证明器接受一个命题，验证的是这个命题；它不会自动验证该模型忠实代表……" | 这是审计 GLM 全线的核心原则；C02（见证错位）与 R3 负控制（作用域错误）都是"内核接受了某个东西，但那个东西不是声称的东西"的实例 |

## 2. 已走过的路（GLM 航向复盘）

1. D1/D2 讨论：用户把 P1–P3 锐化为"算符先行于存在性落定"模板（平行工作索引 §7，core 候选，~~未入核~~【2026-09-30 已入核：KC-000050、KC-000051】）；GLM 据此把罗素面定为 U 线主攻、自指格为助攻。**航向正确**：沿用户原文的问题意识选靶。
2. GR-1a：选靶（等式作为结构）与过程（解释进宇宙）匹配；**偏航点**：C02 见证错位；C03/§0 的全称化。
3. 评审往来与 C01 三次尝试：诚实回退源文件到收据哈希，C01 最终落地。**航向正确**：证据纪律好。
4. M1a：GLM-R2-C01/C02 形式上对；**偏航点**："HIT 对全上升必要"（以知识状态冒充必要性）。
5. M1b + M2：种子障碍分析有价值；M2 守住"只摆两面"。**偏航点**：resizing 误记（已自纠）；"开放问题"的类型判断不准。
6. M1c：GLM-R3-C01 形式上对，忠实重放 KS n = 1；**偏航点**：负控制作用域错误且被声称为"正确理由拒绝"。
7. 自查与委托：GLM 主动发起会话级断裂审计并预修两处——四分句（方向对）与 R2 降格（方向错）。**航向判断**：主动请求审计本身是正确的治理动作；自我更正也需要逐项核证。

总体：GLM 的**形式层**六个命题全部为真且无空洞；偏航集中在**声明层与证据层**。这与用户在委托中点名的模式完全一致："写了机器证明代码，但代码证明的东西可能不是它想证明的东西。"
