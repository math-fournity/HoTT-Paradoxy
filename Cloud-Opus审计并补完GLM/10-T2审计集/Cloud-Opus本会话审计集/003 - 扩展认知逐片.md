# 扩展认知逐片

扩展认知是 AI 阐释层（`essay-role:v1`），不是用户原文权威。下表记录本会话对每一片的实际使用，以及它怎样改变了（或应当改变）本会话的动作。注意 001 片 §3 登记的缺口：003–009 片是在卷宗写完之后才在本会话读到的；下表的"核对"一栏是补读后的回查。

| 片 | 本会话的触及与姿态 | 核对与偏航诊断 |
|---|---|---|
| 001 问题意识与理论的简化 | "当理论让世界更容易思考时，它让哪些现实条件退出了思考；那些条件又会在什么地方重新要求被承认"——卷宗种子句的 E 与 T→T′ 就是按这一问写的 | 一致。该片提醒"不以迎合代替推演"：卷宗给出条件式判词并写出最强反方（`08`），没有替用户宣布胜利 |
| 002 前提改变、结果与时间 | 该片列出的敏感面之一"持续产生下一项是否等于整体完成"，正是门一的原问；该片区分"时序关系"与"时间结构"两种考察内容，卷宗把罗素面放在前者（存在性何时算落定），没有借后者（稠密性） | 一致。补读后可在卷宗 §6 门一处引用这句作为 AI 阐释层的对应（非必须，未改） |
| 003 芝诺、圆环、ASK 与两种方向 | ASK → 门二；B 方向 → 罗素面定位；"完成的含义必须保有细节"→ 元素与塔、带 HIT 与不带 HIT 的区分；"不能让'下一轮再找完整过程'成为无限延期的习惯"→ 一般 n 直接完成而不是走"诚实出口" | 一致。该片说"把 S 的尝试构造想成反复拿入拿出……不把它直接宣告为已经证明的等价"——卷宗对"永不停机"的处理与此同向：只作外部搜索的读法 |
| 004 走进 HoTT 与理论自反 | "理论的真实限制也应保留"→ 正确拒绝不当 BUG；"共同骨架不是免于实例化的理由"→ KS 一般 n 在本仓库原生重放并附 HIT 证书；"它不需要借助无限宇宙的修辞来显得深刻；它需要使一个读者能够看清，哪一步要求回到了自己"→ 强度 II 的故事把每一步落到 `step : NT L k → NT (ℓ-suc L) (suc k)` 的类型上 | 一致。风险提示：罗素面的叙事天然带"无限宇宙"意象，卷宗须始终把它压回具体一步；外部复核时可专门检查这一点 |
| 005 表达界限、文章作为起点 | "形式化要核对的，应当正是叙述所声称的命题；把较弱命题证明得十分漂亮，不能替代较强原问题的完成"——这是整场断裂审计的判据 | 一致。C02 的判词（见证只证较弱命题）直接对应这句话 |
| 006 第三条发现路径 | KS 论文、HoTT 通行知识都当被考察对象：KS §6 的相容性论断标为【来源转述】并写明"论文自述无已发表证明" | 一致 |
| 007 AI 数学的两件事 | 自检两类惯性：GLM 的过度更正（主动降格不等于更可靠）；本会话卷宗初稿的一度加码（"只依赖 P-U"） | 一致；本会话的加码已纠正并记为 TENSION（002 片 KC-000029） |
| 008 现实对齐 | 用"万有目录"讲宇宙；"找到断裂只是候选"→ 门一、门二不代裁；C-72 的现实对照被注明是粗粒度控制 | 一致。该片说"预存标准全部无效"是 AI 新增的排他判断、不能继承——卷宗没有这样写 |
| 009 从可疑前提到针对性过程 | "原生证明器接受一个命题，验证的是这个命题；它不会自动验证该模型忠实代表……"——HITScan 证书、C02 忠实版、负控制的"拒绝阶段"记录都按这一原则设计；"有靶点还不够：过程要对它敏感"→ 近失控制（平凡基环、平凡解释、越级） | 一致。补读后确认：本会话每个负控制都记录了实际拒绝阶段与错误标签，正是为了回应这一片 |

补读结论：扩展认知 003–009 没有改变本会话任何一条结论；它们为已做的判断提供了阐释层的对应。若外部复核认为某处应随补读而改写，以复核意见为准。
