## 2. 逐条详审

### 2.1 GLM-R1-C02：形式见证不陈述所声称的事实（实质性越界）

**L1 声明层**（GLM 原句）：
- `HoTT/formal/glm-russell/iota-syntax/CLAIM.md` L15："本包把该刻画机器化：`val` 的两个 βι 子句**逐字是 `refl`**（GLM-R1-C02），并且这是一个定义性事实"；L20："标准解释 `val : Tm → Bool` 把两条 ι 计算规则都送到 `refl`（定义性；`valReflT`/`valReflF` 见证）"。
- 平行工作索引 §8.3（L104）：同义。
- 会话级审计请求 §3（L29）把形式内容写成"val 的两条路径构造子子句是常函数"。

**L2 形式命题**：`valReflT : (t s : Tm) → Path (Path Bool (val (cond (lit true) t s)) (val t)) refl refl`。

**断裂**【数学事实 + 判断】：这个类型里**没有路径构造子 `betaT`**。`refl : val (cond (lit true) t s) ≡ val t` 能写出来，只说明两端点定义性相等（`val (cond (lit true) t s)` 归约为 `val t`）；之后外层的 `refl ≡ refl` 恒可证，与 `val` 在 `betaT` 上做了什么毫无关系。于是 `valReflT` 能证明的"真实等式判据"对**任何**端点定义性相等的解释都成立。

**机器演示**（`HoTT/formal/cloud-opus-glm-audit/glm-repairs/IotaC02Faithful.agda`，运行 `20260927-COPUS-GLM-REPAIR-01`）：
- `glmFormHoldsAtArt : Path (Path Type (f boolTy) (f boolTy)) refl refl`——GLM 的陈述形式在**人工等式** `art`（其解释是 `ua not ≠ refl`）处照样成立；
- `faithfulFormFailsAtArt : ¬ (cong f art ≡ refl)`——忠实形式在 `art` 处被驳斥；
- `valBetaT-refl : (t s : Tm) → cong val (betaT t s) ≡ refl`、`valBetaF-refl`——忠实形式在真实 ι 等式处成立（证明为 `refl`）。

结论【判断】：GLM 声称的**事实本身为真**（`val` 的 `betaT` 子句确为常函数），但它交付的形式见证不陈述这一事实，因而不能充当"真实等式判据由此机器化"的证据。断裂由忠实版补上。

**三行（修正后）**：
- 声明层读法：在一阶 ι 玩具片段里，标准解释 `val` 把两条 ι 路径构造子定义性地送到 `refl`。
- 逐字形式命题：`valBetaT-refl : (t s : Tm) → cong val (betaT t s) ≡ refl`、`valBetaF-refl`（COPUS-GLM-FIX-C02a）；GLM 原 `valReflT/F` 只作"端点定义性相等"的记录。
- 证据：`20260927-COPUS-GLM-REPAIR-01`（exit 0）。

### 2.2 GLM-R1-C01：形式无断裂，读法越界（措辞越界）

- L2：`realisticIotaSyntaxIsASet : isSet Tm`。L3：`isSetRetract val lit (λ t → sym (q t)) isSetBool`，归一化引理 `q` 的路径构造子子句用 `squareLeft`，Agda 接受；Q7 不涉及本包，但源码无公设、无局部重定义，`isSet` 是库定义。【数学事实】
- L1："本片段内'理论自身的表述完全落定（集合）'是机器定理"（GN-002 修订块二 L3）。【判断】`Tm` 同构于 `Bool`（`val ∘ lit = id` 定义性、`lit ∘ val ~ id` 由 `q`），没有上下文、依赖、替换；把它叫作"理论自身的表述"是命名层的放大。另，`Tm` 本身是一个 HIT（`betaT/betaF` 是路径构造子），HITScan 负证书 `NegCertIota` 如实点名 `Tm`。
- **三行**：读法 = "一个只有 Bool 字面量、条件算子与两条 ι 等式的玩具 HIT 语法（同构于 Bool）是集合"；形式命题如上；证据 = `20260927-COPUS-REPLAY-GLM-IOTA-SYNTAX-02`。

### 2.3 GLM-R1-C03：全称"必须"越界；负控制不检验论证

- L2：`¬isSetTmA : ¬ isSet TmA`，证明经 `cong (cong f)` 把 `art ≡ refl` 送到 `ua flipNotEquiv ≡ refl`，与 `uaβ`+`true≢false` 矛盾。【数学事实】
- L1："非落定**必须**人工注入"（CLAIM 标题与 L21；GN-002 标题与 L27；索引 §8.3）。【判断】形式内容是"注入一条被解释为 `ua not` 的人工等式后，该玩具语法不是集合"——一个存在性实例；"必须"是对一切非落定来源的全称断言，形式内容不支持。CLAIM 的"禁止外推"已写"不外推到'所有非集合语法都来自人工等式'"，与标题的"必须"自相矛盾。
- L4：GLM 负控制 `WrongArtIsRefl` 断言 `art ≡ refl` 由 `refl` 证明，被拒（`art i != boolTy`）——拒绝理由正确，但它只说明 `art` 不定义性等于 `refl`，**不检验 C03 的论证**。补充近失控制 `IotaC03NegTrivialInterp.agda`：把 `art` 解释为常路径后，GLM 的证明脚本逐字被拒（`cong f′ art` 是 `refl`），说明 C03 依赖人工等式的**非平凡解释**（运行 `-GLM-REPAIR-NEG-03`）。
- **三行**：读法 = "在同一玩具片段中，加入一条被解释为非平凡自等价的人工等式后，语法不再是集合"；形式命题如上；证据 = `-REPLAY-GLM-IOTA-SYNTAX-01` + `-REPLAY-GLM-IOTA-SYNTAX-NEG-01` + `-GLM-REPAIR-NEG-03`。

### 2.5 GLM-R2-C02：形式无断裂；"HIT 对全上升必要"实质性越界

- L2 与"集合成员 X 处 Ω²(U, X) 可缩"一致；HIT-free（COPUS-R1-C03）。
- L1 越界句：
  1. `universe-ascent-stall/CLAIM.md` L25："HIT 对第一层非必要，**对全上升必要**（C02 + 事实：无 HIT 的 Type₀ 中无已知非集合成员）"；工作日志 L29 同义；GN-003 L12："全上升依赖（GLM-R2-C02 证明集合成员处引擎熄火）"。
  2. `AscentStallAtSets.agda` L7–11 注释："level >= 2 non-triviality provably requires NON-SET members"。
- 【判断】"必要"有两种读法，两种都不成立：
  - 若"全上升"指**宇宙塔**逐层上升：本会话已机器证明无 HIT 的一般 n 定理 `KS-Theorem-5-9 : (n : ℕ) → ¬ isOfHLevel (2 + n) (Type (lvl n))`（COPUS-KS-C01，HIT-free 证书 COPUS-R1-C05）——无 HIT 也能逐层上升。所以"对全上升必要"**被机器证据否定**。
  - 若指**单个宇宙 Type₀ 自身**没有 h-level：这是一个元理论断言（无 HIT 时 ¬isGroupoid Type₀ 不可证）。GLM 的证据只有"无已知非集合成员"（知识状态），配不上"必要"。KS §6 的相容性论断【来源转述】支持"不可证"，但它是论文作者的信念与模型草图（"We are not aware of any published proof"），不是本仓库机器事实。
  - 注释句 "level ≥ 2 non-triviality requires non-set members" 对**宇宙在 X 处的二阶环路**成立（这正是 C02 的逆否）；但"全上升由 HIT 或宇宙塔供料（source only）"中的 "source only" 现已过时（塔已重放）。
- **三行**：读法 = "对集合 X，宇宙在 X 处的二阶环路空间可缩；因此宇宙的 (≥2) 阶非平凡环路只能出现在非集合成员处"；形式命题如上；证据 = `-REPLAY-GLM-ASCENT-STALL-01` + HITScan 证书。

### 2.6 GLM-R3-C01：形式与证明无断裂；负控制证据层断裂；"replayed"原本成立

1. **L2/L3**【数学事实】：`¬ isOfHLevel 3 (Type (ℓ-suc ℓ-zero))`；`isOfHLevel 3` 定义性等于 `isGroupoid`（`Q7AnnotatedReplay.hlevel3≡isGroupoid`，`refl`）。全链逐行核验见 `04-Q7-数学终审逐行核验.md`：`τ≠refl` 的链方向为 `(tt,tt) ≡ transport refl (tt,tt) ≡ transport (ua ea) (tt,tt) ≡ (ff,tt)`，取 `cong fst` 得 `true ≡ false`，方向正确；`D` 方块的内容从不被检视（矛盾只用 `cong fst (FAM x) ≡ snd x`，定义性）。
2. **HIT-free**：由 HITScan 证书 COPUS-R1-C01 机器确认：名称级闭包 251 名，无 HIT；数据类型只有 `I, ℕ, ⊥, Bool`；公理叶子只有 cubical 内建的 `1=1, IsOne, inS, Sub, Level, PathP`。GLM 原"人工断言"（REVISIONS L13）由此升级为机器证据；但导入闭包确含 4 个 `Cubical.HITs.PropositionalTruncation*` 模块，这一点 GLM 如实写过。
3. **"KS n=1 replayed" vs GLM 的 R2 降格**【来源转述 + 判断】：对照 KS 原文（arXiv:1311.4002v3 §5）：Lemma 5.8 的归纳步定义 ξ := λ(X,q).(q, d_q)，"For m ≡ 0, the type of d_q is q_*(q) = q, which is easily seen to be inhabited after writing q_*(q) as q⁻¹·q·q"；非平凡性来自归纳假设在 n = 0 时的非平凡元素——即 2 上的 swap（"This is swap, which is different from the trivial inhabitant refl₂"）。GLM 的 `D q := compPathL→PathP (sym q ∙ q ∙ q ≡ q)` 就是这个 d_q；`FAM (b , q) := ΣPathP (q , D q)` 就是 ξ；`(c₀ , τ)` 与 `τ≠refl` 就是"基例的非平凡元素 + π₁(ξ(X,q)) ≡ q"；`forceEquivLoop` 就是 Thm 5.9 的"would be propositional"。唯一差别：基环取 Bool×Bool 上的对合 `a` 而非 2 上的 swap，以及 local-global 只用了所需的一个方向。GLM 自己的 GN-003 修订块也这样描述 KS 机制。因此 GLM 的 R2 更正（"机制不同：具体对合+uaβ+集合压平，非 KS 的 IH 传播"）**是过度更正**：KS 的 n=1 情形里，"IH"就是一个具体对合加 uaβ 式的非平凡性论证。正确措辞见 §3。
4. **L4 负控制**【数学事实】：`WrongGroupoidWitness.agda` 只导入 `Cubical.Foundations.Prelude` 与 `a`，`true` 不在作用域；Agda 在**作用域检查阶段**报 `[NotInScope] true` 并以 42 退出，从未进入类型检查。GLM 自己的收据 `20260926-GLM-GROUPOID-UNIVERSE-NEG-01/stdout.txt` 末尾就是这条错误；RUN.json 却写 `KERNEL_REJECTED_AS_EXPECTED`，工作日志 L36 写"负控制（exit 42，**正确理由拒绝**）"。本会话 Linux 重放得到同一错误，捕获工具将其分类为 `REJECTED_BEFORE_TYPE_CHECKING`。修复版 `GroupoidNegFixed.agda` 补上导入后被类型检查器以 `false != true` 拒绝（运行 `-GLM-REPAIR-NEG-01`）；近失控制 `GroupoidNegTrivialLoop.agda`（同一 τ≠refl 脚本作用于恒等等价的环）被以 `true != false` 拒绝（`-GLM-REPAIR-NEG-02`）。

### 2.7 "前两层"句与四分句（R3）

GLM 已把旧句预修为四分句（索引 §9）：Type₀ 非集合（无 HIT，C-63）；Type₁ 非群胚（无 HIT）；Type₀ 非群胚（带 HIT，C-75）；**"Type₀ 无 HIT 时是否群胚 = 开放问题"**。前三句核对无误（前两句的 HIT-free 现均有证书：COPUS-R1-C04、COPUS-R1-C01；第三句 C-75 依赖 HIT，负证书 `NegCertC75` 点名 EM₁、S¹、Susp、HubAndSpoke）。第四句需再精化【判断】：

- 本会话新增的第五句（机器事实）：**对每个 n，第 n 个宇宙不是 n-型（无 HIT，COPUS-KS-C01）**。
