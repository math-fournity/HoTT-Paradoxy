## 五、对“结构弥漫性”新判据的审计

GLM 提出：任意 opaque axiom control 可能只给孤立卡点，而 `ua : (A ≃ B) → (A ≡ B)` 对全部等价生成路径，可能在 `Σ` 回路、SIP 等理论构造中系统性产生卡点；这种结构弥漫性可以构成控制组没有的现象。

这个方向值得进入 R7，但当前只能标：

```text
HEURISTIC_HOTT_RELATED_PATTERN
/ FORMAL_SPEC_OPEN
/ ESSENTIALITY_NOT_ESTABLISHED
/ REALITY_PROMOTION_OPEN
```

原因有四点：

1. 一个按全部等价索引的任意 opaque axiom schema 也可以产生同样广泛的卡点；“数量多／闭包广”不自动说明机制只属于 univalence。
2. 需要定义何谓一个 term “stuck”、何谓“系统性产生”、计数是在语法、判断等价类还是理论构造闭包上进行。
3. `Σ` 回路和 SIP 中存在 ua 生成的路径，不等于每个相关数学使用都需要把这些路径归约成 canonical constructor。
4. 即使建立 axiomatic univalence 的 judgmental canonicity 边界，仍需 promotion source 与 source-grounded consumer 才能升级为现实相对实例。

R7 可新增 `FAMILY_SPREAD` 轴，但不能把它直接当成 HoTT-essentiality 判据。建议对照矩阵：

| 对照 | 目的 |
|---|---|
| 纯 MLTT | 基线 canonicity／reduction |
| 单一 opaque equality constant | 孤立不透明路径 |
| 与等价同型索引的 generic opaque schema | 控制“广泛索引”本身 |
| axiomatic univalence | 测 ua 的命题与判断计算边界 |
| Cubical univalence | 计算规则正控制 |

只有 axiomatic univalence 相对“同型索引 generic schema”仍呈现由 univalence 法则而非不透明性解释的差异，才有更强 HoTT-specific 研究信号。
