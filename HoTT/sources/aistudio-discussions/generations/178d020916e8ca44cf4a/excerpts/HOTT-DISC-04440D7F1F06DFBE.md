    ```python

    )
    ```
*   **解释:**
    *   `^`: 匹配一行的开始。
    *   `\s*`: 匹配任意空白符。
    *   `(?: ... )`: 非捕获组，用于组合多个可能的模式。

    *   `【[^】]+】`: 匹配用中文括号包裹的特殊标题 (e.g., `【引力奇点 #1】`)。
    *   `.*(?:\n|$)`: 匹配标题的剩余部分直到行尾。
