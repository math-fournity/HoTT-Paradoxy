## 1. 新发现（本设计文档的第一产出，影响 M3 叙事精度）

**`L q := (q·ℚq < 2r)` 单独不能作为 √2 cut 的下集**：对负有理数 q（如 q = -2），
q 在 √2 之下（-2 < -1.414…）但 `q·ℚq < 2r` 为假（4 < 2 假）。即 `q²<2` 型谓词
只描述正半轴的判定，不是下封闭集（-1 ∈ L 而 -3 ∉ L，违背下封闭性）。

- 对既有收据的影响评估：`Spec_A`（判定表）在 M3/M3-UNC 中的语义读法是
  「√2 位置的数据形态」，其 LEM/去条件化结论不受影响；但**金形态必须带符号
  处理**（下集须含全部负半轴）。此发现已登记本文件，审计可独立复核。

## 2. 修正后的谓词形态

- `L q := (q <ℚ 0r) ⊎ (q·ℚq <ℚ 2r)`（负半轴免费入下集；正半轴按平方判定）；
  或等价地经三分 `q ≟ 2r` 的形态。
- `U q := 2r <ℚ q·ℚq`（正侧超出；负数自然不在上集）。
- 两谓词均可经 `_≟_` 与序三分构造（ℚ 序可判定，`M3-UNC` 已实证）。

## 4. LEM 的真实位置（§11.2 依赖链的精确化）

四条件的**命题内容在 ℚ 层全部可构造**（判定+见证均可写）——这与 `M3-UNC` 的
「ℚ 层免费」一致。LEM/resizing 的收费点在**下一升格**：把 cut 取等价类、把
「ℝ 取值的命题」塌缩到单一 Ω（Book §11.2 自陈须 LEM 或 resizing）。因此金形态
构造本身可以是**无假设的**（ℚ 层构造+四条件），而「实数作为已完成对象」的
使用环节才带 LEM 债——本设计把这两层明确分开，收费位置不可漂移。

## 4.5 located 见证构造的符号区域分析（本次深查新增；证实不可压缩）

located 的 u-见证（`r² > 2 → ∃ p, r < p ∧ p² > 2`）在 r 的负半轴区域**非平凡**：
- p := r+1 在 r ∈ (-3/2, -√2) 区间失效（(r+1)² 可 < 2）；
- p := r/2 在 |r| < 2√2 区间失效（r²/4 < 2）；
- 正确构造必须按 ℚ 的符号区域分段（r > √2 / 0 < r ≤ √2 / -√2 ≤ r ≤ 0 / r < -√2）
  分别给出见证（如 r<-√2 时取 p := (r + (-3/2))/2 类中点并核 `p² > 2`）。
每一支都消费 ℚ 序算术（单调性/正性/三分）——**located 单条即需要 CutInfra 的
大部分基础设施**。这证实：金形态四条件是一个完整的算术基础层工程（CutInfra
+ 四条件装配），不可压缩为单点补丁。同型分析适用于 rounded ← 的 δ-见证
（`δ := (2-q²)/4` 的正性与 `p ≤ 2` 的 `(q-2)²+2 > 0` 恒真式路径——已核可行，
但同样消费 CutInfra 引理）。
