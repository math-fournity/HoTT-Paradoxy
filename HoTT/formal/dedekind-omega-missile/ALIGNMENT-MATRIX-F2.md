## 矩阵读法纪律

- 「免费内化」格（F2-1/5/6）**不是**本方向的失败：它们说明完成义务的收费是
  选择性的——只收经典理想元素，不收构造性原则；这恰是主定理模式的判别力。
- 「显式假设」格的收据 = 该前提在引擎中的现形证书（LEM 格已齐，AC 格待做）。
- 「不可表达」格的机械化是开放设计问题（元层性质），登记不预设。
- 本矩阵随新收据滚动更新；每格修改须带 run 引用或源陈述标注。
