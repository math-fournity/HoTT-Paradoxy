## 2026-10-15：(5)(6) 是 C-79 (b) 的重证；“只有所有层的汇集永远答不完”说过了头；归因不是新的

收据入库后，在登记时回读 `questioning-delay/CLAIM.md` 与思考笔记 CN-046 至 CN-048，发现三处要更正。本机会话 95a1a81b（012-Opus）自己发现。

1. **(5)(6) 与 C-79 (b) 是同一命题。**
   - `questioning-delay`（2026-09-30）已证：
     - `gatheringStopsAt`：h-层 1+n 的目录在燃料 n 时返回 1+n；
     - `gatheringSilentBefore`：燃料小于 n 时返回 `nothing`；
     - `gatheringJudge`：判定器存在；
     - `setsStopAtTwo`。
   - 本包的 `Stage.stopsAtStage`、`stageJudge` 与内核实跑 `setsGatheringRun`、`fourTypesGatheringRun`，用自己的 `exactRun` 重证了同一内容，`CLAIM.md` 却没有引它，反而写成本包新做的对照。
   - 更正：(5)(6) 的出处是 C-79 (b)，本包只是在同一检查单元里独立重证。
2. **“永远答不完的，只有全部层的汇集，即宇宙”说过了头。**
   - `CLAIM.md` §4 第三条标了【证明】，写“永远答不完的，只有全部层的汇集，即宇宙 (3)(4)”；标题与 README 也有同样的“只”。
   - (3)(4) 只证明宇宙答不完，(5)(6) 只证明每个有限高度的汇集答得完，都推不出“只有宇宙”。
   - 反过来，C-81 已证：不是宇宙的乘积 ∏ₙ K(ℤ, n+1)（HoTT Book 例 8.8.6）同样没有任何有限层，追问等于 `never`。
   - 更正后的说法：
     - 成员高度有上限的对象，追问在那一层停（C-79、C-82）；
     - 成员高度没有上限的对象，追问永远不停，不论它是宇宙（C-78）还是无穷乘积（C-81）；
     - 正如 `questioning-delay/REVISIONS.md` 2026-09-30 第一条所说，宇宙也没有被证明是 `Gathering n` 一族的任何形式极限。
3. **归因与读法不是新的。**
   - CN-046（2026-09-30）已给出同一归因：相同是结构（单价性带来）与成员高度无上限共同造成不停。
   - CN-047 按 B 向（KC-000016、018、048、051）提出，首先要审的是形成规则的“一次交出”。本包 §4 的“宇宙作为现成的整体交出，是宇宙层的 A”与之同向。
   - CN-048 指出：永不停不专属于宇宙（例 8.8.6），并且塔上的永不停与提问方式有关。
   - 本包 §4 的归因表应读作 CN-046 的归因加上新的一行，即 LPO 不是原因。“宇宙层的 A”应放宽为：把所有高度一次交出的对象，宇宙或 ℕ 索引的无穷乘积。这仍是读法，待研究发起人确认。
