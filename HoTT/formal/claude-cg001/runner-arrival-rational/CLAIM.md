## 1. 记号

- `halvedF`、`arrF`、`ΦS`、`arrS`、`ΨN`、`remaining`、`Arrives`：同 C-117、C-118（`godel-q-zfc-runner-arrival`）。
- `Exp.exp K`：Foundation 的算术指数 2ᴷ；它的图像 `expDef` 是 Σ0 公式。
- `arrRatF e`：对每个正有理数 p/q（p、q 是正整数），从某一步起，跑者的剩余距离都小于 p/q。
  - 剩余距离小于 p/q，写成：有 K，q < p·2ᴷ，并且到这一步已减半至少 K 次。
  - 跑者的剩余距离总是 2 的负幂，所以这就是“剩余距离 < p/q”（§2 (5)）。
- `arrRatS a := haltsS (arithTrln.translate arrRatF) a`：有理精度的跑者到达句（ℒₛₑₜ）。
- `arriveRatC`：经典芝诺，对每个正有理数 p/q，从某一步起 q < p·2ⁿ，即 2⁻ⁿ < p/q。

## 3. 证明思路

- **(1)**，在每一个 𝗜𝚺₁ 模型里：
  - ⇒：给定 K，取精度 1/2ᴷ（p = 1、q = 2ᴷ）。从某一步起有 K′ 使 2ᴷ < 2ᴷ′ 且已减半 K′ 次；指数严格单调，所以 K < K′，于是也已减半 K 次。
  - ⇐：给定 p/q，取 K = q。由 q < 2^q 与 p ≥ 1，得 q < p·2^q。
- **(2)(3)**：同 C-118 的语义路线，在 𝗭𝗙𝗖 的每个模型里比较。
  - ω 的翻译解释与标准解释同真（C-109 的工具）；
  - 标准解释是 𝗣𝗔 的模型，因而是 𝗜𝚺₁ 的模型；在那里用 (1)；
  - 再用 𝗭𝗙𝗖 的完备性；(3) 再接 C-118 的 `zfc_arr_iff_never`。
- **(5)(8)**：
  - 在 ℕ 里，`Exp.exp K = 2^K`（Foundation 的 `exp_nat_eq_two_pow`）；
  - 正整数 p、q 满足 q < p·2ⁿ，恰是 2⁻ⁿ < p/q（实数交叉相乘）；
  - 跑者的剩余距离总是 2 的负幂（`remaining_eq_pow`），所以“有 K 使 2⁻ᴷ < p/q 且剩余距离 ≤ 2⁻ᴷ”恰是“剩余距离 < p/q”。
- **(6)**：C-118 的 `zfc_runner` 给出跑者，再用 (2)。
- **(7)**：在每一个 𝗜𝚺₁ 模型里取 N = q，再用完备性。

## 4. 承接了原话的哪一部分

- 【证明】极限理论对芝诺的判词，按通常的 ε–N 写法（ε 取遍正有理数），是 𝗭𝗙𝗖 的定理 (7)。
  - C-423 已证：𝗭𝗙𝗖 同时证明“没有哪一步余量为零”；
  - 本包把那里的“2⁻ᴷ 精度”换成了通常写法里的任意正有理精度。
- 【证明】对哥德尔–芝诺跑者，通常写法的到达句在 𝗭𝗙𝗖 里逐个等价于永不停机句 (3)。并且有一个跑者确实到达，𝗭𝗙𝗖 每一刻都看得见它还没到，却证明不了它“到了”的通常写法 (6)。
- 【判断】这把“𝗭𝗙𝗖 通过极限这扇窗看运动”（缺口表第 5 行，CG-010 D3）的窗口，从 2⁻ᴷ 这一族推到了通常的 ε–N 形式。
  - 窗口里看得见的是“极限意义的到了”；
  - “在哪一步走完”，窗口看不见，C-106–C-108 与 C-423 已证。
  - 这座桥是否成立，仍待研究发起人裁定。
- **没有承接**：
  - 实数本身：没有在 𝗭𝗙𝗖 内部把 ℝ 构造成集合（戴德金分割或柯西列的商），也没有证明“ε 取遍正有理数”与“ε 取遍正实数”在 𝗭𝗙𝗖 内部等价。那一步是阿基米德性质，本包把它留在 Lean 元层。完整构造 ℝ 的工作量与 W8 的 D3 同级，照实降格为不做。
  - C-108 的“所有步之后那一刻”（时刻 1），算术写法里没有它。
