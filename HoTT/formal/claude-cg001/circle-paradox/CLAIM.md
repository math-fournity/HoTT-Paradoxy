## 1. 记号

- `Ring := AddCircle 1`：圆。拿走的那一点是 0。
- `M := {0}ᶜ`：圆上取一点拿走。
- `N := (0, 1)`：两端展开成的线段，开区间，因为那一点被拿走了。
- `unfold : N ≃ₜ M`：展开与复原的同胚。它由 Mathlib 的 `AddCircle.openPartialHomeomorphCoe 1 0` 限制到定义域与值域得到。
- 逐步合回：第 n 步把线段绕回圆上，绕过比例 `θ n = 1 − 2⁻⁽ⁿ⁺¹⁾`。
  - 形态 `bend s t := ↑(s·t)`；
  - 一端在 0 处，远端 `farEnd n := ↑(θ n)`；
  - 缺口 `gap n := M \ range (bend (θ n))`。
- `AttainsAt`、`ArrivesAt`、`Isolated`：同 C-106，`GodelQ/Zeno/Attainment.lean` 逐字节复制。
- 离散环：`Fin m`，离散拓扑，点有大小，即一格。`discreteGap g₀ k := max 1 (g₀ − k)`：每步合拢一格的缺口格数，含被拿走的那一点。

## 4. 读法与归因

- 【证明】不对称在这里：拆开是一个直接给出的映射，不需要极限；逐步合回是一个逼近过程，在稠密的圆上没有有限阶段能完成，只有在“所有步之后的那一刻”（θ = 1）才是 M。
- 【证明】(5)：合回的远端恰是 C-106 的芝诺跑者。
- 【判断】这就是研究发起人说的“圆环复活了芝诺的幽灵”（KC-000055）。
- 【判断】归因与芝诺相同：被拿走的点不孤立，即稠密（KC-000004、KC-000048），这是产生悖论的前提。“只在极限那一刻是 M”，是 A 在圆环上的样子：把无穷多步之后才有的形态当作已经得到。
- 【判断】作为映射，复原（`unfold`）也是一步。它之所以存在，是因为 M 原本就在那里，这正对应“我们当初确实得到了M”。研究发起人问的是“在过程中”两端逼近的复原，那一个在有限阶段做不到。
  - 本包把两者分开写：同胚是理论里的等同，逼近是过程。
  - 研究发起人说的悖论，是这两者在稠密空间里分开了。
