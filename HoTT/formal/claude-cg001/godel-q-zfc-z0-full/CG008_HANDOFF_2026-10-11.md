## 2. 本论（本轮编译实证确认的数学事实）

### 2.1 缺口等价于 D3 对谓词 `zfcTr`（元层 Σ₁ 完全性 / 反射）

`Z0Full.lean:67` 的 `models_zfcTr_iff` 给出（两端都带模型 V）：

```
V↓[ℒₒᵣ] ⊧ zfcTr σ  ↔  Provable 𝗭𝗙𝗖 (⌜arithTrln.translate σ⌝ : V)
```

因此 `zfcTr_D3_internalize` 等价于对所有 `V ⊨ 𝗜𝚺₁`：

```
V↓[ℒₒᵣ] ⊧ zfcTr τ  →  V↓[ℒₒᵣ] ⊧ zfcTr (zfcTr τ)
```

即一条元层算术定理 `𝗜𝚺₁ ⊢ zfcTr τ 🡒 zfcTr (zfcTr τ)`，也就是可证性谓词 `zfcTr` 的 Hilbert–Bernays–Löb 条件 D3。
它**无法靠语法 D3（`provable_D3`）+ 简单内部化**得到，原因见 §3。

### 2.2 报价 `⌜σ⌝` 的真实载体是类型相关的（关键、已编译确认）

`Provable 𝗭𝗙𝗖 (⌜σ⌝ : V)` 与 `Provable 𝗭𝗙𝗖 (⌜σ⌝ : ℕ)` **不是可定义相等的**：Gödel 报价把载体类型 `V` / `ℕ` 编码进结果值，因此两段话的值在 Lean 类型层不等价。

编译实证（见 `Z0Probe7.lean`）证明：

```
𝗭𝗙𝗖.internalize V  ⊢ ⌜σ⌝   ≠   𝗭𝗙𝗖.internalize ℕ ⊢ ⌜σ⌝   （type mismatch）
```

以及 `Z0Probe6.lean` 证明：即便从 `Provable 𝗭𝗙𝗖 (⌜σ⌝ : V)` 经 `Provable.toDerivable` 得到
`Derivable 𝗭𝗙𝗖 (⌜σ⌝ ⫽ ∅)`，它也不是外层句级可证性 `𝗭𝗙𝗖 ⊢ arithTrln.translate σ`
（内部证明演算 `Derivable` 作用在「被报价的序列」上，而外层 `⊢` 作用在语法 `Sentence` 上）。

结论：**任何「先把结论降到标准模型 ℕ、算完再升回 V」的载体重接路线都是类型错误的**，不要再试。

### 2.3 哪些引理带载体，哪些不带

| 引理 | 位置 | 载体 |
|---|---|---|
| `models_zfcTr_iff V σ` | `Z0Full.lean:67` | 两端都带 `V` |
| `zfcTr_D3_standard σ` | `Z0Full.lean:108` | **只**在 `ℕ`（用 `provable_iff_provable`） |
| `provable_iff_provable` | `D1.lean:40` | **硬接线 `: ℕ`**：`Provable T (⌜φ⌝ : ℕ) ↔ T ⊢ φ` |
| `tprovable_tquote_iff_provable_quote` | `Typed.lean:171` | 载体多态，但**两端都带 `V`** |
| `internalize_provability` | `D1.lean:27` | `T ⊢ φ → Provable T (⌜φ⌝ : V)`；只能产生**同一句** `φ` 的内部形式 |
| `tprovable_iff_provable` | `Typed.lean:168` | `T.internalize V ⊢ ⌜φ⌝ ↔ Provable T (⌜φ⌝ : V)` 通用 `[T.Δ₁]` |
