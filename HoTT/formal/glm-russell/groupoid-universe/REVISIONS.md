# groupoid-universe 包修订记录（M1c 单元 2 探索史）

## 2026-09-26 深夜（会话尾）：单元 2 的路线侦察——三条死路、一个精确定位的呈现障碍

单元 2 目标：构造 `FAM : (x : Loop ℓ₀) → x ≡ x`（KS 的 ξ-族）的非平凡性，用于 `¬isGroupoid (Type ℓ₁)` 的总装。本轮探索记录（全部为分析身份，无机器主张）：

1. **死路 A（可判定族）**：试图在成员 `A := (Bool ≡ Bool)`（可判定 2 元集）上定义非均匀族 `FAM(L) := if L = refl then refl else L`。死于层级混淆（自查纠正）：`FAM(L)` 的类型是 `L ≡ L`（环路），不是 `L`；A 是集合 ⇒ `L ≡ L` 是命题 ⇒ 一切元素 = refl ⇒ 任何族都平凡。与"集合成员处引擎熄火"（GLM-R2-C02）完全一致。
2. **死路 B（sym-映射）**：`E := Σ-map(id, sym)` 是定义均匀、HIT-free 的 Loop 自等价，但 `ua E ≠ refl` 需要 `E ≢ idEquiv`，即某点 `(b,q)` 无共轭子 `r: r⁻¹qr = q⁻¹`。而 Loop 的底层环路群是对称群（b 的 X 的置换群），**对称群中每个元素都共轭于自己的逆**——逐点共轭 + funext 使 `E ≡ idEquiv` 恒成立。此死路与载体选择无关。
3. **死路 C（ξ-族的朴素呈现）**：KS 的 ξ-族需要 `d_q : PathP (λ i → q i ≡ q i) q q`（共轭方块）作为第二分量，而该陈述对抽象 q **不合式**（`q i0` 不归约，端点贴不上）。KS 论文依赖的判断性 Ω/Σ•/Π• 交换律在 cubical 里是命题性的——朴素翻译在类型检查层就断掉。
4. **存活的事实**：具体 ρ（= Σ-路径 `(ua e, isProp部分)`）的端点定义性归约（ua 边界）——单元 2 的所有构件应在具体实例上陈述（源码 TODO 已更正）。
5. **后继建议**（单开会话，本会话语境已尽）：ξ-族需要非朴素呈现，候选：(a) 对 Loop₀ 做 encode-decode（以 `b ≡ b`-环路码解码 Loop₀ 的路径空间——绕开抽象共轭）；(b) 点对类型（Pointed）框架下按 KS §4 的 Ω-分配律逐步构造（cubical 的 `Cubical.Foundations.Pointed` 有 Σ∙/Π∙ 基建）；(c) 把 ξ 只在两个生成元处具体化（c₀ 的 a-环与 b-环），用可判定的有限结构拼接非均匀族——注意死路 A 的教训：非平凡性必须来自 Loop₀ 点自带的环路数据（非集合性），不能来自值域。
