# dev-docs

本目录保存调查、候选方案、POC、debug 和未裁定工作。文件必须标明状态和证据；结论定型后
抽取到 `docs/`，不能让本目录成为第二份当前规范。

当前文件 `HoTT理论bug探讨文件索引.md` 是其他 AI 在整理阶段生成的来源导航，身份为
`HISTORICAL_ORGANIZATION_INDEX`。HoTT 当前结论不在该索引维护，而在
`../HoTT/AUDIT_AND_RECONSTRUCTION.md`。

该历史索引也不是 `aistudio-docs/` 中嵌入 HoTT 讨论的完整原文集合。当前高召回、逐字、可回源
视图在 `../HoTT/sources/aistudio-discussions/`；它同时处理问答、章节式文档与无标题正文，查询后
仍应回到 manifest 指定的原始源行区间。整理过程文档和摘要不得替代这套 raw corpus。
