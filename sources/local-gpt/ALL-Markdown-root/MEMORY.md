## 当前有效约束摘要

- 当前第一顺位 `CURRENT_REQUIREMENT` 为 HOTT-005/HOTT-006；相关问题必须先加载
  `HoTT/sources/user-originals/` 两份原文，再加载 `HoTT/Z_LAW_REALITY_RELATIVE_PARADOXES.md`、
  `HoTT/INTRINSIC_TEMPORALITY_OF_HOTT.md` 和主张矩阵。
- 恢复早期 HoTT 讨论或声称“历史资产中没有/已全部覆盖”前，必须查询
  `HoTT/sources/aistudio-discussions/` 的 CURRENT manifest/INDEX 并回到源行；不能假定所有源为问答。
- 固定四层语义：对象时间、弱操作时间、强内生时态、物理时间。不得以可编码性替代内生性，
  也不得忽略 λ-reduction 而声称绝对静态。
- 固定现实相对验收：计算合法性先于真值；有效现实前提被否定/删除且目标效应对它本质敏感时，
  完整现实过程—结论—现象谱 `X` 与理论谱 `Y` 分岔；命题判定只是二值特例。候选必须产生明确
  非现实过程/结论/现象，不能用一般信息损失、无关前提翻转或 no-section 替代。
- 固定完成性提升：G4 包含 `FORMATION_PROMOTION`（未落定 specification→完成对象）和
  `REALITY_PROMOTION`（有界表示→现实完整身份）。Russell 属于前者。
- 固定基础原则边界：理论构建者删维是为了简化、统一和工具能力，不是为了制造悖论；本项目把
  proper abstraction 定义为实质否定至少一个现实区分，因而必有悖论潜势。它不表示每条推论错误；
  具体 HoTT 悖论须有五项实例证据。对外无条件全称仍须量词域和非循环桥梁。
- 固定 Z 最高定性：`Z_STRONG_PHILOSOPHICAL_LAW = 理论抽象必然导致悖论`。必然是完整效应谱中
  至少一个对应、本质敏感效应分岔；技术“潜势／显现”分层不能降格该项目原则，亦不能冒充项目外
  全称定理已经完成。
- 固定程序解释边界：静态无固定点、形成不准入、有限可拒绝约束、修订振荡、运行发散和一般
  不可判定停机是不同结论，必须逐实例证明。
- 固定 AI 认识纪律：`USER_MATH_PHILOSOPHY_FIRST / EVIDENCE_CRITICAL`；先读原文并输出
  `WITHIN_USER_MATH_PHILOSOPHY`，再输出 `STANDARD/EXTERNAL_COMPARISON`。禁止 consensus-first，
  也禁止 user-assertion-is-proof。
- 当前稳定边界是“标准 HoTT 有计算箭头但 temporally unindexed”；同函数异时是第一候选，不是
  HoTT 内部矛盾；跨变体 no-go 与 Guard-Erasure 具体翻译仍为 gap。
