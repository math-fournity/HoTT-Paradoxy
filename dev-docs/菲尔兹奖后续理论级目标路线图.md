# 菲尔兹奖后续理论级目标路线图

> 身份：`DRAFT_ROADMAP / HUMAN_EDITED`。
> 当前约束：F-025/F-026 已采纳；候选尚未由研究发起人选定；已授权有界来源卡研究；没有新的 Goal、STATE candidate、数学证明或发布动作。
> 目的：保存 2026-10-02 多轮选靶讨论的分层结论，让未来工作从“基础理论靶标”而不是“单一定理的惊奇现象”开始。菲尔兹论文库是可选的高价值入口，不是每个候选的准入门。

## 权威边界

- 用户关于选靶层级的直接裁定由 [rulings.md](../rulings.md) 的 2026-10-02 节拥有；当前要求由 [feature-list.md](../feature-list.md) 的 F-025 拥有。
- 本路线图组织 AI 的候选、比较、来源计划、控制与停止条件；它不替代用户裁定，不把 AI 推荐写成已采纳目标。
- HoTT 的原问题、UR、圆环、罗素式过程与证据门仍以 [核心认知.md](../核心认知.md)、[扩展认知.md](../扩展认知.md)、[最高指示.md](../最高指示.md) 和项目当前 owner 为准。
- `dev-notes/0107`、`dev-notes/0108` 与 `.claude/` 下的 CN-054、CN-055、CG-004 是本路线图的历史讨论输入。它们不自动获得 current-truth 或执行资格。

## 如何使用

1. 先读本索引及全部九个分片，再读 F-025、F-026 与相应的用户裁定。
2. 用第 002 片的层级检查候选：论文可作为进入某个理论的原典、消费者、对照或证据入口；菲尔兹关联只在用户明确限定该次任务时才是额外范围条件。
3. 对 ZFC 或其它罗素之后理论，先按第 007 片执行有界的模式 P 资格化；只有研究发起人选定具体理论 T，且对象通过该资格门后，才可按第 005 片建立具体来源／消费者研究任务。本路线图本身不创建 Goal 或 STATE candidate。
