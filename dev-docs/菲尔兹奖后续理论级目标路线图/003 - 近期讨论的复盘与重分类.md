## 3. 这轮留下的四条可复用教训

1. **先问“谁是靶”，再问“哪里有怪现象”。** 定理是入口或现象，不是自动的理论靶。
2. **准确的定理前提是生成候选的约束，不是候选生成前的消音器。** 不能在定理假设里寻找对定理的反例，也不能略过它的范围。
3. **标准回答也是研究对象的一部分。** 极限、截断、forcing 的元理论分层、内部存在的局部语义，都必须写清它保住或改变了什么。
4. **机器骨架不替主理论背书。** 一个 Kac 环、有限模型或 Lean 编码只能证明自己的精确命题；来源定理、解释桥和 UR 判定须分别报告。
