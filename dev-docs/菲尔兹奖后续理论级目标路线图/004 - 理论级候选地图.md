### 候选过程，不是结论

原任务 X_i 可暂定为：取得一个满足全部指定要求、且能在同一体系中整体使用的对象。

过程 P 可暂定为：给定模型 M 与其稠密要求，逐项构造或追踪 generic G，随后检查从 M 到 M[G] 的每一步究竟由谁完成、何时有资格把 G 交给成员关系、量词与算符。

需要观察的不是“forcing 神秘不神秘”，而是：

1. 有限阶段只满足有限要求时，何时能够称 G 已形成；
2. M、外部元理论与 M[G] 各自拥有或不拥有 G 的何种意义；
3. 论文／使用者是否把外部形成的 G 冒充为 M 已持有的对象；
4. 任何所谓“完成”是否替换了原任务的完成标准。

### 正控制、标准回答与撤回条件

- **正控制：** 对外部可数模型及明确枚举的稠密集，存在逐步构造 generic 的标准路径。它防止把“尚未在 M 内拥有”说成“任何现实构造都无法完成”。
- **标准回答：** forcing 明确区分基础模型、外部元理论和扩张模型；generic 并不被宣称为基础模型原有对象。
- **撤回条件：** 若所有实际消费者都保留此层级区分，且没有把局部／外部／扩张后的获得冒充为原模型内已完成取得，则本候选只能保留为正确的元理论分层或表示边界。

### 首批原典问题

- Cohen 1963 论文怎样固定 M、新对象和 N 的关系？
- 何处由外部可数性、枚举或元理论提供了构造资源？
- M[G] 的对象形成与真实集合形成公理的关系是什么？
- 现有 forcing 教材如何严格区分“模型中存在”“外部构造”“扩张中成立”？

### 2026-10-02 启发式发现态：ZFC-H1

本轮用户授权先利用 AI 的内在数学知识生成候选，再回源核验。由此得到的初始机制种子是 `ZFC-H1 / MODEL_RELATIVE_AVAILABILITY`：

> ZFC／模型语义为了把对象、成员关系和量词放入一个可推理的完成宇宙，会把“在某个模型中存在”写成可用的对象事实；而在 forcing、Skolem 和外部构造中，真正完成构造、持有见证和允许后续使用的行动者并不总是同一个。

这不是结论，也不是对 forcing 的现有标准分层的反驳。Cohen 1963 原典首审已明确区分外部可数 `M`、不必在 `M` 中的新集合、非 `M`-definable 的条件序列与生成的 `N`，故 forcing 原典本身目前是 `DEFENSE_WORKS_WITH_EXPLICIT_LAYERING`。H1 仍保留 Skolem 能力支路，并只在发现实际消费者把外部完成、扩张内存在或外部枚举冒充为原模型内可用交付时重开。具体多机制种子、淘汰条件和来源义务见第 006 片。

同一发现态还产生 `ZFC-H8 / COMPLETED_PREDICATE_SET`：对带无界计算追溯的谓词，Separation 可能被误读为把“满足该谓词的对象形成一个集合”升级成“成员资格已被同一过程完成并可交付”。本轮已读 `ax-sep` 的形式：它只给固定公式的受界子集存在，并不承诺算法或成员决定器；故 H8 在公理层已降为 `AXIOM_LAYER_DEFENSE_WORKS / CONSUMER_QUESTION_OPEN`。它保留停机表、有限正控制和“set existence 不等于 effective decision”作为消费者审计探针。

这项防线同时产生了更基础的 `ZFC-H9 / SCHEMA_OPERATOR_CLOSURE`：ZFC 的 Separation 是按外部固定公式给出的 schema，不是宇宙内部读取任意公式代码并输出其扩张的统一 `Build`。若后者被要求在整个 `V` 上正确工作，便需把真值／满足关系作为对象层能力；这个 schema—operator 缺口是初始机制线索，现为 `P_REQUALIFICATION_REQUIRED`，需要 Tarski 原典、精确语言规格、真实消费者和罗素模式 P 的完整资格才可继续。

### 2026-10-02：罗素模式 P 的重新资格门

用户随后纠正了本卡的起点：ZFC 的最大可疑处应先从时间／时序、构造过程、存在性与自指交会的罗素模式 P 寻找，而不应由 H1–H9 的表面机制直接选靶。故 H1–H9 全部降为 `P_REQUALIFICATION_REQUIRED`：每一条都须先回答，理论究竟**不能不收进论域**的对象是什么；对象能否被诚实地外置、分层或改码（不能则才通过“不可另账”）；其存在性／合法身份追问是否有直接自指或无终点的上升依赖；以及理论是否在该追问完成前，已经让核心算符把对象当作可用输入。详细模式、控制与 ZFC 的首批对象清单由第 007 片拥有。

这项修订尤其改变 H9 的身份：formula schema 与 `Build` 的差异本身还不是罗素命中，因为 formula extension 未必是 ZFC 不能不收进的论域元素，`Build` 也未必是理论已经承诺的算符。它只保留为可能承载 P 的元理论支路，不能再被称为当前首选。

### 最小过程

用圆周二重覆盖 p:S¹→S¹，p(z)=z² 的局部截面 sheaf A：

- 每个足够小的圆弧有局部截面；
- 内部语言可按局部语义表达“存在 a:A”；
- 整个圆周没有连续全局截面。

原任务是“在整个圆周上选定一个可整体使用的对象”；过程是沿圆周延续局部选择并要求首尾相合；完成是得到全球一致截面。

这不是形式矛盾。理论的标准回答正是：内部存在意为局部存在，不承诺全局选择。只有找到某个实际消费者把内部存在提升为全局可用，才可能形成 B 向候选；否则应降为理论准确标出的局部／全局差异。

## FND-STRUCT-005：ETCS 的结构不变性与选择公理

这不是“所有范畴论”的泛泛候选，而是 Lawvere 的 **Elementary Theory of the Category of Sets (ETCS)** 及其选择公理所构成的一种精确的结构主义集合基础。它由用户授权推进，不以菲尔兹奖关联为准入条件。

| 字段 | 当前内容 |
|---|---|

| 基础资格 | `G0_SOURCE_SUPPORTED`：Lawvere 将 ETCS 明确写作集合论基础，并以同构不变结构和泛性质而不是 ZF 的成员关系作为基础表达方式。该历史／理论事实来自 [Lawvere 2005 长版](<https://pages.jh.edu/rrynasi1/FoundationsOFMath/Literature/Lawvere2005AnElementaryTheoryOfTheCategoryOfSets%28LongVersion%29WithCommentary.pdf>) 第 2–3 页与原文第 7 页；未被本项目形式化重放。 |

| 初步可疑转换 | 将“有一个具体的、可随呈现变化而被取用的选择”压缩为“存在一个选择映射”，同时不携带使选择在全部自同构下保持兼容的标记、来源或自然性数据。 |

### 首个过程卡：不是 UR 的近失候选

Lawvere 的 Choice 公理表述为：若映射 `f` 的定义域有元素，则存在 `g` 使 `f g f = f`；他随后给出通常的族选择函数形式。取一个二元素对象到终对象的映射，并观察其交换自同构，得到两种容易混淆的任务：

| 项 | 普通选择任务 `X_any` | 被偷偷加强的自然选择任务 `X_nat` |
|---|---|---|
| 输入 | 一族非空对象／纤维 | 同样的结构性输入，但允许所有同构与自同构重呈现 |
| 操作 | 给出某个选择函数或 quasi-inverse | 给出选择，并要求它对所有这些识别兼容 |
| 完成 Done | 每个纤维获得某个元素 | 输出不因任何自同构而改变 |
| ETCS / Choice 的承诺 | 提供 `X_any` 所需的存在性／选择性资源 | **没有**承诺这个额外的自然性条件 |

这正是 Gemini “Identity Scar” 旧说法遗漏的分界。它把“对象可按结构替换”误写成“任意选择也必须自动与所有同构兼容”。后者已经是另一项更强的任务，不能把它的失败反投回前者。

### 已有机器边界只能作控制，不能替 ETCS 背书

本项目已有 `MP-NOCANONICAL-001`：在固定 Cubical Agda 配置中，

```text
UnlabeledTwoElement = Σ[ A ∈ Type ] ∥ A ≃ Bool ∥₁
```

没有统一选点；交换自同构会迫使假想输出成为 `not` 的不动点。保留明确标签 `A ≃ Bool` 时，存在 `labeledChoice`。源码在 [NoCanonicalPoint.agda](../../HoTT/formal/truncation-no-recovery/NoCanonicalPoint.agda)，保存的运行收据是 [MP-NOCANONICAL-001-02](../../HoTT/verification/runs/20260913-MP-NOCANONICAL-001-02/RUN.json)。

这是与 `X_nat` 同形的 **Cubical／单价性控制**，不是 ETCS 的定理，也不证明 ETCS、范畴论或 ZFC 有问题。当前矩阵仍把该证明包的项目状态限定为局部范围；它只说明：一旦输入真的遗忘了标签并要求 transport-coherent output，额外选择不可以免费取得。

### 第一个真实消费者控制：Mumford 的模空间与 universal family

这条线不必依赖菲尔兹奖入口才能成立；本轮选择 Mumford 1965 的原始模空间论文，是因为它恰好把“同构类”与“具体代表族”放在同一任务现场。原始扫描件 [*Picard Groups of Moduli Problems*](https://www.dam.brown.edu/people/mumford/alg_geom/papers/1965b--PicGpMod-EmeryScan.pdf) 的第 33–34 页明确写出：所有非奇异曲线的 universal family 并不存在；当曲线没有自同构时，才有相应的 universal family；若要研究一个 definite model 的不变量，则必须面对“选哪一个模型”的问题。第 37 页进一步说，允许非平凡自同构后，仅说对象覆盖已不够，必须指定具体映射；这是原典自己支付的结构数据。

这是一条真正的消费者链：

| 字段 | Mumford 原典中的情形 |
|---|---|
| 结构性输入 | 曲线按同构分类的模问题／通常的 coarse moduli variety |
| 被要求的具体输出 | 一族可由唯一参数映射拉回的 universal family，或一个 definite model |
| 障碍 | 非平凡自同构；仅有同构类不足以给出整个代表族 |
| 正控制 C+ | 限制为 automorphism-free 非奇异曲线时，原典明确报告有 universal family |
| 标准回答 C− | 原典没有把 coarse classification 说成已经给出 universal family；它公开保留失败，并转向保留更多结构的对象与映射 |

因此这个真实消费者的本轮判词是 `REAL_CONSUMER_CONTROL / DEFENSE_WORKS_WITH_EXPLICIT_PAYMENT`：它证明结构主义／模空间语言确实会遇到代表和自然性的边界，却没有把边界伪装成同一任务已经完成。它不能成为 ETCS 的 UR 见证，反而给后续候选立下更严格的正控制。

### 第二个真实消费者控制：Mathlib 的 `IsIso` 与唯一逆

固定到 mathlib4 commit `8e30cac82f69c18f6cbe88799bdc3ebd74cc592d` 后，[`Mathlib/CategoryTheory/Iso.lean`](https://github.com/leanprover-community/mathlib4/blob/8e30cac82f69c18f6cbe88799bdc3ebd74cc592d/Mathlib/CategoryTheory/Iso.lean) 给出一个软件中的结构主义使用场景：`IsIso f : Prop` 只保存“存在 inverse”的证明，`inv f` 确实以 `Classical.choose` 取回具体逆，而 `asIso f` 是 noncomputable 的。

这表面上像“从 mere existence 取具体见证”，但源码紧接着说明 inverse 唯一，并用这个唯一性建立 `map_inv`：任一函子都把所取逆送到映像态射的逆。于是它的消费者性质是：

| 字段 | Mathlib `IsIso` 的情形 |
|---|---|
| 结构性输入 | 一个态射可逆的 Prop 证明 |
| 具体输出 | inverse morphism |
| Choice 的位置 | `Classical.choose` 从存在证明取出 inverse；明确标为 noncomputable |
| 为何没有 `X_nat` 失配 | inverse 在范畴论中唯一，故所取对象可由唯一性证明兼容，不依赖任意标签或代表选择 |
| 标准回答 C− | 这是 unique-witness extraction，不是从有自同构的对象类任意挑一个点或代表 |

其判词是 `REAL_CONSUMER_CONTROL / UNIQUE_WITNESS_DEFENSE`。它进一步排除了一个过宽的攻击法：**“代码或理论用了 Choice”不等于它把非唯一对象偷渡成自然对象。** 此后 E6 搜索必须明确要求输出在给定结构输入下存在真正的多重候选，并检查消费者是否仍不声明破缺对称所需的数据。

### 第三个真实消费者控制：mathlib4 的范畴 skeleton

同一固定 mathlib4 commit 的 [`Mathlib/CategoryTheory/Skeletal.lean`](https://github.com/leanprover-community/mathlib4/blob/8e30cac82f69c18f6cbe88799bdc3ebd74cc592d/Mathlib/CategoryTheory/Skeletal.lean) 是更强的压力测试。它直接把任意范畴的对象按同构类取商，构造 skeletal category；这一次输出确实涉及每个同构类的具体代表，因而有真正的非唯一性风险。

源码的处理没有隐去这笔账：

| 字段 | mathlib4 `Skeleton C` 的处理 |
|---|---|
| 结构性输入 | `Quotient (isIsomorphicSetoid C)`，即对象的同构类 |
| 具体代表 | `Quotient.out` 取得代表；`fromSkeletonToSkeletonIso` 用 `Nonempty.some` 取得代表到原对象的具体同构 |
| 支付的可计算性 | `fromSkeleton`、`toSkeletonFunctor`、`skeletonEquivalence` 与相关映射显式标为 `noncomputable` |
| 支付的相干性 | `skeletonEquivalence` 保存 unit/counit isomorphisms；`toSkeletonFunctorCompMapSkeletonIso` 给出 natural isomorphism，而不是把代表选择说成定义性相等 |
| 标准回答 C− | skeleton 提供的是等价范畴与带见证的转换，不是一个无代价、自然且可计算的全局代表选择 |

其判词为 `REAL_CONSUMER_CONTROL / NONCOMPUTABLE_COHERENT_REPRESENTATIVE_DEFENSE`。它是历史 Gemini 叙事最直接的反控制：真实系统可以选择代表，但选择不会“污染”原对象；它被显式标记为非计算，并通过具体同构和 natural isomorphism 保留转换责任。

### 当前裁决：同一任务门尚未通过

`FND-STRUCT-005` 现在通过了理论基础位置与来源入口的初检，也有一个清楚的机制与正控制；但它**尚未通过 G3/G4**：

- 将 `X_any` 换成 `X_nat`，改变了完成条件；不能把这个新条件伪装成 ETCS 已承诺的原任务。
- ETCS 的标准回答是强的：Choice 可以给出一个选择，但它并不许诺其对所有自同构自然；若需要自然性、标签、标记、顺序或来源，必须把它们作为额外输入。
- 因此当前结果是 `STRUCTURAL_CHOICE_BOUNDARY / NOT_UR_YET`，不是“ETCS 的非现实性悖论”。

### 下一项有界判别

只有找到另一个真实、版本固定的结构主义／ETCS／范畴论消费者，同时满足下列四点，才允许重开为 UR 候选：

1. 输入只保留同构不变的结构或 mere existence；
2. 后续实际操作要求一个具体、自然或可兼容的选择；
3. 消费者仍声称完成的是同一项任务，而没有显式加入标签、Choice、标记或相干数据；
4. 在加入相应数据的正控制中，原任务确实成功。

Mumford 1965、mathlib4 `IsIso` 与 mathlib4 skeleton 是三个已审真实消费者，分别以“明确保留自同构成本”“唯一见证可安全取回”“非计算代表选择 + 显式相干”落在标准回答一侧。它们形成 `STRUCT-001` 的三消费者有界分母：在此分母内未发现 E6，故 `FND-STRUCT-005` 从 `DRAFT_CANDIDATE` 降为 `DEPRIORITIZED_WITH_SCOPE / REUSABLE_CONTROL`。此前对 Cubical v0.9 及若干固定 partiality／truncation／univalence／成本来源的 `N1` 审计也只给出有界负结论：被检查的接口把选择、相干或细化明确列为假设／数据／类型围栏。这个组合证据不外推到 ETCS、所有范畴论或所有结构主义数学。

### 3. 可复用的不是“ZFC 有矛盾”，而是一组负控制

“身份疤痕”失败的位置恰好能帮助未来防止把表示差异误报为基础理论悖论。对于 `FND-SET-001` 或任何集合论／结构主义候选，都先固定下列层级：

1. **被编码对象与抽象对象：** 当前讨论的是一个具体 ZFC 集合编码，还是一个群、范畴对象或别的抽象结构？
2. **见证与对象：** `f` 是任务输入、一个存在性见证，还是后来选择的具体同构？如果观察依赖 `f`，对象应写成 `(G,H,f)` 或一条箭头，不能把它悄悄写成只关于 `G` 的性质。
3. **语义与证明历史：** 证明、发现或记录 `f` 的行为是否被误当成改变数学对象的事件？若声称发生“污染”，必须给出 pre-state、post-state、允许操作与同一任务的观察量。
4. **不变量与可选择性：** 需要的结论是对所有同构自然成立，还是要求一个具体同构、自然选择或兼容的 transport？后者是 canonicity／naturality／选择的任务，不能借“同构即可替换”这一句话完成。

至少设置三项反控制：`G=H, f=id_G`；同一对象上的非恒等自同构；以及两个不同底层集合但明确同构的群。它们的作用不是证明一个宏大结论，而是检查候选究竟谈的是对象、一个带箭头的图式，还是叙述者加入的证明历史。
