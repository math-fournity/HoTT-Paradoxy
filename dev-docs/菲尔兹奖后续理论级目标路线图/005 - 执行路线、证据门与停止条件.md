# 执行路线、证据门与停止条件

## 1. 尚未选靶时能做什么

当前可做的是只读准备，不是开始研究：

1. 维护本路线图与 F-025 的一致性；
2. 为每条候选建立来源清单、理论范围和标准回答清单；
3. 读取原典前先确认本地 PDF、MinerU 审计状态与公开来源；
4. 记录候选的未知、撤回条件与需要研究发起人判断的 UR 句；
5. 保持所有候选为 `AI_RECOMMENDED_CANDIDATE` 或 `DRAFT_PROPOSAL`。

不得因为路线图存在就创建 Goal、修改 STATE、下载大文件、形式化玩具、向外部发送审计请求或把“当前推荐”写成“用户已选”。

## 2. 用户选定理论后的一条短链

| 阶段 | 输入 | 动作 | 通过条件 | 失败／返回 |
|---|---|---|---|---|
| P0：冻结理论 | 用户选定的 T | 固定版本、理论层级、来源入口与消费者；仅在用户限定时补菲尔兹入口 | T 通过 G0 与来源入口资格 | 若只剩论文或定理，回选靶 |
| P1：来源卡 | 原典与权威综述 | 写规则、假设、模型、量词、语义层级 | 关键句有原典 locator | OCR、二手转述不足时回源 |
| P2：发现种子 | T 的真实收益与取舍 | 写 E／T→T′／P／O 一句话与外行版 UR | 能清楚说出理论为何好用、过程为何敏感 | 只有“惊奇”或“信息损失”时换靶点 |
| P3：任务忠实 | X_i、Op、O、Done | 逐项比较现实／假想现实与理论任务 | 不偷偷增加全称、统一解或新观察量 | 换题则降为表示差异 |
| P4：控制与防线 | C+、标准回答、C− | 说明保留条件时何以成功，防线恢复或改变什么 | 最强反解释被公平处理 | 防线保住原 X_i 时撤回强判词 |
| P5：精确命题 | 已固定的可核证子命题 | 选择形式化骨架、来源审计或模型检查 | 命题与短链一一对应 | 只做玩具时明标玩具范围 |
| P6：交付与审计 | 完整短链 | 分开写来源定理、机器事实、AI 解释、用户判定 | 读者可逐层反驳 | 缺层即降级，不用文采补证据 |

## 3. 证据与机器证明门

机器证明只能承担已经固定、且与短链相称的数学命题。它不能替代：

- Cohen、Grothendieck、Quillen 或其他论文主定理的本项目重证明；
- “理论基础有问题”的哲学判词；
- 现实／假想现实任务与形式命题之间的解释桥；
- 用户对 UR 是否一眼不合理的判断。

若后续选择形式化，须按 F-011：源码、环境、真实 kernel run、负控制、RUN 收据、claim/proof/run 索引齐全；未满足时只写 `QUESTION`、`CONJECTURE`、`HEURISTIC`、`PAPER_ONLY` 或 `SOURCE_REPORTED_NOT_REPLAYED`。

## 4. 来源与论文库边界

- Cohen 1963 原文及 MinerU 文本已在本地菲尔兹库；MinerU 只是阅读辅助，关键术语和定理范围回 PDF／权威版本。它是 FND-SET-001 的可选历史入口，不是该候选的理论资格来源。
- SGA 4 是 topos 路线的原典，但当前 Grothendieck 目录不含它；公开网页阅读可用于预研，下载或入库另按用户授权与论文收集流程执行。它同样是可选来源，不是准入门。
- 未审完的本地 MinerU 文本不能承载关键结论；先查论文库的 `AUDIT-INDEX.md`，再回原 PDF。
- 外部论文声称只作为来源转述，不升级为本项目机器结论。

## 5. 停止、撤回与换靶

允许且应当如实记录的结局：

1. 标准理论语义完全保住同一 X_i：候选撤回或降为正常表示边界；
2. 过程依赖研究者私自加上的条件：修正过程或撤回；
3. 理论级资格不足：降为论文级对照；
4. 原典表明 proposed P 在假设内为空：换过程或换靶；
5. 只有来源报告、没有本项目证明：保留来源级主张；
6. 用户判定 UR 不成立：停止该候选，保留理由，回 P0。

不能把“未找到”写成“理论没有问题”，也不能把“理论有层级／局部语义／外部元理论”自动写成“理论假装完成”。

## 6. 未来接手者的最短路线

1. 读本索引与全部五片，读 F-025 和 2026-10-02 用户裁定；
2. 确认研究发起人是否已选 T；未选时只能更新来源卡和比较，不启动研究；
3. 若选 FND-SET-001，先读 Cohen 原文、现代 forcing 教材的模型／元理论边界，再写 P1；
4. 若选 FND-TOPOS-002，先读 SGA 4 的 universes/topos 部分与内部逻辑来源，再写 P1；
5. 若选 FND-STRUCT-005，先读 Lawvere 的 ETCS 原典、选择公理的精确形式与真实使用者，再检验规范选择是否保住原任务；
6. 每个强结论都按“来源事实／AI 判断／机器命题／用户判定”分层写出。

本路线图的停止条件不是“列出足够多理论”，而是：研究发起人已能在一张完整候选卡上选定一个真正的理论靶，未来执行者不会把论文、过程、定理、基础框架和已证明结论重新混在一起。
