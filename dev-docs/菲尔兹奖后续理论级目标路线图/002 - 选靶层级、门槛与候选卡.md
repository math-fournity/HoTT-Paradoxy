# 选靶层级、门槛与候选卡

## 1. 七层选靶模型

后续工作必须按下列顺序思考。菲尔兹论文库可以提供强原典入口，但不能从最醒目的论文标题倒推问题，也不能成为理论候选的必经门。

| 层 | 必答问题 | 合格产物 |
|---|---|---|
| L0：用户判据 | 什么算 UR？谁判定“不合理”？ | 用户裁定、UR 原话与适用范围 |
| L1：理论靶标 T | 这是否真是基础、共同语言或大范围数学基础设施？ | 精确理论名、版本／变体、广泛消费者 |
| L2：可选来源入口 I | 哪项原典、实际消费者、历史材料或菲尔兹得主工作能帮助进入该理论？ | 可追溯来源与它在候选中的角色；若用户限定菲尔兹范围，再补奖项材料与论文库定位 |
| L3：理论取舍 E, T→T′ | 它为了什么经济性／普适性省去、合并、提前交付或理想化了什么？ | 一句可反驳的发现种子 |
| L4：同一任务 X_i | 现实／假想现实侧与理论侧的对象、输入、操作、观察、完成如何逐项对齐？ | X_i、Op、O、Done 卡 |
| L5：敏感过程 P | 什么过程恰好使被改条件重新决定结果？ | 有限步骤、预期反差、邻近对照 |
| L6：核证与边界 | 标准回答、正控制、最强反解释和证据等级是什么？ | C+、C−、来源／机器／现实三层证据 |

L1 是本轮新加入的防偏航门。没有理论级 T，后面的定理再漂亮也不是本项目的“下一靶”。

## 2. 候选升级门

### G0：理论基础资格

必须能说明该理论至少满足下列之一：

1. 被明确提出、采用或实际承担为数学基础；
2. 是某个成熟领域不可替代的共同语言或基础设施；
3. 规定了该领域中什么算对象、什么算形成、什么算相同、什么可被操作或何时算完成。

“知名”“困难”“得过菲尔兹奖”“影响很多论文”均不足以单独通过。

### G1：来源入口资格（菲尔兹关联可选）

必须定位足以核验理论定位、规则、消费者或历史作用的原典／权威来源。若用户明确限定本次从菲尔兹奖得主工作中选择，再额外定位一位得主的具体原典、工作报告或可追溯贡献。任何来源关联只证明入口相关，不证明理论由作者独创，更不证明理论存在问题。

### G2：过程资格

候选必须有一条人能复述的种子句：

> 理论为了 E，把原任务所依赖的 T 改成 T′；我用 P 让 T 再次重要，预计同一任务中的观察 O 或完成 Done 改变。

若只能说“这个定理很难”“它丢了信息”“它有一个独立性结果”，就尚未通过。

### G3：同一任务资格

不得把现实侧的一次具体完成，暗中换成理论侧的全称分类、统一规范解或不同观察量。若比较的是两个任务，须如实标作表示／合同差异，不能当作 UR。

### G4：标准回答资格

每条候选必须正面写出理论的标准防线：

- 它恢复了被省去的条件吗？
- 它把完成条件改成了局部、截断、模型外、扩张后或别的任务吗？
- 它有没有明确区分理论内、元理论、证明器与现实解释？

若标准防线完整保住 X_i，候选应降为表示差异或正常理论限制。

### G5：证据资格

| 断言身份 | 所需证据 |
|---|---|
| 历史／论文事实 | 原典或权威来源；MinerU 文本只是阅读辅助 |
| 理论规则 | 原始定义、标准教材或形式化系统的精确规则 |
| 数学结论 | 项目 F-011 的 source/run/index 门；否则只能是来源转述或候选 |
| 现实对应 | 现实或理想实验的对象、操作、观察、完成桥；不能由类比本身认证 |
| AI 推荐 | 明标判断／建议，并写可推翻条件 |

## 3. 状态词汇

- `USER_RULE_ACCEPTED`：用户已裁定的选靶原则。
- `AI_RECOMMENDED_CANDIDATE`：AI 当前排序上的候选，不等于用户已选。
- `DRAFT_PROPOSAL`：尚未被当前 owner 接纳的笔记、工作包或预案。
- `RESEARCH_NOT_STARTED`：未建立具体研究会话、任务规格、STATE 记录或证明包。
- `SOURCE_REPORTED_NOT_REPLAYED`：论文或权威来源报告的定理，未被本项目机器重放。
- `REJECTED_AS_TARGET_LEVEL`：可留作对照，但不再是下一基础理论靶。

## 4. 一张最小候选卡

每个进入实际选择的理论只需一张卡，但卡必须完整：

~~~text
ID / 身份：
理论 T 与版本：
基础资格与消费者：
来源入口 I（菲尔兹关联如适用）：
收益 E：
T → T′：
原任务 X_i：
允许操作 Op：
过程 P：
观察 O：
完成 Done：
正控制 C+：
标准回答 / 最强反解释 C−：
原典、证据等级与未知：
撤回 / 换靶条件：
~~~

该卡用于发现后的核证，不把填写表格本身冒充成发现。
