# 刀具系统理念

> **身份：** `CONCEPTUAL_ENTRYPOINT / USER_DIRECTED_WORKING_CONSCIOUSNESS / NOT_A_MATHEMATICAL_RESULT`。
>
> **用途：** 为 P1、P2、P3 和动态 DAG 提供一次可复用的起点：为什么要锻这三把刀，罗素悖论在计算视角下留下的张力是什么，案例怎样参与校准，何时该修旧刀、停止，或认真提出新刀。它不取代用户原文、当前刀具规格、NodeCard、来源审计或数学证明。

## 如何使用

1. 新开、压缩恢复或改变 P-DAG 的语义任务时，先读本索引和下方分片；再读当前任务的三把刀索引、相关单刀、动态 DAG SOP 与 TaskCard。
2. 要修改一把刀、重定义成功、提出新刀或使用“原初理念已被完整实现”一类强判断时，继续读 [全历史逐段理念—实作对照审计](<../audit/20261002-P-DAG-刀具系统全历史逐段对照审计.md>)；它拥有逐段来源、运行和 Git 证据。
3. 要判断某项理论命题是否成立，回到原典、形式证明或相称的运行证据。本文件只保存工作意识和路线，不能支持 ZFC、HoTT、朴素集合论或任何数学系统的矛盾结论。
