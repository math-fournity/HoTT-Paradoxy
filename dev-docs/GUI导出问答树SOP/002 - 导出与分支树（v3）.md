## 3. 自有轮与分叉的定义

- 每轮归属于它所在 rollout 的线程（owner thread）。子分支只继承父段的前缀；前缀轮只存在于拥有它的分支文件夹中，不复制。
- 分叉节点：分支第一条自有轮之前的那一轮（属于父分支或更早的祖先）。它在 `_branch.json` 的 `fork` 中给出父分支、父分支中的轮号、父 rollout 的双条件切点（字节偏移与序号，均为排他）。
- 切点规则与 README 一致：父 rollout 只继承字节偏移小于 B、且序号小于 N 的记录。

## 4. 不可见尾部

- 8 个段共 9 轮，位于切点之后，未被任何 GUI 导出引用（`qa/_tree.json` 的 `invisible_tails`）。
- 它们已逐轮导出到 `qa/_unexported/<rollout>/`，单元名为 `unexported-<rollout 前 8 位>`。标注时须写明“未在任何 GUI 导出中”。
- 它们可能属于未导出的分支（例如 dev-05，或废弃的分叉）。不得据此把它们并入任何已有分支。

## 5. 清单与哈希

- `qa/_manifest.json`：规范导出器的 SHA-256、各导出的谱系与切点、源 rollout 的 SHA-256 与字节数。
- `qa/<分支>/_index.jsonl`：每轮的源 rollout、行号区间、字节区间与源字节的 SHA-256。
- 文档头部的 `source_sha256` 与 `_index.jsonl` 一致。源未变时，导出器重跑后两者逐字相同。
