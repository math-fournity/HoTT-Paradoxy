# ZFC-Q-CORPUS-MAP-SOP：ZFC Q 可追溯语料落盘、MinerU 与文献地图

> **身份：** TASK_SCOPED_CORPUS_RESEARCH_SOP / Q_DISCOVERY_SUPPORT / NOT_A_THESIS_OR_AUTOMATIC_Q_CLAIM。
>
> **调用名：** `ZFC-Q-CORPUS-MAP-SOP`。
>
> **调用词：** `按照SOP=\`ZFC-Q-CORPUS-MAP-SOP\`,继续推进，直至本轮冻结语料没有可获取、可处理、可映射或可资格化的下一项。`

## 目的

本 SOP 将与发现 ZFC Q 有关的文献工作连成一条可追溯主链：

```text
Corpus scope → Work identity → Acquisition → PDF validation → MinerU derivative
             → bibliography/citation map → Q LeadCard → specialized R/Z/Q/E analysis
```

目标是尽可能形成可读、可核验、可继续扩展的语料和线索，服务模式 P、Power Set、H0→Z0 与未来明显理论位置。博士级的元素只用于保证检索质量、覆盖与可回溯，不把工程变成博士答辩项目。

## 与已有项目的关系

- `HOTT-MOTIVE-ZFC-SOP`：HoTT创建动机反投影的专门来源／候选支线；其已存档来源是本语料工程的 seed／control。
- `P-FORGE-SOP`：只消费已资格化的 Q lead；总语料项目不自行启动 worker、P-DAG或刀具。
- 原 PDF：作品内容权威；MinerU输出：派生阅读与检索层；地图：发现与覆盖层；Q Card：候选资格层。
