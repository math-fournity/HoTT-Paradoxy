# 新刀具出生与花纹宇宙合同

> **身份：** `TOOL_BIRTH_CONTRACT / PATTERN_UNIVERSE_AUDIT / NOT_A_DEFAULT_P4_FACTORY / NOT_A_MATHEMATICAL_THEOREM`。

## 1. 为什么三把刀不是封闭宇宙

P1、P2、P3 是经过当前证据锻成的三个惯性系：它们分别偏向理论对象／形成与同一任务、语言回代与极性、构造准入与完成次序。这种分工既给工具以力量，也会限制它们自然看到的“花纹宇宙”。

未来花纹可能有三种命运：它实际上落在旧刀的字段缺口中；它是两把或三把刀交界处的派生结构；或者它带有一个旧刀会扭曲、抹去或根本无处登记的独立理论判断职责。第三种情况允许产生新刀，但**新奇、困难、AI 不同意或已有刀具暂时无结果都不够**。

## 2. `Tool-BirthCard`：先做容纳审计

每个候选 `NEW_PATTERN` 必须先有一张冻结 `Tool-BirthCard`，并且完成下表；没有卡片时不得命名“P4”或把旧刀的空缺当成新刀。

| 字段 | 必须回答的事 |
|---|---|
| `pattern` | 最小可复现结构：理论变体、对象、输入、过程、观察、Done、一个相邻反控制。 |
| `inertia challenge` | 为什么 P1/P2/P3 的既有关注点可能遗漏它；不能只说“这很新”。 |
| `P1 containment` | 尝试以 `u/F/C/Q/same task` 表达；说明是否保留原对象与观察。 |
| `P2 containment` | 尝试以 `Bind/Form/Bridge/Reenter/Polarity/Guard` 表达；说明是否保留原判断关系。 |
| `P3 containment` | 尝试以 `Draft/NeedBuild/NeedEval/Admitted/OperatorUse/BuildDone` 表达；说明是否保留过程与完成条件。 |
| `distortion witness` | 若任一映射失败，给出强行映射会怎样改变对象、过程、观察或 Done 的最小见证。 |
| `controls` | 至少一个正控制、一个负控制，以及为何它们能区分新职责与旧字段。 |
| `source / worker plan` | 哪些 source、blind/source-match/Battle节点可验证这个判断；禁止只用哲学叙述编号新刀。 |

## 3. 三种裁定

| verdict | 何时成立 | 后续动作 |
|---|---|---|
| `OLD_TOOL_FIELD_GAP` | 至少一把旧刀能忠实表示 pattern；缺的是字段、prompt、source、guard、支付扫描或验收。 | 修旧刀，保留旧版本与失败收据，做同卡回归。 |
| `DERIVED_TOOL_CANDIDATE` | pattern 的新能力只在两把或三把刀的组合中出现，但每个基本判断仍可还原到旧刀。 | 写派生 operator 合同、差量、正负控制；先称“派生候选”，不编号新刀。 |
| `UNCONTAINED_PATTERN_CANDIDATE` | P1/P2/P3 都无法忠实保留 pattern 的独立理论判断职责；每次强行映射都有一个可复现 distortion witness。 | 允许创建新刀提案，冻结名称、输入、输出、正负控制、source/worker plan；至少一轮正反控制后才成为 current tool。 |

`P4` 不是预留的自然数。只有 `UNCONTAINED_PATTERN_CANDIDATE` 通过卡片、正负控制和 Git 审计后，才会成为一个新编号；派生工具可从一把或多把旧刀产生，也不自动获得独立编号。

## 4. 新刀的最小出生门

新刀提案需要同时满足：

1. 一个不能被 P1/P2/P3 现有输入、字段与终态忠实表达的理论判断；
2. 一个正控制显示该判断确有辨别力；
3. 一个负控制显示它不会把旧刀已经能判的情形换名重报；
4. 一个来源或运行计划说明它如何对同一理论卡增加可审计信息；
5. 一个 delta SelfAudit 说明原初用户理念是否早已要求这项职责，或为何它是新出现的花纹；
6. 一个精确 Git commit，保存 Tool-BirthCard、控制、范围和被拒绝的替代解释。

若缺任一项，状态只能是 `TOOL_BIRTH_RESEARCH_OPEN`。不能以“现有工具解释不舒服”“模式很漂亮”或“希望它能打某理论”跳过门槛。

## 5. 初始回归样本

| 花纹 | 当前裁定 | 理由 |
|---|---|---|
| 公式定义／存在断言被误作 active consumer | `OLD_TOOL_FIELD_GAP` | L5b/L7b、T4d 修复 P1。 |
| 外部 proof search、公式编码、halt | `OLD_TOOL_FIELD_GAP` | P1 layer、P2 representation、P3 external-time 边界均可容纳。 |
| 罗素 formation promotion | `DERIVED_TOOL_CANDIDATE` 的共享结构，现为 `RK-0` | 它让三把刀共享字段，没有新增独立 verdict，故是 shared anvil，不是 P4。 |
| Power Set formation 被 consumer-only prompt 排除 | `OLD_TOOL_FIELD_GAP` | D-L10F 恢复 P1 formation lane。 |

新的“忒修斯之船／历史身份”花纹必须从零填 `Tool-BirthCard`，不能因它和圆环、SIP、替换或 provenance 词面相近就预判其归属。

## 6. 连续自审接口

每个自然锻造单元的 SelfAuditCard 额外写：

```text
pattern-universe claim:
  old-tool inertias considered
  pattern features preserved / lost under each attempted mapping
  verdict: OLD_TOOL_FIELD_GAP | DERIVED_TOOL_CANDIDATE |
           UNCONTAINED_PATTERN_CANDIDATE | NOT_ENOUGH_EVIDENCE
  Tool-BirthCard path or explicit reason none is required
```

这保证“旧刀容不下新花纹”被记录为可反驳的设计判断，而不是把研究阻塞、模型输出差异或来源缺口误称为理论突破。
