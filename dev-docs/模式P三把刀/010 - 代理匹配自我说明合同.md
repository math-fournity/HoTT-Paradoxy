# 代理匹配自我说明合同

> **身份：** `EXPLAINABLE_MATCHTRACE_CONTRACT / PROMPT_BOUNDED_AGENT_EVIDENCE / NOT_HIDDEN_CHAIN_OF_THOUGHT`。
>
> **目的：** 当 Terra / Max 代理用 P1、P2 或 P3 在理论 X 中选择一个位置时，留下足以让另一位研究者逐项检查的理由链：为什么是这里、为什么不是相邻位置、哪条规则给出该映射、以及改掉哪项事实会使选择失效。它记录可观察的、来源约束的推断依据；不要求、也不能认证模型内部隐藏思维或权重层的因果过程。

## 1. 每次输出的固定外壳

无论最终命中、被 guard 阻断、材料不足还是主动停手，代理必须给出下列八项。每一项都要写出 source locator；若 source card 没有行号，使用冻结字段名和原文短语。

| 段 | 必填问题 | 合格输出形式 |
|---|---|---|
| E0 范围 | 当前分析的理论变体、source card、允许知识和禁止补充是什么？ | 精确范围、prelaunch NodeCard／source-pack identity、deadline 与 `MODEL_RECALL_CANDIDATE`／`SOURCE_GROUNDED` 身份。 |
| E1 事实 | 哪些 source facts 被实际使用？ | `source fact → 原文／规则 → 可用含义`。 |
| E2 候选集 | 曾比较哪些位置或结构？ | 至少“选中项 + 一个邻近项”；若 source 只支持一个，说明为何不能构造竞争项。 |
| E3 字段映射 | 每条刀具字段由哪一事实填入？ | `source fact → P1/P2/P3 field → 不多不少的解释`；P1 的 `C` 还须给出输入、输出／Done 的 source contract 和所属层。 |
| E4 选择 | 为什么此候选胜过 E2 的邻近项？ | 逐门说明通过／失败，不得仅说“更基础”“更像”。 |
| E5 推演 | `Q`、rewrite、state edge 或 guard 怎样一步步出现？Q 是正义务还是可判假的普通查询？ | 最小规则链；每一步列前提、规则、结果及 true/false/blocked 的完成后果。 |
| E6 反事实 | 哪一个 source fact 被删除／替换时，哪一步失效？ | `altered fact → broken field/edge → changed verdict`。 |
| E7 判词 | 结论精确属于哪个证据等级？ | `SITE_SELECTED`、`SITE_SELECTED_Q_TRIVIAL`、`GUARD_BLOCKED`、`CONSTRUCTION_SEMANTICS_NOT_SUPPLIED`、`NO_POSITION_CARD` 或带 scope 的其他状态。 |

`E2` 和 `E6` 共同防止事后只为已经选出的答案编故事。它们不证明代理内部真实采取了同一搜索路径，却使报告的理由链可以被 source perturbation、相邻卡和复跑检验。

若 NodeCard 超时而未交 terminal output，E0–E7 不可由 Master 事后补写；该节点只有 `TIMEOUT_NO_TERMINAL_OUTPUT`。未完成搜索、计划文字或空的 output path 不构成 MatchTrace、source evidence 或负结论。

### 1.1 `P-DISCOVERY` 的公开 trace

无泄漏的一遍发现不应被强迫伪装成已完成的 E0–E7 验证。发现节点可以用下列 `D0–D5` 代替：理论变体与禁止知识；基于模型已学习知识的候选 concrete subject/`u`、process／`F`、process-wide completion `Q?`；至少一个邻近竞争位置；为什么该位置是线索而非结论；明确要求后续 source tracer 补的 C/I/O/Done；以及一个会推翻该线索的来源或控制。`D3` 还必须把 `Q?` 写成 prospective native theory task，而非只问 universe annotation、编码、元语言良构性或实现历史。`D3` 同时执行 D-L6：若 packet-visible `F` 已通过 constructor、eliminator、inverse、computation rule 或给定 witness 直接回答 `Q?`，必须写出最短 `F → answer(Q?)` 并把它登记为 rejected control。`D3` 还执行 D-L7：将 subject 与 process 分开，列出 subject 的对象、输入、观察和 provisional Done；只有过程容器／延迟器而没有被询问 subject 时，必须记为 `DISCOVERY_PROCESS_SKELETON_ONLY`。`D3` 还执行 D-L8：profile 已列出 concrete foundation objects 时，final subject 不能只剩任意变量 C 或“C 的某性质”；必须选一个具体对象／接口或返回 `DISCOVERY_SCHEMATIC_SUBJECT_ONLY`。`D3` 最后执行 D-L9：若 process 有阶段性 local branch，Q? 不能只问固定 `J(k)`；它必须保住 process-wide Done 或返回 `DISCOVERY_LOCAL_BRANCH_ONLY`。D-L6b 随后允许在同一响应中至多检查两个额外显眼 foundation sites；只有一个通过 D-L5 至 D-L9 的 site 可作为最终 candidate，全部被筛掉则返回 `NO_MODEL_RECALL_CANDIDATE / DIRECT_PAYMENT_ONLY`。其允许 verdict 是 `MODEL_RECALL_SITE_CANDIDATE`、`NO_MODEL_RECALL_CANDIDATE`、`DISCOVERY_TASK_TOO_THIN`、`DISCOVERY_META_LAYER_CAPTURE`、`DISCOVERY_PROCESS_SKELETON_ONLY`、`DISCOVERY_SCHEMATIC_SUBJECT_ONLY`、`DISCOVERY_LOCAL_BRANCH_ONLY` 或 `DISCOVERY_DIRECT_RULE_ANSWER`。

`D0–D5` 不可填入 E1/E3 的 source facts，也不可进入 P2/P3 会合。发现节点输出后，必须由独立 `P-VALIDATION` source card 接续；当前 E0–E7 仍是后者的强制合同。

## 2. P1 的选择说明

P1 必须把候选从理论的“显眼基础承诺”进一步说明成一个可审计选择：

```text
native source rule
  → object-level u and formation F
  → actual consumer C accepts/uses u
  → C's same-task demand produces Q
  → minimal reduction tests L6/Q-friction
  → compare a neighboring site and stop or freeze
```

要求：

1. `u/F/C/Q` 不能从不同理论版本、外部模型或临时算法拼接；
2. 单独出现的 relation、predicate 或表达式不是 `C`；必须从 source 找到消费 `u` 的 rule、operation 或任务及其输入、输出／Done。找不到时 E7 为 `SOURCE_CONSUMER_GAP`；
3. `C/I/O/Done` 必须标 proof system、理论对象、语义实际使用或 runtime 层。proof-level Done 不得填入另三层；跨层没有自己的 source contract 时 E7 为 `PROOF_LAYER_ONLY` 或相应 layer gap；
4. `Q` 必须明确说出是谁在何一任务中提出它，不能只是“所有对象都已给出”式修辞；还要说明该任务为何要求 Q 为真，而不是允许 consumer 正常返回 false；
5. 若 Q 被定义展开、反身性或既给 witness 清偿，E7 必须是 `SITE_SELECTED_Q_TRIVIAL`；若 Q 只是一个允许正常返回 false 的判断，E7 必须是 `ANSWERABLE_FALSE_BRANCH`；
6. 邻近位置可以是同一公理的较浅 membership 读法、一个相邻公理、一个元语言总体或一个局部构造，但必须说明它为何没有更好地满足 L0–L7；
7. 代理应报告“我据此选择”的可核查依据，不能声明“我的神经网络实际这样计算”。

## 3. P2 的映射说明

P2 不得从 P1 选中了对象就假设逻辑反馈存在。它必须给出：

```text
source syntax/rule
  → Bind / Form / Bridge / Reenter field
  → domain and direction check
  → exact rewrite or reason it cannot be made
  → polarity / guard / oracle classification
  → neighboring shorter or differently directed chain rejected
```

每一个 rewrite 都要指明等号、蕴含、可替换性或语义桥的方向。若 P2 只得到单向 bridge、受限 domain、分层上升或无对象语言 reentry，必须停在对应 guard／partial verdict，而不能用叙事填出 `q↔H(q)`。

## 4. P3 的映射说明

P3 必须让状态和边来自 source 的操作事实：

```text
source transition or operational contract
  → Draft / NeedBuild / NeedEval / Admitted / OperatorUse / BuildDone
  → prerequisite and effect
  → same-object dependency
  → cycle or completion assessment
  → static-axiom alternative rejected or retained
```

若 source 只给静态存在断言，E3 必须显式列为“缺 transition”；E7 是 `CONSTRUCTION_SEMANTICS_NOT_SUPPLIED`。代理不得因为“构造在直觉上需要时间”而补出状态或 scheduler。

## 5. 由主研究者执行的复核

代理的说明一经接收，主研究者只接受下列复核通过的部分：

1. **源对应：** E1/E3 的每项确实由冻结 source 支持；
2. **最小性：** E5 没有跳过 bridge、domain、admission 或 completion 前提；
3. **竞争控制：** E2 至少有一个真实邻近项，且 E4 的排除理由能复查；
4. **反事实：** E6 不是同义改写，而是足以使指定字段或 edge 失效的变化；
5. **义务模式：** E5 确实表明 Q 是 current Done 的正前提或未支付形成义务，而不是普通真值查询；
6. **证据等级：** E7 未把报告理由升格为数学定理、ZFC 不一致、模型内在机制或现实判词。

有任一项不通过时，保留原输出作为 `UNEXPLAINED_MATCHTRACE`，只可用于修 prompt 或设计下一张 source card。通过以上复核也只意味着“该代理的公开理由链与冻结材料相容”；不能由此推断模型将稳定地在其它理论、版本或未来会话中作同样选择。

## 6. 未来 Terra / Max 提示的强制句

每份盲测提示须含义等价地包含下列要求：

> 请勿提供隐藏思维链。请给出一份详细但可公开审计的 `MatchTrace`：你实际使用的 source facts、比较过的候选、每个 P 字段的来源、选择与淘汰的规则理由、最小推演或阻断点、一个反事实，以及带范围的最终状态。若任何一步无法从卡片得到，明确停在该处。

这句话不允许代理偷看项目既有答案；也不保证它的自然语言理由就是模型内在机制的完整镜像。它将“为什么定位在这里”转化为可被下一轮锻刀和 ZFC 共同会合使用的公开研究材料。
