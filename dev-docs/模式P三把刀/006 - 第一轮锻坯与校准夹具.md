# 第一轮锻坯与校准夹具

> **状态：** `FORGE_1_SPEC_FROZEN / EXTERNAL_BLIND_REPLAY_COMPLETED_WITH_SCOPE`。本片冻结的是三把刀的最小校准合同和合成／来源对照夹具；外部分类已完成所述夹具范围，但不证明任何数学命题，也不将用户的现实解释自动翻译成物理定律。

## 1. 锻造原则

第一轮不追求把三把刀做成通用自动判定器。目标是使每把刀都有：

1. 明确输入；
2. 至少一个应命中的正控制；
3. 至少一个应停止或被 guard 阻断的负控制；
4. 明确预期输出；
5. 可以推翻本轮设计的失败条件。

后续 fresh Terra / Max 盲测只消费冻结夹具，不给出本项目既有 HoTT／ZFC 答案。

## 2. P1 锻坯：理论前提与完成合同

### 最小输入

```text
TheoryVariant     ：精确理论或解释范围
NativePremise     ：被考察的基础前提／接口
RealityOrTask     ：同一任务的现实或假想现实侧
Operation         ：在理论前提下执行的过程
Observation       ：过程要记录的量
Done              ：什么才算完成
ControlVariant    ：移除／离散化／有界化该前提后的对照
```

### P1-F-001：芝诺完成过程夹具

| 字段 | 冻结内容 |
|---|---|
| TheoryVariant | 将运动位置建模为连续、任意可再分的线段的过程读法。 |
| NativePremise | 剩余距离在每一步后仍可再取一半。 |
| RealityOrTask | 从起点到终点的到达。 |
| Operation | `r₀>0`，每一步令 `rₙ₊₁=rₙ/2`。 |
| Observation | 每个有限 `n` 是否仍有 `rₙ>0`。 |
| Done | 某个允许步骤使剩余距离为 0。 |
| P1 expected | `PREMISE_AND_COMPLETION_POSITION_FOUND`，不是数学上“极限无效”的结论。 |
| ControlVariant | 具有最小可执行步长／有限格点的模型；若 `0<r≤δ` 允许终步，则该过程有不同 Done 行为。 |
| Falsifier | 若冻结过程在连续语义中存在一个有限步骤直接达到 `r=0`，或者 Done 被重定义而未披露，则此夹具不成立。 |

### P1-F-002：圆环来源卡夹具

圆环必须从原始来源恢复精确的 `M/N`、去点、展开、端点、逼近、复原操作和 Done；本轮禁止用最近摘要替代。当前只冻结 P1 所需字段：

```text
Cut / Unroll / EndpointState / Approach / ReconnectOperation / Done
```

预期不是先给结论，而是要求代理能指出：理论对“逼近”“闭包”或“复原”的哪一项处理决定 Done。若无法回到原对象与操作，输出 `CIRCLE_SOURCE_CONTRACT_UNRESOLVED`。

## 3. P2 锻坯：formation—reentry—polarity 夹具

### 固定 IR 输出字段

```text
Bind.admitted; Form.constructor; Bridge.kind/domain/direction;
Reenter.legal/domain-proof; Feedback.normalization-witness/polarity;
Guard; Trace.kind; StructuralStatus; InterpretiveStatus
```

### P2-F-001：无限制负极性正控制

```text
D = all admitted objects
Bind(φ) = yes
Form(φ)=u with ∀x∈D. R(x,u) ↔ φ(x)
Reenter x:=u = legal
φ(x)=¬R(x,x)
q=R(u,u)
```

预期结构输出：

```text
normalization = direct
polarity = negative
trace = finite
StructuralStatus = MATCHED
InterpretiveStatus = FINITE_SPECIFICATION_CONFLICT_CANDIDATE
```

这只说明局部规格形状；是否能得到理论内不相容仍由冻结逻辑的 `ConflictOracle_X` 决定。

### P2-F-002：有界 formation 负控制

```text
Form_a(φ)=u with ∀x∈a. R(x,u) ↔ φ(x)
u is not established as an element of a
```

预期：`Reenter=blocked_or_unknown`、`Guard=domain/bound`、`StructuralStatus=GUARD_BLOCKED`。不允许因为已经得到 `u` 就默认 `x:=u` 合法。

### P2-F-003：正极性 sanity control

保持 F-001 其他字段，改为 `φ(x)=R(x,x)`。预期保留 feedback，但输出：

```text
InterpretiveStatus = NONCONFLICTING_OR_UNDECIDED_FEEDBACK
```

它防止 P2 将所有固定点或自代都报告为冲突。

## 4. P3 锻坯：两种不混写的过程模块

### P3-A：admission-order 模块

这是合成的构造语义正控制，不是朴素集合论已经拥有的运行事实：

```text
Draft(u)
NeedBuild(u)
NeedEval(R(u,u))
OperatorUse(R,u) requires Admitted(u)
BuildDone(u) requires Eval(R(u,u))
Admitted(u) follows BuildDone(u)
```

预期依赖图：

\[
Admitted(u)\leftarrow BuildDone(u)\leftarrow Eval(R(u,u))
\leftarrow OperatorUse(R,u)\leftarrow Admitted(u).
\]

预期输出：`ADMISSION_ORDER_CYCLE_CANDIDATE`，并列出每条边的来源。若任何一条边没有规则／语义依据，输出 `CONSTRUCTION_SEMANTICS_NOT_SUPPLIED`，不得补造。

### P3-B：completion-process 模块

芝诺夹具的过程状态：

```text
State(position, remaining)
Step: remaining r>0 → remaining r/2
Done: remaining=0
```

预期输出：`FINITE_STAGES_REMAIN_PENDING`，仅覆盖冻结的减半过程。它不自动等于关于真实时间、连续统或极限理论的定理。离散终步模型是 `COMPLETION_CONTROL_PRESENT`。

圆环的 completion-process fixture 等原始操作合同恢复后补入，不能用想象的 state transition 代替。

## 5. 盲测合同与验收

对每把刀的第一次 fresh Terra / Max 盲测：

1. 固定工具版本、fixture 文本、允许理论信息和禁止答案；
2. 不提供历史悖论名、本项目候选、已有结果或源码路径；
3. 要求代理逐字段填卡，给出 source-of-rule 或明确 `unknown`；
4. Master 核对预期分类；正确的 `NOT_APPLICABLE`、`GUARD_BLOCKED`、`UNKNOWN` 与正命中同样计入成功；
5. 单次错误只修一项刀具规则，写入 004 的横向比较，不事后改变 fixture 的预期答案。
6. 代理必须输出 `MatchTrace`：每个选择、guard、拒绝或 Done 判词都要连到输入 card 的具体规则、最小归约、排除的邻近候选和可推翻条件；不得索取或保存隐藏推理。
7. P1 的 Q 必须经过 `L6/Q-friction`：若最小归约已被同一接口平凡回答，结果记为 `SITE_SELECTED_Q_TRIVIAL`，而不是问题定位。
