# 语料范围、作品身份与获取

## 1. Corpus batch，而不是无限“全部”

每次 run 先建立 `audit/ZFC-Q-CORPUS-MAP/<batch-id>/MANIFEST.md`，固定：

1. 被考察的 ZFC 理论位置或 Q 路线；
2. 现有 seed、反控制和理论变体；
3. 数据库、作者、引文和正式项目入口；
4. 时期、语言、发表类型与访问边界；
5. 本轮纳入／排除规则、最大引文迭代和停止条件。

`CORPUS_COMPLETE_WITH_SCOPE` 只表示该 manifest 声明的语料已处置；绝不表示世界范围“所有相关文献”已读。

## 2. WorkCard 与 AcquisitionCard

每一个 intellectual work 先有 WorkCard，再允许有一个或多个报告版本和下载版本：

| WorkCard 字段 | 要求 |
|---|---|
| Work ID | ZQCM-W-###，稳定于同一 intellectual work。 |
| 作品身份 | 作者、题名、年份、DOI／arXiv／ISBN／正式项目身份。 |
| 地图关系 | corpus batch、M轴、理论变体、P字段或Q路线。 |
| 版本族 | 预印本、正式版、讲演、扫描、译本、代码／文档的关系。 |
| 筛选状态 | 读、待读、排除、不可得与明确原因。 |

AcquisitionCard 记录每次字节获取：

| AcquisitionCard 字段 | 要求 |
|---|---|
| ACQ ID 与 Work ID | 一个 work 可以有多个 acquisition。 |
| access provenance | arXiv、作者、出版社、DOI浏览器页、机构库、用户提供浏览器路线等。 |
| 下载身份 | URL、日期、HTTP／浏览器事实、文件名和字节哈希。 |
| PDF核验 | file、页数、题名／文本层、视觉或页码核对、版本判词。 |
| 处置 | ACCEPTED_ORIGINAL、DUPLICATE_COPY、VERSION_MISMATCH、HTML_NOT_PDF、UNAVAILABLE或NEEDS_REVIEW。 |

DOI、作者、出版社、arXiv和正式项目档案校准作品身份；access provenance 不能反向决定作品身份。

## 3. 获取路线

按下面顺序找原件；具体出版商／年代路由由 math-paper-harvest 承担：

1. 现有本地语料、作者主页、arXiv、机构库和正式会议／出版社开放版本；
2. DOI resolver 与内建浏览器中的文章页，核对正式元数据、版本与可用下载；
3. Numdam、GDZ、mathnet、ICM卷、Project Euclid、作者档案等按论文路由取得版本；
4. 用户提供的浏览器访问路线可作为 acquisition lead；无论来源如何，下载后都必须做PDF和书目信息核验；
5. 无法获取、付费墙、访问受限、版本不明或语言不可读都进入 remainder，不能悄悄从地图删除。

用户提供的 `sci-hub.jp` 等路径仅作为 AcquisitionCard 的 access provenance。它不取代 DOI／作者／出版社／arXiv 的身份校验，也不能单独成为来源引用或候选的证据。

## 4. PDF 接受门

每份候选 PDF 入库前至少检查：

```text
file identity: binary is actually a PDF, not HTML/error payload
pagination: page count is plausible for the identified work
title/text: title, author or opening text matches the work family
version: preprint/formal/scan relation is explicit
sha256: exact acquired bytes are recorded
```

扫描件若没有文字层，可以经页面视觉核对入库，但必须标记需要 OCR／MinerU；无法核对的文件不进入原件 corpus。
