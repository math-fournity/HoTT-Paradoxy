# 目标层级与明显起点

## 1. 攻击的是理论基础接口

研究目标是理论本身赖以承载大范围数学的基础接口，而不是因为某个 Fields Medal 结果重要、某篇论文新颖、某个局部现象反直觉，就把它直接提升为理论靶。菲尔兹奖得主作品可以是可选入口或来源，不是靶标资格。

用户用三个对照说明这个层级：芝诺式问题从数轴的稠密性、实数／极限理论进入微积分基础；罗素式问题从朴素集合论的按条件形成集合进入集合论基础；HoTT 方向从理论自身明显的宇宙／形成承诺进入类型论基础。这里记录的是用户用来校准选点的研究类比，不把它们自动写成彼此等价的数学论证。

## 2. 从最明显、最核心的起点开始

模式 P 不要求先遍历理论 X 和它的全部细节。它的设计预期是：AI 已有关于 X 的知识，在清楚的模式 P 引导下，可以一遍提出一个有针对性的、可证伪的位置线索。起点必须是理论不能轻易外置的核心对象或形成承诺，而不是泛泛的“无穷”“自指”“时间”或一个方便搜索的局部例子。

“理论抽象可能留下可被计算视角揭示的薄弱处”是研究启发式，不是已证明的普遍数学定理。每轮都要检验它在当前 X 中是否生成真实的来源、任务和观察，不得从抽象本身直接推出理论有问题。

## 3. 线索与结论分层

一遍匹配的产物是 `MODEL_RECALL_SITE_CANDIDATE` 或有界的 `FORMATION_ORIGIN_PROBE`。它可以尚无 source-defined consumer、精确 Q 或 I/O/Done；这些必须保持 `UNKNOWN`，并由之后的 source validation 补齐或否决。

位置显眼不等于问题已找到。来源、同一任务、正向未支付义务、刀具会合、现实任务／UR，以及需要交付的机器证明，各有独立门槛。不得将“Power Set 被选中”写成“ZFC 的 Q 已定位”。
