## 3. 实际风险与处置

- **容量不确定**：2.32 MB计划加个人全局、工具与目标证据可能产生显著负载；只凭字节无法判定可装入哪种Claude窗口。保留完整要求，未来实测失败就停止该档研究，不用摘要暗中替换。
- **可执行旧文冲突**：五模板缺路径、三/四件套、恢复例外和旧checkpoint示例会直接影响后续行动。P1必须收敛，不能只加一行“以新规则为准”却让旧操作句继续有效。
- **路由不等于执行**：native AGENTS、import、Skill发现都不会证明理解。真实工具读取与角色化复述单独验收；不建设自动语义判定器。
- **同名覆盖与设置层**：本机没有个人hott同名项不保证未来没有。每次安装/升级核个人和managed覆盖；不泄露认证配置。用户层agents-md设置不能假装在项目层有效。
- **并行current truth**：研究者正在更新STATE/Git。安装只触自身范围；需要受管owner变化时由其唯一integrator消费与提交，旧审查随目标变化重新核对。
- **原模型/角色授权不可偷换**：旧Astra提示词的业务权限属于其实际启动语境。安装完成不自动让Claude接任C或D，也不自动允许使用Claude `/goal`额外评价模型。
- **历史快照保护**：新host metadata只记新执行，旧sealed输入不重写。历史7项manifest不符只影响该旧manifest的认证资格，不据此宣布所有源码损坏。
- **现有writer缺口**：嵌套KC审计分片原子写入缺口在PROTOCOL已登记。Claude适配不声称修复；需要使用时按既有兼容边界如实记录，不另造writer。
