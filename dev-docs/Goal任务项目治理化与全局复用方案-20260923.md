# Goal任务项目治理化：HoTT接入与全局复用方案

> HUMAN_EDITED；2026-09-23；本次实施方案owner。它研究的是AI怎样持续消费HoTT研究认知与执行/审计合同，不开展新数学证明。实际接入/验证状态由本轮验收记录与文件决定；方案自身不证明未来Session遵循。

## 1. 用户意图与本次结果

用户指出：只把规则留在`/goal`启动词和goal-x中，不能充分支持跨Session、压缩后恢复和日常任务；需要根AGENTS与`.codex`项目Skills协同，并与全局repo-cognitive-closure有机衔接。《最高指示》几乎应当成为本项目所有Session的必读材料，只是上下文角色不同。还要求把这种整备技术归纳给以后各repo的AI，适用时主动准备方案、AGENTS、Skills、短提示词、独占Goal和原则上单体的闭包，并为独立审计者准备全套。

本次来源附件为用户粘贴的`Pasted text.txt`；PPP–QQQ是历史对话，仅为来源，不恢复其中旧任务/测试授权；“新的任务”部分决定当前范围。旧Goal5整备仍有用，新增Goal6负责治理化开工与恢复，避免同编号被改成另一个任务。A/B仍由用户另开，当前不启动数学研究或子代理。

## 2. 机制核查与应修缺口

现行全局AGENTS强制认知闭包；两个核心Skill分别负责持续认知消费与持久化。项目root AGENTS、LOAD_SET、PROTOCOL与roles构成现有`.codex`框架。源码`cognition_runtime.validate_roles`已经支持附加角色，graph允许boot新增文件，不需为本次新造加载平台或更换STATE引擎。

原方案缺口：最高指示只在Goal5里要求，普通项目Session可能不读；执行Skill仍硬绑goal-1的旧步骤；B审计未成为明确项目Skill；纯提示词依赖不能区分强制认知材料的研究/审计/治理角色。这些是指令与路由缺口，不是已经实测所有未来AI都会失败。

官方AGENTS/Skills文档与本机metadata共同说明：入口自动发现、正文实读、语义消费和结果验收是不同层。当前本Session发现了`.codex`三项既有Skill，但官方路径表以`.agents/skills`为repo发现入口；不能假定所有host永久兼容`.codex`。按用户指定保留`.codex`唯一正文，root显式路径加载承担必达要求；不依赖UI是否展示新Skill。

## 4. 最高指示的上下文消费角色

- `RESEARCH_GENERATION`：主动寻找理论取舍并构造过程，14题、三次呈现和迁移；后核证。
- `INDEPENDENT_AUDIT`：先保原问/发现标准再审A，不先继承其总结；新理论分析仍履行生成型呈现，但不替A补交付。
- `SOURCE_EXPLANATION`：纯解释/答疑回源、保留原问和解释身份，直接回答，不因数学词汇强制生成新候选或14题练习。此边界由本轮对角色表的near-miss审查补入。
- `GOVERNANCE_ALIGNMENT`：核方法是否保持原意、发现动作、多尺度和证据等级；回答当前改动如何影响未来研究，不凭治理工作硬造HoTT候选。
- `MECHANICAL_CONTEXT`：保留项目目的、来源/角色和避免误改的边界；不触发数学研究，不每条shell命令做14题。

首次进入、跨Session、压缩恢复、角色变化/文件版本变化均全文读最高指示；同Session普通后续turn按任务检查当前有效性，研究换语义单元仍无条件全文重读。所有角色的读取都是完整正文，角色化的是后续动作，不是截取喜欢的章节。

## 8. 验收与回滚

验收链：root→common治理→角色Skill→单体闭包→实际业务规范/原文→工具/证据→结束与恢复。测试包含A/B正确映射、普通机械任务不激活研究、强制highest进入loader、附加角色schema兼容、缺件/角色名错误拒绝、提示词≤4000、goal编号未覆盖、旧seal仍可核。修改最高指示后旧seal的live对照会变，这属于已声明版本变化，旧frozen验证不能被改写。

新Session/真实压缩后能否持续执行、不同模型泛化及业务收益，必须由后续实际行为验证；本轮不启动新的Sub Agent/模型实验，静态与fixture不能冒充fresh PASS。当前主Agent按新common角色实读与复述只是一例本Session行为。

回滚按精确本次patch恢复路由/Skill输入，不reset整个dirty工作区、不删除来源或新成果。全局候选面与runtime差分分别保全；旧发布tag只读，不能移动tag。没有安装/发布的阶段不伪称已经回滚运行系统。

## 9. 当前反思与返回主链

本次目标是让用户要求在正确时刻被重新消费；较小替代“再长一点的提示词”仍缺项目恢复入口，故不足。现有AGENTS/两个核心Skills/loader已能承载，大型调度平台或语义Hook无必要。完成路由、角色、闭包和相称验收即交付，不借全局泛化重开旧实验。详细事实和未完成项写验收记录，避免方案自己宣布成功。
