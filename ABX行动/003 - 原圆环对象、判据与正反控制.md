# 原圆环对象、判据与正反控制

## 1. 不把缺失点当成对象的元素

“圆上拿掉一点”的来源不能由 `Σ x:C, x≠p` 单独承载。该类型只描述相对于已经给定 `p` 的剩余点。ABX 的候选模型必须把以下内容分开并按需要显式记录：

```text
OriginPresentation :=
  (C, p, M, N, e, boundary, closure-spec, operation-spec)

C             指定原圆/目标闭合对象
p             指定被去掉的点
M             去点对象或其结构化呈现
N             开区间/裸呈现
e             N 与 M 的确定等价或嵌入关系（若任务给出）
boundary      两端及其与 p/闭合对象的关系
closure-spec  要恢复的是“某个闭合对象”还是指定 C,p,e
operation-spec 允许的过程、trace 与完成条件
```

这是一份候选接口，不是已经完成的点集拓扑定义。真正的点集圆、开区间、边界及连续性须在选定的演算和库版本中资格化；HIT `S¹` 不自动替代它。

## 2. 两种不同的完成标准

ABX 必须先同时建立下列正反控制，避免把弱复原冒充强复原：

| 名称 | Done | 预期作用 |
|---|---|---|
| `Done_weak` | 从裸 `N` 构造某个闭合/紧化对象，例如一点评紧化 | 这是可能成立的正控制；它反驳“裸 N 绝不能得到任何闭合对象” |
| `Done_strong` | 在允许操作下恢复**指定**的 `C,p,e` 或其来源保持等价，并满足预注册的过程观察 | 这才接近用户说的来源/历史/复原要求 |

若 `Done_weak` 成立而 `Done_strong` 未成立，结论只能是两个任务不同。若 `Done_strong` 也成立，ABX 的当前失配候选必须撤回或改写；不能通过加重语言逃避正控制。

## 3. `H_top`、`R_origin` 与忘却

`H_top(M,N)` 只表达规定范畴中的同胚/等价。`R_origin(P,Q)` 应表达富化来源对象之间保持 `C,p,e,boundary,closure-spec,operation-spec` 的关系。最初需要检验的不是“`H_top` 为假”，而是存在没有额外来源数据的 forgetful 映射：

```text
U : OriginPresentation → BarePresentation
```

以及某个被严格定义的观察或恢复要求是否不能通过 U 因子化。候选否定命题需要加上自然性、对称性、固定原对象或来源保持等明确条件；没有这些条件，“不存在恢复”很可能被一点评紧化或任选表示的构造反驳。

## 4. 对 univalence 的精确位置

univalence 的可用形式是：一个**已给出的**等价可以产生相应类型的路径，并可运输已定义的族。它不自动提供 `U`，也不自动将 record/Σ 中的来源字段删掉。ABX 的理论机制应写成：

```text
K 接受或只观察 U(P) 的 H_top-信息
  且 K 的声明/结果被当作 Done_strong
  而 P 的 R_origin-字段或过程观察对 Done_strong 实际必要。
```

只有这个 `K` 的实际存在才把“普通拓扑抽象的盲区”变成 HoTT 的具体问题。否则 ABX 只建立一个可复用的表示边界。

## 5. ABX-1 已固定的实际模型

本轮选择 `RealCircle` 与指定 `east` 为 `C,p`；直接逻辑删点为
`PuncturedRealCircle`，而实际无条件同胚使用其强细化
`StrongPuncture`。`OpenRealInterval` 是原严格开区间 `N`。这不是
把弱删点偷偷替换掉：弱删点到 `N` 的同胚仍以 `Lift` 为条件，强删点
的连续互逆/类型路径才是当前无条件正控制。

`mCompletion` 和 `nCompletion` 给出当前 `X` 的闭参数表达。前者在
两个端参数处映到同一 `east`，后者两端像不同；参数 0、1 仍是不同的
参数。这消除了“距离为零但两点仍不同”这一不精确表述，而保留了用户
关心的闭图差异。

本轮的 `R_origin` 只采用 `RichCurve` 的可检查代理：参数化、平面实现、
连续闭图和内点一致。`U = Bare` 明确忘去这一结构；`Done_weak` 为目标
载体相等，`Done_strong` 为载体相等加 `Denotes` 的整段闭图相等。`nRich`
通过前者却被 `plainNNotSatisfied` 拒绝，`reexpressed` 通过完整字段运输
而满足后者。这是任务合同的机器化正反控制，不是完整现实历史的形式化。
