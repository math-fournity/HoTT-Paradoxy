## 怎样核对

在仓库根目录，对表中每一行运行：

```bash
git rev-parse "origin/<分支>:dev-notes/<文件名>"
```

结果应与 `git hash-object "dev-notes/branch-archive-20261008/<分支>/<文件名>"` 相同。2026-10-08 写入时七个文件全部一致。
