二、宿主中立（.codex → ZCode 可用且零两套）：联网调查确认三件事实——(1) 根 AGENTS.md 是两宿主唯一的共同自动注入通道（Codex 走 AGENTS.md 标准；ZCode 3.8.1 组合 workspace 根 AGENTS.md，不支持嵌套）；(2) ZCode 无项目级 Skill 发现，但官方支持从 Codex symlink 导入 Skill（可选、默认不装——全局元数据注入会向所有项目收税）；(3) runtime 是纯 python3，ZCode 有 Bash，本 Session 已实际运行过 plan。据此设计：`.codex/` git mv 为 `.cognition/` 单一真值树（SOP→sops/、SKILL_ROLES→ROLES.json，不留复本 stub——两宿主入口本来就是根 AGENTS.md）；双宿主接入矩阵 + 三条硬规则（宿主专属信息只许在收据元数据、规则禁止按宿主分支、validator 禁排他措辞）；SESSION.md 增加 host/model/tier/load_receipt 元数据，ZCode 会话获得证据链一等身份，写 STATE/checkpoint 走完全相同的原子事务。ZCode 私有件（project memory 默认关且在宿主侧、repo wiki 覆盖式再生无历史）声明为辅助件禁入真值链。AGENTS.md 标准本身是 Linux Foundation 托管、60k+ 项目采用的跨工具标准，"根文件单一真值源"正是业界推荐模式——未来 Cursor/Gemini CLI 等也能零成本接入。
