# 后续工程观与决策点

> 记录轮次：dev-notes 0055–0058 的前向部分合集（「后续继续实施数学危机
> 创造与寻找工程」的用户指令对应物）。

## 1. 工程的双重性：创造与寻找

讨论确立的工程观：危机工程 = **寻找**（discovery，G1/G2 型：猎物可能不存在）
+ **创造**（construction，G4/G5/G6 型：仪器、桥、装甲、交付链——无论猎物
是否存在都沉淀为真实成果）。两者的预算纪律不同：寻找型单元允许空手而归且
必须如实登记；创造型单元的验收独立于危机是否发生。

## 2. 扩靶猎法（第一铲定案）

**跨内核分歧地图**：同一命题/构造在 Agda、Coq、Lean 三内核上的对照——
模式匹配消去规则差异、宇宙处理差异、univalence/公理接受的分歧点、同一
文献定理在三个库中的形态差。三实现不一致处 = L2 裂缝最可能现形处。
预期：数周；无论如何产出 L2 元测度的第一份正面贡献（危机不发生也成立）。
前置：三工具链的资格化（复用本项目收据纪律：TOOLCHAIN 钉死 + 双重复放）。

## 3. 可承诺与不可承诺（工程诚实合同）

| 可承诺 | 不可承诺 |
|---|---|
| 狩猎的系统性（分母、八轴覆盖、反解释装甲） | 猎物存在（G1 可能空手、G2 可能反证必要性） |
| 每个单元的收据级可复核 | 「第四次数学危机」这个名字（回顾性命名） |
| G2 模型工作无论如何是篇真论文 | 一致性击穿（G0 之门关闭） |
| 芝诺论点的文献定位与机器证词化 | 共同体必须回应（G6 只能争取不能保证） |

## 4. 终局情形的预登记（讨论明确列出）

若 G1 扩靶 + HoTT 语料审计均空手而归，则诚实终局 = **「此方向（在现有语料
与配置下）不存在第四次危机可猎」**——这本身是可交付的负结果（L2 元测度的
第一份系统性清洁证明）。届时用户面对的选择：接受终局，或换猎场（换理论、
换引擎配置、或转向 L3 的结构性假设）。预登记此情形是为了避免「为保住危机
叙事而降低危机定义」的滑坡——危机定义不可为了结论而修改。

## 5. 与既有资产的关系

- **MATH-FOURNITY**（公开 repo）：不受危机工程影响——其定位是 foundations
  研究材料（结果原则已裁定），危机级与否不改变其交付形态；
- **既有 13+3 收据**：作为 L0/L1 战果与仪器沉淀保留；Astra 审计后的修复
  （A02/A08/A09）已全部闭环；
- **Astra 策略**（《Astra继续尝试》）：其方法论（任务合同/六面规格/反解释）
  已采纳为危机工程的方法论层；其 AST-U00..U09 规模按缺口严重度重排
  （《GLM的审计报告》004 片）。

## 6. 用户决策点（当前全部待裁）

1. **是否开猎**：L2 跨内核第一铲（数周）——不开则危机工程停留在仪器就绪态；
2. **G4 圆环主线立项**：月级研究投资，仅当 G1 命中需要桥，或作为独立的
   「芝诺之问形式化」方向；
3. **G2 模型工作优先级**：与 G1 并行 or 串行；
4. **MATH-FOURNITY Phase 1-3**（资产清洗/三语 README/CI/论文）：与危机工程
   并行的公开线——六决策点中五个已裁，剩 About 措辞与 Discussions 开关；
5. **G1/G2/G3 闸门**：G2 外部审计、G3 push 授权——不变。

## 7. 一句话的工程纲领（讨论的最终凝结）

**以芝诺之问为不变量，以引擎内核层为猎场，以收据纪律为底线，以可反驳性为
装甲——猎物存在与否交给狩猎本身，危机之名交给历史。**
