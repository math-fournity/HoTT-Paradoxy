# 对《Astra继续尝试》策略的评审

评审对象：`Astra继续尝试/四弹一体完整研究策略.md`（索引）+ 9 分片 + evidence/。
其自报状态：`DESIGN_DELIVERED / EXECUTION_NOT_STARTED / CANDIDATE_NOT_CURRENT`。

## 1. 总评

这是一份**方法论上优秀、规模上失衡**的策略。它的任务合同纪律（AST-G01–G06）、
同对象规格（002 片）、三类识别来源分类（005 片 §1）、预生成八类反解释
（009 片 §1）、「成功判据必须允许失败」（审计 004 片 §6）都应被采纳为项目
方法论。但它的执行规模（AST-U00–U09 十单元 + 圆环点集几何主线 + 全新命名
空间）与当前决定性缺口的严重度不成比例——四项可修缺陷本轮已在数小时内
修复完毕；它把「研究纲领设计」当成了「既有资产恢复有效」的前置。

## 3. 拒绝/修改清单

1. **「CANDIDATE_NOT_CURRENT」的全称降格——拒绝。** 既有真定理（B1a@勘误三、
   M2、M3-UNC、GOLD-02 四条件、NecessityLEM）不因叙事层措辞滑动而失效；
   正确处置是**范围重标注**（本轮已做），不是降为「对照支线」。策略自己的
   007 片也说「重放成功不等于它们同义」——同理，叙事失误不等于定理失效。
2. **十单元规模——按缺口严重度重排。** 决定性缺口排序（本报告分片 005）：
   措辞清洗（小时级）→ LEM₋₁ 样例（小时级）→ GOLD packing 到标准 dcut
   （日级）→ A01 解释合同（写稿时）→ 圆环几何主线（**真研究工程，月级**）。
   AST-U00–U09 的依赖图正确，但 U01/U03（共同 X 冻结 + 点集圆环模型）是
   新研究投资，不是「旧成果资格化」的欠债。把它们排在旧资产恢复之前，
   会让公开稿再等数月——而公开稿（A10）才是双方都承认的最短关键路径。
3. **「不将原生 HIT S¹ 直接当点集圆」——接受其方法论，注意其代价。** 该
   纪律正确（ReboundDisarm 的 A07 降格正说明别名不能承载几何），但圆环主线
   因此需要真正的点集/结构化拓扑建模——这是策略低估了体量还是有意设为长线，
   应由用户裁定优先级。
4. **`AST-OMEGA-NEC-SO : SmallRD ℓ → SingleOmega ℓ` 作为首个必要性精确目标
   ——接受其精确化价值，指出其与既有登记的关系。** 这正是矩阵中
   `Necessity ℓ` 的同一命题（SmallRD=ℝLayerAt 的标准规格化）；本项目的
   CONJECTURE 登记与其「允许结局：证明/反模型/OPEN」三向一致。策略在此
   重新发明了已有登记，应改为引用而非另立。
