## 2. R01–R05：有理数层、Pell 序列与规格分离

### R01：Pell 递推

[`MissileOneProcessLayer.agda`](../HoTT/formal/dedekind-omega-missile/MissileOneProcessLayer.agda) 第 101–118 行给出

```agda
pell-gap-never-closes : (n : ℕ) → (D n ≡ 1r) ⊎ (D n ≡ - 1r)
gap-never-zero        : (n : ℕ) → ¬ (D n ≡ pos 0)
```

形式上这是自然数全称不变量，并且 source 以 `--safe --cubical --guardedness` 编译。其数学语义连接“该递推是 √2 的最优有理夹钳”没有在该模块内部形式化；因此公开文本只能从“指定递推的判别式”开始，不能把“所有逼近过程无法完成”写成 theorem。

### R02：有理数层 √2 无理性

[`MissileTwoUniversalIrrationality.agda`](../HoTT/formal/dedekind-omega-missile/MissileTwoUniversalIrrationality.agda) 第 314–319 行给出 `∀ q : ℚ, ¬(q·q≡2)` 与其 Σ-非居住形式。这个 `Spec_B` 是固定输出规格；正确语言是“没有满足该有理数输出规格的值”，而不是“一切算法不会终止”。

### R03/R04：两个指定规格

`Spec_A` 是一个带双向正确性条件的 `ℚ → Bool` 判定表，`Spec_B` 是 `Σ q : ℚ, q·q≡2`。M3 的第 76/96–97 行在 `LEMᵒ` 下构造前者并利用 M2 证明不等价；M3-UNC 的第 47/68–69 行改用有理数序的可构造三分法，去掉 LEM。两者均是合法的形式结果，但 `Spec_A` 并不等于完整 `DedekindReals`，更不等于某个现实过程已被理论宣布完成。

### R05：必须保留的反向校准

R05 的第 33–37 行只是从 R01 直接构造逐点判定和 Σ-否证。它反驳一种会破坏研究目的的误读：已能判定该固定序列在每一步不命中，并不等同于某次搜索、归约、证明检查或一般停机问题不完成。公开包若收录 R05，应将其定位为解释边界控制，而不是第二个“攻击 HoTT”的 theorem。

## 3. R06–R10：cut、层级、正向校准与条件引理

### R06：GOLD 的精确范围

`CutGoldForm.agda` 第 137–139 行定义 `Lₚ/Uₚ : ℚ → hProp ℓ-zero`，第 224 行给出 locatedness，第 353–355 行与第 581–585 行给出 rounded 的两个向内见证；`CutInfra.agda` 提供所需的有理数乘法单调性。GOLD-02 的 kernel run 支持这些具体组件。

但是，对整个 `HoTT/formal/` 的精确搜索未发现 `CutGoldForm` 被导入到 `CutRealLayer`，也未发现将 `Lₚ/Uₚ` 组装成 `dcut`、`DedekindReals` 或 `ℝLayerAt` 的 module。该负结论的搜索范围仅是已审阅的 `HoTT/formal/` 当前 tracked tree；它不主张不可能存在桥接证明。未来若想将公开陈述升到“给出该精确定义下的 Dedekind real”，必须先新增并重跑这条桥接。

### R07：公理注入的控制语义

UA 模块在 [`MissileFourTargetA-UACounterexample.agda`](../HoTT/formal/dedekind-omega-missile/MissileFourTargetA-UACounterexample.agda) 第 18–19 行显式使用 `postulate ua`；LEM/AC 模块在 [`MissileFourChargeDemo.agda`](../HoTT/formal/dedekind-omega-missile/MissileFourChargeDemo.agda) 第 27–28、39–41 行显式使用 `postulate`。它们故意不使用 `--safe`，因为公理注入本身是被观察的条件，不是工程疏忽。

本审计重新观察到：正常对照可接受；UA、AC、LEM 的零/一 `refl` probes 以 `UnequalTerms` 拒绝，并显示公理应用或 transport 卡在中性头部。这证明的仅是**定义性归约边界**。它不构成对象层的 `¬(n≡0)` 证明；后者需要单独构造否定项，不能从一次 type-checker 拒绝偷换而来。

### R08/R10：层级结论必须保留条件

`CutRealLayer.agda` 第 147–148 行定义

```agda
Necessity ℓ = ℝLayerAt ℓ → SingleOmega ℓ
```

而第 246–247 行证明 `SingleOmega ℓ → ℝLayerAt ℓ`。`MissileFourNecessityLEM.agda` 第 109–123 行再证明 `LEMProp ℓ → Necessity ℓ`，其证明不消费 `ℝLayerAt` 前件。由此可见：R10 是一个 LEM 条件下后件直接可得的引理；无条件 `Necessity` 仍未证明。

### R09：HIT 的正向反例控制

[`ReboundDisarm.agda`](../HoTT/formal/dedekind-omega-missile/ReboundDisarm.agda) 第 51–52 行的 `hit-computation-witness : intLoop (pos 0) ≡ refl` 是指定 `S¹` HIT 的闭计算。它应防止仓库把“加入理想点”或“使用 HIT”本身误判为计算失败原因；它既没有判定所有紧化构造，也没有判定现实中的极限过程。
