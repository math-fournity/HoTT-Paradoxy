# 命题忠实性与研究目的审计

## 1. 研究目的的正确表述

未来公开仓库的可接受目的不是“证明 HoTT 错了”，也不是“把全部内部讨论公开”。它应当是一个范围受限的 Cubical Agda 结果包：展示与 HoTT Book §11.2、指定有理数 cut、两个明确规格及命题层级结构有关的精确形式结果，并公开其不证明什么。

项目级研究问题要求区分三种层次：

```text
形式对象 / kernel 命题
      ≠
理论解释或建模选择
      ≠
现实中的同一任务、完成约束与可交付性
```

任何公开说明若从第一层直接跳到第三层，就会违反 [`HoTT研究三问`](../HoTT/HoTT研究三问-找什么-怎么找-凭什么-20260909.md) 所要求的同任务与现实桥梁责任。当前 source 证明了多个有价值的局部数学命题，但没有构成“HoTT 的某条规则使一个原本可完成的现实任务不可完成”的闭合链。

## 2. 逐类忠实性判断

| 主题 | 形式层 | 忠实性判断 | 尚缺的义务 |
|---|---|---|---|
| Pell / M1 | 指定递推的 `D n ≠ 0` | 递推不变量本身清楚；“最优夹钳”是外部数学语义 | 形式化或引用并审阅该递推与所称夹钳的精确关系；固定完成任务。 |
| √2 / M2 | `Spec_B` 非居住 | “无有理数平方为 2”与类型读法相符 | 若要谈算法，定义算法域、正确性和完成/交付判据；不能从空规格推出不终止。 |
| M3/M3-UNC | `Spec_A ≄ Spec_B` | 两个给定类型不等价是准确的 | 证明某理论规则、Book 实践或应用确实把它们当成同一任务；构造同一现实任务桥。 |
| GOLD | 多个 cut 条件组件 | 对逐个类型的陈述可追溯 | 组装 `Lₚ/Uₚ` 到 exact `dcut`；若声称 real object，再连接 `DedekindReals`。 |
| REAL-LAYER | 条件充裕性 | `SingleOmega` 前件明确 | 必要性、`SingleOmega` 与 resizing 的关系、模型/构造替代、真实应用解释。 |
| R07 | type-checker accept/reject 对照 | 元层控制解释清楚 | 若需要对象层不等式，单独形式化；若需要可移植控制，创建新 schema/run。 |
| Rebound | S¹ HIT 闭计算 | 指定 HIT 结论清楚 | 与所讨论的拓扑/完成主张的保真翻译；不能以一个 HIT 外推全部紧化。 |

## 3. 被本审计否决的强表述

以下文字不得进入未来 README、摘要或“结果表”：

- “HoTT 已被机器证明不一致”或“HoTT 被击落”。当前 matrix 自身明确拒绝这一外推。
- “实数完备性被证明非现实”或“实数层必然收费”。R08 仅是充裕性，`Necessity` 保持 `CONJECTURE`。
- “M2 证明任何逼近算法永不停止”。M2 证明的是指定输出类型无 inhabitant。
- “R07 证明公理项不等于 0/1”。当前只能说 `refl` 的定义性检查被拒绝。
- “GOLD 已构造 `CutRealLayer` 的 Dedekind real”。当前 source 仅有组件级连接，缺显式 packing bridge。
- “ReboundDisarm 否定了极限理论”或“极限理论本身通过了现实检验”。它只核验一个 `S¹` HIT 计算。

这些不是文字风格问题，而是命题的量词、理论层、证明种类或观察对象发生了改变。

## 4. M3-UNC 对公开叙事的影响

M3 的原叙事曾强调 `Spec_A` 依赖 LEM；M3-UNC 通过有理数比较的三分法取消了这个前提。由此有两个不可忽略的后果：

1. R04 在同一 `Spec_A/Spec_B` 上形式强于 R03；公开首页若同时呈现两者，必须解释 R03 是历史条件版或对照，而不是第二个独立的最终结果。
2. 旧 `CLAIM-PACKAGE-M3-UNC.md` 中“完整 cut 尚未无条件构造”的历史表述已被后续 GOLD 组件证明部分改变。它不能逐字复制到公开包；应改成更精确的“完整 `CutRealLayer` packing / ℝ 层对象尚未由该链闭合”。

这说明为什么未来公开 package 不能简单复制 `CLAIM-PACKAGE-*` 文本：它必须从 release manifest 的最新 claim-to-prose map 生成或人工核对，而不能让旧研究节点与最新结论并列竞争。

## 5. 可信结论的最小公开语言

推荐的定位句是：

> 本仓库提供一组在固定 Cubical Agda 环境中检查的、关于指定有理数 cut、规格类型的可居住性与不等价、以及命题层级条件的范围受限结果；每个结果都附有精确形式命题、重放入口与禁止外推。

它避免把数学核贬低为“只是代码”，也避免把局部 kernel 事实膨胀为 HoTT、现实世界或哲学结论。是否能再增加“现实对齐”结论，取决于以后是否完成同一任务、理论化步骤、完成条件和现实观察量之间的独立桥接。
