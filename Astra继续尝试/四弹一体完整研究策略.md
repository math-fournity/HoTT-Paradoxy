# 四弹一体完整研究策略

> ⚠️ 逻辑文档索引：全文 = 本索引 + 下方 10 个分片；缺一片即未完成，按表顺序读取；300 行只是软目标，不是上限。

本策略研究 HoTT/Cubical 类型论在表示同一个 X 及其过程时，是否引入现实任务本无的完成障碍，或把形式对象提升为尚未取得的实际交付能力。方法是固定同一对象与任务、构造正反实例、证明转换的保持性或失配，并在原生证明系统中检查；新增目标先按待证候选处理，已核结果以精确source/run/index及其范围为准，文档本身不认证真值。

**总路线：共同 X 与任务 → 过程完成命题 → 理想对象及实际兑现 → 两者的保真/失配证明 → 理论依赖与元层归因 → 相称公开结论。** 四层必须围绕同一个实例连接；四份互不连接的真定理不算整体完成。

版本：`astra-four-stage-strategy/v1.16-same-map-completion-and-rich-task`；日期：2026-09-20；首次设计基线：`19d45ce503fdacb2b6dc6d87f01bf794298b66c6`；此前方案变化由Git的`plan-revise`历史保存，v1.15为`4d44b0e`。本版接通C290同一实际逆映射的闭参数连续延拓及真实端部区别，状态为`OPEN_OBJECTIVE / SAME_MAP_CLOSED_EXTENSION_CHECKED / RICH_AND_TASK_OPEN`。内点一致、分母正性、连续性、M同端像/N异端像、内点单射与闭域非单射均有原生证明；物理复原、来源保持与允许过程合同仍开放。这里completion只指闭参数延拓，不预称Cauchy泛性质。强域/原W条件保持，不新增全Lean解释器前置，也不删除具体过程的native/保真义务。

本策略保留用户“四弹一体”的称谓，正文分别称过程层、对象与兑现层、识别层、元层。当前执行依据是本线程持续Goal，完整原文与逐项未完成义务见第010片。原始圆环模型未闭合前，不切换成仅完成算术支线，也不以重复非法项拒绝替代发现。运行事实与数学交付门禁分别更新。

## 当前选择

原始圆环及其变换过程是主问题。√2/Dedekind/Ω 是已有机械资产最多的对照支线；它可以先消除旧方案中的错误解释，但只有保真连接通过后才允许作为主问题的数学实例。否则两线分别交付，不把算术结果冒充圆环结果。
