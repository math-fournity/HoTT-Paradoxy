# 四弹一体完整研究策略

> ⚠️ 逻辑文档索引：全文 = 本索引 + 下方 9 个分片；缺一片即未完成，按表顺序读取；300 行只是软目标，不是上限。

本策略研究 HoTT/Cubical 类型论在表示同一个 X 及其过程时，是否引入现实任务本无的完成障碍，或把形式对象提升为尚未取得的实际交付能力。方法是固定同一对象与任务、构造正反实例、证明转换的保持性或失配，并在原生证明系统中检查；当前所有新命题均为待验证目标，文档不预先认证其真值。

**总路线：共同 X 与任务 → 过程完成命题 → 理想对象及实际兑现 → 两者的保真/失配证明 → 理论依赖与元层归因 → 相称公开结论。** 四层必须围绕同一个实例连接；四份互不连接的真定理不算整体完成。

版本：`astra-four-stage-strategy/v1.0-design`；日期：2026-09-19；设计基线：`19d45ce503fdacb2b6dc6d87f01bf794298b66c6`。用户要求与共同 X 航向已明确；本策略的具体建模、任务顺序和目标命题是 AI 给出的可审查设计。状态：`DESIGN_DELIVERED / EXECUTION_NOT_STARTED / CANDIDATE_NOT_CURRENT`。

本策略保留用户“四弹一体”的称谓，正文分别称过程层、对象与兑现层、识别层、元层。本轮只完成设计；未来实施时按实际授权、T2/T3 与唯一当前状态 owner 接入，不借旧 Session 的执行指令自动获得权限。

## 当前选择

原始圆环及其变换过程是主问题。√2/Dedekind/Ω 是已有机械资产最多的对照支线；它可以先消除旧方案中的错误解释，但只有保真连接通过后才允许作为主问题的数学实例。否则两线分别交付，不把算术结果冒充圆环结果。

首个执行单元是 `AST-U01`：冻结共同 X、原操作与完成条件，建立能够在原生核中表达的最小任务/观察接口，并完成一个保持任务的正控制。它不是再跑十张旧收据；其目的在于让第一项关键失配具有可检查的类型。随后以 `AST-U02` 的标准 cut 与 M3 对照检验旧算术链，同时推进主线的几何表示资格化。
