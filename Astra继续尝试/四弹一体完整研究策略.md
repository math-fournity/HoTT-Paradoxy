# 四弹一体完整研究策略

> ⚠️ 逻辑文档索引：全文 = 本索引 + 下方 10 个分片；缺一片即未完成，按表顺序读取；300 行只是软目标，不是上限。

本策略研究 HoTT/Cubical 类型论在表示同一个 X 及其过程时，是否引入现实任务本无的完成障碍，或把形式对象提升为尚未取得的实际交付能力。方法是固定同一对象与任务、构造正反实例、证明转换的保持性或失配，并在原生证明系统中检查；新增目标先按待证候选处理，已核结果以精确source/run/index及其范围为准，文档本身不认证真值。

**总路线：共同 X 与任务 → 过程完成命题 → 理想对象及实际兑现 → 两者的保真/失配证明 → 理论依赖与元层归因 → 相称公开结论。** 四层必须围绕同一个实例连接；四份互不连接的真定理不算整体完成。

版本：`astra-four-stage-strategy/v1.40-task-fidelity-corrigendum`；日期：2026-09-21 UTC；首次设计基线：`19d45ce503fdacb2b6dc6d87f01bf794298b66c6`；此前方案变化由Git的`plan-revise`历史保存，v1.38为`98e8b7e9`。C321–324已接回原四层；固定Coq locator源码未提供旧归因所需的无条件承诺。用户已把 redo 与新候选研究分为两个阶段；此前第一阶段已有范围判词，现仅因原 X/数学现实同一性澄清而受限重开 G01/G04。状态`REOPENED_FOR_TASK_FIDELITY_CORRIGENDUM / ORIGINAL_TARGET_NOT_ESTABLISHED_PENDING_CORRIGENDUM / SECOND_PHASE_NOT_OPENED`。不以新包装或无限寻找替代当前结论，也不把负面重做结论冒充已击落 HoTT。

本策略保留用户“四弹一体”的称谓，正文分别称过程层、对象与兑现层、识别层、元层。当前执行依据是本线程持续Goal，完整原文与逐项未完成义务见第010片。主圆环已有实际有界case后，可以推进算术校准，但不能把算术独立成功冒充原广义圆环或四层整体完成；原未定操作/物理对应继续保留。新增勘误明确：`RealitySame` 可进入规格作为共同指称锚，但不会自动给出同任务合同或理论承诺。也不以重复非法项拒绝替代发现。运行事实与数学交付门禁分别更新。
