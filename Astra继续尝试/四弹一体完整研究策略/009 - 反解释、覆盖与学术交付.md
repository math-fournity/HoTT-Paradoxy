# 反解释、覆盖与学术交付

## 1. 预生成八类最强反解释

| ID | 对本候选最有力的回应 | 如何裁决 |
|---|---|---|
| AST-CTRL-01 | 原过程只是被限定为减半，其它允许动作可完成 | 真正保留原动作许可则否定普遍不完成；不忽略成功过程 |
| AST-CTRL-02 | 原始指定点/来源已在输入中，恢复无需额外信息 | 对同一输入构造恢复；成功就撤回“不可恢复” |
| AST-CTRL-03 | 精确表示不是要求有理数精确根 | 对照 Output/Done，并分别证明；不得混题 |
| AST-CTRL-04 | 对无限域的函数可由有限代码给出 | 实际构造查询/精度算法；逐实例 total 与全域统一的证据分开 |
| AST-CTRL-05 | 保留 universe 层级即可开展原任务 | 若任务完成则 Ω-smallness 支线不再支撑主指控 |
| AST-CTRL-06 | 原生 UA/HIT 可计算，失败来自额外不透明常量 | 同一消费者做 native/opaque/普通常量对照 |
| AST-CTRL-07 | 加结构后可保持原任务，而新增的是表示不是新现实输入 | 明确数据从哪里来；已有信息的保留不能被算作偷加 oracle |
| AST-CTRL-08 | 这是公开说明的抽象范围，而非有效完成承诺 | 回到原规则/解释合同；有限表示不适用不升级为基础理论失败 |

这些回应不是预定输给第二弹的材料。任何一个满足原合同，都可以改变当前候选结论。反例本身也要经相称核验，不能用一个尚未实现的“总能修复”承诺结束研究。

## 3. 程序化方法的遗漏检查

| 方法族 | 本轮角色 |
|---|---|
| typed term/proof enumeration | 仅在某个明确有限接口/语法无法手工构造时，生成合法候选；不先建全集枚举器 |
| premise mutation/ablation | 去掉多余 LEM、保留/擦除来源、改变 universe；变体不得冒充原理论 |
| 层级提升/擦除 | 明确 Path/判断相等、mere/chosen、近似/精确的边界 |
| consumer synthesis | 从预先选定任务合成观察上下文，不能事后发明有利判据 |
| composition/self-reference | C08 按实际依赖触发；不以手写递归冒充 Gödel |
| differential/metamorphic/property | 同题 native/opaque 与表示前后对照；随机/有限样例不外推 |
| symbolic/model search | 必要性候选的反模型线索；结果必须资格化到精确原则与域 |
| termination/productivity/search | 对象运行、规范化、证明搜索各自分开；公平性仅在实际无限搜索时要求 |
| versioned source/paper mining | 优先原典、固定库、已有实物与最接近文献，支持归因与新颖性 |

若实际启用有限生成器，先冻结 grammar/参数/成员集；覆盖声称必须有独立重算或覆盖证明、remainder=0。若使用无限代码搜索，声明 dovetailing 与部分结果，不以无命中推出不存在。

## 4. 每轮 omission/holdout

每个 bounded pass 至少选一个独立对照：Book 中另一条构造路线、不同作者的同类接口、标准正控制、或同任务的另一表示。事先说明为何独立及其范围。出现不被八个 cells 接住的结果，登记 `OUT_OF_ENVELOPE`、其新机制和下一有界单元，不静默加入旧分母。

Reducer 只能在保持理论配置、输入、consumer、观察与完成时合并候选；删掉现实对应字段后得出的“小反例”不能继承原目标身份。发现与旧 partiality/cost/choice 边界同形时，先复用旧成果并检查本实例增加了哪条真实连接；没有新连接就停止重复。

## 5. 文献与原创性工作

首批一手对照来源：固定 HoTT Book §3/§11；当前 cubical v0.9 源码；Agda 2.8.0 官方 safe/cubical/postulate 文档；Huber canonicity；de Jong–Escardó 关于 small types 与 injective types 的结果；resizing 的精确 universe 区分。可由 Astra 审计第 007 片的来源表进入。

执行时先确定要借用或对比的精确命题，取得相应版本与必要正文，再比较前提/对象/结论。当前计划没有宣称这些论文全部已读或重放，更没有全面文献覆盖结论。新发现若只是既有定理的同义形式，保留机械资产但不声称首次发现。

## 6. 学术交付

最终读者包应只包含：问题与精确命题、假设、证明、必要正反控制、现实/模型对应、相关工作、开放问题和复现入口。对话史与治理过程不进入公开包，但所有会改变读者判断的限制必须保留。

标题/摘要/结论/claim matrix 使用同一强度：模型相对就写模型相对；附加原则就明示；只证明某表示边界就不写基础 HoTT 已失效。只有 AST-G01–G06 闭合才能交付声明范围内的目标结果。“第四次数学危机”是用户对影响的期待，不是由文件数量或模型自评决定的数学验收字段。

## 7. 本设计的完整性验收

设计交付要求：九片及索引齐备；主 X 与支线不混；四层都有目标/方法/控制/失败/下游接口；所有十个旧审计问题均有处置；U00–U09 顺序和首单元具体；源/run/claim/Git 边界明确；有停止与重开条件；数学未知没有被写成已证结论。

验收不要求假装主定理已经知道真假。设计完成表示执行者知道要判断什么、用什么证据判断，以及不同结果后做什么；不表示已证明一定存在能命中的实例。

本轮仅验证文档结构、链接、范围与设计要件。后续实际证明必须另有原生运行收据与语义验收；不能拿本设计的 PASS 替代数学 PASS。
