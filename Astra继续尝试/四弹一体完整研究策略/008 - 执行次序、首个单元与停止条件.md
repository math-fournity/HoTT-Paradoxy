## 2. 首个执行单元已经具体到可以开工

`AST-U01` 的唯一直接父结果是让共同 X 与第一项候选具有可检查的任务身份。输入固定为：用户 `72#/request/messages/62` 原文、022/023 的原操作描述、Astra 审计第 002/006/007 片、现有 M3-UNC 的实际构造。

按以下顺序完成：

1. 列出原环 C、指定点 p、M、N、展开/复原操作的来源；默认采用原 022 的开区间呈现。标明这个选择是本设计的数学实例，不宣称涵盖所有用户可能表述。
2. 对每个动作写清是否可以改变载体、增加点、保留来源、使用时间参数；不要把“稠密”直接改写为“只允许反复减半”。未获来源支持的限制不可偷偷加入。
3. 定义 Task/Trace/Done 及 Denotes 的最小接口，写出每条桥梁预计检查的命题。实物模型未取得的字段保持显式参数，不用隐藏 postulate 填洞。
4. 把既有 M3-UNC 的**实际平方比较任务**接成第一个非空正控制，验证输入→程序→正确性→观察这条路径；其身份仅为校准，不称圆环完成，也不冒充新数学发现。
5. 给主 X 的点集模型列可导入实物或最小新增定义；如果目前没有已资格化模型，输出 `GEOMETRIC_MODEL_QUALIFICATION_REQUIRED` 和精确下一来源/证明义务，不以假模型宣布主链已通。
6. 做一次独立的错误规格控制：同指一个数但交付类型不同，必须被对照表/检查拒绝等同。它检验规格忠实性，不以此替代原目标。
7. 输出单元结果和 U02/U03 的具体继承接口，完成逐 KC 与遗漏复核。

本单元核源码建议仅建立 `TaskContract.agda`、`TaskControls.agda`，以及必要的本单元说明；不批量创建第 007 片全部模块。它的价值是减少决定性未知及接通真实校准，不是证明了原目标。接口足够即离开，不重复打磨。

## 3. 第一轮最短完整路径

用户持续Goal固定先完成断点检查，再继续完整策略。本次接续先补齐断点GEO-01至04及必要证据门禁；这些工作直接服务U01/U03/U04，不能被独立的算术成功替代。断点专题完成后，按U00/U01剩余→U02→U03/U04剩余→按实际依赖进入U05/U06→U07组合执行。每个单元同步执行U08，并最终处理U09；具体完成性见第010片。

如果 U02 构造性地完成查询/表示，它应作为强正控制反馈主线，不让“Ω 总要收费”的旧叙事继续主导；不需要先完成全部实数代数才回到 U03。如果 U03 的同任务合法过程可完成，当前过程不可能性候选必须停止，不能改回只允许某个失败算法后继续算命中。

## 4. 证明遇阻时怎样继续

| 遇阻类型 | 下一行动 | 不能做的事 |
|---|---|---|
| 语法/库接口 | 固定版本定位并修实现；保留失败 | 称为数学不可能 |
| 规格与原典不符 | 修正目标类型，再新 run | 让旧 PASS 为新类型背书 |
| 证明方向有反例 | 原样保留反例并重定候选 | 削弱控制或改变 Done 保住“成功” |
| 只有参数化接口，无实际模型 | 先取得该模型或限制结论 | 空类型参数下的条件定理冒充实际实例 |
| 无条件必要性不出 | 做预声明的反模型/弱化关系检查，或精确 OPEN | 反复把“某种原则”放宽到同义反复 |
| 同任务恢复有效 | 撤回当前指控，保存可复用正构造 | 把理论防线成功说成第四弹成功 |
| 同一障碍反复出现且无新机制 | 记录原因与一个有信息价值的分支；没有分支则结束该单元 | 仅增加同形案例或更多旧 run |

## 5. 有界停止与后继

一个单元可因命题已闭合、候选被反驳、声明输入范围已检查完或决定性外部输入缺失而结束。观察预算耗尽只给 `INCONCLUSIVE`。没有任何条款授权通过无限运行保证发现；也不因开放世界还有别的问题而阻止当前设计/单元完成。

每次单元结束要回答：新增实际构造是什么；哪个未知减少；原父目标是否更近；有无换题；下一最小判别是什么。只有出现新的规则组合、来源、观察量或反例机制，才重开已经同形失败的工作。旧 session 的高亮项目不自动复活。
