# 第一弹：过程与完成性质

## 1. 本弹要给出的结果

对已经固定的 X 和合法操作，实际构造过程，并证明它是否能满足固定完成标准。需要的证据是操作语义与全称命题，不是一次超时、词语“无限”或某份证明拒绝。

候选命题 `AST-PROCESS-001`：给定初态与 Step，不存在到 Done 的有限 Trace。候选 `AST-PROCESS-002`：给定程序及语义，对任意有限执行步数不进入成功终态。两者依赖不同定义，不能互换；具体程序不终止不等于所有实现都不可能。

## 2. 主线从三种操作模型同时起步

| 模型 | 动作与完成 | 目的及边界 |
|---|---|---|
| `RING-HALVING` | 按明确规则缩小缺口；精确关闭 | 校准无限逼近论证是否只来自被指定的减半算法；不能先归因给稠密性或 HoTT |
| `RING-ALLOWED-RESTORE` | 原任务实际允许的移动、连接、恢复指定点等操作 | 决定真正的原任务能否完成；每个操作须有独立来源与语义 |
| `RING-APPROX` | 明确精度 ε 的接近条件 | 观察“精确未到达”和“任意精度可交付”的不同；此任务是对照，不冒充原精确任务 |

步骤必须包含正控制：尝试有限时间的闭合轨迹、保留指定点和来源后恢复、以及相应结构变换。在这些操作被原合同允许时，不能为保住否定结论临时删去；如果不允许，须说明禁令来自哪里。

对于时间参数化路径，可试拟 `gap(t)` 的显式轨迹及端点条件；能否满足全部拓扑、运动、许可及完成要求由新证明决定，本计划不把某条公式先宣布为现实完成。若它成功保留原任务，当前“所有合法过程不能完成”候选必须撤回。

## 3. 无完成证明的真正范围

首先尝试不变量或可达性证明：固定 `Inv initial`、`Step` 保持 `Inv`、`Inv` 排除 Done，并通过 Trace 归纳组合。这是一条待实施的证明路线；不能把欲证结论直接写成 `Inv` 的未经证明假设。

若排除的是全部有限 Trace，结论范围是所定义的动作系统。要外推全部程序，需给出程序语言与语义覆盖，证明每个合法实现的成功行为对应一个这样的 Trace。没有这条覆盖时不使用“任意算法”。

若涉及真实归约发散，则保存语法、归约关系与发散证书。若只是固定 wall-clock 窗口内未完成，报告 `OBSERVATION_TIMEOUT` 并记录预算，不用重复 timeout 支撑全称。

## 4. Pell 证据怎样接入

在 `AST-X-SQRT2` 支线中，保留 M1 的 `∀ n` 判别式结果，不把它降为有限实验。但补充以下接口义务后才谈夹钳过程：

- `AST-PELL-REP`：整数递推到有理端点的定义；分母合法性；
- `AST-PELL-BOUND`：端点与固定标准 cut 的关系；
- `AST-PELL-DONE`：该过程的 Done 与所用判别式条件的连接；
- `AST-PELL-APPROX`：若需要谈逼近/收敛，单列误差、精度与到达界；
- `AST-PELL-SCOPE`：若没有“最优”的正式比较域与证明，不使用最优二字。

M2 继续提供“输出一个有理数精确根”的边界。它不是证明所有正确的实数算法都不终止，因为后者的输出规格尚需确定。该边界主要用于识别旧链的换题风险。

## 5. 最小输出与退出条件

本弹至少交付一个 `Step/Trace/Done` 实例、一个成功正控制、一个候选否定或明确失败位置。其后立即检查与第二弹的连接，不先扩展通用执行器。

- 否定成立但动作系统是人为减半限制：`ALGORITHM_SPECIFIC_BOUNDARY`，不得完成父目标。
- 同任务正控制完成：`DEFENSE_PRESERVES_TASK`，进入反思并停止该否定候选。
- 缺口在几何模型/来源：`GEOMETRIC_BRIDGE_OPEN`，给出最小模型义务，不用算术替换。
- 原生核接受精确过程命题且桥梁具备：允许进入第二弹；该状态仍不等于最终失配。
