## 4. 当前有信息价值的后继

稳定任务ID：`BP-GEO-RESTORE-01`。目标是检查“删点+记住原点”是否提供自然恢复，以及逆向分类的精确条件。候选类型：

~~~text
Puncture C p = Σ x:C, ¬(x=p)
extend : Puncture C p ⊎ Unit → C
SplitRestore = Σ decode:C→(Puncture C p ⊎ Unit), ∀x, extend(decode x)=x
PointDecidable = ∀x:C, Dec(x=p)
~~~

先尝试两方向的构造，并在需要的set假设下检查是否可取得保持包含映射的等价；再实例化已有QCircle及east。不是预设结果，也不把`Dec(x=p)`默认为真实实数输入自带。若得到恢复，检查它是原任务允许的扩张、重新呈现，还是改变载体；这一判定不能由“类型有项”单独完成。

本任务的八轴：Σ/⊎/Path与删点 → 加回指定点/逆向分类 → 记录来源的恢复任务 → 自然包含与decode消费者 → 集合层路径/函数 → 显式恢复及观察等式 → 原生Agda及反向构造 → 固定Cubical v0.9。只研究该有界类；不声称搜索任意几何操作。
