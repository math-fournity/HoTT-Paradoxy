# 第二弹：理想对象与有效兑现

## 1. 第二弹检验的对象

保留旧策略“先构造最强回应，再检验它是否完成原任务”的核心。回应可能是紧化、极限、标准 cut、携带模数的近似算法、保留来源的结构化表示或层级追踪。不能先把它们都命名为“假装完成”。

本弹的待证目标 `AST-REALIZATION-001`：一个确切理论对象 E 是否提供了第 002 片规定的输出与完成证据。若否，定位缺少的函数、输入或证明；若是，当前第一弹的过强解释失效。

## 2. 三种取得方式必须分开

| 方式 | 实际给定 | 需要证明 |
|---|---|---|
| supplied | E 及其规格作为任务输入 | 使用者能取得什么；不声称已实现 E 的生产者 |
| generated | 一个程序/有限构造描述及其正确性证明 | 它在所需输入上实际产生什么；所需总性/生产性命题 |
| existential | 仅有相应存在命题，可能被截断 | 消去到当前输出是否许可，是否需要选择原则 |

不同输入不能直接比较谁“更容易完成”。比较 supplied 与 generated 时，任务要么都只要求使用已给输入，要么都包含生产输入的义务。获取成本不会因存在对象名称而消失，也不会因对象是无限域函数就自动变成无穷次执行。

## 3. 几何主线的回应必须实际给出

至少检查以下三类回应，均围绕同一 `AST-X-RING`：

1. **恢复被记录的原指定点/边界数据**：若原输入已经携带来源及点 p，恢复不能被误称为额外 oracle；须证明这种恢复保留原操作许可和完成标准。
2. **构造扩张或紧化对象**：给出实际载体、嵌入和相应结构，不用 `base : S¹` 的别名冒充。构造对象是否就是原任务的完成，取决于原任务是否要求运行过程、保持原载体或允许扩张；分别核查，不预判。
3. **显式过程恢复**：在允许操作中给出有限 Trace 或时间参数化实现。检查完成发生在原任务要求的层，而非只证明某个极限对象存在。

如果扩张改变了输入域或增加了不可获得信息，登记具体改变；但“有新定义”或“用了构造子”本身不算新增现实资源。若反解释保留全部原条件，本候选必须接受它为成功恢复。

`BP-GEO-RESTORE-01`现已检查自然映射`(C去p)⊎Unit→C`及逆向读出，并在原QCircle/east/包含映射上实例化；任意C,p的条件规格不需要额外isSet C。来源为第二轮C-261–C-264，身份仍是内核接受、全交付门禁PARTIAL。集合层恢复之后必须继续核拓扑、原载体许可和有限过程；局部正构造不能被忽略，也不直接宣布用户复原任务完成。

## 4. 算术支线先完成最强构造性对照

`StandardDedekind.agda`与`Sqrt2CutBridge.agda`已经新增并通过C297/C298原生核验，旧`CutRealLayer.agda`原字节保持。定义与固定Book §3.7/§11.2对照：

```text
inhabited : ∥ Σ q, L q ∥ × ∥ Σ r, U r ∥
rounded   : 逐点 L/U 与截断存在命题的双向关系
disjoint  : ∀ q, ¬ (L q × U q)
located   : ∀ q r, q < r → ∥ L q ⊎ U r ∥
```

`isProp (dcutStd L U)`和StandardReals集合性已经证明，旧GOLD组件已实际装配为标准载体元素。强locatedness合法注入截断；1<2处的原强输出L1⊎U2非Prop亦已检查，不能将这种选择数据当所有标准实数的定义要求。当前SQ-REP已完成到固定L/U标准载体这一精确范围。

已核实现固定`L/U : ℚ → hProp ℓ`：双向函数版本dcutStd在Typeℓ，标准载体在Type(ℓ+1)；字面Book rounded类型Path版本dcutBook在Type(ℓ+1)，与dcutStd的跨层等价有实际项。该层级差别没有被隐去。当前GOLD标准元素和旧DedekindReals0元素均在Type1，不需要新增LEM/resizing/SingleOmega前提；ℝLayerAt0的额外缩层目标没有取得，必要性仍开放。

`Sqrt2CutBridge.agda`已实现截断存在装配、rounded桥、标准disjoint、截断located和与原L/U的refl对应，并桥接旧修正dcut。当前尚未新增实数环运算、嵌入及环内x²=2定理；若将来作该主张须另补相称证明，不能由模块名字代证。

## 5. 同一 √2 的四个任务公开并列

| 任务 | 输入/输出 | 作用 |
|---|---|---|
| `SQ-QUERY` | 输入 q:ℚ；返回精确 L/U 命题的可决定结果与正确性 | 构造性查询正控制，不再将旧 q²<2 表直接当整个下切割 |
| `SQ-APPROX` | 输入精度 n；返回有理上下界及宽度、包含性证明 | 检验有效近似的完成；每个 n 的 total 算法与一次跑完所有 n 分开 |
| `SQ-REP` | 返回标准 cut 及其规格 | 检验有限形式描述/程序能否交付这个无限对象的表示 |
| `SQ-RATIONAL-ROOT` | 返回 q:ℚ 及 q²=2 | 已有 M2 的边界控制；不冒充前三者 |

SQ-QUERY已由C299对全部q构造实际L/U Dec并接goldReal投影。负三处旧平方表false、真实下切割true；Sqrt2TableRecovery又从任意旧Spec_A加符号判断恢复正确下切割查询，并逐q证明一致，故不能把语义差异说成不可恢复。

当前近似单元固定有理二分、初始下界1与上界2、按n递归，保持L(lower)/U(upper)，目标宽度等于(1/2)^n。先定义明确宽度函数与不变量，再证明全部n；固定样例只作执行控制，不承担全称性质。每个n的有限交付不等于一次执行全部精度。

若前三项构造性通过，旧“该给定数据不对应任何完成”说法不能继续泛称这一个 √2；必须明确原来要求的是哪种完成。若某项失败，先区分库缺件、规格错误、实现困难、所需原则或已证不可能，不直接判理论失效。

## 6. 从单个对象到统一实现

对固定 √2 的算法，不外推为所有 Dedekind cuts 都有统一算法；对所有 cuts 的可能障碍，也不倒推固定 √2 无法完成。

只有当真实待审能力量化所有 cuts 时，才引入明确程序编码、有效语义和 `Realizes code cut`，研究统一实现。采用现有 R2 资产前核其通用性/显式 CT 前提与当前类型论的连接。这个升级是新的候选域，不允许在固定对象候选被否定后悄悄替换输入分母。

## 7. 本弹输出

输出一份按回应分类的兑现表，以及被实际证明的 E→输出连接或其缺口。状态可为 `REALIZATION_CONSTRUCTED`、`MERE_EXISTENCE_ONLY`、`EXTRA_INPUT_REQUIRED`、`REALIZATION_IMPOSSIBILITY_PROVED_WITH_SCOPE` 或 `OPEN`。

“没有找到实现”不是“不对应任何过程完成”。只有精确实现类上的反证、归约或模型结果才能支持后一个强度。数学结果通过 F-011 后，才可进入第三弹组合。
