# 同一变形的延拓、距离与纤维

研究对象仍是同一个实数平面的N、M与第六轮F。本轮把曲线参数从(0,1)扩充到[0,1]，证明新函数在所有内点与旧函数一致；时间仍取[0,1]。源码[EndpointClosure.lean](../../../HoTT/formal/astra-real-geometry/EndpointClosure.lean)及C-271–C-273为唯一数学依据。

## 1. 消去端点分母

令v=2u−1，定义：

~~~text
d = 1 − |v| + (1−t)² |v|
n = ((1+t²)/2)v + ((1−t)/2)d
D = d² + (tn)²
B̄(t,u) = (nd/D, tn²/D)
F̄(t,u) = A_t(B̄(t,u))
~~~

A_t是上一轮同一个`turn`，没有重新选择几何对象。`closingDen_pos`证明D在整个闭方形严格正，包括四角；因此公式在闭边界也有定义且联合连续。`unboundedParameter_formula`和`stretch_as_fraction`将原ρ及stretch化为n/d；在开参数域中d>0，`extended_agrees_interior`证明F̄(t,u)=F(t,u)。该一致性对任意实数t与任意开区间u成立，联合连续交付范围是声明的闭方形。

这一步既没有把某个数值逼近当极限，也没有用“定义了末值”跳过连续性证明。

## 2. C-272：端点距离的完整时刻判别

令`g(t)=dist(F̄(t,0),F̄(t,1))`。实际证明：

| 命题 | 形式定位 |
|---|---|
| g在闭时间区间连续 | `endpointGap_continuous` |
| g(0)=1 | `endpointGap_initial` |
| 每个0≤t<1都有g(t)>0 | `endpointGap_pos_before` |
| g(1)=0 | `endpointGap_zero_at_end` |
| F̄(1,0)=pole且F̄(1,1)=pole | `extended_final_left/right` |

没有证明g在整个过程单调递减，报告也不作这个声称。准确结果是：每个末时刻之前的距离均正，末时刻距离为零，且距离函数连续。

## 3. C-273：精确核对全部重合情况

闭参数末态像是整个单位圆；它不单射。更精确地，对任意u,v∈[0,1]：

~~~text
F̄(1,u)=F̄(1,v)
  ↔ u=v ∨ (u=0 ∧ v=1) ∨ (u=1 ∧ v=0).
~~~

此外，`F̄(1,u)=pole ↔ u=0 ∨ u=1`，每个内点均不映到pole。证明分别使用末端显式值、内点一致性、第六轮的嵌入性及去点像排除；覆盖整个闭参数域，不是抽样测试。

因此不能把“两个不同参数的像重合”说成“两个不同的平面点距离为零”。相同的是末端像pole；不同的是参数域中保留的0、1标签。删除这两个参数后，正好回到原F的开曲线和去点圆像。

## 4. 与已有结果的关系

C-269的每时刻嵌入只要求开参数域，不与本轮闭参数末态非单射冲突。C-267的整平面同胚不可达也没有被撤回。C-271–C-273只是明确了这些不同结构和操作合同在同一个具体模型中的关系；未交付全演算HoTT结论。
