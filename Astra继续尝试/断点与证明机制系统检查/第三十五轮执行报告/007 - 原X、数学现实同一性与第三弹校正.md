# 原X、数学现实同一性与第三弹校正

## 1. 勘误触发和不改变的部分

用户在本报告完成后澄清：A、B 和共同的 X 最初要观察的不是“\(\sqrt 2\) 是否有有理精确根”，而是带指定点的圆 `C` 去点、去点圆 `M`／开区间 `N` 的呈现、以及两端闭合并复原的过程。逐字可见问答由本专题的[对话原文索引](../对话原文.md)及其新增分片保存；历史方案证据仍是022、023、025，均未改写。

本勘误不撤销001–006已经成立的范围判断：旧 M3 确实只否定了指定算术规格的等价；当时没有找到 HoTT 实际承诺把它们当成同一任务。需要修正的是表述范围：`Spec_A`／`Spec_B` 不能被描述成已经观察或击中了原圆环闭合过程。它们只是一项有用的校准，表明“共同数学对象”不会自动消除输入、输出或 Done 的差异。

## 2. 三个不能合并的关系

对于原主过程，当前采用如下分层：

```text
R = RealitySame(A, B, X)
  A、B 共同指向 C → M/N → 闭合/复原的被考察过程。

C = SameInput(A,B) ∧ SameOperation(A,B) ∧
    SameObservation(A,B) ∧ SameDone(A,B)
  A、B 在明确合同下确实承担同一任务。

H = 某个 HoTT 规则、定理、库接口或实际消费者，
    把 A 当作足以履行 B 的可替换处理。
```

R 可以是外部语义前提、模型解释或形式规格的显式参数；这不要求 HoTT 内核先证明“现实中的 X”。它也可在较具体的模型里由 `Denotes`、来源关系或模拟定理支持。可是 R 的内容只是共同指称，不能自行推出 C，更不等于 H、类型相等、同伦等价或 `Spec_A ≃ Spec_B`。

静态 A 可以是 `M ≅ N`、紧化、极限点、理想元素或已有闭合对象的表示；过程性 B 则问在已经公开的操作、观察与 Done 下，端点是否实际合并、闭合结构和去点位置是否得到复原。若要加入离散、量子化或其它现实模型，它们仍是额外的现实前提，不能由拓扑或 HoTT 自动提供。

## 3. 对第三弹和整体判词的后果

第三弹的待证链不是先假定 `Spec_A ≃ Spec_B` 再用 M3 否定它，而是：固定原 X 的 A/B/合同，定位一个真实 H，再检查 H 是否保持所选 Observation 与 Done。若 H 不存在，结果是“在已审来源中没有发现实际理论把该静态处理当作过程完成的同一任务承诺”；这保持 `ORIGINAL_FOUR_STAGE_TARGET_NOT_ESTABLISHED`，但理由变为原圆环任务缺少 C/H，而不是简单说两项算术规格不同。

若 H 被定位，才需要为该精确 H 制定新命题、反解释、源/运行边界和机器证明门禁。现有 M3、M1/M2、B1a 或 C321–324 都不能替它占位；第四层的条件充分性也不会把 H 自动补上。

本轮勘误的停止条件是完成 R/C/H 映射并对已固定的原方案、当前策略、已有形式资产和已审自然消费者作有界检索。它明确不包含全库搜索、新消费者合成、重跑未变 kernel 输入，或第二阶段的新候选研究。
