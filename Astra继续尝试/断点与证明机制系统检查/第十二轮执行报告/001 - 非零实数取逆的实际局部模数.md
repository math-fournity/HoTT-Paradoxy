# 非零实数取逆的实际局部模数

`ReciprocalContinuity.agda`针对实际`nonzero-ℝ lzero`：元素包含一个Dedekind实数及其apart-from-zero证据，度量为原实数度量的子空间限制。`recip`就是库的`real-inv-nonzero-ℝ`，不是新公设函数。

## 1. 固定点附近的控制

在当前输入x处，取正有理数r并要求`r+r ≤ |x|`。对输出精度ε定义：

~~~text
C(r) = inv(r) * inv(r)       （正有理数运算）
budget(r,ε) = inv(C(r)) * ε
μ(r,ε) = min(r, budget(r,ε))
~~~

μ本身是一条明确的正有理数函数。代码证明C·budget=ε；不是从“逆函数应当连续”的名字反推其存在。

## 2. 两项实数估计

由三角不等式、`r+r≤|x|`和`dist(y,x)≤r`，`nearbyLower`得到`r≤|y|`。这一步保证邻近点的逆元有共同上界。

`inverseBound`从`r≤|z|`推出`|1/z|≤1/r`。证明先把非零实数逆元的绝对值识别为正实数|z|的逆元，再使用正实数取逆的逆序性及有理嵌入的逆元保持。

`reciprocalDistance`给出精确式：

~~~text
dist(1/x,1/y) = (|1/x|·|1/y|)·dist(y,x)
~~~

随后`localEstimate`依次取得：

~~~text
dist(1/x,1/y) ≤ C(r)·dist(y,x) ≤ C(r)·μ(r,ε)
             ≤ C(r)·budget(r,ε) = ε.
~~~

量词遍历所有声明的非零实数x/y和所有正有理ε，邻域使用库原来的闭有理邻域条件，不是有限样本。

## 3. 所需r怎样取得

nonzero证据给出|x|严格正；库的lower-cut性质给出截断存在的正有理γ<|x|。在连续性这一命题目标内合法消去该截断，取r=γ/2，再用上述μ构造模数的截断存在。

本轮没有新增、也没有传入选择公理或LEM。结论形态是库定义的`∀x, ∥Σμ, modulus-condition∥`；没有升级成一个已提取、对全部任意实数表示都有效运行的全局数值选择器。库已有公设/变体边界照旧披露，本说明不代替最小公理依赖提取或全库一致性证明。
