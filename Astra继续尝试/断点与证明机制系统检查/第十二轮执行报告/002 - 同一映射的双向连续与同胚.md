# 同一映射的双向连续与同胚

`StereographicContinuity.agda`保持C-281的实数、乘积、圆子空间和逻辑去点子空间度量；强域度量仅再限制到`apart(x,1)`子类型。没有另设一个“让映射连续”的拉回度量来求通过。

## 1. 前向投影

强域到两个坐标的映射保留原邻域，连续模数可取恒等。常值1、取负和加法给出`1−x`连续；把同一值及既有非零证明放入非零子空间，连续性不变。再与本轮已证明的取逆连续性复合，最后乘以y，得到**上一轮同一个**`stereographicForward`的点态连续性。

## 2. 反向参数化

真实乘法和加法给出t²、D=t²+1及两个分子连续；D已有实际非零证明，使用相同子空间/取逆组合取得q=D⁻¹连续。两次乘法和乘积映射给出C-285同一`paramPlane`连续，保留其圆方程和apartness证明分量后，取得`parameterize`对原子空间度量的连续性。

这里没有改写C-285源码，也没有把函数换成另一个只与它形式相似的函数。

## 3. 精确同胚合同

本轮自建`PointwiseHomeomorphism X Y`记录，完整字段为：

~~~text
forward, backward
forwardContinuous, backwardContinuous
∀y, forward(backward y)=y
∀x, backward(forward x)=x
~~~

其中Cont直接使用库的逐点模数式连续性。`strongHomeomorphism`六字段全部由实际函数和已核证明填充；不是只有名称的结构，也不冒称使用了库中要求更强的`uniform-homeo-Metric-Space`。

原W域同时有`weakHomeomorphism : Lift → PointwiseHomeomorphism puncturedCircleMetric realMetric`；提升和忘却都保持原点坐标及邻域，复合律沿上一轮真实等式装配。`classicalWeakHomeomorphism`明确以LEM₀为充分输入。无条件弱域Lift、其否定/独立性及LEM必要性仍未证明。

## 4. 仍未交付的内容

本轮得到的是所给度量下的双向连续互逆，即精确度量合同中的同胚。没有声称双向一致连续、等距或两个原给定metric作为数据相等。

目标另一端目前是全部实数；与原先(0,1)开区间的实际原生连续重参数化仍待构造。构造来源、固定端部、环境同胚或运动轨迹、时间/物理可实施性、完整Lean翻译仍各自独立，不能从同胚字段中自动取出。
