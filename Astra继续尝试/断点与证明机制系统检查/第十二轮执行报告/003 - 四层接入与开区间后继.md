# 四层接入与开区间后继

本轮把原生几何从集合层互逆推进到同一度量下的双向连续。`BP-GEO-NATIVE-STEREOGRAPHIC-01`的强域↔Real同胚阶段具备完整声明证据；原W域仍有条件，GEO04和四层redo整体不关闭。

## 1. 反思八项

1. 同一任务：五个本地模块形成依赖链，旧圆、旧映射和旧metric均未改；强/弱域仍分别命名。
2. 策略：从实际consumer缺少的连续性反推局部模数；真实库和明确估计服务既有主线。
3. 证据：取逆代数、附近下界、逆元上界、模数预算都由Agda检查；未用postulate补主结论。
4. 负结论：一次NotInScope是API名字错误，保留为实现失败；不作为数学拒签或负控制。
5. 新输入：库提供绝对值short-map，可用于后继开区间；这只是定位，不冒充新接口已完成资格化。
6. 修正：方案中的“双向连续未完成”应原位改为已完成到Real；无条件弱域与原过程义务不变。
7. 漂移：不用更强的uniform-homeo代替所需pointwise合同；不把同胚变成metric相等。
8. 工作姿态：局部估计完成后立刻回到具体两映射，而非停在一般连续函数理论；后继回原(0,1)接口。

## 2. 完备性与反解释

八轴：Dedekind/非零子类型/度量/截断 → 局部逆元误差控制与连续组合 → 同一圆点/参数任务 → 实际reciprocal和C-285两映射 → 原邻域/坐标 → 对全部点的连续与两律 → 原生Agda → no-erasure声明公设配置。

量词来自证明项，无有限枚举和开放世界完备性声明。正控制是原两复合律、坐标投影的恒等模数与原W域条件同胚；截断只消去到命题，不假装拿到全局数值选择函数。当前接口失败的修复没有改变数学规格。未触达的HoTT其它断点、自然误用、物理过程和全理论仍开放。

## 3. 下一有界单元

`BP-GEO-NATIVE-INTERVAL-01`：构造Real与C-281同一OpenRealInterval的实际互逆连续映射，再与本轮同胚复合。候选公式可从`t/(1+|t|)`到(-1,1)再作仿射重标；公式只是下一构造方向，尚未过核，不能提前交付为成立结论。

仍须证明每个输出严格位于开区间、逆向分母可逆、两条复合律和双向连续；不能用闭区间仿射同胚替换，也不把有界/无界域的双向一致连续要求混入。原弱域的Lift条件必须继续穿过复合后的接口。

完整四层中的GOLD标准打包、查询/近似/Pell桥、必要性、原操作限制、其它证明机制和学术交付仍按完整策略保留。当前结果是实际几何的正对照与保真推进，不构成HoTT内部矛盾。
