# 同一原生曲线族的证据记录

C319的`NativeMotionEvidence`是单个数学实例的typed记录，所有字段绑定既有motion/closedMotion、原Real/Plane/开闭参数及原n/m图；不是可由任意换题模型填充的抽象接口。实际构造`nativeMotionEvidence`已过核。

| 字段 | 原函数上的义务 |
|---|---|
| jointOpen | 原开参数族的联合连续 |
| jointClosed | 同源闭参数族在闭方形上联合连续 |
| sliceHomeomorphisms | 每个闭时间切片到实际平面子空间像的同胚 |
| interiorAgreement | 全部原开参数上closedMotion=motion |
| initialDiagram | 完整闭参数初态等于原nCompletion |
| finalDiagram | 完整闭参数末态等于原mCompletion平面图 |
| endpointMeeting | 闭时间内端部同像iff t=1 |
| finalFibers | 全末态同像参数关系的双向分类 |
| closedBounds | 原闭时间/闭参数域每坐标≤256 |
| openBounds | 原闭时间/开参数域每坐标≤256 |
| weakCoverageCriterion | 该固定末态参数化的完整Weak覆盖iff Lift |
| weakChosenOutput | 给定Lift，返回原Weak点对应的原参数和等式 |

原分母资格由构造定义及C314持有，汇总记录不抹去它们。主run重新编译原依赖链，未仅凭文档把旧结果加在一起。新旧源清单核对保持原函数字节不变。

这完成第二十五轮005中声明的原生参数图几何构造/检验范围，并显式定级Weak条件。它不证明整个Lean/原生实数模型之间的机器翻译，更不自动建立原广义现实操作、某个被指控的HoTT能力承诺或现实相对失配。记录标题中的完成只属于这里列出的固定数学合同。
