# 原始四层论证与各任务判词

研究对象是原圆环问题与后来四弹规格之间的关系，不预设 Pell、平方比较或 Ω 小型化已经保真代表圆环。六条用户原文分别保留原始 P/非P 设想、距离与复原、N 不能成为 M、理论风险、证明机制，以及“来源/断点属于对象”的要求。本轮全文复读冻结的六条文本及022/023/025/027/030；哈希与入口见006。本文是其证据审计，不改写原文。

## 1. 原问题中必须保留的内容

用户并非仅问两个裸集合是否有双射。原文把来源、缺点、闭合方式、允许变换和复原能力放入对象问题；027文本又允许 M 的其余部分变形，并强调端部/断点结构。当前 Rich 模型已保留完整闭参数图、开部分与其关系，因而确实比裸载体更丰富。但它没有声称记录全部创造历史、因果事件或所有物理可操作性。

“M 与 N 是同一研究对象对”仍不自动确定允许哪种操作。C320在固定这对对象后，继续把操作合同列为显式数据。采用某个精确合同是研究实例化；若要把结论提升到原广义现实断言，还须证明该合同忠实于原要求。不能让本 AI 的新正构造享有题意豁免，也不能让旧否定构造享有题意豁免。

## 2. 当前各候选的判词

| 候选 | 直接证据及已成立范围 | 当前判词与关键限制 |
|---|---|---|
| R-CURVE 连续曲线变形 | C311–319及C320：同一原生曲线族、实际像的切片同胚、闭图、端部时间、纤维和统一坐标界 | `DEFENSE_PRESERVES_TASK`，限已声明的曲线合同；“此合同内N不能成为M”不成立。不是物理实施或全部来源语义 |
| R-AMBIENT 有限环境同胚 | C293/294及C320：保存全闭图的每步环境同胚，nRich→mRich 的成功类型为空；swap 正控制非空 | 限定的 `REPRESENTATION_BOUNDARY_ONLY` / 操作边界；不能省略环境/闭图合同后声称所有过程不可能；G02错误承诺未定位 |
| R-REP 给定完整源的重新表示 | C295/296：给定完整源、载体编码，运输后的目标保留原闭图；目标不是预先指定的普通nData | `DEFENSE_PRESERVES_TASK`，限给定源的表示合同；不等于从丢失历史的裸数据恢复任意源，也不等于物理弯曲 |
| 固定最终图的完整Weak覆盖 | C319：该图覆盖Weak点，等价于Lift/RNZA；给定Lift还能返回选定参数 | `OPEN_WITH_PRECISE_OBLIGATION`。精确原则关系成立；相对整个基线的可证性/独立性、一般任意同胚必要性和现实归因未证 |
| A-SQRT2 原M1/M2/M3连接 | C297–303：标准GOLD、查询与各阶段近似有实现；有理精确根/Pell归零等任务无实现；旧Spec_A/B精确接入不同请求 | 旧整体指控为 `WRONG_SPECIFICATION_OR_ATTRIBUTION`。同指√2不等于同交付规格，M3未证明HoTT自己许诺了两请求等价 |

| 元层引擎与规范化 | C304原生J/Glue/HIT消费者和已有精确公设控制；原027/030元层论证 | 指定实现/公设/运行事实保留；理论普遍不对齐、所有可行框架三难或不可能性未机器证明 |

这些判词不形成新的“任何结果都算击落成功”规则。可保任务恢复成功就关闭对应指控；有界差异保留其范围；尚缺连接必须继续标OPEN。

## 3. 五份原方案中的决定性推论

022把开区间的某些性质推进到“一切连续复原都不能完成”；需要完整操作量词。C320提供同一参数图上的实际连续变形正实例，因而旧文字不能继续作为该合同的全称不可能性证据。

023把理想对象的定义或增加理想点读成现实过程已被完成。必须另找理论或真实使用者把这项对象存在提升为哪一种操作能力的具体步骤；定义自身不充当这项承诺的来源。

025混合了几个不同问题：HIT圆的构造子与依赖消去、点集删点、裸类型识别、截断存在、平方比较和有理根输出。特别是“只有一个点构造子”不是当前已核的“所有点都可无条件选定路径到该点”的证明。本文不据此另交付一个未重放的HIT元定理；要求回到精确消费者与消去条件。当前几何包使用实际实数点集圆，不用名称相同替换它。

027的“引擎必须把所说的一切真的执行完才签字”还混淆证明检查、项归约、规范化、搜索和物理操作。030实际上已把B1b必要性降为猜想、B2降为问题，并撤回一项旧LEM论据。结尾更强烈的措辞不能取消正文承认的这些未决。

## 4. 对当前用户问题的直接回答

有必要redo，且redo已经产生实质纠正：原生系统既能接受精确的否定定理，也能接受在不同合同下的正构造。“Agda不给通过”必须继续拆成错误项被拒绝、证明了某个否定命题、工具/公设配置问题和未完成搜索；它们不是同一个事件。

当前不能认同“四弹完美地击落HoTT”。理由不是一般地坚持传统理论，而是目前的正负结果尚未对应同一个被HoTT错误许诺的任务。六项义务的剩余见004。该判断允许未来被新的原文、自然消费者或保真证明修正，也不把修正责任转交给用户。
