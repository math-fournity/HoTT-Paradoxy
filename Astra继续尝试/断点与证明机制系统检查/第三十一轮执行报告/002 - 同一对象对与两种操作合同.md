# 同一对象对与两种操作合同

C320在固定without-K/no-erasure原生Agda库中检查同一nRich/mRich对，而非把新正构造与旧否定定理各取一个名称相同的替身。入口为[NativeTaskIntegration.agda](/Volumes/D/HoTT_AI_HANDOFF_20260911/HoTT/formal/agda-unimath/hott-z/NativeTaskIntegration.agda:31)。这是有限范围的类型内定理，不是系统一致性或现实物理证明。

## 1. CurveRun精确要求

`CurveRun r s`携带闭时间上的开参数曲线，以及闭时间×闭参数的连续扩展；两者在内部逐点相等。每个时间切片是开区间到**该切片实际像、使用原环境度量**的同胚；`sliceIsActualMap`进一步要求同胚的正向函数就是原曲线映射，而非任取一个无关同胚。

它还要求在整个闭参数域上，初态等于`closedImage r`，末态等于`closedImage s`；全闭域满足既有每坐标绝对值≤256的界。没有改成只核内部几个样点，也没有用给像另赋有利拓扑绕过连续性。

`actualCurveRun : CurveRun nRich mRich`由既有`motion/closedMotion`和原证明逐字段实现。本轮没有改动该原函数、原闭延拓或n/m闭图；证明记录中实际中间曲线及其地图身份可直接查看。

## 2. 与有限环境任务的同对照

`Success (r,s)`沿用NativeCurveTask：有限条`AmbientStep`，每步给全平面同胚并要求完整闭参数图相容，最后等于目标Rich对象。它不是所有连续曲线变形的同义词。

新增定理精确如下：

~~~text
CurveRun nRich mRich × ¬ Success(nRich,mRich)
¬ (CurveRun nRich mRich → Success(nRich,mRich))
¬ ((r s : RichCurve) → CurveRun r s → Success(r,s))
¬ (CurveRun nRich mRich ≃ Success(nRich,mRich))
~~~

第一项同时提供实际曲线构造与已核环境任务否定；第二、三、四项据此拒绝把曲线成功转为环境成功。与此同时，`Success(nRich,swappedN)`有实际非恒定环境变换控制，避免把环境类定义成一概为空。`¬(mRich=nRich)`也仍保留：曲线可变形不是两个带预设闭图结构的对象已经相等。

## 3. 这具体消除了什么疑问

过去“Lean通过、Agda拒绝”容易被听成两个证明器对一个命题判了相反结果。当前**同一原生Agda包**同时接受了上述正构造和否定定理，明确显示这次差异在允许操作及成功类型。它没有用Lean普通Eq冒充HoTT原生结论。

正负两边都使用nRich/mRich，但它们的谓词不同，因此并未给出同一P与¬P。若有人宣称两种成功类型等价，该具体宣称会被C320否定；本轮没有找到原HoTT规则或所读原典段落作出该宣称。

## 4. 不能外推的内容

- mRich的开像是StrongPuncture；“不等于删去点”的WeakPuncture之完整覆盖仍由C319的Lift/RNZA条件负责。
- CurveRun允许端部轨迹随时间改变；它不是端部全程固定、不变闭包或全程全平面同胚的任务。
- 全闭图相容不等于全部历史来源数据。没有把Rich当作用户全部“现实同一性”的穷尽定义。
- 坐标界给空间范围，没有给速度、能量、有限信息测量或物理设备实现。
- 抽象中的相等、曲线变形和物理同一性分别有自己的桥梁义务。
