# 显式变形与精确机器命题

研究对象固定为`Plane = EuclideanSpace ℝ (Fin 2)`，N=`lineOpen`，M=`circleOpen`，定义与第五轮C-266–C-268完全相同。时间域是闭区间[0,1]，曲线参数域是开区间(0,1)。源码[DeformationCircle.lean](../../../HoTT/formal/astra-real-geometry/DeformationCircle.lean)在经典Lean4.34.0/mathlib中实际检查以下命题。

## 1. C-269的精确强度

~~~text
∃ F : MotionTime → Interval → Plane,
  Continuous (fun (t,u) => F t u) ∧
  (∀ t, IsEmbedding (F t)) ∧
  range (F timeStart) = lineOpen ∧
  range (F timeEnd) = circleOpen
~~~

`MotionTime=Icc(0,1)`，`Interval=Ioo(0,1)`。`IsEmbedding`是子空间拓扑意义的嵌入，包含单射及诱导拓扑条件，强于只声明函数连续或没有看到交点。末时刻t=1在定义域内，末态像的相等是核验命题，不只是“无限逼近M”。

## 2. 明确构造

令ρ为源码中`unboundedParameter : Interval ≃o ℝ`：先将u映到2u−1，再通过`orderIsoIooNegOneOne`的逆映到实数。它是固定的有序同构，不是任意选择的黑箱路径。

~~~text
squash(c,r) = r / (1 + c |r|)
q(t,u) = ((1+t²)/2) squash((1−t)², ρ(u)) + (1−t)/2
D(t,r) = 1 + (tr)²
B(t,r) = (r/D, tr²/D)
A_t(x,y) = ((1−t)x + 2ty − t, −2tx + (1−t)y)
F(t,u) = A_t(B(t,q(t,u)))
~~~

源码名称依次为`squash/stretch/bend/turn/deformation`，限制到闭时间区间后的见证为`curveMotion`。

每一步的性质分别检查：

- squash的分母正；c≥0时严格单调。
- stretch联合连续且对u严格单调；利用区间连通性得到拓扑嵌入。
- bend的分母恒正；其像所在的非零分母图表中有连续左逆`r=x/(1−ty)`，从而是嵌入。
- turn是整平面的显式仿射同胚，行列式`(1−t)²+(2t)²`恒正；正反向与连续性均核验。
- 复合给出联合连续性和逐时嵌入。

这里turn本身为环境同胚不意味着整个F可扩张为环境同胚；bend和stretch随时间改变曲线在环境中的呈现。

## 3. 初末状态

`squash_parameter`检查ρ与初态的具体关系。t=0时q=u、B=(u,0)、A为恒等，故`deformation_start u = lineEmbed u`，像精确为N。

t=1时q=ρ(u)，结果为：

~~~text
((r²−1)/(1+r²), −2r/(1+r²)),  r=ρ(u).
~~~

`circleParameter_mem`证明它在单位圆且不等于pole=(1,0)；`circleParameter_onto`反向从任意单位圆非pole点构造r=`−y/(1−x)`，证明整个M都被覆盖。ρ满射使`deformation_final_image`得到末态像=M，而非仅有M的一个子集。

## 4. C-270的统一空间界

`deformation_uniform_box`证明对所有0≤t≤1、所有u∈(0,1)，F的两个坐标绝对值都≤60。它和C-269使用同一显式函数，不是两个互不相关的存在性结果。

证明在t≤1/2时由squash控制q，t≥1/2时由bend的有理分母控制坐标，再用turn的系数界得到统一粗界。60不是最优界；它用于排除这条路径需要任意远空间这一潜在混淆，不证明速度、材料或长度条件。

该构造全程使用同一个开参数域，没有将参数端点加入曲线。闭参数域上的连续延拓、端点相遇及与固定环境操作的关系由下一单元另行检查；本轮不凭直观动画认证这些命题。
