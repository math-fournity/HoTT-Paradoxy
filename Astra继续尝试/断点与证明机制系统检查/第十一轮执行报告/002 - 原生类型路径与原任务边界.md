# 原生类型路径与原任务边界

本轮使用固定no-erasure变体中的公理式HoTT univalence。它是without-K配置下的声明公设路线；不把它描述成Cubical的判断计算，也不重新启用已隔离的等式擦除原语。

## 1. 这次类型路径连回了实际几何函数

`strongTypePath = eq-equiv strongCircleEquivReal` 的类型是 `StrongPuncture ＝ Real`。

`strongTypePathAction` 进一步对任意w证明：把该路径转回等价后作用于w，结果等于已经构造并验证逆映射的实际`stereographicForward w`。`typePathNorthOne`给出同一路径作用于north的结果等于1。

这些是**命题等式**。不声称该路径本身归约成refl、不声称一般不透明univalence公设有Cubical的判断计算规则。这里已把几何函数和原生类型路径的作用接通，不能再把当前结果只描述成一个有限Bool/整数图的演示。

## 2. 原始弱删点域仍保留其真实条件

源码同时构造：

~~~text
weakCircleEquivReal : Lift → PuncturedRealCircle ≃ Real
classicalWeakCircleEquivReal : ExcludedMiddle0 → PuncturedRealCircle ≃ Real
weakTypePath : Lift → PuncturedRealCircle ＝ Real
~~~

Lift下先按同一个点提升到StrongPuncture，忘掉apartness后返回原点；两边proof分量都是命题，相应复合律真实证明后才组成等价。没有把原W域改名为A域。

这是精确的条件结果。无条件Lift/LocalStability及其否定或独立性仍未证明；LEM仅是已有充分条件。也未证明“任何任意类型等价都必定提供Lift”，因为上一轮必要性针对特定逆元任务，不能自动扩展成所有可想象双射的必要性。

## 3. 已相等的类型与仍需证明的结构

这次Path位于底层类型宇宙；给定欧氏/乘积度量、环境嵌入、端部completion、构造来源及允许动作没有自动获得同一性。

尚未证明：

- 两个实际映射对所给度量点态连续，及其同胚装配；
- 与开区间(0,1)的实际原生连续重参数化；
- 与此前Lean实数、度量及具体映射的机器保真翻译；
- 原始固定端部或来源条件下的变形轨迹、时间/物理完成。

因此不能从本轮得出“原现实任务已经可还原”，也不能把带这些结构的对象直接替换成裸类型后，指控HoTT内部给出了P和非P。

当前证据支持一个具体正控制：在声明的强域上，HoTT里的实际点集等价和它所产生的类型路径正常对应。是否存在另一条自然使用链错误忽略必需结构，仍需具体来源、消费者与保持性证据。
