# 实际参数化与两条复合律

复用C-281的`Real = ℝ lzero`、方程圆`RealCircle`及缺口east=(1,0)，复用C-283/C-284的`StrongPuncture`和真实前向投影。没有引入新的Real参数、替代圆或同名HIT。

## 1. 对每个实际实数的定义

~~~text
D(t) = t² + 1
q(t) = inverse(D(t))
x(t) = (t² − 1) q(t)
y(t) = (t+t) q(t)
parameterize(t) = ((x(t),y(t)), 圆方程证据, apartness证据)
~~~

`positiveD` 从平方非负及0<1推出D(t)>0，随后由库的实际实数逆元得到Dq=1和qD=1。整个强域构造没有接受LEM/DNE/Lift作为输入。

## 2. 圆方程和缺口排除

`pythagoreanNumerators` 对任意实数t证明：

~~~text
(t²−1)² + (t+t)² = (t²+1)²
~~~

证明展开平方、分配律及加法消去；没有把这一恒等式写成公设或用数值采样代替。`scaledSquares` 与Dq=1继而给出x²+y²=1。

`paramDenominator` 证明 `1−x(t)=2q(t)`；代码给这个分母一个具体逆元 `½D(t)`，并验证乘法等于1。再使用上一轮已经证明的“任意逆元⇒apartness”取得 `paramStrong`，所以参数化确实落在声明的强删点域。由已有Strong→Weak也排除east，未把east作为有限参数的值偷偷加入。

## 3. 两个方向均回到原输入

~~~text
forwardParameter : ∀t, stereographicForward(parameterize t) = t
parameterForward : ∀w:StrongPuncture, parameterize(stereographicForward w) = w
~~~

第一条使用 `y(t)=t·(1−x(t))` 和分母逆元方程。

第二条重新消费原圆点的方程，推出：

~~~text
d²+y² = 2d
(t²+1)d = 2     （t为该点的前向投影，d=1−x）
d = 2q(t)
~~~

消去d有明确的已给逆元作依据，未在不知道可逆时约掉因子。随后分别恢复x、y，以子类型命题性处理证明分量，取得同一个强删点圆元素的等式。

两个复合律装配为 `strongCircleEquivReal : StrongPuncture ≃ Real`。这是全部声明输入上的形式证明，不是若干参数的回归样本；它仍只说明底层点集类型的等价。
