# 同源闭公式与构造性正分母

保持原Real、RealPlane、开参数及C311–C313函数。扩展后的参数为原`ClosedParameter=[0,1]`，时间先取全部Real，再限制到原闭时间区间。设a=center(u)，g=1−abs(a)，原scale=(1+t²)/2，offset=(1−t)/2；使用原EndpointClosure的同源表达：

```
D = g + (1-t)² abs(a)
N = scale(t)*a + offset(t)*D
K = D² + (t*N)²
Bclosed = (N*D/K, t*N²/K)
closedMotion = reflectY(turn(t,Bclosed))
```

C314证明对所有实t和闭u都有K>0。源码没有先决定t=1：严格序的cotransitivity给出0<t或t<1；t<1分支由abs(a)<1或0<abs(a)给出D>0；正时间分支在中心不为零时利用N−offset*D=scale*a及apartness cotransitivity，得到N或D相应的apartness资格，再推出平方和正。所有分支只向命题消去。

原`closedCenterAbsBound`给闭区间上abs(a)≤1；scale严格正沿用原构造。没有添加LEM、Circle Lift、RealNonzeroApartness、SingleOmega或选择参数，也不把这一事实写成相对于整个基础库的公理最小性结论。

每个除法由实际正分母构造逆元。`closedMotionContinuous`在Real×[0,1]上联合连续；`closedSquareMotionContinuous`明确限制到[0,1]×[0,1]。不是离散采样，也不是仅对固定t逐片检查。继承基础公设与固定工具配置见003。
