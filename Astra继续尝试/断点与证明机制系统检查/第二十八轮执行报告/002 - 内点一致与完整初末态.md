# 内点一致与完整初末态

C315的首要对应关系是所有原时间和开参数上的等式：

```
closedAgreesInterior t u :
  closedMotion t (openIntoClosed u) = motion t u
```

它由实际代数链得到：无界原参数乘gap回到center；stretch分母乘gap等于closingD；原stretch乘closingD等于closingN；闭B公式等于bend作用在同一个分数参数上。因此没有用另一条曲线恰好也连接端态，或仅把同名对象写成相等。

完整闭区间上的初末态也逐点核验：

```
closedInitialDiagram u : closedMotion 0 u = nCompletion u
closedFinalDiagram u   : closedMotion 1 u = pr1 (mCompletion u)
```

初态通过D(0,u)=1、N(0,u)=u及原bend/turn零时刻公式；末态通过D(1,u)=gap、N(1,u)=center、K与原homogeneous分母一致，再用显式反射后的turn公式给出原m全图。原n/m和原motion源码未修改。

两个边界参数closedZero、closedOne在末态都映到east，所以闭域末态函数非单射。另以C313和内点一致性，证明closedMotion在原开参数上的限制对每个时间仍单射。

这不是P与非P：两个单射命题的定义域不同。闭参数扩展中的0/1也不是原开区间成员；其末态图包含被删除点的边界值，不表示原去点圆内部又含有该点。还没有由“两端同像”推出“只有两端构成非平凡纤维”，后一完整分类是下一独立义务。
