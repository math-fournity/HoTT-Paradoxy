# 同一逆映射的真实闭参数延拓

本轮直接使用C-281的Real、RealCircle、east、OpenRealInterval及原度量，导入C-290的`strongCircleUnitHomeomorphism`。新增闭参数域另有名字`ClosedParameter`；原(0,1)定义和已核源码没有改动。

## 1. 固定公式与取逆资格

对实际实数u定义：

~~~text
v = (u+u)−1
d = 1−|v|
K = v²+d²
c(u) = ((v²−d²)/K, ((v+v)d)/K)
~~~

`completionPositive : (u : Real) → 0<K`具有实际证明项，并非额外输入。证明用构造性严格序的cotransitivity：从0<½取得“0<|v|”或“|v|<½”的截断析取。在第一支，v²正；第二支由|v|<½<1得到d正、d²正；加上另一非负平方得K正。两支消去的目标是命题，因此没有取出不合法数据，也没有增加全局LEM。

`homogeneousEquation`对一般a、b及K=a²+b²>0，利用实数代数证明归一化点在圆上。核心等式为`(a²−b²)²+((a+a)b)²=(a²+b²)²`，再用实际逆元消去分母。`completionCircle`据此对全部Real有定义，闭参数延拓是其限制。

“全部实数”只是此公式的定义域和正性量词；没有把圆环物理过程推广为所有实数时间。

## 2. 原metric连续性

`centerContinuous/gapContinuous/completionKContinuous`组合原实数加法、绝对值、乘法连续性；K的非零子类型映射接入C287已核的取逆连续性。两个坐标、原乘积度量以及圆的子空间度量依次装配。

`mCompletionContinuous`是闭参数原子空间度量到原圆度量的点态连续证明。没有重定义为拉回度量使其自动连续，也没有声称统一模数、可执行数值算法或环境同胚。

普通线段的对照同样具体：`nCompletion u=(pr1 u,0)`，使用同一闭参数域和原平面乘积度量，有独立连续性项。

## 3. 与原内点映射逐点相同

最重要的连接不是公式看起来相似，而是内核实际检查：

~~~text
mInterior : (u : OpenRealInterval) →
  mCompletion (openIntoClosed u)
  ＝ pr1 (PointwiseHomeomorphism.backward strongCircleUnitHomeomorphism u)
~~~

对每个原内点，d=1−|2u−1|严格正。`homogeneousMatchesParam`证明齐次公式等于旧立体投影逆参数式在`v/d`的值。旧C290的真实逆映射恰为先取v=2u−1，再取v/(1−|v|)，最后圆参数化；连接由实际项检查，不是注释中的约定。

该结果确保本轮没有换一个只在端点好看的新曲线来制造差别。C-291完整量词、源码、运行及禁止外推见唯一claim矩阵。

本报告的completion始终只表示“闭参数上的连续延拓”。本轮未证明Cauchy完备化、紧化泛性质、闭延拓唯一性或任意公式的等价分类；这些也不是当前端部消费者所需的前置。
