# 端部同像与内点单射的精确区别

C-292检查同一实际延拓的边界值、内点排除与单射性质。所有边界值由公式推出，源码没有为M/N另填“端点相同/不同”的布尔标签。

## 1. 两端究竟发生什么

~~~text
mCompletion(0) = east = (1,0)
mCompletion(1) = east = (1,0)
nCompletion(0) = (0,0)
nCompletion(1) = (1,0)
~~~

M端的证明分别计算center(0)=−1、center(1)=1，两处gap=0，平方为1，K=1，然后使用`homogeneousEast`推出圆子类型里的相等。N端是实际直线坐标，由0≠1得到`nEndsDistinct`。

这里有两个不同的**边界参数**，其M延拓像是同一个east。`closedEndpointsDistinct`与`mEndsCoincide`同时成立，属于函数不单射的正常形式；并没有构造两个不同的圆内点然后要求它们相等。

原开区间不包含这两个边界参数。对全部原内点，`interiorStrong`和`interiorNotEast`证明像满足原Strong并且不等于east。因而删去点没有被偷偷加进M的内点像。

用户“距离已经没有，却又没有靠在一起”的解释，不能直接当作本模型的形式定义。模型目前精确表达的是“两个边界参数的延拓像相同，而所有内点像都排除该点”。如果还要记录两个趋近方向、来源或禁止合并的操作，需要把这些额外要求写成明确结构/任务；当前证明没有替用户删除这项研究要求。

## 2. 开域单射与闭域非单射

源码同时提供：

~~~text
interiorInjective : (u v : OpenRealInterval) →
  mCompletion(openIntoClosed u) = mCompletion(openIntoClosed v) → u=v

completionNotInjective : ¬ ((u v : ClosedParameter) →
  mCompletion u = mCompletion v → u=v)
~~~

前者由`mInterior`回到C290真实逆映射，再用其逆律；后者用0与1这两个不同参数的同像证明。两个命题的定义域不同，没有得到同一个P及其否定。

这为后续核验提供具体区别：内在同胚可以作为裸载体的关系，而附带闭参数呈现和端部观察的对象还需要检查更多数据。本轮尚未完成该丰富结构的原生路径/等价判定，不能先把这句话提升为已经检查的no-lift定理。

## 3. 与原“复原”任务的距离

本轮获得有限的公式及证明项，且证明了数学连续性与端部性质。它没有给出来源保持的合法操作序列，没有实例化物理Step/Trace/Done，也没有证明“所有现实还原都不可能”。时间参数、环境移动、保端部变形、增加点、重新编码是哪些允许操作，需要依原任务分别固定。

本轮也不宣称重证了旧Lean连续曲线族F或其全部纤维分类。直接原生结果对应本轮同一函数；旧Lean结果保留独立模型及原范围。无条件原弱删点域Lift仍开放，不能把Strong内点覆盖说成已无条件覆盖所有弱删点定义的点。

因此本轮既不支持“完美击落HoTT”的结论，也不支持“已经替现实完成一切复原”的结论。它提供了可以继续审查的真实端部数据和完整的内点连接。
