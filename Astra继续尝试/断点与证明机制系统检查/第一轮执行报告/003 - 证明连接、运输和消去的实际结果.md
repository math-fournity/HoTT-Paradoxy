# 证明连接、运输和消去的实际结果

## 九个类型拒绝控制

每个控制有对应通过的正向源码。九个拒绝run的exit均为42，实际诊断均为 `UnequalTerms`；不是只有退出码符合预期。

| 控制文件 | 被拒绝的具体内容 | 正向对照 |
|---|---|---|
| MissingBridge.agda | 把c≡d接到a≡b后，而未提供b≡c | PathControls.compose/restore |
| OverlapMismatch.agda | 两个Partial面在重叠处给出true/false | LocalCoherence.compatibleFaces |
| MissingFace.agda | 用IsOne i1见证消费任意φ的Partial | fullFaceConsumer |
| GlueMismatch.agda | 局部true经not映为false，却给全局true | glueConsumer |
| HITMismatch.agda | 两个端点输出不同，却沿构造路径取常值 | joinedConsumer |
| TruncRecover.agda | squash边界要求两个原见证输出兼容，而条款未满足 | uniqueRecovery/unitRecovery |
| QuotRecover.agda | 对全关系商取原代表，缺少代表无关性 | lawfulObservation |
| MixedRecovery.agda | 加入ua运输之后仍无商兼容证明 | combinedPreservesDeclaredObservation |
| OpaqueRefl.agda | 将公设路径运输当作已定义性化简，用refl交付 | ClosedComputation.nativeClosed与显式β证书 |

这些观察没有支持“拼接或消去已在这些例子中漏检必要条件”。它们只覆盖这些声明、演算和版本；不据此证明所有核规则正确。

## 固定参照不是无关标签

`FixedFrame.agda` 先取 `Bare=ΣX:Type.X`，其中已包含选定点；然后使用 `Framed=ΣX.(X×(X≃Bool))`。额外部分是可被实际调用的参照等价。

`observe` 真正应用参照映射于点。内核接受裸表示的路径、固定参照两项的分离，以及同时运输点和参照后观察保持的证明项。该检查避免两个错误：把Bare说成“不含选点”，以及只给对象附上答案标签就宣称发现深层差异。

## 截断和商的恢复边界

`EliminationControls.agda` 的否定命题都带有“恢复每一个原见证/代表”的精确等式要求。它同时实现命题目标的合法恢复、Unit实例以及常值Bool输出。因此不能总结为“截断以后不允许返回任何Bool”或“商以后没有任何可计算消费者”。

## 原生计算和公设控制

`ClosedComputation.nativeClosed` 的原生ua闭项以refl通过；`OpaquePath`明确添加公设p与β，允许用β，但相应`OpaqueRefl`被拒绝。原生文件还给出这个公设合同的具体见证，避免使用已知不相容的额外公设制造假对照。

该实验只区分这几个项的命题证书与定义性计算，不证明一般不规范化、不可判定或永久不停机。

## 来源交叉检查

`UpstreamLoopHoldout.agda` 消费固定Cubical库中的`winding`、`intLoop`和`windingℤLoop`，以整数绕数比较一周路径与常路径，内核接受。它防止把C-251误读成“圆的一切路径都已相同”。

这是不同数学消费者的来源交叉检查；由同一AI选择并执行，**不是盲测、第二位研究者复核或跨证明器复现**。
