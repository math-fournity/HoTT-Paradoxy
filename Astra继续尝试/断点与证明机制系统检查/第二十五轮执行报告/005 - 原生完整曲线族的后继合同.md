# 原生完整曲线族的后继合同

选择`AST-U03-NATIVE-MOTION-01`，填补本次G04识别的具体缺口：在已核原生实数/平面/区间中，直接构造与原Lean公式对应的完整时间曲线族，验证其实际性质；不以NativeSourceContract的重呈现Run或一个静态末态图替代。

## 已读取的精确源

DeformationCircle.lean定义：squash(c,r)=r/(1+c|r|)；stretch把原区间的无界参数送入可变范围；bend(t,r)=(r/(1+(tr)²),tr²/(1+(tr)²))；turn是带平移的可逆线性坐标变换。deformation=turn∘bend∘stretch。EndpointClosure.lean又给出closingD/closingN/closingDen的同源闭参数公式。

一个必须处理的对应差异：Lean末态circleParameter的第二坐标写为−2r/(1+r²)，当前原生paramPoint写为正的对应表达。源码并不支持把两张参数图直接写成同一个函数。后继拟用固定第二坐标反射作对齐，但须实际证明它保持初始直线、目标点集以及所需参数/端部关系；该对齐目前是待证步骤。

## 不缩水的完整义务

1. 固定时间为原闭区间，曲线参数为原开区间；每个新分母的资格有证明，定义使用实际Real/RealPlane。
2. 原生公式及初末态与当前n/m参数化对接；强删点域和原Weak域分别定级，后者需要的原则不得隐去。
3. 联合连续、每个切片的嵌入性质均有相称证明；仅连续或单射不能冒充全部嵌入。
4. 同一公式的闭参数延拓、内点一致、端部相遇与完整纤维范围分别验证；不得把静态mCompletion当完整时间延拓。
5. 保留有界空间/固定端部/环境同胚/物理速度之间的差别。原Lean的60粗界不是物理定理；若原生只证明另一明确有限界，按其准确数字交付。
6. 回同任务审计说明该过程属于R-CURVE的哪些条件，为什么不能直接替R-AMBIENT或原广义来源任务；再决定是否真正补上四层连接。

可按依赖分阶段实现，但父单元在上述声明范围达到前不能只因端点或某个代数引理过核而称完成。先尽力保持原有构造前提；确需显式逻辑原则时固定理论变体和与经典Lean的关系，不偷偷加入全局公设，也不把有条件结果报告为无条件HoTT结果。
