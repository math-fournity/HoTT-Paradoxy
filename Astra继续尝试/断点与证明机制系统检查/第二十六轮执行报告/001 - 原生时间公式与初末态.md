# 原生时间公式与初末态

固定原`Real=ℝ₀`、`RealPlane=Real×Real`和C281以来的`OpenRealInterval=(0,1)`。时间先取全部Real，再限制到原`ClosedParameter=[0,1]`。没有改为离散时间、有限样本或抽象HIT圆。

令`r(u)=unsquash(fromUnit(u))`，即原开区间同胚给出的无界参数；设

```
c(t) = 1-t
a(t) = (t²+1)/2
b(t) = (1-t)/2
E(t,r) = 1 + c(t)² |r|
s(t,r) = a(t) r/E(t,r) + b(t)
B(t,r) = (r/(1+(tr)²), tr²/(1+(tr)²))
T(t,(x,y)) = ((1-t)x+2ty-t, -2tx+(1-t)y)
Fraw(t,u) = T(t,B(t,s(t,r(u))))
F(t,u) = reflectY(Fraw(t,u))
```

源码用带apartness证据的逆元而不是对零分母赋约定值。`stretchDenPositive`从平方、绝对值及其乘积非负直接给出`E>0`；bend分母复用原`positiveD`。这一阶段没有加入LEM、RealNonzeroApartness、Circle Lift或SingleOmega参数。继承库公设另见002，不能由“没有这些显式参数”推断最小公理独立性。

`motionContinuous`通过已有实际度量空间的加法、乘法、绝对值与非零逆元连续性组合，类型是`Real×OpenRealInterval→RealPlane`的联合点态连续性。随后`closedTimeMotionContinuous`沿时间子空间包含映射限制到`[0,1]×(0,1)`。

初末态证明采用实际代数路径，没有假定目标等式：`stretchZero`回到原u，`stretchOne`回到原r；`bendZero/turnZero`给初态；`reflectedBendTurn`用`Dq`、分配律和差运算给出末态。最后的接口逐点等于已有图：

```
initialOriginalDiagram u :
  closedTimeMotion closedZero u = nCompletion (openIntoClosed u)
finalOriginalDiagram u :
  closedTimeMotion closedOne u = pr1 (mCompletion (openIntoClosed u))
```

这里并未把m替成普通n，也未只做Rich结构重呈现。原Lean公式的末态y为负方向，原生m的y为正方向；本轮用固定`reflectY`对齐，证明其对合性、保持初始直线及`rawFinalOrientation`。参数u保持相同，没有以“点集像同名”代替函数图对应。

与Lean的比较是对所读具体有理公式的人工语义核对：乘法次序、`1+t²`与`t²+1`、除2与乘1/2按交换实数代数解释。当前交付的是原生系统内独立构造及原图等式，不声称已机器证明整个Lean/HoTT实数模型之间的保真翻译。
