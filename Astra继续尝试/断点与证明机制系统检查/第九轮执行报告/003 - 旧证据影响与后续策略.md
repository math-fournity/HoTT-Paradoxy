# 旧证据影响与后续策略

本轮改变的是特定证明环境的资格和实际几何模型入口，不改用户“四弹重做”的成功标准。整体仍须完成同一 X/任务、过程、对象、识别、必要前提与集成判词；只有各份代码检查成功不够。

## 1. C-05 的处置

旧 C-05 的 run `20260913-MP-UNIMATH-NOSECTION-REPLAY-02` 保留了导入 pushouts 和 erasing-equality 的日志。这使旧配置不能再被无条件描述成普通 HoTT 的可靠检查环境；旧 exit 0 仍是当时发生的运行事实，原件不改写。

新 `MP-ASTRA-NOSECTION-RESTRICTED-001` 用**完全相同的项目派生源码**在隔离副本重新检查，两次正式运行均 exit0。primary 为 `-02` / C-282。它只检验旧的无统一选点及 PointedOrientation 推论是否还成立；不是对全部库的一致性证明，也不把“统一选点”扩大为任何选点都不可能。

第一次成功运行 `-01` 复用 C-05，随后关系检查真实返回 `CLAIM_ID_REGISTERED_TWICE`。项目 registry 要求一个 claim 只能归属一个 package，且旧矩阵前缀冻结；因此为**变更配置后的重资格化陈述**分配 C-282，另作 `-02` 正式运行并冻结索引。C-282 不计作新发现的数学定理。旧源码、旧run、`-01`及失败核查输出均保留；当前资格原位进入旧registry包的 qualification 字段，新proof行连C-282，未改公共validator或伪造旧收据。最初`-01`的索引标记只是被保留的失败登记阶段，不是当前primary或有效完整关系认证。

`IMPORT-AUDIT.json` 的历史扫描只解释 external_dependencies 为对象数组的正式 manifests，并逐项列出未解释的其它形态。此分母中旧成功 run 为 C-05，另有其 include 根失败尝试及本次显式诊断。未登记为这种 manifest 的历史工具运行仍是未覆盖部分；不能说历史影响已经全库穷尽。

## 2. 八项反思

| 项 | 本轮判断、证据与改变条件 |
|---|---|
| 分母一致性 | 继续共同圆环/任务；895 模块只是本次导入闭包。发现更多实际消费者时扩大复核，不能换成证明库整体有问题即达成目标。 |
| 策略锚定 | versioned source mining 与 rule ablation，由实际实数导入触发，不是自由搜索一个可造假的 empty 项。 |

| 漂移 | 方案 v1.11 将配置风险、实际实数对象和短 Goal 原位写回；不在末尾用另一段“以此为准”盖旧状态。 |
| 工作姿态 | 不因看到 empty 就宣布 HoTT 被否证，也不因问题已有官方说明而忽略项目自己的证据缺口；用相同源码的消融和正常构造回到主线。 |

## 3. 搜索包络与下一选择

八轴：univalence/identity → 额外路径归约与消融 → 实数几何表达任务 → circle/interval 及旧 no-section 消费者 → 路径与 Bool 动作/类型检查 → 给定源码检查完成 → 固定原生 Agda → 原树和两文件差异的隔离树。

无无限枚举或开放世界完备性声称。本次 generator 是一个按机制构造的诊断与其同源码消融；reducer 没有把物理运动替换成 Bool 任务，Bool 只服务配置诊断。独立来源为 Agda 版本化文档；真实模型和旧证明是正控制。实现、公理与现实对应三层保持分开。

下一有界单元 `BP-GEO-NATIVE-PUNCTURE-APARTNESS-01`：先固定逻辑删点与正分离删点两个输入，检查当前库取逆所需分母证据，实际构造两者之间可证明的映射及正控制；随后用正确接口推进立体投影/连续性。出现额外逻辑原则时原样登记，不改掉用户 M 的定义来求通过。完整四层、GOLD 打包、其它证明断点机制、自然使用链和学术交付义务不删除。

最小替代是继续把 Lean 经典证明当原生结论；它不满足已接受的保真目标，因此本次资格化有直接必要性。环境问题关闭到当前两项消费者后返回几何主线，不把穷尽审计整个依赖库设为永久前置。
