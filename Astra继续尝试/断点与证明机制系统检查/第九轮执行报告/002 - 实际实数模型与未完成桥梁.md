# 实际实数模型与未完成桥梁

`NativeRealCircleQualification.agda` 使用隔离副本里的实际 Dedekind 实数、运算和度量。模型有明确的非空实例；没有用一个抽象 `Real : Type` 参数、Bool 或 HIT S¹ 名称代替整个实数点集。

## 1. 本轮精确规格

| 对象或项 | 实际定义/证明 | 范围 |
|---|---|---|
| `Real` | `ℝ lzero : UU (lsuc lzero)` | lower/upper cuts、非空、rounded、disjoint、located 的实际库结构 |
| `RealPlane` | `Real × Real` | 两实坐标，不是 Lean 的 EuclideanSpace 类型别名 |
| `realPlaneMetric` | 两份实数度量的乘积 | 有理邻域逐坐标合取；不是已经证明与 Lean 欧氏范数度量相同 |
| `RealCircle` | 平面中 `x*x + y*y = 1` 的度量子空间 | 实际方程定义，未证明与合成 HIT 圆等价 |
| `east/north` | `(1,0)` 与 `(0,1)`，分别给出圆方程证据 | 不从非空圆参数中假定它们 |
| `northNotEast` | 投影第一坐标到库的 `0 ≠ 1` | 精确点的不等式 |
| `PuncturedRealCircle` | `Σ p:RealCircle, ¬(p=east)` 的子空间 | 这里用逻辑否定；不能静默改成正的 apartness |
| `puncturedNorth` | north 及其排除 east 证据 | 去点圆的实际元素 |
| `OpenRealInterval` | `0 < x` 且 `x < 1` 的子空间 | 库 `le-ℝ` 是严格不等式 |
| `intervalHalf` | 实際有理嵌入 1/2 和两个序证明 | 区间的实际元素 |

上述源码草稿 attempt005 和正式全量输入重查 `20260920-MP-ASTRA-NATIVE-REAL-001-01` 均 exit 0；后者用时约208秒，源码和895模块库图保留。最终索引/关系复验以 DELIVERY.json 为准。

## 2. 公理和依赖边界

Agda 自身生成的 imports.dot 给出 895 个模块。`IMPORT-AUDIT.json` 记录每个来源/hash，属于**语法导入闭包上界**，不是提取证明项后的最小公理集。手工核对的公开 postulate 家族包括 univalence、function extensionality、truncations、replacement、circle、pushouts；Agda.Primitive 中另有宇宙/Level builtin 声明。

词法扫描还命中两个库文件里的三处 `{!!}`，原文均在 `{- ... -}` 注释内，不是这次被检查的未完成项。不能把关键词命中本身当作漏洞。相反，普通函数替换后的 erasing-equality 模块已不再声明该 primitive；原语所在文件改动有独立 hash。

本模型在较高宇宙中使用实数。入口没有假定 SingleOmega、LEM 或把所有命题压到同一较低层；但导入闭包另有上述公设，因此也不声称完成了“纯核心、无任何附加公理”的依赖最小化。上游的文档、原始 archive 和修改后的树身份不能混写。

## 3. 与 Lean、GOLD 的义务逐项对应

| 既有结果/输入 | 本轮接通 | 仍缺的真实义务 |
|---|---|---|
| Lean 实数去点圆同胚开区间 | 同形的方程圆、指定点、逻辑删点与开区间原生定义 | 实数表示、度量拓扑、映射、逆、连续性和宇宙接口的保真；不能把类型同名当翻译 |
| Lean 连续曲线族 F 及端点完成 | 当前有可容纳实坐标的实际对象 | 原生定义 F、参数、除法前提、连续性、单射、完成与精确纤维 |
| 原生整数边界观察 C278–279 | 本轮替补完整实数对象的基础入口 | 整数观察仍不是整个 F 或全实数模型的证明 |
| `CutRealLayer` | 已核对其 `DedekindReals ℓ : Type (ℓ-suc ℓ)`、截断 located/存在、SingleOmega 与 sufficiency 的声明 | Cubical 与 without-K 两套 rational/cut/Path 表示的翻译；未证明必要性 |
| `CutGoldForm` 的 √2 cut | 已核其 L/U 的精确公式、上下 cut 正性及实际依赖 | 把实际 L/U 和四条件打包到标准实数，接查询/近似/Pell任务；不能 import 名称就算连通 |

特别保留下一项真实风险：库的 `is-nonzero-ℝ` 以“负或正”的截断析取定义，取逆接口消费这个数据条件。逻辑上的 `¬(p=east)` 是否足以在当前构造逻辑下取得立体投影分母的正/远离零证据，尚未证明。不能沿用经典 Lean 中的反证步骤而不登记新增前提，也不能在证明前断言它做不到。下一单元要实际核这条义务及最强正控制。
