# 圆与原开区间的复合及作用域

本轮复合实际六字段同胚，得到固定圆/缺口与原N=(0,1)的内在几何连接。这里不是把Lean的Eq直接解释成HoTT结论，也不要求先建立整个Lean演算到HoTT的解释器：相关命题已在声明的原生HoTT模型直接证明。

## 1. 强域与原逻辑弱域分别保留

~~~text
strongCircleUnitHomeomorphism
  : PointwiseHomeomorphism strongMetric intervalMetric

weakCircleUnitHomeomorphism
  : Lift → PointwiseHomeomorphism puncturedCircleMetric intervalMetric

classicalWeakCircleUnitHomeomorphism
  : ExcludedMiddle0 → PointwiseHomeomorphism puncturedCircleMetric intervalMetric
~~~

Strong仍为先前声明的apartness域。原W仍为`p≠east`，没有改定义；其同胚结果在类型中显式携带Lift条件，LEM₀只作充分输入。未证明无条件Lift、其否定/独立性，也未证明“任何同胚都要求全局LEM”。

## 2. 原生类型路径也对齐实际复合函数

`homeomorphismEquiv`由六字段提取真实类型等价；univalence产生`strongIntervalTypePath : StrongPuncture ＝ OpenRealInterval`。`strongIntervalPathAction`对每个点证明该Path转回等价的作用，等于实际复合同胚的前向函数。原W域另有Lift条件下的Path。

这是底层类型的命题路径作用；给定metric的数据相等、判断归约、来源历史及允许过程均没有随之被证明。

## 3. 当前可以结束与不能结束的判断

可以结束“尚无实际原生圆/开区间模型和对应”的缺口：C-281至本轮已经提供实际模型、严格输入条件、互逆连续映射、强域及条件弱域版本、原生等价/Path作用。这个内在几何子命题无需再等待一个全语言翻译器。

不能结束原任务：同一个现实X的构造来源、环境嵌入、端部completion及Step/Trace/Done仍须具体化。以前Lean的曲线族F、环境不可达和闭参数完成并未自动成为本轮原生证明；若要以HoTT结论交付这些命题，仍需相应原生证明或相称保真翻译。

因此本轮是标准内在同胚的强正控制，不构成“所有允许方法都可复原”，也不构成HoTT内部矛盾。现实判词与数学证据等级继续分开。
