# 同一开区间的严格归属与连续互逆

本轮的目标N直接导入`NativeRealCircleQualification.OpenRealInterval`及`intervalMetric`，定义仍为实际Real中`0<u`且`u<1`的子空间。没有重建另一个名字相同的区间，也没有包含端点。

## 1. 有界化及逆映射

中间域`SignedInterval`精确为`Σ z:Real, |z|<1`，使用同一实数的子空间度量。

~~~text
s(t) = t / (1+|t|)
g(z) = z / (1−|z|)
~~~

实际构造内容包括：1+|t|严格正、其实际逆元为正；|s(t)|<1；由输入|z|<1得1−|z|严格正；两个逆向分母都有独立证据。没有按t的符号作排中律分支。

`unsquashSquash`与`squashUnsquash`分别证明g(s(t))=t和s(g(z))=z。关键中间式是`1−|s(t)|=(1+|t|)⁻¹`及`(1+|g(z)|)(1−|z|)=1`，均由实际实数代数推出。

绝对值short-map、上轮取逆连续性及现有加法/乘法组合给出两个实际函数的点态连续性，装配`realSignedHomeomorphism`。

## 2. 回到原先(0,1)

~~~text
a(z) = ½(1+z)
b(u) = (u+u)−1
~~~

`toUnitPositive`和`toUnitUpper`给出严格的0<a(z)<1。证明中还构造正量`½(1−z)`并核其与a(z)之和为1；端点不会靠弱化成≤被纳入。

反向从原u的两个严格输入条件证明b(u)<1及−b(u)<1，再取得|b(u)|<1。两个复合律恢复的是原子类型元素，证明分量由命题性处理。`signedUnitHomeomorphism`六字段都由实际函数及证明填充。

## 3. 全部实数到原N的合同

`realUnitHomeomorphism`组合上述两份真实同胚。因此其实际前向公式为`½(1+t/(1+|t|))`；逆向按b后g执行。代码提供严格归属、两复合律及原metric的双向点态连续性，而非只给一个函数表达式或若干采样点。

此实数↔开区间构造没有额外Lift/LEM输入；继承的no-erasure库配置和声明公设仍明确。没有声称双向一致连续、等距或物理过程。
