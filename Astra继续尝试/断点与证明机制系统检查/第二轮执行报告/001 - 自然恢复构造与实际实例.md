# 自然恢复构造与实际实例

本单元检查删点后加回指定点的自然映射，以及其逆向读出所需的条件。输入是同一个类型C、指定点p、删点包含映射；使用safe Cubical Agda，保存精确源码及实际运行。交付身份为内核接受和run验证事实；全局证据门禁仍PARTIAL，未升级为完整项目数学结论。

## 1. 三个主包、四项规格

C-261/C-262的[PointRestoration.agda](../../../HoTT/formal/astra-breakpoint-check/PointRestoration.agda)对任意宇宙层ℓ、C:Type ℓ、p:C定义：

```text
Puncture = Σ x:C, ¬(x≡p)
Completed = Puncture ⊎ Unit
extend (inl (x, absent)) = x
extend (inr tt) = p
SplitRestore = Σ decode:C→Completed, ∀x, extend(decode x)≡x
PointDecidable = ∀x:C, Dec(x≡p)
```

内核接受两个方向的函数：SplitRestore→PointDecidable及PointDecidable→SplitRestore。给定可判定输入时，还接受Completed与C之间的Iso和等价，正向函数就是extend。**实际实现不需要额外isSet C前提。** 两个逻辑方向不被写成证据类型之间已具有≃。

反向函数直接消费恢复函数的输出分支：若返回原删点元素，便有“不等于p”的见证；若返回新点分支，则利用右逆律得到“等于p”。这里没有把可判定性另加作未经使用的标签。

## 2. 有理坐标圆的实际实例

C-263的[RationalRestoration.agda](../../../HoTT/formal/astra-breakpoint-check/RationalRestoration.agda)复用首轮方程x²+y²=1的QCircle与east=(1,0)。它由库中的有理数可判定相等、Σ结构及命题纤维构造pointDecision，没有postulate所需决策。

实际检查项包括：自然恢复等价；删点包含映射保持；新点映到原east；north恢复控制；原生ua给出的类型路径及其运输与extend的逐点路径相等。正向和逆向都依赖同一原对象，不是用同名C另造目标。

## 3. HIT圆的分层反向控制

C-264的[HomotopyRestorationControl.agda](../../../HoTT/formal/astra-breakpoint-check/HomotopyRestorationControl.agda)在完全相同的内部路径排除定义下，用首轮circleExclusion及整数绕数见证检查noHomotopySplit与noPointDecision。其反证路线是：假设有SplitRestore，便得到S¹收缩结构，再与已检查的非平凡路径控制相冲突。

这些相反结果涉及不同类型与不同相等语义，不构成同一个数学命题同时真与假，也不证明现实圆环的两种表示互相矛盾。

## 4. 本轮改变了什么

首轮只有删点后的元素和条件端部关系；本轮首次把删点包含、指定点和自然恢复接成可运行的双向结构，并把逆向分类的必要输入显式化。它不是重复Bool模型，也不是只给base一个别名。

这缩小了后续未知：必须进一步判断当前恢复表示的拓扑与动作许可，而不是继续泛称“加回一个点在理论上不能表达”。但实际M/N的完整拓扑与操作任务尚未因此完成。
