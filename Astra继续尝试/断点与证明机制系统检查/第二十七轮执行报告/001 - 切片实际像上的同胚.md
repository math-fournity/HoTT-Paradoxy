# 切片实际像上的同胚

沿用C311/C312的`motion t`，没有改动原函数、原实数、原开区间或初末态。所用像是库的`im-Metric-Space intervalMetric realPlaneMetric (motion t)`：成员是平面点及命题截断的原像存在性，度量由原平面子空间继承。

目标不是裸集合双射，而是以下完整记录，正向映射被固定为原函数的像分解：

```
motionSliceHomeomorphism : (t : Real) →
  PointwiseHomeomorphism intervalMetric (curveImageMetric t)
forward = map-unit-im (motion t)
backward = recoverInterval t
forwardContinuous = motionSliceContinuous t
backwardContinuous = recoverIntervalContinuous t
forwardBackward = recoverIntervalRight t
backwardForward = recoverIntervalLeft t
```

记录包含正反两个方向的连续性与两个逆律。因此不能把证明解释为“换一个任意双射”或“只检查单射”。单射另由`motionSliceInjective`作为推论给出；`closedTimeSliceHomeomorphism`把所有实时间的结果限制到原闭时间区间。

逆函数按原公式逐层处理：先反射第二坐标，再应用turn的仿射逆；在bend正分母坐标图中恢复stretch输出；反解正比例缩放/平移，再反解带绝对值的有理压缩；最后用原实数到开区间的连续映射返回原u。`recoverRealOnCurve`和`recoverIntervalLeft`直接对原输入检查复合。

每个时间t的像可以不同；没有假定全时刻像是同一个预定子集，也没有携带原闭参数端点的额外固定条件。该结果给的是原R-CURVE模型中的切片嵌入性质，不能因此推出原R-AMBIENT合同下的全平面同胚过程。
