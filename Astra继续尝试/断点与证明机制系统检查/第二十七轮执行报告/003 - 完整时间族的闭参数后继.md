# 完整时间族的闭参数后继

父`AST-U03-NATIVE-MOTION-01`保持第二十五轮005的完整范围。本轮处理了每片拓扑嵌入，下一必须回同一个F的闭参数扩展，不重开已核的裸同胚/静态图或改成Rich重呈现。

待证公式取原EndpointClosure的同源表达，按本轮原生符号写为：

```
a(u) = center u
D(t,u) = gap u + remaining(t)² * abs(a(u))
N(t,u) = scale(t)*a(u) + offset(t)*D(t,u)
K(t,u) = D(t,u)² + (t*N(t,u))²
Bclosed(t,u) = (N*D/K, t*N²/K)
Fclosed(t,u) = reflectY(turn(t,Bclosed(t,u)))
```

这些在本片只是后继设计，不是本轮新增已证命题。下一先在原`[0,1]×[0,1]`证明K的正分母资格，再证明内点与当前motion相等、联合连续及初末态。之后处理端部在t<1的分离、t=1的相遇与完整纤维，保留具体空间界。优先尝试原构造前提，不因经典Lean用了按t=1分情形，就无说明地加入全局排中律。

同任务归因仍须遵守：原开参数上的连续嵌入族、保全闭端部标记的环境同胚有限过程、物理制造过程是不同合同。本轮只消除原生F的切片性质缺口；它不证明后两种过程存在，也不把数学函数的存在当作现实执行记录。

八项反思：分母和原函数不变；来源与S策略锚定为同任务的跨框架差分；由原生核检查而非AI裁定数学真值；无失败不外推全理论；新的重要消费点为实际像的子空间度量和截断消去资格；core未变；策略只把已核嵌入改为当前进展，不降低完整要求；下一回闭参数/界，避免熟悉的算术或表示例子循环。

八轴cell：原生实数/命题像×反解有理坐标而非擦除×圆环连续变形×原motion切片×平面子空间度量×双向连续和逆律×native kernel×固定without-K配置。直接全称构造不涉及有限候选穷举/fairness；原Lean源码提供独立框架对照，但不是盲测或全模型保真。当前遗漏包括全闭参数与纤维、空间界、广义原操作与理论错误承诺。发现新的域/前提差异须重评，不得仅增加案例数。
