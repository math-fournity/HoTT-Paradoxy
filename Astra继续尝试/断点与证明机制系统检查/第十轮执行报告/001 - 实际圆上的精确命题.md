# 实际圆上的精确命题

理论配置沿用第九轮：Agda 2.8.0、without-K、固定 agda-unimath 两文件 no-erasure 变体及其声明公设。这里的实数、乘法和圆方程都是实际库对象。`↔` 表示两个方向的逻辑蕴含，不冒充 `≃` 或宇宙中的路径。

## 1. 输入与量词

`C = RealCircle` 是 `{(x,y):ℝ₀×ℝ₀ | x²+y²=1}`，`e = east = (1,0)`；`p` 始终量化于这个相同的 C。

~~~text
W(p) = ¬(p=e)
A(p) = apart-ℝ (xCoord p) 1
d(p) = 1 - xCoord p
I(p) = Σ r:ℝ₀, d(p)*r=1
~~~

库的 apartness 是严格次序两方向的**截断析取**；它不是直接交给程序一个任意精度的有理数界或运行时间保证。`W(p)` 活在较高宇宙，`A(p)` 为低层命题；本轮使用跨层蕴含，不偷设 SingleOmega。

逆元的定义 I(p) 对候选 r 不预设 apartness。这样“存在逆元→A(p)”是任意逆元的必要条件，而不只是对某个库函数参数的复述。

## 2. 实际圆方程参与的关键一步

`firstCoordinateOneIsEast` 从 `xCoord p = 1` 推出 `p=e`。证明先把圆方程改写成 `1+y²=1`，用实际实数加法消去取得 `y²=0`，再调用实数平方零的引理得到 `y=0`，最后用子类型的命题性恢复圆中点的等式。

因此这是作用于实际圆的推导，不是把“不是缺口”定义成想要的答案标签。

## 3. 逻辑删点与统一提升

源码给出以下明确函数：

~~~text
A(p) → W(p)
W(p) ↔ ¬¬A(p)
Lift = ∀p:C, W(p) → A(p)
LocalStability = ∀p:C, ¬¬A(p) → A(p)
Lift ↔ LocalStability
~~~

另定义 `SamePointRefinement`：给每个原逻辑去点圆元素 w 一个 StrongPuncture 元素 s，**同时证明 s 的圆中点等于 w 的圆中点**。其与 Lift 的双向蕴含也在同一模块中。不能任意把输入点换成 north 后声称已恢复原点所需的信息。

## 4. 逆元的必要与充分条件

`strongToRawInverse` 使用实际 nonzero-real 逆元构造；`rawInverseToStrong` 从任意 r 的 `d(p)*r=1` 推得 d(p) 非零，再由差的 apartness 反推出 A(p)。两边真实组成：

~~~text
A(p) ↔ I(p)
UniformInverse = ∀w:PuncturedRealCircle, I(pr1 w)
UniformInverse ↔ LocalStability
~~~

这里的 UniformInverse 是一个给所有逻辑删点输入产生逆元的函数；不是对每个点分别在元语言中说“也许存在”。**必要性只精确到本地 A 族的双重否定稳定性**；没有证明它等价于所有命题的排中律或任何 resizing 原理。

当前无条件构造了上述蕴含函数；没有无条件构造 Lift/LocalStability 本身，也没有构造其否定或独立性模型。这一开放项不能从“代码尚未写出来”升级为数学不可能。
