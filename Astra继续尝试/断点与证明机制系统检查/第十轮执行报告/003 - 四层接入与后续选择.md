# 四层接入与后续选择

本轮推进四弹 redo 中的“同一个实际模型、同一个点、同一个逆元任务”的输入保真。它完成局部蕴含/条件定位，不把完整redo改成这些局部命题的验收。

## 1. 已接通与仍开放

| 父义务 | 本轮改变 | 保持开放 |
|---|---|---|
| 实际圆模型 | 用同一 C/e 的圆方程取得决定性坐标引理 | 与 Lean 完整实数表示/拓扑的保真翻译 |
| 同任务输入 | 同点 refinement 明确携带点相等证据 | Lift/LocalStability 的无条件成立、否定或独立性 |
| 真实消费者 | 前向立体投影坐标消费实际逆元，且任意逆元反推 A | 反向参数化、复合律、连续性及区间接口 |
| 最强反解释 | 显式 LEM 足够；不存在已证完全缺逆元的弱删点见证 | 这不证明用户全部允许操作或物理过程可完成 |
| 第四层归因 | 必要性精确到此 A 族局部稳定性 | 未证明 LEM/resizing/SingleOmega 必要，也未连通 GOLD/旧算术层 |

## 2. 八项反思

1. 分母仍是同一实际 C/e；W 未换成 A。若 later consumer 需要别的条件，另列不混同。
2. 来源为实际库的 inverse/nonzero/apartness 消费链与前轮未决接口；对应 source mining 和 typed consumer synthesis。
3. 全部具体项交给原生 Agda；新模块不写待证结论公设；继承库公设和 no-erasure 变体边界照旧披露。
4. 未声称 LocalStability 不可证。三个通过草稿不是无穷模型扫描，更不是全 HoTT 无缺陷证明。
5. 新信号是任意逆元都能反推 A，移除了“只是某API人为要求”的弱点；同包保留缺逆元见证的否定作为反向控制。
6. core 未变；新的精确信息要求改方案后继，不能继续用“还未表达实际圆”描述当前态。
7. v1.12 原位维护当前后继与限定；未完成的无条件提升问题继续可见，不挪出父范围。
8. 从基础条件检查返回真实几何映射。没有因熟悉双重否定而转去泛泛证明更多逻辑引理，也不把额外前提自动当目标缺陷。

## 3. 包络与后继

八轴：实际Dedekind/Σ/否定 → 逻辑删点到apartness → 同一个圆点的取逆任务 → 库的inverse及任意逆元消费者 → 点/坐标/逆元方程 → 统一函数及同点保持 → 固定Agda实际检查 → 已固定no-erasure公理式HoTT。

本轮无枚举文法，无有限采样替代全称；量词由源码承担。独立反向检查是从任意r的乘法方程反推出A，正控制为north和显式LEM输入。语义未约化为Bool。未触达的时间连续性、其它高阶证明断点、全库误用与物理对应仍开放。

下一有界单元：`BP-GEO-NATIVE-STEREOGRAPHIC-01`，构造实数参数到这个圆的实际有理参数化，给出apartness和两个复合律，再连接点态连续性与开区间。弱删点域通过当前精确Lift条件保持为单独义务；强域结果不得冒充原弱域无条件结果。遇到可构造Lift或独立性证据时重新裁决该义务；同一任务无条件闭合前不关GEO04。

原Goal的四层集成、GOLD标准打包与查询/近似/Pell连接、必要性、自然使用链、其它断点机制和公开证据交付仍保留。先完成具体映射，比继续堆叠与这个任务无关的否定例更能减少关键未知。
