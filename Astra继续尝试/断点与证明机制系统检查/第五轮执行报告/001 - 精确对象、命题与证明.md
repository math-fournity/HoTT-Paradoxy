# 精确对象、命题与证明

研究对象为`Plane = EuclideanSpace ℝ (Fin 2)`中的实际子集，不是有限点集、纯参数标签或原生HIT圆。以下结果在固定经典Lean/mathlib中实际过核；共同源码为[AmbientCircle.lean](../../../HoTT/formal/astra-real-geometry/AmbientCircle.lean)，唯一claim索引为[CLAIM_EVIDENCE_MATRIX](../../../HoTT/CLAIM_EVIDENCE_MATRIX.md)。

## 1. 对象和观察量

- `circleOpen`：单位圆子类型中不等于指定`pole=(1,0)`的点，经自然包含进入平面的像，即M。
- `lineOpen`：`lineEmbed t=(t,0)`对`0<t<1`的像，即N。
- 观察量：`closure S ∖ S`，即在**这个指定平面中**闭包多出的点。

这个差集不等于平面拓扑边界`frontier S`；不能把定理命名中的`missing_boundary`误读为计算全部拓扑边界。也不能说M本身含两个重合实体端点；形式对象中缺点不属于M。

## 2. C-266：内在对应及不同的闭包余集

实际命题：

~~~text
closure circleOpen ∖ circleOpen = {pole}
closure lineOpen ∖ lineOpen = {lineEmbed 0, lineEmbed 1}
lineEmbed 0 ≠ lineEmbed 1
embeddedIntrinsicHomeomorph : ↥circleOpen ≃ₜ ↥lineOpen
~~~

圆的证明先在球面子类型中证明指定点不是开点，再由补集稠密和闭嵌入得到平面闭包等于完整单位圆。线段的证明使用`lineEmbed`的等距闭嵌入以及`closure (Ioo 0 1)=Icc 0 1`。同胚通过C-265的具体构造和两个实际像子空间之间的对应组成；并未将同胚作为公设。

## 3. C-267：内在同胚不能扩张成整平面同胚

实际命题：

~~~text
¬ ∃ h : Plane ≃ₜ Plane, h '' circleOpen = lineOpen
¬ ∃ h : Plane ≃ₜ Plane, h '' lineOpen = circleOpen
~~~

若这样的h存在，连续双逆及单射性使`closure S ∖ S`的像等于像集的对应余集。代入C-266，单点集的像必须等于含两个不同端点的集合，因此推出这两个端点相等，与`line_endpoints_distinct`矛盾。反向利用h的逆。

这里的“不存在”有完整量词范围：**所有该固定平面的自同胚**。它不是抽样负结果，也不需要枚举平面函数。但它没有量化所有只定义在曲线上的变形。

## 4. C-268：有限操作模型

`runAmbient`的输入是一份有限列表，每个元素都是`Plane ≃ₜ Plane`；一步将当前子集替换为该同胚的像。归纳证明任何有限列表的结果仍是某个整平面同胚的像，再应用C-267，得到：

~~~text
∀ hs : List (Plane ≃ₜ Plane), runAmbient hs lineOpen ≠ circleOpen
~~~

正控制`one_step_positive_control`确认单步确实执行取像，空列表和复合在同一归纳中处理。这个模型有明确数学操作语义；它没有宣称所有物理操作、切割、加点或无限极限均属于该列表。

## 5. 对原论证的含义

精确支持：若“能由N变成M”要求每步保持整个平面的拓扑结构，则所指定N不能变成M；这是对用户环境差异认识的一项实物支持。

精确限制：内在`↥M ≃ₜ ↥N`与环境`∃h : Plane ≃ₜ Plane, h '' N=M`是不同形式命题。两者的相反判定不能拼为同一P与¬P。传统点集拓扑本身已经表达并核验了本轮差异；是否有HoTT的真实使用者错误地把前者当后者，需要额外的具体使用证据和保真连接，当前未给出。
