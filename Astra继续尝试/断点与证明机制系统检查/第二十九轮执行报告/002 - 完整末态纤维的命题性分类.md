# 完整末态纤维的命题性分类

C317对全部原闭参数u,v给出双向关系：

```
closedMotion 1 u = closedMotion 1 v
  ↔ (u=v) ∨ ((u=0) ∧ (v=1)) ∨ ((u=1) ∧ (v=0))
```

源码关系为`FullFiberRelation`，析取和合取都在Prop中，未返回任意实数相等的Bool/Dec或可自由提取的输出标签。该关系先对原mCompletion证明，再由完整末态图等式接到原closedMotion；两边 implication 都有代码。

证明链分为四步：

1. 实际m图的删点分母为`2*gap²/K`。若某闭参数的像具有Strong资格，就能从该分母的apartness导出gap>0，从而把同一个参数纳入原开区间。
2. 原开参数单射性因此提升为“内点的纤维在整个闭参数域中唯一”，覆盖内点与边界的交叉比较。
3. 若u<v且二者同像，则假设u>0会使u成为内点并产生矛盾，所以u=0；同理v=1。反序情形给另一顺序的端点对。
4. 以`abs(u-v)`的located分支收尾：正差距给apartness从而给端点对；差距<1时，任何apartness都会迫成差距=1而矛盾，所以参数相等。所有分支的目标都是命题，不假定实数可判等。

这补上了上一轮明确未证的“是否只有端点对形成非平凡纤维”，没有将两个端点的一个见证冒充完整分类。它分类的是原映射的同像参数关系，不额外断言对任意Weak圆点有原像，也不提供对外部实数输入的有效相等判定器。
