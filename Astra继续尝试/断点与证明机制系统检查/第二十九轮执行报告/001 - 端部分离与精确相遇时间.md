# 端部分离与精确相遇时间

C316保持第二十八轮同一closedMotion、原Real和ClosedParameter，证明：

```
closedEndpointsDistinctBefore : (t : Real) → t < 1 →
  ¬ (closedMotion t closedZero = closedMotion t closedOne)

endpointMeetingTime : (t : ClosedParameter) →
  (closedMotion (pr1 t) closedZero = closedMotion (pr1 t) closedOne)
  ↔ (t = closedOne)
```

证明并非采样：先用固定反射与turn的显式左逆，把假定的端部同像传回closedBase；由于t<1时两端closingD正，再用bend坐标图逆传回两个分数参数相等。两端分母都等于(1−t)²；两个分子分别是−scale+offset*D和scale+offset*D。消去正分母与公共平移后会得到−scale=scale，与原scale严格正相冲突。

在原闭时间域中，端部同像排除t<1；结合t≤1和实数序紧性，得到t=1。反向使用已核的末态端点等式。因此不需要为任意t返回一个“t<1或t=1”的可判定标签。

“所有t<1不同”与“t=1相同”条件不同，不构成P与非P。这是原数学时间模型中的边界值事实，没有声称两个原开区间成员在某时被合并，也没有证明物理材料、速度或实际制造过程。
