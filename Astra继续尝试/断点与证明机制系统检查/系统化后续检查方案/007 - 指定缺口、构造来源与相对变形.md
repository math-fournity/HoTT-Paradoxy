# 指定缺口、构造来源与相对变形

本片完整回应用户新增的“缺口属于M的结构、固定两端仍可变形、某些形状只能由特定构造产生”的想法，修订检查方案而不追认HoTT缺陷。用户原文在[对话第007片](<../对话原文/007 - 归档交付与指定缺口的新问题.md>)及[独立原文消息027](../原始消息/027-user.txt)，保留“同坯”等原始用字。本片是AI讨论与候选设计，不是原文或新机器定理。

## 1. 本次新增了什么实质内容

此前只说M来自删点，容易被简化成来源标签。此次进一步提出：哪些部位须固定、哪些部位可动、缺失点与两侧关系必须保留，以及允许的生成方法会限制可达对象。应把这些内容变成可检查结构，而不是仅给对象加一个origin_id。

因此需要更新方案，增加一条具体的`BP-GEO-01`候选及C13/C14。它保留原来的六机制横向路线；不会把所有检查重新锁定到一个圆环图形上。

## 2. “缺失点属于M”需要区分成员与结构

若底层点集定义为`M₀ = C \ {p}`，p就不是M₀的成员。这是该定义的含义；不能又把p作为同一底层集合的成员输入来取得矛盾。

但可以把用户这句话理解为：**p的缺失、缺失发生的位置及两侧如何关联，是完整研究对象不可删除的结构。** 候选对象可记录：

```text
M* = (底层M₀、环境空间E、原圈C、指定缺失点p、嵌入j、端部关联、允许操作ℴ)
```

这是待细化的建模方案，不是本轮已建立的类型或定理。p不必在M₀内，仍可在环境/标记结构中被记录；这保留用户意图而不制造成员关系冲突。

同样，“两个端点”须明确：去点圆/开区间中的两端、另行加入的边界点、还是环境中的极限位置。不能把不存在于底层的两个端点当作已给变量；也不能因底层无端点就丢弃用户所要求的两侧关系。

## 3. 一个更具体、但尚未证明的表示候选

可尝试用开区间上的嵌入γ及其在闭区间上的连续延拓γ̄记录M：内部点给出残余形状；两端的延拓值都指向指定缺失点p；内部像不含p。这里的0、1是参数域/补充边界中的两个标记，不是M₀内的两个残留端点。

普通直线段呈现N也要先固定其环境嵌入与两端的关联。不能把一个带全部环境数据的M*同完全没有指定数据的裸N比较，然后从资料不对称直接断言所有N构造不可能。

此建模产生可检候选：端部是否关联到同一指定位置、嵌入/闭包关系、缺口标记和允许变形是否保持。它们可能在某类变形下构成不变量；**本轮没有证明这些不变量或任何不可达定理。**

## 4. 三种关系不能合并

| 关系 | 要求 | 本轮需要检查 |
|---|---|---|
| 抽象同胚H | 底层拓扑空间的对应 | 当前M₀/N₀比较实际是哪项同胚 |
| 保结构的关系E | 指定缺口、环境/端部等结构的对应 | 底层对应能否提升到该结构 |
| 构造可达Reachℴ | 用允许操作从指定初态产生目标 | 操作域、输入、完成与不变量 |

Reach通常有方向性，不能未经论证称为另一种等价关系。若研究双向可达，应明确两方向和所需性质。用户的“只能由这类方法创造”需要先固定ℴ，再证明对其全部合法过程的限制；不能把“不可能的其他方法”直接排除在Allowed定义里，以同义反复制造结论。

“删点”作为一种方法能得到M，与“任何其它方法都不能得到同一完整对象”是两个强度不同的主张。后者目前是CONJECTURE，需要排查参数化、重嵌入、保结构运输等合法替代，并说明这些操作算不算用户要求的创造。

## 5. 与已有数学概念的对照

保持指定部分不动并非传统数学全未考虑的维度。Hatcher《Algebraic Topology》第0章第3页定义homotopy rel A：在指定子空间上的限制随时间不变。[原文](https://pi.math.cornell.edu/~hatcher/AT/ATch0.pdf)

UCR的同位扩张讲义区分嵌入的同位与环境同位，并讨论固定边界的变形。它们把环境和保持条件显式放入问题。[讲义](https://math.ucr.edu/~res/math260s10/isotopyextension.pdf)

这些来源说明需要同已有概念比较，不能直接宣布“传统拓扑不知道这些差异”。但它们也不自动解决用户的完整构造来源要求。究竟是已有相对/嵌入结构、额外的过程语义，还是新的组合，须经逐项保真对照；新颖性保持OPEN。

## 6. 两个新增检查模板

**BP-C13：指定缺口及端部关系的保真。** 输入为M*和具可比较数据的N*。分别检查忘却到裸空间前后的关系；寻找候选不变量及对应。正控制：同一个完整对象的重参数化且结构一并运输。错误控制：只给底层同胚却请求完整结构等同。探索控制：实际HoTT表示是否静默漏掉该字段，或者合法重建了它。

**BP-C14：构造方法与相对变形的可达性。** 先固定一小类ℴ，例如明确保持标记的嵌入变形；把删除、加点、重参数化、重新指定环境等操作分别登记许可条件。寻找不可达不变量，同时尝试最强允许恢复。正结果可为可达、受限不可达或OPEN；不预设只能删除法成功。

有限grammar只支持其分母内结论。要说“所有合法变形/任何其它构造”都不行，需要对精确类别的全称证明，不能由有限探针或直觉完成。

## 7. 何时能形成对HoTT的挑战

若仅得到“裸空间同胚，但某种相对变形不可达”，应先作为关系/表示边界交付，不能自动判HoTT规则错误。

若找到某个HoTT定义或实际使用，在任务需要缺口/端部/生成约束时只保留裸类型，又把其等价解释成完整可互换性，则可形成具体的命题忠实性或使用失配候选。还须核对是否有合法保结构表示、是否需要原任务没有的数据以及该使用是否真的发生。

若要进一步指控核心规则，须定位精确允许的推导与同一命题上的冲突；如果忠实保结构编码能满足任务，就要承认这条候选可以修复或被反驳。“理论创造者、使用者会不会陷入”目前是条件性的风险问题，不能由新名称或一个图形推定实际群体错误。

## 8. 更新裁决

采纳为检查方案的新结构化候选；不采纳为“已经证明N不能构造M”“已创立新拓扑学”或“HoTT已被击落”。U00/U01起点不变；U02明确纳入C13/C14并同U03等机制互相反馈。新对象模型和相应数学证明尚未执行。

## 9. ZCode 7cb 成果接入后的精确检查（2026-09-20）

该会话四个Flash入口已独立重放，命题忠实性审查见[报告002](<../../ZCode-7cb会话成果吸收审查/002 - 四个形式模块的重放与命题忠实性.md>)。复用其排除Σ、配对、投影、恒等函数和`f p refl`控制；这些不替代C13/C14中的实际模型。

- 来源恢复：显式定义Rich/Bare/Forget、输入中是否已有p及恢复要保留的观察。若要证明无法恢复，目标须确实是恢复任务；`∀x:C, x≠p`连x=p也包含，不用它代替“忘却p后不可恢复”。
- 成员与函数族：`FamilyCarrier`是接收已有排除证据的函数族；实际cut成员应接入真实L/U及必要序结构。`F x x≢p`不能被报告成不需要输入证据的提取。
- 实际使用者：固定agda-unimath的Dedekind定义/截断析取，以及当前点集模型的实际使用入口，检查其数据与任务要求。检索分母、参数、返回码与未触达接口单列；关键词无命中不作全库否定。
- 判断顺序：先有实际模型与必要条件，再查忘却/等价/恢复是否改变该任务；参数化控制通过不构成几何降优先级的理由。若正恢复成功，撤回相应不可恢复候选。
