# 语义路线与删点表示保真

当前实物入口：首轮PathComplement与QCircle分层已执行；第二轮[自然恢复报告](<../第二轮执行报告/001 - 自然恢复构造与实际实例.md>)将原包含、指定点、右逆与可判定条件连接起来。Completed仍未赋予拓扑，不能把其类型等价当成拓扑和或同胚。实数几何与原动作保真继续按本片及第007片执行。

## 1. 四种对象分别定义

点集拓扑空间及其底层集合（包括需另行保留的环境嵌入、指定缺口与端部关联）；原生Identity/Path与高阶路径的同伦类型；具体证明项/上下文/推导树；参考任务的输入/动作/观察/完成要求。四者间的“删一点”不能无证明互换，几何类比只用于生成候选。

## 2. BP-M01：删点与表示转换

令D为参考侧删点，F为表示转换，D'为HoTT侧候选操作。待检两条路线：

```text
X --D--> D(X) --F--> F(D(X))
X --F--> F(X) --D'--> D'(F(X))
```

尚未定义F/D/D'，不预断它们交换或不交换。先固定类型、指定点参数、结果比较关系及观察。没有合法D'时报告表示资格缺口，不能任意写个类型就称为所需删除。

第一对照使用点集底层set的相等删点；第二对照检查原生同伦类型中的候选表达`Σ x:A, ¬(x=a)`。后者字面排除Identity/Path，不预称点集删一点；差异需原生证明及模型对应。**不以“HIT S¹去掉base就是开区间”为前提。**

v1.2执行义务：以固定Cubical库的`isConnectedS¹`为候选依据，尝试构造`(Σ x:S¹, (x ≡ base → ⊥)) → ⊥`，命名为“内部路径排除”。同时运行集合层非空删点正控制；有限Bool仅校准删除语法，不冒充实数圆。几何支线优先给出非平凡环/域上的单位圆点集实例，并显式登记其到实数拓扑圆的剩余义务。不得从内部路径排除为空推出HoTT不存在任何删点表示。

正控制：同一语义侧的重命名/同构及对应指定点保持操作。候选控制：先忘结构再删点，和保结构删点再忘却。仅有不保观察时归类表示边界；实际推理承诺保持却失配时，再审核那项承诺。

## 3. 观察量保持开放

候选观察包括居住性、路径可连通性、圈/高阶结构、边界关系、局部兼容、见证可恢复性、计算行为、原任务完成。每单元在看结果前选定观察，不事后挑指标制造命中。

保留无需来源历史也能检查机制的分支，也保留历史确实必要的分支。原圈C、删点M、同胚呈现N、另一个无来源N各有角色，不能靠同名混用。

新候选BP-GEO-01见[第007片](<007 - 指定缺口、构造来源与相对变形.md>)：将缺失点与两侧关系作为完整对象的结构，区分底层成员、标记边界和环境极限位置。C13检查关系保真，C14检查在明确操作类下的构造可达性；不能把“不允许N产生M”写进规则后再宣称已证明不可能。

## 4. 最小表示合同

| 字段 | 当前实例须固定 |
|---|---|
| theory | exact calculus、universes、公理、相等层 |
| source/target | 对象与表示；保留/忘却哪些结构 |
| δ | 缺失条件与下游需求 |
| transformation | 真实删除/忘却/等价/消去项或规则 |
| consumer | 实际消费转换结果的推理或程序 |
| observation/completion | 比较什么、何时完成；不拿checker结束当对象运行完成 |
| correspondence | 输入、输出、上下文和观察的保持义务 |
| alternative | 最强保任务恢复/反解释 |

只补当前实例必要字段，不造全现实总模型，不把所有未来语境压成单一R。新观察不能容纳时按005未知入口扩展。

## 5. 模型资格化与回退
