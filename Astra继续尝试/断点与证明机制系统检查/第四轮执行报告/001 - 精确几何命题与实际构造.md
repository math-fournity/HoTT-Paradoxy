# 精确几何命题与实际构造

源文件：[PuncturedCircle.lean](../../../HoTT/formal/astra-real-geometry/PuncturedCircle.lean)；唯一数学索引：[C-265](../../../HoTT/CLAIM_EVIDENCE_MATRIX.md)。本轮使用经典Lean实数及点集拓扑，尚未提供到Cubical Agda的保真翻译。

## 1. 对象及量词

~~~text
Plane = EuclideanSpace ℝ (Fin 2)
Circle = {v : Plane | dist v 0 = 1}
Punctured p = {x : Circle | x ≠ p}
Interval = {t : ℝ | 0 < t ∧ t < 1}
puncturedCircleHomeomorph : (p : Circle) → Punctured p ≃ₜ Interval
~~~

圆是实际二维实数EuclideanSpace中的单位球面；不是HIT `S¹`，也不是有理坐标圆。拓扑由库的范数空间、子空间和顺序拓扑给出。p作为删去的指定点在输入中显式保留；这一步没有声称“忘掉p之后也能恢复p”。

`pole`取第0坐标为1的标准单位向量，并证明它属于圆；`actualMToN`是该具体实例。非空控制因此不依赖一个可能没有实例的圆参数。

## 2. 实际组合

1. `stereographic' 1 p`提供圆上排除p的开放部分同胚；把其source/target等式转成真实子空间同胚。
2. 一维EuclideanSpace经连续线性等价和单坐标求值对应ℝ。
3. 库的`orderIsoIooNegOneOne`把ℝ对应到(-1,1)；仿射函数`x/2+1/2`把该区间对应到(0,1)。子空间的界限由实际有序域证明给出。
4. 三段组成`puncturedCircleHomeomorph`，继而检查具体实例的满射、逆向往返及两向连续性。

代码不只声明某个Homeomorph类型存在；其值由已固定库接口具体装配。实际检查包括：`every_interval_point_has_circle_preimage`、`exact_inverse_roundtrip`、`forward_continuous`、`inverse_continuous`。

## 3. 这改变了哪一项状态

原方案要求M/N的内在同胚不能只引用直觉或历史AI答复。本轮为该要求给出真实实数模型的机器证据。它也为后续更丰富结构比较提供共同底层；随后不能把“没有基础模型”当作永久理由。

但本结果只对应H关系。R关系、允许过程Reach、端部固定及现实任务Done尚未因此得到同一性或分离定理。源码含`noncomputable`与标准经典选择依赖；这说明构造所采用的形式环境，不单凭该标记断言“任何有效算法不存在”。
