# 求逆同点提升与条件同胚

C308把相互推导接到明确输出任务。全部实数仍限于已固定ℝ₀，圈和开区间仍是原模型。

| 条件/类型 | 同RealNonzeroApartness的关系 |
|---|---|
| 原Circle Lift | C307双向函数 |
| ∀r,¬¬apart(r,0)→apart(r,0) | 双向函数 |
| ∀r,¬(r=0)→Σu:Real,r·u=1 | 双向函数，u没有事先额外限制 |
| 对原Weak输入统一返回同一个点的Strong表示 | 双向函数，保持原点 |
| 对每个原Weak输入统一返回原分母的实数右逆 | 双向函数 |
| 原弱去点圆与原(0,1)的PointwiseHomeomorphism | 已证给定原则时的充分方向 |

统一求逆的反向使用“存在任意右逆则apart于0”的实际库定理，不是因为输出类型先偷偷要求apartness。保持点的refinement还单独有refinementPreservesPoint=refl。

WeakLiftConsumer接已有真实连续映射/逆映射、两侧逆律及原度量连续性；通过原生univalence取得类型路径，并核其作用就是实际同胚的前向映射。提供原则这一输入在函数签名中保留，没有由“代码过核”把它消除。

## 必要性准确止于哪里

必要性已经针对表中同点提升和指定分母/实数求逆合同给出。没有证明“任何可能的弱圆同胚都必须给出这项原则”，也没有证明原物理变形、固定端部或来源任务等价于这些求逆合同。

LEM₀是显式充分输入；本轮没有证明它必要。原则本身是否无条件成立、其独立性/反模型，以及同二进制Markov原则的完整关系仍未闭合。已有noMissingInverseWitness保持有效：这不是找到一个Weak点并证明该点所有逆元都不存在。

因此可交付的是指定任务的原则强度刻画和有条件几何恢复，不能将其改名为HoTT自我否定、所有恢复不可能或四弹已经收官。
