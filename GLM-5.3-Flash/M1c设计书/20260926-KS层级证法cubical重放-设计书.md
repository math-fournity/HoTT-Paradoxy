## 0. 两个被推翻的自设门槛（先修正）

## 1. KS 的层级簿记（【来源】，已逐字核对）

| 构件 | 定义 | 所居宇宙 |
|---|---|---|
| 𝒰^{≤n} | `Σ (X : 𝒰ₙ), is-n-type X` | 𝒰ₙ₊₁（定义类型，非原始宇宙） |
| Pₙ | `λ X → Ω^{n+1}(𝒰ₙ^{≤n}, X)`（点对） | 族：𝒰ₙ^{≤n} → 𝒰∙ₙ₊₁ |
| **Loopₙ** | `Σ (x : 𝒰ₙ^{≤n}), π₁ (Pₙ x)` | **𝒰ₙ₊₁** |
| Loop₋₁ | 𝟐 | 𝒰₀ |

关键引理链：5.5（𝒰^{≤n} 是 (n+1)-截断）→ 5.6（Pₙ 是集合族）→ 5.7（Loopₙ₋₁ 是 n-截断，得 hₙ）→ 5.8（Ω^{n+1}(𝒰ₙ, Loopₙ₋₁) 有**非平凡**元素；归纳基 n=0 用 𝟐 上的 swap）→ 5.9（𝒰ₙ 若是 n-型则该 Ω 为命题，矛盾）。

归纳步的机制（5.8 的核心，【来源】）：local-global 把 𝒰ₙ₊₁ 的一个 (m+2)-环变成 Loopₘ 上的族；Loopₘ 的点**自带** Ω-数据（它是 Σ（基点，环路）），故 ξ := λ(X,q).(q, d_q) 现成；非平凡性由 IH 的单个点 ((Loopₙ₋₂,h), q̃) 见证——**归纳假设只在单点使用，从不需要下层宇宙的全局结构**。

## 2. n=1 实例的 cubical 翻译（【设计】）

目标：`¬ isOfHLevel 3 (Type ℓ₁)`（𝒰₁ 非群胚；book 编号"1-型"）。n=0 实例即 C-63（已在库）。

构件（ℓ₀ 任意，ℓ₁ = lsuc ℓ₀）：
- `U0le0 := Σ (X : Type ℓ₀), isSet X`（𝒰₀^{≤0}: Type ℓ₁）——即库中的 hSet 结构。
- `Loop0 := Σ (x : U0le0), (x ≡ x)`（Type ℓ₁）。
- 基础非平凡环：q̃ := ua notEquiv（𝟐 ≡ 𝟐 in Type ℓ₀），经 Σ≡Prop 提升为 `p₀ := ((𝟐, isSet𝟐), (q̃, isProp-path)) : Loop0`。
- 主引理（需 HIT-free 重证）：`LG : Ω²(Type ℓ₁, Loop0) ≃ Π• ((X,q) : Loop0), Ω¹(Loop0, (X,q))`——C-75 的 localGlobal 已机器但同文件导入 EM，**不得导入**（会污染 HIT-free 边界）；按论文 §5.2 的证明链重写：univalence → ≃-Σ 展开 → 引理 5.1（prop 分量中和 Ω）→ Ω-Π• 交换（4.7）。
- ξ 族：`λ (X,q) → (q, d_q)`——把点自带的 q 还为其 Ω¹(Loop0,(X,q))-环路（Σ 的 Ω-分解，引理 4.5 实例）。
- 非平凡性：ξ 在 p₀ 处的分量定义性读回 q̃；若 `isOfHLevel 3 (Type ℓ₁)` 则 Ω²(𝒰₁,Loop0) 是命题 ⟹ ξ = refl 族 ⟹ 分量 = refl ⟹ q̃ = refl，与 C-63 式的 swap ≠ refl 矛盾。

## 3. 风险清单（为何这是"天级"而非"小时级"）

1. **定义性等式迁移**：论文的证明链依赖判断性 η（Σ）与 Ω/Σ•/Π• 的定义性交换律；cubical 里这些是命题性或需显式 PathP 操作——ξ 分量"定义性读回 q̃"一步可能需要 C01 式的呈现工程（那一次用了三次尝试）。
2. **点对（pointed）机器**：cubical 库的 `Cubical.Foundations.Pointed`（C-75 已用过 Ω^≃∙）提供 Ω/Π∙/Σ∙；引理 4.5/4.7/5.1 需按实例重证或查库等价物。
3. **提升税**：Agda 无宇宙累积，跨层处显式 lift，且 lift 的定义性计算要核对。
4. **HIT-free 边界**：全部导入限定 Prelude/Pointed/Equiv/Univalence/HLevels/Bool/Σ——不得触 EM/S¹/截断 HIT。
