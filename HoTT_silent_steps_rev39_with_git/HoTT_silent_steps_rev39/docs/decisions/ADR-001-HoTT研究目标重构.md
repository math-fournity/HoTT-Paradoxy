# ADR-001：HoTT–Z 研究目标从“推翻/45 包完成”重构为审计级基线

日期：2026-08-31
状态：`ACCEPTED_FOR_CURRENT_WORK`
来源：用户允许“完成工作包整体目标，或者更好的新目标”；详细证据见 `../../HoTT/`。

## 背景

交接包把来源整理、一般表示论、HoTT 无选点、资源逻辑、计算理论、极限、宇宙/Gödel、三篇论文、
哲学稿和发布工作拆成 45 个包。机械依赖完整，但 37 个包被统一标记 `COMPLETE_INTERNAL`，且多个
验收需要当时不存在的机器、文献或外部证据。原始“HoTT 缺时间/被推翻”目标也不被可保留证明支持。

## 决定

当前本地目标改为六个成果面：来源谱系、主张纠错、窄数学核心、可复现构建、原创性边界和外部
发表门。前五项完成并有直接证据后，本地目标完成；第六项保持 `OPEN_EXTERNAL`，不能由同一 AI
自我关闭。45 包只保留为历史计划证据，不建立第二套包管理系统。

当前允许的数学主线是指定忘却映射下的表示损失、无免费富化、二元素族无统一选点，以及明确
reduct 的方向/来源反例。禁止把它表述为 HoTT 内部不一致或绝对不能编码动态。

## 后果

- 优点：结论与证据等级对齐；构建可重放；未来 AI 有唯一 current owner；不再用文档数量替代成果。
- 代价：三篇论文和“最终判决”标题降为历史/候选；若要发表，必须先获得真正新定理和外部证据。
- 非决定：本 ADR 不裁定 HoTT 的哲学优劣，也不禁止未来单独研究 linear、guarded、Gödel 或 Zeno。

## 重审条件

出现以下任一项时可重审：一个不能退化为一般集合因子化/二元素 swap 的新 HoTT 定理；完整
closest-work 比对支持原创性；第二独立 univalent 实现；或独立专家报告指出当前边界有实质错误。
