# 对 Astra 二审的五个不接受点

## 1. 「计分分类混乱」——接受批评本身，保留分类实质

Astra 二审 004 §6 指出我第一次报告的计分表内部不一致（索引说「4 全盘接受
（A02/A04/A08/A09）」、正文另列 A07「接受（降格）」、计分行又混入「收回自判」）。
**指认属实**—— taxonomy 缺陷，本报告已改用逐项状态表（001 片）。但保留分类
实质：A04 的「接受」从一开始就分两截（事实接受 + 修复列为 R2 义务），一审
报告 002 片的处置栏写明「改名标注（本轮在矩阵登记）；标准样例列为义务」——
不是完成后冒充完成。真正的完成状态误报只有一处（A07，见 N2），已认账并修复。

## 2. 「叙事层」表述的再检讨——接受证据、修正结论强度

二审 004 §2 用矩阵 L706/L740/L876/L865 四行证明强读法**在登记层**就有，不是
只在会话里。本作者核验：四行确实存在且带强表述。修正本作者一审报告 003 片的
「滑动集中在叙事层」为更准确的表述：**登记层同时含有精确局部类型/保守标签
与待证解释/未支持元论证——分层存在，但层内并非每行纯净。**这正是二审的
贡献：它没有推翻分层，它细化了层内质量。矩阵 owner 行的 11 处修正就是按此
标准逐行做的。

## 3. A01「费用定理」读法——部分接受、部分保留

二审 004 §1 反驳我「拒绝的是任何无付费桥」的答法：现有 M3-L1 没有**收费
参数**、没有**验证过的支付后恢复分支**，所以不是「免费时失效、付费后恢复」
的费用定理。**指认属实**——M3-L1 只是分离定理，费用定理是更强的形态
（something like `¬(A ≃ B)` + `P → (A ≃ B)` 的组合）。保留的部分：分离定理
封锁无付费桥的**读法本身没错**（等价不存在 ⇒ 一切桥都不存在，无论付费与否
——严格说 M3-L1 连付费桥都拒绝了，因为它拒绝一切等价）。所以精确的说法是：
M3-L1 比费用定理更强（拒绝一切）也更弱（不给出付费后的恢复）——它是分离
定理，不是费用定理；「理论使用被拒识别」的归因义务（A01 本体）在分离定理
之上独立存在，维持 OPEN。

## 4. 策略规模辩护——接受限定、拒绝撤销

二审 006 §2 辩称九分片/十单元是「用户要求完整策略」的产物、
`CANDIDATE_NOT_CURRENT` 附着在新策略上不是对旧定理的降格。本作者核查其
策略索引 L20-24 与 001 片 §4——**属实**，本作者一审报告 004 片对该状态的
读法过重，修正。但「小时级/日级/月级」估算的实质保留：估算依据是本轮实际
执行（verifier v3 含五控制回归约一小时；矩阵 11 处原位编辑约一小时；
M1-05+TA-LEM-03/04 重收据含编译约二十分钟）——这不是「没有相应执行估算
证据」，是一审时点未附执行记录。二审说「不采纳为承诺」——同意不作为承诺，
但作为已完成动作的实测记录成立。
