## 1. 证据门禁

- **规则**：当前 AI 把一个命题作为数学结论交付之前，必须在语义匹配的证明器内核上实际运行，并留下完整证据。源码进 `HoTT/formal/`；运行原件进 `HoTT/verification/runs/<run-id>/`，必需文件是 `RUN.json`、`stdout.txt`、`stderr.txt`、`environment.txt`、`source-manifest.json`；唯一的快速索引是 `HoTT/CLAIM_EVIDENCE_MATRIX.md`。完整规范：`docs/quality/数学结论机器证明与证据留存规范.md`；根 `AGENTS.md` 的 `MATH_PROOF_BEFORE_DELIVERY_V1`（`rulings.md` 第 15 条）。
- **不能冒充的**：普通 Python 枚举、Lean 的相等（它满足 UIP）不能冒充原生 HoTT 证明；有限测试不能冒充全称定理；超时不是不停机；文件存在、Git 提交、另一个 AI 的赞同，都只证明各自的范围。
- **规模**（快照）：365 个运行目录（2026-09-12 至 09-30）；共享主张矩阵到 C-356；Claude 线另有 CG001-C-01 至 C-80，目标内索引在 `.claude/goals/CG-001-targeted-overview/证据索引.md`，给共享矩阵的行草稿（relay R1，96 行）尚未登记。

## 4. 证据身份词汇

| 标记 | 含义 |
|---|---|
| 【用户原话】 | 逐字引用研究发起人，出处是 `核心认知.md` 的 KC 编号 |
| 【用户判定】 | 研究发起人对研究结果的判定，逐字；它不是数学定理 |
| 【数学事实】或“机器证明” | 由证明器内核检查通过、有运行收据的形式命题，只在所写的范围内成立 |
| 【元层推论】 | 从已证命题加上定义做的简单推理，没有单独机器化 |
| 【来源转述】 | 论文或他人文件里的说法，本仓库没有重新运行 |
| 【解释】【判断】 | AI 的解释或评价 |
| 【建议】 | AI 的设计建议 |
| 【猜想】【开放问题】 | 没有证明的命题；文献里还没有答案的数学问题 |

常见的状态词：`FORMAL_CHECKED_WITH_SCOPE`（有范围的形式核验）；`CLOSED_WITH_SCOPE`（在明确范围内完成）；`DEFENSE_WORKS`（HoTT 在这里正确地挡住了越级）；`REPRESENTATION_BOUNDARY`（换一种表示就能完成，边界在表示）；`STRONG_CANDIDATE`（强候选，还缺判据）；`QUALIFIED_HIT`（合格命中）；`NO_HIT_WITHIN_SCOPE`（范围内没有命中，不等于不存在）。

## 5. 怎样反驳本仓库的结论

下面每一条都是明确的撤回或降级条件；审计意见请交研究发起人（仓库 `math-fournity/HoTT-Paradoxy`）。

**芝诺幽灵**（社区稿 01 第 8、10 节）

- 在书式 HoTT 里给出半单纯类型的统一定义：强形式撤回。
- 指出 `Coh₂`、`Coh₃` 不是标准的六边形与 P₄ 相干，或两个半球没有恰好划分 P₄ 的 14 个面：相应的形式事实重做（M1 至 M3）。
- 论证现实里的“相同”本来就是结构而不是落定的事实：现实侧前提动摇，由研究发起人裁定（P1）。

**罗素幽灵**（社区稿 02 第 10、12 节）

- 指出附录 A 的逐字命题与故事里的句子说的不是一件事（量词、宇宙层级、截断指标的偏移）：形式层重做（M1）。
- 论证解释桥不忠实，或“存在不要求落定”：成功主张失去前提，由研究发起人裁定（P1、P2）。
- 在不用高阶归纳类型的书式 HoTT 中，给出单个宇宙在某一层落定的相容性证明：改变“高阶归纳类型必要”的来源级判断（M5）。
- 指出 `HoTT/formal/claude-cg001/questioning-delay/QuestioningDelay.agda` 里的程序与社区稿 02 第 3.1 节的过程 Q 不是一回事（判定器的形状、从第几问开始、输出的含义）：CG001-C-77 至 C-80 的读法重做。

**任何一条**：只要找到一个运行的收据与源码对不上，相应命题就降级。
