## 1. 罗素线与 UR：本来一句话的事，在 HoTT 的宇宙里永远了结不了

（A 向为主；B 向读法留在修复一侧。）

**一句话**【解释，AI；“不合理”的判定属于研究发起人】：两个东西是不是同一个，本来是一句话的事。HoTT 为了省事，规定同构的就是同一个（单价性）；又为了普适，让任意高维的形状在宇宙里一次齐备（高阶归纳类型）。于是在它的宇宙里，“是同一个”永远了结不了：一层层追问“这份相同到哪一层了结”，每一层都确定地答“还没有”，每一层之上还有一层。这和芝诺的形状一样：每走一步都确定地还没到（只借这组关系，不是说二者在形式上等价）。

研究发起人的定义与判断：【用户原话，KC-000054，节选】「本来应该很简单的事情，甚至在X理论中，都做不到」「其实看了你捕捉到的HoTT的内容，我已经闻到了这种`不合理`的味道。」

**短链**：

1. **取舍**：单价性让同构即相同，“相同”从此是数据，不再是一次检查就落定的事实；高阶归纳类型让任意高维的形状一次齐备；宇宙由形成规则一次交出，单价性从一开始就在它上面运转。
2. **过程**：把“确认是不是同一个”落实为程序 Q，逐层问“这份目录里的相同，到第 k 层了结了没有”（技术上：它是不是 h-层 k+1 的类型）。每一问由判定器交出带证明的“是”或“否”；答“是”就停，并报出层数。程序停下，当且仅当在某个有限层了结，而且有精确的停机时刻（CG001-C-77）。
3. **观察**（同一个程序，每次只改一处）：

| 情形 | 结局 | 命题 |
|---|---|---|
| 相同是事实（按同一组方程转写到 Lean） | 宇宙第 1 问停 | CG001-C-80 |
| HoTT，ℕ、Bool | 第 1 问停 | CG001-C-79 |
| HoTT，h-层 1+n 的类型的目录 | 恰好第 1+n 问停 | CG001-C-79 |
| HoTT，同一乘积、成员高度封顶 b | 恰好第 2+b 问停 | CG001-C-82 |
| HoTT，不是宇宙的乘积 ∏ₙ K(ℤ,n+1)（HoTT Book 例 8.8.6） | 对任何判定器都等于 `never` | CG001-C-81 |
| HoTT（含高阶归纳类型），宇宙 | 对任何判定器都等于 `never` | CG001-C-75、CG001-C-78 |
| HoTT，集合截断 | 第 1 问停；但截断把 Bool 与自己相同的两种方式合成了一种，而且解码不回宇宙 | CG001-C-83 |

   三级阶梯与一般 n 的总体上升另见 CG001-C-71 至 C-76。不用高阶归纳类型时，落不定的是宇宙塔：Kraus–Sattler 定理 5.9、5.10 对一切 n 在本仓库机器重放，并有名称级的“无高阶归纳类型”证书。

4. **反解释检查**：
   - “追问方式天生停不下来”：同一个程序对 ℕ、Bool 第 1 问停，对封顶的目录在封顶处停；停下恰好等于“在某个有限层了结”（CG001-C-77）。
   - “全是宇宙的问题”：换成不是宇宙的乘积，照样永不停（CG001-C-81），所以宇宙不是必要条件；封顶的乘积同样是一次交出的，却停了（CG001-C-82），所以 Π 的一次交出不是充分条件。
   - “有限证明就是回答”：有限证明交出的，是“了结的那一层不存在”的证书。程序化之后，这是两个完成标准不同的程序：问“有没有一层了结”的程序第 0 步就答“没有”，问“在哪一层了结”的程序永远交不出（CG001-C-78）。【解释】按 UR，那件本来简单的事是后者：确认是不是同一个，要确认到底。
   - “换题”（最强）：对集合截断发问，第 1 问就停（CG001-C-83）。回应：截断回答的是“有几个分支”，它把“相同”的多种方式合成了一种，而且回不到宇宙，被问的对象已经换了。这像用极限回答芝诺：一条定义把“走到了”宣布回来，被改掉的条件本身并没有恢复。这一回应是解读，交社区审计（社区稿 03 的第 4 问）。

**数学事实新不新**：大多不新。这类乘积没有有限层，是 HoTT Book 的例 8.8.6；宇宙本身，书里（2013）写的是预计可以证明它不是任何 n-型、但尚未做出（§8.8 末尾）；Kraus–Sattler 2015 证明了单价宇宙层级里的第 n 个宇宙不是 n-型（不用高阶归纳类型）；含高阶归纳类型的单个宇宙在本仓库有机器证明（CG001-C-75），此后文献里有没有公开证明待查（调研请求 Q0）。新的主要是读法，以及它指向的前提。研究发起人要的本来就是【用户原话，KC-000015，节选】「它在HoTT中也存在具体的现象、表现」，新颖性不是判据。

**两向分工**：书式 HoTT 里的现象按 A 向为主：现实里一问就了结，理论里永远了结不了（KC-000052）。B 向读法，即 KC-000050、KC-000051 的存在性追问（理论把尚未落定的宇宙一次交出、当作已经交付），留在修复一侧：截断、只在集合层工作、2LTT 的外层，都是凭定义把“相同是事实”宣布回来。在 B 向读法下，解释桥与现实侧前提“存在要求落定”仍未逐字裁定（终局判词第 1 节与社区稿 02 第 11 节按 09-27 的判定作了解读）；A 向读法不需要这道门。

**最强反方**：

- “换题”：见上面的反解释检查。
- “相同本来就该是结构”【来源转述】：在高阶规范对称里，结构式的相同被认为更贴近物理（芝诺线的同一反方）。【判断】这是对 UR 前半句“本来应该很简单”的否定，由研究发起人与社区审计判断（社区稿 03 的第 2 问）。
- “存在不等于落定”（只针对 B 向读法）：宇宙由它分类类型族的能力完整刻画，逐层追问只是对一个已存在对象的无穷描述。
- “拒付有代价”：ZF 把一切集合的总体拒为真类，从此不能对它做数学；HoTT 授信，换来可运算的宇宙和单价性。【判断】这是成本收益论证，它确认了归因（授信正是经济收益所在），不否认现象本身。

**归因**（KC-000049：正题，待与研究发起人讨论；全文见收尾报告第 4 节、社区稿 02 第 9 节与 03 的“这说明什么”）：

- 候选前提：单价性（同构即相同，收益是经济）；高阶归纳类型（任意高维一次齐备，收益是普适）；Π 的一次交出；宇宙是被追问的对象；解释桥；现实侧前提“相同是一次检查的事实”。
- 区分证据：相同换成事实，就停（CG001-C-80，粗粒度：Lean 换掉的是整个“相同是结构”，不只单价性一项）；高度封顶，就停（CG001-C-82）；换成普通乘积，仍然永不停，所以宇宙不是必要条件（CG001-C-81）；封顶的乘积也是一次交出，却停了，所以 Π 的一次交出不是充分条件。
- 判断【判断，有条件：条件于研究发起人对“那件简单的事”的认定】：首先审单价性，其次是高阶归纳类型。同样高维的形状在经典数学里也有（这个乘积的同伦群每一维都是 ℤ，来源级），变的是“相同”指什么。反证法只否定合取的整体，所以这是排序，不是唯一的被告。

## 2. A7 无穷相干：一条独立的芝诺式候选（不是 09-27 判定所指）

**一句话**【解释，AI】：HoTT 为了让“同构的东西可以当成同一个”（单价性），把“相同”从一次检查就落定的事实，改成了可以一层层追问“以什么方式相同”的结构。于是半单纯结构这样一个在“相同是事实”的世界里一行就写完的定义，在 HoTT 里每补一级“对得上”的要求，就长出下一级；每个固定层都写得出，对层数统一的内部定义至今写不出。这和芝诺的形状一样：每一步都走得动，每一步都还剩一段（只借用这组关系，不是说二者在形式上等价）。

**短链**：

1. **取舍**：单价性让同构即相同；代价是“相同”变成数据。例如 Bool 与自己“相同”有两个真的不同的证明，沿第二个搬运 `true` 得到 `false`（CG001-C-63，HoTT Book 例 3.1.9）。
2. **过程**：写下半单纯结构，即用点、线、三角形、四面体一层层粘出形状，要求“面的面”对得上。经典数学里这是一行定义。
3. **观察**：
   - 在“相同是事实”的世界（Lean 4）里，这一行就是完整定义，六边形相干由 `rfl` 成立（CG001-C-65）；
   - 在 HoTT（Cubical Agda）里，同一行定义接受对不上的数据：两条化简路线在圆周上一条绕 1 圈、一条绕 2 圈（CG001-C-64）；
   - 补上六边形之后补法不唯一，再下一级（P₄）对其中一种补法不成立（CG001-C-66、CG001-C-68）；
   - 要补几级由“相同”有几层决定：各层是集合时补一级，是群胚时补两级（CG001-C-70）；
   - 每个固定层都写得出（机器检查到第 5 层，CG001-C-62）；对层数 n 统一的内部定义是公开难题。
4. **反解释检查**：
   - “普通类型论也有”：不带 K 的类型论可以一致地加上 K，让一切类型都成为集合，后退就停了；HoTT 加不了，因为单价性推出宇宙不是集合，连集合的宇宙也不是（CG001-C-63、CG001-C-71）。
   - “改用集合就行”：那是换了任务。经典数学以严格定律完成的，是值为同伦类型的半单纯空间，不是半单纯集合。

**证据走到哪一级**：

| 台阶 | 状态 |
|---|---|
| 形式事实 | 已到。上述各条由内核检查通过，各有负控制；16 个运行在 Linux 重放，与 macOS 原收据一致（`FORMAL_CHECKED_WITH_SCOPE / CROSS_PLATFORM_REPLAYED`） |
| 从事实到“做不完” | 统一定义的不可能性是开放问题，没有被证明；“各层是 t 层时补到第 t+1 级”的一般形式是元层论证，没有机器化 |
| 研究发起人的判定 | 用户 2026-10-01 澄清：09-27 总判定中的芝诺幽灵指圆环悖论与仓库后续讨论、分析，不是 A7。因此该总判定没有替 A7 的两个问题作肯定回答（现实里“相同”是否落定为事实；“每层做得到、缺统一方法”算不算无法完成）；两项仍开放。A7 是否升为“条件式合格命中”不能由 AI 自证 |
| 社区审计、外部复核、Terra | 都还没有发生；给 Terra 的回信 019、补充信 020 待研究发起人转交 |

**最强反方与撤回条件**：

- “只是还没有人想出来”：这是最大的风险，也是明确的撤回条件。书式 HoTT 里一旦出现半单纯类型的统一定义（包括把 Herbelin–Ramachandra 2026 第 6 节的展望实现出来），强形式立刻撤回。
- “物理上，结构式的相同更贴近现实”【来源转述】：在高阶规范对称里，弱 2-群被认为更贴近物理，实践中常改用严格 2-群。【判断】所以“现实里的相同终究落定为事实”在这个领域并不自明；不过实践里截断后退的办法，正是在定律一层加回事实式的相同，这与本线的归因同向，但不替研究发起人作答。

**归因**（KC-000049：正题，待与研究发起人讨论；全文见社区稿 01 第 7 节）：

- 候选前提：A 单价性；B 内涵相等；C 一切类型都是“纤维的”，没有事实式的层；D 内层自然数没有和外层（事实式的）自然数绑定；E 统一性要求；以及现实侧前提“面的面对得上是一次落定的事实”。
- 竞争归因与区分证据：B 是普通类型论也有的，但 HoTT 的特殊之处是 A 关掉了“加 K”这条退路；按截断层数的对照把病因定位到“相同的层数”；已知的修复都要加回事实式的相同，还要绑定自然数（去掉 C 与 D）。
- 判断【判断，有条件】：起作用的是 A 与 C 合在一起，即理论内部只有结构式的相同，而且在宇宙上层数没有上限；已知修复还要 D。条件是开放问题保持开放，或得到否定的回答。

## 3. 两条线的共同点

【解释，AI】A7 候选与罗素线可以从单价性等共同前提出发作比较；旧研究记录曾把二者称作同一条线的两面，这是 AI 的研究组织方式，不是用户 2026-09-27 总判定的含义。用户后来明确说，芝诺幽灵指圆环悖论及本仓库对此的后续讨论、分析。数学证据、用户判定和 AI 解释必须分开。

## 4. 不宣称

- HoTT 不一致。HoTT 有模型，全部机器证明也没有推出任何矛盾。
- “很可能已经找到”是数学定理。它是研究发起人的判断。
- 数学事实是新的。大多不新，见第 1 节“数学事实新不新”。
- 半单纯类型在书式 HoTT 中不可定义。这是开放问题。
- “永不停”对现实中的运行已经无条件成立。内核检查的是理论内部的定理（CG001-C-78、CG001-C-81）；读到现实运行上，还要以所用理论一致为前提，对任意判定器另需典范性。
- “对截断发问换了题”已被证明。这是解读，交社区审计。
- B 向读法下解释桥与“存在要求落定”的哲学正当性已经成立。它们交社区审计。
