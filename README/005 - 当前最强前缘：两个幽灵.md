## 1. 芝诺幽灵（A 向：现实里做得完，理论里做不完）

**一句话**【解释，AI】：HoTT 为了让“同构的东西可以当成同一个”（单价性），把“相同”从一次检查就落定的事实，改成了可以一层层追问“以什么方式相同”的结构。于是半单纯结构这样一个在“相同是事实”的世界里一行就写完的定义，在 HoTT 里每补一级“对得上”的要求，就长出下一级；每个固定层都写得出，对层数统一的内部定义至今写不出。这和芝诺的形状一样：每一步都走得动，每一步都还剩一段（只借用这组关系，不是说二者在形式上等价）。

**短链**：

1. **取舍**：单价性让同构即相同；代价是“相同”变成数据。例如 Bool 与自己“相同”有两个真的不同的证明，沿第二个搬运 `true` 得到 `false`（CG001-C-63，HoTT Book 例 3.1.9）。
2. **过程**：写下半单纯结构，即用点、线、三角形、四面体一层层粘出形状，要求“面的面”对得上。经典数学里这是一行定义。
3. **观察**：
   - 在“相同是事实”的世界（Lean 4）里，这一行就是完整定义，六边形相干由 `rfl` 成立（CG001-C-65）；
   - 在 HoTT（Cubical Agda）里，同一行定义接受对不上的数据：两条化简路线在圆周上一条绕 1 圈、一条绕 2 圈（CG001-C-64）；
   - 补上六边形之后补法不唯一，再下一级（P₄）对其中一种补法不成立（CG001-C-66、CG001-C-68）；
   - 要补几级由“相同”有几层决定：各层是集合时补一级，是群胚时补两级（CG001-C-70）；
   - 每个固定层都写得出（机器检查到第 5 层，CG001-C-62）；对层数 n 统一的内部定义是公开难题。
4. **反解释检查**：
   - “普通类型论也有”：不带 K 的类型论可以一致地加上 K，让一切类型都成为集合，后退就停了；HoTT 加不了，因为单价性推出宇宙不是集合，连集合的宇宙也不是（CG001-C-63、CG001-C-71）。
   - “改用集合就行”：那是换了任务。经典数学以严格定律完成的，是值为同伦类型的半单纯空间，不是半单纯集合。

**证据走到哪一级**：

| 台阶 | 状态 |
|---|---|
| 形式事实 | 已到。上述各条由内核检查通过，各有负控制；16 个运行在 Linux 重放，与 macOS 原收据一致（`FORMAL_CHECKED_WITH_SCOPE / CROSS_PLATFORM_REPLAYED`） |
| 从事实到“做不完” | 统一定义的不可能性是开放问题，没有被证明；“各层是 t 层时补到第 t+1 级”的一般形式是元层论证，没有机器化 |
| 研究发起人的判定 | 09-27 的总判定把芝诺线算作复活。社区稿 01 第 9 节把这句判定读作对两个待裁定问题的肯定回答（现实里“相同”是否落定为事实；“每层做得到、缺统一方法”算不算无法完成），但判定没有逐字回答它们。是否升为“条件式合格命中”，方向追踪写明由研究发起人裁定，AI 不自证 |
| 社区审计、外部复核、Terra | 都还没有发生；给 Terra 的回信 019、补充信 020 待研究发起人转交 |

**最强反方与撤回条件**：

- “只是还没有人想出来”：这是最大的风险，也是明确的撤回条件。书式 HoTT 里一旦出现半单纯类型的统一定义（包括把 Herbelin–Ramachandra 2026 第 6 节的展望实现出来），强形式立刻撤回。
- “物理上，结构式的相同更贴近现实”【来源转述】：在高阶规范对称里，弱 2-群被认为更贴近物理，实践中常改用严格 2-群。【判断】所以“现实里的相同终究落定为事实”在这个领域并不自明；不过实践里截断后退的办法，正是在定律一层加回事实式的相同，这与本线的归因同向，但不替研究发起人作答。

**归因**（KC-000049：正题，待与研究发起人讨论；全文见社区稿 01 第 7 节）：

- 候选前提：A 单价性；B 内涵相等；C 一切类型都是“纤维的”，没有事实式的层；D 内层自然数没有和外层（事实式的）自然数绑定；E 统一性要求；以及现实侧前提“面的面对得上是一次落定的事实”。
- 竞争归因与区分证据：B 是普通类型论也有的，但 HoTT 的特殊之处是 A 关掉了“加 K”这条退路；按截断层数的对照把病因定位到“相同的层数”；已知的修复都要加回事实式的相同，还要绑定自然数（去掉 C 与 D）。
- 判断【判断，有条件】：起作用的是 A 与 C 合在一起，即理论内部只有结构式的相同，而且在宇宙上层数没有上限；已知修复还要 D。条件是开放问题保持开放，或得到否定的回答。

## 2. 罗素幽灵（B 向：现实里做不完，理论却当作已经做完）

**一句话**【解释，AI】：宇宙是 HoTT 不能不放进论域的东西，单价性这条规则本身就是在说它。追问它是否存在，按我们的落实（解释桥），就是一层层问“它的成员以什么方式相同”：在“相同是事实”的世界里第一步就答完；只装集合的目录第二步答完；装一切类型的最低宇宙（含高阶归纳类型），HoTT 自己的证明在每一层都答“没有落定”。把逐层追问写成程序之后，HoTT 在内部证明：无论谁来判定每一层，这个程序都永远交不出答案（2026-09-30，内核检查）；读到现实中的运行上，仍以所用理论一致为前提。可是 HoTT 用一条形成规则，一次就把宇宙交了出来，所有运算从一开始就在它上面运转。这和罗素的结构一样：现实里做不完的追问，理论当作已经完成（形状不同：罗素的 S 来回振荡，宇宙一路上升）。

**短链**：

1. **取舍**：宇宙作为论域元素，由形成规则一次交出（`Type ℓ : Type (ℓ+1)`），单价性从一开始就在它上面运转。
2. **过程**（解释桥，研究者的落实，最需要哲学审计）：把“追问宇宙的存在性”落实为过程 Q，一层层问“成员以什么方式相同”，问到“至多一种方式”就停。
3. **观察**：
   - 事实世界（Lean 4）里，装一切类型的目录第一步就停（CG001-C-72）；
   - HoTT 里，装一切集合的目录第二步停（CG001-C-71，加上 CG001-C-76 给出的上界）；
   - HoTT（含高阶归纳类型）里，最低宇宙对每一层都答“否”（CG001-C-75）；
   - 不用高阶归纳类型时，落不定的是宇宙塔：Kraus–Sattler 定理 5.9、5.10 对一切 n 在本仓库机器重放，并有名称级的“无高阶归纳类型”证书。
   - 把 Q 写成带判定器的 Delay 程序（判定器每一层交出“是”或“否”的证明）：程序停下，当且仅当目录在某个有限层落定（CG001-C-77）；在最低宇宙上，对任何判定器它都等于永不停机的程序 `never`，任何有限步的运行都拿不到答案（CG001-C-78）；同一个程序在 h-层为 1+n 的类型的目录上恰好第 1+n 问停；按同一组方程转写到 Lean，宇宙第 1 问停（CG001-C-79、CG001-C-80）。
4. **反解释检查**：
   - “追问方式天生停不下来”：对 ℕ、Bool 第一步就停，对集合目录第二步停，Q 有区分力；程序化之后这是定理：停下恰好等于“在某个有限层落定”（CG001-C-77）；
   - “全是高阶归纳类型的锅”：拿掉它，上升仍在，只是主语从单个宇宙变成宇宙塔；
   - “有限证明就是回答”：有限证明交出的，恰恰是“落定的那一层不存在”的证书（社区稿 02 第 5 节）。程序化之后，这是两个完成标准不同的程序：问“有没有一层落定”的程序第 0 步就答“没有”，问“哪一层落定”的程序永远交不出（CG001-C-78）。

**证据走到哪一级**：

| 台阶 | 状态 |
|---|---|
| 形式事实 | 已到。三级阶梯的每一格由内核检查通过并有负控制；最低宇宙“每一层都答否”是机器事实（用了高阶归纳类型）；宇宙塔的一般 n 重放带名称级证书（`FORMAL_CHECKED_WITH_SCOPE`） |
| 从事实到“停不下来” | 2026-09-30 写成内部定理：对任何判定器，追问程序在最低宇宙上等于 `never`，任何有限步的运行都拿不到答案（CG001-C-78；内核检查，五个负控制，七个运行在 Linux 上精确重放，尚未在第二个平台重放；Claude 线的目标本地索引）。读成“现实中照程序跑永远拿不到答案”，还需所用理论一致，对任意判定器另需典范性（核心立方类型论已有典范性证明，来源转述）。owner（全景视野、方向追踪）在这一点上仍记为 `META_INFERENCE_NOT_MACHINIZED`，待授权更新 |
| 研究发起人的判定 | 09-27 的总判定把罗素线算作复活。终局判词第 1 节与社区稿 02 第 11 节按这句判定，把两道门读作“解释桥不改写、第一道门不算（存在要求落定的整体）、第二道门回避”，并写明这是解读；研究发起人一句话确认或改写，才算逐字裁定（方向追踪的状态是 `BRIDGE_AND_EXISTENCE_PREMISE_UNADJUDICATED`） |
| 社区审计、外部复核 | 都还没有发生；外部复核请求已成文：`Cloud-Opus审计并补完GLM/13-外部复核请求.md` |

**最强反方**：

- “存在不等于落定”：宇宙由它分类类型族的能力完整刻画，逐层追问只是对一个已存在对象的无穷描述。【判断】这是对现实侧前提的否定，逻辑上成立，由研究发起人裁定。
- “拒付有代价”：ZF 把一切集合的总体拒为真类，从此不能对它做数学；HoTT 授信，换来可运算的宇宙和单价性。【判断】这是成本收益论证，它确认了归因（授信正是经济收益所在），不否认现象本身。

**归因**（KC-000049：正题，待与研究发起人讨论；全文见社区稿 02 第 9 节）：

- 候选前提：单价性；高阶归纳类型；宇宙是论域元素（形成规则）；宇宙大小分层；解释桥；现实侧前提。
- 判断【判断，有条件】：永不停来自三件事的合取。单价性负责“抬一层”，高阶归纳类型负责“没有上限的高度”，形成规则负责“不能不答，而且一次交出”。研究者的倾向是：决定项在普适性的理想化（这是倾向，不是结论）。条件是现实侧前提与解释桥被接受。2026-09-30 的程序版本给了同一个过程上的对照：按同一组方程转写到“相同是事实”的 Lean（粗粒度），第 1 问停；在 Cubical Agda 里保留单价性、给成员高度设上限 1+n，同一个程序第 1+n 问停（CG001-C-79、CG001-C-80）。

## 3. 两条线的共同点

【解释，AI】两条线盯的是同一个取舍：单价性把“相同”变成了结构。芝诺面看它让“完成一个定义”变得做不完（A 向）；罗素面看它让“一个做不完的追问”被理论一次交付（B 向）。CN-038 把这两面称为同一条 A7 线的芝诺面与罗素面。两条线都落在研究发起人说过的位置上：【用户原话，KC-000029，节选】「就是它想要理论的经济收益的地方」。这是对应，不是预言。

## 4. 不宣称

- HoTT 不一致。HoTT 有模型，全部机器证明也没有推出任何矛盾。
- 半单纯类型在书式 HoTT 中不可定义。这是开放问题。
- “追问永不停机”对现实中的运行已经无条件成立。内核检查的是理论内部的定理（CG001-C-78）；读到现实运行上，还要以所用理论一致为前提。
- 解释桥与“存在要求落定”的哲学正当性已经成立。它们交社区审计。
- 研究发起人的判定是数学定理。
