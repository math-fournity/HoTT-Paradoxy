## 核心设计原则（本目录自守）

1. **不重建**：GPT 方案 v2.1 的十片是九轮证伪程序的可靠收敛，本目录只 patch 其缺口，不推翻。
2. **不越权**：本目录不碰 goal.md / STATE / MEMORY / 方向 / 全景 / 核心认知 / claim matrix /
   Git commit 的写回；采纳由 canonical integrator 在授权下执行。
3. **可证伪**：每个增补片的采纳判据都写成可勾选/可反证的形式（延续 GPT 方案 006/010 的
   自证伪纪律）。
4. **不新增数学定理**：本目录不含任何新数学 claim，只改工作排序、阈值、降级路线与治理条款。

## 与 GPT 方案 v2.1 的合并方式

采纳时，canonical integrator 将本目录的每个增补片内容并入对应 GPT 原片（或作为独立子条款
追加），并在原片头部登记修订依据（引用本审计报告 + 用户裁定），不回改 GPT 原片的历史字节。
