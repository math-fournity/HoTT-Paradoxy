## 2. 任务合同（六面规格，按 Astra 方法论）

| 面 | 本单元的固定内容 |
|---|---|
| 对象 X | 带指定点的圆 C_pt；M = 去点结果（携带来源胚型）；N = (0,1)（无来源） |
| 输入 | M 与 N 各自的构造记录（M 必须携带「来自 C_pt 去点」的来源证据） |
| 输出 | H-同胚的构造与证明；R-分离的构造与证明 |
| 允许操作 | HoTT 原生类型构造（Σ/路径/HIT）；**禁止** postulate 任何待证命题 |
| 观察 | 消费者能否从对象中取出「断点三件套」信息（M 可、N 不可） |
| 完成 | 单元级：模块过核 + 正控制成立 + 靶形陈述（全称主张**不做**，只登记为下一单元） |

## 3. 成功/失败判据

- **成功（单元级）**：`RingOrigin` 模块过核——(a) M 的来源携带类型可构造；
  (b) 正控制：携带来源的合法构造被接受（无 postulate、--safe）；(c) 靶形
  陈述：裸 N 类型上「断点取出函数」不可定义（以类型陈述，不必强证不可定义——
  可用「M 的取出函数类型 inhabited + N 的对应类型为空或结构不同」的可核形式）。
- **失败/收尾**：形式化中若发现 R 信息可经 univalence 自动保留（即 Σ 携带
  冗余），如实登记 `SOURCE_CARRY_REDUNDANT`——这本身是有价值结论（「植入」
  假说在该形态下不成立）。
- **边界**：本单元**不**声称找到了 HoTT 共同体的实际「植入」现场（那是下一
  单元的语料狩猎）；不声称圆环悖论已完整形式化（点集拓扑全建模是后续单元）；
  不声称 HoTT 不一致。
