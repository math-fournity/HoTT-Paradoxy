# ADR-002：HoTT 现实相对悖论与原文优先交接

状态：`ACCEPTED`

日期：2026-09-01

来源：R-007、HOTT-005、HOTT-006。

## 背景

长期对话显示两类重复漂移：一是把用户要找的理论—现实悖论改写成 `HoTT ⊢ ⊥`；二是把计算
合法性、时间和圆环/芝诺参照收缩成一般因子化或无规范选点。旧 1,081 文件交接包证明字节快照
完整不等于未来 AI 能恢复正确工作意识；Better Best 原文此前还停留在临时 attachment 路径。

## 决定

1. 当前研究目标改为寻找合法 HoTT 推演在现实过程解释中的非现实性；内部不一致不是 P0。
2. 用户逐字原文进入 `HoTT/sources/user-originals/`，并在相关 Session 中先于 AI 规范解释读取。
3. `HoTT/Z_LAW_REALITY_RELATIVE_PARADOXES.md` 是 Z/计算合法性/候选排序的唯一 current owner；
   `INTRINSIC_TEMPORALITY_OF_HOTT.md` 保持具体演算时间分层职责。
4. 同函数异时为第一候选；Guard-Erasure 的具体 HoTT 遗忘翻译为主要开放目标；无规范较早事件
   降为支持性实例。
5. 未来 Session 交接采用 living governance routing + Fresh Session 理解检查，不建立第二个 current
   handoff 压缩包或每 Session 一份交接文档。

## 被否方案

- **再打一个全目录压缩包**：可保存字节，不能决定当前真值，且会复制历史/规范/快照状态。
- **只写 AI 摘要**：会删除“序列点、落定、计算合法性、抽象否定”等原始指导力。
- **把全文塞进 AGENTS/MEMORY**：破坏职责并制造多份当前正文。
- **继续以 no-canonical-earlier-event 为 P0**：它是无截面实例，不产生用户要找的非现实过程。
- **重建 45 包平台**：管理复杂度大于当前两个技术目标。

## 后果

- 未来 AI 必须先读原文，启动成本略增，但关键用户语义不再依赖压缩摘要。
- HOTT-006 在真正 Fresh Session 验收前保持“已实现待验证”。
- 同函数异时仍只是纸笔/文献支持候选；需 project formalization 与外部校准。
- 现有旧审计和只读交接包继续保留历史身份，不被删除或回写。

## 重审条件

- 用户改变现实相对悖论目标；
- Fresh Session 证明当前读取链仍不能恢复工作意识；
- owner 发生职责重叠或上下文成本真实接近 host 限制；
- 同函数异时被严格反驳或由更强、同样合法的 HoTT 现实悖论替代。
