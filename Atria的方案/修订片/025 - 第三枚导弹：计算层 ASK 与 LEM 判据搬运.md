## 1. 关键技术核查（构思之前必须钉死的三件事）

### 1.1 HoTT 的 S¹ 不是经典拓扑学的 S¹——「圆去掉一点」在 HoTT 中无对应物

对用户「传统拓扑学是 HoTT 的前提」这一命题（记 C5）的核查：

- HoTT 的 `S¹` 是 higher inductive type，**只有一个点构造子** `base` 与一条路径
  构造子 `loop : base = base`。经典拓扑学的 `S¹` 有不可数多个点。
- 按最直接的写法 `Σ (x : S¹), x ≠ base`（`≠` = `¬ (x = base)`）：对任意 `x : S¹`，
  `x = base` 可 inhabited（`S¹` 只有一个点），故 `¬ (x = base)` 对所有 `x` 皆不成立，
  该 Σ 类型**是空类型**，**不是** `(0,1)`。
- 结论：经典拓扑学的 `M = S¹\{p} ≅ (0,1)`、以及单点紧化把 `(0,1)` 变回 `S¹`，
  **不是 HoTT 的前提**，也不能被原样搬进 HoTT。HoTT 的「拓扑」是同伦论式的
  （∞-groupoid / identity type），不是点集拓扑式的
  （开集 / 稠密性 / 极限点 / 紧化）。
- **因此 C5 字面不成立**。这与上一轮错误的形态同型：上一轮太轻易接受
  「拓扑学可以做到」（形式可构造 ≠ 完成）；这一轮不能太轻易接受
  「拓扑学被 HoTT 当前提」（理论间搬运 ≠ 前提关系）。

**但 C5 的方法论内容保留**：`M≅N` 与「实数 = cut」是**同一个否定现实动作的两个
投影**——前者说「完成空间 ≅ 缺口空间」（静态等价），后者说「理想元素 = 无穷逼近的
完成」（声明等价）。两者共享同一动作：**把「到达」替换为「宣布已在」**。
这才是 M=N 在 HoTT 中的藏身之处（GLM §4.3 独立给出同一判定）。

### 1.2 「把过程替换成已完成对象」这一族原则，在 HoTT 中真实存在且逐字可定位

- **univalence**（等价即相等）：把「构造双向映射」替换成「它们相等」的静态事实。
  方向是**同质化**——把可区分者判为同一个。
- **命题截断 `‖A‖`**：把「存在构造」替换成「存在性成立」，元素**不携带见证**。
- **存在量词 = Σ 类型**：`∃ x, P x` 的元素是**已完成的对** `(x, proof)`。
- **LEM**：`P ∨ ¬P` 被当作一个**已完成的判断**，而做出该判断需要执行判定过程。

其中与「无限逼近/极限」最同形、且**已被本项目登记**的是两条：**F2-2 LEM**
（PREMISE-001 008 片：「LEM 断言 `P ∨ ¬P` 有 inhabitant，即结果已经存在，
但完全不给出判定过程」）与 **F2-7 Dedekind-Ω 的 Ω 依赖链**（Book §11.2 自陈：
实数取值命题要塌缩到单一 Ω 须假设 **§3.5 resizing** 或 **§3.4 LEM**）。

**修正后的精确靶子 = Book §11.2 自陈的 Ω 依赖链**：这是 HoTT **内部自陈的**、
把「实数作为已完成对象」与「LEM」绑在一起的那条接缝。打击点因此从「HoTT 内核」
（不可证，repo 禁止预设）移到「HoTT + 经典叠加的接缝处」（可证、可逐字定位、
且 HoTT 自己承认这条链）。**这是加强而非削弱用户的构想**——它把「否定现实的元素」
定位在 HoTT 自己指认的位置上。

### 1.3 「A 可停机、B 不停机、A≡B」在纯类型论中不可能

若 A 与 B 是同一判据（同类型、同归约关系）下的项且 **A ≡ B（判断式相等）**，
则它们有相同正规形，停机性必然相同（规范化唯一性，类型论标准元定理；本轮未跑核，
按标准结果陈述）。若能构造「HoTT 判定合法、类型良好、但实际不停机」的项，
那本身就是 HoTT 的不一致性证明——repo 明文禁止预设。
**所以用户命题 ③（A=B）不可能是项相等。** §2 给出它唯一能合法成立的形态。

## 2. 计算过程 A 与 B 的构思（采纳 GLM 形态 + 本 Session 核查）

**关键设计（GLM §5，本 Session 核查接受）**：A 与 B 必须是**同一任务的两个规格**，
差别只在「理想元素是否被当作已给定的输入」：

- **共同任务**：确定 √2 在有理数中的位置。
- **过程 A ——「读出」`read-position`**：输入是 √2 的 Dedekind cut
  （`(L, U) : (ℚ → Ω) × (ℚ → Ω)`，满足 inhabited / rounded / disjoint / located）；
  动作是对任意 `q : ℚ` 回答「`q` 在下集还是上集」；**停机立即**——答案存在输入里，
  读出是一步操作。**A 的合法性完全来自「把理想元素当作已到手的输入」。**
  这正是 023 片要求**预先生成的反弹**（「实数就是 cut，直接读」）被升格为 A 的定义：
  本 Session AI 当初「把单点紧化当作可以做到」的那处错误，经
  个人失误（022）→ 系统性反弹（023）→ **前提层进口识别（本片）**三次升格，
  成为 A 的弹体。
- **过程 B ——「算出」`compute-position`**：只准用 ℚ 与其算术，不给 cut；
  交付类型 `Spec_B = Σ (q : ℚ), (q · q) ≡ 2r`。停机条件是输出相遇点。

**A 合法的地位**：数据层合法性（规格类型有居住者），**不是**过程层停机定理；
且 `Spec_A` 的居住性依赖 LEM/Ω 构造那条腿，**必须逐字标注**（不能藏在"显然"里）。

**B 非法的地位**：由 M1（已收据）+ M2（待发射）：M1 证「这条最优夹钳永不闭合」，
M2 证 `¬ (Σ q : ℚ, q · q ≡ 2r)`——**交付类型的居住性被机械证明为空**。
这不是"还没停"，是"**不可能停**"：构造系统能表达的最强「不可完成」。

## 3. A=B 的真实身份：前提层进口识别 + 引理候选 M3-L1（本片核心）

### 3.1 引理候选 M3-L1（GLM §6.1 提出，本 Session 接受）

> 在含 M2 结论的 HoTT 中，可证 **`¬ (Spec_A ≃ Spec_B)`**（两规格类型不等价）。
>
> 论证骨架（机械可查）：若 `Spec_A ≃ Spec_B`，等价映射传输居住性；
> `Spec_A` 居住（cut-as-data 构造，LEM 依赖须带进假设清单）⟹ `Spec_B` 居住；
> 与 M2 的 `¬ (Σ q, q·q≡2)` 矛盾。

**这个引理候选的含义是严厉的**：**HoTT 自己的核，在前两枚战果之上，证明了
「读出任务」与「算出任务」不等价。而理论的工作方式——「实数就是 cut」、
「位置已经确定」——恰恰把它们当作同一任务在使用。** 这个「当作」不在核里、
不在任何定理里，**只住在前提层**。

### 3.2 逼选结构（第三枚的引爆方式，替代「逻辑炸弹」字面读法）

理论必须二选一：

- **要么**放弃「实数位置已确定」的工作方式（A 不再冒充 B 的完成）——
  那么传统完备化带来的全部经济性（§11.2 的整个实数层）失去其「已完成」身份；
- **要么**保留该工作方式——那么理论在明知的、核可证的 `Spec_A ≄ Spec_B` 之上，
  仍以同一性使用两者：非现实性**在被使用的位置**上被机械暴露。

**两支都命中，无处逃逸。** 这就是 `PROCESS_DECLARATION_GAP` 的第三条腿——
**识别腿**（候选名 `IDENTIFIED_TASK_VERDICT_COLLISION`，仅候选）：
过程层（M1）+ 声明层（M2）+ **识别层（M3-L1）**。
