# 覆盖阴影与同族坍缩的强制披露纪律

> 对 012 片（现象新颖性披露）的**跨族层补强**。012 片要求单族分答"旧文法是否已可部分表达"；
> 本片要求**跨族**披露两件 012 片没覆盖的事：方向覆盖阴影与多成员族的同族坍缩。
> 本片不新增数学承诺，不改 011 片的机械纪律。
> 触发来源：`reflection`（PREMISE-001 step-6 omission audit，2026-09-16，
> `audit/PREMISE-001-STEP6-OMISSION-AUDIT-20260916.md` §二 O-1/O-2/O-3）。

## 1. 问题（observed，跨族差分）

三族（E-02 / A-03 / B-01）的 93 个越界见证**全部**是 delay-equivalent 对，
共享同一分离机制族（value_mismatch / deadline_observation / completion_divergence）。
原因是结构性的：`_witness_separates` 的前置条件就是 `delay_equivalent(left, right)`，
所以 delay 片段内一切分离天然是方向 B 的形状（理论识别了一对、观察层不同意）。

两个后果，当前方案条款都没有要求披露：

1. **方向覆盖阴影**：方向 A（现实可完成而理论化引入额外完成困难）在 delay 片段内
   **没有对象承担**。一个真实的方向 A 候选已存在于信封外（2LTT 受限接口完成真实任务，
   `RESTRICTED_INTERFACES_COMPLETE_REAL_TASKS`），但 GEN-001 链无法消费它。
   不披露会把"三族链贯通"误读成"两个方向都被覆盖"。
2. **同族坍缩**：多成员族（DIVISIBILITY 三联 D-01/E-04/G-03）的成员可能共享同一机制
   pattern。CE-MAP 已有先例：6 个候选被归约为 1 个 pattern（scope promotion），
   判词 `PATTERN_REDUCED_NOT_CERTIFIED_AS_FULL_TASK_EQUIVALENCE`。
   不披露会按成员数放大 O-1 式的重复计数。

## 2. 新增纪律（强制）

### 2.1 每个多成员族必须加答"同族坍缩"一问

修订片 012 §2 的三问之后，**多成员族**（一个 task family 含 ≥2 个 PREMISE 成员）
必须加答第四问：

```text
Q4 同族坍缩：本族的多个成员是否共享同一机制 pattern？
  - 若共享：登记 PATTERN_REDUCED_NOT_CERTIFIED_AS_FULL_TASK_EQUIVALENCE，
    说明共享的机制层与各成员的差异层（consumer / observation / completion），
    并只报一个验收单元（其余成员作为该 pattern 的实例列出，不各报一个单元）。
  - 若不共享：给出区分证据（机制层的可观察差异，不是 consumer 名字不同）。
  - 若无法判定：登记 UNCERTAIN_PATTERN_RELATION，列出可判别的最小实验，
    不得默认"不共享"。
```

**理由**：CE-MAP 的归约是**机器可复算的**（6→1 有收据），不是主观判断。
GEN-001 验收单元若不沿用同一归约标准，会在跨族层面产生 CE-MAP 已经修正过的
重复计数。

### 2.2 每个 GEN-001 交付包必须携带方向覆盖声明

`GEN-001-INDEX.md` 与每个族的 REPORT 必须在"禁止外推"段加一行：

```text
本族的分离机制属方向 B（delay-equivalent 对 + 观察层不同意）。
方向 A（现实可完成、理论引入额外困难）在 delay 片段内无对象承担，
故本索引不声称覆盖方向 A。登记：DIRECTION_A_UNREPRESENTABLE_IN_DELAY_FRAGMENT。
```

**理由**：这是对"机器统观覆盖了两个方向"这一误读的**预防性**披露，
成本极低（一行），但防止后续把方向 B 的成功读成全方向成功。
已验收三族按 012 片 §4 的不重跑原则，只在 INDEX 的禁止外推段补这一行，
不重跑族的执行链。

### 2.3 step-6 omission audit 的最低内容要求

后续每个 bounded pass 之后的 step-6 审计必须包含：

1. 至少一个**独立 taxonomy/source/framework/holdout**（不得复用建分母用的来源）；
2. 跨族机制差分（把已完成族的越界见证按机制族对齐，报告重叠比例）；
3. 七类 UnknownIngress 的**逐类状态**（新增 / 更新 / 未新增；"未新增"是观察不是不存在）；
4. 明确的 `revised` / `no-plan-change` 裁决，`revised` 必须指向新修订片。

**理由**：step-1 审计只做了分母层的遗漏检查；step-6 若只复用同一来源，
会系统性漏掉机制层与方向层的阴影。本条把 step-6 的最低内容钉死。

## 3. 对现有条款的影响

| 条款 | 影响 |

| 003 片 §4（覆盖要求） | 补：覆盖声明必须含方向覆盖（2.2） |
| 011 片 §2（越界理由唯一） | 不变（机械纪律不动） |
| 012 片 §2（三问） | 补 Q4（仅多成员族，2.1） |
| 006 片 §5（ingress 登记） | 补：ingress 必须逐类列状态（2.3 第 3 点） |
| 009 片（P3/P4 自动化 + 外部审计） | 不变；本片的披露全部进审计层，不改判定权限 |

## 4. 已验收族的处置（不重跑）

- 三族（E-02 / A-03 / B-01）的执行链不重跑；O-1 的跨族披露由 step-6 审计文件承担。
- `GEN-001-INDEX.md` 的禁止外推段补 2.2 的方向覆盖声明（一次提交）。
- DIVISIBILITY 三联是**首个**适用 Q4 的多成员族：跑之前本片已生效，
  故其 REPORT 必须含 Q4 答案；若判共享，只报一个验收单元。

## 5. 本片不声称

- 不声称三族应被合并或作废（文法新颖性成立，机械 PASS）。
- 不声称 DIVISIBILITY 三联确实同型（Q4 要求判定，本片不预判）。
- 不声称方向 A 的 2LTT 候选是"非现实前提"（P3/P4 + GEN-001 + 原生核才能升级）。
- 不声称补了方向 A 的表达能力（那需改冻结引擎或换片段，超出本片范围；只登记缺口）。
- 本片无数学结论（F-011）。
