# 自我审计升级：论证化、逐段落、分片化

> 修订对象：本方案 017 片 §3「关键判定可审计清单」+ 治理 Skill `hott-local-session-governance` §5
> 「逐 KC 回评」+ SOP `hott-paradox-search-sop` §3 的 S-4/S-6。
> 触发来源：用户 2026-09-17 裁定——自我审计必须逐条走过核心认知、逐段落走过扩展认知，
> 输出的是论证报告而非是非答案；要针对**已走过的路**与**即将作出的选择**写分析；
> 审计产出是**分片文件集**，不是单文件。`source=user`。

## 1. 被修订的旧合同及其不足

旧审计合同（017 片 §3 + 治理 Skill §5）规定：每个单元在
`.codex/research/hott/sessions/<SID>/CORE_COGNITION_AUDIT.md` 保存全量表，每条 KC 一行
`kc_id | relation | assessment | evidence_locators | unresolved_note`，覆盖全部 46 条。
扩展认知（四件套第四件）**只以 `essay_change: 有/无` 一个字段出席**。

不足（本次修订的诊断）：

1. **颗粒度只到条，不到论证**。一行 `assessment` 可以写「ALIGNED：本单元用 Theory Schema 先行」，
   这既不能证伪，也不能让外部审计者判断「为什么是 ALIGNED 而不是 TENSION」。它是一个断言，
   不是一个论证。
2. **扩展认知被完全旁路**。扩展认知 8 片是「思想展开」层，它教的是工作姿态（先发现后归因、
   ASK、两种方向、现实对齐、骨架式模仿、知识谱当对象）。工作姿态的偏航不会在任何 KC 的
   一行表格里显形——它显形在「下一步为什么选这个」里。旧合同没有要求审计下一步。
3. **不审计未来**。旧合同只回评本单元做过的事。但偏航最危险的位置是**选择点**：
   下一单元是区间 I 设计探针、还是 V2 第二族 G-c、还是 SUPPLY-010？这个选择与核心认知 /
   扩展认知的关系，旧合同完全不问。
4. **单文件无法承载论证**。46 条 KC 的逐条论证 + 8 片逐段落论证 + 已走路复盘 + 未来选择分析，
   单文件必然超 300 行软目标，从而要么压缩回一行（退化），要么违反分片合同。

## 2. 新合同：审计的产出形态

`CORE_COGNITION_AUDIT.md` 从**单文件全量表**变为**逻辑文档索引**（`governance-shard-index:v2`）：

```text
.codex/research/hott/sessions/<SID>/
  CORE_COGNITION_AUDIT.md          # 索引：banner + 分片表 + 汇总计数 + 必填字段
  CORE_COGNITION_AUDIT/
    001 - 审计合同与证据基线.md
    002 - 核心认知逐条论证之一（KC-000001–KC-000024）.md
    003 - 核心认知逐条论证之二（KC-000025–KC-000046）.md
    004 - 扩展认知逐段落论证之一（shards 001–003）.md
    005 - 扩展认知逐段落论证之二（shards 004–006）.md
    006 - 扩展认知逐段落论证之三（shards 007–008）.md
    007 - 已走过的路：航向复盘.md
    008 - 即将作出的选择：偏航分析与裁决.md
```

约束：

- 索引保留 runtime 必需的 `SESSION_REQUIRED_FILES` 入口（`CORE_COGNITION_AUDIT.md` 路径不变，
  内容为索引），并自带 v2 banner、分片表、`last_shard`、`append_target`。
- **必填字段**（`core_change` / `direction_change` / `panorama_change` / `essay_change` /
  `update_decision` / `cross_conflicts` / `unresolved`）写在索引里，不散落分片。
- 每个分片第一行 H1 与索引表标题一致；新建分片必须与索引行、`last_shard` 在同一事务更新。
- checkpoint payload 必须把索引与**全部**分片作为事务文件写入；payload 自检新增
  「索引表内所有分片路径都在 files 中」的机械断言。

## 3. 新合同：核心认知逐条论证的必填五元组

每一条 KC（46 条全量，不得遗漏）必须给出：

```text
relation | 该条要求的工作姿态 | 已走过的路实际做了什么（含证据定位） | 论证：为什么是这个 relation | 对即将作出的选择的指令 + 反证条件
```

- `relation` 沿用 `ALIGNED / DEEPENED / CORRECTED / TENSION / DEVIATED / NOT_TOUCHED`。
- **NOT_TOUCHED 不等于不写论证**。即使未触及，也必须写清：该条要求什么姿态、本单元为什么
  没有触及它、**下一单元要做什么才会触及它**。这三行把 NOT_TOUCHED 从「诚实空格」升级为
  「可执行的未覆盖清单」。
- **TENSION / DEVIATED 必须带纠偏动作与回到航向的具体下一步**，不得只登记不处理。
- 每条的「反证条件」= 什么证据会让外部审计者把这个 relation 改判（例如「若引擎存在清单外
  的通用 dependent 生成器，则 A3 收窄」）。反证条件缺失的 relation 判为不合规。

## 4. 新合同：扩展认知逐段落论证

扩展认知 8 个分片，按**小节**（`##` 级）逐段审计，每段给出：

```text
该段教的工作姿态 | 已走过的路是否在这个姿态上（证据） | 偏航诊断 | 对即将作出的选择的指令
```

重点段（必须逐段、不得合并）：

- 001 片「在回答以前，先让问题真正发生」+「理论为什么要把世界变得简单」；
- 002 片「被改变的前提，怎样在结果里重新出现」+「时间与时序：先后关系不能穷尽时间问题」；
- 003 片「把静止的图景重新展开」+「在真与假之前，谁允许我们提出这个问题」+
  「两种方向：有时困难被制造，有时困难被抹去」；
- 004 片「走进 HoTT，保留问题」+「当理论把自己放进问题里」；
- 005 片「一个理论可以表达多少」+「让一篇文章变成思考的起点」；
- 006 片「把知识谱当作被考察对象」（第三条发现路径）；
- 007 片「AI 数学的两件事：助力、阻力与符号翻转」；
- 008 片「现实对齐：理论是现实的骨架式模仿」（含「对齐的断裂处 = 候选出发地」）。

允许的诚实结论：某段姿态**尚未被本链路真正执行**（例如 008 片的「用现实解释理论并在断裂处
停下」这一动作，机器统观链路只在其原始出发点上执行过，未系统执行于前提清单）。这类结论
必须写进分片 008（未来选择），并转化为下一单元的具体动作。

## 5. 新合同：已走过的路 + 即将作出的选择

分片 007（航向复盘）必答：从 PREMISE-001 step-1 到本单元，链路的每一步分别响应了哪些 KC /
哪些扩展认知段落；有没有一步的成就是用「分母内的干净穷举」替代了「发现」；累计的
`unresolved` 里哪些是**结构性未闭合**（不会因多做几个单元而消失），哪些只是**时间未到**。

分片 008（未来选择）必答，且**这是审计的落点**：

1. 列出当前 STATE 的 `next_minimal_verification` 指出的全部候选方向；
2. 每个方向：它由哪条 KC / 哪段扩展认知支持？它可能违反哪条？给出论证；
3. 裁决：选哪个、为什么、放弃哪些、放弃的理由；
4. 该裁决的**反证条件**（什么证据会让本 AI 撤回这个选择）；
5. 若裁决被后续证据推翻，回退路径是什么。

**009/017 的自动化纪律不因此改变**：裁决由 AI 自主作出、自主执行、全部留痕；不邀请用户介入；
外部 AI 追溯审计为终局复核。本片增加的是**留痕的深度**，不是新的介入点。

## 6. 与既有条款的关系

- 017 片 §3「关键判定可审计清单」：**扩展**。清单中的每个关键判定，其审计落位现在指向
  CORE_COGNITION_AUDIT 的具体分片（KC 论证分片或未来选择分片），不再指向单文件行号。
- 009 片 §3（P3P4_AUDIT_TRAIL）：不变。本片不放宽 P3/P4 的 steelman / falsifier 要求。
- 治理 Skill §5：按本片 §2–§5 重写（索引 + 分片 + 五元组 + 逐段落 + 未来选择）。
- SOP `hott-paradox-search-sop` §3 的 S-4（反思）与 S-6（收尾）：S-6 的「逐 KC 回评」
  升级为「按 020 产出分片审计集」；S-5 的裁决分流增加一条：**若审计产出改变下一单元的选择**，
  必须先更新 STATE 的 `next_minimal_verification`（经 checkpoint）再执行，不得审计归审计、
  执行归执行。
- 013/014 片的强制披露纪律：不变，仍按族执行。

## 7. 本片不声称的

- 本片提升的是**审计的可证伪性与未来选择的可追溯性**，不提升找到悖论的概率。
- 逐条论证仍可能出错；外部审计者可以推翻任何一条 relation，反证条件就是为这个准备的。
- 分片化不等于充分：一个把 46 条 KC 都写成 ALIGNED 的审计，即使分片合规、论证齐备，
  仍是失败审计——**判据是论证是否可被证伪，不是格式是否合规**。机械校验只覆盖结构。
