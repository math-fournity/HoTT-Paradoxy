# P3P4 自动化执行与外部审计层（角色重分工）

> 修订对象：本方案 007 片 §2/§3/§5/§7 与 008 片 §1/§3/§5/§6/§8/§9 中
> "P3/P4 必须由角色 B（用户）判定、AI 不得自证非现实性"的全部条款。
> 依据：用户 2026-09-16 明确裁定——"人可以做的，说给你听你可以理解，
> 那么事实上，就意味着你可以独立做"；AI 可以做 P3/P4，但必须留下可审计信息，
> 用户不再前瞻性介入，改由外部 AI 在全部完成后追溯审计。
> 修订性质：**把 P3/P4 从"用户专属判定层"改为"AI 执行 + 强制审计层 +
> 外部追溯审计"**。防火墙的内容（不自证为结论）保留，形式（沉默）取消。
> source=user。

## 1. 为什么这是修正而非放弃（assessment）

007 片把 P3/P4 判定权交给用户，理由是 KC-000043：AI 在最流利的层上助力与阻力重合，
自证不可信。这个理由在**"自证直接成为结论"**这个用法下成立，但它被错误地落地成
"AI 连候选都不许产出"，进而产生三处真实代价（本审计独立判断）：

1. **与 P2 的设计自相矛盾**：008 片已允许 AI 产出 `reality_skeleton` /
   `divergence_point` 并显式标为"候选解释、非结论、用户可否决"。P3 候选
   （"这个省略在该任务下确实不可省"）是对**同一个现实域**的同级判断，
   认识论风险与 P2 同类。禁 P2 的复制品而放行 P2，风险上不自洽。
2. **违反 KC-000046**：用户 2026-09-16 的修正明确"AI 缺的是用现实理解理论的
   **动作**，不是思考现实的**能力**"。在 P3 处禁掉这个动作，就是保证该能力
   永不发育。SOP 应当**要求**该动作，而不是在决定性处禁止它。
3. **销毁盲点证据**：35 行空白判定表把构造性劳动全压给用户，且项目获得零诊断数据。
   用户的否决模式本是关于"AI 的现实域盲点在哪里"的最高质量证据。用户已明确选择
   不再承担这 35 行；那么由 AI 产出候选、外部 AI 审计，是唯一仍能保留这份证据的形态。

**同时必须保留的**（本片不放宽）：P3/P4 的任何判定都**不是数学结论**，也不是
"该前提非现实"的已成立命题。它们是 `AI_ADJUDICATED_PENDING_EXTERNAL_AUDIT`
的候选判定，可以被外部审计推翻，推翻时必须能追溯并回滚全部下游产物。
MATH_PROOF_BEFORE_DELIVERY_V1 与 F-011 的地位完全不变。

## 2. 新角色分工（替换 007 片 §3 与 008 片 §3 的 P1–P4 表）

| 步骤 | 内容 | 归属（v2） | 理由 |
|---|---|---|---|
| **P1** | 前提逐字是什么、出处在哪里 | **角色 A（AI）** | 不变 |
| **P2** | 它替思考者节省了什么 | **角色 A（AI）** | 不变 |
| **P3** | 在什么任务下，被节省的条件重新变成不可省略 | **角色 A 执行，强制审计层** | 用户 2026-09-16 裁定 AI 可独立做；判定不成为结论，见 §3 |
| **P4** | 替代物换了什么 | **角色 A 执行，强制审计层** | 同上 |
| **AUDIT** | 逐条复核 P3/P4 的候选判定，可批准/推翻/要求重做 | **角色 D（外部 AI，用户安排）** | 用户不再前瞻介入；审计为追溯性、终局性 |
| **C** | 冻结任务族 → 枚举 → 保归约 → 原生核收据 | **角色 C（引擎）** | 不变 |

角色 B（用户）保留两项**非介入式**权威：**(a) 随时可以直接推翻任何 AI 判定**，
**(b) 定义外部审计的验收标准与审计者**。除此之外不要求用户逐条判定。

`reality_anchor_holder` 的合法取值从"必须是用户或用户明确授权来源"扩展为：
`用户` / `用户授权的外部 AI 审计者` / `AI(带审计层, pending)`。
第三种取值的条目全部带 `audit_status=AI_ADJUDICATED_PENDING_EXTERNAL_AUDIT`，
且不得在任何对外交付中被当作已成立结论。

## 3. 强制审计层：每条 P3/P4 判定的必填字段

AI 执行 P3/P4 时，每一条必须完整填写下列字段，缺一项则该条判定无效、
不得进入 SUPPLY_REGISTRATION：

```text
P3P4_AUDIT_TRAIL（角色 A 必填，缺一无效）
  / ai_verdict        : 非现实 | 现实 | 暂不判定
  / verdict_reason    : 判定论证；必须指明在哪个现实任务下、哪个被省略条件
                        重新不可省（P3），以及替代物换了什么（P4，仅非现实时）
  / reality_steelman  : 与该判定相反方向的最强论证。没有 steelman 的非现实判定
                        不合格（反 004 表构造偏见的硬纪律：每一行的
                        divergence_point 都被写成"理论节省了什么"，天然诱导
                        非现实读法；必须先给出"该省略其实可接受"的最强理由）
  / falsifier         : 什么观察/事实会推翻本判定（可操作、可指认）
  / confidence        : 高 | 中 | 低，附理由
  / corpus_self_audit : 本判定主要由"省略结构撑得起"还是由"语料流利度"驱动？
                        若后者，必须降一档置信度并说明
  / evidence_anchors  : 支撑本判定的现实域知识来源（文件/行/commit/可复现对象）
  / audit_status      : 固定 AI_ADJUDICATED_PENDING_EXTERNAL_AUDIT
                        （外部审计复核后改为 AUDITED_APPROVED 或 AUDITED_OVERTURNED）
  / depends_on        : 本判定若被推翻，哪些下游产物必须回滚（SUPPLY_REGISTRATION
                        ID / 冻结任务族 / GEN-001 run / CE-MAP 行）
```

**steelman 纪律**是本片的核心保护机制。它取代了旧防火墙的"沉默"，
代价更低且不阻断 KC-000046 的动作：AI 必须在判定非现实之前，先为
"该省略其实是可接受的"给出最强辩护。给不出强 steelman 的条目，
只能判 `暂不判定`，不得判 `非现实`。

## 4. 执行流变更（替换 008 片 §8 的 step 3）

```text
3. AI 逐条执行 P3/P4，必填 §3 的 P3P4_AUDIT_TRAIL 全部字段；
   全部标 AI_ADJUDICATED_PENDING_EXTERNAL_AUDIT。
   完成后整单提交（git），不改分母，不产生任何数学结论。
3a. 对判为"非现实"的条目执行 SUPPLY_REGISTRATION（登记审计链 + 回滚令），
    冻结任务族，进入 GEN-001 链。这些产物全部带 pending-audit 标记，
    可被外部审计一次性回滚。
3b. 外部 AI 审计（角色 D）：逐条复核 P3P4_AUDIT_TRAIL，
    输出 AUDITED_APPROVED / AUDITED_OVERTURNED / REDO_P2（否决现实域）。
    推翻时按 depends_on 回滚下游，并在 git log 留痕。
```

判定表 004 的表头同步修改：P3/P4 两列由 AI 填入候选判定 + 审计字段；
新增"AUDIT 复核"列由外部 AI 填入。用户列保留为可选的直接推翻通道。

## 6. 反解释与自我限定

- **本片不是"AI 可以自证非现实性"**：AI 可以**判定**，但判定是
  pending-audit 的候选，不是结论。任何"该前提非现实"的交付措辞
  仍需 MATH_PROOF_BEFORE_DELIVERY_V1 意义上的机器证明（经 GEN-001 链与原生核）。
- **本片不声称 AI 的现实判定可靠**：恰恰相反，§3 的全部字段存在的前提是
  "AI 的现实判定可能系统性出错，因此必须可追溯、可推翻、可回滚"。
  `corpus_self_audit` 字段把 KC-000043 的惯性从"禁止"改成"显式记账"。
- **steelman 纪律不保证无偏见**：它把 004 表的构造性偏见从隐含变成可见，
  不消除它。外部审计仍是终局判断层。
- **用户介入权的边界**：本片取消的是"必须等用户判定"这一阻塞，
  不取消用户的任何权利。用户随时可推翻、可暂停、可改回旧分工。
- **本片不产生数学结论**：全部为规程修订。F-011 不适用。
