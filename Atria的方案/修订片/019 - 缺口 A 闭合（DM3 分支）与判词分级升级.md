# 缺口 A 闭合（DM3 分支）与判词分级升级

来源：缺口 A 闭合单元（`TASK-FAMILY-GAP-A-INTERVAL-ORACLE-DE-MORGAN`）执行收据（2026-09-17）。
身份：方案修订（reflection=gap-a-closure-registration + verdict-grading）。本片
**不做 P3/P4 判定，不产生数学结论**（F-011），唯一登记的机械事实是**否定性**的
（布尔律非必需，作用域 = DM3）。AI 全自动执行（修订片 009/017），本片全部进审计层，
判词与关键判定均带可推翻条件。

## 1. 验收结论：`DM3_DE_MORGAN_CONFIRMED_NON_BOOLEAN_LIFT`

修订片 018 §3(A) 登记的缺口 A（区间 I 的 oracle 不存在）在**DM3 分支**上闭合：
V2 的三个结构性分离被搬到标准非布尔 De Morgan 代数 DM3（三元链 `0 < a < 1`，`~a = a`，
故 `a ∧ ¬a = a ≠ 0`）上，由 Cubical Agda 2.8.0 原生核逐项确认。详见
`HoTT/generators/GAP-A/GAP-A-DM3-REPORT.md`。

## 2. 判词分级升级（015 §5 强制披露的执行）

修订片 018 §3(A) 的 model-dependency 表把 V2-1 的 4 个 kernel 见证一律标为
`POINT_SET_MIRROR_MODEL_KERNEL_CONFIRMED`。本单元按**机制**分级：

| 机制 | 升级前（018） | 升级后（本片） | 依据 |
|---|---|---|---|
| `availability_observation` | `POINT_SET_MIRROR_MODEL_KERNEL_CONFIRMED`（WV-0001 依赖类 `SUPPLIED_SET_MEMBERSHIP`，不调点集专属律，但提升未核证） | **`DM3_DE_MORGAN_CONFIRMED_NON_BOOLEAN_LIFT`**——在非布尔 De Morgan 代数上由原生核确认，解释无关 | `VERIFY-GAP-A-DM3-WV-0230`（校准锚 `WV-A-availability`）+ BLI |
| `level_observation` | 同上（`BOUNDED_LEVEL_COMPARISON`，不调点集专属律） | **同上**——有界塔层级比较，有限可判定，解释无关 | `VERIFY-GAP-A-DM3-WV-0041 / WV-0001`（校准锚 `WV-L-level`）+ BLI |
| `density_observation` | **仅为模型层**（`FACE_LATTICE_ORDER` 调用点集序，mirror §10 证明不完备） | **分裂**：DM3 上由原生核确认（`VERIFY-GAP-A-DM3-WV-0158`，校准锚 `WV-D-density`）+ 布尔律非必需；但 **DM3 的链序仍是模型层**——DM3 是 `I` 的一个模型，不是 `I`。故判词**不声称**区间 `I` 上的稠密性分离成立 | WV-0158 + BLI + `non_embedding_check` |
| delay 轴 `value_mismatch` | `COMPUTATION_AXIS_BOOLEAN_PAYLOAD`，提升未核证 | **未变**（本单元不处理 delay 轴） | — |

**升级的净语义**：availability 与 level 两个机制从「模型层、提升未核证」升级为
「结构层、解释无关、原生核在非布尔 De Morgan 代数上确认」。density 仍**部分模型层**：
它的 DM3 实例被核确认，但「稠密性」这一现象依赖序结构，而 DM3 的序是模型的序。
**这不与 018 §4 的教训冲突，而是它的第一次正面应用**：本单元正是按
「是否需要点集专属律」排序，把两个不需要的机制先脱离点集模型。

## 3. 强制披露（随判词登记，外部审计优先看）

- **`interval_i_confirmed = false`（最重要）**：本片**不声称**任何分离在真实区间 `I` 上成立。
  `I` 的相等不可判定，无法写返回 `Bool` 的 `separates`。DM3 与点集面格都是**模型**；
  「DM3 结果能否提升回 `I`」仍是开放问题（§5）。
- **ingress 披露**：4 条 level 见证经共享 `tower` 机制被点集 V2 文法接受（DM3 坐标 = 0
  落在点集声明的面内）。`level_observation` 机制与点集片段共享，这些见证 L1 不可见但
  点集可复现，按 011/012 纪律登记为 ingress，**不计入**越界分母。
- **`scoped_all_reasons_unique = false` 的精确读法**：跨文法族拒因不同（delay 族不可解析 op
  vs 点集族不可表示 DM3 坐标）；**族内** 392/392 拒因唯一。这是更强而非更弱的证据；
  011 片的「越界理由唯一性」判据在多族场景下按族内唯一性执行，本片明确这一解释。
- **缺口 B 未变化**：12 个 symbolic-horn 文法为 schema 级 `BACKEND_MISMATCH`，
  本单元未对其跑机械检查——作用域边界，非已证不相交。
- **KEY_ADJUDICATION_AUDIT_TRAIL**（017 §3）：四路核 / BLI / 越界 / 非嵌入 / 判词升级
  五类判定均带 `question / verdict / verdict_reason / falsifier / audit_status`，
  存于各 verify run 的 `RUN.json`，推翻条件可操作（见 REPORT §6）。

## 4. 本单元 reflection（方案级）

1. **「缺口」与「单元」必须分开记账**：缺口 A 的原始表述是「DM3 **或真实区间**上的
   V2 值解释」。本单元闭合的是 **DM3 分支**；把「区间 I 分支」留为开放，而不是含糊地
   把 DM3 结果叙述成「区间 I 的 oracle 已建立」。判词里 `interval_i_confirmed` 与
   `gap_a_dm3_branch_closed` 两个布尔量分离，就是为了这个。
2. **018 §4 的排序教训被正面应用，并产出第一次分级**：V2-1 把三机制一律标
   `POINT_SET_MIRROR_MODEL_KERNEL_CONFIRMED` 是保守但**信息丢失**的。本单元证明
   availability/level 可脱离点集模型，density 只能部分脱离。**回写 LESSONS**：
   后续 V2 族与缺口闭合单元必须**按机制给出依赖类分级**，不得整族一个标签。
3. **BLI 单元是本单元价值最高的产物**：它把「点集模型携带了区间没有的布尔律」这一
   015 §3.4 的**预先警戒**，从模型论论证升级为**原生核确认的否定性机械事实**
   （`boolean_law_needed = false`，作用域 = DM3）。这是「可靠但不完备」这一表述的
   可核验版本：不需要布尔律，三分离照样产生。它同时给出一个可证伪的锚点：
   kernel ACCEPT `BLIFalsify.agda`（即 `dm3Meet da (dm3Neg da) ≡ d0`）将推翻它。
4. **017 自动化纪律第二次完整跑通**：门槛判定（G-a/G-b/G-c 三门槛同时命中，全部脱离
   点集面格）、作用域化（4 条 ingress 排出越界分母）、判词生成与分级、非嵌入 omission
   检查、checkpoint 与交付物，全部 AI 独立完成并留痕，**无 `AUTOMATION_BLOCKED_EVIDENCE_GAP`**；
   证据标准（F-011 / `DENOMINATOR_SINGLE_SOURCE` / remainder=0 / 四件套加载）一字未改。

## 5. 剩余开放问题（登记为可追责边界）

1. **区间 I 分支（缺口 A 的另一半，开放）**：DM3 是 `I` 的非布尔模型，不是 `I`。
   `I` 的相等不可判定 ⇒ 不能写 `Bool` 返回的 `separates`；`I` 上的分离必须以别的形态
   表达（类型族 / cofibration 条件 / PathP，而非 Bool 观察）。**这是一个设计探针问题**：
   须先确定「`I` 上能写什么」，再决定是否可验收。**若探针结论是「`Bool` 形态的分离在 `I`
   上结构性不可写，且替代形态改变了分离的定义」**，则登记为有界负结论并转 §5.2。
2. **V2 第二族（候选，结构性优先）**：G-c 层级塔的**独立供给**——`level_observation`
   已被本单元证明解释无关、结构层，是最干净的下一族；G-a 稠密族需序，优先级低。
   或 SUPPLY-010 新任务族。
3. **缺口 B（可选后续，不阻塞）**：对 12 个 symbolic-horn 文法补跑 schema 级不相交断言。
