## 1. 执行模式 vs 测试模式：本片的核心纪律

023 片把齐射结构落盘时，其措辞仍是「已打造未发射」「预期机械核验形态」
（`PENDING_KERNEL`）。用户指令把这一点彻底改写：

- **测试模式**（废止）：把「过程不可完成」「第二击无法被反弹」当作**待检验猜想**，
  交付物是论证结构与预期证据形态；未取得机械核验不影响交付。
- **执行模式**（本片确立）：策略（022/023 的齐射结构）一经确定即进入**执行**，
  交付物是**被原生核接受的证明代码 + run 收据**。「未跑核」不再是可接受的交付状态。

**唯一的合法中断条件**：策略本身有问题。此时必须**停下来讨论策略**，并把讨论结果
落盘为新修订片后再继续。策略没有问题时，继续打磨论证文本、扩充候选、增加同形
负结论，都不构成进展——这些是 014 片已登记的「分母内同形重复」风险在攻击链上的
直接翻版。

**与 017 片的关系**：017 片的「全面自动化」是**不邀请用户介入**；本片补的是
**不降低证据标准**：自动化取消的是等待，不是 `MATH_PROOF_BEFORE_DELIVERY_V1`。
两者叠加 = 全速执行 + 交付门禁不松。这两条共同构成本 repo 的执行纪律基线。

## 2. 「击落」的语义边界（不可漂移，违反即被门禁拒收）

用户指令中的「必须击落」是**执行强度**指令，不是**目标命题**的改写。本 repo
明文不预设 HoTT 不一致（AGENTS + PREMISE-001 008 片 §6）。因此：

- ✅ 「击落」在本 repo 的唯一可执行读法 = **把 `PROCESS_DECLARATION_GAP` 的
  非现实性数学锚定**：过程层给出「该过程在 ℚ 上不可完成」的**机器证明**；
  声明层给出「反弹所用的理想元素不对应任何过程完成」的**逐字定位与论证**。
- ❌ 误读一：把「必须击落」读成「必须在 HoTT 内导出矛盾 / 证明 HoTT 不一致」。
  这与 repo 纪律直接冲突，且 `MATH_PROOF_BEFORE_DELIVERY_V1` 会拒收任何
  未证却声称的版本。
- ❌ 误读二：把「必须击落」读成「必须让某个具体 run 失败/超时」。有限观察不证明
  全称命题（AGENTS 数学表述协议）；`timeout`/退出码只证明那一次观察。

**这一区分是本片的硬边界**：执行强度可以提高到「必须」，但命题语义必须保持在
「锚定非现实性」这一层。任何把导弹证明读成「HoTT 被证明矛盾」的交付措辞都是误读，
必须在交付文本中显式排除。

## 4. 第二枚规格（下一执行单元）

第二枚的**数学锚**必须是可机器证明的全称命题。可用三层锚点：

1. `√2 ∈ ℝ`——Book §11.2 源陈述，`SOURCE_REPORTED_NOT_REPLAYED`（源陈述可引，
   但不是本 repo 的机器证明）。
2. **`¬ (∃ q : ℚ, q · q ≡ 2)` 的全称形式**——**可机器证明，尚未证**。
   Pell 不变量只证了「这条最优序列永不闭合」，未证「任意有理数 q 的平方都不等于 2」。
   计划：下降法（无穷下降 / 良基归纳），目标库
   `Cubical.Data.Rationals`（ℚ = ℤ × ℕ₊₁ 的 set quotient，含 `_·_`/`_<_`/`discreteℚ`）；
   若 `Cubical.Induction.WellFounded` 接口不足，回退手写强归纳（分母良基序）。
   run-id `20260917-MP-DEDEKIND-OMEGA-M2-01`。
3. Ω 塌缩须假设 resizing 或 LEM——Book §11.2 源陈述，`SOURCE_REPORTED_NOT_REPLAYED`。

**为什么全称式是第二枚的正确锚**：反弹的形态是「实数就是那对开谓词，
不需要夹到相遇」。击穿反弹需要一个**独立于序列选择**的硬事实：任意有理数都不是
那个界——即夹钳缝隙**不可能**被任何有理过程关闭，不只这条序列没有关闭。
这正是 023 片 §2 第二枚「理想元素不对应任何过程完成」在 Dedekind-Ω 簇上的
可形式化核心。

**风险登记**：全称式需良基/强归纳下降证明（约 100–150 行盲写，中高风险）；
失败不降级命题强度，只换证明路径（手写强归纳 / 对分母的良基序 / 已有的
`Cubical.Data.Rationals` 离散性 + ℤ 上的良基结构）。

- **纯 HoTT 中 Dedekind 实数就是那一对开谓词**：cut 即缝隙本身，「理想中间点」
  读法在纯构造设置下可被辩护。第二枚的「理想元素不对应过程完成」因此是**论证**
  而非单一形式命题；它的强度来自 §4 的全称无理性 + Ω 依赖链的组合，不来自任何
  单一定理。本项**不构成策略错误**（不触发 §1 的「停下来讨论」），但它是
  **交付措辞的边界**：第二枚交付时必须标注为
